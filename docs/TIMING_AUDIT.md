## 先明确的六件事

1. **起卦法。**《先天后天论》分先天气期、后天卦数加时与动静数期。书中“先天、后天”的术语按原文使用，不能混成洛书九宫数。只有本卦和动爻，不能反推出唯一原数。
2. **应什么。** 得财、无财、破财不同；成交与交易损失不同；出行吉凶、出发日与归期不同；归迟并没有一个必然“宣告不归”的日期。
3. **何种时间。**《占卜克应之诀》说“应之期远，则以年，近则以月，又近则以日也”。申日与申时分别是日和时，原书没有统一选下一轮申酉、只取最近两个日期的规定。
4. **用哪张表。** 五行日气（mh-143）金为申酉；八卦时序（mh-052）乾列戌亥、兑列酉，两套按各自原文保存。不能把乾戌亥换成金申酉后仍称同一取法。
5. **数说的是什么。** 即成、渐成、稍迟没有被原文定成一二三天；“乾克体，阻一日”是有生扶又受克时的阻滞时长，不能变成第一天必败。物方时数、年月日时原数与成数不能互相替代。
6. **历法只是换算。** 甲戌日起下一次申酉在第10、11日，日支计算无误；把这次历法匹配直接认定为交易失败日，缺少原书要求的取法与事理判断。完整干支60日循环，日支12日循环，均不按公历或农历月初重置。

## 关键原句

- mh-058：“先天之卦，定事应之期，则取之卦气”；“后天则以卦数加时数，总之而分行卧坐立之迟速，以为事应之期。”
- mh-068：“如欲决其日辰，则以用卦之气数参决之。”
- mh-071：“欲知名成之日，生体之卦气详之。”
- mh-072：“欲知得财之日，生体之卦气定之。欲知破财之日，克体卦气定之。”
- mh-116：“看卦中有生体之卦，则事应于生体卦气之日；有克体之卦，则事败于克体卦气之日。”
- mh-122：“又若问行人，以生体之日为归期，无生体比和之日，则归必迟。”

27条完整引文、章节、原文偏移与章节哈希均保存在 `data/timing-audit.json`。10个卷一案例保留原断、反馈及时间措辞；观梅没有反馈不补写，牛案预测21日内与反馈20日分别保存。同盘古案不能复制给新盘。

月令与全盘生扶还要依mh-119论轻重。原文明说得令之体虽遇他卦克，亦无大害；某一克体支期不能独自证明“大凶”。本次接口的事件与日期是候选依据，不替代全盘总断。

日应是当日日气，刻应是当下外兆；观物趣时是时令取象。mh-146天时应属于占别事时的天气外应，不能与mh-063专占晴雨混成同一算法。mh-149条文中的含混措辞保留供检索，不据之编出具体天数。

## 待核文字及原数

- **mh-058“或坤为戌、亥之日时”**与mh-052坤未申、乾戌亥不合。上传本与本次在线对校本同载此文，疑乾字，未获纸本证据，不擅改；这句不驱动映射。
- **mh-108与109屋宅寿限**：按前章给数，田家合29、王家27、韩家44；后章寿限却载29、22、31。原断照录，22、31不冒充统一算法校验通过。
- **mh-078“主卦”**及后列天地否各动爻叙述需消歧；不把其矛盾反向改写384盘结构。
- **mh-040、041互卦生克措辞**：少年案有生也有克，牛案有比和也有克；不称所有互卦同向。
- **mh-116阻日数**属于时长，和未来日期分开。时序中的一四九等数词保留原样，未明定按尾数或轮次就不自动扩展。

以上问题在 `timing-audit.json.issues` 单独记录，和原来的结构问题清单并存。它们不是已经裁定的错字，原始上传资料不变。

## 用户旬空扩展

本次三卷未检出旬空、空亡专条。既有空亡规则来自用户另外提供的规则，继续独立保留，不能宣称其完整出自本书。

填实、冲实首先表示空象状态变化，不能自动证明钱已到、婚已成。旺空动空保留作用，部分命中不清零整卦。真空不因未来填冲自动恢复；这不等于取消凶应期。程序已经修正真空一律封掉凶期及数期的问题。

## 调用及日期边界

```js
const result=await stories.getStory({
  primaryId:42,movingLine:4,monthOrder:'spring-wood',domainId:'domain-11',
  voidContext:{ganzhi:'甲戌'},timingScale:'day',
  timingContext:{castingMethod:'pre-heaven',periodMethod:'element-qi'}
});
result.timingDecision.event;  // 交易不成，凶
result.timingDecision.period; // 申、酉日；selectedCycle:null
result.timing.calendarOccurrences; // 下一次匹配支日在第几日；selectedAsEventDate:false
```

以上是联调示例。采用 `trigram-periods` 时同一乾卦会查到戌亥，经卦时序与五行金日方法分别注明，不暗中替换。

`timingContext.castingMethod`记录先天、后天或未明手动；`periodMethod`记录五行卦气、经卦时序或数期。后天原数必须能复现原盘，`numericalApplicability`表示已经依据所问事情急缓判断数期适用，不是为让界面出日期而随手置真。`eventWindow:'today'`阻止把总数机械变成多日以后。数法仍须占者实际动静，不能把App里的跪拜镜头当作现实坐立输入。

临近日、远月年须有依据；月份的农历月序、地支与月令各自保留。公历具体年月日、当地时区、夏令时与换日点由CalendarProvider按明确政策转换。当前模块没有伪造该历法能力，也没有把下一个支日当唯一应验日。
