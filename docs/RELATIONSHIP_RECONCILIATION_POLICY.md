# 矛盾复合 · 这段已经结束的感情能复合吗？

正式问项为 `relationships.reconciliation.reconcile`，类型为 `relationship_reconciliation`。所问为已分开的两个人能否在双方自愿下恢复恋爱关系。联络重新开始、愿意谈当初的分歧、采取可持续的修复行动、明确同意复合，分别看待。复合后的稳定由正式目录中的另一问项处理。

## 古籍与断法

《梅花易数·人事占》mh-064 和《体用总诀》mh-061 以体为主，以用为事。用、体互、用互和变用分别对原体看开局、过程和末段，按 mh-117 的先后次序及 mh-119 的旺衰通看。各节点应用同一月令五态和直接生克，十二个月支分别索引。生体看修复中真正出现的支持，比和看彼此接应，体克用看是否有能力化开旧的难处，体生用看是否只有一方维系，用克体看当下仍未越过的分歧或界限。

《婚姻占》mh-067 所说相就用来类比双方各自有意愿且能彼此配合。能否重新在一起还要看导致分开的关键问题是否有实际改变，以及两人是否都明确愿意。《周易》各动爻依 mh-056《占卜总决》核读完整爻辞和条件，结合必要的王弼注、孔颖达疏。主证与反证逐篇记录。原体贯穿本互变，直接作用采用经典体用法。

## 应期

以 mh-116《占卦诀》及 mh-122《占卜克应之诀》照应事选节点及尺度，以 mh-143《日应》核对所取日支五行。近期见面、表达意愿、共同尝试修复或出现实际分歧具备可观察条件时，按该节点取日。古婚占的吉凶年月保留原适用条件。复合本身若无合适的尺度和取日依据，篇内明记未取日理由。

有据时每篇一项应事，按实际起卦日期先查当月剩余合格日，无候选再查下月，最多显示两个日期。历史盘沿用原日期，阅读文档使用标明的演示日期。完整爻辞、古籍依据和可折叠的计算说明沿用现有排版。

坎为水。初六入坎窞取在难中重蹈，不能因变位有援就抹去爻凶。九二《象》明言未出中，小得与复合分开。六三进退皆险而勿用，可留有用的善后，不移为利于重来。六四纳约自牖按王孔取朴素而明信。九五以真平为无咎的条件，仍在险中不等于已平。上六徽纆、丛棘据原典取羁系深而久，未据此断现实违法或用三岁算时间。

[《周易正义·坎》](https://zh.wikisource.org/wiki/周易正義/03坎)

[《周易正义·离》](https://zh.wikisource.org/wiki/周易正義/03離)

[《周易正义·咸》](https://zh.wikisource.org/wiki/周易正義/04咸)

雷风恒。初六据《象》始求深，有往来基础不宜立刻求深。九二能久于中则悔亡。九三以行为反复而受羞，须实际持续履约。九四久处不当而无获，着手位置须改。六五保留妇人吉与夫子凶原文，古注按角色区分守和断，现代用作是否该守或该变的两种责任，不按性别判。上六以频动为常反无功。

[《周易正义·恒》](https://zh.wikisource.org/wiki/周易正義/04恒)

天山遁。初六遯在后而有厉，《象》取不往避灾。六二牛革据王孔取中和厚顺而固志，条件是双方自愿。九三系遯有厉、小事可办而不可大事，不将臣妾转成当代身份。九四好遯之吉系于能放下牵恋。九五嘉遯取正志、守界限，后援可以利善后。上九肥遯，据《子夏传》及孔疏取退而饶裕，卦爻的退吉均须与复合问事分开。

[《周易正义·遯》](https://zh.wikisource.org/wiki/周易正義/04遯)

雷天大壮。初九据王孔「有孚」属凶可信，非额外吉证。九二以居中履谦取贞吉。九三王孔取罔为罗网，恃壮自困，保留触藩拘累。九四谦行而藩决、大车可承，和九三情势有别。六五依王孔易为平易，提前舍壮而无悔，不推断物品丢失。上六进退俱难，须审实定志方可解咎，不只取艰则吉。

[《周易正义·大壮》](https://zh.wikisource.org/wiki/周易正義/04大壯)

火地晋。初六据王孔及所引何氏取有进有退，罔孚时须宽裕。六二忧而不改中正，保留受福的取义，不断为确定某位亲属来助。六三同信而悔亡，认可须用实际行动验证。九四鼫鼠据王孔无所守，诸家异训不影响进无所据的取用。六五以委任得人解失得勿恤。上九原为有限攻伐，厉中可吉、常用则吝并留，现代仅取处置有范围，不用来合理化要求他人复合。

[《周易正义·晋》](https://zh.wikisource.org/wiki/周易正義/04晉)

[《周易正义·明夷》](https://zh.wikisource.org/wiki/周易正義/04明夷)

[《周易正义·家人》](https://zh.wikisource.org/wiki/周易正義/04家人)

火泽睽。初九勿逐自复与见恶人免咎保留分寸，不把失马复回直译为复合。九二巷遇以未失道为限。六三前有牵阻，终能遇刚。九四据孔疏元夫为可相遇而交孚的同志，不解释为配偶。六五厥宗应九二，噬肤取隔处可解。上九释弧取核实后去疑，遇雨重释疑交和，不推断天气或复合日期。

水山蹇。初六据《象》宜待，来誉是见险能止。六二匪躬重在尽职，终无尤不承诺感情回报。九三来反为回到内位，内喜不直作复合。六四依马、郑及王孔，连有难、迟久之意，《象》重当位有实。九五大蹇中的朋来以中节为条件。上六来硕吉须难已能解，见大人可类推得适切协助，不推断特定人会出现。

[《周易正义·解》](https://zh.wikisource.org/wiki/周易正義/04解)
