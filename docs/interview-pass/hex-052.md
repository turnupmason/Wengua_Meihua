## 初六动 · 寅月、卯月

先停一步再开口

艮为山 → 雷水解 → 山火贲

简断

头一问是个带钩子的问题：上家公司最大的毛病是什么。你先停了一下，只讲事、不评人，这一停让你站住了脚，能过这一轮。中间被追问得紧，挨了几下重的；到后段那份改进记录一摆出来，局面就翻了过来。

开局：问题一抛出来就带着钩子：上家公司最大的毛病是什么。脱口而出的话就在嘴边，你压住了。

过程：随后的追问一下比一下紧，问你为什么不早提、提了有没有用，你答得吃力，几次只能先认下自己没做到的地方。

结局：到后段，你把那份自己整理的改进记录拿出来，哪年提的、改了什么、效果几何，一页页都在。「艮其趾」，脚趾还没迈出去就先停住；「无咎，利永贞」，停得住就不出错，守得久才有利。小象「未失正也」，开头那一停，正是没失了分寸。中间挨的那几下是真重，可后段的东西更实。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，后段拿出改进记录，局面翻了过来，属吉应。带钩子的问题先想好只讲事的说法，备两句。

总断：吃力，但能过。碰上带钩子的问题，先停一下，只讲事。

等问题说完

艮为山 → 雷水解 → 山火贲

简断

对方提问常常停在半截，后半句隔一会儿才补上。你每次都等问题说完再答，答得不快，却句句对得上，后半场讲到从头跟到尾的那个项目时越答越有底，这一关能过。

开局：第一问只说了半句：你上一份工作里，最难的一件事——话就停在那里。你没接，等到后半句「是怎么解决的」出来，才开口。

过程：随后几问都是这样，有的半句之后转了方向，你若抢着答就答偏了。这一段问得密，你答得稳，可也费了不少心思。

结局：后半场转到你从头跟到尾的那个项目，从立项到复盘，你讲得又顺又全，前面攒下的稳当在这里一下兑现。「艮其趾」，抬脚之前先停；小象「未失正也」，停得是地方，就不失正。这一卦后段的帮衬足，前面那几回忍住没抢，换来的是后面一路顺畅。
