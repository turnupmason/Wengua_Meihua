## 初九动 · 寅月、卯月

换回熟悉的讲法，指定的四步没走完

风天小畜 → 火泽睽 → 巽为风

简断

案例题一开口，对方就点明要按他们给的四步来拆，你照着讲了两步觉得别扭，又换回自己最熟的那套讲法，结论站得住。那四步没走完，这一轮就还差一步；其余几问你讲得顺，经历也讲得实。

开局：对方给的限定只有一句话，说在案例开头，口气平常，后面怎么看你，看的却正是这四步。

过程：自我介绍和两段经历都问得不深，你一路顺着答，旧项目里的细节随手就能举出来，没有哪一问把你问住。

结局：回到熟路，讲出来的东西挑不出错，「复自道，何其咎」，从自己的路上走回来，本身没有过错，象曰「其义吉也」。只是对方要看的是你能不能照他们的步子走，这一点没有交出来，别的几问答得再稳，也垫不上这一块。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，照对方给的步骤讲到一半，又换回自己的讲法，属耗应。练案例时专挑限定了方法的题，照规定的步骤讲完一遍。

总断：碰到对方点名的方法，讲得生涩也照着走完，再用自己的话补一句结论。这一轮就落在那四步上，没被选上。

头两问都落在没做过的方向

风天小畜 → 火泽睽 → 巽为风

简断

开局：岗位要求里那一行写得不起眼，问的却正是它：对方从你简历上没有的方向问起，一问追着一问。

过程：你想把话头引回自己做过的项目，每次刚开口，下一问又把你带回那块业务，两问加起来占了大半时间。

结局：「复自道，何其咎」，回到自己的路上不算错，象也说「其义吉也」。这条退路在后面几问是通的，问到你熟的项目时，细节、数据张口就有；头两问却没有路可退，硬讲出来的只是概念。

  “体克用，名可成，但成迟。”
  本用对原体为开局的直接依据。

- mh-071《求名占第九》，原文第 552 行起。
  “体生用，名不可就，或因名有丧。”
  同一关系条文用于理解末段走势。

- mh-122《占卜克应之诀》，原文第 822 行起。
  “应之期远，则以年，近则以月，又近则以日也。”
  日级窗口只适用于已进入近期流程的对应面试事项。面试日、通知日以对方安排为准。

- mh-143《日应》，原文第 967 行起。
  “不宜克体，亦不宜体卦生之也。”
  死坎变用仍受相乾生，取亥、子日参末段投入。
