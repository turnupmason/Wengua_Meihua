泽水困 → 风火家人 → 兑为泽

简断

开头那个问题又长又绕，你读了两遍还没摸到头绪，却一直坐在那里想，白白耗掉了全场最多的时间。后面几乎没有阻挡，可时间回不来，终究还差半截。

开局：一上来就是又长又绕的一问，你坐在那里想。

过程：那一问讲了一段公司历史，最后才问你「如果是你，当时会怎么选」。你在历史里找线索，找了很久，看不见路。

结局：后面几问都不难，你答得顺，可剩下的时间只够简单说。初六小象「幽不明也」，困在看不清的幽谷里；这一轮的幽谷就在开头，看不见路，耗得最多。
