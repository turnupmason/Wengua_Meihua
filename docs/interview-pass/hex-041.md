## 初九动 · 寅月、卯月

中途一问压住了整场

山泽损 → 地雷复 → 山水蒙

简断

自我介绍和头几个问题都交代得清楚，可问到一半，对方抛来一道要把几段经历串起来讲的综合问题，你手里的例子各管一段，接不成一条线，后面的时间也被它吃掉。串不成线的那一问，把整轮卡在门槛外，还差一截。

开局：前两个问题问的是做过什么、在哪里做，几句话就说完了。

过程：到了问答当中，对方忽然要你拿一个例子说明：资源、时间、人手都受限时，你怎样取舍，结果又怎么衡量。你准备的几个故事各自只答得上一角，临场拼接，越讲越长，追问一个接一个落下来。整场最重的一下就在这里，来得早，又硬，后面要讲的东西只能匆匆带过。

结局：末了几问不难，只是剩下的时间已不宽。「已事遄往」，手上这件讲到一个站得住的结果，就该收口转向；「酌损之」，删什么要掂量。那道综合问题，把能说清的一段讲透，坦白其余部分没做过，比硬拼三段省时，也更站得住。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，练讲时又被一个要串起几段经历的问题拖住，属凶应。那类综合问题只选一个例子讲到结果，计时练三遍。

总断：综合问题挑一个最完整的例子讲到结果就停，余下几问照常答。中间那一问拖走的时间补不回来，整轮还差半截。

## 初九动 · 巳月、午月

句句答得上，句句差半截

山泽损 → 地雷复 → 山水蒙

简断

问到的你都接得住，哪一问都没把你问住，偏偏每一答都停在「做了什么」，没讲到结果和你自己的那一份。对方手里能记下的东西太少，这次没成，差在收口。

开局：自我介绍讲得从容，经历的先后、角色交代得明白，没有磕绊。

过程：中途有一两个追问来得急，问你当时为何那样做。你答得上，几句就过去了，并不吃力。

结局：问题出在每一答的收尾。你讲到「我们后来做成了」便停，换下一个话题，至于做成到什么程度、哪一步是你拿的主意，没有说。「已事遄往」，是事办完再走；这一轮正好反过来，事没讲完人先走了。对方要据此记下你的长处，空着的地方，只能空着。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，练讲时想清楚就跳过，结果那句没说出口，属凶应。录下自己讲的例子，听每段结尾有没有结果和个人分工。

总断：每个例子讲完，补一句结果有多大、你个人管的是哪一段，再收口。几处空着的结尾凑在一起，结果和你个人那一份始终没交代，没被选上。

自我介绍收不住口

山泽损 → 地雷复 → 山水蒙

简断

一开口就讲多了：自我介绍把几段经历从头铺到尾，原本一两句的事说成了一大段，后面真正要你展开的问题只剩零碎时间。中途的追问不难，收尾那一问又有分量，整轮下来还欠一截。

开局：介绍自己时，学校、实习、项目、兴趣挨个铺开，每段都想说透。这是全场耗得最多的地方，嘴上说得越满，后面的余量就越薄。

过程：当中几问冷不丁有点偏，但都是你熟的东西，答起来不费劲。

结局：压轴的是讲一个完整的项目，这本该是全场的重头戏，偏只剩一点时间，只够把背景讲完。「酌损之」，减要掂量着减：介绍里那些对方从简历上已看得到的，就是该减的部分；「已事遄往」，一段讲到结果就往下走。
