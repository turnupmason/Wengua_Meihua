## 初九动 · 寅月、卯月

常见题被反过来问

天泽履 → 风火家人 → 天水讼

简断

对方没问你最擅长什么，反过来问哪类工作你做得最吃力、怎么补，背熟的那段优点一句也用不上，只能现场找例子。这道反问把这一轮拖到了还差一截的地方；前面照实讲的经历都立得住。

开局：问题一出口就不是你练过的方向，对方要的是短处和补法。

过程：你想拿准备好的长处改个说法应付，讲了两句又收回来，换成一件真实做砸的事，可来龙去脉要一边想一边理，讲得断断续续。

结局：「素履，往无咎」，照本色说话，本身没有错处；你讲的那件事是真的，对方追问细节也都对得上。只是这一问要的是怎么补，补法得当场组织，这一块讲得薄，前面那些照实的话垫不起来。

总断：常见题都反过来问自己一遍，短处配一件真事、一个补法。被那道反问拖住，这回没成。

案例被要求一步一步讲

天泽履 → 风火家人 → 天水讼

简断

案例题一开始，对方就说要听你每一步怎么做，你习惯跳着讲，从目标直接跳到结果，中间几步被一个个追问回来补。跳过的步子被一步步问出来，到头还差一截；开口那两句定位倒是准的。

开局：案例本身不偏，可对方把规矩说在前头：每一步都要讲出来，跳过的不算。

过程：你讲得快，觉得显而易见的环节一句带过；对方偏偏在这些地方停下来问「这一步具体怎么做」，问到第三处，你的节奏全乱了，补出来的步骤也前后打架。

结局：「素履，往无咎」，讲出口的那几步走得正，没有一步是错的。毛病在没讲出口的那几步：对方要看的是整条路，省掉的地方就是空着的，空处一多，这道案例就立不起来。

总断：案例按步骤讲，一步一句，哪怕觉得多余也说出来。那几处跳步让这次没成，还差一截。

## 初九动 · 申月、酉月

理由攒到最后才补

天泽履 → 风火家人 → 天水讼

简断

讲方案时你只报结论，理由想着最后一起说，结果收尾时对方让你逐条补，五六条理由挤在最后几分钟，讲得匆忙。前面的结论都对，这一轮却还欠一截，欠在理由没跟着结论走。

开局：你报结论报得快，一个接一个，听上去很笃定。

过程：对方没有打断，一直让你讲完；你把每个判断的依据都留在心里，打算放到最后汇总。

结局：到了收尾，对方说「刚才这几个结论，依据分别是什么」，你一条条往回找，有两条记得清，其余的只能讲个大意。「素履」本是一步一步照实走，这一回走成了先跑后补，攒下的那笔账到最后一起来还，无咎也免不了它。

应期：以下为传统推算的参考窗口。
可留意本月21、22号前后，收尾时被要求逐条补上前面结论的依据，属耗应。结论和理由捆在一起练，说完一个判断紧跟一句为什么。

总断：每说一个结论，顺口带一句依据，不往后攒。结论对、理由欠着，这一轮落选。
