报错了一个数，退回去改了

水雷屯 → 山地剥 → 风雷益

简断

讲案例时你把材料里的一个数报错了，讲到结论才发现对不上；你停下来说刚才那个数说错了，退回去改正，再把结论重讲，这一轮能过，只是多费了一阵。

开局：起初你答得慢，每句话都想了再说。

过程：案例讲到一半，你报出的一个数比材料上大了十倍，当时没察觉。

结局：讲到结论，你发现数对不上，心里一紧。「乘马班如，泣血涟如」，进退之间发慌。你没有硬圆，退回去把那个数改了，再从那一步往下讲。这一阵你底子薄，阻力也不轻，改正花了时间，可改正以后整段就通了，结果不受它拖累。

应期：以下为传统推算的参考窗口。
可留意本月21、22号前后，开头答得慢，每句都想好了才说，属吉应。讲案例时把用到的数写在纸上，讲一个勾一个。

总断：能过，费了些工夫；数报错了就当场改正，从那一步重讲。

古籍依据：《周易·水雷屯》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·谒见占第十四》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·体用》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。
