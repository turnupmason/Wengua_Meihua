## 初六动 · 寅月、卯月

刚上岸的雁

风山渐 → 火水未济 → 风火家人

简断

你转行过来不久，像刚落到岸边的雁，开场讲得有劲，问什么都接。对方一句「你这方面经历偏少」之后，你接着就花了好一阵为自己辩解，又在末尾把学习计划从头讲了一遍，力气都往外送，离要的样子还差一截。

开局：新方向你入行才一年多，开场介绍自己时却讲得很足，有劲道，节奏也快。

过程：讲到一半，对方插了一句：你这方面的经历偏少。你接过话头，解释自己怎么自学、怎么补课，一解释就是好一阵。

结局：「鸿渐于干」，大雁一步步往前，眼下才到水边；「小子厉，有言」，年轻的处境有险，又招来几句议论；「无咎」，说到底没有过错。小象「义无咎也」。那句议论本不必接得那么重，你却拿出整段时间去辩，到末尾又把学习计划细讲一遍，前后两回往外倾，开场攒下的劲都散了。

应期：以下为传统推算的参考窗口。
可留意本月16、28号前后，末尾把学习计划从头讲了一遍，属耗应。被说经历偏少时，用一句话回应，接着讲做过的事。

总断：力气倾在辩解上，没被选上。开场那段自我介绍，讲得有劲有节奏。

## 上九动 · 亥月、子月

绕弯的问法

风山渐 → 火水未济 → 水山蹇

简断

一上来对方的问法就绕，一个问题里套着三层，你接得磕绊。这一关还是能过，只是迟：后面你把每个问题先拆开再答，一层一层讲清，到最后章法立住了。

开局：假如你接手一个延期的项目，团队又不服你，客户还在催，你先做什么——头一问就把三层套在一起。

过程：你先答了客户，对方追问团队怎么办；你又答团队，对方再问项目本身。一来一回，前面答得很乱。

结局：后来你换了个办法：每个问题先拆成几层，一层一层答。讲到最后，次序清楚了，前面的乱也收住了。「其羽可用为仪，吉」，羽毛可用；小象「不可乱也」，乱了就不可用，你到后来没再乱。这一卦压你的东西多，帮你的少，过得迟。

应期：以下为传统推算的参考窗口。
