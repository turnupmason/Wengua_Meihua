## 初九动 · 寅月、卯月

等待有用，收尾继续耗费使通过偏难

水天需 → 火泽睽 → 水风井

简断

这轮面试倾向难以通过。起初有人给出明确要求时，可以按要求准备，中间的细问还要多费心思，最后也可能继续补材料。把最切题的经历先讲透，等待期间只补明确需要的内容，少在暂未问到的事情上分散精力。

开局：坎水体春休，本用乾金春囚而生体，开头有助，力度有限。收到明确要求时，适合先按它整理经历。

过程：体互离火春相，受休水所克，实际核验要费力处理。用互兑金春囚而生体，仍能接上一点帮助。先抓住最关键的问题，别在背景里花掉太多时间。

结局：初九“需于郊，利用恒，无咎”，按常规等待可以少犯难处。变用巽木当旺，受休坎所生，末后仍容易耗在解释和准备。前面的弱助能接续沟通，尚不足以支撑最后通过，本轮偏难。

可留意本月12、13号前后，若收尾还需补材料，整理和说明可能比较费心，属阶段性凶应。

总断：本轮偏难通过，可能在等待中继续补答。按明确要求把相关经历说清，收到反馈再判断是否还需补充。
