## 初九动 · 寅月、卯月

点子都送了出去，自己没说清

水天需 → 火泽睽 → 水风井

简断

前面你稳稳当当，没冒一点险；最后对方聊起他们手上的难题，你一口气给了七八个点子，越说越多，说到结束也没讲清这些事你自己做过哪件、能接哪件，到头来没被选上。

开局：你守着自己最有把握的几件事，不往生地方走。

过程：几问下来平平稳稳，没出错，也没出彩。

结局：「需于郊」，在离险地远远的郊外等着，「利用恒，无咎」，守常就不出错，前面正是这样。到了最后，对方说起他们的难处，你像打开了闸，点子一个接一个往外倒。倒出去的都是对方的，你自己能做什么，反倒一句没落下。这时候往外流得最猛，收尾全在给，没一处在收。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，收尾聊对方难题，点子一个接一个往外给，属耗应。每说一个点子，接一句「这件事我做过……」。

总断：聊对方的难题时，每个点子都挂上你做过的一件事；七八个点子没一个落到你自己身上，还欠一截。

开局：拿不准的话题你一概绕开，只讲有底的。

总结讲完了，结论没出口

水天需 → 火泽睽 → 水风井

开局：头几问正对着你熟的事，你接得很顺。
