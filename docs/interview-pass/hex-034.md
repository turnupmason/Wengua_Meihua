## 初九动 · 寅月、卯月

抢着开口，漏听了半句

雷天大壮 → 泽天夬 → 雷风恒

简断

对方第一个问题话没说完你就接上了，漏掉后半句里的限定，讲的例子跟问的不是一回事；后面你稳住了，也补回一些，可头一问的偏差一直挂着，整场还差半截。听完整句再开口。

开局：头一问你听到一半就开讲，问的是一次没做成的事，你讲成了做成的那次。

过程：到第三四问你才回过味来，后面的回答放慢了，没再抢。

结局：收尾几问答得稳当，头一问那次答偏却已经摆在那里。初九「壮于趾，征凶」，力气全使在脚趾头上，一抬脚就往前冲；王弼说「居下而用刚壮，以斯而进，穷凶可必」，凶就在起步这一下。

应期：以下为传统推算的参考窗口。
可留意本月18、19号前后，头一个问题没听完就开口，漏了限定，属凶应。等问题说完，先在心里重复一遍限定词。

总断：起步抢了一拍，后面没补全，这回没被选上。头一问等对方说完，停一秒再答。

每一问都先出口再改口

雷天大壮 → 泽天夬 → 雷风恒

开局：问题都不刁，可你接得太快，第一句往往不准。

过程：每改一次口就要多解释几句，时间一点点被磨掉。

结局：到最后两问时间所剩无几，只来得及讲个结论。小象「其孚穷也」，诚意是有的，冲在前头却把它用尽了；初九的凶不在哪一刀重，在一路小磕小碰。

雷天大壮 → 泽天夬 → 雷风恒

有一问你一听就觉得眼熟，照准备过的答案讲了，没留意它比原来少了一个前提，答案落了空；后来补回一两处，整场仍还差半截。听到眼熟的问题，先对照一下和原来哪里不同。
