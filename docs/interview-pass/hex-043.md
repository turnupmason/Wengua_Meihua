## 初九动 · 寅月、卯月

一上来就冲着最难的那件去

泽天夬 → 乾为天 → 泽风大过

简断

自我介绍刚说完，你就把话题引向最难讲的那个项目，想先把硬的那块啃掉，可手上准备不足，讲了很久也没讲透，后面的问题都被挤得匆忙。末尾那个分量很重的问题，已没有余力接住，还差一截。

开局：介绍完自己，你就主动把话头转到那个最难讲的项目上。

过程：那个项目你只做过一部分，细节记得不全，讲着讲着就要停下来想，追问一来，又得回头补。原本几分钟的事，拖成了大半段。

结局：收尾对方问了一个分量很重的问题：如果让你负责整条业务线，第一步做什么。这一问本该是你发挥的地方，你却只剩下几句话的时间和力气。初九「壮于前趾，往不胜为咎」，脚趾先往前冲，走不赢便是过失；小象「不胜而往，咎也」。冲得早，冲的又是自己最没底的那件。

应期：此盘暂无有据的日期可列。

总断：先讲最有把握的经历，难的那件等对方问到再讲。开头冲得太猛，收尾接不住，这次没成。

古籍依据：《周易·泽天夬》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·谒见占第十四》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。

问题没听完就开口

泽天夬 → 乾为天 → 泽风大过

简断

开局：对方第一个问题还在铺背景，你已经开口答了。

过程：接下来几问也是这样：对方刚说到「如果客户……」，你就接上了自己的例子，等对方把后半句「临时撤单」说出来，前面讲的已对不上，只好改口。

## 初九动 · 亥月、子月

连环追问，断在第二环

泽天夬 → 乾为天 → 泽风大过

简断

对方问的是一串连着的问题，第一问你答得干净，第二问要拿第一问的结果往下推，你一冲就接不上了，后面几问跟着断。手上没有余力把链子续起来，差了一口气。

开局：头两问你答得踏实，只是讲得不快。

过程：中途对方连问几层：先问你怎样估算一个市场，再问按这个估算该配几个人，再问预算怎么排。

结局：第一层你算得清楚，第二层要从第一层的结果往下推，你急着往前，换了一套新数，前后对不上，第三层便无从谈起。初九「往不胜为咎」，往前冲却接不住；小象「不胜而往，咎也」。收尾那个问题分量又不轻，你已没有力气去追。

应期：以下为传统推算的参考窗口。
