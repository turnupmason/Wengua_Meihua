## 初九动 · 寅月、卯月

开场那条要求比平时严

天火同人 → 天风姤 → 天山遁

简断

开场对方定了一条规矩：只许用一个项目把三项能力讲全，比你平时练的严得多，头几问你讲得紧，一句一句地守。这一关过得去，吃力在开场，中段几问也要使劲，收尾的帮衬只有薄薄一层。

开局：规矩说在最前面，你平时都是一项能力配一个例子，这回得全挤进一个项目里。

过程：你挑了最大的那个项目，从里面一块块翻出对得上的经历，翻到一块讲一块，讲得慢，几处还得停下来想怎么接。

结局：最后一问对方顺着你的项目问收获，你讲得实在，前面那几段零散的经历在这里合上了。「同人于门，无咎」，象曰「出门同人，又谁咎也」，跨出门这一步你守住了规矩，没有偷偷换项目，这一守就无咎。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，开场那条要求比你平时练的严，属凶应。挑一个最大的项目，练着用它讲全三项能力。

总断：每个大项目都练一遍：用它一个讲全几项能力。面试能过，开场那条规矩最费劲。

开局：上来就问到最深处：资源不够时，怎么推动一件跨部门的事。

过程：你讲了起因和结果，中间怎么说服各方那一环说不清，只好先说「这一块我稍后补充」。

结局：后面那问一提审批流程，你就接上了：中间那一环正是先过审批、再拉人。「同人于门，无咎」，出门那一步最难，你没硬编，留着；同路的东西在门外等着，后面一问把它送了回来，补上就没有过错。

天火同人 → 天风姤 → 天山遁

简断

开头对方说了一句「只谈你主导过的事」，这句限定听着平常，分量却重。面试能过，你把这句话记在心里，后面几问都照着它挑例子，没有一处讲到别人主导的事上去。

开局：限定只有一句，夹在开场白里，语气很随意。

过程：你听进去了，后面每挑一个例子，都先自问一句：这是不是我主导的，过了才讲。

结局：收尾时对方又问到一个细节，你顺手把它补进了刚才的答案里，答案更完整了。「同人于门，无咎」，出门那一步只有这一句规矩，你跟着它走，就挑不出错；你自身底气足，这一步落得轻。
