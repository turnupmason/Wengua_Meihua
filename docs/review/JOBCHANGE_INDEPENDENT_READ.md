## 逐篇查什么（每篇标题、简断、正文全读）

1. **盘面说法**：每一句讲旺衰、生克、轻重、「最弱／最旺／最重／最轻」「此气之最」的话，与 packet 对：五态（旺相休囚死）不说错；「最」字要在本爻五气里真是最；生克方向不说反；一层间接作用（制、生）只按定稿第八节讲，不连环累计；互卦管中段、变卦管收尾不说乱。另两类成批出现过（谦、豫、履）：错用《体用》「有生此卦者吉，有克此卦者凶」去论证「克体之卦得生，阻力更重」（这句讲的是体，不能拿来讲克体之卦，克体之卦得生则有力只按一层间接作用白话讲）；连环推演，如「你越费力料理坎水，木克得的生越实」，把两层生克连成因果。「此月最慢」「此气之最」一类比较，须在本爻五气里核实，同爻各月不得互相矛盾。（口径，2026-11-20 定：「午月火最旺」「子月水最盛」只说本月当令、不与同气另一月比的，可留；拿同气两月比轻重的，如「子月比亥月更足一分」「此月灭得最彻底」而亥月同气，才改。《衰旺论》的「衰」就是死：体休、体囚都不说「体衰」，不引「体衰而有生体之卦，则衰稍解」「若体衰而逢克」，体休说「不在旺相、不算有力」，体囚说「受制、力弱」；《体用总诀》「体衰则凶」同此，只在体死时引，体旺相单引「体盛则吉」，用党多只引「用党多则体势衰」不接「体衰则凶」；交稿前跑 `node scripts/review/tishuai-audit.cjs job-change --hex <卦序>` 须 0（订正说明 docs/review/TISHUAI_FIX_BRIEF.md）。原书 494 行（「体党多而体势盛」「用党多则体势衰」「体生用，为之泄气」「体宜受用卦之生」等）出自【体用总诀】，682 行（「彼灭其吉」「稍解其穷」）出自【体用】，标出处时分清。引文异文以《周易正义》为准，如明夷六二小象作「顺以则也」，库本 yijing64.txt 作「顺而则也」，正文从正义。）
2. **结论**：首句、简断首句判词与 outcome 一致；全篇不出现相反的倾向；先准备的篇写明要先落定哪件实事；可走的篇写明日子按双方约定。
3. **引文**：「」内逐字对原典（`sources/reference/zhouyi-zhengyi-hans/`、`sources/original/`），出处（王注、孔疏、程传、本义、小象、彖、大象、《梅花易数》各诀）不张冠李戴。
4. **不该有的话**：安慰、许诺、预告好转（「不会落空」「不至于吃亏」「不会出岔子」「可以放心」之类在留、先准备的篇里尤其要看；用户面试稿 4,608 篇只有 4 处这类说法）；替人断心意、断性格（「你精力足」「你容易……」）；编出来的经过与场面写成读者实况（举例用「多是……这一类」）；写给作者的话、规则名目；他项用语。
5. **文字**：段间、篇内意思重复；同一爻十二篇收尾成模子；不顺、过长、指代不明的句子。
