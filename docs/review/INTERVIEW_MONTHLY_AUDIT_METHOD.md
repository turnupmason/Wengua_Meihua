# 面试月稿：逐批核查与规则审计

本文件配合[逐月长稿规范](INTERVIEW_MONTHLY_REWRITE_20261118.md)。用户于 2026-11-18 再次要求保持已写 576 篇的厚度，正文与规则审计同步推进，逐批检查，并更新 main。

## 写作及发布的单位

每个动爻先完成十二个月稿，作者实际读回全文；每卦六个动爻全部完成后，发布 72 篇、作者回执及阅读页。同气月份仍有独立月键与独立全文，不增加未经批准的月支冲合。正文以先前 576 篇实际 417–510 汉字的厚度为参照，按解释所需伸缩。不能靠固定建议补长，也不为查重改变卦理。

新增正文只能由作者写入 `sources/editorial/interview-pass/monthly/`。本轮新增的构建程序只把已写定的正文排成阅读文档，不生成、拼接或改写文章。

## 机器核查

```bash
# 一个动爻写作中的部分稿；不签署全文核读回执
node scripts/review/check-interview-monthly.mjs --hex 3 --draft

# 作者已完成整卦及回执后，构建对应阅读页
node scripts/build-interview-monthly.mjs --hex 3

# 检查本批与全部已经发布的月稿，再生成机器记录
node scripts/review/check-interview-monthly.mjs --hex 1,2,3,17,33,34,49,50,52 --docs --json docs/review/INTERVIEW_MONTHLY_CHECKS.json
```

检查项包括：

- 十二月键的顺序、完整性和唯一性；摘要与正文首段的结论绑定。
- 对应旧五气稿的 outcome、取期种类、作用位置、方法和有无窗口。现行结果不得在润色中暗改；专业说明 judgment 的明确事实或引文解释错误，可按下述订正记录修复。
- 正文汉字数、摘要 60–120 汉字、空段及占位文字；长度只是提示或结构门槛，不能证明文笔合格。
- 全文、整段以及剔除引文后的 24 汉字以上完整句子的重复。常见短术语不要求为避重而改名。
- 使用独立的文王卦序上下卦表、六爻位运算、八卦五行表和五态表，核本互变、真实动爻、六节点及四条对原体关系，并与引擎和旧事实层比较。独立表不调用引擎的排盘和生克函数。
- 取期通过现有日期解释器，分别以 2026-11-11 和 2026-12-31 验证：不取起卦日之前的日期；晚些查看历史不改变原候选日期；结果类吉应只对应能通过的稿件。过程受阻的日期不改写成失败公布日。
- 当前作者源 SHA-256 与作者回执一致；阅读页必须含本篇标题、摘要与全部原文自然段。

独立算法在 64 卦 × 6 动爻 × 12 月令共 4,608 个输入上与当前引擎比较，本互变、各节点五行五态及直接关系均无差异。2026-11-19 在 main 的 `c9f2cdc` 基础上重做全量比较，共 124,416 项，记录见[全量盘面复算](INTERVIEW_MONTHLY_CHART_COVERAGE_20261119.json)。这项记录只核盘面事实，不计入未写完月稿的作者核读数量。

### 专业说明的证据订正

若旧 `judgment` 与已记录的一层作用、盘面事实或实际核读的古籍释义冲突，应修正文稿，不能因保留旧字段而继续发布已知矛盾。每个受影响的月稿须带 `judgmentCorrection`：`old` 保存完整原句，`new` 与修正后 `judgment` 完全相同，`reason` 说明具体错误，`sourceEvidence` 至少给一个仓库内真实文件 `path` 和明确的 `scope`，`impact` 明记 `outcomeChanged: false`、`timingSignatureChanged: false`。同气月份采用相同修正理由正文，作者回执记录修复及仍未解决的规则优先级。

程序仅检查原新文绑定、证据路径存在、同气一致、结果与取期结构未改，并在机器记录中逐条列出订正；这不代表程序已经判定解释正确。变更结论本身仍须另行证据裁决，不能通过改写专业说明绕过。涉及古籍真实吉意与当前“不成”判据冲突的，须完整保留吉意，并明确标注优先次序待复核。

阅读页的通用条文对照会保留相关判读原文，其中一些条文的前提并不适用于当前盘面。2026-11-19 起在该栏明确标出这一适用范围：实际采用的依据、反证和待复核权重，应以本篇专业说明及对应卦的核读记录为准；不能仅因引文出现在页面上，就认定它已用于本篇裁决。这次显示说明不改既有正文、原始判读数据或二分结果。

## 人工与 AI 作者的解释审计

逐篇先读旧正文、完整专业理由及反证，再读原爻辞、小象与相关注疏。每卦回执列六爻解释与存在的分歧，定位到具体动爻和月份。原文版本、解释选择、项目判定优先级分别记录。

需要特别保留的证据冲突包括：旺体与衰克如何权衡；有生有克时的结论；末泄与无克体条文；吉爻辞与现行二选一判据的分歧。代码通过不自动关闭这些问题。

《周易正义》需上六解释三阳相援、敬待而终吉，不能把“三人”硬换成三道题，也不能把“终吉”全部缩成避免一次失误。其疏文还提醒不可将爻象逐一拘泥地比作人事细节。这为清除旧稿的无据现代场景提供了直接依据。

屯九五的“小贞吉、大贞凶”在王弼、孔颖达解释中涉及施泽范围、职位和所系，不能不加说明就等同“小公司可过、大公司不过”。小畜初九、九二的“复”，在王孔注疏中又有刚健上通的解释，也不能只据“复”字写成回到原来答题模板。以上原义如何用于面试属于类推，回执应注明边界。

原典核对入口：

- [《梅花易数》卷二：求名、体用、衰旺等](https://zh.wikisource.org/zh-hans/梅花易數/卷二)
- [《梅花易数》卷三：占卦诀、体用互变之诀、体用衰旺之诀](https://zh.wikisource.org/zh-hans/梅花易數/卷三)
- [《周易正义》屯卦](https://zh.wikisource.org/zh-hans/周易正義/01屯)
- [《周易正义》需卦](https://zh.wikisource.org/zh-hans/周易正義/02需)
- [《周易正义》小畜卦](https://zh.wikisource.org/zh-hans/周易正義/02小畜)

注：正义子页面的数字是卷次，不是六十四卦的卦序。本地原典快照位于 `sources/reference/`；新增回执必须引用实际阅读的文件和正确页面。
