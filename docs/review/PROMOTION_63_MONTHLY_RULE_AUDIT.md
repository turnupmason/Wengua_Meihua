# 既济 · 本次晋升与随岗加薪逐月规则审计

既济六爻各十二个月，共 72 篇。每篇按原卦、动爻、月令对照[晋升五气原断](../../sources/editorial/promotion-pay/hex-063.json)和[盘面事实](../../data/authored-readings/promotion-pay/hex-063.json)。问的是在任者本次能否升职；薪资单列，只随这一次职级是否落实而论。

爻义以[《周易正义》本地录文](../../sources/reference/zhouyi-zhengyi-hans/06既濟.txt)对读。体用轻重回到[《梅花易数》卷一至三](../../sources/original/meihua-volumes-1-3.txt)的《求名占》《占卦诀》及体用、互变诸条。已在任而见直接克体，依本问项的既定规则保留原断；吉、无咎及一时有助各按所在阶段解释。

## 取期与核对范围

逐篇保留五气原稿的取期种类、作用位、取期方法及有无窗口。日期只随该段已有对应动静时旁参。对照阅读页中的完整正文、薪资、简断与应期栏目，检查同爻相邻月份的起句与重复表达。此次为编辑修订及程序逐篇核查，尚无独立人工全文复审。

## 本卦校勘与生成页核验

初九区分王孔所释始济未达与程朱所说止进。上六王注依「过而不已，则遇于难」，取其过犹向前之戒。六二得助的原断与其他五爻分别核对。

六组共 72 篇正文为 471–561 汉字，薪资与应期另计。生成页按动爻与月令拆篇，与各自的标题、简断、正文、薪资、专业说明和应期逐项比对。1,944 项盘面对照无差异，两组起卦日期共 144 例，与五气原稿所得日期一致。当前古籍引文检查未标出未匹配引句。
