# 小过 · 本次晋升与随岗加薪逐月规则审计

小过六爻各十二个月，共 72 篇。每篇按原卦、动爻、月令对照[晋升五气原断](../../sources/editorial/promotion-pay/hex-062.json)和[盘面事实](../../data/authored-readings/promotion-pay/hex-062.json)。问的是在任者本次能否升职；薪资单列，只随这一次职级是否落实而论。

爻义以[《周易正义》本地录文](../../sources/reference/zhouyi-zhengyi-hans/06小過.txt)对读。体用轻重回到[《梅花易数》卷一至三](../../sources/original/meihua-volumes-1-3.txt)的《求名占》《占卦诀》及体用、互变诸条。已在任而见直接克体，依本问项的既定规则保留原断；吉、无咎及一时有助各按所在阶段解释。

## 取期与核对范围

## 本卦校勘与生成页核验

九四孔疏依「既无能为，自守则无咎」断句，守分可免过，前行仍须戒。六五由上震变兑，所成是泽山咸，变用兑金受体艮土所生，末段的用力归己。

六组共 72 篇正文为 472–559 汉字，薪资与应期另计。生成页按动爻与月令拆篇，与各自的标题、简断、正文、薪资、专业说明和应期逐项比对。1,944 项盘面对照无差异，两组起卦日期共 144 例，与五气原稿所得日期一致。当前古籍引文检查未标出未匹配引句。
