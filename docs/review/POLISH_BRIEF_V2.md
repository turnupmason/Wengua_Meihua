## 锁定，不能动

每项的第 1、2、3、10、11 栏：爻、气类、结论码、复核依据、应期声明。正文里的吉凶倾向、快慢、关键条件、爻辞引文的意思都不能改。

## 可以改

第 4–9 栏：标题、简断、开局、过程、结局、总断。逐篇做 V5 第十三节的五遍：读懂原稿 → 逐段润色 → 逐句对照原稿查有没有改了意思 → 用普通读者的眼光通读 → 查格式。原本自然的可以不改，记录里写「原稿已自然，未改」。

文风底线：像人说话；不写「不……，也不……」；不堆三项顿号并列和四字词；不自夸；不写套话；正文没有计算语言（检查脚本会报）；简断 60–120 个汉字；全问项不出现重复句。


## 计算说明（每篇必写）

用户要求：重写时把这次复核新用的依据写进计算说明。App 的「计算说明」折叠栏会显示这几行，替换掉原来的第十栏内部依据。在润色记录里给每篇加字段 `calculationNotes`：3–5 行字符串数组，每行不超过 90 个汉字，内容与复核记录的判断一致：

1. 「定档：」盘中哪处生体、哪处克体、哪处泄或比和，按哪句古籍定为吉、有条件或难。写书名篇名和原文短句，例如：定档：本用坎水生体，体互兑金克体，变用为体所克。《梅花易数·占卦诀》「有生体之卦，又有克体之卦，则事有阻节，好中不足」，取有条件。
2. 「旺衰：」本盘关键几处的旺相休囚死，以及它们让事情变快变慢、变轻变重的作用（引《体用衰旺之诀》《衰旺论》等）。
3. 「爻辞：」动爻怎么读，落不落在考试结果上，是否因此升一档、降一档或不调，引经文、小象；注疏只引复核记录里没标「待核」的。
4. 可选第 4、5 行：本盘特别的地方（例如「先天起卦，爻辞参看不主断」「此盘即观梅占原盘」）。

禁止出现：盲断、主审、作者、裁定、复核、口径条号（第 17 条、R2↑、R1a 之类代号）、「改判」「原稿」等审稿过程用语。只写盘面依据和古籍依据。
