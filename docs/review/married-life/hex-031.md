# 泽山咸（031）夫妻婚姻 · 全卦规则审计

## 古籍与实际盘面

- 《周易正义》校本 `sources/reference/zhouyi-zhengyi-hans/04咸.txt`：24–37咸感、二气感应、止而说、以虚受人，现代借相互感应与合宜相处，不单看卦辞吉义覆实际体用。初六38–41「咸其拇」，足指最末，感初有志、未至伤静，象志在外指应九四，不是婚外之人；六二42–45「咸其腓，凶。居吉」，腓动躁、静居顺而不害，借合宜从容商议；九三46–48「咸其股，执其随，往吝」，股随足而动、志在随人且不能自处，借各自真实表达意愿、共同认可选择；九四49–54「贞吉，悔亡。憧憧往来，朋从尔思」，二体心神感初、须以正、憧憧未光大，借合宜交往原则，不把朋字当现实外遇证据；九五55–58「咸其脢，无悔」，感过心而浅于心神、厚于言语，志浅末，无悔而已，借将相互理解切实落实；上六59–62「咸其辅、颊、舌」，小象「滕口说也」，咸道转末感仅于口舌，借实际共同决定与行动，非凭爻辞断口舌争吵或身体事件。
- 《体用总诀》校本 `sources/revised/meihua-volumes-1-3.txt` 493–495原体、本用、体互、用互及变用四作用，497坤生阴人之利，502艮生物安稳事有终始，506震克体不安静，507巽克体处家阴人小口之厄，509离克体文书之忧。取《说卦传》09.07:21艮止震动兑悦，09.08:22离文明，09.09:21–22坎耳兑口，09.11:21–22乾父、23–24坤母、25–26震躁、27–28巽长女进退不果、29–30坎加忧、35–36兑口舌，梅花130–131乾老人父、坤老妇母。始终四关系对原静体：下三爻本艮直生，体互上乾同比，现实男性长辈参与才取可协作之方向，依旺衰不套乾来生/克。用互下巽被原兑克，按强弱判断现实未决家事可制难制，不当巽克体。初末离直克取文书与已有共同约定的牵制，二末巽受体克，三末坤直生才援497，现实女性长辈相助以本人意愿及能力为条件。上三爻原艮生本兑和用互上乾，兑口舌悦取自身沟通投入，非511来克，乾父老人取照应现实尊长家事的自身付出，非504来克。体互下巽直接克原艮，507处家，实际女性长辈意见牵制才谈协调难易。四末坎受体克，耳听与加忧取现实顾虑可制难制，不援508；五末震直克才援506，已有生活变动压力；六末乾受原艮生耗，仍区分原有男性尊长家事的投入与真实外来约束。不以单一象指认人物或第三者。
- 实盘31咸→44姤。初二三动下艮，原上兑金，前艮生体、体互上乾同比、用互下巽受体克，末分别49革（下离火直克）、28大过（下巽木被体克）、45萃（下坤土生体）。四五六动上兑，原下艮土，本兑及用互上乾均受体生耗、体互下巽直克，末分别39蹇（上坎水受体克）、62小过（上震木直克）、33遁（上乾金受体生耗）。互卦名、变卦名不直接判婚变。
- 五态：春寅卯木旺火相水休金囚土死；夏巳午火旺土相木休水囚金死；秋申酉金旺水相土休火囚木死；冬亥子水旺木相金休土囚火死；辰戌丑未土旺金相火休木囚水死。

## 范围及分层

同气同盘判别一致。年月候只在现实已有共事或其牵制时取实生、比、直接克对应的月令；同土前安顿后相助、同木中意见后变动不拆作两个时日；被原体克难制及受体生耗均非来克。育儿只取493–495、530–532婚姻共同责任承接能力现代类推，辅以双方共同真实意愿、长期稳定分担、实际照料条件，不引生产占，不预测受孕、性别、健康。传统原典、卦盘、文风的内部一致性可审核，并不证明实际预测准确率。
