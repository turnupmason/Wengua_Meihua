# 012 天地否·夫妻婚姻规则审计

## 文献实核及口径

六爻×十二月72篇独立人工行文，固定原静卦体，本用、体互、用互、末变用分别以直接关系对原体论五态，非上下互相串联生克。结合古义借用于现实共同家庭生活：育儿仅评当下是否适宜考虑要孩子，以实际分担、双方共同自愿及真实养育条件为前提，不是产占或孕产医疗判断。年月仅实际事项存在时的传统候类，不判婚姻必成、伤害、他缘或育儿日期。传统取象及文本内规则一致不是现实预测准确率实证。

实际读取原典：`sources/reference/zhouyi-zhengyi-hans/02否.txt` 第30–52行。彖象天地不交、上下不交言否闭（24–29），不能以卦名判真人必然婚变。初六30–33「拔茅茹，以其汇，贞，吉亨」，王孔谓三阴同类如拔茅相茹，处否初未宜苟进，守正不谄（今借互相关联家事须先有双方共识，不套古志在君角色）。六二34–37「包承，小人吉，大人否，亨」，王孔从否时顺承于上小人路通，大人能否闭小人之吉其道乃亨，小象不乱群；现代互助有分寸，不把失当责任一并接受，更不评夫妻品格为大小人。六三38–40「包羞」，群阴以小道承上且位不当，孔疏所包承唯羞己；今借不合实际承诺应坦诚共改，非指现实隐藏过错。九四41–44「有命无咎。畴离祉」，初六守正志在君而居穷下，四命初无咎，畴匹谓初，离丽即附著得祉，象志行；今借实际合宜的共同安排及当事人的真实响应，不赋夫妻古发命权限。九五45–48「休否，大人吉。其亡其亡，系于苞桑」，休美于否、遏绝小人，居尊不自安而心存将危戒慎，以系桑根牢固为喻；今借改旧难后须巩固实际分担，古危亡非实际危险之预言。上九49–52「倾否，先否后喜」，否之极能倾毁否道，先否后通方喜，不能用古喜断关系必然改善；取先解除真实阻隔再维持有益相处。

实际取象：`sources/revised/meihua-volumes-1-3.txt` 129–137行八卦万物属类、493–495行《体用总诀》体、用、互、变关系；497行坤生体“得陰人之利”，坤证母老妇在131行，古《说卦传》简体09.11:23–24坤母，仅实际女长辈自愿协助才谈有益方向；乾父老人130行、09.11:21–22，乾受体生只取真实相关事务有自身投入，不误套496尊长惠送。艮生体502“物当安稳，事有终始”，艮同气则用495比和与09.07:21–22艮止，不按生体吉义硬套。巽受体克依495看强弱、09.11:27–28取进退不果；巽直接克体结合507及同上古象，在家事中取真实变化及实际要求牵制，不拿古灾指认真人。震动决躁见09.07:21–22/09.11:25–26，震受原乾克，不把旺震变成主动克体；坎加忧/耳听09.11:29–30、09.09:21–22，尾坎受乾生只取自身投入而非直接生扶；离明09.08:22、501文书喜仅离直接生坤，可借实际意见明白确认与有益照应；兑悦口言见09.07/09.09:21–22；尾兑受体生依495取为自身沟通投入，非套511兑克体口舌。梅花520–522人事、530–532婚姻、542–543为另问产占，795后体用原则。各篇用古籍校本核对，现代亲属取象不用于指认现实人数、行为或婚外关系。

## 实际盘及三十组

寅卯春木旺火相水休金囚土死，巳午夏火旺土相木休水囚金死，申酉秋金旺水相土休火囚木死，亥子冬水旺木相金休土囚火死，辰未戌丑土旺金相火休木囚水死。下列五令次序均春、夏、秋、冬、四土。婚姻F=favourable较有安稳经营条件、C=conditional维持与改善有条件、D=difficult当前安稳偏难；对应育儿suitable=双方共愿稳定分担及现实养育条件具备较宜考虑、conditional=先落实分担及现实难处再考虑、defer=眼下宜缓。

- 初六：天地否(12)原静上乾，互风山渐(53)上巽为体互、下艮为用互，变天雷无妄(25)下震。原用坤、用互艮分别生体，巽和尾震分别由乾所克。春D/defer：囚乾，两死土薄生，双旺木难制，古戒苟进；夏C/conditional：死乾受相坤相艮有气生，两休木难制；秋F/suitable：旺乾，两休土平生、双死木可制；冬D/defer：休乾，两囚土薄生、双相木难制；土F/suitable：相乾，两旺土生力足，两囚木可制。夏/土已有需协助家事时参辰未戌丑土旺月前中两处直接生扶，其余无独立候。
- 六二：静上乾，互同，变天水讼(6)下坎受乾生耗。春D/defer：囚体两死土薄生，旺巽难制、尾休水耗；夏C/conditional：死体两相土有助，休巽难制、尾囚水耗薄；秋F/suitable：旺乾两休土平生，死巽可制、尾相坎耗可承；冬D/defer：休乾两囚土薄助，相巽难制、尾旺水重耗；土F/suitable：相体两旺土生、囚巽可制、尾死坎微耗。夏/土参前中直接生同一土旺候类，须现实已有需协助家事；其余无候。古包承宜辨互助范围。
- 六三：静上乾，同互，变天山遁(33)下艮亦直接生原乾。春D/defer：三死土微生、囚乾难制体互旺巽；夏C/conditional：死乾三相土有气生，休巽难制；秋F/suitable：旺乾三休土平助、死巽可制；冬C/conditional：休乾三囚土薄生、相巽难制但比前两爻少末难制或耗，无重耗、可实际改善；土F/suitable：相乾三旺土生、囚巽可制。夏/土已有需协助家事候前三阶段直接生体土旺月，共同候类不取三次具体日期；余无候。古包羞位不当提醒实际承接失妥应改正。
- 九四：静下坤，原上乾受体生、互下艮体互直接同比、上巽用互来克；变风地观(20)上巽再来克。春D/defer：死坤，囚乾微耗、死艮弱比、双旺巽直接克重；夏C/conditional：相坤，死乾微耗、相艮比有力，两休巽直克可承；秋C/conditional：休坤，旺乾重耗、休艮平比、两死巽薄克；冬D/defer：囚坤，休乾耗、囚艮弱比、两相巽直克实；土F/suitable：旺坤相乾有耗可承，旺艮比足，两囚巽微克。春冬已有反复家事要求，参寅卯木旺月中尾两处直接来克同候类；土令已议家事参辰未戌丑土旺月中段合作；夏秋无独立候。古有命畴祉借合宜共责有真实响应。
- 九五：静下坤，同互及本用，变火地晋(35)上离直接生。春D/defer：死坤囚乾薄耗、死艮弱比、旺巽来克重、相离尾生有助不得抹中克；夏F/suitable：相坤死乾微耗、相艮有力比、休巽来克可承、末旺离生力足；秋C/conditional：休坤旺乾重耗、休艮平比、死巽浅克、末囚离生薄；冬D/defer：囚坤休乾有耗、囚艮薄比、相巽克实、死离微生；土F/suitable：旺体能担相乾耗，旺艮比足，囚巽薄克，休离平生。春冬已有分歧候中来克寅卯木旺月，春末相离有助留而不另择关系改善时日；夏已有需办或协助家事参末旺离巳午火旺月，土已议家事参中旺艮辰未戌丑土旺月，秋无候。古苞桑戒慎求固，非实际危亡。
- 上九：静下坤，同互及本用，变泽地萃(45)上兑受体生耗。春D/defer：死坤、本末囚金微耗、死艮弱比、旺巽直克重；夏C/conditional：相坤，本末死金微耗、相艮实比、休巽直克平可担；秋D/defer：休坤、本旺乾尾旺兑双实耗，中休艮比平、死巽薄克；较九五多旺兑耗重而非来生；冬D/defer：囚坤前后休金有耗、中囚艮薄比相巽来克实；土F/suitable：旺坤承两相金耗，旺艮中比有力、囚巽来克薄，有现实共责承接能力。春冬已有实际意见或要求反复，寅卯木旺月仅中段巽直克牵制；土令已有共同家事参辰未戌丑土旺月中体互旺艮直比；前后两处体生耗不选期，夏秋独立候不足。古倾否取实去阻碍后可改善，尾兑悦言是沟通耗，并非推口舌争吵事实。
