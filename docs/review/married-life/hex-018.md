# 018 山风蛊·夫妻婚姻规则审计

## 文献实核及口径

72篇按六爻十二月独立手写并逐篇全部字段读回。静卦作原体，本用、体互、用互及末变用的作用分别直接对原体判断，不将四处串成新的相生相克。传统取象仅借以理解夫妻共同生活中的真实事务与实际分担，不当实证预测。古亲属象须现实确实相关才论，不指认现实亲属某种行为或内心，不以爻辞判定婚变或现实危险。育儿是双方当下考虑要孩子的适宜度，条件为真实双方意愿、共同分担稳定及实际养育能力；没有生产或孕产医疗判断，育儿证据只引婚姻承接传统依据493–495、530–532作现代应用，不以生产占为依据。

《周易正义》实际读 `sources/reference/zhouyi-zhengyi-hans/03蠱.txt` 34–55。初六34–37「干父之蛊，有子，考无咎，厉终吉」，以柔巽之质干父之事、堪任且不必尽承，量事制宜、意承考，取原事务可适当修整而非照搬旧要求；古有子不取真实孩子出现，厉不作实际危险。九二38–41「干母之蛊，不可贞」，屈己刚而既干且顺、干不失中，今重尊重另一当事人及实际调整，不采用古注性别评语。九三42–44「干父之蛊，小有悔，无大咎」，以刚干而无应有悔，履得其位、正干父之事，今借实际修事尚须如实协调，不定人过错。六四45–47「裕父之蛊，往见吝」，柔和容裕而无应，往未得，今取宽容未足以实际办好家事而非无原则承担。六五48–51「干父之蛊，用誉」，柔处尊位、用中而应，象传承以德，疏明中和而不任威力，现代借有真实响应的共同安排，不断人的名誉、不以威强压。上九52–55「不事王侯，高尚其事」，处事之上不累于位、清虚高尚，象曰志可则；今取尊重彼此合宜生活原则及实际责任界限，不劝夫妻离开现职或推卸共同责任。

《梅花》`sources/revised/meihua-volumes-1-3.txt` 130–137类象，母老妇在131、乾父老人130，艮少男童子136（若真涉及亲属条件才借象）；493–495体用总诀，506震克原文为虚惊恐惧，动作和决躁性质只采用《说卦》09.07、09.11:25–26而不借震克作真实危险；507巽克借现实变化限制，511兑克借已有口舌协商牵制，均按直接来克方向。兑和乾受原体土生只作自身投入，非采用金生体吉义；尾坎受土克是办事项难易非坎克体；尾离受木生是耗不是新增生扶；尾坤受木克看原体能否料理对象，不借坤生体义断女性尊长直接帮助。说卦艮止、震动、兑说悦09.07，巽进退不果09.11:27–28、兑口舌35–36，坎加忧29–30、离文明09.08:22，母09.11:23–24；这些是传统性质与人事借象，现代生活只按真有事务或亲属参与才使用。520–522人事、530–532婚姻；古婚姻整体承接力用到新增养育责任是现代类推，不混入古产占分题。

## 实际盘、五态及三十组

五令次序春、夏、秋、冬、四土：寅卯木旺火相水休金囚土死；巳午火旺土相木休水囚金死；申酉金旺水相土休火囚木死；亥子水旺木相金休土囚火死；辰未戌丑土旺金相火休木囚水死。婚姻 F=favourable，C=conditional，D=difficult，育儿分别 suitable（三实际条件齐才可考虑）、conditional（当前困难先实解及共担稳定）、defer（眼下暂缓）。月候仅有现实事务且直接生比来克有强气才列；相同元素不同阶段只列同一传统候类，非必然时日；旧事存在才参。

- 初六：原18山风蛊静上艮，互54雷泽归妹上震体互、下兑用互，变26山天大畜下乾。巽本与震体互分别直接克艮，兑用互与乾末均受原艮生而耗。春D/defer：死艮受双旺木重克，两囚金耗薄；夏C/conditional：相艮能承两休木平克、两死金耗微；秋D/defer：休艮受两死木薄克但两旺金耗重；冬D/defer：囚艮受两相木直克实及两休金生耗；土C/conditional：旺艮承两囚木克薄及两相金生耗，无直接支持，先落实分担。春冬实际已有待改家事、实施困难时参寅卯木旺月本用巽前段反复及体互震中段行动阻节；其他无独立候。古以承先、堪任、量事制宜修旧事非预示孩子。
- 九二：同静上艮、同本及互，变52艮为山下艮直接同比。春D/defer：死艮双旺木克重、囚兑生耗微、尾死艮比薄；夏C/conditional：相艮可承双休木平克、死兑耗微及尾相艮实比，仍待先稳分工；秋C/conditional：休艮双死木克微、旺兑耗重、尾休艮普通比留改善机会；冬D/defer：囚艮双相木直克实、休兑生耗、末囚艮薄比；土F/suitable：旺艮承双囚木克薄、相兑耗与末旺艮实比，实际有承接。春冬候前中木旺月旧安排及执行困难，夏土已有家事参辰未戌丑土旺月尾艮比的协作稳定；秋无强候。古既干且顺取分担方法适宜。
- 九三：同静上艮、互同，变4山水蒙下坎受原艮克。春D/defer：死艮双旺木重克、囚兑耗薄、末休水难制；夏C/conditional：相艮承两休木克平且死兑耗微、末囚水可制；秋D/defer：休艮两死木薄克、旺兑耗重、末相水难制；冬D/defer：囚艮双相木实克、休兑耗、末旺水难制；土C/conditional：旺艮承双囚木薄克与相兑生耗、末死坎可制但未得直生比。春冬前中已存在家事候木旺月实际安排反复与执行阻节，其他无强直接生比克候。古小悔无大咎取真实修事不保证结果。
- 六四：原下巽静，原用上艮受体克；互54下兑体互直克、上震用互直比，变50火风鼎上离受体生耗。春F/suitable：旺巽克死艮易，囚兑克薄、旺震比实、相离自身耗可承；夏D/defer：休巽难制相艮、死兑克微、休震比普通，末旺离受体生耗重；秋D/defer：死巽难制休艮、旺兑重克、死震比微、囚离耗薄；冬F/suitable：相巽克囚艮可理，休兑克平可承、相震比实、死离耗微；土D/defer：囚巽难制旺艮、相兑实克、囚震薄比、休离自身耗。春冬中段既有家事参寅卯木旺月震直比实际协作，秋土中段已有沟通争议参申酉金旺月兑直克协商牵制，夏无强候，尾离只耗不选火月。古裕父宽容仍需实际回应。
- 六五：静下巽、同本及互，变57巽为风上巽同比。春F/suitable：旺巽能制死艮，囚兑薄克，中旺震与末旺巽两强比；夏C/conditional：休巽难制相艮、死兑克微、休震及休巽两比平；秋D/defer：死巽难制休艮，旺兑克重，震巽两死比薄；冬F/suitable：相巽制囚艮可理，休兑克平可承，震巽两同比实；土D/defer：囚巽难制旺艮，相兑实克，囚震巽比薄。春冬已有家事参寅卯木旺月中段震比协作和尾巽比协调，秋土参申酉金旺月已有沟通牵制中段，夏无具体候。不同于六四，夏以两普通比替换旺离耗，改善仍有条件；古承以德不任威力。
- 上九：静下巽、同本及互，变46地风升上坤受原体克。春F/suitable：旺巽制本死艮和尾死坤皆易料理，囚兑克薄、旺震比实；夏D/defer：休巽制两相土难，死兑克微、休震比平, 多一末难制而非六五尾普通比；秋D/defer：死巽制两休土难，旺兑重克，死震薄比；冬F/suitable：相巽制两囚土可理，休兑克平可承、相震直比有实；土D/defer：囚巽制两旺土难，相兑克有气、囚震比薄。春冬已有需共同办理的事情，参寅卯木旺月中段震同比协力；秋土已有现实沟通困难参申酉金旺月中段兑来克，夏无强候；前尾两土受体克不另选土月。古志可则重合宜责任原则，不劝弃责。
