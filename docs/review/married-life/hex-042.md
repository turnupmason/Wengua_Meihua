# 042 风雷益·夫妻婚姻规则审计

## 古籍实核与现代使用

实读 `sources/reference/zhouyi-zhengyi-hans/04益.txt` 24–61。初九38–41「利用为大作，元吉，无咎」，益初动始，刚能干而有兴作之才与时，位下非任厚事之位，必须实际大功及人相与方免咎；现代重要共同生活安排须各方实际参与及具备真实能力。六二42–45「或益之十朋之龟，弗克违，永贞吉。王用享于帝，吉」，柔中当位能谦冲，益自外来非召而至，位不尊所以须永贞，享帝为古礼；今借自愿实际帮助及守信，不以弗克违强迫配偶或保证他人相助。六三46–49「益之，用凶事，无咎。有孚中行，告公用圭」，求益己自为，若用于救真正困难且不私不亢、有信实行中方免咎，告公执圭属古礼；现代实际重要困难要通过共同商议和投入解决，不据古凶事判现实危险。六四50–53「中行，告公从，利用为依迁国」，柔当位、在上应下，虽位不中而用中行，迁国是古时大事有依；今借重要家事真正参与、双方认可和实际依托，不据迁国推定搬家或命人服从。九五54–57「有孚惠心，勿问元吉。有孚，惠我德」，因物所利而利之、惠心而有信用、物亦有相应；今取照顾真实所需和共同分担信用，勿问不指真人真实内心，不保证回报。上九58–61「莫益之，或击之，立心勿恒，凶」，居益极过盈、求益无已、独唱莫和，戒求索无度；现代借尊重实际能力及合理责任，古击凶不作现实伤害、危险或婚姻结果判断。

实读 `sources/revised/meihua-volumes-1-3.txt` 130乾父老人、131坤母老妇、493–495体用总诀、504乾来克取尊长怒、511兑来克取口舌、530–532婚姻。坤在本卦各爻出现皆受原静木体直接克，母老妇具体照料责任须以真实有关才论；不得作为来克或生扶。艮安止取《说卦》09.07，均为直接受原木体克的现实可料理或难料理事项。震主行动，巽有进退义取《说卦》09.07、09.11:25–28，仅共同协作或调整方向，不作真实心意、地点、身份。六二尾兑直接克原巽，口言及意见牵制方用511、说卦09.11:35–36；六四尾乾直接克原震，男性长辈现实涉事或其他明确家庭要求实制方用504、130与说卦09.11:21–22，不指认善恶或必然干涉。六三尾离受原巽直接生为自身投入，文明取《说卦》09.08:22，不能冒作外来火克。上九尾坎直接生原震只取现实可用援手总诀493–495，非具体人物、地点等。育儿统一为现代夫妻生活整体承接类推，以493–495、530–532为依据，非产占，不引用542–543，不涉及生育日期、健康、产孕、性别。
