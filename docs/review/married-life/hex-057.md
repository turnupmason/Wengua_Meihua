# 057 巽为风·夫妻婚姻规则审计
2026-11-27，72篇逐月独立写作及作者全字段实读。以下规则分组及取象仅为传统易占内部推理与现代婚姻经营的类推，不是可验证的婚姻事实推断，也不声称真实预测准确率。

## 查证原文、边界及变卦
已核《周易正义》sources/reference/zhouyi-zhengyi-hans/06巽.txt 40–65。初六40–45「进退，利武人之贞」，法未明、柔巽志疑而待整齐，今借共同分工清晰，非发令或压服。九二46–49「巽在床下，用史巫纷若，吉，无咎」，卑巽而得中、用之于神祇非威势，今借体谅合宜，非祭祀或自贬。九三50–53「频巽，吝」，频蹙不安、志穷，今借不长期勉强迁就。六四54–57「悔亡，田获三品」，乘刚虽有悔、得位承尊履正行命有功，三品各有其用，今借已商定家事重真实成效，非钱财预测。九五58–61「贞吉，悔亡，无不利。无初有终。先庚三日，后庚三日，吉」，居中正能申命，骤以刚直化人则开始不悦，前后申明才得成；今借夫妻充分商议并逐渐实行，不取古日数或一方管制。上九62–65「巽在床下，丧其资斧，贞凶」，巽极过甚丧所以断，斧为威断之喻；今借彼此体谅而仍有判断能力、自主承接责任，非真实损财、配偶施威。
《说卦传》09.11:27–28巽有进退义，取实际生活分工；09.09:22、09.11:35–36兑口舌悦，互兑确系直接来克原木，才在已有现实言语分歧时援《体用总诀》511行，不由卦虚构争吵。09.08:22离文明，互离为原木所生，只作己耗、明确实际投入，非第三者。09.11:21–22乾为父，梅花130老人、504来克原体尊长忧，初/四变乾直接来克原木，只有真正有男性长辈意见干涉共同家事时才取象，不能断言家中必有长辈矛盾。09.07:21、09.11:33–34艮止，二/五变艮由原木所克，为实际家事可制或难制，非来克。09.09:21–22坎耳，三/六变坎水直接生原巽木，借现实倾听与相助，《体用总诀》493–495、500。无直接第三者、女性尊长关系证据，不另作假设。
同一原静巽木贯穿本、互、变四直接作用：《体用总诀》493–495、795–796。初二三静上巽木、本用下巽，体互上离与用互下兑；四五上静下巽木、本用上巽，体互下兑与用互上离。本57互38火泽睽；初变09风天小畜、四变44天风姤，乾金直接克原体；二变53风山渐、五变18山风蛊，艮土受原木克；三变59风水涣、上变48水风井，坎水直接生原木。原体不随节点更换。春木旺火相水休金囚土死；夏火旺土相木休水囚金死；秋金旺水相土休火囚木死；冬水旺木相金休土囚火死；土旺金相火休木囚水死。
育儿只借婚姻关系承接力（梅花493–495、530–532），无孩者仅判断当前是否适合考虑，真实共同养育意愿、原有责任长期稳定共同承担与实际照料能力三条件齐才可议；不预测怀孕、出生时间、人口或身体健康。时段只对应已经存在的实际事项：强或有气直接同比、克、生所见，木旺月寅卯前段共同办事，金旺月申酉中段已有口舌，初四同金旺后段实际男性尊长意见，三上水旺月亥子后段实际援助；不把普通或薄克、薄生及体生耗、体克难制取成应期。
