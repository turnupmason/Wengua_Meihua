# 030 离为火·夫妻婚姻规则审计

## 古籍实核与使用范围

实际研读 `sources/reference/zhouyi-zhengyi-hans/03離.txt` 34–54。初九34–36「履错然，敬之，无咎」，注疏释错然警慎貌，处离之始未既济，须谨慎践履，现代借双方采取负得起责任的办法。六二37–39「黄离，元吉」，黄中色，居中得位、柔处柔，文明之盛得中，现代兼顾双方实际需要而非勉强一方。九三40–43「日昃之离，不鼓缶而歌，则大耋之嗟，凶」，下离终明将没，注疏宜委事任人、养志无为，不取现实寿夭、时辰，而借实际职责及时交接。九四44–46「突如其来如，焚如，死如，弃如」，明道始变、突进炎盛与承接失当，现代不骤然增加家庭责任，非灾害危险或夫妻离弃的现实判断。六五47–50「出涕沱若，戚嗟若，吉」，履非其位忧深而所丽在尊、众所助，现代如实说明困难寻求实助，不据爻认定配偶哭泣或内心。上九51–54「王用出征，有嘉折首，获匪其丑，无咎」，离极道成、各安其所丽，古王者除民害以正邦，现代仅借解决实际家事的主要难处，不借古军国刑罚指真人行为、安危，不作暴力指引。

实际研读 `sources/revised/meihua-volumes-1-3.txt` 130乾父老人、493–495体用总诀、498震直接生体、499巽直接生体、530–532婚姻。乾父老人须现实家事确涉及才取，乾为受体克对象，非尊长来克。兑悦/口舌《说卦》09.07、09.11:35–36，仅借事项商议性质，实际受原体克，不用兑来克口舌占。巽进退不果09.11:27–28、震动09.07及决躁09.11:25–26、艮止09.07、离文明09.08:22，巽震为真实生体的传统支持方向，艮为原体生耗，不算外来克制或支持。全部现代养育推演仅以493–495、530–532婚姻承接类推，非产占；真实养育共愿、长期实际分担、现实养育条件均必要。

## 独立盘与三十组五令

固定原体为未动本经卦，原用、体互、用互、末变用各与原体直接论，互不串联。五令为春寅卯木旺火相水休金囚土死，夏巳午火旺土相木休水囚金死，秋申酉金旺水相土休火囚木死，冬亥子水旺木相金休土囚火死，四土辰未戌丑土旺金相火休木囚水死。F/suitable较利长稳、三现实条件齐可考虑要孩子；C/conditional婚姻可改善维护、已有难处实际解决和共同分担稳定才重议；D/defer目前长稳较困难且暂缓考虑要孩子。候只参真实存在的家事及相应作用，不取婚姻结果、年限、生育日期。

- 初九：本30离为火静上离，互28泽风大过上兑为体互、下巽用互，末56火山旅下艮。原下离同气，上兑受体克，下巽直接生，末艮受原离生而耗。春F：相离同比实、旺巽强生、囚兑可理、死艮微耗；夏F：旺离同比强、休巽平生、死兑易理、相艮实耗可承；秋D：囚离薄比、死巽微生、旺兑难制、休艮耗；冬C：死离微比、相巽实生、休兑难制、囚艮耗薄；土D：休离平比、囚巽薄生、相兑难制、旺艮重耗。春已有共同家事参巳午火旺月起段协作，实际需协调援手的既有家事参寅卯木旺月中段；夏前火，冬中木，秋土无明确年月候。尾耗不作土来克候。
- 六二：静上离，原下离比、上兑体互受克、下巽用互直生，末14火天大有下乾受体克。春F：相离实比、旺巽强生、囚兑乾可理；夏F：旺离强比、休巽平生、死兑乾易理；秋D：囚离薄比、死巽微生、旺兑乾难制；冬C：死离微比、相巽实生、休兑乾难制；土D：休离平比、囚巽薄生、相兑乾难制。春前火中木，夏前火，冬中木，秋土无候；两个受体克对象难制不作金来克月。古黄离取中。
- 九三：静上离，原下离比、上兑受体克、下巽来生，末21火雷噬嗑下震直接生。春F：相离实比、旺巽旺震双强生、囚兑可理；夏F：旺离强比、休巽休震平生、死兑易理；秋D：囚离薄比、死巽死震微生、旺兑难制；冬C：死离微比、两相木生实而休兑难制；土C：休离比平、双囚木薄生保改善方向、相兑难制。春既有家事火旺月前协作，木旺月中段实际协调援手及尾段实际执行援手；夏前火；冬中尾木，秋土无候。古日昃贵适当委事、非寿夭。
- 九四：静下离，原上离比、28下巽体互直接生、上兑用互受克，末22山火贲上艮为体生耗。五令与初九同码 F/F/D/C/D，盘力逐项同初九但互卦体用名换位。春前火中木，夏前火，冬中木，秋土无候；艮受原离生而耗，非直接来克。古突进警戒不是实际灾害。
- 六五：静下离，原上离比、下巽体互直生、上兑用互受克，末13天火同人上乾受体克。春相离实比旺巽强生囚二金可理 F，夏旺离强比休巽平生死二金易理 F，秋囚离薄比死巽微生旺二金难制 D，冬死离微比相巽实生休二金难制 C，土休离平比囚巽薄生相二金难制 D。候春前火中木、夏前火、冬中木，秋土暂无；古忧而获助可借真实支持，不代判真人心意。
- 上九：静下离，原上离比、下巽体互直生、上兑用互受克，末55雷火丰上震直生。春相离实比双旺木强生囚兑可理 F；夏旺离强比双休木平生死兑易理 F；秋囚离薄比双死木微生旺兑难制 D；冬死离微比双相木生实休兑难制 C；土休离平比双囚木薄生相兑难制 C。春前火中尾木、夏前火、冬中尾木、秋土无明确月候。中尾木分别是现实协调援手和执行援手，均需原家事已有；古军国语境不指现实暴力或危险。
