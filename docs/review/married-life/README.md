## 写作、核验及发布方法

- 64卦、6个动爻、12个显式月令，总目标4,608篇。本项从零原创，不承接未婚求婚或表白的五气旧判；每篇保留原体、四直接作用、实盘旺衰、具体象类和古爻依据。五气相同的盘锁定婚姻相处方向与育儿适宜度一致，文字分别撰写。
- 各篇正文500–650汉字，简断60–120汉字；没有固定模板起笔，不用虚构故事凑厚度。用户明确禁止“不能……更不能”式连环否定。对尊长、口舌、亲属及交往边界的判断须有实际卦象及生克证据，区分直接古条和现代家庭类推。无孩者每篇均给当前婚姻承接新增育儿责任的适宜方向，不预测孕产。
- 每篇正文、简断、标题、判断、取期和证据由作者实读；不同独立AI阅读者完整读回并返修复读，逐对象 SHA-256 锁定，不冒充真人验收。全部出稿经过 `scripts/review/married-life-monthly.mjs` 独立计算及渲染核对；`scripts/review/check-missing-person-style.py --item married-life` 复现全量风格及重复检查。词筛提示均由 Guan 按语境处置，风格碰撞实修并重新全文双读。机器校验不单独证明语义正确或未来真实事件。
- 每完整卦72篇后提供逐卦古籍、规则及五气三十组判读依据的独立审计，完整源指纹与审计文件逐一对应。发布不改变运行时代码或真人专业审核状态。
