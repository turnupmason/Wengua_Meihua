# 048 水风井·夫妻婚姻规则审计

## 古籍实际核读及现代取义

实读 `sources/reference/zhouyi-zhengyi-hans/05井.txt` 24–65。初六43–46「井泥不食，旧井无禽」居井底、上无应，泥滞而久未渫治、一时见舍，今取既有不合宜的日常分担须真正改善。九二47–50「井谷射鲋，瓮敝漏」井本以下给上，上无应而反下比初，失井的正常用道，如谷水下注；今取共同生活实际投入必须真正改善原有问题，非物损或财损预测。九三51–53「井渫不食，为我心恻，可用汲。王明，并受其福」井已修洁有上应可汲而尚未见用，待明主用其才，今借已有合宜分工尚须在实际生活中发挥效用，不由心恻读真人内心或移古尊卑。六四54–58「井甃，无咎」，得位无应、自守能修井崩坏、未可上给养人。54的自守有55校注说明依据四库全书本改原抓取白守，孔疏亦作自守。借真正修正旧的实际分担，非房屋、身体或现实关系结果的预断。九五59–62「井洌寒泉，食」，中正刚直、不食不义，古喻主择贤才行洁高然后用。现代借分工办法须能真正发挥日常效果，不以古泉喻现代卫生、健康、食物、人品和家庭尊卑。上六63–65「井收。勿幕有孚，元吉」，水已出井、井功大成、幕覆，贵不擅其有不私其利而与众共享；今取共同责任有真实效用且双方受益，不以元吉确定婚姻结果、不以古孚认定真实心意。

《梅花》`sources/revised/meihua-volumes-1-3.txt` 130乾父老人、131坤母老妇、493–495四直接作用及体用总诀、496乾生体尊长援手、503兑生体悦事、510艮克体诸谋中阻、511兑克体口舌、530–532婚姻。乾只初六尾变用直接生原坎，男性长辈实有参与方论实际援助，不指定人物或人数。九二尾艮来克取实际安顿限制，以《说卦》09.07艮止相证。九五尾坤受原巽克，是有待料理的责任，母老妇仅现实涉及才论，不冒作来克或援手。第一至三爻中兑直接生原坎，悦象取沟通中实际照应，后四至六爻中兑直接克原巽，取口言和真实要求限制，六四尾兑另直克独立。坎主耳听与加忧由《说卦》09.09:21–22、09.11:29–30，四至六爻前坎直接生原巽取理解实际困难而可用帮助；三爻尾坎同比仅真实共同承担，不作外生或危险。巽进退取09.11:27–28、离文明取09.08:22，前3本巽体生用为自身耗、中离受原体克可理或难制；后3中离受原体生为自身耗，不作火来克。育儿仅依493–495及530–532婚姻共同承接现代类推，非生产占，不用542–543，不推产孕、身体、性别、生育日期。

## 排盘与三十个五令组

独立复核48本卦水风井、互38火泽睽；初二三下动静上坎为原水体，本下巽受原体生为己耗，中上离体互受体克、中下兑用互直接生；四五六上动静下巽为原木体，本上坎直接生、中下兑体互来克、中上离用互受原体生为己耗。所有中间及末作用独立回指原体，不以互卦彼此串生克。春寅卯木旺火相水休金囚土死；夏巳午火旺土相木休水囚金死；秋申酉金旺水相土休火囚木死；冬亥子水旺木相金休土囚火死；辰未戌丑季土土旺金相火休木囚水死。F/suitable 只在无孩者已经长期稳定共同分担、双方真实愿养育及实际养育条件齐时可考虑。C/conditional 原困难须实解，长期稳定共担及共愿和实际养育条件齐，才议；D/defer 暂缓，先改善旧实际分担，未来三项齐再议。月候只既有实际家事或实际制约、旺相生比来克，不把受体克或体生耗择为来克或援期，也不预测夫妻结果或生育年月。

- 初六48→38→5水天需，末下乾直接生原坎。春D：休坎生旺巽重己耗，相离受克难制，囚兑与囚乾各薄生；夏D：囚坎生休巽普通耗、旺离难制、双死金微生；秋F：相坎生死巽微耗，囚离可理、双旺金各强生；冬F：旺坎生相巽实耗可承，死离易理、两休金各普通生；季土C：死坎生囚巽薄耗，休离难理、两相金分别实生有改善方向。秋土既有需实际照应的家事，申酉金旺月参中兑交流援手、尾乾具体支持的两实际阶段，男性长辈真实参与才论；春夏冬无明确月候。
- 九二48→38→39水山蹇，末下艮直接克原坎。春D：休坎生旺巽重耗，相离难制，囚兑薄生、死艮微克；夏D：囚坎生休巽有耗，旺离难制、死兑微生、相艮实来克；秋F：相坎轻己耗、囚离可理、旺兑强生、休艮普通来克可承；冬F：旺坎生相巽实耗可承、死离易理、休兑普通生、囚艮薄来克；季土D：死坎生囚巽薄耗，休离难理，相兑实援、旺艮尾重来克仍须料理。夏实际有安顿限制家事土旺辰未戌丑月尾段阻力；秋有实际需援家事金中交流援手；土金中实援及土尾实际限制独立，各须实事。春冬无明确候。
- 九三48→38→29坎为水，末下坎同比。春D：旺巽重己耗、相离难制、囚兑薄援、休坎普通尾比；夏D：囚坎生休巽普通耗、旺离难制、死兑微生、末囚坎薄比；秋F：相坎轻耗、囚离可理、旺兑强生、相坎实比；冬F：旺坎生相巽可承实耗、死离易理、休兑普通生、末旺水强比；土C：死坎生囚巽薄耗、休离难理、相兑实援、死坎微比，有实际扶助改善而旧难仍待解决。秋金旺中现实沟通援助与水旺尾共同办理实际家事各参；冬亥子水旺月尾实际共同协作；土金旺中实际交流援手；春夏无明确候。
- 六四48→38→28泽风大过，变上兑另直接克原巽。春F：旺巽受休坎普通生、囚兑两薄克、中相离实耗可承；夏D：休巽得囚坎薄生、中尾死兑各微克、中旺离重耗；秋D：死巽得相坎实生，双旺兑中尾各重克，中囚离薄耗不足改判；冬F：相巽得旺坎强生，中尾两休兑普通克可承，死离微耗；土D：囚巽得死坎微生，中尾相兑各实来克，中休离普通耗。秋若已有需援手家事参亥子水旺月前段实际援手；金旺申酉月中段分担意见制约与尾段执行其他具体限制独立。冬水前实际援手；土金中实际分歧与尾实际办理限制分别触发；春夏无明确候。
- 九五48→38→46地风升，末上坤受原巽克。春F：旺巽得休坎平生，囚兑薄来克，相离实耗可承，死坤易理；夏D：休巽得囚坎薄生，死兑微克，旺离重耗，相坤难体克；秋D：死巽得相坎实生，旺兑重克、囚离薄己耗，休坤难体克；冬F：相巽得旺坎强生，休兑普通来克可承，死离微己耗，囚坤可理；土D：囚巽得死坎微生，相兑实克、休离普通己耗，旺坤难制。秋水前实际援手与金中真实分担意见或其他要求的限制；冬水前实际援手；土金中实际限制。春夏无明确候，全部月令尾坤不作来克不取土候。
- 上六48→38→57巽为风，末上巽同比。春F：旺巽得休坎普通生，囚兑薄来克，相离实己耗可承，旺巽尾强比；夏C：休巽得囚坎薄生，死兑微来克，中旺离重己耗仍须实解，末休巽普通比留共同办理改善方向，非强援或当前适养；与六四夏D相比尾由微克转为普通比，与九五夏D相比尾由难制相坤换普通比。秋D：死巽得相坎实援，旺兑重来克、囚离薄耗、死巽尾微比；冬F：相巽得旺坎强生，休兑普通克可承，死离微己耗、相巽实尾比；土D：囚巽得死坎微生，相兑实来克、休离普通耗，尾囚巽薄比。春木旺寅卯月尾共同家事实际协调，夏无明确年月候；秋水前实际援手、金中真实限制；冬水前已有需援家事与木尾已有共同待办分别触发；土金中已有实际分担要求制约。古元吉不改变实际四作用及月令。
