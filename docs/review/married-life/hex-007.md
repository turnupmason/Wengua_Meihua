# 地水师（007）夫妻婚姻 · 全卦规则审计

## 原典及取象

- 实际校读 `sources/reference/zhouyi-zhengyi-hans/02師.txt`：初六「师出以律，否臧凶」（30–33），王孔重起始有共同规矩，现代借为夫妻初段共同认可的生活原则；九二「在师中吉，无咎，王三锡命」（34–37），居中能统而有应，借实际共同承担与相互认可；六三「师或舆尸，凶」（38–41），乘刚失位、进退无据，小象大无功，仅取缺少实际共同条件时反复推进难有成效；六四「师左次，无咎」（42–45），得位无应宜处、未失常，借条件不具时暂缓；六五「利执言，无咎」及后段所任合宜与否（46–48），小象「以中行也」「使不当也」，借已有正当事由可以明言、责任按能力安排，不以长子弟子预断家中孩子身份；上六「开国承家，小人勿用」（49–52），师终安定结果、任事得当，小象正功，借长期家庭责任妥善分配，不据古身份词判身边人的善恶，也不将军旅之义直接断现实人身事故。
- 实读 `sources/revised/meihua-volumes-1-3.txt` 493–495行体用及生克，505坤来克、506震来克、507巽来克、510艮来克、511兑来克；坤类131老妇，兑类及《说卦传》09.07、09.09、09.11口、悦、坎耳加忧、坤母、震动作决躁、巽进退不果、艮止。初至三原坤为体，坎受体克，坎忧依强弱可处理或难制，非坎来克；坤体互同气，女性尊长若确参与相关家事才可谈同向协调；震用互直接克体才取不安静；初末兑受生耗，不能作兑直接来克口舌，取交流耗心力；二末坤同比；三末巽直接来克才取意见迟疑及进退牵制。四至上原坎静体，坤本及用互直接来克，505原文「或有阴人之侵」仅借母、老妇类象与现实家庭意见条件，非证实际侵害或某人必然介入。震体互为受原坎生耗；六四末震亦受生耗，六五末坎同比，末旺相有实际同向接应，末休囚死较弱；上六末艮直克取阻碍。
- 原盘7师、互24复，从初到上变19临、2坤、46升、40解、29坎、4蒙。初至三下动、上坤土为原静体，本下坎水受体克、体互上坤同比、用互下震木来克，末下依次兑金受生耗、坤土同比、巽木来克。四至上上动、下坎水原静体，本上坤土及用互上坤土来克、体互下震木受原体生耗，末上依次震木受体生、坎水同比、艮土直克。四作用全对原体，不以体互替代、不因变名作吉凶。
- 五气：寅卯木旺火相水休金囚土死；巳午火旺土相木休水囚金死；申酉金旺水相土休火囚木死；亥子水旺木相金休土囚火死；辰戌丑未土旺金相火休木囚水死。
