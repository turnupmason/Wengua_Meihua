# 036 地火明夷·夫妻婚姻规则审计

## 古籍实核与现代使用

实读 `sources/reference/zhouyi-zhengyi-hans/04明夷.txt` 24–54：初九31–34「明夷于飞，垂其翼。君子于行，三日不食。有攸往，主人有言」，居卦初远于难，君子尚义远行而不敢显，主人见殊类而疑；借家事有实际不便先量力处理，不据古远行、饮食或三日定现实安全、健康或日期。六二35–38「明夷，夷于左股，用拯马壮，吉」，庄氏左取伤小，王孔柔中循则、徐徐用马以自拯；只借实际帮助缓解既有困难，非身体伤情预测。九三39–42「明夷于南狩，得其大首，不可疾贞」，古狩征除暗主后，民迷日久化宜以渐，不可速正；现代仅借先实解主要家事难处、逐渐改善其他责任，不以古军国征伐指真人、伤害或危险。六四43–46「入于左腹，获明夷之心，于出门庭」，左取顺，腹事情之地，得情势而能随时离难；仅借实查问题、选择合宜做法，不以获心意断配偶隐秘内心。六五47–50「箕子之明夷，利贞」，箕子近于至晦而执志不回，明不可息；只借共同生活合理分担原则和自主判断，不以古人物近难断现实危险、品性、夫妻身份或支配关系。上六51–54「不明晦，初登于天，后入于地」，明夷之极，本初光照转于晦，象称失则；借已合宜安排仍需以现实长期成效检验，不作现实人物、危险、婚姻结果预测。

实读 `sources/revised/meihua-volumes-1-3.txt` 493–495体用总诀、131坤母老妇、498震直生体、501离直生体、530–532婚姻。离文明取《说卦》09.08:22，实际办事指导、援手只按有真实事由；震动09.07及09.11:25–26，原震来克时只借现实行动安排牵制，不引用506的古惊惧灾象；原震直接生时取498动中之喜的实际协作援手类推。坎有耳及忧09.09、09.11:29–30，受原坤克时是原体自身料理事务的难易，不作坎来克；静下离时坎来克才取已有顾虑造成的具体限制，非真人隐藏心理。坤母老妇取实际有关女性长辈的照料条件，不指定哪一边亲属、人数或态度；坤受体生时是本人/夫妻耗力，非女性长辈来克。乾在六二末为体生耗，不取乾亲属来克或来援；艮安止《说卦》09.07，初九尾艮同气与上六尾艮体生耗分别论，非任意转生。育儿一律现代关系承接类推，只以493–495、530–532，不引用产占。真实共同养育意愿、现实养育条件及已经稳定的共同分担是必要条件；不预测生育日期、产孕、医学、性别。

## 原盘与三十个五令判组

固定原体不变，本用、体互、用互、末变用均直接分别与原体论；不得互卦相互串生克。五令：春寅卯木旺火相水休金囚土死；夏巳午火旺土相木休水囚金死；秋申酉金旺水相土休火囚木死；冬亥子水旺木相金休土囚火死；四土辰未戌丑土旺金相火休木囚水死。F/suitable 表实际较利长稳，三现实条件齐可考虑要孩子；C/conditional 婚姻可维持改善，已有困难需实解、共同分担稳定、两人真愿且实际养育条件齐再考虑；D/defer 当前长稳偏难，暂缓考虑要孩子。年月只参确有原先生活事务的现实帮助、协作或限制，直接旺相生比来克才参；不能用受体克难制或体生耗另作来克年月，也不择婚姻、人物安危或生育结果日期。实际独立盘的原卦36、互40雷水解，前三爻静上坤，体互上震用互下坎；后三爻静下离，体互下坎用互上震。

- 初九36→40→15地山谦，静上坤土，本下离直接生，中上震来克、下坎受原坤克，末下艮同比。春D：死坤得相离实生、旺震重克、休坎体克难理、死艮微比；夏F：相坤得旺离强生、休震平克可承、囚坎可理、相艮实比；秋C：休坤、囚离薄生、死震微克、相坎难理、休艮平比；冬D：囚坤、死离微生、相震实克、旺坎难理、囚艮薄比；土F：旺坤、休离平生、囚震薄克、死坎易理、旺艮强比。春巳午火旺月参已有需援手家事前段支持、寅卯木旺月参真实行动牵制中段；夏前已需助参火，尾既有长期共同责任参辰未戌丑土旺月实际共担；冬参中段木实际制约；土参尾土实际分担；秋无明确年月候。

- 九三36→40→24地雷复，静上坤，本下离直生、上震直接克、下坎受原坤克，尾下震另直接克。春D：死坤相离实扶、两旺震分别重克、休坎难制；夏C：相坤旺离强援、两休震普通制约仍须分别解决、囚坎较可理；秋C：休坤囚离薄生、两死震微克、相坎体克难制；冬D：囚坤死离微生、两相震实克、旺坎难制；土F：旺坤承休火平援、两囚震浅克、死坎易制。春火旺月参前段实际帮助，木旺月分别参中段已有行动实制和尾段未解制约；夏前火实际援手；冬中尾木各真实限制；秋土无明确年月候。古不可疾贞取循序改善，不作军事或真人安危。
