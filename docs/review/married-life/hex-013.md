# 天火同人（013）夫妻婚姻 · 全卦规则审计

## 原典、盘面与取象

- 实读仓库汉化校本 `sources/reference/zhouyi-zhengyi-hans/02同人.txt`：初九「同人于门，无咎」（38–41），无应、心无系吝而宽和；六二「同人于宗，吝」（42–44），古偏狭于本宗，现代夫妻不偏一方习惯；九三「三岁不兴」（45–48），古贪于所比而欲据六二夺九五之应，借尊重关系边界，事实及双方意愿为准，不据古军旅象判身边人或实定三年；九四「弗克攻，吉」（49–52），九四效九三争六二违义伤理，不克后自省反则，今取主动调整不合宜的生活做法；九五「同人先号咷，而后笑」（53–56），二五正应而三四争二有间隔、小象中直，借先有现实阻碍、后相合须真实共同意愿，古「大师克相遇」不移作现代强迫手段；上九「同人于郊，无悔」（57–60），远于内争而未获同志、志未得，不断分离或婚变，取减少争论之后也要有真实共同目标。古争据应合关系只用于共同尊重交往分寸，不能证实第三者、实际行为或意图。
- 实读 `sources/revised/meihua-volumes-1-3.txt` 493–495 原体/用互变及四类直接关系，509离来克文书之忧仅在已有生活约定需双方决定时借用，502艮直接生体取「物当安稳，事有终始」，499巽生体之直接扶助结合《说卦》09.07巽入为现代相互理解。乾父老人取梅花130及《说卦传》09.11:21–22；乾是中比或受原火克的对象，不套504乾来克尊长之怒；只在父亲、公公等男性长辈确有家事参与时，按实际可商、同向助力或难协调论。巽进退不果09.11:27–28，震动决躁25–26，前三爻的巽、九三末震均受原体克，旺衰定能制难制，不作来克。上九末兑亦受体克，09.07及09.11:35–36悦及口言取实际沟通是否有力料理，不套511兑克体口舌。
- 实盘13同人→44姤，初至三下离动，静上乾为原体，本离直接克乾，体互上乾同比，用互下巽受乾体克，末下依次艮（33遁，生乾）、乾（1乾，同比）、震（25无妄，受乾克）。四至上上乾动，静下离为原体，本及用互上乾受火克，体互下巽直接生原火，末上依次巽（37家人，生火）、离（30离，同比）、兑（49革，受离克）。各动处直接对原静体，不以互体代体、变卦名不直接定婚姻事实。
- 五气：春寅卯木旺火相水休金囚土死；夏巳午火旺土相木休水囚金死；秋申酉金旺水相土休火囚木死；冬亥子水旺木相金休土囚火死；土辰未戌丑土旺金相火休木囚水死。
