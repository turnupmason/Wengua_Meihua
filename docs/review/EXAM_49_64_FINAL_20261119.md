## 二、写手报来的疑问与裁定

| 盘 | 疑问 | 裁定 |
|---|---|---|
| 丰上六「三岁不觌，凶」（不翻）与渐九三「妇孕不育，凶」（翻） | 宽严不一 | 维持。丰上六小象「自藏也」，凶在自身闭藏，定稿第二步以它为「不降」原例；渐九三「不育」是成果出不来，落在结果上 |
| 归妹六五 秋、土令 | 无生体之卦而判能过，与《占卦诀》「无生体之卦，有克体之卦，则事不谐」字面相悖 | 维持。定稿 R3↑：克只在中段且无气、体有力、开头与结局皆比和或体克用。依据是《求名占》「体克用，名可成」、《体用互变之诀》「变生体及比和，则事事临终有吉利」、《时令之应》「克体卦气，则宜乘衰」 |
| 旅初六五月令 | 变用比和而判过不了 | 维持。本用泄体，「体生用，名不可就」；变用不生体，不能按「先凶后吉」翻成（定稿第十节第 2 条，例外只限变用生体，依少年有喜色占） |
| 节六四、上六 | 本用泄、末段体克用判过不了，与 R3↑ 末段体克用作吉不一致 | 维持。两条开头不同：R3↑ 要求开头比和或体克用；本盘开头泄体，须变用生体才翻 |
| 小过上六 春令 | 体死、克体二木当令，「凶，是谓灾眚」而判能过 | 维持。二木受兑金所制，按定稿第八节作气弱，仍按有生有克判。依据屋宅占「火虽无气，终是制金」「亦当有损失之忧」：制只减轻，不当作无克。凶辞翻转须克在变用，或体死而克体之卦有力，本盘不合，写成要过的坎 |
| 既济上六 冬令 | 体死、克体之水当令而判能过 | 维持，理同上；另有变用巽木相而生体，合《衰旺论》「体衰而有生体之卦，则衰稍解」 |
| 兑九二、六三、九五、上六 秋、土令 | 离火无气，得无气之木相生即作有力 | 维持。原书观梅占巽木囚、离火休，仍说「互中巽木，复三起离火，则克体之卦气盛」，生它的卦无气照样起作用（定稿第八节规则 1） |
| 涣初六 春、冬令 | 克体之兑得死土相生作有力 | 维持，理同上 |
| 艮上九 夏、土令 | 克体震木无气，得坎水生而作有力，致不合 R3↑ | 维持，理同上 |
| 巽上九 秋令 | 结论系于兑金被离火所制是否作无气 | 维持，按定稿第八节规则 2 |
| 鼎上九五月令「大吉，无不利」判过不了 | 最强吉辞配过不了 | 维持。本用泄体、两互金克体，无生体之卦；「无生有克之盘不因吉辞升」。原书《观物用易例》鼎变恒断「虽圆而今毁缺矣」，与此同向 |
| 革九四 春令「有孚改命，吉」 | 可否读作直接落在结果而翻 | 维持不翻：改命是行事之吉，非正说考过；与晋升同爻裁定一致 |
| 中孚九二「我有好爵」 | 好爵正对求名，可否作吉辞 | 维持：本句是取象，无吉凶断辞；且本盘无生体、本用克体，吉辞也不翻 |
| 艮六二「不拯其随」 | 王注与程朱两说 | 正文取程传、本义「腓随股」一说，未写书名，不算错引 |
