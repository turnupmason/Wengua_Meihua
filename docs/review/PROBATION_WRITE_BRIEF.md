## 转正场景怎么写

- 问的是「这次试用期能不能转正」。能转正写「这次能转正」「试用期能通过」「能转为正式员工」，不写加薪幅度。
- 场面只写试用期里真有的东西：试用期内交的活、带教与交接、考核表与评定标准、述职或答辩、上级评语、试用期满前的谈话、转正审批与通知、延长试用。
- 生扶只写这些东西，例如考核标准正对你做熟的活、交接下来的事正好补上一项硬指标。不写「贵人相助」，不写某人保你。
- 只断事，不断人：
  - 不写上级心理（看好你、嫌弃你），不写你的情绪性格，不写同批人数、名次；
  - 不写「被画饼」这类断定别人用意的话。
- **在任专条**：因盘中有克体之卦而判转不了的篇（`polish-v5` 的 `probationRule` 写着「在任专条」），正文要让读者看懂卡在哪一处，比如考核表上的一项硬指标、试用期限、编制、审批一环。只写这一次转不了正，不吓人，不写「被开除」「被追责」；延长试用可以写成可能的走向，但不许诺。计算说明「判断」行要写明依据：「《求名占》：若在任占卜，最忌见克体之卦。」
- **不出现他项用语**：考试、考场、考生、卷面、卷尾、卷首、全卷、试卷、卷子、阅卷、合格线、及格、分数、得分、扣分、丢分、拿分、保分、交卷、答卷、考题、放榜、过线、面试官、面试。检查脚本会拦。
  - 「考核合格」是人事考核等级，可以用。
- 转不了正的篇说得委婉，检查脚本认这些说法：
  - 转正的：这次还没转成、转正还差一步、还没转下来、这次没转成、转正这回没成、试用期这回没过、没能转正；
  - 通用的：还差一截、还差一口气、差了一口气、还欠一截、够不上、达不到、这回没成、这次没成。
  - 每篇自己组织，不要全卦一个说法。
  - 标题、简断、总断、无期说明里不用「转不了、转不成、不能转正、过不了、拿不下、输在、栽在、败在、坏在」。不安慰，不许诺下次。
- 不用含糊口气：偏难、倾向、多半、或许、未必、恐怕、有望、把握不大、可能性。

## 每篇要改的栏

1. **第 3–8 栏正文**：整篇重写，写法按上面。
2. **第 9 栏判断依据**：
   - 事实、引文、结论照旧；
   - 考试场景的字眼（卷面、答题、阅卷、考试等）改成转正场景，或改成不带场景的判断说明；
   - 因在任专条或转正专属爻辞改判的篇，要把这条依据写进去，原句照 `PROBATION_REJUDGE_20261118.md`；
   - 不出现「档、R 代号、有条件、存疑、待核、口径、原稿、改判、复核、盲断」。
3. **第 10 栏应期**：
   - 一般篇：每个窗口的种类、位置、依据（第 0、1、4 项）不动，事件（第 2 项）和提示（第 3 项）按转正重写，规则见第八节；
   - 合格结果类（name-support、name-body）只能用在能转正的篇，写转正通知怎样到来，每篇换一种说法；
   - `timingNeedsRework` 的篇：原来的结果类窗口已不成立，用 `{"i":n,"col":10,"set":[...]}` 整栏重选，或改成无期说明。
     - 改选时，种类必须与那一位置对原体的关系一致，例如 control 取克体那一处；第 4 项依据照这一盘写；
     - check-hex 会验；
   - 无期说明（字符串）重写成 30–60 字。
4. **计算说明**：
   - 「判断」「旺衰」两行的事实与引文不动，只把考试字眼改掉；
   - 「爻辞」一行按本篇转正场景重写落点，点出月令；同一爻五个月令的爻辞行不能一样；
   - 求名、古例等行保留。
5. **爻辞读法**：`review-v2` 的 `lineReading` 读一遍。自动替换后读不通的，用 `"col":"line"` 改顺，取义不变。
6. **通读记录**：每篇写 `{"i":n,"read":"读出了什么、怎么写的"}`。

## 写回

```bash
node scripts/review/agentfix.cjs workplace-probation <卦序> edits.json opusWrite
```

edits.json 的格式见 `scripts/review/agentfix.cjs` 文件头。col 取值：
- 3–9：正文各栏和判断依据，可用 set（整栏换）或 from/to（局部改）；
- 10：整个应期栏，只能 set；
- `t2:k` / `t3:k`：第 k 个应期窗口的事件 / 提示；
- `omit`：无期说明；
- `note:k`：第 k 行计算说明；
- `line`：爻辞读法；
- 另有 `{"i":n,"read":"……"}` 写通读记录。

临时文件放在你自己的草稿目录。
