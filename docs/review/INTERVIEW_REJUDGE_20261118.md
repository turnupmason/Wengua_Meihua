# 面试求职 `career.interview.interview-pass`：补判口径与回测（2026-11-18）

## 一、类型

能否类：问的是「这次面试能通过吗」，结论只判能过、过不了，不用「有条件」。现有 1,920 篇基础正文的结论码：不通过 1,465、附条件通过 428、其他「通过」细码 27。「偏难通过」一类的含糊判语全部要改。空亡版本按用户决定不用于断语（见 `wengua-entries-no-void`），只留档。

## 二、口径

照 [断语判断口径 V2 定稿](../READING_POLICY_V2.md) 第二节判定步骤和第十三节二分规则执行。第二节原文已写明适用于面试。原书依据与考试相同：
- 《求名占》「体克用，名可成，但成迟；用克体，名不可成；体生用，名不可就；用生体，名易成；体用比和，功名称意」；
- 《谒见占》「体克用，可见；用克体，不见；体生用，难见，见之而无益；用生体，可见，见之且有得；体用比和，欢然相见」。

两章取向一致。

### 爻辞

384 条动爻沿用考试问项逐条定下的读法（`sources/editorial/exam/review-v2` 的 `lineReading`）。考试里翻转的 12 条，在面试里取义相同，照搬：
- 乾初九「潜龙勿用」、颐六三「十年勿用」、井初六「井泥不食」：不被取用；
- 夬初九「往不胜」、夬上六「终有凶」、复上六「终有大败」、剥六四「剥床以肤，凶」、益上九「或击之」、渐九三「妇孕不育」、讼九二「不克讼」：所求落空；
- 明夷六二「用拯马壮，吉」、旅六五「终以誉命」：吉辞正对所问。

面试与考试不同的地方在于「见人」。凡讲相见、遇主、受命、宾客的爻都逐条重看：

| 爻 | 面试里的读法 | 结论 |
|---|---|---|
| 乾九二、九五、蹇上六「利见大人」 | 正对面试，但三处的盘都是无生有克或体弱 | 吉辞不升（第二步「无生有克之盘不因吉辞升」） |
| 观六四「利用宾于王」 | 本义「利于朝觐仕进」，正对 | 盘无生有克，不升 |
| 丰九四「遇其夷主，吉」、丰初九「遇其配主，往有尚」 | 遇主正对面试 | 九四生体之卦皆死（升判须一处旺相），初九无生有克，皆不升 |
| 师九二「王三锡命」 | 受命正对 | 无生有克，不升 |
| 睽九二「遇主于巷，无咎」 | 遇主正对，但无咎不是吉辞 | 不调 |
| 姤九二「包有鱼，无咎；不利宾」 | 问事人是「包有鱼」的一方，不利的是宾，不是问事人 | 不降，维持成 |
| 蛊六四「往见吝」、困初六「三岁不觌」 | 已判不成 | 同向 |
| 丰上六「阒其无人，三岁不觌」 | 小象「自藏也」，凶在自藏，与试用期同读 | 不降 |
| 屯六二「女子贞不字，十年乃字」 | 本义「守正不许妄求」，不字是自守，不是不被取 | 不降 |

所以面试 1,920 盘的结论与考试定稿逐盘相同：能过 639、过不了 1,281。

## 四、改动面

与现有结论不一致 797 盘：不通过改能过 365、附条件改能过 281、附条件改过不了 147、通过改过不了 4。其余 1,123 盘结论不变，但正文里「偏难通过」「通过偏难」一类含糊判语全部要改，所以 1,920 篇整体按考试定稿的写法重写。

## 五、做法

1. **搬到通用流程**：面试改用与考试相同的作者源格式 `sources/editorial/interview-pass/hex-NNN.json`，由 `build-promotion-pay.mjs` 构建，复用全部检查脚本。空亡版本只留档，不再构建进正文。
2. **逐卦重写**：
   - 结论、判断依据、计算说明里的「判断」「旺衰」两条，照考试同盘套用，事实一致，问法换成面试；
   - 「爻辞」一条与正文按面试场景重写，写法守考试定稿的各项要求：委婉判词、结构不成套、应期文字；
   - 面试场景写问答、举例、追问、岗位要求，不写面试官心理，不写录取人数。
3. **核对**：引文、盘面说法、判词、相似度全部为 0，再构建校验。

## 六、写作中报来的结论疑问与裁定

这些盘的结论与考试同盘相同，裁定后两问项一并维持。

| 盘 | 疑问 | 裁定 |
|---|---|---|
| 大有九二（秋、冬、四季）与九三（秋、四季） | 九二多一处比和的离反判过不了，九三没有比和之卦反判能过 | 维持。《体用衰旺之诀》「内外并[无]生体，虽体之卦党多，皆是衰卦，终不吉也」只说体党皆衰。九二变用离与体同气而无气，正合这句；九三全盘没有比和之卦，这句不适用，按《求名占》「体克用，名可成，但成迟」判成，体死者除外。口径第十三节第 4 点已写明 |
| 豫九四「由豫，大有得」 | 吉辞直落求取 | 维持过不了：本用克体而全盘无生体，按口径第二步「无生有克之盘不因吉辞升」，翻转又须本用不克体 |
| 大有上九「自天佑之，吉无不利」 | 全卦最吉之辞 | 维持过不了：本用离火克乾体，全盘无生体。「吉无不利」虽算无条件大吉，升判仍须至少一处生体之卦旺相；按口径「本用克体而全盘无生体的，一律为难」。先天起卦不以爻辞主断（口径第一节第 5 条） |
| 谦九三「劳谦君子，有终，吉」（四季） | 体旺、克体之震囚，是否临界 | 维持过不了：震木得坎水生，盘中无金克震，按第八节规则 1 作有力论（《屋宅之占诀》「火虽无气，终是制金」），不合 R3↑「克体之卦无气」的条件 |
| 蹇上六「往蹇，来硕，吉；利见大人」（四季） | 体艮土旺、变用巽木囚，似合升判条件「克体之卦不旺相而体旺相」 | 维持过不了：巽木得两处坎水生，盘中无金克巽，按第八节规则 1 作有力论；调整后的强弱代入升降条件，「克体之卦不旺相」不成立 |
| 颐六三「拂颐，贞凶，十年勿用，无攸利」（夏、秋、冬、四季判能过，春判过不了） | 读法说落在结果上，结论却多数能过 | 维持。五个月令同读：落在结果上。降判门槛是「有条件降为难，只在克已在变用，或体死而有克体之卦旺相时」。春令体死、克体之震旺，降为过不了；其余月令克只在本用，结局变用生体，《体用总诀》「用凶变吉者，先凶后吉」，不合降判门槛 |
| 大畜六四「童牛之牿，元吉」 | 大吉断辞对盘的分量 | 维持过不了：升判须至少一处生体之卦旺相，五个月令皆不具 |
| 咸六二「咸其腓，凶；居吉」、九三「咸其股，执其随，往吝」 | 凶、吝读作自身做法 | 维持能过：小象「顺不害也」「志在随人，所执下也」，都把凶吝归于行为，按口径第二步写进正文作提醒 |
| 小过上六「飞鸟离之，凶，是谓灾眚」（五个月令判能过） | 凶辞重，春令体死 | 维持。凶落在结果上，五个月令同读；降判须合三条之一（克在变用；体死而克体之卦有力；盘中无克体之卦）。克体之震、巽皆受兑金所制而无生，按第八节规则 2 作气弱论，三条皆不合；结局变用离火生体 |
| 未济六三「未济，征凶，利涉大川」（冬） | 体死、两处坎水旺克体 | 维持能过：R2↓「体死，有克体之卦旺，生体之卦都不旺相」，此盘生体之巽木相，不合；结局变用生体。征凶取冒进之戒，利涉大川同在本爻 |
| 观六四「观国之光，利用宾于王」 | 本义「利于朝觐仕进」，正对求职 | 维持过不了：本用克体而无生体，见第二节 |
| 剥六四、复上六 | 盘中无克体之卦，凶辞主断 | 维持过不了：口径第十三节第 3 步，盘中无克体之卦时，落在结果上的凶辞直接主断 |
| 鼎上九「鼎玉铉，大吉，无不利」 | 本卦最吉之辞，五个月令判过不了 | 维持：全盘无生体之卦，「无生有克之盘不因吉辞升」，同大有上九 |
| 旅六五「终以誉命」 | 正对所问，五个月令结论不一 | 维持：同爻同读，升判条件（生体之卦旺相、体不囚死、变用不克体）逐盘成立与否不同，只夏令成立 |
| 渐九三「妇孕不育，凶」 | 无克体之盘单凭爻辞判过不了 | 维持：口径第十三节第 3 步 |
