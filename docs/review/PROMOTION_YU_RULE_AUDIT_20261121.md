## 三、原五态与一层有效作用

原气仍按寅卯木旺、巳午火旺、申酉金旺、亥子水旺、辰未戌丑土旺的五态表保存。原体休不与囚死并为弱，也不升作旺相；作用节点处休则论作用偏轻。原气与作用力度分开，受生或受克不能改写原月令值。

| 位置 | 一层作用核对 | 本轮落实 |
|---|---|---|
| 初六体互坎 | 坤、艮制水，无金生水 | 有生而薄，不能删成无生；不递归以体木制土取消土对水的作用。 |
| 六二体互与变用两坎 | 两处水各受坤、艮制，各无金生 | 各处薄助，不将两份薄助相加定作强助；后生与中生的阶段不同。 |
| 六三体互坎 | 受本坤、互艮、变艮制，无金生 | 生助仍存而薄，三土用党多另判体势衰；春冬木原旺相仍保留。 |
| 九四本震 | 得坎生，无金制 | 五气原木态各存，有效克力均按有力；体土旺也不递归取消坎的生木。 |

| 上六变离 | 同时得震生、受坎制 | 取火原态：春相有力、夏旺有力、秋囚薄、冬死甚薄、四土月休轻。春夏生助不因受克便一概缩薄。 |
