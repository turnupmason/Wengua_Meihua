## 二、口吻要点

1. **开头**：首句明说结论，但不套「某月这段关系……」的模子。面试稿的开头多是「本轮不能通过。此卦首先提示……」「这一轮能通过，宜耐心讲清来由」「按卦象断，本轮不能通过」「这一轮不能通过，但卦中并不是一片衰弱」。确定关系照此：「这一回关系定不下来，……」「这段关系能确定下来，……」「按卦看，这一回还走不到确定关系……」，结论之后紧接本篇的要害（一句话点出胜负手），月令放到第二句或第二段去讲。同一卦 72 篇的开头要有变化，月份开头的不超过一成五。
2. **句子**：完整、平实、偏书面，主谓齐全，一句讲清一层意思，平均三十字上下。不用十字以内的口号短句、对仗警句（「站得稳比往前走要紧」「诚意不必加码」），不用「不追；不催；」式的分号排比，不用「就好」「就够了」收尾的轻飘话。
3. **建议**：用「宜……」「可……」「不必……」「应……」，并带上做法或理由，最好与本盘相连。例：「宜围绕实际要求组织经历，既把可靠的方法讲透，也核准它在哪些条件下成立」「较合此局体休、后助轻的特点」。不写「这个月先顾自己」「对方来，好好接；对方不来，不追」这类口头吩咐。
4. **卦理**：旺衰、生克用白话讲清，再落到所问的实事上：「兑体休，本用休兑比和，能够协调，不能当作强援，也不等于自身全无基础」。注疏照录原句，再说「可以从中取……的分寸」「不能因……就……」，讲清取舍与边界。
5. **时间指代**：讲本月用「卯月」「本月」「此月」或干脆不点，不用口语「这个月」；讲这一回用「这一回」「此局」「这一盘」。
6. **结尾**：落在这一盘给出的分寸与做法上，可以收在爻辞的警戒或吉意上；不安慰、不许诺、不预告换季（见 `consolation-scan.mjs`）。
7. 其余照旧：不编人物、心理、经过；不替对方断心意；不用他／她指对方；不写给作者看的话；引文照原典。

### 考试逐月稿的全文核读

先读同一动爻、同一气类的考试原断，再与乾至需、已定稿的讼卦及同卦面试稿对读。开篇要让来问的人知道这次能否过，紧接着说明这个月的把握或失分在何处。原断若说开卷受阻，宜讲清阻在哪里、平日的准备能应付哪一段，以及后面的帮助究竟能补多少。专业判断中的月势、爻义和取期，应能在这些话里找到着落。

考试稿只答来问者这一次能否通过。底稿里的题型、题序、分值、阅卷细则、考生的具体举动或成绩通知方式，都须回到卦上查它的来由。卦能说明初受制、中段有同气、末段仍须自身出力，正文就将这三层的轻重及其对能否通过的影响讲清。原断提到的试题情节也应删去。评估已有基础与当月助力时，照面试、确定关系示范稿的分寸说话。

每篇落盘后连读题名、简断、正文、应期和展开的卦理说明。尤其核对正文已经删掉的题情是否还藏在日期窗口、建议或取期理由中。审计逐月记明结论、月势、本互变如何相接、爻辞所能解释的范围，以及应期究竟指哪一段。标明未取日应的依据，过程受阻的参考日不得写成成绩公布日。

## 三、检查

`node scripts/review/style-monthly.mjs <问项目录> [--hex N] [--list]`，门槛按用户亲写面试稿 58 卦的实际分布定：
- 正文首句以「某月」开头全库 ≤ 15%（面试 12%），简断以「某月」开头全库 ≤ 10%（面试 4%）；面试单卦两极，故不按单卦卡，但写作时同一卦也要变化开头；
- 平均句长 28.5–34 汉字（面试 28.5–33.1；太长读着发沉），十字以内短句 ≤ 5.5%；
- 「就好／就够了／就行了／就是了」与「这个月」每卦各 ≤ 1；
- 「宜」每千句 55–220（面试最高 218；写作目标 100–180，交替用「可」「不必」「应」等）；
- 简断平均 ≥ 75 汉字；
- 写给作者的话（「这一面要如实写下／记下」「写进正文」等）为 0；替对方断心意的疑似句（「对方心里／觉得」「两边都提不起劲」等）逐条列出，人工判定后改掉。
用户自己的稿里也有「如实看」「不以……翻转结果」这类给读者讲道理的话，那是口吻的一部分，不算写给作者的话。
以上取面试稿各卦的最低一档，面试稿 58 卦过 57 卦（大有「宜」每千句 42 为例外）；这是底线，写作要以面试稿的中位（句长 31、短句 0.5%、宜 137‰、简断 88 字）为目标。
脚本只量口吻的外形，不代替通读；验收仍要抽读并与面试稿并排对照。
