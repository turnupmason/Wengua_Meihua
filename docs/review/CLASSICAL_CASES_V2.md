## 不合的四例说明了什么

1. **间接生克没算进去。** 观梅：用离克体，原书说「互中巽木，复三起离火，则克体之卦气盛」，巽生离使克体加重；变艮生体，所以「但被伤而不至凶危」。V2 只看各处对体的直接关系，把这盘算成「体旺克衰、末后生体」的吉。原书在田姓屋宅也用了同一路：「虽兑金克木，得有离火，火虽无气，终是制金」。《体用》篇（682 行）明写：「此卦生体，诸卦有克此卦者，彼灭其吉。此卦克体，诸卦又有克此卦者，稍解其穷。」项目现在不启用间接作用（`approvedIndirectRules` 为空），这是 V2 最大的一处漏洞。
2. **原书有时取变卦的互卦。** 问病否卦：二爻动原书说「互见巽、离」，这是变卦讼的互卦，不是本卦否的互卦（巽、艮）；五爻动「互变俱生体」也是按变卦晋的互卦算的。本馆一律取本卦互卦（卷一《互卦起例》：「以重卦去了初爻及第六爻……」）。同一书内两种取法并存，二爻、五爻两例的出入主要来自这里。
3. **问病与吉事分量不同。** 问病二爻原书断死，主因之一是变坎「泄体败金」。V2 对吉事把末段泄体定为有条件；对疾病、官讼这类问项，泄与克的分量应更重（原书《体用衰旺之诀》「问病必死，问讼必败」）。本馆目前的问项都是吉事，这一点暂不影响，但以后写疾病、诉讼类问项时必须另定。
4. **卦名卦象。** 枯枝坠地：九四「睽孤，遇元夫」本身不凶，原书靠「睽、损卦名，俱有伤残之义」断凶。V2 只在卦象与爻辞同向时才许降档，这一例说明原书有单凭卦名取象的用法。但这类用法高度依赖所占之物（枯枝、寺院），本馆问项是否适用要逐篇判断，不宜一概套用。
