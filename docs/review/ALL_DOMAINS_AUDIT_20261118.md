## 六、做法（一个领域一个领域）

每个领域按同一个顺序：
1. 确认类型。
2. 写定这一领域的口径：原书专章，例如《求名占》《婚姻占》《失物占》《人事占》，再加定稿通则。
3. 原书卦例回测和网上卦例回测，逐例分析对错原因。
4. 每卦一次补判。
5. 引文核对、盘面核对。
6. 构建、校验。

先做完一个，再做下一个。

建议顺序：面试求职 → 晋升加薪 → 能否转正 → 职场情况 → 跳槽去留 → 确定关系 → 复合 → 桃花缘分 → 暧昧表白 → 失物找回 → 宠物找回。
