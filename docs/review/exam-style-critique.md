结论：模板不只在个别词上，**整篇的骨架就是固定的**。开局写开头，过程写中段，结局先引爻辞再说一句「放到考场上」，总断先给结论再给一条做法。读者连看三篇就能背出第四篇的结构。

## 一、模板味（15 例）

1. **全库结局（例 1#0）**：「初九说龙还潜在水里……放到这场考试上，是你的本事还藏着」
   → 98% 的结局都用「某爻说」开头，再加一句「放到／放在／用在考场上」把话接回来。这是写作流程留下的接缝。
   → 爻辞可以放在段中，也可以放在段尾，不必句句先引。比如：「你的本事还没全拿出来，像初九讲的潜龙，还在水底下。」接回考场的那句不要写，直接说事。

2. **全库过程（例 12#28、16#24、39#21）**：「中段那类题本身不算硬」「中段是你发挥最好的阶段」「中段查难点有力气」
   → 九成过程段都以「中段／中间」开头。这是按互卦位置排出来的，读者看到的就是格子。
   → 从这一段真正发生的事起句：「写到第三、四道大题，原来那套办法开始不灵了。」位置信息让内容自己带出来。

3. **40#29 简断**：「外面几乎没有可借的帮助……开头就得先出一份力，中间自己核条件也不容易，末尾几项要求只能做到一部分」
   → 典型的三段式。开头、中间、末尾各占半句，像念清单，看不出哪一处最要紧。
   → 只说最要紧的一处：「你这次最吃亏的是底子薄，每道题都要从头想，写到最后几项就没时间了，过不了线。」

4. **64#2 简断**：「开场的题就很硬，中段又压来一关同样重的，偏偏你近来手上没劲……卷尾题量大」
   → 同样是开、中、尾三段，又带一句「你近来手上没劲」的套话。
   → 「前后两道硬题你都接不住，这次过不了。能做的是先抢那些单独给分的小问。」

5. **21#6 开局**：「开头有点帮助，分量不大，你本身就站得稳。」
   → 「有一点帮助，分量不大」就是计算说明「无气，有而不重」的直译，全库 201 篇这么写。
   → 说清是什么帮助，或者干脆不写：「前两题正是你练过的题型，可以先写。」

6. **47#7 简断＋结局**：「最后还有一点帮助，分量不重」「末段还有一点帮助，分量不大」
   → 同一篇里同一句话说了两遍，「帮助」也没说是什么。
   → 留一处，写成具体的事：「最后一道题给了现成的公式，照着套就行。」

7. **49#25 简断**：「中间还有一点帮助，分量不重，这场能过。」
   → 和第 5、6 例一模一样。
   → 「中间有道题和你做过的一道几乎一样，能省些时间。」

8. **31#5 / 56#18 / 59#9 / 30#7 / 53#28 总断**：「能过，只是慢些。」「能过，只是慢。」「能过，但会慢。」「能过，但慢。」「结果是过，只是慢。」
   → 五篇总断几乎是同一句。全库总断以「能过」起句的有 302 篇。
   → 总断要落在本篇自己的那个点上：「做得慢不要紧，那道证明题慢慢写，分够了。」

9. **1#0、14#21、29#1、31#5、33#25、34#12、52#13、64#2**：「人还没进入状态」「你眼下精力不足」「你眼下精力和熟练度都偏弱」「你最近精力也一般」「你精力又偏弱」「你眼下又没什么力气」「你近来手头又不宽裕」「偏偏你近来手上没劲」
   → 体卦衰弱被一律翻译成「你最近状态差」，全库 189 篇，而且是在替读者下判断（另见第四类）。
   → 改成可以核对的考试事实：「这类题你练得少，写起来要一步步想。」

10. **9#20 / 15#0 / 17#15 / 25#3 / 63#27**：「考前把证明的步骤多写几遍」「考前把同类题换着角度多练几遍」「考前把题目要求写明的那几类步骤练熟」「考前多练几道分量重的大题」「考前把常用方法的适用条件逐条核一遍」
    → 「考前把……练熟」出现 207 次，等于什么都没建议。
    → 一篇只给一条，而且要具体到这一盘：「把那种要你写证明过程的题，限时写三道。」

11. **12#28 / 20#4 / 24#0 / 33#25 / 44#29**：「为下一次攒底」「留作下次之前的功课」「留着底子下次用」
    → 过不了的篇有 146 篇用「下一次」收尾，听上去像在安慰人。
    → 写清这次还能做什么：「这次能保住的是前面三道大题，最后那块放弃不可惜。」

12. **19#18 标题**：「提示不多，题目却在你会的范围里」；**1#29 简断**：「题目在熟悉的范围里」；**1#0 简断**：「题目多是你练过的路子」
    → 「题目在……范围」「练过的路子」反复出现，占了好开头却不交代信息。
    → 删掉，或者换成具体的考法：「题型就是你做过的那几种。」

13. **13#22 / 13#23**：「先熬一段苦，后面能回到自己的节奏」「中段想起旧题，局面慢慢转过来」
    → 同爻的两个月令，标题都是「先苦后顺」的老套路。九五的「先号咷后笑」也被两篇用同一个意思解释了。
    → 同爻的不同月令要写出旺衰带来的差别：一篇写「苦在题多」，另一篇写「苦在一开始写不下去」。

14. **39#21 / 33#13 / 49#25 标题**：「有人援手，自己也接得住，这场有望过线」「中间偏累，写得完的题先写完」「写对了就收手，这场能过」
    → 277 个标题以「这场／这次……」收尾，还常常是两个分句再加一个结论，标题写成了一句简断。
    → 标题只抓一个画面或一句话：「有贵人，也得自己接」「写对就停笔」。

15. **2#29 总断**：「这一条这场就照做，能挽回多少算多少。」**53#29 总断**：「检查照原次序来，只补真正影响结果的理由，结果可期。」
    → 结尾的鼓励话是空的，「能挽回多少算多少」「结果可期」放进哪一篇都能用。
    → 删掉空话，只留动作和结论：「这次过得了。检查时只补那些会扣分的理由。」

## 二、结论含糊、前后矛盾（15 例）

1. **全库过不了的篇（例 1#0、40#29、34#12 总断）**：「这次难过。」「这次难过。」「难过。能拿分的那一步先写下」
   → 「难过」一词两义，单独成句时读者先想到的是「伤心」。全库 181 篇这样用。另外，过不了的 1,281 篇里有 754 篇，简断和总断都没有一句「过不了」这样的明话。
   → 至少一处要明说：「这次过不了。」「这一场考不过。」

2. **6#6 简断／总断**：「这次过线偏难」「结果偏难」
   → 结论已经定为不成，读者看到的却是「偏难」，像是还有一半机会。
   → 「这次过不了线。中段那道硬题拼不过，能保住的是会做的那部分。」

3. **50#26 简断／总断**：「所以结果不乐观」「能过的把握偏小」
   → 两处都在打擦边球，没有一句是定论。
   → 「这场过不了，开头写得太长，把后面的时间吃掉了。」

4. **56#11 / 60#8**：「这次过不了的可能大」「这场过不去的可能大」
   → 「可能大」本身就是在说概率（另见第四类），也不是定论。
   → 「这次过不了。」

5. **44#29 结局**：「这一场即便不过，你的阵脚还是稳的」
   → 「即便不过」把已定的「过不了」又说回假设，自相矛盾。
   → 「这一场过不了，但你停在站得住的地方，没把会的分丢掉。」

6. **14#21 / 46#5 / 45#18 简断**：「过关的把握偏小」「过关的希望很小」「过线的难度不小」
   → 用程度词代替结论。
   → 统一改成明话，程度放到卡点上：「这次过不了，卡在开头那道要写依据的题。」

7. **3#26 总断**（能过）：「卡住时换题，别干等，这场能过的可能不小。」
   → 已经判了能过，总断却说「可能不小」，反而让人起疑。
   → 「这场过得了。卡住就换题，别干等。」

8. **1#29 简断／总断**（能过）：「只补确实漏掉的地方，这场多半能过。」「结果偏向通过。」
   → 「只补……就」是条件句，再加上「多半」「偏向」，又回到了已经废掉的「有条件」口径。
   → 「这场能过。收尾有时间，只补漏的地方，写对的别动。」

9. **53#29 总断**（能过）：「检查照原次序来，只补真正影响结果的理由，结果可期。」
   → 结论放在最后，而且是「可期」。
   → 「能过。检查照原来的次序，只补会扣分的理由。」

10. **35#19 / 47#7 / 43#22**（能过）：「这一场多半能过」「这场多半能过」「过线在望」「结果偏好」
    → 能过的篇也在含糊。全库有 64 篇简断、111 篇总断只用「有望／多半／可期／偏好」，没有一句「能过」。
    → 「能过」两个字要出现，轻重写在后面：「能过，而且不吃力。」

11. **34#0 简断**（过不了）：「你精力足，题目压过来的分量也不重，只是从头到尾没人能帮你一把，每一分都得自己挣，这次过线难。」
    → 前两句全是好消息，败因又是考试里本来就没有的「外援」，读者会认定这篇写错了。
    → 「这次过不了，坏在起步抢快：第一个条件没看全就往下写，后面补不回来。」

12. **16#24 简断＋过程**（过不了）：「你的底子相当扎实，开头的约束扛得住，中段的题大多也能处理」「中段是你发挥最好的阶段」
    → 五分之四的篇幅在写顺，败因只有一句含糊的「收尾还有几处要返工」，读起来像一篇能过的稿。
    → 卡点放在第一句，写具体：「这次过不了，最后那道大题要从头重写，时间不够。」

13. **48#18 简断**（过不了）：「开头就有扎实的帮助……中间那道检查压力也不大……收尾还有一道限制，力度不大，偏偏落在最后」
    → 败因是一道「力度不大」的限制，读者不会信。计算说明里是「克在变卦」，正文没有把这一点写成分量。
    → 「这次过不了：最后一道题有个硬条件，你改过的答法还是没满足它，这一处就丢了线。」

14. **57#25 / 62#25 / 49#25**（能过）：「真正的坎在你自己……证据够了就写上卷面」「前面守住了边界，就接得住它」「该收手时就收手……结果会是好的」
    → 能过的篇写成了「做到 X 才能过」，读者会以为是有条件的。
    → 先把话说死，再提醒：「能过。要提防的只是写到最后不敢下结论，证据够了就写。」

15. **2#29 简断**（过不了）：「风险在于一种做法明明能用，你还想把另一种也证明完……这场难过。」
    → 把结局写成「风险」，像是避开就能过，和结论的方向冲突。
    → 「这场过不了。毛病出在一道题上想把两种做法都写完，后半卷没时间了。」

## 三、不通顺、病句、错字、搭配不当、生硬书面腔（15 例）

1. **52#13 简断**：「你近来手头又不宽裕」
   → 「手头不宽裕」是缺钱的意思，用错了。
   → 「这类题你近来练得少。」

2. **50#26 标题**：「开头花销大，收尾只能稳住一部分」
   → 「花销」指花钱，和时间搭不上。
   → 「开头写得太长，后面来不及」。

3. **29#1 简断**：「中间辨认题意会绊一下，这一下本身不高」
   → 「一下」不能说「高」。
   → 「中间有道题的问法容易看错，这道坎不高。」

4. **5#22 过程**：「中段那一问要求虽严，力度不大」
   → 「严」和「力度不大」互相抵消，读者不知道到底难不难。
   → 「中段那一问抠理由抠得严，不过你写得出。」

5. **5#9 简断**：「有人能把常见题给你讲一讲，从起步到中段都有，分量不重，你自己也会觉得吃力。」
   → 「分量不重」到「你也吃力」之间缺了因果，「从起步到中段都有」是硬塞进来的位置信息。
   → 「常见题你听人讲过，自己写还生，所以会慢。」

6. **18#26 过程**：「首尾那些实打实的要求都会压到这里来」
   → 首尾的要求怎么会压到中段？逻辑不通。
   → 「中段要你在两种答法里挑一种，这一挑最难。」

7. **18#26 简断**：「如果你拿手的是某一种问法，就去做一道条件变过的题，看看长处还用不用得上。」
   → 不知道这是考场上做还是考前做，「某一种问法」也是空的。
   → 「考前专门找条件换过的题来做。」

8. **39#21 过程**：「中段查难点有力气」
   → 「查难点」搭配别扭，「有力气」是计算说明里「体有力」的直译。
   → 「中段的难题你找得到下手处。」

9. **4#14 简断**：「题干的材料一直替它们加分量」
   → 拟人生硬，读者看不懂「它们」指什么。
   → 「题干材料多，那两处要求比看上去难。」

10. **48#18 结局**：「修补只是免错，离被取用还差一步」
    → 书面腔，「被取用」在考试里没有对应的意思。
    → 「井壁修好了，水还没打上来：错是改了，分还差一点。」

11. **54#26 开局**：「起头的几题能照着熟悉的格式写，进度慢。」
    → 「能照着写」和「进度慢」之间缺转折，读着像两句拼起来的。
    → 「前几题有熟悉的格式可照搬，就是写得慢。」

12. **62#8 开局**：「起手能处理具体的难处，从平日最熟练的问法开始较稳。」
    → 「起手能处理具体的难处」是公文腔。
    → 「前面几题难不住你，先挑最熟的写。」

13. **18#26 结局**：「所守的东西自有可取之处，只是和眼下要的结果着眼点不同」
    → 书面腔，像注疏的翻译。
    → 「上九说不去侍奉王侯。你下的功夫有用，只是没下在这次要考的地方。」

14. **17#15 结局**：「九四说随有获，贞凶；有孚在道，以明，何咎。」
    → 把经文原样塞进「说」字后面，没有翻成白话，普通读者读不懂。
    → 「九四说，跟着别人捞到的好处，守着不放反而凶；心里诚、走正路，就没有过错。」

15. **46#5 过程**：「下笔得多费些工夫，好在耗得有限。」**63#27 过程**：「旧步骤只能维持一部分」
    → 「耗得有限」「维持一部分」都是计算说明（「泄轻」「比和薄」）的直译，口语里没人这么说。
    → 「写起来费点事，不至于拖垮你。」「平时那套步骤只能用到一半。」

## 四、编造或越界（14 例）

1. **9#20 结局**：「后段会有人愿意和你一起对答案，帮得不多，却正好补上你最缺的那一步」
   → 考场上和别人对答案就是作弊，「富以其邻」的解释越界了。
   → 「后面有道题和前面的题互相印证，对上了，就补上你最缺的那一步。」

2. **15#0 简断＋结局**：「后面会有实在的提示接上来，把不会的地方老实标出、问清」「后面会有一份分量不轻的说明或提示送到手上」
   → 考场上没人可问，也不会有人送提示，这是编出来的人物和事件。
   → 「谦谦君子」可以写成「老实承认哪题不会，先放下」；生体可以写成「后面的题给了能反推前面的条件」。

3. **5#9 简断**：「有人能把常见题给你讲一讲」；**11#19 标题／开局**：「有人真心帮」「起步能拿到一些支持」；**39#21 标题**：「有人援手」
   → 无端编出了一个帮手。读者会问：是谁？考场上哪来的？
   → 生体改写成考试里真有的东西：题目给的提示、熟悉的题型、做过的原题、自己的笔记。

4. **34#0 / 33#25 / 40#29 / 52#13 / 62#8**：「没人能帮你一把，每一分都得自己挣」「卡在没有外援」「外面几乎没有可借的帮助」「没有助力可借」「又没有谁拉你一把」
   → 把「无生体」写成「没人帮」，又当成过不了的理由，这有违常识：考试本来就没人帮。全库 168 篇。
   → 「无生体」在考试里应该写成「卷子上没有一道题是送分题」「没有可以套用的现成办法」。

5. **13#23 简断**：「人也提不起劲，甚至有点想放弃」
   → 编造心理。
   → 「前几题写得不顺。」

6. **10#14 简断**：「你很可能高估了自己在这一块的把握」
   → 替读者揣测心理。
   → 「这类题容易看漏条件，下结论前把条件再对一遍。」不写读者心里怎么想。

7. **3#26 结局**：「这种卡住的感觉多半来自心里着急」
   → 心理推断，还带「多半」。
   → 「卡住的时候先换题。」

8. **22#26 结局**：「你最擅长的反而是把话说朴素」
   → 凭空给读者安了一个特长，而且和本篇的败因「铺得太开」矛盾。
   → 「白贲讲朴素。这场就该写得朴素，别铺开。」

9. **56#11 / 60#8**：「这次过不了的可能大」「过不去的可能大」；**3#26**：「能过的可能不小」
   → 用口语说出了一个概率，规范禁止这样写。
   → 直接下结论。

10. **33#13 结局**：「考试分量不算大，这份吉落得下来」
    → 替读者判定「这场考试是小事」，是借「不可大事也」越界解经。读者如果是在考公、考研，会觉得被冒犯。
    → 「九三说牵挂多、累，但料理身边的小事吉。一题一题做完，就是这份吉。」

11. **50#26 结局**：「鼎有玉铉，大吉无不利，前提是这只鼎拎得起来」
    → 爻辞没有这个前提，是为了配合「过不了」硬加的条件，曲解了经文。
    → 照实说：「上九本是大吉之辞，可这一盘没有生扶，大吉落不到分数上。你能做到的是收尾不出乱子。」

12. **40#29 结局**：「这份收获要靠真的射中，而你这次力气不足，弓拉不满」
    → 爻辞原文「获之」，说的就是射中了，正文却反过来讲。
    → 「解卦上六说射中了高墙上的鹰隼。这是吉辞，但这一盘体弱，又没有一处生扶，吉落不下来。」

13. **41#23 结局**：「六五讲收到一份推不掉的厚益……这次的益处来得不算多」
    → 先讲「厚益」，马上又说「不多」，读者会觉得爻辞被拿来随意拉扯。
    → 「六五说福气是从上面来的。这一场的帮手不厚，但方向对。」读者自然能明白厚薄是两回事。

14. **16#24 简断**：「考前想好哪些题只检查、不重写」
    → 考前还不知道卷子上有什么题，建议做不到。
    → 「考场上给自己定一条：写完的题只检查，不重写。」

## 五、计算说明问题（12 例）

1. **全库**：每篇第一行都以「定档：」开头，53% 的篇里有「不调档／不升档／降档／翻档」。
   → 「档」是内部分级用语，读者不知道有哪几档。
   → 第一行改叫「判断：」；「不调档」改成「不改结论」或「不影响能不能过」。

2. **17#15 / 12#21**：「《体用衰旺之诀》「体卦乘旺，虽有他卦克之，亦无大害」」
   → 原文是「凡体卦宜乘旺……此得令之卦，乘旺之气，虽有他卦克之，亦无大害」，「体卦乘旺」四个字原书里没有，这两篇还没加省略号。全库另有 92 篇写成「体卦乘旺……」，同样不是原文。
   → 改引「体卦之气……乘旺之气，虽有他卦克之，亦无大害」，或者干脆引「凡体卦宜乘旺」。

3. **11#19 / 19#18 / 30#0 等（全库 193 篇）**：「《体用》「诸卦有克此卦者，彼灭其吉」」
   → 篇名本身不错（原书第 681 行【体用】），但和《体用总诀》《体用互变之诀》《体用衰旺之诀》放在一起，读者会以为篇名被截短了。43#22 又用了《体用总诀》。
   → 统一写《梅花易数·体用》，第一次出现时就点明「《体用》一篇」。

4. **全库篇名前缀不统一**：7#0、14#21 写《梅花易数·占卦诀》，3#26、5#9 写《占卦诀》；14#21 写《梅花易数·衰旺论》，6#6 写《衰旺论》。
   → 同一本书前后写法不同，像出自不同人之手。
   → 全篇第一次引用时写「《梅花易数·××》」，后面只写篇名；或者一律不写书名。

5. **3#26（全库 15 篇）**：「特别：本馆以年月日时起卦，属先天」
   → 「本馆」是内部自称，读者不知所指，「特别：」也不是规定的行首。
   → 「起卦：本卦以年月日时起，属先天卦……」

6. **8#23（全库 13 篇）**：「说明：此句上传本作「内外并也生体」，据订正本读作「内外并无生体」」
   → 「上传本」是过程用语。
   → 「说明：此句通行本作「内外并也生体」，文义不通，据订正本读作「内外并无生体」。」

7. **63#27**：「上六「濡其首，厉」（底本作「濡其道」）」
   → 「底本」指哪个本子没说，「濡其道」也不是通行异文，读者会怀疑引文出错。
   → 删掉括号；确实要保留的话，写明是哪一本。

8. **30#7 / 40#29（全库 29 篇）**：「故不列日期」「缺可单独定位的日子，不列日期」
   → 应期是不是列出属于另一栏的事，写在计算说明里像工作备注。
   → 删掉，或者移到应期栏，用读者的话说：「这一盘没有能单独定日子的事。」

9. **18#26**：「《复明时令之应》「克体卦气，则宜乘衰」此盘用不上」
   → 引了一句又说用不上，徒增噪音。
   → 删掉。

10. **27#26 / 43#22**：「全盘无生无克」，而同一行又写「俱为体震所克」「变用震木为体所克」
    → 「无生无克」本意是没有生体、克体的卦，可读者看到的是「有克」，以为前后矛盾。
    → 写成「无生体、无克体之卦，只有体克用」。

11. **33#13**：「吉限小事，一场考试属小事，吉辞落得下」
    → 计算说明替读者把考试定成小事，和第四类第 10 例同一个问题。
    → 「象曰『不可大事也』，吉在逐件料理，与本盘无克体同向。」

12. **50#26**：「鼎之恒即《梅花易数》覆物占玉绦环一例」
    → 原书出处是【观物用易例】里「以钟覆物」一条，「覆物占」不是篇名。拿猜物的例子来论考试，也太远。
    → 写《观物用易例》，并说明只是借「虽圆而毁」看吉辞下面还有缺口。不然就删掉。

附带一条风险：定稿数组第 [9] 栏（例 2#29「R1b」、9#20「第十三节」、6#6「688 行」、13#22「口径②」）全是内部代号和行号。按 POLISH_BRIEF 的约定，它已经被 `calculationNotes` 替换，不在界面显示，但要确认构建产物和接口都不带出这一栏。

## 六、其他老师傅不会这样写的地方（10 例）

1. **全库三段式解卦**：开局写本用，过程写互卦，结局写变卦，每一段都要报一次「帮助多少、阻力多少」。
   → 老师傅只讲决定胜负的那一处，其余一笔带过。80 篇里有一半，关键点被平均分给了三段。
   → 每篇先找出唯一的胜负手（最重的克，或最实的生），给它整段篇幅，另外两段各一句。

2. **6#6 / 12#28 / 24#0**：过不了的篇也要写「后段会有些帮助，能补回一部分」「后段你会松一口气」
   → 计算结果是有生，就照写有生，结果是过不了的篇读来又像还有希望。
   → 帮助如果改变不了结论，就并到「能保住的分」里写，不单独当一层喜讯。

3. **26#17 结局**：「六四说给小牛先套横木，防在未壮之时，所以大吉……这一场的合格线够不着」
   → 刚说完「大吉」就转成过不了，中间没有过渡，读者会愣住。
   → 先把「吉辞为什么落不下来」用一句白话讲清楚：「爻辞是吉的，但这一盘最后一处克得重，吉只能保住前面的分。」

4. **29#28 结局**：「多年不必当真去算日子，它说的是困住的状态很顽固。」
   → 这一句写得好，是全样本里少有的老师傅口气。其余篇很少替读者先挡掉误解。
   → 推广这种写法：凡是爻辞带「三岁」「十年」「泣血」这类吓人的字眼，都先说一句它在考试里指什么、不指什么。

5. **60#8 总断**：「若已经考完，这份习惯留到下一次」
   → 一篇里同时照顾考前和考后的读者，暴露出文稿不知道读者站在哪个时间点。
   → 统一按「考试还没考」来写，考后的读者自己会明白。

6. **36#24 开局**：「长题会让你不知不觉写超时，越写越舍不得停」
   → 写读者「舍不得停」，是心理描写。
   → 「长题容易写超时，给它定个停笔的时间。」

7. **23#26 总断**：「这次通不过，差得不多。下一场……你的底子撑得起。」
   → 结论是对的，但「差得不多」加「底子撑得起」是在安慰人，老师傅给断语不哄人。
   → 「这次通不过。分丢在讲理由的小题上，这类题下次当正题来练。」

8. **55#21 过程**：「题意里有可以承接的内容，具体难处大多能当场解决。」
   → 一句话里没有一个实词，换到任何一篇都能用。
   → 「题目给的条件够用，难的那道照着条件一步步推就出来了。」

9. **45#4 结局**：「初六说诚意没能贯彻到底时，人心会乱，可一握手又笑了」
   → 爻辞讲得好，但「中途看到两份材料说法不一」是凭空设想的考场情节。
   → 情节要从卦象出来（萃卦，众多材料聚在一起），并且点明这是一种可能，不说成一定会发生。

10. **全库「你」字开头的断言**：「你准备足」「你底子厚」「你精力足」「你心里有底」
    → 老师傅只断卦，不断人。读者自己知道准备得怎么样，被说中了不稀奇，说错了就失去信任。
    → 把「你怎样」改成「这一卦里你这一方怎样」，或者写成「这场考的恰好是你练得多的东西」。

## 总评

### 最突出的 5 个问题

1. **骨架完全固定。** 开局、中段、结局加爻辞引子，总断再给一条做法，九成以上的篇照这个格式填空。这是模板味的根源，单换几个词去不掉。
2. **「生体／无生体」被翻译成「有人帮／没人帮」。** 在考试里，这既是编造（帮手、提示、对答案），也有违常识（考试本来就没人帮），还常被当成过不了的唯一理由（全库 168 篇）。
3. **过不了的结论说不出口。** 59% 的过不了篇，从头到尾没有一句「过不了」，靠「难过」「偏难」「可能大」打擦边球。「难过」在中文里还有伤心的意思。能过的篇也有不少用「有望／多半／可期」，或者写成「只要……就」，把已经废掉的「有条件」又带了回来。
4. **计算说明里的旺衰词被直译进正文。** 「分量不重」「有而不重」「压得住」「力度不大」「耗得有限」「你眼下精力不足」，读者读到的是参数，不是考场上的事。
5. **为了配合结论去拧爻辞。** 鼎上九加上「前提是拎得起来」，解上六把「获之」读成「没射中」，遯九三说考试是小事，中孚、比卦的「有人」变成作弊对答案。吉辞配过不了时，没有老老实实交代「辞吉而盘不吉」。

### 给改写者的 10 条写法准则

1. **一篇只写一个胜负手。** 从盘里挑出最重的那一处，生或克都可以，用整段写透，其余位置合起来不超过两句。
   - 反：「开头有点帮助，中段有一道关，收尾也要花力气，这场能过。」
   - 正：「这场能过，难只难在那道要你写全理由的大题。别的题你照常写，时间留给它。」

2. **过不了的篇，简断第一句或第二句必须出现「过不了／考不过／不够线」这类明话；能过的篇必须出现「能过」。** 全文禁用单独的「难过。」，「偏难」「多半」「可能大」「有望」「可期」不能代替结论。
   - 反：「这次难过。」「结果偏难。」「这场过不去的可能大。」
   - 正：「这次考不过。」「这一场够不上线，差在最后那一大题。」

3. **能过的篇不写条件句。** 「只要……就能过」「守住……结果会是好的」一律改成先下结论，再加提醒。
   - 反：「该收手时就收手，守住已经写对的答案，结果会是好的。」
   - 正：「能过，而且不难。唯一要提防的，是写完了还想改。」

4. **能过的篇必须分清轻重，用一句话写明是哪种过法。** 轻松过的写「不费事」；吃力过的写清功夫下在哪一类题、哪一步，并且只写一处。
   - 反：「能过，但要下功夫。考前多练，考场上稳住。」
   - 正：「能过，但要磨。磨在中间那道材料题：先把材料分类，再动笔。」

5. **过不了的篇写清两件事：卡在哪一处，这一场还能保住什么。** 「下一次」最多出现一次，不能拿它收尾。
   - 反：「这次难过线。考前多练，为下一次攒底。」
   - 正：「这次过不了。卡在开头那道要写依据的题；前面三道你会，先写满，这部分分保得住。」

6. **生扶只写考场上真有的东西，不写人。** 可以写：题目给的条件、做过的原题、熟悉的题型、前后题互相印证、自己记得的公式。不可以写：有人讲、有人帮、有人对答案、送来的提示。「无生体」不写成「没人帮」。
   - 反：「后段会有人愿意和你一起对答案。」
   - 正：「最后一题给的条件能倒推回前面那一步，看出来了，就补上了。」

7. **不断人，只断事。** 不写「你这阵子状态差」「你精力足」「你心里着急」「你很可能高估了自己」，改写成考题本身的难易和题型对不对路。
   - 反：「你近来手上没劲，熟悉的写法只撑得住一小段。」
   - 正：「这套卷子偏向你练得少的那类题，熟悉的写法只用得上前两题。」

8. **爻辞照实讲，吉凶和盘面不一致时直说。** 不给爻辞加原文没有的前提。吉辞配过不了时，写「这句本是吉辞，但这一盘……所以吉只落在……」。
   - 反：「鼎有玉铉，大吉无不利，前提是这只鼎拎得起来。」
   - 正：「上九本是大吉之辞。可这一盘开头耗得太重，吉只落在收尾不出乱子，补不回总分。」

9. **打散固定开头。** 结局不要用「某爻说」起句；过程不要用「中段」起句；开局不要用「开头／开场」起句；简断不要用「这一场」起句；也不用「放到考场上」来接话。
   - 反：「九五说先号啕后欢笑。放到这场考试上，是前面苦后面顺。」
   - 正：「前面几道写得想哭，后面却越写越顺，同人九五『先号咷而后笑』说的就是这个。」

10. **计算说明写给懂一点易的读者看。** 不出现「档」「本馆」「上传本」「底本」「不列日期」这类词；引文和原书逐字核对，篇名统一；「无生无克」要写成「无生体、无克体之卦」。
    - 反：「定档：……判成。爻辞：……不调档。」「《体用衰旺之诀》「体卦乘旺，虽有他卦克之，亦无大害」」
    - 正：「判断：……定为能过。爻辞：……与盘面同向，不改结论。」「《梅花易数·体用衰旺之诀》「凡体卦宜乘旺……虽有他卦克之，亦无大害」」
