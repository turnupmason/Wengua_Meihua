# 晋升加薪 `career.promotion-pay.promotion`：补判口径与回测（2026-11-18）

## 一、类型

能否类：问的是「这次能晋升并随岗加薪吗」，结论只判能升、升不了。升职落实即随岗加薪，加薪不单独判，能升的篇另写随岗薪资说明。

旧版（promotion-pay-1.0.2）只有两档，但没按定稿口径补判，正文满是「偏难」。旧稿与旧应期表 `timing.json` 移到 `sources/editorial/promotion-pay/legacy-v1/` 留档。

## 二、口径

1. **通则：** 照[断语判断口径 V2 定稿](../READING_POLICY_V2.md)第二节判定步骤与第十三节二分。原书依据与考试相同：
   - 《求名占》「体克用，名可成，但成迟；用克体，名不可成；体生用，名不可就；用生体，名易成；体用比和，功名称意」；
   - 每盘先取考试同盘定稿结论。
2. **在任专条（用户 2026-11-18 定）：** 《求名占》「若在任占卜，最忌见克体之卦，如卦有克体者，即居官见祸，轻则上司责罚，重则削官退居」（梅花易数 553 行）。
   - 问晋升的人在职，盘中本用、体互、用互、变用任一处直接克体，即判本次升不了。
   - 有生有克的盘不再按结局拆为能升。
   - 旧政策曾把这一条归为「另一所问」，现改。
3. **晋升专属爻辞：** 384 条爻沿用考试逐条读法。考试翻转的 12 条照搬，例如乾初九「潜龙勿用」口径原文就举晋升为例；旅六五「终以誉命」正对任命。另按晋升逐条重看相见、受命、王事、大小事一类：

## 三、结论
