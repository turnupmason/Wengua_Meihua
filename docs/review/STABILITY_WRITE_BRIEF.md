## 职场情况怎么写

- 问的是「眼下这份工作稳不稳，会不会被裁」。三档都要明说：
  - **稳**：简断前两句和总断写明能稳住，如「这份工作稳得住」「位置坐得稳」「保得住」「不在裁员之列」；
  - **有隐患**：写明「有隐患」「有变数」「有一处松动」「不算稳」，同时说清隐患在哪、眼下还能做下去；
  - **风险大**：写明「风险大」「风险不小」「位置不稳」「难保」。
- 风险大也不吓人：
  - 不写「一定被裁」「被开除」「失业」「丢饭碗」；
  - 写卡在哪一处、这阵子要盯的是什么。
- 检查脚本按 `scripts/review/state-vocab.mjs` 认判词。每篇自己组织句子，不要全卦一个说法。
- 不用含糊口气：偏难、倾向、多半、或许、未必、恐怕、有望、把握不大、可能性、说不准、难说、看运气。
- 场面只写职场里真有的东西：
  - 手上的职责与交付、部门调整与编制、业务收缩或扩张；
  - 汇报线变动、考核与绩效、合同与续签、调岗、交接；
  - 降本、裁员名单、人事通知。
- 生扶只写这些东西，例如手上的活正是部门留着的核心业务、新接的项目让你的位置更实；不写「贵人相助」，不写某人保你。
- 只断事，不断人：
  - 不写上级心理（看重你、想挤走你）；
  - 不写你的情绪性格；
  - 不写同事人数、名次；
  - 不写「被画饼」这类断定别人用意的话。
- **在任条**：
  - 盘中有克体之卦的篇（`stabilityRule` 写着「在任见克体」或本盘有克体），正文要让读者看懂压力来自哪一处，例如编制收紧、汇报线变化、一项考核硬指标、业务线调整。
  - 有隐患的篇写成轻的一面（挨批评、被调整、被约谈一类），风险大的篇写成重的一面（岗位存续本身受威胁）。
  - 计算说明「判断」行写明依据：「《求名占》：若在任占卜，最忌见克体之卦。」
- **不出现他项用语**：考试、考场、卷面、试卷、阅卷、合格线、分数、面试、转正、试用期、晋升、升职、职级、能过、过不了。检查脚本会拦，判断依据、计算说明、爻辞读法也拦。

## 每篇要改的栏

1. **第 3–8 栏正文**：整篇重写，写法按上面。
2. **第 9 栏判断依据**：
   - 事实、引文照旧；
   - 考试的结论句（「定为能过」「定为不成」之类）改成本篇三档：「定为稳」「定为有隐患」「定为风险大」，写明由来，依据见 `stabilityRule` 与 `STABILITY_REJUDGE_20261119.md` 第二节；
   - 因在任条或职场专属爻辞定档的，把那条原文写进去；
   - 不出现「档、R 代号、有条件、存疑、待核、口径、原稿、改判、复核、盲断」。
3. **第 10 栏应期**：
   - 每个窗口的种类、位置、依据（第 0、1、4 项）不动，事件（第 2 项）和提示（第 3 项）按本篇结论与职场场面重写，规则见 READ_THROUGH_BRIEF 第八节；
   - 只用扶助、受制、耗费、比和四类事件，不写结果日、裁员日；
   - 无期说明（字符串）重写成 30–60 字，不用「日级、节点、生体、克体、依据不足」。
4. **计算说明**：
   - 「判断」行：事实与引文不动，结论改成本篇三档，并写明理由（在任条轻重、生体可救、体乘旺、爻辞降档等）；
   - 「旺衰」行：事实与引文不动，考试字眼改掉，结论措辞配合本篇三档；
   - 「爻辞」行按职场场景重写落点，点出月令。同一爻五个月令的爻辞行不能一样。
5. **爻辞读法**：`review-v2` 的 `lineReading` 现在是考试读法，用 `"col":"line"` 改成职场读法：
   - 爻辞原文、小象、注疏原句保留；
   - 只改落点：凶吝是落在职位存续上，还是落在自身做法上，按 `STABILITY_REJUDGE` 第二节的表；
   - 表里没列的爻，按同样的标准判断，拿不准就报。
6. **通读记录**：每篇写 `{"i":n,"read":"读出了什么、怎么写的"}`。

## 写回

```bash
node scripts/review/agentfix.cjs workplace-stability <卦序> edits.json opusWrite
```

edits.json 的格式见 `scripts/review/agentfix.cjs` 文件头。col 取值：
- 3–9：正文各栏和判断依据，可用 set（整栏换）或 from/to（局部改）；
- 10：整个应期栏，只能 set；
- `t2:k` / `t3:k`：第 k 个应期窗口的事件 / 提示；
- `omit`：无期说明；
- `note:k`：第 k 行计算说明；
- `line`：爻辞读法；
- 另有 `{"i":n,"read":"……"}` 写通读记录。

临时文件放在你自己的草稿目录。
