# 山泽损六五｜财富财运十二月规则审计

本山泽损（41），互地雷复（24），变风泽中孚（61）。上艮动，静下兑金为原体。本上艮土、用互上坤土分别直接生兑；体互下震木和尾上巽木分别受原兑克制为财。无直接克体或原体生泄。同气两土和两木各自合槽，现实同资源或同笔客户报酬不双计。受体克而难掌控不等于克体或破财，也不作贵人助益。

## 六维及古据
- 《梅花易数》437–438、441、445、449–451、459：原兑西方沟通服务、饮食货品交易、金属器具，依旧有技能和客户需求、工作量及报酬办理。
- 405–408、411、418–420、428、502：本艮东北山林田土、场地、土石材料及固定服务，直接生兑为前段资源方向。252–253、256、259–260、265–266、275、497：用互坤西南乡里田土、实物仓储，直接生兑为中段资源。春死冬囚生薄，夏相是真助但原兑承接薄，季土旺真助，秋休普通资源条件；同一给付不重复计。
- 283–285、287、294、299、306、555–557：体互震东方经营活动、竹木茶货及材料供应，受原兑克制为中段主动财。315–319、327–328、337、555–557：尾巽东南工艺、木竹茶货及商贸服务，受原兑克制为末段财。季土、秋体力较足，问期内寅卯日参有关现实可控财，换月重新核，不保证真实交易；春夏冬财难制，按照实际工作能力维持已有财。两处财同笔则不双计。
- 493–495、555–557、795–804：四直关系及求财旺衰，无来克体或己生泄，不另编破财情境。既定任务费用照实核、确认给付，收入扣成本、留日常及工作周转，有余再积存。
- 655、968、658、965：月日环境与方应。每月申酉金旺准备和办理已有财，春冬另辰未戌丑土旺金相准备；有真实生助候的月份不重复土准备。
- 《周易正义》04損58–61：六五或益之，十朋之龟，弗克违，元吉，古义自抑损而有人来益、众才得用；借现实依真实提供的资源协作，不以吉辞保证到账。
