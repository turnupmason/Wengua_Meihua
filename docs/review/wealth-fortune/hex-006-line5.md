# 天水讼九五：十二月求财规则审计

本天水讼→互风火家人→变火水未济。静下坎水，本用乾金直接生坎，体互离火及变用离火分别受坎克，另用互巽木直接受坎生。始助、中财中耗、末财；均对原体直接判断，无比和也无来克。梅花493–495、555–557、795–804。周易正义02訟50–53 九五“讼元吉，以中正也”，疏重中正断枉直；只借对应现实收款和工作责任的公平核实，不把爻吉作进账保证。
