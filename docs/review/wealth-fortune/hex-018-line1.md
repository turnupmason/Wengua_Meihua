# 山风蛊初六：十二月求财规则审计

本山风蛊→互雷泽归妹→变山天大畜（26）。静上艮土；本下巽木及体互上震木分别直克原艮；用互下兑金及变下乾金分别受原艮所生，都是直接耗项。无生体、比和或体克用，自身原有收入可维持的判断必须与新增进账象薄区别。梅花493–495、555–557、795–804，周易正义03蠱34–37初六“干父之蛊，有子，考无咎，厉终吉”，古义能胜任既有事务，借作按真实责任处理原有财务，不推现实父亲或继承事件。
