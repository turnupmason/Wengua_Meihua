# 天火同人初九财富财运：十二月与五组规则
初九动下，原体静上乾金，本用动下离火直接克原乾。互卦天风姤，上乾体互与原乾同比，下巽用互受原乾直接克为可制财关系。初九变阴，末天山遁，下艮为变用直生原上乾。阶段13/44/33，四关系逐一相对原体，不串联。
- 《梅花易数》493–495、795–798、804及555–557：本离火直克、体互乾同比、用互巽受体克、末艮生，结合各季强弱及实际阶段。春相离克囚乾、难制旺巽、弱比生，D/W；季土相乾制囚巽、同比实、旺艮生且离休克浅，F/P；夏旺离重克死乾且中段难制，尾相艮生实但原体死、前阻重故C/C，非保证后续到账；秋旺乾克死巽、同比旺、离克微，尾艮生平，F/P；冬休乾难制相巽、中比普通尾生薄、离微克，C/C。进款与留存分开。
- 乾220–222、235–236、242：西北、公门、金玉贵货与权责，从现有规范业务、单位客户、重货品品质的买家维护原收入；相比旺同业有力协作，衰弱时仅按现实能力，不虚构尊长出资或有身份的贵人。离374–377、388–390、398、509：南、文人、书文、文书财，来克体古有文书忧，现实已有文件及取款要求按实际办理，旺相时核重、弱时浅核，不断已损。
- 巽313–319、326–328、337：东南、竹木茶货与工巧，用互下巽受原乾克属可制财方向，并非方应独吉；有力可控时据现有客户、交付、付款条件争取所得，难制时量自己的真实能力。艮405–412、418、428、502：东北、山田土石，变用艮直接生原乾可用生体专条，旺相可参真实地土物资伙伴或工作资源后助，夏原体死且本克重仅条件财，休囚死助有限不另定强财候。
- 《周易正义》02同人38–41「同人于门，无咎」「出门同人，又谁咎也」：王注孔疏广同、不系吝，借取财可坦诚接洽合宜的实际客户与伙伴，而不凭关系推额外馈财。
- 655、968：春夏相旺本离克体实，obstruction role use，巳午月或问期内火日核已有南面文书及实际限制。土秋用互巽有力受原乾克为gain role use_mutual，本问期寅卯木日参已有可制财；跨入寅卯月须换文章、因囚金旺木重判。季土尾旺艮有力生体gain role changed_use，辰未戌丑土月或问期内土日参已有实际外援、所得；夏相艮生实但体死且前克重，仅conditional-gain同角色和土气。秋休艮及春冬衰艮生薄、弱离克和弱制不立独候；同比无专财日。全十二月原乾土旺相、金旺两个prepare，按真实工作准备，非专财日。965方应只按实际比、生、克及有事方向，不从巽对象方位独断吉。
