# 水雷屯六三 · 财运收入五气规则审计

原卦水雷屯，六三动，静上坎水为原体，下震为本用；互山地剥，上艮体互、下坤用互；六三阴化阳使下震变离，末为水火既济。四直接作用：原坎生震己耗、体互艮和用互坤来克原坎、原坎克变用离为末取财方向。六三不同初九末坤来克和六二末兑生体，本末一耗一克，末有没有真取财的力量在五气间不同。不能凭既济卦名直接作圆满得财结论，也不以总数量对消四个节点。

## 古据
- 《梅花易数》555–557【求财占第十】体为主用为财，体生用财有损耗之忧，用克体无财，体克用有财；体克用及生体为见财候，来克及体生用为损耗候。必须由各阶段的原体与其对应节点的旺衰判断能否真克，弱体难制强财仅有求取方向，不作进账有力。无财与损失仍分别审，末有财也不能略去前期投入。
- 493–495本为始、互中、变末；796–798体互较紧用互次，804体旺遇衰克力较轻、衰体逢旺克不利。母体不换；同时有正反关系须分辨阶段，不预设补回金额。
- 505坤来克田土之忧、510艮来克「百谋中阻」皆有真实对应财事才取具体类象，既有场所责任或领取条件未满足才核查。震受体生，引用《说卦》09.07:21–22 震动以说明具有实际办理行动的财事成本，不误用震生体得财条。离受体克，取《说卦》09.07:21–22离丽及《梅花》135离属文书；仅在已有书面条件取得的财事存在时察其实际领取要求；不将501离直接来生原体的文书喜益套成确定新财。
- 《周易正义》简校01屯46–49六三「即鹿无虞，惟入于林中。君子几，不如舍，往吝」；王注「见路之易，不揆其志」，孔疏解释未先商度形势便徒往所求，虞为虞官。孔疏明言「几，辞也」不以几微解，本文不拿六三断未来具体征兆。现代财事借意：先据真实领取条件及成本判断是否值得继续办理，不因后段有财方向就盲追无来路的财，也不凭鹿、树林类象指认现实行业。
