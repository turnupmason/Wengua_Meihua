# 坤为地六三 · 财富财运规则审计（12月、5气组）

## 实盘与断财
本、互均坤为地，六三变地山谦。原体静上坤土，动下坤、上体互坤、下用互坤均直接比原体，末下艮土也直接比和原体。依《梅花易数》555–557行求财专章「体用比和，财利快意」，结合493–495、795–798、804行本、互、变先中后和旺衰断力。四处相合不是四种财源，也并非四份生扶；原体弱时同气财源亦弱。不因无生体和体克用便断全无财；四边无来克、己耗，弱财也不反断破财。六三以待时守正、有终辅现实财事，两者不抵消明确财理。

## 具体引源
- 《周易正义》简校本01坤46–49行：六三「含章可贞，或从王事，无成有终」；王注「不为事主，顺命而终」，孔疏「唯上唱下和，奉行其终」，象「以时发」。此处用于依真实条件把已有财务责任办完，待相应时机；不因「无成」将财利断作必然无收入。古时君臣结构不是现代用户实际身份推定。
- 《梅花易数》131、136行坤为地、土、谷米、布帛；艮为山土；《说卦》09.07:21–22艮止。前中坤同比着眼已有物资或财务条件；尾艮止仅看真实财事怎样收束、完成既有交接，不指认某一人或新增行业，更不用502行艮生体之喜、497行坤生体之类，因为直接关系都是比和。
- 《梅花易数》555–557行分得财、破财候。四处只是比和，无生体、体克用、克体或己耗的专候依据，十二篇不额外择日；旺相土只能提升财利相合的力度，不能单独作为实际到账日。
- 正文与简断都判财务相合及实际进账之力度，辨析已有财物、估计收入、到账、费用与结余，不把同气推成确知外来的钱，也不把低进项说成已发生损失。
