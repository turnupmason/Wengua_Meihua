# 水雷屯六四 · 财运六维逐月五气审计 v2（白话咨询式）

六四动上坎，静下震木为原体；互卦山地剥，下坤土是体互，上艮土是用互；变卦泽雷随，上兑金为变用。四节点各对原震直接作用：本坎生震；下坤及上艮各受原震之克；末兑直接克原震。与初九、六二、六三不同，本卦初始有进益方向，中段是由自身力量制取财物，末段来克限制留财。体气弱则不硬断中段财；外助有力与尾克有力并存分开收入机会和实际利润，不按节点多少相抵。

## 原典和具体六维适用边界

- 《梅花易数》555–557【求财占第十】，用生体为进益之喜、体克用有财、用克体无财；生体与体克用作见财候，克体作阻耗候。493–495始中末，796–798体互较紧、用互次，804辨月令衰旺。收入能否取得与扣费后实际余款分开写，来克不是已发生损失。本用生体强弱和自身制财能力分别核实。
- 原体震木据285动、294竹木茶货、动处求财、306东，指既有行动、木货、亲自经办工作等经营能力，东方为对应经营事项属性。非震来生体，不引498的专门来助义。弱木宜守本职、既知报酬和能完成办理的事；旺相有余力处理已存在财事，不以单一象断职业或改行指令。
- 本用坎来生据500：北方、水边人进益、鱼盐酒货及文书交易之利；346舟人等、357–358水货等求利交易、367北。北边已有货运物流、水货、文书服务、相关客户及经办者，类推实际已有的支付、履行与外助条件。原坎休在春时原震旺能承受，秋坎相虽原震死也确有来益条件，冬坎旺来生相震有力；夏囚、季土死的坎不许强外援。生体可看既有实际帮助，不编陌生贵人及身份，原来客户真实给付才适用。
- 互剥下坤是体互，上艮是用互，皆受原体克。坤253乡人、259仓库、265–266田土实物农产交易、275西南；艮407–408山中人守静、418–420山田土类、428东北。对应西南东北已经存在的场地、田土、仓储实物等收入事务，须自身力量制取，非这两土生身送财，亦非两土来克，不套505、510的田土忧或阻隔条。春旺震克死土、冬相震克囚土可取；季土囚震面对旺土、夏休震相土、秋死震休土均难制。依据658、965，体克财的方位只是对应财事属性，不称方应吉。无强比和，合作及实际客户按原有履约及费用分担来定。
- 末上兑直接克原体震，511古兑克主口舌纷争、毁折；459西方。据此只核已有西向议价、费用说明及结算中的实际责任。金在春囚、夏死、冬休，直接克力较薄，不硬判损财、独损日；季土兑相、秋旺，对囚/死原震制力较重，尤其区分实收与净所得。防花未到账的钱、检查现实分工与承担责任，不臆断欺诈或虚构新纠纷。
- 《周易正义》01屯50–53六四「乘马班如，求婚媾，往吉，无不利」，象曰「求而往，明也」。王注、孔疏是明知所应可纳且二不能为己之难，方往为吉。借到求财是具体财路已有接受及付款等条件才继续办理；吉辞不能替代四节点旺衰的财势，不按婚媾字面编财事。
- 655、968地支月日与原体旺相，658、965方应。本有力生体参亥子、两土可制参辰未戌丑月及问期内相应日；兑有力来克参申酉月日核已有阻收费用。无强见财节点的夏或季土取原体旺相木水月日准备，非财候；不硬定公历日，结构化应期旁证按问期内历法解析。利润建议依实收扣已付及必付款项，留基本生活及业务周转，财未取得不预支。
