# 泽天夬初九十二月求财规则审计

- 43泽天夬→1乾为天（互）→28泽风大过（变）。静上兑金原体、动下乾金本用，两互皆乾（下用互、上体互），尾下巽木变用。前三乾各直接同比原兑，巽受原兑直接克为自主财；493–495、555–557、796、804依据各直接作用五气，不链推，不将同气卦数机械叠加。
- 兑西方口舌译人饮食金类（437–441、445、449–451、459）；乾西北公门长者管理金玉贵货（222–223、227、233–236、242）；巽东南木茶工巧秀士（314–316、319、326–328、337）。均限定真实已有财源、实际客户与伙伴共同任务、报酬和费用。《周易正义》05夬38–41初九壮于前趾、往不胜为咎，古疏审其筹策然后往，借财务以本人真正工作能力和现实条件作决定，不凭爻义虚构损财。
- 655、658、965、968方应月日。土季与秋原兑相旺，可有力制尾巽，木gain变用，问期内寅卯木日参现实已有东南木茶工艺工作报酬，进入木旺月按金囚重新判。前三同比不另财候，卦无直接克体耗体，不造损日。申酉金旺、辰未戌丑土旺金相为prepare原体旺相环境，作既有业务和现实任务准备。
