# 地水师上六财富财运：十二月与五组规则
上六动上，原体静下坎水，本用动上坤土直克原水。互卦地雷复，下震体互受原坎生为己耗，上坤用互直接克原坎。上六变阳，末山水蒙，上艮变用直接克原下坎。阶段7/24/4，三来克、一己耗，逐一对原体，不串联，四负关系无有力正财节点。
- 《梅花易数》493–495、795–798、804及555–557：原体水强弱、三土来克与震木己耗随当令力量分辨。春冬三弱克但震木实耗，土夏三旺相土重克木耗弱，秋三休土弱克、一死震微耗无有力正财关系，均D/W。秋不能断实际重损。无财不等于已损，收入实收扣实际费用再留。
- 坎342–346、357–358、367：北方、舟人、水边鱼盐酒货、流通，现实已有北向物流、水货业务与熟悉客户按实际交付和取款要求维护。盘无正财关系，合作按工作及资金的现实能力，不凭口头合作认定有强助。
- 坤252–259、275、505：西南、田土仓库、乡人，来克体有田土忧，前中已有仓地费用与领取条件各按实际责任。艮405–412、418、420、428、510：东北、山田土石、阻隔，末艮来克，现实已有东北土物、交接与最后领取要求按实际核，强时重查、弱时轻查，不断事实损失。震283–288、294、306：东方、动、木竹茶货，原坎生下体互震为中段己耗，真实已有动木材料或运输、办理费用按实际查，不援引506震克体。
- 《周易正义》02師49–52「大君有命，以正功也」「小人勿用」：王注、孔疏于师之终正功、择人宜当的古义；财事按已完成工作及现实约定核报酬，依实际能力选择合作者，不虚构职位、赏赐、对方身份品格。
- 655、968：春冬下体互震旺相受原水生，drain仅 body_mutual，参寅卯月或问期木日实核中间动务支出。季土夏两坤与末艮三土旺相各克原水，obstruction roles use/use_mutual/changed_use，辰未戌丑月或问内土日实核前中仓地与末尾交接等不同阶段限制。弱克弱泄无独立强损候。全十二月申酉金旺水相、亥子水旺为两prepare，非确定到账日。965方应按现实对应事务，不独断方位吉凶。
