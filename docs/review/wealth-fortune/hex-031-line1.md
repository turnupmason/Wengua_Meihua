# 泽山咸初六十二月求财规则审计

- 31泽山咸→44天风姤（互）→49泽火革（变）。静上兑金为原体，下动艮土为本用，下互巽木用互，上互乾金体互，尾下离火变用。按《梅花易数》493–495、555–557、796、804原艮土直接生兑、兑直接制巽取财、乾与兑同比、离直接克原兑，各自对原体作用而非连锁。不把同气合作误作生体，不把来克硬断损钱。
- 兑西口舌、译人饮食金类交易（437–441、445、449–451、459），艮东北山田土石场所生体（405–412、418–420、428、502），巽东南工巧木茶秀士（314–316、319、326–328、337），乾西北公门长者管理金玉贵货（222–223、227、233–236、242），离南文书文字技艺炉冶（375–377、379–380、387–390、398、来克509）。所有行业方位人群限已有财路或真实资源。初六《周易正义》04咸38–41咸其拇，古疏初有其志尚未移足，财务借初始意向不等实际报酬，不凭此改变四关系和旺衰。
- 655、658、965、968：旺艮生原相兑实为 gain use，夏相艮实助但死兑承接薄、尾强克，前段 conditional-gain use；辰未戌丑月或问内土日参东北现有材料场所资源，跨月重核。强原兑制巽为 gain use_mutual，问期内寅卯日参东南已有木茶工艺实际报酬；进入木月原兑囚木旺，重新判。尾离相旺来克为 obstruction，季土休离浅克 risk-review，巳午月或问内火日核实际南方文书工艺要求，不作已损。乾同比无独财日。申酉金旺、辰未戌丑土旺金相 prepare 现有工作收入及能力，和已有同元素资源候并列时不重复计算报酬。
