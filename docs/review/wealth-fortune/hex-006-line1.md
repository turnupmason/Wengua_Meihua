# 天水讼初六，十二月令求财规则

本天水讼→互风火家人→变天泽履。原上乾金，本下坎水为原体生，体互上巽木受原体克，用互下离火直接克原体，末下兑金比和原体。引梅花555–557「体生用，财有损耗之忧」「体克用，有财」「用克体，无财」「体用比和，财利快意」，493–495、795–804判实际角色、先中末和五态；509离克体文书忧；说卦09.07:21坎陷、巽入、兑悦，09.11:27–28巽进退不果、35–36兑口舌。周易正义02訟32–35初六「不永所事，小有言，终吉」、象“讼不可长”“其辩明也”；财事以现实依据辨明、减少无谓耗费，非保证财到。

| 月气 | 原体与四作用 | 财务/进账 | 应期 |
|---|---|---|---|
| 春寅卯 | 囚乾生休坎已有耗；体互旺巽难制，用互相离来克有力；尾囚兑比薄 | D/W，进账薄、耗失及文书阻节 | 亥子水耗、巳午火阻耗，若相应事项已存在 |
| 夏巳午 | 死乾生囚坎耗薄而体弱，体互休巽难制、用互旺离重克；尾死兑比薄 | D/W，强克及无力控财，止争减损 | 巳午火气阻耗，不另立弱泄候 |
| 秋申酉 | 旺乾生相坎实己耗，体互死巽可制、用互囚离克浅，尾旺兑比强 | C/P，进账条件明确，但本位实耗仍计算 | 亥子水耗，寅卯木见财 |
| 冬亥子 | 休乾生旺坎重耗、体互相巽难制、用互死离弱克，尾休兑比平 | D/W，己耗主导且财难取 | 亥子水耗 |
| 土辰未戌丑 | 相乾生死坎轻耗、体互囚巽可制、用互休离克浅；尾相兑比强 | C/P，进账具条件，先耗及手续仍区分 | 寅卯木见财 |

候依据555–557仅取本中有力且所问实际事项存在者；比和虽财利快意而无专条独立候，未给起卦日及问期不写公历。各月均原创、同五气双码一致。初六古义止争仅为财务处置分寸，非用终吉替代盘理。
