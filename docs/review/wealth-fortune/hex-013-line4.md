# 天火同人九四财富财运：十二月与五组规则
九四动上，原静下离火；本上乾动用受原离克，为可制财。互天风姤，上乾用互受原离直接克，下巽体互直接生原离。九四变阴，末风火家人，上巽为变用，亦直接生原下离。阶段13/44/37，两可制财、两生体，四关系分判相对原体，不串联，不重复计同一份收益。
- 《梅花易数》493–495、795–798、804及555–557：春相离有力制两囚乾且两旺巽生助实，夏旺离制两死乾、两休巽普通助，均F/P；季土休离难制两相乾、两囚巽弱生，C/W；秋囚离难制两旺乾、两死巽微生，D/W；冬死离难制两休乾、两相巽生有力但承财能力弱，C/C。无直克体或己耗，不断已损。实际进款与净余区分。
- 离374–377、388–390、398：南方、文人、书文、文画及炉冶，现实已有文字文书、设计文画、炉冶工艺客户据已有需求和真实报酬条件维护；不引离生体，只为原体经营能力。
- 乾220–222、235–236、242：西北、公门、长者、权责与金玉贵货，本及用互两乾受体克为可控财，春夏凭现有能力争取真实单位管理、金属器具贵货买家报酬，弱时量力。不引乾生体尊长馈赠，也不冒称方应吉。巽313–319、326–328、337、499：东南、茶果竹木、工巧、山林；体互下巽和尾上巽直接生原离，可用生体专条。春旺实际中尾合作资源有力，夏休普通、土秋弱薄、冬相生实但原体死为条件财；仅原有东南材料、茶木工艺客户或实在资源与伙伴才参，不虚构赠财/身份。
- 《周易正义》02同人49–52「弗克攻，吉」「困而反则也」：王注孔疏取遇困能返回法则，财事按真实工作能力、合作要求与正当付款规定办理，不从爻义猜现实争斗或具体交易结果。
- 655、968：春夏两乾均被原离有力制克，合并同金gain roles use/use_mutual，本问期申酉日参现实具条件可控财，跨申酉月需换文章重判原离囚金旺。春中尾两旺巽各生原相离，合并同木gain roles body_mutual/changed_use，寅卯月或问期内木日核真实中尾资源；冬两相巽生实但原离死仅同角色conditional-gain，换月至新令重核，非保证到账。夏休巽普通、土秋衰巽不单立财期，弱难制也不立专财候。十二月巳午火旺、寅卯木旺火相两个prepare 环境备真实旧财，非见财候。965方应根据节点与实际事务；两金或两木同气合槽不按节点数定笔数。
