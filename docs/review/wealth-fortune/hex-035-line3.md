# 火地晋六三｜财富财运十二月规则审计

本火地晋（35），互水山蹇（39），变火山旅（56）。下坤动，静上离火为体。本下坤、用互下艮及尾变下艮三个土分别受原离生泄，体互上坎直接克原离。四负无比和、直接生体及原体克财，全五气D/W；原有工作宜维护，浅克耗不等于实际亏损。三土分别看真实前中后费用，同一实际支出只核一次，不串生克。

## 六维及古据
- 《梅花易数》376–380、388–390、398：原离南方文书文字、表达、明辨及技艺，已有文案、记录、教学或技术类工作依真实服务及客户报酬，非断具体职业。无比和、直接生体，无强外援；共同工作按事实资源、职责及成本确定报酬。
- 252–253、256、259–260、265–266、275：首坤西南乡里田土、实物仓储。405–408、411、418–420、428：用互和尾艮东北山林田土、场地及土石材料。三个土分别直接受原离火生泄，夏相、季土旺、秋休有实际耗财，辰未戌丑月日合槽核前西南实物仓储、中尾东北场地材料实际费用；同笔实际费用只核一次。春死微耗、冬囚耗浅按正常所费核。
- 345–352、357–358、367、508：体互坎北方水货、运输流通，直接来克原离，秋相冬旺有力，亥子月日核真实中段交付阻处，春休克浅，水旺日期仅风险复核已有中段责任；夏囚及季土死克浅微，常规核。不是确定破财事故。
- 493–495、555–557、795–804：本中末四直作用、财势旺衰；655、968、658、965：月日及方应。各月寅卯木旺火相、巳午火旺环境准备原有财路，无独立财候。真收款扣实际成本留日用、工作周转，余钱量力存；跨月核五态。
- 《周易正义》04晉39–42，六三众允悔亡，古疏志在上行，与众同信，顺而丽明得悔亡，借现实已有共同工作把真实任务、计价及报酬达成共识，不以爻义代替四负盘理。
