# 火地晋初六｜财富财运十二月规则审计

本火地晋（35），互水山蹇（39），变火雷噬嗑（21）。下坤动，静上离火为体。本下坤及用互下艮土分别受原离生泄；体互上坎水直接克原离，末变下震木直接生原离。无比和或原体克财。中段坎克和末段震生先阻后助，不互相抵销；两处土耗为先中两阶段，若实际同支出只计一次。

## 六维与古据
- 原离《梅花易数》376–380、388–390、398：南方文字文书、技艺、表达及明辨，已有文案记录、教学或技术服务等属类延伸，依真实工作和客源给付，非断职业。无比和，按真实工作、分工、费用决定合作。
- 首坤252–253、256、259–260、265–266、275：西南乡里田土、实物仓储。用互艮405–408、411、418–420、428：东北山林田土、场地和土石材料。两土均直接受离生泄，为开销耗项，季土旺重耗，夏相及秋休实耗，合土气辰未戌丑月日核前中实际支出，非必亏损；春死耗微、冬囚耗浅照正常成本核。
- 体互坎345–352、357–358、367、508：北方水货、运输流通，直接来克原离。秋相冬旺直接强克，亥子月日核现实已有中段交付责任和阻处；春休浅克，亥子水旺环境仅风险复核已有责任，非强损；夏囚季土死克浅微正常核。
- 尾震283–285、287、294、299、306、498：东方经营活动、竹木茶货与材料服务，直接来生原离。春旺及冬相有力生体，寅卯月日真实资源gain，冬原体死承接薄、后助不抵中段重阻；夏休普通助益conditional-gain；季土囚秋死助薄，常维持既有资源。
- 493–495、555–557、795–804：四关系、旺衰求财；655、968、658、965，月日环境及方应。本月若无木助日期，寅卯木旺火相准备，巳午原火旺环境各月准备办理旧财，不同财日同环境不重复设。跨月重核，用实际收入扣正常开支留生活和工作周转，余额量力储。
- 《周易正义》04晉32–35初六晋如摧如、罔孚裕无咎，进退不失正，功业未著宜宽裕进德。借已有可办工作实际完成取信，不硬断客户不信任或未来必收款。
