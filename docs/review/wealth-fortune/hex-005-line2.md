# 水天需九二 · 第二爻十二月规则审计

## 文献与取象

- 《梅花易数》555–557求财专条：用生体有进益、体克用有财、比和有财利、克体无财且有破财候、体生用有耗损之忧。始、中、末的关系均对原静体，依493–495、795–804分体用、互变和月令力度。乾金本用生上静坎水；中互火泽睽下兑（用互）生原坎，上离（体互）受坎水直接克；九二阳变阴，乾化离，变卦水火既济，下离火亦直接受原坎所克。全局仅双生与双受克之财，**没有直接克体或体生用**。弱体难克不理作已经损失的财，既济卦名不取代强弱论。
- 《梅花易数》496、503：乾生体取公门、金宝、尊长之益，兑生体有货利、朋友讲习等益。关联现实已有收入来源及真实给付条件，不由身份或古象确定事实。《说卦》09.07:21–22，兑说、离丽；09.11:35–36兑口舌，用互兑于此来生，借言语核明已有收入要求，不把本卦兑口看作克体口舌之损。兑生益与体克所求财分论，不将四节点推为四笔现实收入。
- 《梅花易数》501是离生体文书之喜；本盘离受原坎克，故仅借离之文书类象，讨论凭据、核准、实际结算条件，不能搬来直接生体的财利结论。体强可以取财不等于凭文书保证给付。
- 《周易正义》简体02需:36–39：「需于沙，小有言，终吉」，王注「近不逼难，远不后时，履健居中，以待其会」，孔疏释去水渐近，难稍近，虽小有责让之言而终吉；小象说「衍在中也」，疏释宽衍。文章据此劝已知收入的条件适时核实，处中留有处理余地，因时推进。若现实有商谈差异才取其象，不断真实争执；终吉也不代替取财的盘面旺衰。
- 不凭古象猜测财主、金额、收益率、交易标的或有无亏损。现实实支、收入及结余单独核算。见财候从555–557的生体与体克财两类取支。弱生、难制者不硬起候；强体克薄火虽取财方向有条件，须现实存在可收取之财并具体可办才取火气候；无克体和体生耗关系不立损耗专候。日期缺真实起卦时点及问期，不给绝对兑现日。
