# 水天需九二 · 第二爻十二月六维规则审计（v2）

## 盘面、财源与古爻

《梅花易数》555–557求财五关系，体用互变与旺衰493–495、795–804。静上坎水为原体，下乾本用直生；互火泽睽下兑为用互直生原坎，上离为体互受原坎克；九二阳变阴，下乾化离，末水火既济之下离仍受原坎克。全局双生、双体克财；不见直接克体或体生用，故不依未能取财或文书类象断已发生破财，既济名称不替代直接关系强弱。首中末均对原体，不因多个关系推为现实有多笔进账。实际成本仍需明确给付金额、交付凭据及已付/应付费用；无耗关系不代表没有现实费用。

本爻古据《周易正义》02需:36–39「需于沙，小有言，终吉」，注言近不逼难、远不后时，履健居中以待其会，疏言沙近于难，有小责让亦能待会，象传衍在中。《需》九二适时办理、留有商量余地的取义仅对应现实已有财务条件，不预设真正争执或由「终吉」断必然入款。末水火既济为卦序，不根据卦名翻转财势。

## 具体取财、人际与方应

- 坎体：《梅花易数》134水族鱼盐等、346江湖舟人、357–358水边货利与交易、367北。将流通、水货运输、北方类已有业务、本职承接能力作为原体特性而非凭体指认现实行业或能力；旺相可承，休囚死应以既有财源为主。
- 本用乾生：《梅花易数》496原文公门、金宝、尊长惠送之益，222公门人老人长者、235–236金玉交易及求利、公门、242西北。已知西北机构、规范管理类本职、金玉货利或现实给付关系可作外来财源。强生才重视借前辈或机构现实给付支持；弱生只维护现有渠道。不能凭角色类象猜给钱人或另有财。
- 下用互兑来生：《梅花易数》503饮食金玉货利、朋友讲习等益，437–438译人、口、悦、饮食，449–451求利交易、459西。《说卦》09.11:35–36兑口舌。取既有西方饮食、交流、翻译客户的支持、酬劳及商谈兑现；兑生体非克体争吵，弱生未必可依或强助。真实合作依给付、交付、分工和付款职责。
- 上体互与末下离均受坎克：《梅花易数》376–379文人、文字等，388–390文书财及交易、398南，体克用取财555–557。南方文书、文字、创作技艺、依手续取得款项为原体自力财；水弱难制火，主要排雷是防未具备条件的财被提前当作可用，非离克体文书忧。旺相坎可制囚死离，则已有能力和凭据的财有条件办理，不断外来贵人送财。原盘没有来克、体生己耗，因此不硬断竞争、借贷不还、亏损或新增支付事故。
- 财气、月日与方位：《梅花易数》655、968支月日旺气；658、965方卦与体用喜忌、555–557见财和耗候。方向是对应现有有利财路的传统属性；没有实际财事不作为出行择地、投资标的或实际进财保证。支月日无绝对公历日期；同气月改变须重核所克节点力量。只有实际存在的收款或收入条件才参见财月日，弱生、难克不定财候，金水体旺相则作蓄力、整理依据的环境。
