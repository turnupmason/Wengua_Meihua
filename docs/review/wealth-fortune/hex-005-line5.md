# 水天需九五 · 五爻十二月六维、顾问白话及动态应期规则审计

## 关系及爻义

《梅花易数》493–495、555–557、795–804：本水天需九五动上坎，静下乾为原体；坎水受原乾金直接生，己耗；互火泽睽下兑与原乾直接比和、上离直接克乾；五阳变阴成地天泰，上坤土直接生原乾。四节点均对原体，不因泰卦卦名断吉，不串生互卦。比和有财利、强比实际协作，变坤生为后面外助，非当下到账。区分实际财势、进款希望、净余。土令相乾承浅耗浅克，中相比足，末旺坤强生，F/P；秋金旺而相水初耗有力，C/P；夏末坤生虽有力而中离旺克重，C/C。春冬弱后助不能弥补实际前耗，D/W。

《周易正义》02需:47–50「九五：需于酒食，贞吉」，象曰「酒食贞吉，以中正也」。王注「“需”之所须，以待达也」，九五得位而持中，以待通达；求财借中正守已有正常收入，不凭酒食字样断宴请或款必到手，不以贞吉压过盘上耗阻。

## 六维取象与原典

- 乾原体：《梅花易数》222–223、235–236、242取西北、公门人、刚健、金玉求利；管理、规章职责、器物技术等既有能力为现代类推，本职收入倾向不指认真实职业。旺相可着力，囚死及冬水重耗宜守。
- 下兑体互：《梅花易数》437–438译人、口舌饮食，441静物金类，449–451财利、交易，459西方。555–557比和财利快意；有力同气适合西边原有饮食、沟通翻译客户及同向伙伴共同完成实际工作，金属货品仅为静物类象。比和弱时即使相合也办事力较薄；不当外部送财、比和无独立日期候。
- 末变坤生：《梅花易数》497坤生体田土、乡人等进益，253、259、265–266、275乡人、仓库、田土实物求利及西南。后期真实仓储、供给、地方熟客、农产资源可看是否实际给予支持；坤旺相有实助，秋休生平限已有支持事项，春冬死囚生薄不单财候。不是确认某个贵人、无依据的新钱。
- 本坎受乾生：《梅花易数》134水货、346江湖舟人、357–358水边货利失陷、367北。北边水货、运输流通等已有先付开支及资金占用按实际核查；旺相水实耗，休水对囚乾仍要留心，囚水或死水浅耗不硬造强损日。离用互直接克：《梅花易数》376–379文人与文字、388–390文书技艺求利交易、398南、509离克体文书忧。春夏来克有力，土令休离及秋冬弱离照常复核，非指认实际损失或风险行业。
- 聚财及应期：以扣除真实成本后所余为准。655、968支月日五行旺衰及658、965方应；巳午火气核已有文书强阻，浅克仅作火旺时复核；亥子水气观察实际耗费，辰未戌丑土气参真实末坤资源助益；申酉金旺日月只作原体准备/办理已经核实的业务。弱比不造专财候，后坤弱生不定收钱日，不保证给付或损失，动态按问期计算。
