# 山地剥六三｜财富财运，十二月规则审计

## 盘式与四直接关系

本山地剥（23），互坤为地（2），变艮为山（52）。下坤动，上艮为静体。原艮与本下坤、体互上坤、用互下坤、尾变下艮分别比和，共四处。各同气节点照始中末实务责任核查，不当成四笔收入、直接生体或体生用泄财。无直接生体、来克原体、原体克财或体生用关系。春同土皆死D/W，冬同土皆囚C/W，秋皆休C/C，夏相及季土旺F/P，依BRIEF比和五态统一判断。无明确额外新财或直接财损象，正常成本须如实扣。

- 《梅花易数》405–408、411、418–420、428，艮东北山林田土、场地、土石材料与静中事务。原艮为静体，原有工作、实物场地使用和山林土石材料的真实报酬为主财源；尾艮与原艮同气，现实已有工作条件的客源及伙伴协作。旺相有力、休普通、囚死薄，比和非直接生体或体克财，不占客观职业或陌生新财。
- 《梅花易数》251–254、259、265–266、275，坤西南、乡里、田土、谷帛实物及仓库；三坤各与原艮同比。原有仓储、实物供给及地方业务客户与伙伴可按真实工作量、资源、任务、费用和报酬合作，不认作贵人施财。财势佳时也不计多份相同收入、成本或预期款。
- 《梅花易数》493–495、555–557、795–804，体用四关系及财势五态。四处比和旺相可落实旧财，休可维持，囚死配合薄；不见直接克体或泄财，不能断明确财损事件，正常支出仍照真实计量及单据核，钱到账扣实际费用，保留原业务与日用周转，余下储备。
- 《梅花易数》655、968、658、965，月日与方应。春冬辰未戌丑旺土及巳午火相体月日整理原有工作和资源，夏土秋同参辰未戌丑及巳午火相土月日办理已有收入、准备及协作。四处比和均非专门新财日；无直接克体或生泄，不造破财日。动态仅依真实问期和已知业务参，不保证到账。
- 《周易正义》03剝:37–40，六三剥之无咎，三与上九相应，独协阳而免咎。借爻义维护已有真实合作能力、任务与责任相合的工作关系，非预测某个特定伙伴或事故。
