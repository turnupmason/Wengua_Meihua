# 地泽临六四十二月求财规则审计

- 19 地泽临→24 地雷复（互）→54 雷泽归妹（变）。下静兑金为原体，上动坤本用；上互坤为用互、下互震为体互、末上震为变用。两坤各自直接生原兑，两震各自受原兑直接克制为财；不作坤生兑再制震的间接链，不将两阶段同一报酬算两份。四关系依据《梅花易数》493–495、555–557、796、804。
- 兑西口译人饮食、金类交易，437–441、445、449–451、459；坤西南田土仓储谷帛、乡众（252–254、257、259、265–266、275）、生体田土谷帛之益（497）；震东竹木草木、动中求利（283–285、287、294、306）。方向为现实既有客户或资源属性，不能单凭方位假设送钱人物或推荐新行业，无直接来克或己生耗。古《周易正义》03臨44–47六四至临无咎、位当，履正尽所当做，依真实能力负责。
- 655、658、965、968时应：土坤生实两节点合土槽 use,use_mutual（强原体时gain，原体死承财有限时conditional-gain），辰未戌丑月或问内土日核现实前中田仓谷帛帮助及所得，换月重新核。体克两木合木gain（body_mutual,changed_use），有力可控财仅参问期内寅卯日，换寅卯月须按金囚木旺重判。申酉金旺及辰未戌丑土旺金相为原体准备，非必然财日。不判已亏、利润金额，实收扣费用。
