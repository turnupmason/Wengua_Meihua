# 地泽临六五十二月求财规则审计

- 19 地泽临→24 地雷复（互）→60 水泽节（变），下静兑金原体。本用上坤、用互上坤各自直接生原兑；体互下震受原兑克为财；末上坎受原兑生泄为耗。四关系分判，不作土生金克木的传递，不把同一份收入计数。关系据《梅花易数》493–495、555–557、796、804。
- 兑西口译、饮食金类交易，437–441、445、449–451、459；坤西南、乡众、田土仓储谷帛（252–254、257、259、265–266、275），497坤生体田土果谷布帛财；震东竹木动中得利（283–285、287、294、306）；坎北水货舟人、鱼盐酒货流通（345–346、350–352、356–358、367），尾为己生耗故核实际原有成本而非坎克体险陷之忧。客户、资源、费用均有现实条件；不虚构具体人物和得失、金额。
- 《周易正义》03臨48–51“知临，大君之宜，吉”“行中”，古注“委物以能”，按真实能力合作分工。655、658、965、968支月日方应。两坤合土助槽 use,use_mutual（土旺金相gain；夏相坤生实而金死承弱conditional-gain），辰未戌丑月或问内土日核已有前中帮助，换月重核。体克震可取财参问期内寅卯日，转寅卯月须按金囚木旺重判；尾水耗实参亥子月/问内水日核现有收尾费用。原兑金旺申酉，土旺金相辰未戌丑为准备。无实际生扶/制取强财条件时不另立专日；无直接克体。
