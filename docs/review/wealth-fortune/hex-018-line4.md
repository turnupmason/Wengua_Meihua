# 山风蛊六四：十二月求财规则审计

本山风蛊→互雷泽归妹→变火风鼎（50）。静下巽木；本上艮土受巽克为财，用互上震与巽同木比和，体互下兑金直克巽，变上离火受巽生为末耗。四关系对原体直接判断，无外来生体。梅花493–495、555–557、795–804；周易正义03蠱45–47六四“裕父之蛊，往见吝”，古义旧事宜宽裕适处而所往未合，借谨慎核实能力、实际工作和条件，不编家中旧事。

巽315–319、327–328、337东南工巧技术、移动货物竹木茶供应为自身；艮405–408、418–420、428东北山林田土场地稳定事务为受巽克财的实际对象，春冬有力可取、其余难制；真实客户、交付、计费与成本。震283–285、294–299、302、306东方经营活动、动中山林木货，同木比和春冬强、夏普通、土秋薄，非贵人来生。中兑437–438、441、445、449–451、459、511西方口悦沟通服务、饮食货品责任直克原巽，土秋实阻、春夏冬较浅；末离375–377、387–390、398南方文书文字、炉冶加工费用直接受生，春相夏旺土弱体仍实耗、秋冬浅。卦无直接生体，已知真实协作或自身能力，不硬断外援、具体人物或未发生费用。965方应非受克财对象方自动吉；655、968环境及555–557财耗应期，土支日及跨月重新判断。实收扣费用留周转。顾问白话逐月原创，正文简断及独立动态旁证绑定。
