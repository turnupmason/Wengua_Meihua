# 地泽临六三十二月求财规则审计

- 19 地泽临→24 地雷复（互）→11 地天泰（变）。原静上坤土，本下兑金，体互上坤土，用互下震木，变下乾金。前兑及变乾各受原坤生泄，体互坤直接同比，震直接来克原坤。四者各自直接判，不二次生克，不将两处金象等于两笔费用。关系依据《梅花易数》493–495、555–557、796、804。
- 坤西南田土仓库、谷帛静中有财，252–254、257、259、265–266、275；兑西口译饮食、金类交易，437–441、445、449–451、459；震东竹木动中求利，283–285、287、294、306，506来克；乾西北公门、权责及金玉贵货，220–222、235–236、242。前兑与后乾成本注意场景分别，现实客户和资源有前提，不断定已发生具体欠款、损失或身份。
- 《周易正义》03臨40–43“甘临，无攸利。既忧之，无咎。” 古疏甘美谄佞非正、能忧危改修，不推定伙伴骗人；借来看财须识真实付款、成本、交付，莫仅据表面报酬。655、658、965、968月日方应。申酉金月与问期内金日核前兑及尾乾实耗（同金合drain，roles use,changed_use），寅卯木月与问内木日核实克中段，均只据已存在的事项，不定金额或确切损失日。巳午火旺土相、辰未戌丑土旺原体准备。不见生体和体克，仅同比，故无独财候。
