# 水雷屯初九 · 财运收入五气规则审计

范围：近期一般求财与收支得失，非特定合同、投资、借贷或奖金。水雷屯初九动，原上坎水体不变，本下震木为用；互山地剥上艮体互、下坤用互；末水地比下坤为变用。四直接作用依次为原体生本用（己耗）、体互与用互直接克原体、变用直接克原体。体互较紧、用互次；不能因末卦名为比而误判—原体坎与变坤并非比和。盘内无体克用、用生体或同比节点，故不同五气均缺直接进财依据；依体衰旺轻重区分耗失与阻财压力，而非按三克统计相同的实损程度。

## 原典与具体取象

- 《梅花易数》555–557 求财，以体为主、用为财；体生用财有损耗之忧，用克体无财；两类均是破财候的正文依据；无财与已破财不能混同。493–495本始、互中、变末及体生用泄己、来克不宜。796–798体互紧、用互较次，以及末受克。804旺体遇弱克不能重断，衰体遇旺克压重。
- 505坤来克之田土忧及相关损象；510艮克体「诸事多违，百谋中阻」，《说卦》09.07:21–22震动、艮止。震受原体生仅由动象借为办理求财事项消耗，未用原典498震**生体**得财；坤田土及艮中阻均仅在现实对应事项存在时核查实际费用、未满足的条件，不确定某行业或某个人。坤克并非必然真已受损。
- 《周易正义》简校 01屯36–41 初九「磐桓，利居贞，利建侯」；王注停而居正，孔疏解释不进非宴安弃成务，建立治理秩序。现代借义：先办妥已有可兑现条件和必须承担的收支责任，勿盲目新增付出；并非一定获贵人财，也不是停止一切工作。
