# 水天需九三 · 第三爻十二月六维及咨询白话审计（v2）

## 盘面与专项依据

《梅花易数》555–557求财五关系，493–495、795–804本互变及旺衰；静上坎水为原体，本用下乾金直生。中互火泽睽的下兑为用互来生，上离体互受原坎克；九三阳变阴，下乾成兑，变水泽节，下兑金仍直接生原坎。三生节点分布于首中末，表示财源有前后延续的机会而非三笔现实收入；单一体互离是原体自己所求财。全局不见直接克体与体生用；没有上述破财方向不代表现实费用为零，财难取得不等于自身已亏。旺相体及有力生体时可承财，弱体有强生前中末皆在时获实在外援，弱生兼难制时不机械断有财。

《周易正义》02需:40–43：「需于泥，致寇至」，王注以刚逼难，欲进而招寇，犹有待时；孔疏释泥溺近险仍需待，象传「自我致寇，敬慎不败」。取义为已有财源亦依现实承接力及已具条件办理，不贸然答应未知报酬或资金责任。爻中的寇不指认真实偷盗、侵财、同行攻击等，节卦名不当作已发生具体耗费。五气强弱不能被单一古爻或卦名翻转。

## 六维证据：财源角色、人群行业和方位

- 原体坎：《梅花易数》134、346江湖舟人、357–358水边财与鱼盐货交易、367北方。现代水产、运输、流通等属于坎的经营类象，须确有原有技能客户；休囚死守已有本职/经营基础，旺相有承接力。原体方位非独立外财来源。
- 本乾直生：496公门、金宝、尊长惠送之益；222公门人、老人长者，235–236金玉交易/求利公门，242西北。现有西北机构、规范管理本职、金玉业务或已知给付责任的前辈，按实际财务事实借外来助益。金囚死仅原有潜在支持，需要维护原来关系；相旺及体旺相能承的休金较有力或有条件助益。不识别实际贵人或预断必来财。
- 用互与末兑生体：503饮食金玉货利、朋友讲习等益；437–438译人、口、悦、饮食，449–451求利交易、459西。西方饮食、翻译、交流类现实客源依需求及实际给付取象；兑来生在中间及尾位，非口舌来克，不指争吵。有实际提供资源的机构或前辈时按现实分工、付款责任、工作范围协作；弱生不能把好说话当资金及合作必成。两个兑不预设两个客户。
- 体互离受体克：376–379文人书事等、388–390文书财及交易、398南，555–557体克用取财。南方文书、文字技艺等本人能依凭据及实际承接力取得的财；弱体克相旺火难，事难兑现并非合同本身有损；旺相水能制死囚离，可以靠已有实际条件取财，不冒称来生贵人。方位仅财对象属性；《梅花易数》658、965方卦以体用关系论；未明现实财源不作为出行或投资指令。
- 卦气及留存：《梅花易数》655、968支月日旺气；555–557见财、耗候分开。本、互用、末三金旺相来生参申酉月日，休金来生而体旺可承者只作条件助益候；体互囚死离可制而确有实际财款参巳午日，适用火月应重核制财力。不见来克体或体生耗无破财候；囚死金来生薄、相旺火难制不给强财日期，改申酉金旺水相、亥子水旺作准备复核。实收、实际必要费用、周转与余款分核，不把象意写成真实赔钱、确定收益或投资建议。
