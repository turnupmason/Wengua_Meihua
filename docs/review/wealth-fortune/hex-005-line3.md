# 水天需九三 · 第三爻十二月规则审计

## 盘理与文献

- 《梅花易数》555–557【求财占第十】：以体为主、以用为财，用生体财有进益之喜，体克用有财，克体为无财及破财候，体生用为耗损。493–495、795–804确定本用先、互中、变末，体互紧于用互，均直接对原静体，以旺衰论实际作用，不串联间接五行、不计吉凶票数。本下乾金生静上坎水，互火泽睽下兑用互生原坎，上离体互被原坎直接克；九三阳变阴，下乾成兑，变水泽节，下兑金仍直接生原坎。三个来生节点分别在首、中、末，表示进益持续机会，并不判定现实有三笔款或三个提供资金的人。体互离为另一财路；全局无来克或体生用，不把财难取得作已出现损失，也不从无耗关系推出实际开支为零。
- 《梅花易数》496乾生体有因官有财、尊长惠送、金宝等类象；503兑生体有食物金玉货利之源、朋友讲习等益。《说卦》09.11:35–36兑口舌，因用互及变兑均生体，依现实存在的收入往来或商议见助益方向，不把兑口直接看为争吵或损财。乾尊长公门等仅为财源类象，取有依据的实际条件，不猜财主身份。《梅花易数》501离生体文书之喜在本盘仅借文书类象，离受体克是本人能否落实付款凭据、相关手续及真实财事，不搬用直接生体的得财结论。
- 《周易正义》简体02需:40–43：九三「需于泥，致寇至」，王注以刚逼难、欲进招寇，尚有待时，敬慎防备可以不败；孔疏释泥溺逼难犹需待；小象「灾在外也」「自我致寇，敬慎不败也」。应用于本问，仅以较明财路与现实办事能力之间的分寸看是否贸然增加支付、强求尚未落实的财，并不据寇认定偷盗、财务侵害或有人要抢钱。九三不可仅凭旺生即推现实冒进，亦不可用古爻凶辞抹去三生体的财象。水泽节卦名不编造现实具体消费情节。
- 见财候依555–557生体、体克用：囚死金生弱、休囚体制相旺火难，不设无力财候；三相金生死水时有相金实助，且尾位继续有力生体，较九二尾难制有所改善；旺相体承来生及可制之财俱见，可参金气、火气，但须真实已有给付或能够办妥的财务事项。无来克、体生耗关系不设破财候；不推具体日期、收益或金额，不以进账当作扣费后的利润。
