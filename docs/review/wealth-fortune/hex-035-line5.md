# 火地晋六五｜财富财运十二月规则审计

本火地晋（35），互水山蹇（39），变天地否（12）。上离动，静下坤土为原体。本上离火直接来生原坤，体互下艮土同比原坤，用互上坎水受原坤直接克制为财，尾变上乾金受原坤土生泄为耗。无直接克体；前中助益、自取财和尾段实际耗费不互相抵销。旺衰决定作用力量，进款不等于净余。

## 六维及古据
- 《梅花易数》252–253、256、259–260、265–266、275：原坤西南乡里田土、谷帛实物仓储，已有实物保管、供给、场地服务及原客户为实际收入根底。405–408、411、418–420、428：体互艮东北山林田土、场地土石材料，与原坤比和，原有伙伴依工作、资源、费用及报酬协作，旺相有力、休普通、囚死薄，不当作额外赠财。
- 376–380、388–390、398、501：本离南方文字文书、表达技艺，直接生原坤，实际帮助资源和贵人方向。春相火生有力但原坤死承接薄，夏旺火实助，土休普通生，巳午月日分别条件候、gain、条件候；秋囚冬死薄助维持已有资源，非强财。
- 345–352、357–358、367、555–557：用互坎北方水货、运输流通，是受原坤所克的财，夏相坤可制囚坎、土旺坤可制死坎，问期内亥子日参已有现实可控财，跨月核；春秋冬难制，按自身实际承办能力审查，不是来克体或额外馈赠。
- 221–222、227、235–236、242：尾乾西北公门管理、金属器具及规范服务，直接受原坤生泄为耗。季土相金实耗，秋旺重耗，冬休普通实耗，申酉月日核已存在的西北尾段成本；春囚轻、夏死微耗照正常所费核。无直接来克，不凭空推人事或确定破财。
- 493–495、555–557、795–804：本中末四直作用及求财旺衰；655、968、658、965：月日及方应。全月辰未戌丑土旺准备办理原有工作；秋冬巳午火相土环境准备不独立财候；有真实火助时同一环境不重复列。真到账扣实际费用，留日常及工作周转，余款量力存。
- 《周易正义》04晉46–49六五失得勿恤，各有其司、委任得人、不代下任，借现实共同工作厘清分工、任务及收费，非断特定人物或保证财。
