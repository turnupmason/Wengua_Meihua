# 山风蛊六五：十二月求财规则审计

本山风蛊→互雷泽归妹→变巽为风（57）。静下巽木，本上艮土受巽克为财；用互上震与变上巽分别同木比和；体互下兑金直克巽。无直接来生及体生用，既有合作相合不等于外人施财。梅花493–495、555–557、795–804；周易正义03蠱48–51六五“干父之蛊，用誉”“承以德也”，古义以中和承任而非威力，借真实工作交付及信誉，不凭此预测父亲或声誉事件。
