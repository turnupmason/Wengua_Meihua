# 水风井初六：十二月求财规则审计

本水风井→互火泽睽（38）→变水天需（5）。静上坎水，本下巽木受原坎生而耗，体互上离火受原坎克财，用互下兑及尾下乾金分别直接生原坎，实际资源援助。无直接克体。梅花493–495、555–557、795–804；周易正义05井43–46初六井泥不食、旧井无禽，古疏旧井失治而不堪用，借整理原有业务质量和交付条件，非具体灾祸或保证收益。
