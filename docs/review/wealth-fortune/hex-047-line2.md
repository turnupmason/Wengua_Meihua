# 泽水困九二｜财富财运十二月规则审计

本泽水困（47），互风火家人（37），变泽地萃（45）。下坎动，静上兑金为原体。本下坎水受原兑直接生泄为前段耗；用互下离火直接克兑为中段阻；体互上巽木受兑克为中段自财；尾下坤土直接生兑为后段资源助益。无同比。前耗中阻、可控财与尾助分阶段，后段援助不抹去中途实际责任。

## 六维及古据
- 《梅花易数》437–438、441、445、449–451、459：原兑西方沟通服务、饮食货品交易及金属器具；依原技能、实际客户需求和工作报酬办理。
- 345–352、357–358、360、367：本坎北方水货、运输流通及涉水服务费用，直接受原兑生泄为前段耗；冬旺重耗，春休普通实耗、秋相实耗，亥子月日核实际前费；夏囚土季死浅微耗按真实成本核。
- 375–377、387–390、398、509：用互离南方文字文书、技术及加工，直接克兑；春相夏旺对弱金克重，巳午月日核已有中段任务；土季休火浅克，只在火旺环境复核；秋囚冬死克浅微按事实查。
- 315–319、327–328、337、555–557：体互上巽东南工艺、木竹茶货及商贸服务，受原兑克为自取财。土季与秋体力足可制囚死木，问期内寅卯日参考现实可控财，跨月重核（主动财尤其木旺月）；春夏冬体较难制木，依实际承办能力，不作贵人财。
- 252–253、256、259–260、265–266、275、497：尾坤西南乡里田土、实物仓储，直接生原兑，后段外部资源。春死冬囚生薄；夏相真助但死兑承接薄且中段旺离强阻，条件候辰未戌丑月日；土季旺真助同月日gain，秋休普通资源条件；有真实给付才参，换月重核。
- 493–495、555–557、795–804：四直关系及旺衰；655、968、658、965：月日环境及方应。每月申酉金旺准备/办理原财，春冬另辰未戌丑土旺金相准备；已有尾坤资源候的月不重复土准备。实收扣费用留日用和周转，余钱量力储备。
- 《周易正义》05困44–47：九二困于酒食、朱绂方来、征凶无咎，古义刚中履谦、物所归、盈而又进则失宜，借现实以真实资源及成本办已有任务，不解作确定馈赠。
