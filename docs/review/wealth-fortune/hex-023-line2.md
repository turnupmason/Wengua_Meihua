# 山地剥六二｜财富财运，十二月规则审计

## 盘式与四直接关系

本山地剥（23），互坤为地（2），变山水蒙（4）。下坤动，上艮为静体。原艮与本下坤、体互上坤、用互下坤分别比和；尾变下坎水直接被原艮克，为原体可取之财。三个同气比和位置分辨，不当三笔收入、直接生体或生泄项。无直接生体、来克原体或体生用关系，财事困难不等于已财损。正常支出照实际核。春原艮和三坤同弱，休坎难取；夏土旺相，囚死坎可制；秋土休和三休坤普通协作，相坎难制；冬弱土难制旺水，弱同比只能维持现有收入。

## 六维及古据

- 《梅花易数》405–408、411、418–420、428，艮东北山林、田土、场地、土石材料与静中事务，现实原有场地服务、材料、山林等真实需求与既有报酬为主业，按实际交付、成本和收费核，非断陌生职业。
- 《梅花易数》251–254、259、265–266、275，坤西南乡里、田土、谷帛实物和仓库。三坤分别和原艮同比，既有仓储、实物地方客户与合作伙伴。旺相同比有力、休普通、囚死薄。共同工作需实际资源、任务、费用和报酬明确，非外来生体或贵人送钱，不能当作重复收入或新财节点。
- 《梅花易数》345–352、357–358、360、367，坎北方、水边、舟运及鱼盐酒货、流通；末坎水为原艮所克对象，具备实力时凭已有真实客户的水货运输、流通、水边业务取财，非凭方位断实际收入；春秋冬难制，额外财量力，不立强财期。无直接克体及生泄，难制非已经破财；正常成本扣除，留周转、余款储备。
- 《梅花易数》493–495、555–557、795–804，体用四关系及财势五态；655、968地支月日及五气；658、965方应。夏相和季土旺原艮可有力制尾囚死坎，问期内亥子支日仅参考具体可控财，跨月重核。夏土秋辰未戌丑土旺与巳午火相土月日办理旧财，春冬辰未戌丑土旺及巳午火相体环境准备。三坤比和不独立定财期。事件须有真实任务和报酬，尤非保证到账，跨月按新月令再审。
- 《周易正义》03剝:34–36，六二剥床以辨，足与床身分界处已见渐近侵削。借爻义核现实原有收入的工作基础、责任范围及计价，不断真实床损或直接损财事件，不盖月令旺衰。
