# 山泽损初九｜财富财运十二月规则审计

本山泽损（41），互地雷复（24），变山水蒙（4）。下兑动，静上艮土为原体。本下兑金直接受原艮生泄为耗，用互下震木直接克原艮，体互上坤土同原艮比和，末变下坎水受原艮直接克制为财。无实际来生体；同土原工作及伙伴是真实相合，不当外援。前耗、中阻与尾财不互相抵销，旺衰及承办能力按五气核。

## 六维及古据
- 《梅花易数》405–408、411、418–420、428：静艮东北山林田土、场地、土石材料及固定服务，已有真实客户和原技能为主要财路，按明确需求、工作及报酬办理。252–253、256、259–260、265–266、275：体互坤西南乡里田土、实物仓储，跟原艮同土相合，旺相伙伴有力、休普通、死囚薄，按真实工作资源和成本合作。
- 437–438、441、445、449–451、459：本兑西方沟通服务、饮食货品交易、金属器具，直接受原艮生泄为前期费用。季土相金、秋旺金、冬休金有实耗，申酉月日核已有相关费用；春囚夏死耗力浅微，依实际成本核，不断必亏。
- 283–285、287、294、299、306、506：用互震东方经营活动、竹木茶货及材料供应，直接来克原艮。春旺、冬相对弱艮克有力，寅卯月日核已有中段交付实际责任；夏休木浅克，仅木旺环境风险复核，非强损；季土囚秋死震克浅微按实际查。
- 345–352、357–358、367、555–557：末坎北方水货、运输流通，受原艮克为财，夏季土体有力可制囚死水，问期内亥子日参已知现实可控财、跨月重核，水旺月须重新判断，不硬断成交；春秋冬原艮力弱或普通难制休相旺坎财，先核自身真实承办力。
- 493–495、555–557、795–804：四关系及旺衰求财；655、968、658、965月日旺相环境与方应。各月辰未戌丑土旺及巳午火旺土相环境准备、办理旧财，不同比专财日。实际到账扣成本、留必要周转及日用，余款量力存。
- 《周易正义》04損42–45：初九巳事遄往，无咎，酌损之，古疏事竟速往、酌量减损合志，借已有任务依真实工作范围完成及成本量力办理，不以爻义覆盖克耗、取财。
