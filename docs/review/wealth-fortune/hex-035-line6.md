# 火地晋上九｜财富财运十二月规则审计

本火地晋（35），互水山蹇（39），变雷地豫（16）。上离动，静下坤土为原体。本上离火直接生原坤，体互下艮土同原坤比和，用互上坎水受原坤克财，末变上震木直接克原坤。无原体生用泄财。先助与末阻不互相抵销，春原体死、尾旺木重克虽有前助，仍整体求财难；夏季土原体有力，末木力量浅，不将弱克当重损；秋冬各依真实四关系。

## 六维及古据
- 《梅花易数》252–253、256、259–260、265–266、275：原坤西南乡里田土、谷帛实物仓储，依已有保管、供给、场地等工作及真实客户取得报酬。405–408、411、418–420、428：体互艮东北山林田土、场地土石材料，原坤同土比和，原有工作伙伴按实际资源、任务和费用配合，旺相有力、休普通、囚死薄。
- 376–380、388–390、398、501：首离南方文字文书、表达技艺资源直接生原坤，真实外援、贵人助益方向。春相离真助，但原坤死承接薄且尾旺震克重，前助不抵尾阻；夏旺真助，季土休普通条件生。春相离前助而弱体承接薄且强尾阻，只取conditional-gain；夏旺离gain；季土休离conditional-gain，巳午月日察实际资源，跨月重核，秋囚冬死助薄常核。
- 345–352、357–358、367、555–557：用互坎北方水货、运输流通，被原坤所克为财；夏相坤可制囚水、季土旺坤可制死水，按实际已知可控财参问期内亥子日，跨月重核，水旺月须重新判断，不硬断成交；春秋冬坎财难掌控，先按自身真实承办力评估。
- 283–285、287、294、299、306、506：末震东方经营活动、竹木茶货及工料供给，直接来克坤，春旺及冬相对弱坤克有力，寅卯月日核已有现实末段交付责任阻处；夏休震浅克，木旺环境只作风险复核责任，季土囚及秋死震克浅微常核。无原体生泄，正常成本照实，并非一定破财。
- 493–495、555–557、795–804：本中末四直关系和求财旺衰；655、968、658、965：月日方应及环境。每月辰未戌丑土旺环境准备办理旧财；秋冬离弱助时巳午火相土准备，不独立财日，离有助益候时不重复同环境。实际所得扣必要费用留日用及工作周转，余款量力存。
- 《周易正义》04晉50–53：上九晋其角，过明之中、进极过亢，道未光，借现实工作任务应量力调整，不据爻断兵事、人物或确定财损。
