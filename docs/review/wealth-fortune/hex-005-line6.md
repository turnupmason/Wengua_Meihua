# 水天需上六 · 六爻十二月六维、顾问白话及动态应期规则审计

## 关系及爻义

《梅花易数》493–495、555–557、795–804：本水天需上六动在上坎，下乾静为原体。本坎水受乾金直接生，己耗；互火泽睽下兑比原乾，上离直接克乾；上阴转阳为风天小畜，上巽木直接受原乾金克。末为主动取得的财对象，乾强可制、乾弱难制，不因最后巽木旺便直接判断财丰厚。四节点各对原体，原体不重定，不串生克。全局无直接来生；比和有财利却不是别人的实际资财。土相乾能承浅耗浅克，中相比有力，尾囚巽可制，F/P；秋旺乾、旺兑同旺，末死巽可制，但相坎初实耗，C/P；春夏冬前有现实耗或阻主导且末难制，D/W。

《周易正义》02需:51–54「上六：入于穴，有不速之客三人来，敬之，终吉。」王注及孔疏皆取难终而三阳自来，敬之乃吉；求财以实际末巽关系定财。财务上只取对现实已经有实际需求的客人认真接洽、量力承办；上六卦爻注疏的三人是初二三阳爻，不预测现实三人、三单或三笔收入，也不据爻辞替代末巽的主动取财难易和盘无生体，不写强外援。

## 六维古典依据

- 原乾：《梅花易数》222–223、235–236、242，乾西北、公门规范、官贵金宝、刚健；以管理、器物技术、实际职责等原有本领类推所得，非推定实际职业。体旺相则有承办能力，囚死及冬实耗宜守原收入。
- 下兑体互：《梅花易数》437–438口舌饮食、译人，449–451求利交易，459西方；555–557比和财利快意。强比可有已有饮食交流客户或伙伴配合，弱比只是有一定沟通基础，真实分工、交付、费用和报酬宜明确；无生体，不说贵人送钱；比和无独立进财专候。
- 变用巽：《梅花易数》315–319人物工巧、秀士及相关属类，327–328求利交易，337东南。末巽受乾克，旺相乾可制时取真实工巧、木竹茶货及材料供应等客户的工作所得，方位仅财对象属性，不能用巽生体条说外援。原体弱难制，保已知财路不把难取财当破财。
- 本坎：《梅花易数》134水货属类、346江湖舟人、357–358水边货利及失陷、367北。北方水货运输流通已有费用算己耗，实际垫款核回收。用互离：《梅花易数》376–379文人文书文字、388–390技艺求利交易、398南、509离克体文书忧。强克审已有合同和付款凭据，薄克按现实常核，不断实际损失或指认他人骗钱。
- 聚财与时段：依实收扣费用看净余，不把未落实款项算可用余额。655、968月日支气，658、965方应。末巽受强金制有财候参寅卯日，跨到木旺月要重新核当时金木强弱；有力克体与体生用实耗参相应火、水支月日；土令弱离只火旺环境复核；申酉金旺环境准备及办理既知工作，非专财期。日期用真实问期动态计算，不保证实际到账，不把比和日期单列。
