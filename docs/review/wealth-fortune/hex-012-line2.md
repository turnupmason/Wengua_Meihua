# 天地否六二：十二月求财规则审计

本天地否→互风山渐→变天水讼。静上乾金；本用坤、中用互艮分别直接生乾；体互巽受乾克，变用坎受乾生，为中取财、末己耗。无比和、无直接克体，不作串生克。梅花493–495、555–557、795–804。周易正义02否34–37六二“包承，小人吉，大人否，亨”，疏义为处否坚守君子之道、不因顺承而失正；不由爻名判断现实人物好坏，仅借处理正当工作职责、计价和费用。
