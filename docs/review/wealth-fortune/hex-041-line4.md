# 山泽损六四｜财富财运十二月规则审计

本山泽损（41），互地雷复（24），变火泽睽（38）。上艮动，静下兑金为原体。本上艮土及用互上坤土分别直接生原兑；体互下震木受原兑克制为财；尾上离火直接克原兑。无原体向外生泄。有真实前中资源与末段阻处时按阶段核、不互抵。同气两土合助槽，同现实资源不双计；受克之木财难掌控不作主动财或贵人助益。

- 《梅花易数》437–438、441、445、449–451、459：原兑西方沟通服务、饮食货品交易及金属器具，原有技能与客户；依实际需求、工作量、报酬办理。
- 405–408、411、418–420、428、502：本艮东北山林田土、场地、土石材料及固定服务，生原兑为前段真实外部资源的方向。252–253、256、259–260、265–266、275、497：用互上坤西南乡里田土、实物仓储，生原兑为中段实际外援。春死冬囚薄，夏相可实助但承接薄且尾阻重，季土旺真助，秋休普通帮助条件。同项现实资源不重计，具体服务和费用据实协商。
- 283–285、287、294、299、306、555–557：体互下震东方经营活动、竹木茶货及材料供应，受原兑克为自取财。季土、秋体有力可制囚死木，问期内寅卯日参考已有真实可控财，不保证实际成交，跨月重核；春夏冬较难克取，先守原财，视真实承办力。
- 375–377、387–390、398、509：尾离南方文字文书技术及加工来克原兑，春相和夏旺对弱金克重，巳午月日核已有尾段文书技术责任；季土休离克浅，火旺环境复核非强损，秋囚冬死浅微按事实核。无原体向外生泄，不虚构耗财。
- 493–495、555–557、795–804：本中末四关系与旺衰；655、968、658、965地支月日环境及方应。每月申酉金旺准备及办理旧财，春冬另辰未戌丑土旺金相准备；双土已有真实资源候与土旺准备区分不重复。实际到账扣费用，留必要日用和工作周转，有余再存。
- 《周易正义》04損54–57：六四损其疾、使遄有喜，疏释企望同道之疾，初九以正道来、四速纳而有喜，借现实合作真实资源及解决已知工作阻处，非断恋爱或疾病。
