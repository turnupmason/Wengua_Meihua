# 地水师六五财富财运：十二月与五组规则
六五动上，原体为静下坎水，本用为动上坤土，直接克原坎。互卦地雷复，下震体互由原水生，为己耗；上坤用互直接克原体。六五变阳，末坎为水，上坎变用与原下坎比和。阶段7/24/29，分别四直关系，不能串联。
- 《梅花易数》493–495、795–798、804及555–557：本用与用互两土各直接克体，体生下震己耗，末上坎比和。春水休、土克轻但旺震耗实尾同水平；土夏水衰两土旺相克重，尾比薄；均D/W。秋冬相旺原水，尾同比有力而前中有实际克耗，故C/P，冬相震泄实须区分实收与净余。不能把助力虚构为额外赠财或断实际损失。
- 坎342–346、355–358、367：北方、舟人、水边鱼盐酒货、流通事业和合作事务；先维护真实既有物流、水货供销客户与伙伴，末坎相旺之秋冬才较有力协作，其他五气尾同比平弱无力承担额外财务责任。初中受克不意味着原有收入全失，合作依据事实与工作能力。
- 坤252–259、275、505：西南、田土、仓库及乡人众人，克体古有田土忧，实际已有仓地费用、取款条件按前中两段分别核，弱克只查真实事项，不认定已损。震283–288、294、306：东方、动作及木竹茶货，对下体互己生耗的费用类别，真实已有东方材料采购、搬货或外出办事费用才查，不引506震克体。
- 《周易正义》02師46–48「田有禽，利执言，无咎」及任用合宜古义：应事实、处置得当，依现实合作方能力安排适当职责，不凭卦猜交易、所得金额或对方身份。
- 655、968：春冬下体互震旺相且受原水生，drain仅 body_mutual，真实中段动木费用参寅卯月或问期内木日；季土夏两坤旺相克体为obstruction use/use_mutual，辰未戌丑土月或问期同支日，核前中现实条件。弱克弱泄无单独阻耗日，末比和不择专门财候。全十二月申酉金旺水相、亥子水旺两prepare，真实旧财和资料准备，非确定到账。965方向按现实事项，不独断吉凶。
