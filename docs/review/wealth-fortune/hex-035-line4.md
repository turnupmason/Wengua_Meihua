# 火地晋九四｜财富财运十二月规则审计

本火地晋（35），互水山蹇（39），变山地剥（23）。上离动，静下坤土为体。本上离火直接生原坤；用互上坎水受原坤土直接克制为财，实际可制与否依月令。体互下艮、末变上艮分别与原坤同土比和，现实同一资源或合作事项不重复记。无直接来克及原体生泄。

## 六维及古据
- 《梅花易数》252–253、256、259–260、265–266、275：原坤西南乡里田土、谷帛实物及仓储，原有实物、场地、保管等技能和明确客户报酬可依现有工作取得，非固定职业断。
- 376–380、388–390、398、501：首离南方文字文书、表达和技艺，直接来生原坤，是实际资源和贵人助益的方向。春相有力但坤死承接薄，夏旺真助，土休普通，巳午月日分别条件/真实/条件助益，跨月重核；秋囚、冬死薄助，已知资源正常维护。实际给付非保证。
- 345–352、357–358、367、555–557：用互坎北方水货、运输流通，受原坤直接克财，夏相土可制囚水、季土旺可制死水，问期内亥子日参现实可控财，跨月核，不硬断收益；春死秋休冬囚土未能有效制休/相/旺水财，照具体承办力和成本评估，非来克体。
- 405–408、411、418–420、428：体互及末艮东北山林田土、场地、土石材料，两土各与原坤比和，已有伙伴按现实任务资源、费用和报酬协作，旺相有力、休普通、死囚薄，不当作另两笔收入或外来送财。
- 493–495、555–557、795–804：本中末四关系及求财旺衰，655、968、658、965：月日及方应。各月辰未戌丑土旺月日准备办理原有业务；秋冬离助薄，巳午火旺土相环境仅准备，前三季离有财候时避免同环境重复列。无克耗关系不臆断破财，实际收入扣正常费用、保日常与工作周转，余款量力存。
- 《周易正义》04晉43–45：九四晋如鼫鼠、贞厉，古疏无业可安、无所据守、五能而不成一伎术，借现实专注已具备的技能及真正可控的财事，不据爻另断财损。
