# 地天泰六五 · 五爻十二月六维、顾问白话及动态应期规则审计

## 关系及爻义

《梅花易数》493–495、555–557、795–804：地天泰六五动上坤，静下乾为原体；互雷泽归妹下兑为体互、上震为用互，变水天需上坎为变用。始坤直接生乾，中兑直接比原乾，中震直接受乾金克，末坎直接受乾金生，后段己耗。始中末各对原体，不能串生。土相乾得旺坤强生、相兑比有力、囚震可制、尾死坎耗浅，F/P；秋旺乾、中旺兑有力，死震可取，休坤普通助，但尾相坎耗有实，C/P；夏死乾得相坤生有力，死兑比薄、休震难制、尾囚坎耗轻，C/C；春囚乾得死坤薄生、囚兑比薄、旺震难制，尾休坎有耗，D/W；冬休乾得囚坤薄生、休兑比平、相震难制、尾旺坎实耗重，D/W。前面的资源帮助及后来耗费需分别看，进账不等于利润，尾耗不意味已发生损失。

《周易正义》02泰:46–49「帝乙归妹，以祉元吉」，古注取履中居顺、感以相与、不失其礼，象曰「中以行愿」。财事借共同任务双方实际能力、分工及费用和报酬约定的相应之义，不从古文有婚嫁便预测婚事、具体性别贵人或他人钱财，不以元吉推翻原体强弱与末坎己耗。

## 六维古典依据

- 原乾：《梅花易数》222–223公门官贵、235–236金玉求利交易、242西北，现实本职、管理规范和器物技术等既有工作能力为类推。体旺相承接有力，囚死及冬水重耗宜守原财，不凭卦推定现实职业或推荐行业。
- 本坤直接生体：《梅花易数》497坤生体田土、乡人、谷帛益；251–254乡里农夫田野、259仓库、265–266实物田土贸易、275西南。已知仓储、实物、农产供给及地方熟悉资源作为真实外援，旺相有实助、休普通条件、囚死弱不定强财候。
- 下兑体互与原乾比和：《梅花易数》437–438口舌饮食、译人，449–451求利交易，459西；555–557比和财利快意。西边沟通翻译饮食等既有客源及同向伙伴的实际配合，旺相比和办事较有力，弱比仅有相合方向；不认为别人直接送财，不造独立日期。
- 上震用互受乾克：《梅花易数》284–285起动、288木竹、294、299动中及竹木茶货财交易、306东。原有东方经营活动、材料调运、木货供应等实际客户，有力金克弱木时可凭自身组织、技术及交付能力取得收入；弱乾难制时不宜扩张，非震来克或震生体。
- 尾坎受乾生：《梅花易数》134水货属类、346江湖舟人、357–358水边货利及失陷、367北方。原有北方水货运输、流通以及交付后所需的成本、款项占用为现实尾耗方向。水旺相及休水对囚金有实际耗，囚死水耗轻照常核。此盘无直接来克，不凭坎象猜欺诈、事故或既成亏损。实收扣所费、留生活及周转，余款依实得安排。
- 动态应期：《梅花易数》655、968支月日和658、965方应；555–557生体及体克用财、体生用耗候。坤旺相实际支持参辰未戌丑月日；秋休坤普通生只已知资源条件财候。中震可制时参寅卯日，换木旺月份重核；末坎有实耗参亥子月日，弱耗不硬造强损。申酉金旺、土气相体准备只原体环境，非专门收入时机，比和同气亦无独立财候。日期依真实问期动态计算，不保证到账。
