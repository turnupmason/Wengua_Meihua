# 天雷无妄九五十二月求财规则审计

- 25天雷无妄→53风山渐（互）→21火雷噬嗑（变）。下静震木原体，上动乾金本用；上互巽木用互、下互艮土体互、尾上离火变用。乾直接克原震，巽直接同比，艮受原震直克取财，离受原震直生耗。依据《梅花易数》493–495、555–557、796、804，四节点各比较原体，不能用土等中间生克串联，不能把毛收入当净余。
- 震东方竹木草木、动中求利（283–285、287、294、306）；乾西北公门长者管理金玉贵货（222–223、227、233–236、242，来克公事之忧504）；巽东南工巧木茶秀士（314–316、319、326–328、337），同比非生；艮东北山田土石材料场所（405–412、418–420、428），为所克财；离南方文书炉冶工艺火类（375–377、379–380、387–390、398），受体生耗非生体，不援引509离克体。实际已有业务及伙伴才核。古《周易正义》03無妄53–56九五无妄之疾勿药有喜，古疏明示假病象以喻人事、非妄勿妄治，财务仅借提醒不妄改原有工作与未经证实的投资；非医疗劝告，不硬断坏事。
- 655、658、965、968：体互艮财可制为gain body_mutual，限问期内辰未戌丑日参已知东北材料场所工作报酬，入季土月按木囚土旺重判。前乾强克 obstruction use，冬休乾浅克risk-review，申酉月或问内金日核西北已有管理器具要求；春囚克浅、夏死微不独候。末离春相及夏旺实耗、季土休离普通耗但原体弱均drain changed_use，巳午火月或问内火日核已有南面文书工艺验收费用，不断已亏、普通耗不夸重。秋囚、冬死离耗薄微不立独期。同比不单立财候，寅卯木旺与亥子水旺木相prepare非确定财日。
