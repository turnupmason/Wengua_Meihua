# 坎为水六三｜财富财运，十二月规则审计

## 盘式与四直接关系

本坎为水（29），互山雷颐（27），变水风井（48）。下坎动，上坎为静体。本下坎比和原坎，体互上艮土直接克原坎，用互下震木及尾变下巽木分别受原坎水生耗。两木耗分别对原体辨中、尾阶段，若现实同一笔费用只按实际所费核一次，不串生克。无直接来生及原体克财。春休坎同比普通，死艮克浅，双旺木重耗；夏囚坎同比薄，相艮实阻，双休木实耗；季土死坎、旺艮重克、双囚木耗浅；秋相坎同比足，休艮浅克、双死木微耗，C/P依谨慎旧财；冬旺坎同比足、囚艮浅克、双相木实际中尾耗，C/P，不能把原有进账等同厚利润。

## 六维及古据

- 《梅花易数》345–352、357–358、360、367，静坎及本坎北方水边、舟运流通、鱼盐酒货。原有货运、交收、水货等已知工作与真实客户为主要财源，原与本坎比和，原有流通伙伴依工作量、资源、交付、费用和报酬协作，旺相有力、休普通、囚死薄，非外来生体或额外赠财。
- 《梅花易数》405–408、411、418–420、428、510，体互艮东北山林田土、场地、土石材料，直接克原坎，夏相及季土旺艮对弱坎来克有力，真实场地材料及工作交付责任要核，辰未戌丑月日参真实阻项。秋休艮克浅，辰未戌丑土旺环境仅复核真实责任，非强损。春死冬囚艮克浅常规核。
- 《梅花易数》284–285、288、294、299、306，用互震东方经营动中、竹木茶货和工料供给；314–319、326–328、337，末巽东南工巧、竹木茶货与材料供应。两木分别直接受原坎水生泄为费用耗项，春旺耗重，夏休及冬相有实耗，合木气寅卯月日核真实中尾两段费用，实际同一支出只核一次；季土囚木耗浅及秋死木耗微，实际经济成本照账扣。盘无来生体或体克财，实际进账不等于净利，先扣实费、留日常及工作周转，再看余款。
- 《梅花易数》493–495、555–557、795–804，四直关系及财势旺衰；655、968支月日与环境；658、965方应。各月亥子水旺、申酉金旺相水月日准备、整理或办理既有工作，无同比独立财候。两木耗合一槽分阶段真实核，艮克核阻或风险复核，不把阻耗日期当确定损坏、亏损或事故。跨月须重核实际五态。
- 《周易正义》03坎:54–56，六三来之坎坎，险且枕，入于坎窞勿用，居出皆险无功，取现实原有工作先核承办能力和收支依据，不盲加资金或以爻义一概盖除原坎有力同比带来的原有进账条件。
