# 坤为地六二 · 财富财运规则审计（12月、5气组）

## 实盘与断财
主、互皆坤为地；六二变地水师。静上坤土始终为原体；本用下坤、上体互、下用互均直比原体；末下坎水为原体所克。求财篇555–557行比和财利快意、体克用有财、所制用卦气财候。前中比和是实际财源有条件相合，不把同气重复充作独立生入的多个财源。尾坎是体克用，非用克体；难制只表示取财力不足，不反断破财。按《梅花易数》493–495、795–798、804行区分首中末、体互紧、临终收束以及旺衰，六二古爻义辅以循实正当的处理。

## 具体引源
- 梅花555–557：体克用有财及体用比和财利快意，得财气候与克体、己耗损候区分。本盘无直接克体或体生用边，故不得从难收收入断既有财物已损。比和没有本篇专列的财日规则。
- 梅花131、134：坤地、土、米谷、布帛等既有实物类; 坎水；《说卦》09.07:21–22坎陷，末坎受体克，用于现实取款关节是否能解决，不凭孤象指认为欺诈、事故、支出既成；原坤及本互同气，不误引497行坤生体。
- 《周易正义》简校本01坤40–45：六二「直方大，不习无不利」；注居中得正、任其自然而成，疏释正直、方安、厚载以及质与兴动相符。借其已有实际正当财源与能力相副之理，不直接由爻辞承诺任何收益。
- 全文与简断均分别判断财务倾向及进账，前后仍明确实际收款条件、真实支出、净得益的差别，不假设财源和确定事件。
