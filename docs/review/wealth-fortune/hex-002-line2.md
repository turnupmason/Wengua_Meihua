# 坤为地六二 · 财富财运 v2 规则审计（12月、5气组）

## 盘面、财势、聚财及取候
主、互均坤为地；六二变地水师。原体静上坤土，本用下坤、上体互、下用互均直比原体，末下坎水受原体直接克。求财篇555–557行比和财利、体克用有财、所制财用卦气得财候。依493–495、795–798、804行分始、中、末及旺衰。尾坎取财难或易在原土能否实际制水，非坎反来克体。全盘无任何直接来克和体生用，难收与实际破财不同，实际仍须核真实费用。

## 行业、方位、人际与排雷
- 《梅花易数》252–259、265–266、275行坤为田野地土、乡里、仓库、谷帛及西南，人物乡人众人；求利「静中得财」「多中取利」，交易可取地土、五谷、布帛，春占不利。作为原体又见本、互的直接比和，取已经存在的稳定本职、日常经营、地土物质、仓储管理、实物供应，不推荐另开行业、西南方仅原有资源条件。乡人众人按已经熟悉的本地客源及共办事项类推，不指认真实身份。旺/相比和协作有力，休比力平，死/囚比意向尚可续却欠实际付款、承接力，须核职责支出与付款。无生体节点，不能套497行坤生体外援。
- 坎在尾下为受原体克之财，依据求财555–557行体克用有财。梅花345–346、357–358、367行水边、舟人、鱼盐酒货、北方；有现实北向物流、运输、水货、流通等事可作掌握财事类象，而非指定行业或外人送财，357–358亦明示恐有失陷，故不凭坎水一象保证得财。实际已有交付和收款关节时，取《说卦》09.07:21–22坎陷，核取财程序与条件，旺/相原土制财有力，休/死/囚土难制较费力，不反作坎来克土，不指认欺骗、给定亏损。四处直接关系均无来克/己耗，主要防预期所得误作可用资金、弱体取财能力不足。
- 《周易正义》01坤40–45行六二「直方大，不习无不利」、象曰直以方，王注居中得正、任地质，孔疏质与行相副。借意按照真实权责与能力办理已具收取条件的收入，不将古爻吉辞当作确定财利。
- 所得为真实收款扣实际承担费用，聚财能力随原体与尾可制财方向判断，留必要生活、周转或应急储备；不凭单盘定一生收入、数字、投资收益。
- 655、968行明确月日五行旺气，658、965方应明确坤西南、坎北及以体为主比和方应；方向结合实际节点角色，坎虽为财用并非外助。555–557原章比和财利不独立设财日；旺/相土有力制尾坎时，参亥子水气见财候，仍须实际财源与当时收取条件，不保证到账；弱土难制尾水不取候，只参土旺辰未戌丑月/日或巳午火土相环境准备。无来克或己泄，不附会破财日。
