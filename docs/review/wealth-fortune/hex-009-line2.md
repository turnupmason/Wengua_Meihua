# 风天小畜九二 · 财运六维逐月五气规则审计 v2

九二动下乾，静上巽木为原体。本风天小畜，互卦火泽睽（上离体互、下兑用互），末风火家人（下离为变用）。本乾金、用互兑金分别直接克原巽；中间体互离火和末变下离火均由原巽木直接生，为自己支付或工作耗用；非离火串克乾兑。与初九尾巽同气不同，九二没有生体、比和或体克财节点；两火耗实的月份，中段与后段均有须核的真实费用，不断出两个确定的额外事件。冬季原体相、所有来克泄耗均轻，C/W，余财可守而额外进账象弱，并非绝无收入。其他五气组阻耗主导D/W。不能凭爻辞吉或家人卦名说必有外来钱及贵人。

## 六维古据及适用情况

- 《梅花易数》555–557求财占，用克体无财、体生用财有损耗之忧；体克用或生体为见财、克体与体生用为破财候，但先审实际五行力量及事。493–495始中末、796–798体互较紧用互次、804旺相休囚死关系。四节点分别对原巽判断，不跨节点串生克，不以数量累加金额、利润或亏损。旺相原巽仍需实际承受支出；弱克/轻耗不推固定损失或损期。原体有余力维持已有收入不等于新增财；额外进项难不等于必然已亏。
- 原巽木为经营能力：315秀士、319工巧器物及竹木、327–328竹木茶货求利交易、337东南。依真实已在做的东南技术、工巧、木茶货流通或本职收入与既有客群；弱财势宜守熟业、原本具备领取条件的报酬，不据巽门倍利条推定利润，非巽生体不套499外来财之条。没有实际新财节点，也不凭其他方位推荐投资、改行或寻找新客；方向仅有现实对应业务的取象。
- 本乾直接克原巽：梅花504公事、门户、财宝损与尊长忧，222长者公门人、227金玉财宝、242西北。现代类推已经存在西北方向公事、管理审批、贵重货品经管、相关负责人要求与支付责任，须以真实办理要求及费用来判断；不指认具体长辈、负责人或贵人造成损财。用互兑同金来克，511古有口舌纷争及毁折，437–438译人、口，459西；现实西边报价、议价、付款说明、结算以及费用承担需照实核对，未存在则不硬推情节。秋双旺金直接克死巽重；季土双相金克囚巽实；春囚、夏死、冬休金来克薄，不硬定其他损候。不套496乾生体或503兑生体贵人财。
- 体互和变用均离火受原巽木生：376–380文人、文画书事及文书文字技术，388–390文书交易，398南方；依555–557体生用为耗己，现有南边文书经办、文件文字制作、交付技艺或原有材料与工作费用按实际承担。春两相离与夏两旺离各得原巽生而耗实，重在中途以及后续已有费用的区别；季土两休火、秋两囚火因原巽亦弱而耗薄，冬两死火耗微。没有离来克或生体关系，不引509文书忧来克或501离生体财，不能把同一费用自动判两笔或开销必已造成亏钱。
- 实际人际协作：按《周易正义》02小畜38–41九二「牵复吉」，象「牵复在中，亦不自失也」，古注二居乾中欲升巽五，五非止畜之极尚不闭固，牵连而复得中、不自失。借义实际有共同做的工作及伙伴资源时依真实分工、原履约条件、收款及费用承担力行事，非从九二吉辞就有实际外援或同气配合。盘没有生体比和，单凭身份、口头支持不纳入预计收入。
