# 泽山咸九三十二月求财规则审计

- 31泽山咸→44天风姤（互）→45泽地萃（变）。静上兑金为原体、下动艮土本用，下互巽木用互、上互乾金体互、尾下坤土变用。本艮、尾坤各直接生原兑，中下巽原兑克为自主财，中上乾同比。《梅花易数》493–495、555–557、796、804；四关系各对原体，不连锁；同土资源不当两笔报酬，乾同气非生体。无直接克耗。
- 兑西口舌译人饮食金类（437–441、445、449–451、459），艮东北山田土石材料场所（405–412、418–420、428、502生体），巽东南工巧木茶秀士（314–316、319、326–328、337），乾西北公门长者管理金玉贵货（222–223、227、233–236、242），坤西南田土仓储谷帛乡众（252–254、257、259、265–266、275、497生体）。行业方向限真实已有客户与资源。古《周易正义》04咸46–48九三咸其股、执其随、往吝，取进不能制动、退不能静处、志在随人，借财务自己掌握能力与现有资源，不盲从，不由古爻否定明确的生克。
- 655、658、965、968：前艮及尾坤同土分别生原兑，有力时gain use/changed_use合槽，夏相土真助死兑承接有限 conditional-gain 两角色合槽，辰未戌丑土月或问内土日核实际东北材料场所与西南田仓资源，换月重判，同项不重复。秋休土普通助照实，不设强财候。中巽可有力制取时 gain use_mutual，问期内寅卯日参东南木茶工艺已有报酬，进入木月按原兑囚、木旺另判。乾比和不独财；申酉金旺、辰未戌丑土旺金相prepare既有财路、资源与费用。
