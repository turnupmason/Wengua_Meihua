# 天雷无妄初九十二月求财规则审计

- 25天雷无妄→53风山渐（互）→12天地否（变）。上静乾金为原体，下动震本用；下互艮为用互、上互巽体互、末下坤为变用。本下震、体互上巽各受原乾直接克制为财；用互下艮和变下坤各直接生原乾。依据《梅花易数》493–495、555–557、796、804，四关系均与原体比较，不将艮或坤当作中间链，不把同款或同一种帮助多计。无来克或体生用耗。
- 乾西北公门长者管理金玉贵货（222–223、227、233–236、242），震东竹木动中求利（283–285、287、294、306），巽东南木茶工巧秀士（314–316、319、326–328、337），艮东北山田土石实物（405–412、418–420、428，生体502），坤西南田土仓储谷帛乡众（252–254、257、259、265–266、275，生体497）。方位行业均为已存在业务及资源的属性，非空断新客户。初九古《周易正义》03無妄38–40无妄往吉，行不犯妄而得志；借其正当诚实之义，依真正能够完成任务而行，非单凭爻辞判必有财。
- 655、658、965、968：木财有力合槽 use,body_mutual，仅问期内寅卯日参现实已有东方木货动务与东南木茶工艺报酬，若进入寅卯月须按金囚木旺重新计算。土生有力合槽 use_mutual,changed_use，强原体时gain，死金承接有限时conditional-gain，辰未戌丑土月或问期内土日参已有东北材料场所及西南田仓谷帛资源支持和所得，换月重判。秋休土普通生助不立独财候。申酉金旺和季土旺金相分别prepare，非独立财日。实收扣费用后核余钱，不保证金额或新进账。
