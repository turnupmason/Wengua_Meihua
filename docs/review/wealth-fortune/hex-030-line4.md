# 离为火九四：十二月求财规则审计

本离为火→互泽风大过（28）→变山火贲（22）。静下离火，本上离同比；体互下巽木生原离，用互上兑金受原离克，尾上艮土受原离火生。无外来克体。梅花493–495、555–557、795–804；周易正义03離44–46九四“突如其来如”，疏重急进失位，现实据能力及已有工作责任办理，非断现实火灾等事件。
