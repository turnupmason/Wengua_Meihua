# 泽雷随九五｜财富财运，十二月规则审计

## 盘式和四直接关系

本泽雷随（17），互风山渐（53），变震为雷（51）。上兑动，下震为静原体。本上兑金直接克原震，体互下艮土受原震克，用互上巽木及尾上震木分别与原震比和。无来生原体或原体生用。两木比和非直接生扶现金，分别核协作力量，不重记为两笔收入。原震旺相可制弱艮，为自取财；原震弱、艮土旺相或休气难制，为承办力不足，不作艮土来克。土秋兑相旺来克弱震为实阻，春夏冬弱金来克照实核，冬休兑为金旺环境风险复核，非强损判。

## 六维古据

- 《梅花易数》284–285、288、294、299、306：震本体及尾震东、经营活动、动中、竹木茶货。原有工作技能、实际需求的客户和真实报酬为财源；尾震同比为已有实际合作同向伙伴及客户，旺相比足、休普通、囚死弱。不凭卦定职业或推断具体客户来钱。
- 《梅花易数》405–408、411、418–420、428：中下艮东北山林田土、场地、土石材料与稳定事务。艮在此受原震克，非直接生体；有力可制时依已有客户、真实工作量及交付取得报酬，弱震难制则先守原有工作，不为未知材料需求增加成本。
- 《梅花易数》314–319、326–328、337：中巽东南工巧、材料供应、竹木茶果，与原震比和；尾震也是同比，双比支持真实合作，夏两普通比有现实相合条件，虽额外财难掌握判C/C。合作依明确分工、计价、成本及验收。无来生强贵人，不把口头交情当施财或两笔所得。
- 《梅花易数》437–438、441、449–451、459、511：本兑克体，西方口舌、饮食、货品交易；现实风险核西边已有工作沟通、交付、计价、费用承担及回收。土秋兑相旺来克弱体为实际阻碍；春夏囚死金来克浅，冬休金来克浅，按实际责任正常核查或环境复核，非硬断财损。不造欺诈、争吵或具体诉讼。无体生用泄耗，正常成本仍实收扣，留必要周转后计余款。
- 《梅花易数》493–495、555–557、795–804，体用财势、始中末与五态；655、968支月日气、658、965方应。春冬原震旺相可制艮，已有真实场地材料财参辰未戌丑日，跨月土旺重核；夏休震难制相艮，原有双比普通，寅卯木旺及亥子水气相体准备，不独立定财。土秋申酉金气核已有初段实阻，木旺水相体准备；冬休金克浅仅旺金环境风险复核，双同气无专财期。动态按真实问期计算，非必得财日。
- 《周易正义》02隨:44–46九五「孚于嘉，吉」，嘉善、中正随时、得诚信。现实财事重有据善正、按已约定的工作与给付诚实办理，而非陌生贵人或凭人关系得钱。
