# 天水讼六三，十二月令求财规则

本天水讼→互风火家人→变天风姤。静上乾，本坎受原乾生；体互上巽及尾下巽均受原体克，用互下离直接克原体。引梅花555–557求财五关系、财候损耗候，493–495、795–804始中末及衰旺，509离克体文书忧；说卦09.07:21–22坎陷、巽入，09.11:27–28巽进退不果；周易正义02訟40–43六三「食旧德，贞厉，终吉。或从王事无成」，王孔释保全旧日德禄位，柔顺不争，处危仍自谨、不敢先成王事。本问借守已有实际收入、在能力内取财，不硬以终吉许新财。
