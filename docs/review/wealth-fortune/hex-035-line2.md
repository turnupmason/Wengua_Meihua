# 火地晋六二｜财富财运十二月规则审计

本火地晋（35），互水山蹇（39），变火水未济（64）。下坤动，静上离火为体。本下坤、用互下艮分别受原离生泄；体互上坎与末变下坎各直接克原离。四负无比和、生体或原体克财，不因春夏体较有力即断有专财助；原工作收入维护，五气统一D/W，浅克耗不等于已损失。首中同土耗与中尾同水克均分真实阶段，同一现实支出或责任只计一次。

## 六维与古据
- 《梅花易数》376–380、388–390、398：原离南方文字文书、表达、明辨及技艺，借已有文案记录、教学技术服务等具体工作、客户和报价取原收入，非断固定职业。没有比和与生体，不凭交情断伙伴相助、外援或贵人，按真实任务与资源合作。
- 252–253、256、259–260、265–266、275：本坤西南乡里、田土、实物仓储；405–408、411、418–420、428：用互艮东北山林田土、场地及土石材料。两土分别直接受原离火生泄，季土旺重耗、夏相实际耗、秋休普通实际耗，辰未戌丑月日合槽核前中真实费用，同笔费用不可重复，非必亏损；春死冬囚耗微浅照实成本。
- 345–352、357–358、367、508：体互坎及尾坎北方水货、运输流通，分别直接来克离。秋相冬旺克体有力，合水气亥子月日核现实已有中后阶段的交付责任和阻处，同一现实责任不重复算；春休浅克仅亥子水旺环境风险复核，非强损；夏囚及季土死克浅微，正常核责任。
- 493–495、555–557、795–804：本中末四关系与旺衰求财；655、968、658、965：月日及方应。每月寅卯木旺火相、巳午火旺月日准备原有财路，盘无独立见财日。真正到账扣实费、保工作及日用周转，余款量力存。跨月重新核五态。
- 《周易正义》04晉36–38：六二晋如愁如、贞吉，受兹介福于其王母。古疏其德未昭仍履中正不改，守正获吉，借既知工作真实履责取信，不硬断母系、外赠财或覆盖四负盘理。
