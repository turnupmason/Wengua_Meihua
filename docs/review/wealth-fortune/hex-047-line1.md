# 泽水困初六｜财富财运十二月规则审计

本泽水困（47），互风火家人（37），变兑为泽（58）。下坎动，静上兑金为原体。本下坎水直接受原兑生泄为前段耗，用互下离火直接克原兑为中段阻，体互上巽木受原兑克为中段自财，尾下兑金与原兑同比和。无直接生体，不把同气伙伴当外馈。取财与耗、阻分开，弱克与弱耗依实际情况核，不断必损。

## 六维及古据
- 《梅花易数》437–438、441、445、449–451、459：原兑与尾兑西方沟通服务、饮食货品交易及金属器具，原技能和真实客户；尾兑与原兑同比，旺相伙伴配合有力、休普通、囚死薄，依实际工作、资源与费用协作。
- 345–352、357–358、360、367：本坎北方水边、水货及运输流通，直接受原兑生泄为前段耗；冬旺重耗、秋相实耗、春休普通实耗，亥子月日核真实运输流通及交收费用；夏囚季土死耗浅微照实核。
- 375–377、387–390、398、509：用互下离南方文字文书、技术及加工，直接克原兑，春相夏旺对弱兑克重，巳午月日核已有中段职责；季土休火浅克仅火旺环境复核，秋囚冬死克浅微按实际核。
- 315–319、327–328、337、555–557：体互上巽东南工艺、木竹茶货及商贸服务，受原兑克为中段主动财。季土秋原体有力克取囚死木财，问期内寅卯日参已有现实可控财，跨月重核（主动财尤其木旺月）；春夏冬难制，客源看实际承办力，不作外援。
- 493–495、555–557、795–804：四直关系及五气财势；655、968、658、965：月日环境及方应。每月辰未戌丑土旺金相、申酉金旺准备与办理旧财，同比不另设专财日。实收扣费用、留日用工作周转，有余量力存。
- 《周易正义》05困40–43：初六臀困于株木、入于幽谷、三岁不觌，古疏处困之初进不获拯、暂隐以待困解，借现实先处理已有阻处；不解作字面三年、疾病或保证所得。
