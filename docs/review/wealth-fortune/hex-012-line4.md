# 天地否九四：十二月求财规则审计

本天地否→互风山渐→变风地观（20）。静下坤土；本乾金受坤生为己耗，中体互艮与坤同土比和，用互巽及变用巽均直克坤。四直接关系独立，没有生体与体克用见财节点，不能把比和强弱说成独立财候。梅花493–495、555–557、795–804；周易正义02否41–44九四“有命无咎，畴离祉”，古义合宜命令及守正，只借确定实际职责和合理报酬。
