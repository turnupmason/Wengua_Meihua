# 地泽临初九十二月求财规则审计

- 19 地泽临→24 地雷复（互卦）→7 地水师，静上坤土为原体，本下兑金用、互下震木用互、互上坤土体互、变下坎水变用。四者均分别直接对原上坤：本兑受其生泄耗，互震直克，互坤同比，末坎受其克为财。不得以震木生某卦的间接链代替，亦不得将独立节点算成数笔钱。依据《梅花易数》493–495、555–557、796、804。
- 坤西南田土仓储谷帛静中之利，252–254、257、259、265–266、275；兑西口译人饮食金类交易，437–441、445、449–451、459；震东竹木草木动中求利、来克503–506中之506，283–285、287、294、306；坎北舟人鱼盐水货流通，345–346、350–352、356–358、367。只据已存在的客户、资源及收付条件说明方向，不虚构事件、人事、固定金额。
- 《周易正义》03臨32–35初九咸临、感应而志行正。用于现实依约筹措费用或争取收入，不以吉辞覆盖原体衰弱。支月日依据655、658、965、968。实际耗金申酉月或问期内金日核支出，震木克重寅卯木月或问内木日核中段事项；可取坎财只在所问月原坤适强才立问期内亥子日，跨亥子月土囚水旺须重新判。火土原体准备候与具体收款区别。
