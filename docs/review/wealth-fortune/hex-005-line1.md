# 水天需初九 · 逐月第一爻六维规则审计（v2，以末版对象为准）

## 盘理及专项原典

原静体上坎水；本用下乾金直接生坎；互火泽睽上离为体互，受原坎克；下兑为用互，直接生坎；初阳变阴，下乾成巽，变水风井，下巽受原体水生而耗。所有作用均直接对原体，依据《梅花易数》493–495、795–804：始、中、末及体互紧于用互，辨月令旺衰。555–557【求财占第十】用生体有进益、体克用有财、体生用有损耗之忧、用克体无财且破财候、比和财利快意。本盘无来克，尾受体生是己耗，离难制是取财难，不指外来侵财。进账、耗失与扣除费用后的实际积蓄有别。

《周易正义》02需:32–35，初九「需于郊，利用恒，无咎」，王孔释远险保常，借到近财就是有现实收入条件宜正常办理，不用未到账的款支持额外安排，并非一概不进或单凭无咎必得财。

## 财源与角色、行业及方位证据

- 原坎体的经营特性：《梅花易数》134，346江湖舟人，357–358水边财、鱼盐货交易，367北。流通、水货、运输等行业类推均以现实已有业务为前提；体气不足宜守本职和已掌握的客户、流通能力，体旺相则能承财，不因体坎便声称实际职业或北方必得外财。
- 本乾生体：496有公门、金宝及尊长惠送之益；222公门人、老人长者；235–236交易及求利公门、金玉财；242西北。由此取西北机构、规范管理类本职收入、金玉货利、前辈或已有支付职责者为对应外援，金相旺及旺体可承时有利；囚死金只作已有潜在联系，不把位象当现实贵人或保证他给钱。
- 用互兑生体：503金玉饮食货利、朋友讲习；437–438译人、口悦、饮食，449–451求利与交易，459西方。《说卦》09.11:35–36兑口舌。客源联系西向、原有饮食、交流、翻译、表达服务等真实业务；兑来生时沟通可以帮助落实应得之财，若兑弱则实际支持薄，合作尚需核客户付款条件、责任成本，非因弱兑指出欺骗。
- 体互离受原坎克：555–557体克用有财；376–379文人、书事等，388–390文书财与交易、398南。501为离生体文书之喜，本处只借类象，主动凭自己的文字技艺、凭据与实际手续争取已有财利。弱水难克相旺火则财难取，并非离克体文书之忧；相旺水制囚死离可取、非外援。
- 尾巽受原坎生：315–319人物、进退不果、竹木工巧，327–328木茶山林类财货，337东南。此处作用是己耗而不是巽生体或受体克，不当作东南财源。若已有相关物料加工、服务修改或交付安排，先确定工作范围、追加费用及各方实际责任。强木受生耗重，弱木耗薄仍应按已有费用核实，不据物象推定真实消费或损失。
