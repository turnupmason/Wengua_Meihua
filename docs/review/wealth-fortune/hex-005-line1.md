# 水天需初九 · 逐月第一爻规则审计（12篇）

## 专项文献与盘理

- 《梅花易数》555–557【求财占第十】以静体为主、以用为财，生体有进益之喜、受体克为有财、体生用有损耗之忧、用克体无财、比和财利快意；得财候可参生体、受体克两类，破财候可参来克及受生两类。没有来克不保证没有耗泄，来财或进账也不等于净余。
- 《梅花易数》493–495、795–804以体为主，互为中，变为末；本用最紧，体互更紧于用互，所有作用均直接对静体。动为下乾、静为上坎，互火泽睽上离（体互）下兑（用互），初阳变阴，下巽，成水风井。乾兑金均生坎水，离火受坎水克，巽木受坎水生而使体耗。无来克，不从兑口舌断争执损失，不从巽木受生断遭人侵害。
- 《梅花易数》496、503：乾生体有公门、金宝、尊长惠送之益，兑生体有货利、朋友讲习等益。以现实财源是否已经存在为前提，乾不等于现实职位或某位给钱的人；兑口联系商议实际收入条件。《梅花易数》501论离生体文书喜，本盘是离受克；借离文书类象解释争取已知财利所需凭证与手续，非引用来生之财结论。《说卦》09.11:27–28、35–36巽进退不果、兑口舌。末巽受坎生，为原体自己的耗，并非直接克体；如已有尚待决定的支付责任，明其金额、必要条件与时间，不能假定现实中已经发生某笔支出。
- 《周易正义》简体02需:32–35，初九「需于郊，利用恒，无咎」，王弼注「居需之时，最远于难，能抑其进以远险待时，虽不应几，可以保常也」；正义释恒为常、远难待时；小象「不犯难行」「未失常」。因此无论财力强弱，宜依已有收入途径及实际可履行的条件办理，非一味禁止增收，不能以无咎判一定得财。
- 近期不设确定历日，按具体有力之生体或体克用财候、受体生之耗候作传统观察方向。已知财项为前提，木气耗候只用于核查支付或费用责任；死囚薄节点不强加候，旺火受弱水克难不取见财候。无需凭卦预测投资收益、支付金额或已发生事实。各月正文与简断将进益、净余及财力分别交代。
