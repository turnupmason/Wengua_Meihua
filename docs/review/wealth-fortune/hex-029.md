# hex-029 · 六动爻三十组求财规则审计

## 坎为水初六｜财富财运，十二月规则审计

## 盘式与四直接关系

本坎为水（29），互山雷颐（27），变水泽节（60）。下坎动，上坎为原静体。原坎与本下坎比和；体互上艮土直接克原坎，用互下震木直接受原坎水生泄，尾变下兑金直接生原坎。始、中、尾各作用单独对原体判定，无原体克财。春休坎同比普通、旺震重耗、死艮浅克、囚兑弱助；夏囚水同比薄，相艮实阻、休震实耗、死兑弱助；季土死坎与旺艮阻重、囚震浅耗而相兑后段有力生扶，整体求财及进账C/C，不能把后助抵消中阻；秋相坎同气有力、休艮克浅、死震耗微、旺兑生扶有力；冬旺坎同比强，囚艮克浅、相震实耗、休兑普通生扶，实际净余仍需防真实费用。

## 六维及古据

- 《梅花易数》345–352、357–358、360、367，本及原坎北方水边、舟运流通、鱼盐酒货，现实已有货运、交收、水货及涉水业务技能和客户为主要收入，本坎同比在真实伙伴承办力下协作。旺相有力、休普通、囚死薄，不认作生体贵人或额外进款。共同任务确认资源、工作量、费用和报酬。
- 《梅花易数》405–408、411、418–420、428、510，体互艮东北山林田土、场地、土石材料，直接克原坎。夏相艮及季土旺艮对弱坎来克有力，真实场地、山林材料、工作交付责任重核。秋休土来克相坎浅，只辰未戌丑土旺环境风险复核，春死冬囚艮来克浅常规核实际责任，不另立强损候。
- 《梅花易数》284–285、288、294、299、306与555–557，用互震东方经营动中、竹木茶货和工料供给，直接受原坎生为费用耗项。春旺震耗重、夏休震受囚坎生与冬相震受旺坎生有实耗，寅卯月日核实际已有活动、材料和业务支出，不硬断已经亏损。季土囚震浅耗，秋死震微耗，照实核常规成本。
- 《梅花易数》437–438、441、445、449–451、459、503，尾兑西方口悦沟通、饮食货品、金玉器物，直接生原坎，季土相及秋旺兑有力生助，已知沟通服务、食货器物资源可帮助原事业，申酉月日参考实际外援；季土原坎死与中旺艮重阻，后助不能抹除前面实际责任，也不保证新增收入。冬休兑普通助用conditional-gain申酉月日观察已有外援条件，非强财。春囚夏死兑仅弱助照实核，不立外援专候。盘无自身克财，不凭生助断特定贵人或真实到账。
- 《梅花易数》493–495、555–557、795–804，体用四直作用及五态；655、968支月日与环境；658、965方应。亥子水旺环境整理、准备及办理已有工作各月适用；春夏申酉金旺相体环境准备，非弱兑额外财候；季土、秋、冬已用申酉月日为真实助益或观察槽，不以同气重复另立准备。按问期和已知事件参，换月重核。实收扣实际费用，留必要日用和工作周转，余款量力储备。
- 《周易正义》03坎:48–50，初六习坎入于坎窞，处重险复入险底，无应援失道难以自济，借古义核原工作承办能力、交付责任和收支依据，不硬断现实事件，不以爻义覆盖尾有力生助或原有工作机会。
