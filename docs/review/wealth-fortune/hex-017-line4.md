# 泽雷随九四｜财富财运，十二月规则审计

## 盘式及四条关系

本泽雷随（17），互风山渐（53），变水雷屯（3）。上兑动，下震为原静体。原震分别受本上兑金直接克、克体互下艮土、与用互上巽比和、受末上坎水生。原体贯始中末；秋初兑旺克死震而尾相坎生，先阻后助，不因尾生抹除初段实阻。春冬旺相木可制弱艮取财，且有同气协作及尾生助；本兑弱克仍按事实核，冬休金须金旺环境风险复核，非强损。无原震生泄关系，不因卦象虚构费用或已损，但正常支用仍实扣。

## 古籍证据和六维映射

- 《梅花易数》284–285、288、294、299、306，原震东方、起动、动中、木竹茶货。现实原技能及已有客户组织、经营活动或供货报酬。体旺相承接力较好，休囚死先量力，不凭象推职业或保证客户出现。
- 《梅花易数》405–408、411、418–420、428，艮东北山林田土、场地、土石及静中事务。在此由原震克，非艮生体。木旺相能够克土可凭实际技能和交付取得场地服务、材料供给等有据报酬；弱震难制土不预判损失。结合已有客户与实际用量、日期、价格、验收和应收条件核清。
- 《梅花易数》314–319、326–328、337，巽东南工巧、材料供应、竹木茶果；与原震比和，已有真需求的客户和伙伴同气协作。强比有力、普通比维持、弱比力薄；比和非他人直接给财。共同工作职责、费用、报酬按实际分配。
- 《梅花易数》500、134、346、357–358、367，坎直接生原震，北方、水边、水货及运输流通等实际资源援手；旺相生力，休普通条件；囚死薄。秋尾相坎生助有力但首兑旺克重，为有据尾助财，需已知资源实际兑现，不作必得财或抹消初阻。
- 《梅花易数》511、437–438、441、449–451、459，兑克原震古有西方、口舌、饮食货品之忧及交易争竞之象。现实核西边沟通服务、饮食及货品交易、价款和交付责任。土秋兑相旺来克弱体，有实阻；春夏兑囚死克浅照实核，冬休兑来克浅仅旺金环境风险复核，不凭兑象编纠纷、欺诈或既成财损。无体生用泄耗关系，实收仍须扣日常费用、留周转后储备。
- 《梅花易数》493–495、555–557、795–804，始中末和体用财势及旺衰；655、968支月日，658、965方应。旺相原震可制艮财，参辰未戌丑日，跨月土旺重核；尾旺坎资源实财参亥子月日，休坎普通条件，秋相坎先阻后援有据尾助财候，弱水不立强财。原震弱期寅卯旺木与亥子水相体环境为准备，非新财；秋水环境已在尾助财槽、不重复准备。土秋首相旺兑阻参申酉月日，冬休金弱克仅申酉旺金环境复核，不作强损。巽比未独立财候。动态应期依据真实问期，不保证收款。
- 《周易正义》02隨:40–43，九四「随有获，贞凶。有孚在道以明，何咎」古义有所获仍须循正、以孚明功，现实按既有真实客户需求、明确分工和报酬凭据处理事情，非必来财或确定违约事件。
