# 地水师六四财富财运：十二月与五组规则
六四动上，原体为静下坎水；本用为动上坤土，直接克原体。互卦地雷复，下震木体互由原坎水生、属己耗，上坤土用互直接克原坎。六四变阳，末雷水解，上震木为变用由原坎水生、属己耗。阶段7/24/40。四直接关系是两来克、两己耗，没有生体、比和、体克用，不能串联。
- 《梅花易数》493–495、795–798、804及555–557：两坤来克、两震体生用分别按实际气力及阶段。始中坤旺相时重点办理旧财限制、场地真实费用；中尾震旺相为实际向外消耗，核中段与收尾各自成本。秋两弱克两弱耗不判重损，但无有力进财关系，新增仍偏难；五气均D/W，与同类无正财关系一致。无财不等于已损。
- 坎342–346、357–358、367：北方、舟人、水边鱼盐酒货和流通，对原体财路，现实已有工作、货运物流或水货供应客户才按真实交收和付款维护。没有强生体、比和或有力体克财，不从合作意愿推有人送钱；合作据真实能力、收入及费用分配。
- 坤252–259、275、505：西南、田土、实物仓库、乡人，克体古有田土忧。现实已有仓场地费用、旧工作或给付条件才核，前中均受制时分别明确事项及支付责任。弱克仅查真实事项，不断重损。震283–288、294、306东方、动、木竹茶货，仅作体生用的支出类别，实际已有中间/收尾材料采购、送货、外出事项等才适用，不引震克体506。
- 《周易正义》02師42–45「师左次，无咎」「未失常也」：王注孔疏得位无应宜止、守不失常；财事量力守原有工作，不盼强增财，不从爻义认定实际亏损。
- 655、968：春冬两震木同时旺相且受原坎生，现实有中尾费用可合并同木drain两个真实角色（body_mutual、changed_use），事件按实际阶段分核，参寅卯木月或问期内木日。季土和夏两坤土旺相直克时合并obstruction为use/use_mutual，辰未戌丑土月日参前中真实限制；弱克/弱泄均不硬设强候。申酉金旺水相、亥子水旺均为原坎准备环境而非财日。965方应方向仅限现实相关事务。
