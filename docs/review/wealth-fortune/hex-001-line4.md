# 乾九四求财逐月稿 v2 与顾问白话规则审计（十二篇、五气五组）

九四动在上，静下乾为原体，动上乾作财；体互在下为乾、用互在上为乾，各与原体同比；九四化阴令上乾变巽，末风天小畜（1/1/9）。末巽木受原静乾金克制。三同比一体克用，所有直接关系均相对于静下原乾，不重设互/变体。

- 《梅花易数》493–495、795–798、804：本为首、互为中、变为末，体互较密；同党俱衰不当强援。原乾囚/死及休，尾旺/休及相巽难以由体制财；金相旺时相对衰巽受体克可取。555–557【求财占】比和财利快意，体克用有财且有见财之气，实际旺衰决定是否能够作有力财候，无财与损财不同。
- 乾方西北221、242；金玉、公门财235–236；222官贵、公门人、老人长者。三乾同气用于现实已有的正规工作、规范管理、金属贵货等收入，以及已存在的制度付款/采购单位与重品质的货物需求方；既有资深人、实际负责收入的人员、同业合作旺相利共同办事而谈得拢/愿配合未必有财力，衰同气只保已经存在的财路。盘无直接生体，不套496乾生体贵人送钱。
- 巽东南314、337，木竹工巧319、山林及木竹茶货求利交易327–328、进退不果316及《说卦》09.11:27–28。其为体所克的末财，方位与类别仅在现实有相应财源时作对象属性，不冒称方位天然吉或将难制说成巽来克体，不借利市三倍猜收益倍数。965【方应】比和为宜与克/生耗的类型区分。
- 《周易正义》01乾35–37九四「或跃在渊，无咎」，王注乾道革之时、进退无常、持疑犹豫、疑以为虑，孔疏欲进未即进，以時未可行而务进有咎为戒。用于已有财务选择按实际能力审慎进退，非每遇有利盘就另找新财、扩大投资。四关系无来克、体生用；未收不足非已损，净余照实收减实际成本，留足生活周转应急。
- 655、968木旺寅卯月日、金旺申酉月日；555–557有力尾巽体克用取木气见财候（已有尾部财事项才参问期中的寅卯日，问及寅卯月另核当时原体能否制财），非固定到账。末巽难制无有效财候，只用原乾旺气申酉月日准备、整理、核实际收入和成本。同比不另定财期，不设没有实际损耗节点的损日。
