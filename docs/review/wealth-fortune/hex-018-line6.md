# 山风蛊上九：十二月求财规则审计

本山风蛊→互雷泽归妹→变地风升（46）。静下巽木，本上艮土、变上坤土分别受巽克为财，中用互上震同比，中体互兑金直克巽。无直接来生及体生用。双土财按始末分别说明，土气合槽，不等两笔必得所得。梅花493–495、555–557、795–804；周易正义03蠱52–55上九“不事王侯，高尚其事”，古义志不累于职位，借现实财务以真实工作与报酬为据，不预测岗位或贵人身份。
