# 天火同人上九十二月求财规则审计

## 固定盘与审稿依据

- 13 天火同人 → 44 天风姤（互卦）→ 49 泽火革；下静离火原体，上动乾金本用，互下巽木为体互、互上乾金为用互，上兑金为变用。
- 本用乾、用互乾、变用兑三者各自直接受原离克（体克用为财）；体互巽木自身直接生原离。中段上下互各自对原静体判，不用巽生火之链推导后兑。无用克体、体生用，弱取财不等于已损。关系据《梅花易数》493–495、555–557、796、804。
- 离南文人书文文画炉冶，374–377、388–390、398；乾西北公门权责金玉贵货，220–222、235–236、242；巽东南工巧茶木及生体山林茶果利，313–319、326–328、337、499；兑西口译人饮食金类交易，437–441、445、449–451、459。只核现实既有业务、客群、伙伴，不凭卦虚构身份、新财或专一行业。上九《周易正义》02同人57–60“同人于郊，无悔”“志未得也”，是远争而求同未得；并非逢人会共同致富、实际争讼或已亏。
- 655、658、965、968：支月日和方应。实际可制的金财于问期内申酉日参照，若问期转入申酉月，须重新按离囚金旺判。三金合一槽（use,use_mutual,changed_use），不是三笔财；巽旺/相生分别实际/条件木财，寅卯月或问内木日参照，换月重核。寅卯木旺火相、巳午火旺月日为原体准备，不承诺到账日期。正文首段明确进财及净余，论现实旧客、行业和方向、能力及资源、成本与留存。
