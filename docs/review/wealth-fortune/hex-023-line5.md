# 山地剥六五｜财富财运，十二月规则审计

## 盘式与四直接关系

本山地剥（23），互坤为地（2），变风地观（20）。上艮动，下坤为原静体。原坤分别与本上艮、体互下坤、用互上坤比和，尾变上巽木直接克原坤。三土同比各有位置，按已有实际工作、人际协作和客户资源来核，不当成三笔额外收入。无直接生体、体克财或体生用耗财关系；常规成本照实际核。春冬旺相巽有力克弱土、三弱比难抵；夏相土及季旺土三比有力，休囚巽来克浅；秋休土同比普通、死巽克甚浅，非强财。

## 六维及古据

- 《梅花易数》251–254、259、265–266、275，原坤西南乡里、田土、谷帛实物、仓库，已有工作与客户实际服务、交付、合同和报酬为原财；两互坤与原坤分别同土相合，为现实仓储、实物供给、地方客户和伙伴已有协作。旺相有力、休普通、囚死薄，不把同比当来生体。
- 《梅花易数》405–408、411、418–420、428，本艮东北山林田土、场地、土石材料，与原坤比和；场地服务、材料或山林原有客户与伙伴按真实需求、可用资源、工作量、责任、费用及报酬协作。各同比非直接生体或体克财，不能视为另有贵人送钱或同一收入重复。
- 《梅花易数》314–319、326–328、337、507，尾巽主东南工巧、竹木茶货和材料供给，在本盘直接克原坤土，春冬旺相巽有力克死囚坤，已有相关供料、加工、验收、交付及付款责任要重点核，非凭卦断具体损财事件；夏木休，季土木囚，秋木死，来克浅，正常核实际责任。盘无原体生泄，正常材料、场地、设备等成本仍从实收扣，留必要日用及工作周转，余款积存。
- 《梅花易数》493–495、555–557、795–804，四直接关系及财势旺衰；655、968支月日与五气，658、965方应。春冬尾旺相巽有实际责任参寅卯月日核阻，夏休巽克浅仅寅卯木旺环境复核责任，非强损，季土囚和秋死巽常规核，不立额外风险日；各月辰未戌丑土旺与巳午火相体环境整理、准备或办理旧财，三土比和不另定专门财候。遇新月令核旺衰，实际问期与真实责任落槽。
- 《周易正义》03剝:45–47，六五贯鱼，以宫人宠，待众阴之宠不害正事始无尤无不利，借古义于共同工作规定真实任务、角色、费用和报酬范围，不由古文推断现实宫廷、亲密关系或人事事件。
