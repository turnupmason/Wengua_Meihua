# 山地剥初六｜财富财运，十二月规则审计

## 盘式与四直接关系

本山地剥（23），互坤为地（2），变山雷颐（27）。下坤动，上艮为原静体。原艮分别与本下坤、体互上坤、用互下坤比和，尾变下震木直接克艮。三坤同气各有位置，核原有业务、人际和客户配合，不将三个比和当三笔钱或外人直接生助。无体克用、直接来生体或体生用耗财关系；已有正常成本须实扣。春冬艮弱，旺相震尾来克有力；夏土同气旺相，休囚震克浅；秋三休坤普通协作、死震克浅，不能凭相合当强财。

## 六维及古据

- 《梅花易数》405–408、411、418–420、428，原艮东北、山林田土、场地土石与静中事务。现实原有技能及场地、实物、山林等客户需求为原有工作财源。自身有力且同气协作可办旧财，不推断客观职业、额外投资或陌生财路。
- 《梅花易数》251–254、259、265–266、275，坤西南、乡人田土、谷帛实物和仓库。三个坤分别同比原艮，现实已有仓储、实物供给、地方业者及客户的协作。旺相同比有力、休普通、囚死薄；已有合作按真实工作量、交付、费用与报酬分别核，非生体，亦不确定存在贵人送财。与原体同气非财对象，不能另设三个进财期或重复收费。
- 《梅花易数》284–285、288、294、299、306、506，尾震东方、起动动中、经营活动及竹木茶货，在本盘直接克原艮土，为已有活动、材料、供给以及交付责任的阻碍。春冬旺相震来克弱艮有力，核真实事；夏休或季土囚及秋死震来克浅，按实际责任正常核，夏弱木仅木旺日月环境风险复核，不硬断具体纠纷、事故或已损。无直接体生用泄财，正常成本从实收扣，留日用和周转后计余款。
- 《梅花易数》493–495、555–557、795–804，体用四关系及财势五态；655、968支月日气，658、965方应。春冬尾旺相震有实际责任参寅卯月日核阻，辰未戌丑土旺及巳午火相体环境准备；夏相艮及三相坤、季土旺艮及三旺坤和秋休艮及三休坤，辰未戌丑旺土及巳午火相体环境办理原有财源及准备，非强财期。夏休震来克浅，寅卯木旺环境复核具体责任，非强损。季土囚震、秋死震只常规核。动态依实际问期计算，不因比和定专门收款日。
- 《周易正义》03剝:30–33，初六「剥床以足，蔑贞凶」，床足先受侵削、剥自下起。引爻义用于现实财务维护原有客户、交付及收付基础，不推断真实床损、具体破财事或一概抹去月令有力的协作。
