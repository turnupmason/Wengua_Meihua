# 乾为天初九求财逐月稿 v2 规则审计（十二篇、五气五组）

初九动，主乾为天、互乾为天、变天风姤。原静上乾金，动下乾金为财；上体互乾金、下用互乾金均分别对原静体比和，末变用巽木受原体金克。四直接关系为三同比、一体克用，不重设互变体，不以月令本身增加克耗节点。v2 新稿保持前版专业判码，新增财利、方位人群、合作、排雷、守财、具体支月/日，全部以实盘作用结合原典。

- 《梅花易数》493–495、795–798、804：本初、二互中、变终，体互较紧；同党多而皆衰非旺助，原体旺相可克相对衰木，春囚及夏死金制旺/休木困难，冬休金亦不易制相木。555–557求财占：比和财利快意；体克用有财，须能制取方用为有力见财候；未得财不自动成损财。
- 乾西北（221、242）、金玉贵货及公门财（235–236）、官贵、公门人、老人长者（222）：乾本用、两互比体，同气有力可解释既有财源、专业资格及同业/权责人员协同；乾弱只能保原有相合，互助尚不一定兑现。管理工作、本职报酬是原典尊位公门财的现代类推，不能保证真实职业。无乾直接生体结构，不套496为贵人送钱；只有相应现实人物与财源方可用。
- 巽东南（314、337）、木香竹木工巧（319）、木竹茶货及山林交易（327–328）、进退不果（316）：巽是末段原乾要克的财，用于既有相关收入或可收款事项，不是方位天然必吉，也不是来克原体的损财。体弱时取财困难，体强时原已存在的相关财事可较有把握解决实际收取条件。无巽生体，不套499馈财，不根据“利市三倍”推实得倍数。
- 《周易正义》01乾26–28初九「潜龙勿用」、孔疏引张氏以道未可行，阳处下。先有真实能力才办事，不因有财象便承担超出现时财力的支出。
- 《梅花易数》655、968：寅卯月日木气旺，申酉月日金旺。555–557明确体克用得财卦气；有力末巽才参问期内寅卯日作已知末财观察候，跨寅卯月须重核当时原体制财能力，非必收款日。末巽难制且仅三比薄时不设专门见财候；只参申酉月或问期内申酉日的原乾旺相环境复核收入条件、准备财事，不冒充求财应期。全盘无直接来克、体生用，不设破财候。
