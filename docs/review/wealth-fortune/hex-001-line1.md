# 乾为天初九求财逐月稿规则审计（12篇、五气5组）

## 实盘、原典与适用

初九动，主乾为天，互乾为天，变天风姤。原静上乾金，动下乾金为财用；上体互乾金、下用互乾金均分别对原静体比和，末变用巽木受原体金克。四直接作用是三同比与一我克；不重设互变体，不从季令另添卦节点。

- 《梅花易数》493–495先中末、体盛、比和及生克；555–557【求财占第十】体克用有财、比和财利快意；无财、破财须分。体克用卦气是见财候，单纯比和不另强设专属候。
- 同书795–798体用互变，体互较密；804体衰且无生体，虽然体党多而皆衰也不足为实益。春囚、夏死金无直接生体，末木比金旺不能按体克用名义径断实得；秋旺、季土相金制末衰木能力较有；冬休金同气基础仍有而力有限。
- 同书130乾为官贵、金宝、刚物，《说卦》09.07:21–22乾健，财源类推已存在的职责、财物及能力，不引496乾生体贵人财给予本同比盘。没有确认行业、人物、财物或具体收益。
- 《周易正义》01乾26–28初九「潜龙勿用」，孔疏引张氏「以道未可行」；阳处下，提醒根据现实际条件循序办事，不抵消旺相盘可取得财利。
- 《说卦》09.11:27–28巽进退、不果、近利市三倍。后段巽的象落实到已存在的财事如何议定和兑现；不是巽生原体，亦不引用巽生体得财之条、实际商事或收益倍数。
