# 山泽损九二｜财富财运十二月规则审计

本山泽损（41），互地雷复（24），变山雷颐（27）。下兑动，静上艮土为原体。本下兑金直接受原艮生泄为耗，用互下震及尾下震木分别直接克原艮；体互上坤土同原艮比和。无实际来生体与原体克财；同土原工作及伙伴为相合，依实际任务取酬，不作外援或独立财候。前耗及中后阻按阶段核，两个震对应同一现实责任勿重复算。

## 六维及古据
- 《梅花易数》405–408、411、418–420、428：静艮东北山林田土、场地、土石材料及固定服务；已有客户需要原技能、服务或材料，照确切工作及计价取酬。
- 252–253、256、259–260、265–266、275：体互坤西南乡里田土、实物仓储，与原艮同土相合，旺相伙伴有力、休普通、死囚薄；依已知真实资源、分工及实际成本协作。
- 437–438、441、445、449–451、459：本兑西方沟通服务、饮食货品交易、金属器具，直接受原艮生泄为前期耗。季土相金、秋旺金、冬休金有实耗，申酉月日核已有真实费用；春囚夏死耗浅微，照成本核，不断必亏。
- 283–285、287、294、299、306、506：用互及尾震东方经营活动、竹木茶货及材料供应，两处直接来克艮。春旺、冬相对弱艮克强，寅卯月日核中后实际职责阻处；夏休木浅克仅木旺环境风险复核；季土囚秋死克浅微照真实职责核。同项现实责任不重复作损。
- 493–495、555–557、795–804：四关系旺衰及求财；655、968、658、965月日旺相环境与方应。各月巳午火旺土相、辰未戌丑土旺环境准备及办理旧财，不因比和虚立独立财日。实收扣实际支出、留必要周转及日用，有余量力存。
- 《周易正义》04損46–49：九二利贞、征凶、弗损益之，古义履中守正、损益节适，借现实按原有资源和真实成本做已有工作，不以爻义覆盖当月克耗。
