# 山水蒙 · 六三动 · 规则审计（五气十二月）
本卦山水蒙，动下坎水为财、静上艮土为己；中互地雷复，上体互坤土、下用互震木；六三为阴，动变阳，下坎成巽，末山风蛊，下巽木为变用。四直接作用对原艮：本用艮克坎，体互坤比和，用互震来克，尾巽来克。全盘无生体及体生用的直接关系，生克不串联，末来克与己生耗分开。原艮月令越强则制财及承受来克越有力，中间及末段有来克和强弱不同，不能完全以本财可制断全局。

## 逐项古籍与解释
- 《梅花易数》555–557《求财占第十》：「体克用，有财；用克体，无财。体生用，财有损耗之忧；用生体，财有进益之喜。体用比和，财利快意。」体克用及生体为见财候，来克及体生用为破财候。此盘本克财依据，体乏力时财难实取，双来克风险与体生泄耗区分；无现实破财事实推断。比和虽有财利之意，不独立取日期候。
- 493–495始中末、796–798本用最紧、体互较紧于用互及变末、804体旺而克体卦衰可减轻损害，衰体无生体而同气党衰薄不构成实扶。此盘逐阶段判，本财控制力度、体互同气能否承接、中震来克、尾巽来克分别判定。夏相土虽有力制囚水，两个休木在用互及变位连续来克，故总财势为有财可争取而后续有条件，进账保持明；季土原体旺，二木均囚，影响轻，故定财势有利。春冬弱艮难制坎，中尾来克力实，故困难；秋休艮难制相坎，土互同气平承，二死木来克微，保守维持而取财受限。
- 506–507震巽来克原义：震有虚惊、山林之失，巽有山林生忧。《说卦》09.07:21–22震动、坤顺、艮止、坎陷；09.11:25–26震决躁、27–28巽进退不果。震来克联系已知实际行动或条件改变，巽末克联系已存在的尚待决定财务责任。原本与林木相关财事方参来克山林忧象。不从坎受克断坎生体水货财利，也不凭任何类象推断新行业、实际亏损、欺骗或给钱人。
- 《周易正义》01蒙49–52六三「见金夫，不有躬，无攸利」，王弼注、孔颖达疏以金夫为上九刚阳，六三自往求而不守其躬；小象「行不顺也」。古释并非在说求财者会遇富人或诱骗之事。本文借其失守之戒，不因所求的财看起来好而偏离已知真实财务要求及本人实际可承担的范围，不套未婚或男女道德劝告。
- 时段只为真实已知财事所参传统卦气，非已计算具体公历兑现日。来克气候来自有力的震巽作用；弱体难制本坎不设见财候。盘里无直接己耗，不代表现实无需实际开销。
