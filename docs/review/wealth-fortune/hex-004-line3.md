# 山水蒙 · 六三动 · 规则审计（v2 五气十二月）
本山水蒙，动下坎水为财、静上艮土为己；互地雷复，上体互坤土、下用互震木；六三阴动变阳，下坎成巽，末山风蛊，下巽木为变用。四直接作用对原艮：本艮克坎，体互坤比和，用互震来克，尾巽来克。无生体及体生用直接关系。不按互变重新定体，不以震巽间接生克、节点票数判断。与初六尾兑己耗、九二尾坤同气不同，此盘中末皆来克，力度依原体与各节点旺衰。

## 六维证据及具体适用
- 《梅花易数》555–557求财章「以体为主，以用为财」，体克用有财、用克体无财，体生用耗、用生体进益、比和财利。体克及生体为见财候，来克及体生用为破财候；无财非已亏损，来克也不作实际损失确证。493–495、796–798、804原体、本用最紧与体互用互及末位强弱；655、968月日五气，658、965方应参实际已有财事，方位不作为现实人物认定或出行路线。此盘按本制财之力、体互同气之承接、中震及末巽来克强弱逐个判。
- 原体艮土：梅花406–408、418–420山田土物、守静、山林田土财类与东北象；用在经营方式为稳妥经理现实已知事务、场地和实物管理或稳定本职，非声称用户从事某行业。原艮弱时维持原有收入优先；旺相有力可主动取现实已有财，不等贵人馈送。
- 本用坎：梅花345–346、357–358北方、水边鱼盐酒货、江湖舟人等类象；现代以已有水货、水产食品、运输配送与流通行业、对应客户和北方已有渠道类推。坎在本用受原艮克，是自己有力能取得的财，不引用500坎生体之助财。若原艮死囚休难制休旺相水，只作有基础可争取的潜在方向，不虚构客户身份、特定区域赚钱、改行业及犯罪事实；土旺夏相制弱水可依现实收入条件主动取得。
- 体互坤：梅花252–253、259、265–266西南、乡人众人、仓库田土和货物等类象，体互坤与艮直接同比，土旺或相可示原有协作、分担经管业务有力，秋休平比，春死冬囚相合意向但助力弱。只有现有伙伴、共同资源、货物与账务才能借坤为合作条件，分明真实分工成本收入，不将比和换作497来生贵人送财。
- 用互震：梅花283–285东方、起动虚惊；506来克主虚惊、山林之失，周易正义《说卦》09.07:21–22震动，09.11:25–26震决躁。风木巽：梅花316进退不果、319木竹工巧、327–328山林木茶货、337东南、507来克有山林生忧。此中旺相震克与末旺相巽克是实压力方向，已有东方行动、林木、条件调整等及东南木茶材料、工巧和交付反复决定事项应核实际成本及承担；不得从巽孤象断他人欺骗或受生己耗。土旺及夏相、秋休体所见弱木克较轻，按实际变动作核查，不硬定重损。
- 《周易正义》01蒙49–52六三「见金夫，不有躬，无攸利」，王弼注、孔颖达疏金夫指上九刚阳而非富人，六三自往求而失其身守；小象「行不顺也」。仅用于提醒不要因眼前有好处的想象，超出本人现有现实能力承担费用、责任、工作要求；不据原婚姻语境推断财富给予人或恶意诱骗。
- 聚财：春冬财难制，中末强克实压，余财偏薄宜守现有；秋本制财乏力，但土平比与两死木弱克，无直接己耗，留财程度一般，多进账仍条件；土旺制财有力，中比旺、囚木来克薄，能取并可承已有支付，较能留下；夏相土制财有力，但中末两个休木虽轻在两阶段延续来克，整体有进且待条件，需把款到账及真实费用分开核算。守真实收入与支出、留基本周转，按实际余款积累。无体生用不等于现实零成本，不预测确定金额或长期财富。
