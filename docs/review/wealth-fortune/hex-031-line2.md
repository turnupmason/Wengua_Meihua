# 泽山咸六二十二月求财规则审计

- 31泽山咸→44天风姤（互）→28泽风大过（变）。下动艮为本用、上静兑原体；下互巽为用互、上互乾为体互，变下巽为变用。本下艮土生原兑，两处巽木各受原兑直接克为自主财，乾金与兑比和；《梅花易数》493–495、555–557、796、804四作用分别对原体，不连锁，不以两个巽机械计两笔收入。不见直接克耗。
- 兑西口舌译人饮食金类（437–441、445、449–451、459），艮东北山田土石实物（405–412、418–420、428、502生体），巽东南工巧木茶秀士（314–316、319、326–328、337），乾西北公门长者管理金玉贵货（222–223、227、233–236、242）；行业方位均以真实已存在的客户和工作、资源为条件。六二《周易正义》04咸42–45咸其腓，凶居吉，取躁以相感凶、不躁静居吉，引申财务守已有能力不躁进，不推翻明确财理。
- 655、658、965、968：本下艮土强生为gain use，夏相艮真助但死兑承接有限为conditional-gain，辰未戌丑土月或问内土日核已有东北真实材料场所资源，跨月重判；秋普通助不另立财期。两巽由原强兑克有力时 gain use_mutual/changed_use 合槽，问期内寅卯日参实际东南木茶工艺中尾报酬，同款只记一次，进入木月按金囚木旺重判。乾同比无专财期，申酉金旺与辰未戌丑土旺金相安排prepare原有财路及工作。
