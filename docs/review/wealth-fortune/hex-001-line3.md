# 乾为天九三求财逐月稿规则审计（12篇、五气5组）

静上乾做原静体、动下乾做财用；上体互下用互均乾，分别与原体比和；九三转阴使下乾变兑金，末变天泽履（1/1/10），兑金和原乾仍然同气。四直接作用全是比和，无独立体生用、用克体、体克用、用生体，不重设财体。

- 《梅花易数》555–557：比和财利快意，求财与破财专门应期来自生体、体克用及克体、体生用两组。四比无专条见财或损候，不能以同金另立具体日期；不把进款未多作实际损钱。
- 同书493–495、795–798、804：本用为初，二互为中，变为末均直接论原体；同党虽多皆衰仍不利，囚气四比判C/weak为有财路但新增进账偏薄，死气四比判D/weak为财利难以增长（非已损财），春/夏不能把四比叠为强财；季土/秋金相旺同比承接得力；冬金休条件仍相合但财力平。
- 《周易正义》01乾32–34九三「君子终日乾乾，夕惕若厉，无咎」，王注居上不骄在下不忧、因时而惕、不失其几，孔疏勉力不止息而常怀忧惕、戒慎才得无咎。用此提醒现实已有收入责任、收款条件、实际费用，勤而有戒但不因勤慎逆反实际旺衰。
- 《说卦》09.07:21–22乾健、兑说悦；09.11:35–36兑口舌为言语之具。末兑同比时，实际已存在的收入商议、结算确认可从沟通相合取象；没有兑生体施财及兑克体口舌纷争关系，不借503、511写出朋友送财、毁折损财或确定争执。不臆断行业、贵人、数额。
