# 山泽损上九｜财富财运十二月规则审计

本山泽损（41），互地雷复（24），变地泽临（19）。上艮动，静下兑金为原体。本上艮土、用互上坤土及尾上坤土分别直接生原兑；体互下震木受原兑克制为财。无其他卦直接克体或原体生泄。同气三土合资源槽，现实若同项帮助不重复计；中震财依实际承办能力，不与资源助益混同。

## 六维及古据
- 《梅花易数》437–438、441、445、449–451、459：原兑西方沟通服务、饮食货品交易、金属器具，已有技能及真实客户工作依需求、工作量、报酬办理。
- 405–408、411、418–420、428、502：本艮东北山林田土、场地、土石材料及固定服务，直接生原兑为前段资源。252–253、256、259–260、265–266、275、497：用互及尾坤西南乡里田土、实物仓储，分别直接生兑为中后段资源。春死冬囚生薄，夏相是真助但承接力薄，季土旺真助，秋休普通帮助条件；同现实资源不因三处土重复记，依给付、任务及成本合作。
- 283–285、287、294、299、306、555–557：体互震东方经营活动、竹木茶货及材料供应，受原兑所克为中段主动财。季土秋体有力可制，问期内寅卯日参已知现实可控财，跨月重核，木旺月须重新判断，不保证实际交易；春夏冬难制，先看原有工作承办能力。不因木财方向设额外贵人。
- 493–495、555–557、795–804：本中末四直关系及求财旺衰。无来克体或己生泄，难取新财非已破财，正常成本照实际工作核明，收入扣费用并留工作日用周转，有余再储备。
- 655、968、658、965：月日环境及方应。各月申酉金旺月日准备/办理原有财路，春冬另辰未戌丑土旺金相准备；已有真实生体资源候时不重复立土准备。夏条件援、季土真助及秋普通援，换月重核。
- 《周易正义》04損62–65：上九弗损益之，古义处损终而反益，守正而为物所归，借现实真实资源及工作协作，不解作特定身份或保证财。
