# 天雷无妄六三十二月求财规则审计

- 25天雷无妄→53风山渐（互）→13天火同人（变）。上静乾金原体，下动震本用；下互艮用互、上互巽体互、尾下离变用。震、巽各受原乾直接克取为财，艮直接生原乾，尾离直接克原乾。四作用分别同原体比较，493–495、555–557、796、804。不以中段生再克的间接链抵消尾克，不将财象等同既得收入。
- 乾西北公门长者管理金玉贵货（222–223、227、233–236、242），震东竹木动中求利（283–285、287、294、306），巽东南工巧木茶秀士（314–316、319、326–328、337），艮东北山田土石实物（405–412、418–420、428、生体502），离南方文书炉冶火类（375–377、379–380、387–390、398，来克体文书之忧509）。原典《周易正义》03無妄45–48六三无妄之灾，王孔古义失正僭所当为而致灾；借金融实务只提示守职责、真实办理和费用约定，不推断已遭无妄灾、他人侵财。
- 655、658、965、968：前中两木财合槽 use,body_mutual，强原体时gain仅参问内寅卯日，入寅卯月按金囚木旺重判；艮生有力为use_mutual的gain或条件助conditional-gain，辰未戌丑土月或问内土日核已有东北材料场所资源助和所得；春夏尾离强克obstruction，季土休离浅克risk-review，均巳午火月或问内火日核已有南面文书工艺验收交付要求，非既有损失。秋冬离克微不独损，休艮普通生助无独财日。金旺申酉及土旺辰未戌丑金相均prepare。
