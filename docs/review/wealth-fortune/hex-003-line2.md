# 水雷屯六二 · 财运收入五气规则审计

水雷屯六二动，原静上坎水为体，下震为本用；互山地剥，上艮体互、下坤用互；六二阴化阳，下震成兑，末水泽节。四关系均对原坎：本坎生震（己耗）；体互艮、用互坤分别来克；变兑直接生原坎（末回益）。与初九末坤来克明显不同，六二终于有生体；不凭卦名「节」就断节省或财利已兑现。互变不立新体。主要看前耗、中阻、末扶的不同旺衰，不把生克节点数量当结果。

## 古据
- 《梅花易数》555–557【求财占第十】体生用有损耗之忧，用克体无财，用生体有进益；生体及有力体克用为得财候，克体及体生用为破财候。无财、耗费和已破财分别处理；必要支出不等于确定亏损。
- 493–495体用总诀本始、互中、变末；796–798体互较紧、用互次、变生体临终有吉；804体旺遇衰克可承、衰体遇旺克重，若有生体则具回扶方向。各五气实际处理早耗中阻和晚扶，不把有后扶等同前面全无风险。
- 505坤来克田土忧，510艮来克百谋中阻；503兑生体「或有食物金玉货利之源」。前段震仅受原体生己耗，从《说卦》09.07:21–22震动借为已有办理事项之消耗，不误取震生体得财。坤艮之来克按确有场所、田土或财务条件阻滞等现实事项核查；兑生体指实有已知财源的补益可能，不强指行业、某人给钱或收益确定。
- 《周易正义》简校01屯42–45 六二「屯如邅如，乘马班如，匪寇婚媾。女子贞不字，十年乃字」；王注志在五而为屯难所隔，孔疏班旋不进，难息而反常。49以前之本爻相关范围已核至45。现代求财借义：正当既有条件若还未通则先按应做部分办理，待实际阻隔化解；不硬解婚姻、人物或字面十年财期，不臆测原因。
