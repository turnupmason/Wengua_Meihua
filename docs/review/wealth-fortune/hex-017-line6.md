# 泽雷随上六｜财富财运，十二月规则审计

## 盘式与四条关系

本泽雷随（17），互风山渐（53），变天雷无妄（25）。上兑动，下震为原静体。原震分别受本上兑金、尾上乾金直接克，克体互下艮土，与用互上巽比和。初兑及尾乾虽同属金气，分别核各自的克力与责任，日期可合一金气槽，不作两笔确定损失。木旺相可制弱艮取财；弱木难制土是取财能力不足，非土反克木。无直接生体与体生用，外来强贵人施财无生扶证据，具体已有支用依事实计算。

## 六维古典依据

- 《梅花易数》284–285、288、294、299、306：原震东方起动、经营活动、动中及竹木茶货。现实原有能力、熟悉工作及顾客需求是原财路，不从卦象预测职业或必然新增顾客。
- 《梅花易数》405–408、411、418–420、428：艮东北山林田土、场地、土石材料与稳定事务，在此受原震克，非艮生体。旺相原震克弱土，现实有据场地服务、土石材料供给、山林业务可凭本人本领及交付取财；弱震难制土则先量力，不为未知报酬扩大支出。已有工作量、材料用量、期限及计价凭据核清。
- 《梅花易数》314–319、326–328、337：巽东南工巧、材料供应、竹木茶果，原震同比。原有真实任务的客户和伙伴有工作协作关系，旺相比有力，休一般，囚死弱；合作非直接来生或某人送钱，依真实分工、费用和实际报酬办理。实收扣正常费用、留必要日用及周转，再安排余款。
- 《梅花易数》437–438、441、449–451、459、511：兑初段克体，西方口舌饮食、货品交易及沟通服务相关已有责任。金与原震五态结合判轻重；相旺金克弱震实阻，囚死金来克浅，冬休金克相木浅但可金旺环境复核，非必有争吵、违约或损财事实。
- 《梅花易数》504、221–223、227、235–236、242：乾尾克体，西北公门、规范管理、器物和手续责任。与本兑分别克原震，不因同气合槽漏掉前后两处现实事项。土秋实克、春夏冬浅克程度不同；直接生泄原震未见，不将正常成本编为确定已损。
- 《梅花易数》493–495、555–557、795–804，始中末体用四关系、财势五态；655、968支月日气与658、965方应。春冬有力原震可制艮土，真实可控事项参辰未戌丑日，跨月重核；土秋两金相旺克体参申酉月日实际阻合槽，春夏弱金常规核，冬两休金来克浅只申酉金旺环境风险复核合槽；夏、土、秋寅卯木旺与亥子水相体准备，非独立财期；巽比和无专财日。无直接来生或生泄，不定强贵人财、体生用耗日。日期依真实问期动态计算，不保证到账或损失。
- 《周易正义》02隨:47–50，「拘系之乃从。维之」，象传上穷也。古义所随至上极不随从，须拘系乃从，用于现实财事核明已有交易的约定、履约范围和给付，不据古文兵刑预测现实行为或纠纷。
