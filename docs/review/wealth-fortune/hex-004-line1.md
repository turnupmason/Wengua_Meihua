# 山水蒙 · 初六动 · 规则审计（五气十二月）
本卦山水蒙，原静上艮土为己，动下坎水为财。互地雷复，上坤为体互，下震为用互；末山泽损，下兑金为变用。四作用一律直接对原艮：本艮克坎；体互坤比和；用互震来克；末艮生兑耗己。不另立体、不让坤或震、兑互相生克改变本盘方向。无生体节点。取象不等于现实行业、事实、交易金额。

## 原典与落地
- 《梅花易数》修订录文555–557《求财占第十》：以体为主，以用为财。体克用有财；用克体无财；体生用有损耗之忧；用生体有进益；比和财利快意。体克与生体为得财气候，来克及体生为破财候。弱体难克强用按有求取方向而难实得，不误判无财为已破财；尾耗仅为真实支出、耗己风险，不等于本金已损。
- 493–495论本、互、变与体盛；796–798论本最紧、体互重于用互、变为末；804论体旺而他卦克衰影响小，衰体且无生体时同气党力衰薄，不以数量判吉凶。四节点按当月强度逐一审查。
- 506震来克「主有虚惊，常多恐惧……或于山林有所失」；《周易正义》09.07:21–22震动、坎陷、艮止、坤顺，09.11:25–26震决躁，29–30坎隐伏、通，35–36兑口舌、毁折。震来克在这盘用于既有行动、变动阻力；真实林木财事若已存在才取具体类象。末兑非克体，兑口舌取既有议价、商议的费用，不当作原书兑来克口舌纷争的专断。坎本用受克取财，不用坎生体之鱼盐酒货财源条硬套行业。
- 王弼注、孔颖达疏《周易正义》01蒙41–44：初六「发蒙，利用刑人，用说桎梏，以往吝」；王注「蒙发疑明，刑说当也」「刑不可长」；小象「以正法也」。用于目前财务时对应辨明实际领取和付费条件、正当处理并止于必要限度的类推，不将古时刑罚当作现实建议。28–29险而止，37–38山下出泉不知所适为蒙之义。
