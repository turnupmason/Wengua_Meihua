# 山水蒙 · 初六动 · 规则审计（v2 五气十二月）
本卦山水蒙，原静上艮土为己，动下坎水为财。互地雷复，上坤为体互，下震为用互；末山泽损，下兑金为变用。四作用一律直接对原艮：本艮克坎；体互坤比和；用互震来克；末艮生兑耗己。不另立体、不让坤或震、兑互相生克改变本盘方向。无生体节点。取象不等于现实行业、身份、事实或交易金额。

## 原典依据：财源、方向、人际及风险
- 《梅花易数》修订录文555–557《求财占第十》：以体为主，以用为财。体克用有财；用克体无财；体生用有损耗之忧；用生体有进益；比和财利快意。体克及生体为见财气候，来克及体生为破财候。弱体难克强用只按求取之方向而难实得，不误判无财为已破财；尾耗为可能的支出、耗己风险，不等于本金已损。
- 493–495论本、互、变与体盛；796–798论本用最紧、体互重于用互、变为末；804论体旺而他卦克衰影响小，衰体且无生体时同气党力衰薄，不以数量判吉凶。期法655月日明列寅卯木、巳午火、申酉金、亥子水、辰戌丑未土各旺；658明确方卦及强弱关系。方位只落在有现实依据的客户或事项上，非推定对方实际在哪。
- 原艮（406–408、411、418–420）：东北、山田土石、山中人、守静、山林田土交易，作为静体经营方式及财务能力类象，稳定本职、实物经管、场地事务为现代类推，非断当事职业。春冬及秋艮弱时仅守已熟知资源；土旺夏相有力据实办理。
- 本用坎（345–346、357–358）：北方、江湖水边、舟人，求利有鱼盐酒货之利；按555–557体克用，此坎是所求之财，不借500坎生体的外来援助原句。若水货、流通、配送、水产食品等现实业务或相关客群存在，土旺相可争取，弱体仅潜在方向、以实际资格判断；不由坎的盗、沟渎等类象断实际犯罪。北方为有事实对应的潜在业务方向，不要求出行谋财或改业。
- 上体互坤（252–253、259、265–266）：西南、乡里、农夫众人、仓库、田土五谷实物；此盘同气比和非497来生。土旺比有实承、夏相有力，原有实物资源、仓储等的协作者可合理分工及核对收入与费用；秋休平比，春死冬囚的同气仅有配合方向，条件不足以承接强克或旺财。无有力生体节点，不硬造贵人。实际客户群体以坎的舟人、水货或现代相近流通食物客源为条件，坤同气仅协同，非自动进账。
- 506震来克，有虚惊、山林之失；283、285东方、起动虚惊；《周易正义》09.07:21–22震动、艮止、坎陷，09.11:25–26震决躁。已有行动、变化、林木财事项才借中震来克核查实际障碍与额外成本，不断实际损失。
- 末兑非克体，故不套511兑来克主口舌纷争；《说卦》09.11:35–36兑口舌、毁折，梅花437–438译人及口；658西方，449兑求利口舌等。兑受体生泄己，结合已有西向商谈、议价、沟通、交付结算费用等成本自耗，不指认他人争执、侵财。
- 《周易正义》01蒙41–44初六「发蒙，利用刑人，用说桎梏，以往吝」，注「蒙发疑明，刑说当也」「刑不可长」，小象「以正法也」。借为现代财事查清现实取得与付款要求，解除疑碍之后止于必要投入，不把古刑罚当作现实建议。
- 聚财能力与净余：本坎可制而末相兑有实耗，土旺体能承但净余不能等同进账；夏相体制财有力、末死兑耗薄可较留财；春冬弱体难得，中强克及尾耗牵制，秋难得而尾旺兑重耗，均宜守现有财力。现金收付如实核算、留基本周转、费用按实，不给确数利润或配置指令。
