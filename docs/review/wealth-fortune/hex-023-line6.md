# 山地剥上九｜财富财运，十二月规则审计

## 盘式与四直接关系

本山地剥（23），互坤为地（2），变坤为地（2）。上艮动，下坤静体。原坤与本上艮、体互下坤、用互上坤、尾变上坤四处分别比和，各节点仍独立辨关系，不将四比和当四笔独立收入或重复费用。全卦无直接生体、来克原体、原体克财及体生用生泄关系。依统一比和五态春同土皆死D/W，冬同土皆囚C/W，秋皆休C/C，夏相及季土旺F/P。无独立新财或直接损财象，真实成本照实扣。

## 六维及古据

- 《梅花易数》251–254、259、265–266、275，原坤西南乡里、田土、谷帛实物、仓库，已有实物保管、供给、场地、地方客户的实做工作为主要收入。中间上下坤及尾上坤分别同原坤比和，西南仓储实物及地方伙伴、客户实际工作依资源及需求、明确责任、交付及报酬来配合。各同比旺相有力、休普通、囚死薄，非直接生体或额外财。
- 《梅花易数》405–408、411、418–420、428，本艮东北山林田土、场地、土石材料及静中事务，与原坤比和，东北方向真实已有场地山林土物工作伙伴及客户可在各自承办力下共同工作。原工作已有真实资源先充分利用，不预设实际职业或陌生合作，不重复计同一支持、本钱及收入。
- 《梅花易数》493–495、555–557、795–804，四直接关系与五气财势。没有直接来克或自身生泄，财势薄并非已有财损，仍须核日常材料、器材、仓储、场地及运送成本。收入进入后扣实际费用、留日用和工作本钱周转，有真实净余再作储备。
- 《梅花易数》655、968、658、965，支月日与方应。各月辰未戌丑旺土与巳午火相体月日整理原有工作、资源、合作、费用和报酬，若原工作有具体任务可办理，四比和不另设新财日；无直接来克或生泄，不另定实际损财候。具体月份及日支落在真实问期，非到账保证或所有月都同财势。
- 《周易正义》03剝:48–50，上九硕果不食独全于剥终，君子得舆覆荫于下，小人剥庐失所庇。借古义维护原有工作赖以完成的资源、客户及真实协作，不因爻辞推断现实人物性格、事故或某人必给钱。
