# 水天需六四 · 四爻十二月六维、顾问白话与动态应期规则审计

## 关系与古义

《梅花易数》493–495、555–557、795–804：本动上坎，静下乾金为原体，本坎水由乾直接生，己耗；互火泽睽下兑为体互，与原乾金直接比和，上离为用互，直接克乾；四阴变阳成上兑，末泽天夬上兑金再次比原乾。不重新定体，也不把中离与二兑串生。全局无生体或体克取财；比和在求财专条为财利快意，弱比不代表必得钱，后比也不自动回补前耗。没有独立比和进财应期。各组由原体承受能力及中末比和是否实际有力，连同本生泄及中直克决定财势。

《周易正义》02需:44–46「需于血，出自穴」，王注「九三刚进，四不能距，见侵则辟，顺以听命者也」；孔疏释处坎之始、阴阳相伤、难相逼遂避其穴，象传顺以听命。财务上仅取遇到现实不能承担的要求时量力、避免不明支出，不从血字断实际事故或身体伤害，也不要求无条件接受对方要求；实际义务以真实凭据为准。

## 六维取象与古籍

- 乾体：《梅花易数》222–223官宦、公门人、刚健，235–236金玉交易、公门求利，242西北。规范管理、器物技术、真实职责等现有本职为经营类象；旺相体承财强，囚死体宜守原收入，体位不当新贵人财源。
- 体互及末兑比和：《梅花易数》437–438译人、口悦、饮食，441静物金类，449–451求利、交易，459西方；555–557比和财利快意。取西侧饮食供给、交流翻译等实际客户及同向伙伴相合，旺相比可借已有业务协作，休囚死比兑现能力较薄。没有来生，不以比和说外人资财或确认实际贵人，真实协作看工作、收入分配与支付条件。
- 本坎受体生：《梅花易数》134水货属类、346江湖舟人、357–358水边货利、失陷象，367北方。北侧水货、运输或流通业务现实有先付成本、资金占用时核依据和回收，不取坎生体之财。旺相及休水受弱金生较见己耗，死水浅耗、囚水有限勿硬定强损。
- 用互离直接克体：《梅花易数》509离克体主文书忧，376–379文人书事等、388–390文书财及交易、398南。南文书文字技艺已有财事的合同、计价与支付依据为核实方向，强克防真实阻，薄克正常复核；不据文书忧指认某人骗财、既成损失。
- 时机：《梅花易数》655、968地支月日五行旺气，658、965方应随体用。申酉金旺用于原体准备、落实已经查实的业务，非独立见财日；555–557来克、体生耗明确有力才立火阻、水耗。弱离在文中明确巳午环境复核文书，旁证为risk-review非强损；浅耗不单列。日期依真实问期动态计算，不保证实际成交或收入。
