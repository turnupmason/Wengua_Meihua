# 天火同人九五财富财运：十二月与五组规则
九五动上，静下离火为原体；动上乾受原离直接克，是可制财。互天风姤，上乾用互亦受原离直接克，下巽体互直接生原离。九五变阴，末离为火，上离变用与原下离同比。阶段13/44/30，四直关系各对原体，不串联、不按节点数重复计收入。
- 《梅花易数》493–495、795–798、804及555–557：春相离可制两囚乾、旺巽直生有力、末相离比实，F/P；夏旺离可制两死乾、休巽普通生、尾旺离比强，F/P；土休离难制两相乾、囚巽弱生、尾休离比平，C/W；秋囚离难制两旺乾、死巽微生、尾囚离比薄，D/W；冬死离难制两休乾、相巽实际生有力但原体死承财弱、尾死离比薄，C/C。收入及净余分开，盘无直接己耗或来克，不判已损。
- 离374–377、388–390、398：南面文书文字、文画设计、炉冶的原有财源及现实客户，末离同比相旺时行业同行合作有力，弱时或休则依现实能力，非生体外赠。乾220–222、235–236、242：西北、公门、长者、权责、金玉贵货，本及用互两乾受体克，春夏原离有力凭实际管理工作、贵货器材业务和已有客户争取收入，其他月份难制量力，不冒称方应独吉。
- 巽313–319、326–328、337、499：东南、茶果竹木工巧、山林，体互下巽直接生体为实际中段资源助，春旺有力、夏休普通、土秋弱、冬相实助但原体死仅条件性财。已有东南茶木材料、工艺客户与资源供应方才参，不猜客人身份、馈赠、金额。合作按真实费用与报酬。
- 《周易正义》02同人53–56「同人先号咷，而后笑」「同人之先，以中直也」：王注孔疏先后经困难、以中直求和同，借到实际经营宜真实协调工作要求与报酬，不凭爻义虚构争斗、预断一定先亏后赚。
- 655、968：春夏两乾有效受克，合并同金gain roles use/use_mutual，本问期内申酉金日参现实已知可制财，跨入申酉月则原离囚金旺，须换月重判。同一收入不重计。春下体互旺巽有力直接生原离，gain role body_mutual，寅卯木月或问期内木日参现实中段资源款；冬相巽生实但原体死承财弱，conditional-gain 同角色和木气，换月再核。休巽普通、衰巽弱生、难制乾不另立强财候；尾离同比不独定财日。全十二月巳午火旺、寅卯木旺火相两prepare，真实财事准备，非确定财日。965方应按实际事务。
