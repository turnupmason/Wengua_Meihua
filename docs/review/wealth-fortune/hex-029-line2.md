# 坎为水九二｜财富财运，十二月规则审计

## 盘式与四直接关系

本坎为水（29），互山雷颐（27），变水地比（8）。下坎动，上坎为静体。本下坎同原坎比和，体互上艮土与尾下坤土分别直接克原坎，用互下震木受原坎水直接生泄。两土克与一木耗分别考察原体，不串生克或抵消；两个土若现实指同一项责任或支出，只核一次。无直接生体或原体克财。春休坎同比普通、旺震耗重、两死土浅克；夏囚坎、相艮相坤实克、休震有实耗；季土死坎双旺土重克、囚震耗浅；秋相坎同比有力、两休土浅克、死震耗微，C/P（比和支持原有收入但双浅克和微耗仍谨慎）；冬旺坎同比强、两囚土克浅、相震有实耗，C/P。

## 六维及古据

- 《梅花易数》345–352、357–358、360、367，静坎及本坎北方水边、舟运流通、鱼盐酒货。原有运输交收、水货等已具备的技能和真实客户为主要财源。本坎同原坎比和，已有流通伙伴按资源、计价、交付和各自费用协作，旺相有力、休普通、囚死薄；非外人直接生体、贵人施财。
- 《梅花易数》405–408、411、418–420、428、510，体互艮东北山林田土、场地及土石材料，直接克原坎。《梅花易数》251–254、259、265–266、275、505，尾坤西南乡里、田土、谷帛实物及仓库，亦各自直接来克原坎。夏相、季土旺双克有力，现实已有场地、材料及仓储货品中尾段责任核，辰未戌丑月日合土气两角色，不重复计同一实际任务费用；秋休双浅克，土旺环境仅复核已有责任，非强损；春死及冬囚土克浅常规核。
- 《梅花易数》284–285、288、294、299、306、555–557，用互震东方经营动中、竹木茶货和工料供给，由原坎直接生泄为耗。春旺震受休坎生耗重，夏休震受囚坎生及冬相震受旺坎生均为实耗，寅卯月日核实际存在的东方活动、材料相关开销，季土囚震、秋死震耗浅微，常规成本照实核。不认正常支出必已亏损，实际利润按真正收入扣开销并留必要日常及工作周转，余款量力存。
- 《梅花易数》493–495、555–557、795–804，体用四关系及财势五态；655、968支月日旺相环境；658、965方应。各月亥子旺水、申酉金旺相水月日整理、准备及办理已有工作，不立比和新财候，无直接生体及原体克财的独立财日；阻耗月日按真实事项参考，非保证有损，跨月重核。
- 《周易正义》03坎:51–53，九二坎有险，求小得，未出中而可小得，借古义处理自己确能完成、已有明确报酬的任务。不能以爻义硬断具体得财或损财，不覆盖体用旺衰。
