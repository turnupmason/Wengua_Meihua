# 风火家人九五十二月求财规则审计

- 37风火家人→64火水未济（互）→22山火贲（变）。静下离火原体、动上巽木本用，下互坎水体互、上互离火用互、变上艮土变用。巽直接生原离，坎直接克原离，上互离同比，尾艮土直接受原离生耗；493–495、555–557、796、804依四直接关系五气，不链推、不叠计。
- 离南文书文字技艺炉冶（375–377、387–390、398）；巽东南木茶工巧秀士（314–316、319、326–328、337、生体499）；坎北水边舟人鱼盐酒货（345–346、350–352、356–358、367、克体508）；艮东北山田土石材料场所（405–412、418–420、428）。皆联系真实已有业务、客源、伙伴资源、工作要求及实际费用。《周易正义》04家人50–53九五王假有家、古义以王者之德至于家、交相爱，财务借此明确各方分工、付款责任，非臆断亲友送财。
- 655、658、965、968月日。春旺巽实生原相离为木gain，夏休巽普通助、冬相巽实助但原体死且中坎重克为木conditional-gain；寅卯木月或问内木日核现实已有东南材料工艺资源，非现金。春休坎浅克为水risk-review、秋相坎实克冬旺坎重克为水obstruction，亥子水月或问内水日核实际北方水货运输交付任务。土季旺艮尾重耗、夏相艮尾实耗、秋休艮普通耗弱体仍核实费，土drain变用角色，辰未戌丑土月或问期内土日核真实东北材料场地成本，非断已损。火木prepare原体旺相环境，与木资源槽去重。同比不单定财候。
