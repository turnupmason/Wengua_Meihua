# 风天小畜上九 · 财运六维五气规则审计 v2

上九动上巽，原静下乾金为体。本小畜，互火泽睽（下兑体互、上离用互），变水天需（上坎变用）。本巽木由原乾克，是自主财关系，中体互兑与乾比和，中用互上离火直接克乾，尾坎水由原乾金直接生而己耗。所有作用直指原体，不将坎水间接克离作化解，也不由需卦名称断定等待多久；无直接生体，不判外来贵人资财。春夏本巽难制、兑比薄，离来克实际有力而坎己耗薄，D/W。秋原乾旺能制死巽，旺兑比强，囚离克浅，尾相坎由原旺乾生实际耗，C/P（能得财而净余有压力）。冬休乾难制相巽，休兑比平、死离微克、尾旺坎实耗主导D/W。季土相乾可制囚巽，相兑比和有力、休离浅克、尾死坎耗微F/P。五组与已发5/6及10/1同直接关系和五气判码一致；季土薄尾耗不据6/1本用先耗作同样处置。
