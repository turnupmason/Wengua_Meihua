# 坤为地六五 · 财富财运 v2 顾问白话规则审计（12月、5气组）

## 盘面及气力
本卦及互卦都是坤为地，六五动于上，静下坤土作原体。动上坤本用、下体互及上用互都是同土，分别与原下坤直接比和；变水地比，末上坎水受原下坤土直接克。古《梅花易数》555–557行：比和财利快意，体克用有财，力量按493–495、796、804行始中末、五气。全盘无直接来克及己耗，不将不能取到的财认作已经损钱；末弱水可被旺相土实际控制有真财条件，弱土难制相对强水只保有原先同比条件、不立强财候。

## 财源、合作客源、方向、风险
- 梅花252–259、265–266、275行坤为西南、地土谷帛仓库、乡里众人，「静中得财」「多中取利」；前中三比有实际承财力时可依现实既有工作和经营，适用本地熟客、既有仓储农产和实物资源，弱时则守已有。旺相三比表示已有搭档能力相合、休平、死囚薄，不是496–503生体贵人送财。
- 梅花342–346、357–358、367行坎北、舟人、水边鱼盐酒货及流通；尾上坎受原坤克，只在原旺相足以制死囚坎时取可掌握的现实财事；方位只是财源属性，367行方道与965方应有别，非北方一定有利。土休囚死时取财难，应查真实能力、成本和交付、付款关系，不把坎作反克或实耗。全盘无直接克己或泄己，不能虚构亏损事故、合作欺骗。
- 《周易正义》01坤54–57六五黄裳元吉、文在中，王孔中和通理，不用威武，借义于原有岗位及合作责任，实际成果求财、不过分强揽责任。不取字面服饰或确定富贵。
- 655、968月日卦气：亥子水、巳午火、辰未戌丑土；658、965方应，仅生体/比和明宜，坎在这里是受克取财对象。旺相土能制死囚水，求财555–557取亥子月/问期内亥子日参真实已有可控后财，按事件、changed_use；全盘无强克或泄损候。原体准备土旺辰未戌丑（全部）；夏火巳午土相（仅巳午）。难制弱体不硬设亥子财候、比和无独财日。实际时机侧车事件对应正文，prepare只归body、明元素土/火，gain只归changed_use，由坎水自动解析月日。
