# 地泽临九二十二月求财规则审计

- 19 地泽临→24 地雷复（互）→24 地雷复（变）；原静上坤土。本用下兑金，体互上坤土，用互下震木，变用下震木。原坤生本兑泄耗；中上坤同比；中下与末下两个震各直接克原坤。按四节点各自对原体，不从互与变相同就合并掉关系，也不由数量认定多笔费用。关系依据《梅花易数》493–495、555–557、796、804。
- 坤西南田土仓库谷帛静中有财（252–254、257、259、265–266、275）；兑西口译饮食、金类交易（437–441、445、449–451、459）；震东竹木草木动中求利（283–285、287、294、306），来克原典506。仅已存在的业务与客群/伙伴、实际责任及费用，不虚构新增人物事件，不确定财务金额。
- 《周易正义》03臨36–39 九二咸临吉无不利，古疏“必须商量事宜，有从有否”，不盲从，不能用爻吉掩盖旺衰与费用。寅卯木月或问内木日复核实克中尾，两震同木合槽 use_mutual, changed_use，具体须区分两阶段但不重计同一实际成本。金耗有力以申酉月或问内金日核前段费用。655、658、965、968月日方应。仅有比和、无生体和体克，不立独财候；巳午火旺土相、辰未戌丑土旺原体准备。
