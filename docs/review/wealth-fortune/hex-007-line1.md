# 地水师初六财富财运逐月原创规则：五气五组

初六动下，静上坤土原体；动下坎水本用，为原体所克。互卦地雷复，上坤为体互，直接比和原体；下震木为用互，直接克原体。初六变阳，末地泽临，下兑金为变用，受原坤土生，属原体向外泄耗。阶段ID 7 / 24 / 19。四关系体克用、体互比和、用互克体、体生变用，均直接对原上坤，不能串生。

- 《梅花易数》493–495、795–798、804及555–557：体克用有财，体力不足时难制；同土比和有合财及协作之象，力薄不是强外援；用互来克按震旺相程度分中段阻力与费用压力；尾兑体生用按其气分泄耗。收入、成本、实际结余分别判断，不把无财视为已损，前财不抹掉尾耗，尾耗也不抹掉已有进款。
- 坤252–259、265–266、275，西南乡里众人、静中多中财地谷仓，现实已有物料、仓地、农产及本地熟客才可作为收入。中段体互坤强时合作有承接力，弱时意愿可能有而实际兑现弱；无生体不套497乡人进财。坎342–346、357–358、367北方、舟人、水货、鱼盐酒货及流通，原本是受体克的对象，强体可从已有水运物流、货源服务及真实客户需求履责取财，弱体宜核自身能否承接，方向只是对象属性。965方应生/比宜，不说坎为生体或北方普遍吉。
- 震283–288、294、306、506，东方、动、竹木以及来克山林损忧。实际有木货交接、业务搬动或调整才核真实成本及职责，春冬强克中途阻力重，夏、季土及秋按弱克，不凭象推定事故。
- 兑437–441、449–451、459西方、口、饮食、交易、金类；尾变直接由坤土去生，说明实事中相关交易、沟通服务、餐食支出等向外费用；季土及秋尾兑有气时较显，明确与毛收入分开，弱兑仅核真实支出，禁止引兑克体511断人际受损。
- 《周易正义》02師30–33「师出以律，否臧凶」「失律凶也」，王注孔疏不因有功而失律，现实工作及合作应明确职责和费用、付款依据，按约定履行，不推定现实纠纷或败财。
- 655、968支月日：本坎强受体克有力时，问期亥子日参现实原有水货流通财；跨亥子月变囚土旺水，应按新月令盘重核不可平移。旺相震来克参寅卯月/日obstruction，旺相兑受原体生泄参申酉月/日drain，均按已有真实事项，不断已损。土旺辰未戌丑、夏火巳午土相可作原坤prepare环境，对应正文。不以体互比和另立财日，不以弱克泄硬定损期。
