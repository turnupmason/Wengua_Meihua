# 水雷屯九五 · 财运六维逐月五气审计 v2（白话咨询式）

九五动上坎，静下震木为原体；本水雷屯，互山地剥（下坤是体互、上艮是用互）；变地雷复，上坤土为变用，静震承继。四个节点分别对原体：坎水生震木，中坤艮土皆受原震克，末上坤亦受原震克。与同为上动的六四不同，尾坤不再是兑金来克，而是自己能否控制土类财的方向；本互末全无用克体或体生用，求财不易时不写已经亏损。原体衰弱、财事有方向却缺取财力量，不能把土旺变成收入厚。没有强比和；只有原本坎水直接来生的帮助方向。

## 古据与实际六维

- 《梅花易数》555–557【求财占第十】，用生体为进益、体克用有财，两者有力才取见财候；493–495本始互中变末、796–798体互较紧用互次、804按旺相休囚死辨实际力量。原体自身能力、外源助益、原体能否制中尾三土与最后净收入分别判断；不串生，不把三个同类土节点当成确定三笔财。无直接损关系不保证无经营成本，实际积财需实收减必要费用、留生活及周转。
- 原震体经营能力，285动、294竹木茶货及动处求财、306东。已在办理的东方动务、木货流通、亲自经办或本职工作按原有能力维护；非震来生体，勿用498生体益条，不推测实际职业或推荐另换财路。
- 本坎生体取500北方、水边人进利、鱼盐酒货和文书交易之利，346舟人等、357–358水货交易、367北。北边已有运输、物流、水货、文书服务及真实客户或经办方，满足实际给付条件才作财源；春休坎有旺震承受，秋相坎直接生死震仍有实际外益，冬旺坎生相震强，夏囚坎及季土死坎薄，均不得据某人实际身份确定贵人或送钱。弱助时原有确定报酬优先，强助时原本客户和经办资源有利也需真实履约。
- 互剥下坤253乡人、259仓库、265–266田土仓储实物农产、275西南；上艮407–408山中人守静、418–420山田土类、428东北。末复上坤同属坤土，三处均受震木直接克，是靠自身能够掌控的财事，不是坤艮生体或受土来克，不能错引505、510来克风险与497、502生体支持。现实存在西南东北场地、实物经管、仓储或土物相关报酬时据能力争取；旺相原震有力制死囚土，弱休囚死震面对较强的相旺休土难制，强财方向区分。尾上坤承接土类财取力，不凭复卦名断翻本。依据658、965方应，体克用的西南东北是对应财对象方位，不冒为方应吉方。
- 《周易正义》01屯54–56九五「屯其膏，小贞吉，大贞凶」，象曰「屯其膏，施未光也」。王注、孔疏释膏乃膏泽恩惠，居尊位者本当恢弘博施而系应限于二，出纳之吝有司小正吉、大人不能恢弘博施则大正凶。现代借义是按真实资金和工作能力办理既存财务，量力承担合作和真实费用。不是从字面保证小买卖赚钱或大投资赔钱，不把膏理解为特定油货。盘无直接克耗，所以排风险以尚难取得报酬、预支预计收入、过分承担已存责任为主，而非虚构新的损失、诓骗或人际冲突。
- 655、968五行地支月日及原体旺相；体克可制、生体有力作对应卦气见财参考。北坎本财为亥子；中坤艮与末坤合土财辰未戌丑（同元素同类型合并角色，不声称三个独立进款）。弱生、难制土财不设有力见财期，木旺寅卯、水旺亥子而原震相的月日参考整理准备。无克耗不另定日。动态侧车绑定实际原文角色、事件及月日规则，不硬编码公历，不保证实际到账或收益。
