# 山风蛊九三：十二月求财规则审计

本山风蛊→互雷泽归妹→变山水蒙（4）。静上艮土，本巽、中体互震直克艮，另用互兑受原艮生，变用坎水受艮克为尾财。无直接生体、无比和。梅花493–495、555–557、795–804；周易正义03蠱42–44九三“干父之蛊，小有悔，无大咎”，疏重依正道干事，借实际旧事务不足可纠正，非虚构家中父亲事。
