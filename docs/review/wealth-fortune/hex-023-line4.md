# 山地剥六四｜财富财运，十二月规则审计

## 盘式与四直接关系

本山地剥（23），互坤为地（2），变火地晋（35）。上艮动，下坤静体。原坤与本上艮、体互下坤、用互上坤分别比和，尾变上离火直接生原坤土。三比和与尾来生是分别四直关系；已有原有业务和相关伙伴可协作，外援须实际工作所需和资源；不把比和当重复财富或尾来生当自身可克财。无直接来克或原体生泄、原体克财关系。财势弱非已遭明确财损，常规成本均从实际收入核。

## 六维及古据

- 《梅花易数》251–254、259、265–266、275：原坤及两互坤西南乡里、田土、谷帛实物和仓库。原坤为静体，原有场地、货品保管、实物供给和地方服务为原有工作财。两互坤和原坤同比，已有仓储、乡里、实物业务客户及伙伴可按真正需要、资源、交付与报酬协作。
- 《梅花易数》405–408、411、418–420、428：本艮东北山林田土、场地、土石材料，与原坤比和。原有场地及山林土物伙伴可协作，与两个互坤皆属同比而非外在直接生体；旺相有力、休普通、囚死薄；不重复计算同一收入或费用。
- 《梅花易数》375–377、380、387–390、398、501：尾离火南方、文书、聪明才学、明晰、文书之利与直接生体助财。春夏离相旺直接有力来生，已有文书办理、技术协助及相关客户资源可改善工作；季土休离普通生扶观察条件，秋冬囚死离仅照实核，非强财或直接赠款断语。不见体克财，实际所得须依原业及工作协作。没有直接来克或原坤生泄，正常费用仍需据实核，收款扣费用、留周转后余款积存。
- 《梅花易数》493–495、555–557、795–804，体用四关系及财势；655、968支月日；658、965方应。春夏尾相旺离有力生原坤，巳午月日作真实已有南方文书技术资源外援的参考，季土休离普通生体以巳午月日观察实际可用资源条件（conditional-gain，非强财）。有真实事件才参考，跨月重核，不能保证到账。辰未戌丑旺体月日准备和办理已有业务；秋冬离生薄，巳午火相土月日仅作原体准备，无独立外援日期；火气若已指真实尾生事件，不同气重复另列准备槽。同比不另定财候。
- 《周易正义》03剝:41–44，六四剥床以肤，剥及人身，《象》切近灾。借爻义核现实已有工作基础及直接交付、计价、责任，非占客观身体事件或无根据实际财损，不能覆盖四直关系的旺衰。
