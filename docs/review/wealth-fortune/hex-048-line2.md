# 水风井九二：十二月求财规则审计

本水风井→互火泽睽（38）→变水山蹇（39）。静上坎水，本下巽木受原坎生而耗，体互上离火受原坎克财，用互下兑金来生原坎，尾下艮土直克原坎。梅花493–495、555–557、795–804；周易正义05井47–50井谷射鲋、瓮敝漏，古疏井水反下注，违井之用，现实核已有支出与真实最终取酬条件，非断具体事故或必赔。
