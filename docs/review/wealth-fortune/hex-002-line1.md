# 坤为地初六 · 财富财运规则审计（12月、5气组）

## 盘面与断财原据

主卦坤为地，互卦坤为地，初六变地雷复。静上坤土为原体；本用下坤、体互上坤、用互下坤均与原体直接比和；末下震木直接克原坤。全篇依据《梅花易数》555–557行求财：用财比和为财利快意，用克体为无财；克体及体生用为破财候，体克用及生体为得财候。末来克是收入受阻与耗损警候，实际无财并不自动等于损失。依493–495、795–798行本用最紧、互中、末终，非三比一克投票；土之旺衰与木之来克各自评价，不把三比视为额外生扶；无间接串生克。

## 古经与象类的逐项适用

- 《周易正义》简校本01坤36–39行：初六履霜坚冰至、阴始凝、疏「防渐虑微，慎终于始」。用于已有小额负担、收入迟滞的及时核查，不从一爻之戒推翻土旺比和，也不把寒冰断作天气事故。
- 《梅花易数》131行坤为地、土、布帛、米谷等；各稿将这些取象与实际已有的物资、财物或资产收入联系，未引497行坤生体，因为此盘坤为直接比和，不是生体。没有现实同类事项不指认财源、推荐新行业。
- 同书132、506行震类木、震克体「或于山林有所失」。在末段实际关系为震木直接克坤土，以已有动项、调整及相关财物损耗风险取象；另《说卦》09.07:21–22的震动支持动象。不给确定事件、不声称已有损失。
- 12篇均区分预计、实收、支出及净财务结余。不借古条推投资命令、数额、到账公历日期。简断与正文各含进益耗失及进账方向。固定模板起笔/禁句式均不采用。
