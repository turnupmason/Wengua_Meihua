# 坤为地初六 · 财富财运 v2 规则审计（12月、5气组）

## 原盘、财势、取候与留财
主卦坤为地，互卦坤为地，初六变地雷复。静上坤土为原体；本用下坤、体互上坤、用互下坤均与原体直接比和；末下震木直接克原坤。依据《梅花易数》555–557行求财：体用比和为财利快意，用克体为无财；克体及体生用为破财候，体克用及生体为得财候。末来克可以取阻收与耗损警象，非现实已经破财。依493–495、795–798、804行本用最紧、互中尾终并衡旺衰，不数三比抵一克，三比并非三份额外生扶。

## 财源属性、方位、人与排雷逐项取证
- 原体、本用和双互坤同土相合。梅花《坤卦》252–259行：地理田野、乡里、平地、西南，人物乡人众人（此处不识别真实人物），布帛、五谷、仓库；265–266行「静中有财/静中得财」「多中取利」且春占无财，275行方道西南。取现有稳定本职、常规经营、实物供给、土产货物、地土使用或库存仓储等现代类推方向，财源与方向仅依据现实已有条件，不荐新行业、不承诺西南财。旺/相三比既有合作可发挥，本地熟客、乡里多人资源相合；休同比协作力平，死/囚弱比保接续意向，必须查真实付款、成本职责，不等于已获外援。坤为比和不用497行坤生体贵利之说。
- 据震卦283–288（东方、竹木、动处、人物等）、294（山林竹木、动处求财）、306（东），《说卦》09.07:21–22震动，以及506行震克体「或于山林有所失」。震在末下为直接克体而非财源节点；东向现实业务变化、木货物资与既定搬移交付费用确实存在时，可查后段收取条件与追加成本。强克月强调压力，弱克月仅核实际尾项，不将孤象变成固定损失、行业禁忌或凭空事件，也不误当震生进财。
- 《周易正义》01坤36–39行初六履霜、坚冰至，象始凝、孔疏「防渐虑微，慎终于始」。十二篇据此及早辨别逐小累积的真实支出。旺/相原体承财与弱尾克相配，实所得扣真实成本较易留下；休气留财一般，弱体受旺相木克则须先守已有、积基本周转。利润不等于进款，不凭古爻编金额及一生财富。
- 期候按555–557行仅生体、体克用为见财候，克体及体生用为损候，三比不能另设专财日。依655行、968行确定寅卯木、巳午火、辰未戌丑土的月日旺气；965行以体为主比和方应，658行坤西南震东。强尾震木参寅卯月或所问期内寅卯日为既有事项受制压力；所有十二稿均明确土旺辰未戌丑月/日（夏令亦可巳午火旺土相）作核账准备及相合有利环境，非特定兑现日期，无问期/起卦公历不编日期。
