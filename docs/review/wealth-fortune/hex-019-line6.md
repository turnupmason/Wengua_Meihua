# 地泽临上六十二月求财规则审计

- 19 地泽临→24 地雷复（互）→41 山泽损（变）。下静兑金为原体，上动坤本用；上互坤用互、下互震体互、尾上艮变用。坤、坤、艮三土各直接生原兑，震受原兑直克取财；没有来克与体生用耗。依据《梅花易数》493–495、555–557、796、804。三土同类不等三笔现金或叠加力量，不以山泽损卦名判已损。
- 兑西口译人饮食金类交易（437–441、445、449–451、459），坤西南田土仓储谷帛乡众（252–254、257、259、265–266、275，生体497），艮东北山田土石山林实物（405–412、418–420、428，生体502），震东竹木草木动中求利（283–285、287、294、306）；方向和行业均为已有现实客户、工作或资源属性。古《周易正义》03臨52–55上六敦临无咎，志在助贤而志在内，合作依据双方真实能力、资源及费用责任，并非凭卦虚构贵人送财。
- 依据655、658、965、968：三土强生合土槽 use,use_mutual,changed_use；原体强时gain，原体死承接有限时conditional-gain，辰未戌丑土月或问内土日核现实前中西南田仓谷帛及尾东北材料山田场所帮助及所得，换月重判。体克木有力为body_mutual gain，仅问期内寅卯日参现实已有木财，进入寅卯月金囚木旺须重新判断。普通三休土生不立独财日。申酉金旺和辰未戌丑土旺金相为prepare，不立确定财日。
