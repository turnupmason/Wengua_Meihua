# 乾为天九二求财逐月稿 v2 规则审计（十二篇、五气五组）

静上乾金为原体，动下乾金为财用。体互、用互分别上乾、下乾，均比原体。九二由阳转阴，下乾变离，成天火同人（1/1/13），尾离火直接克原乾。四关系三同比、一来克，均按原静体，不重设财体、另添外应。

- 《梅花易数》493–495、795–798、804：本用初、两互中、变为末，体互较密；金之强弱取五气，三比同衰且无生扶不足为利，尾来克强弱另论。555–557【求财占第十】比和财利、用克体无财及来克破财候皆明确；求财难得不自动等于实际损钱。
- 乾221、242西北，235–236金玉贵货、公门中得财；222官宦、公门人、老人长者。现代正式职责、规范管理/服务、金属货物等依据这些财象类推，已有按正式程序交收的单位客户、货品品质价值需求者及有经验同行、实际收入权责者是条件相符的人群而非实际身份判断。三同比旺相可协作、休力平、囚死弱不预判额外收到钱；无乾生体，不套496贵人送财。
- 《周易正义》01乾29–31九二「见龙在田，利见大人」，王注出潜离隐、居中不偏，孔疏阳气发见、贤者渐出潜。在实际已有财事中，将本人实际能完成的职责或已办成果向现实有权确认收入者呈明，不以大人身份确认新外援。
- 尾离：梅花375、398南，376人物文人，377–380文画书事、书文，388、390文书财、文书交易；本为克体关系，取509「离卦克体，主文书之忧」，如果实际已有相关南方业务/文字服务及书面凭据等收入事项，则看落实尾端手续或实际发生费用，不推倒行业本身为败财、指认某人失信或确定损失。965【方应】生体及比和为宜、克体不宜，方向仅限现实关联方位与类象，不作地域保证。
- 655及968明确寅卯木、巳午火、申酉金、季土辰未戌丑月/日之气，三同比无专章财候，申酉旺金月或问期内申酉日、辰未戌丑金相时可供核现有收入与筹备，均非固定收款日。尾离相旺来克而原体囚死时，既有末段文书财事可参巳午月或问期内巳午日的压力候；休囚死弱火克更强金时不单立破财候。不从春木再间接生离推其他事故。
