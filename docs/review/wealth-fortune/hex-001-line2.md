# 乾为天九二求财逐月稿规则审计（12篇、五气5组）

静上乾金原体；动下乾金财用。体互、用互分别为上乾、下乾，均对原静体比和。九二由阳转阴，下乾变离，成天火同人（主互变1、1、13）。尾离火是直接克原体，非原体生用己耗。三个相同经卦的同气作用与一处尾来克分时段及盛衰，不作数量投票。

- 《梅花易数》493–495、795–798、804：本、互前中、变为终，四直接作用均向原体，盛衰有轻重，前三比同衰又无生扶不能叠作强援，尾克弱时不抹除得力前三比。求财章555–557：比和财利快意；用克体无财、克体卦气亦破财候；收入受阻与真实资金损失必须分开。
- 《周易正义》01乾29–31九二「见龙在田，利见大人」，王注出潜离隐、居中不偏；孔疏阳气发见、贤者出潜。用爻辞提醒盘中实际条件及既有收入权责可呈明，非贵人给予钱财、未据原496乾生体条虚构实际帮助。乾为健《说卦》09.07:21–22、乾官贵梅花130行按现实已有正式职责或决定权类推。
- 《梅花易数》509离卦直克体「主文书之忧」是本尾离来克的具体证据。若现有财事确需书面依据或相关流程，宜核实际收款条件及必要成本；不强指已经产生文书争议、亏损或收入遭拒。
- 有力末克配有现实相关事项的巳午火气，提示留意求财压力、现实支出及收款情况，不定具体损失日。三比同气不单设见财日，较弱末克不硬凑候。
