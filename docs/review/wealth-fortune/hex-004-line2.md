# 山水蒙 · 九二动 · 规则审计（五气十二月）
本卦山水蒙，原静上艮土为己，动下坎水为财；互地雷复，上坤为体互，下震为用互；原下坎中阳变阴，末山地剥，下坤土为变用。四作用直接对原艮：本艮克坎，体互坤比和，用互震来克，尾坤比和。全盘无直接生体、无体生用耗己。这一点区别于初六之尾兑泄土。末比和不能直接改写成来生或另生财款，不因剥卦字义误定末破财。

## 原典与财事类推
- 梅花修订录文555–557《求财占第十》：以体为主，以用为财；体克有财、用克无财、比和财利快意；体生用为损耗忧、用生体进益；财期为体克用及生体，损耗候为来克及体生用。以五行气势区分能否有财实得，弱体难制强用不写财已到账；中段来克并非现实确定损失，无体生用也不意味现实无支出。
- 493–495本、互、变始中末；796–798本用最紧、体互重于用互；804辨体旺衰与克身力量：原体弱时同衰之党难强扶。中强震克不可因多个同气票数消解；末坤比和可承接，不另立时日专候。
- 《周易正义》01蒙45–48：九二「包蒙吉，纳妇吉，子克家」，《象》「子克家，刚柔节也」。王注以刚居中，孔疏释「包含」「皆与之决疑」「能干其任」「克荷家事」。本问财务经营上取明辨现实取得条件、分清支出责任、按能力荷任的爻义，不断婚姻、生育或有某位家庭成员实际送钱。
- 《说卦》09.07:21–22坤顺、震动，09.11:23–24坤为地、为均，25–26震决躁，29–30坎陷及通（坎陷又见09.07:21–22）。坤比和可在已存在共有财款、分配或责任共同承接的事项中取相协与均分，不据坤生体田土获财的497条直接断有田土收入。震克体依梅花506有虚惊、山林之失；用互来克为中段真实行动、变动压力，具体行业取象限已有事项。坎在本用受克，不引用坎来生的鱼盐酒货财利条。
