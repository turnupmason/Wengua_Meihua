# 山水蒙 · 九二动 · 规则审计（v2 五气十二月）
本卦山水蒙，原静上艮土为己，动下坎水为财；互地雷复，上坤为体互，下震为用互；原下坎中阳变阴，末山地剥，下坤土为变用。四作用直接对原艮：本艮克坎，体互坤比和，用互震来克，尾坤比和。全盘无直接生体、无体生用耗己。这一点区别于初六之尾兑泄土。末比和不能直接改写成来生或另生财款，不因剥卦字义误定末破财。

## 财源、方位、客源、关系、聚财及原典
- 《梅花易数》555–557《求财占第十》以体为主，以用为财；体克有财、用克无财、比和财利快意；体生用有损耗忧、用生体有进益。财期为体克及生体卦气，来克及体生用为耗损期。弱体难制强用不预言已获财，来克的阻耗风险不等于现实已损；无体生用不意味现实无支出。493–495、796–798按原体、本互变始中末，804强弱论体、作用及同党；655、968支月日旺气，658、965方卦与体用关系参考，方位不替代现实实际业务。旺相体可制弱财，衰体难制强财；中强克不可被同衰两比机械票数消解。
- 原静艮（406–408、418–420）：守静、山田土物、东北等类象，以体为现实经营能力的取象；实物、场地经管、稳定本业收入为现代类推。春死冬囚秋休原体乏力，宜守已熟知财源。土旺火旺土相时宜以自身实际可办事项取财，而非空等贵人或外来机会。
- 本用坎（345–346、357–358）：北、水边、江湖、舟人，鱼盐酒货为古财象；对应实际已有的运输流通、水产食品、水货业务及相关客户，不预言实际职业或给钱人的身份。坎在本用受体克，故有体旺相可主动克取、弱体制财难的区别。方位只在现实已存在北方渠道时参考；不借500坎生体外援，不因坎象有盗或险推定真实偷盗与损失。
- 两坤比和（252–253、259、265–266，周易正义《说卦》09.11:23–24坤均）：坤地、西南、乡里农夫众人、实物田土和仓库等，旺相同比可协作、共同经管的钱务及货物宜核实收付职责，并非有人来生送钱；休同比平承，春死冬囚比助弱。俱按已存在的伙伴、旧客、乡里实物共同资源来讲，不指认身份。尾坤同原艮，有平承条件，无新增直接来克或己生耗；比和不单起专门财期。
- 用互震（283–285、506，09.07:21–22震动、09.11:25–26震决躁）为东、动、虚惊与山林忧。此处是真正来克原体，中段的已有行动、林木财事或办理条件变更的压力，并非断实际损失。强震在春冬防实际费用、支付及进度受限；季土夏秋震弱依真事项核实，不扩大为严重损财。无直接己生耗，现实费用按实核。
- 《周易正义》01蒙45–48：九二「包蒙吉，纳妇吉，子克家」，《象》「子克家，刚柔节也」，王弼注以刚居中，孔疏释包容、「皆与之决疑」、「能干其任」、克荷家事。今用于已有收入取得和分配职责、费用责任，理清疑难，按实际力量荷任；不用婚姻男女角色为财源或断某人给钱。
- 聚财：土旺、夏相本财可取，坤两旺相比和且无新增尾克耗，较能留财，实际需先扣现实成本与生活所需；秋休守已有、增加财要条件，聚财一般；春冬财难取、中强克，留财偏薄。建议真实现金到账、待收、成本与共担支出分开记，保正常周转，不提前支用预期收入，不推确数收益或终身财富。
