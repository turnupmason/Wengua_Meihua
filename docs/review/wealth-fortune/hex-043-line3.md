# 泽天夬九三十二月求财规则审计

- 43泽天夬→1乾为天（互）→58兑为泽（变）。静上兑金原体、动下乾金本用、下互乾用互、上互乾体互、尾下兑变用。四处各直接同比原兑金；493–495、555–557、796、804依原体和各直接用的五气，不链推，不以四同比机械重计实际收入。
- 兑西方口舌译人饮食金类（437–441、445、449–451、459）；乾西北公门长者管理金玉贵货（222–223、227、233–236、242）。现实限定已有工作、客户、真实行业任务、伙伴分工及给付成本。《周易正义》05夬46–49君子夬夬，弃情累、决断而无滞，借财务依真任务与价款作决定，不以古义臆断他人阻扰。
- 655、658、965、968月日方应。四同比有力时现实伙伴协作及已有报酬有力，力普通则原财维系，力薄新增弱；804体党虽多皆衰不吉，不能假作新财有力。无直接体克财、生体、耗体或克体，故不立专财候与损候。申酉金旺、辰未戌丑土旺金相月日作为prepare原体旺相环境，整理真正已有客户工作、共同任务和实际费用。
