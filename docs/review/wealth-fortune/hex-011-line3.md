# 地天泰九三 · 三爻十二月六维、顾问白话及动态应期规则审计

## 关系及爻义

《梅花易数》493–495、555–557、795–804：地天泰九三动在下乾，原静上坤土；互雷泽归妹上震木作体互、下兑金作用互，变地泽临下兑为变用。原坤分别生本乾、用互兑及末兑，三处己耗；体互震直接克坤。盘无比和、生体或体克用，不设新财进款候；原有收入可守，依现实工作报酬，不把弱财说成没有一分钱。三金各节点是直接受土生，旺衰决定力度，不能用投票三负机械决定结果；季土旺可承三相金实耗、木浅克，C/W；夏相土承死金浅耗、休木浅克，C/W；春死土旺震来克强、冬囚土相震克有力且休金耗实、秋休土三旺金己耗重，D/W。两兑同气不表示两笔必然支出；时段同金气合一槽，但现实成本照真正任务计，不重复计算。

《周易正义》02泰:38–41「无平不陂，无往不复，艰贞无咎。勿恤其孚，于食有福」，王注时将大变、居不失正，孔疏处变革之世艰贞无咎。借为现实财务变动时按既有约定核实际任务、费用和支付责任，守正且量力。不据古文直接断灾、失业、收入到账或食禄所得，不以爻义越过四直接负作用。

## 六维古籍链接

- 原坤：《梅花易数》251–254田野乡人农夫、259仓库、265–266田土五谷实物交易及静中求利、275西南。以原来熟悉的农产、货品经营、仓储工作、地方客户为现实既有收入条件，而非推定职业或推荐行业；体旺相可承开支，弱体以原报酬守。
- 本乾：《梅花易数》222–223公门官贵、235–236金玉器物求利及交易、242西北；中末兑：《梅花易数》437–438译人、口舌饮食、449–451求利交易、459西。乾、兑均原坤所生，只取现实西北器物采购、管理办理费用和西方沟通饮食服务、翻译费用等己方支出线索，不套用乾兑生体或克体象。真实费用可能发生于起初、中途和后段，须依现实凭据，两个兑同类不重复算成实际损失。
- 体互震：《梅花易数》284–285起动、虚惊，288木竹，294、299动中木竹茶货求利交易，306东，506震克体虚惊、山林之忧。春冬旺相木有力克弱土，若已有东方材料调运、任务变化、交付责任等现实事项，重点核实际要求；土夏、秋较弱，只正常复核，不据虚惊猜现实事故或欺诈。
- 合作与客源：原坤乡里、实物、田土、仓储真实客户是已知财源。全卦无直接生助、比和，不能从爻辞断贵人或天然合作和谐；需要共同任务则按实在的工作、出力、支付及各方成本协作，不凭关系贸增负担。
- 聚财及应期：《梅花易数》655、968支月日五态、658、965方应与555–557体生用、克体耗阻候。土秋冬三金有实耗参申酉月日合一槽；春冬旺相震木克弱土参寅卯月日阻；夏土弱震只木旺环境复核已有任务。辰未戌丑旺土作原体准备、整理既有业务环境，非独立财候。实收扣真实费用、留日用和周转，动态依实际问期计算，不保证支出或收入日期。
