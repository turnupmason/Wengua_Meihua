# 火雷噬嗑（021）暧昧表白规则审计

## 古籍本据与取义范围

实际通读《周易正义》上经卷三噬嗑（`sources/reference/zhouyi-zhengyi-hans/03噬嗑.txt`，维基文库 revid 2404948，https://zh.wikisource.org/wiki/周易正義/03噬嗑），含王弼注、孔颖达疏、全六爻、小象。卦彖颐中有物、噬嗑而亨指排除实际间隔之象；古代断狱场景不以字面移作现代情感互动的手段。

- 初九「屦校灭趾，无咎」：王注处刑初受刑非治刑、过始于微而桎足止行、小惩大诫；孔疏取械足止小过，象“不行也”。现代仅取举动有不妥即及时停止，非现实伤害预测或可惩戒他人。
- 六二「噬肤灭鼻，无咎」：王注中位所刑当、肤柔脆而乘刚深过其分；孔疏刑虽深得理方无咎，象“乘刚也”。取合理处理一项具体小问题同时不越过双方实际交流界限，不作身体伤害预测。
- 六三「噬腊肉，遇毒，小吝无咎」：王注履非位、物坚难噬，以怨生释毒，承四不乘刚而刑不侵顺；孔疏坚肉难啮且苦味为譬，象“位不当也”。取实际交流不顺后照实处理、可恢复普通相处，不判中毒、伤害、恶意或对方真实心情。
- 九四「噬干胏，得金矢。利艰贞吉」：王注失位不中而物难服，金刚、矢直，得刚直而利艰难守正，未尽通理；孔疏干胏难啮、吉仍有艰贞条件，象“未光也”。现代只取具体难处须诚实合度解决，已提供实际双向交往且解困后才有表白前提。
- 六五「噬干肉，得黄金，贞厉无咎」：王注位不正而得中，干肉坚、黄中金刚，虽得当仍须贞厉；孔疏用刑得当方无咎，象“得当也”。取已获实际信息或问题有解仍应谨慎，不能当作恋爱得到认可。
- 上九「何校灭耳，凶」：王注处罚之极、恶积不改、非可再惩诫；孔疏何为担负枷械、聪之不明而至此，象“聪不明也”。只取尊重已经听到的真实意见、停止重复追问，不据身体现象、古代诛罚或恶字判断任何现实人物品性。所有五态均保留不宜正式表白，即使有强同气或直接生体。

《梅花易数》仓库 `sources/references/meihua-2.json`、`meihua-3.json` 实读体用分主宾、体用互变、五行旺衰及婚姻占方向原段。传统古籍可供核校取义和规则一致性，不能证实现实预测准确率。
