# 地水师（007）暧昧表白逐月规则审计

原五气稿 `sources/editorial/confession-decision/hex-007.json`；古义实读 `sources/reference/zhouyi-zhengyi/02師.wiki`、`sources/reference/zhouyi-zhengyi-hans/02師.txt`（[《周易正义·师》](https://zh.wikisource.org/wiki/周易正義/02師)），辅以《梅花易数》人事占、婚姻占、体用总诀、体用互变、衰旺与克应。传统军旅之辞只取处事条件，不照字面预言现实人的祸福，不用军事统帅、任命、褒贬套现代关系。

初、二、三爻动下坎，静上坤为体，本用坎受土克；体互坤比和、用互震克体。四五上动上坤，静下坎为体，本用坤与用互坤克水，体互震受体生；始终对同一原体论本互变，不以月令生旺另增盘内直接生体。
 
| 动爻 | 古义与末卦 | 分季判断及取期边界 |
|---|---|---|
| 初六 | 师出以律，王孔释师初齐众有律；末临，兑受体生。 | 春冬旺相震中克弱体，木候限已有相处安排中段兑现遇阻；秋旺兑耗重，原无日；火土月可料理务实约定，仍缓正式表白，取体互土气仅双方已有共同安排。 |
| 九二 | 在师中，吉，无咎，王三锡命；得中有应、能任事，末坤比和。 | 春弱体受旺震克，先落实相应而缓，木候限已有相处安排中阻；火土体用同气有力且中克轻，真实双向已有时宜表意，变用同气候只实际相约之后末段交流；秋轻表意无日；冬弱体中克、无充分应合，缓表白，木候限实际约见中阻。 |
| 六三 | 师或舆尸，凶；进无应退无守，末升巽克体。 | 五气皆难，不用卦名升推情意。春冬中末木克较实，末巽木候限已有往来尾段缺配合；火秋土弱克无具体日事，旺相体可料理不等于对方有应。 |
| 六四 | 师左次，无咎；得位而无应，可处不可行，末解震耗。 | 春旺木耗、夏两相土克、土月两旺土克，难而宜止；夏本用土候限已有重约开头不便，土月用互候限已有安排中段缺确认；秋冬水体有力可保常，正式表白后置，不取日。 |
| 六五 | 田有禽，利执言，无咎；长子帅师，弟子舆尸，贞凶；王孔重有据执言、任使得当。末坎比和。 | 春弱土克无应事；火土两土实克弱水，缓表白，用互土候限已有私人转述或直接沟通中段实际答复受阻；秋冬相旺坎有承接，末水候限先前误会已实际澄清后的往来恢复，不指定谁发起或同意告白。 |
| 上六 | 大君有命，开国承家，小人勿用；师终以正功、据实定任。末蒙艮克体。 | 本用、用互及末三土克，体互震受生耗；春秋虽克轻仍证据少，冬旺坎能承担日常，均无日；火土三克较实，末艮土候只已有安排尾段确定怎样做到时的限制。全爻正式表白后置，不以蒙名或“小人”评价对象。 |

心意取象、对方自行主动联系倾向、此时宜否表白均逐篇分别说明，未将普通应答、接受安排与恋爱同意混同。旧判断与日期条件按原五气稿保留，作者逐篇读回后由独立阅读者逐篇审查，退修过的对象重新读回及重绑。
