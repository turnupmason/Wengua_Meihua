# 水山蹇（039）暧昧表白规则审计

## 古籍校读

实际读《周易正义》下经咸传卷四蹇，仓库 `sources/reference/zhouyi-zhengyi-hans/04蹇.txt`，维基文库 revid 2404967，https://zh.wikisource.org/wiki/周易正義/04蹇 ，实际六爻王弼注、孔颖达疏、卦彖象。卦辞利西南不利东北，王孔从平易与险阻解释进退，《彖》以坎外险、艮内止阐明见险能止，《象》反身修德。仓库本已对读四库本《周易注疏》卷07蹇卦疏，校“西南顺位”异文；现代不以卦辞实际推荐方位、推实际灾祸或虚构相处障碍，而取面对不便、先查真实条件、能止及自省。

- 初六「往蹇，来誉」：王注处难始、居止初、独见前识，睹险而止以待其时；孔疏解释初居艮始、不往故得誉，小象宜待。今借难办见面先退回双方认可的普通交往，不以退作为逼对方追求的手段。即使中段旺相比和有现实支持，仍先保来往。
- 六二「王臣蹇蹇，匪躬之故」：王注履当其位、居中应五，任难不为私身远害；孔疏申尽忠济难之义。只借有限、真实、自愿担事，不套古代君臣身份、不劝一人牺牲自身，不以付出交换爱情。实事参与、普通答复与独立私人联系必须分开。
- 九三「往蹇，来反」：王注进则入险、来则得位，为下卦之主、内之所恃；孔疏以邻坎说明进险、小象以一阳居下卦而内喜。今取恢复双方原来合宜的来往，前后仍有实际条件限制，不以“反”判断对方必回头、不作复合保证。
- 六四「往蹇，来连」：王注往则无应、来则乘刚，往来皆难；虽得位履正但遇难非妄所招。孔疏兼引马融“连亦难”和郑玄“迟久之意”，小象“当位实也”。现代借现实不便需要逐步处理，非归咎他人。中程得到助力，亦不可略掉前后现实限制及末段耗力。
- 九五「大蹇，朋来」：王注独处险中为大蹇，守正中而不改节，同志者集而至；孔疏进一步释“同志者”可自远来，并辨朋、友义；小象“以中节也”。现代仅取实际共同分担、已经有自愿双向私人来往且原有问题实解时才宜表白，不将普通相助断成恋爱意愿，不推具体人数或他人必至。
- 上六「往蹇，来硕；吉；利见大人」：正式引文采用仓库目录标点；《周易正义》本为“往蹇来硕，吉。利见大人”。王注往则难长、来则难终，众难济而志大得，险夷难解可兴大道；孔疏释硕大，且小象“志在内也”“以从贵也”据应三。只借从不合实际处退回可做之处、接真实可用的照应，不将大人指具体身份，不以古辞推真实感情或他人必来、不将传统候日用于确定现实事件。

按仓库《暧昧表白：断法与古籍出处》所列《梅花易数》人事占、婚姻占、占卜总决、体用总诀及互变衰旺之诀、先天后天论、占卦诀、占卜克应之诀及日应确定原体、各段直接作用及旺衰、限定候选事件。古籍核对仅印证传统规则和文字释义的一致性，非现实预测准确率之证；事实始终由本人明确表达、实际主动行动及双方自愿决定。
