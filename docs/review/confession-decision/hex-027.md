# 山雷颐（027）暧昧表白规则审计

## 古籍校读

实际通读《周易正义》上经卷三颐（仓库 `sources/reference/zhouyi-zhengyi-hans/03頤.txt`，维基文库 revid 2692196，https://zh.wikisource.org/wiki/周易正義/03頤），含王弼注、孔颖达疏、卦彖大象、六爻及小象。卦彖“养正则吉”“观其所养”“观其自养”，孔疏从养贤及自养两方面解释，今取双方相处有真实自愿和与能力相称的照顾，不套古代尊卑，不由传统卦象推定实际心意。

- 初九「舍尔灵龟，观我朵颐，凶」：王弼以舍己明鉴，羡人躁求而竞进释凶；孔疏以灵龟喻己之明德、朵颐嚼物喻贪求，小象“亦不足贵也”。仅取不因期待感情放下自己的现实需要，不评人品、不以己方投入索求回报。
- 六二「颠颐，拂经于丘。颐，征凶」：王注处下体之中，无应于上而反养初、违所履之常；孔疏释颠倒、拂违、征行为凶，小象“行失类也”。正式目录征凶与正义注末误作“颐贞凶”应区别，采用经文与孔疏原释征凶。今取给予方式不适宜时先调整；不按上下伦理定谁欠谁的感情。
- 六三「拂颐，贞凶。十年勿用，无攸利」：王注履不正，以谄纳于上、违养正，十年见弃；孔疏释如此行事经年仍不可用，小象“道大悖也”。今取不合实际意愿的相处应改变，不以谄字判人动机，十年绝不按现实等待或日期解。
- 六四「颠颐，吉；虎视眈眈，其欲逐逐，无咎」：正式引文完全按仓库目录“眈眈”及分号；《周易正义》王注孔疏本作“耽耽”，为异文，义不变。王注以上体得位应初以上养下得宜释吉，威而不猛、不恶而严、尚敦实；孔疏申不可亵渎、寡欲少求，小象“上施光也”。现代取合宜、量力、尊重对方而不求交换的帮助，不将虎视古象作窥探、紧盯或强迫现实人物的理由，不按上下尊卑定关系。
- 六五「拂经，居贞，吉。不可涉大川」：王注以阴居阳而违常、无应于下比于上，守贞从上可吉，患难未解未可涉；孔疏以五近上九、顺阳亲从释居贞吉，小象“顺以从上也”。仅取先守现实相处的适当范围，不冒进；不按古代身份或涉川古象推现实危险。
- 上九「由颐，厉吉，利涉大川」：王注阳处上履四阴，众宗阳而由之得养，养主不可渎而厉，居高而有所承担；孔疏以能主养释利涉，小象“大有庆也”。今取照料现实责任须能力充分而慎重，有己方料理能力不等双方心意已经明确，也不要求一人承担另一人全部生活，不作涉险预测。

《梅花易数》仓库传统体用互变五行关系作为传统规则的一致性核对；古籍不证实现实恋爱预测的准确率。此案以真实双方行动和本人明确意思为事实依据。
