# 水雷屯（003）暧昧表白：作者规则审计

## 底本与取义

- 《周易正义》卷一屯，仓库 `sources/reference/zhouyi-zhengyi-hans/01屯.txt`，维基文库 revid 2689596（https://zh.wikisource.org/wiki/周易正義/01屯）。实读王弼注、孔颖达疏、卦辞及六爻《象》；不是仅据卦名猜辞。初九「磐桓，利居贞」，注以处屯初动难，守静非贪安；六二「女子贞不字，十年乃字」，注以二志应五、屯难后来复常，疏以十为数极，不把十年当现实日期；六三「即鹿无虞……君子几，不如舍，往吝」，王孔以无虞官而追鹿释不揆相受与否，几为语辞，见不可进当舍；六四「求婚媾，往吉，无不利」，四应初、二不从初、象「明也」为察明实情后可往，不保证现代对象接受；九五「屯其膏，小贞吉，大贞凶」，注系应于二而施未广，疏小正出纳、大人不能博施，不以安慰或少量回复当广泛推进；上六「乘马班如，泣血涟如」，进无所适、居不获安、无所委仰，「何可长也」，戒持续困滞，不定实际痛哭伤害。
- 《梅花易数》仓库 `sources/references/meihua-2.json`、`meihua-3.json` 实读体用生克、互变与旺衰原段；体为主用为事，动爻所在卦为用，不臆造互相传导的复合生克。变用不另改原体，末同气不作直接生扶。古籍只校传统取象，不是情感预测准确率的实证资料。
