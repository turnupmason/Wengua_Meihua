# 水泽节（060）暧昧表白规则审计

## 古籍校读

通读《周易正义》下经丰传卷六《节》，仓库参考录文 sources/reference/zhouyi-zhengyi-hans/06節.txt（revid 2404988，https://zh.wikisource.org/wiki/周易正義/06節）。卦辞「节，亨。苦节，不可贞」，彖言节以制度，不伤财，不害民；取实际相处有可持续的分寸，不以古制提出恋爱义务。正式完整爻引以项目目录定本为准，上六用分号。参考录文校勘说明据《周易注疏（四库全书本）》卷十261、274–275行网页，初九“虑于险为”校为“虑于险伪”、六三疏“不节苦”校为“不节若”，非古本影像审读。

- 初九「不出户庭，无咎」：王孔取节之初立制须慎密，知通塞，时可行方行。现代借真实相处分寸未成熟先慎，不按户庭断现实所在、人身行动，也不据无咎保证结果。
- 九二「不出门庭，凶」：王孔从初制已造、至二当宣而匿失时，宜行不行、可施之事遂废。不同初九立制慎密；今借一件确能共同实行的小事可以照实问，不因古凶催表白或强求感情答复。
- 六三「不节若，则嗟若，无咎」：王注若辞，阴处阳、柔乘刚违节，自致哀嗟而无所怨咎。孔疏明失位违节及自身所致。今借自查相处中自己多作的额外安排，不以无咎保证吉利、亦不据古嗟叹判现实情绪或归责任何人。
- 六四「安节，亨」：王注得位而顺，不改其节而能亨；孔疏得位上顺五、安行其节方通，与六三失位违节反照。现代借双方真实自在能实行的相处安排，不以古承上规定谁顺从谁。
- 九五「甘节，吉，往有尚」：王孔得正居中、为节之主，节不伤财、不害民，甘为不苦，往有嘉尚。现代借两边都实际自愿、无需一方承担不合理负担，吉不保证对方表态接受。
- 上六「苦节；贞凶，悔亡」：王孔以过中至极、过苦施人不可堪，固守则凶；以斯修身、俭约无妄可亡悔。今借自查合理分寸与调整自己的过多要求，不以节制施人或责自己，也不据古凶辞断事实后果。

依项目《暧昧表白：断法与古籍出处》列《梅花易数》人事占、婚姻占、占卜总决、体用总诀、体用互变之诀、体用衰旺之诀、先天后天论、占卦诀、占卜克应之诀、日应核传统体用方向与阶段。古籍审读证实历史训义与传统推演内部一致，不是现代实际预测准确率证据。

## 本互变及五态

水泽节上坎水下兑金，互山雷颐上艮土下震木。下三爻静上坎原体、本用兑金直生、体互艮土直克、用互震木由坎生泄；末初九变坎为水（坎比和），九二变水雷屯（震为体生泄），六三变水天需（乾直生）。上三爻静下兑金原体、本用坎水为体生泄、体互震木由原兑克、用互艮土直生原兑；六四变兑为泽（兑同比），九五变地泽临（坤直生），上六变风泽中孚（巽受原体克）。

下三爻：春休坎得本囚兑薄生，死艮克浅、旺震体生耗实，初九末休坎同比平，九二末旺震为第二处实耗，六三末囚乾薄生。夏囚坎得死兑薄生，相艮直克实、休震耗，初九末囚坎比薄，九二末休震又耗，六三末死乾薄生。秋相坎得旺兑生实，休艮克可承、死震耗浅，初九末相坎比实，九二末死震耗浅，六三末旺乾生强。冬旺坎得休兑生平，囚艮克浅、相震耗实可承，初九末旺坎同比，九二末相震耗可承，六三末休乾生平。土月死坎得相兑来生实，旺艮直克重、囚震耗薄，初九末死坎同比微，九二末囚震第二处薄耗，六三末相乾直生。原体始终固定，同气和生助不能消去中段实际限制。

上三爻：春囚兑生休坎有耗，体互旺震受原体克而难制，用互死艮薄生，六四末囚兑比薄，九五末死坤薄生，上六末旺巽难克。夏死兑生囚坎耗浅，体互休震难制，用互相艮直生实，六四末死兑比薄、九五末相坤直生、上六末休巽难克。秋旺兑生相坎耗可承，可制死震，休艮生平，六四末旺兑比实，九五末休坤生平，上六末死巽可制。冬休兑生旺坎耗实，难制相震，囚艮生薄，六四末休兑比平，九五末囚坤薄生，上六末相巽难克。土月相兑生死坎耗浅、可制囚震、用互旺艮实生，六四末相兑同比，九五末旺坤直生实，上六末囚巽较能料理。体克对象非外部来克，体生耗非外方主动照应；同气不指定谁先主动联系。
