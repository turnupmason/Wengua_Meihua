# 泽地萃（045）暧昧表白规则审计

## 古籍校读

实际通读《周易正义》下经夬传卷五萃，仓库简体校注本 `sources/reference/zhouyi-zhengyi-hans/05萃.txt`，维基文库 revid 2404976，https://zh.wikisource.org/wiki/周易正義/05萃 。《彖》顺以说、刚中而应、聚以正；王孔说明并非一味顺说而聚，须以中正为主，故聚通；现代仅取两边合宜自愿相处、信任由事实逐渐建立。不以卦象断现实人物内心，不将祭祀、身份、竞争、人数具体化。

- 初六「有孚不终，乃乱乃萃；若号，一握为笑；勿恤，往无咎」：王注初应四却疑三而信难终，谦不争免咎；孔疏分别释一握至小、为笑及谦而无咎。只借相处莫求夸大、不以暂时相聚作信任已成，不从爻位断有第三者或其它人的实际心理，不以古一握对应人数或物品。
- 六二「引吉，无咎；孚乃利用禴」：王注柔中当位、异操而聚，须牵引方吉无咎；孔疏申志静退、居中未变及忠信行以省薄祭，明禴为殷春祭、四时祭最薄。现代取双方实际自愿牵引和真诚简约，不强求对方前来、不用祭礼或送礼索取回应。
- 六三「萃如嗟如，无攸利；往无咎，小吝」：王孔以三四俱失位，聚非其正而患生；上六无应独立求朋，往同志处可免咎，同阴相合非正应仍小吝。只借放下不自在的相处方式，另选双方实际同意的正常来往，不能推断情感竞争、性别或感情转向。
- 九四「大吉，无咎」：王注履非其位而下据三阴，得据失处，须立大功获大吉方免咎；孔疏亦从以阳处阴和下据三阴申义。仓库简体参考已据四库本《周易注疏》卷八“又下據三隂”校旧录“不”为“下”。古吉在实有成，不因一回相聚便断恋爱，现实困难解除且双方已有稳定各自自主的私人来往才取合宜表白。
- 九五「萃有位，无咎，匪孚；元永贞；悔亡」：王孔说虽有盛位，四据而己德不行、信不孚物，修仁守正久方悔消，小象“志未光也”。现代只借实际信任需长期事实证成，不据“匪孚”判对方人格或内心，不以传统一回接应确定感情。
- 上六「赍咨涕洟，无咎」：王孔释聚之上极无应援，不敢自安而知危忧警故免咎；孔疏释目出曰涕、鼻出曰洟。仓库简体参考据四库本卷八及四部丛刊本卷五校旧录“无所不害”为“众所不害”，非以危为吉。现代借察觉相处的费心并适时放下，不据爻辞诊断他人情绪、推真实遭遇或以悲伤要求对方安慰。校注版出处 https://zh.wikisource.org/wiki/周易注疏_(四庫全書本)/卷08 及 https://zh.wikisource.org/wiki/周易_(四部叢刊本)/卷五 。

按仓库《暧昧表白：断法与古籍出处》所列《梅花易数》人事占、婚姻占、占卜总决、体用总诀及互变衰旺之诀、先天后天论、占卦诀、占卜克应之诀及日应，核原体固定、各段直接生克比和、五态与事件候。古籍对照验证传统释义与推演规则的一致性，并非现实预测准确率证据；真实感情始终由本人明确表达、实际行为与双方自由选择来判断。
