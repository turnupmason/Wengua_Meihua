# 第025卦天雷无妄：暧昧表白长篇规则审计

## 原义与来源

底稿 b7755f365ec9d61e39e54330ea23bb80bec75cc5，`sources/editorial/confession-decision/hex-025.json` 五气原稿30行。实核 `sources/reference/zhouyi-zhengyi/03無妄.wiki` 全卦及六爻43–85行，[《周易正义·无妄》](https://zh.wikisource.org/wiki/周易正義/03無妄)。古籍及其注疏为传统取象、义理依据，非现代心理与未来行为确定事实。原注政事、耕作、灾疾语境按原义读，借为真实、合宜相处分寸，不直接套为当代事件或人物角色。

- 初九「无妄往，吉」，象「无妄之往，得志也」。王弼注“行不犯妄，故往得其志”，孔疏“不为妄动”。今借如实行动，非预先确定他人会给予爱情。
- 六二「不耕获，不菑畬，则利有攸往」，象「不耕获，未富也」。王弼“代终已成而不造也”，孔疏不敢创首、唯守其终，古臣道语境。借延续已有真实相处，不凭空造机会或欲不劳得情。
- 六三「无妄之灾，或系之牛。行人之得，邑人之灾」。古注以系牛、行人与邑人说同一事不同人承得失，系牛在有司与邑人的不同处境，不是定现实某方有罪。现代借问清实际变动与牵连，绝非具体灾害、事故或他人心理变化的预测。
- 九四「可贞，无咎」，象「固有之也」。注疏贵谦顺、可以任正、“坚固有所执守”。今借守合宜的真实来往与各自意愿，非不计代价维持关系。
- 九五「无妄之疾，勿药有喜」，象「无妄之药，不可试也」。古注非妄所致的偶然不顺，不宜另妄加处置；疏明是假病象喻人事，并辨致病原因和自然之疾。现代稿只借相处不要过度补救、偶然别扭可自然恢复，不用于具体健康、诊疗或停止治疗。
- 上九「无妄行，有眚，无攸利」，象「无妄之行，穷之灾也」。王弼“处不可妄之极，唯宜静保其身而已”，孔疏位穷行有灾。今借不妄推进，保留真实可相处的界限，不从眚预测具体事故，即使中段同气较好仍不宜当前告白。

实核 `sources/revised/meihua-volumes-1-3.txt` 520–532、796–804行《人事占》《婚姻占》与体用互变、旺衰诀。全节点以固定的原静体独立判生克、旺衰，没有以变卦另取体。
