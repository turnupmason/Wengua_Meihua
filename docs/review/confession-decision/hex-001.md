# 乾为天（001）逐月表白断语规则审计

原典：本库 `sources/reference/zhouyi-zhengyi/01乾.wiki`、`sources/reference/zhouyi-zhengyi-hans/01乾.txt`（[《周易正义·乾》](https://zh.wikisource.org/wiki/周易正義/01乾)）；`sources/revised/meihua-volumes-1-3.txt` 的《人事占》《婚姻占》《体用总诀》《体用互变之诀》《体用衰旺之诀》及《克应之诀》。原五气底稿为 `sources/editorial/confession-decision/hex-001.json`，基准提交 b7755f365ec9d61e39e54330ea23bb80bec75cc5。

两互皆乾金；初、二、三动于下，则上乾为体，四、五、上动于上，则下乾为体。本用和两互均对原静乾体比和，原体不随变卦另定。月令仅定旺衰，不等于盘内另有五行生体。十二月各自写定，同气判断及原取期一致。

| 动爻 | 末段及爻义 | 本项判断与原期 |
|---|---|---|
| 初九 | 下巽，姤；「潜龙勿用」重伏而未宜用，巽木受体克 | 春夏冬暂缓，土秋保留实际接触，仍不宜立即告白。土日体互限续共同话题；秋用互限已有约见合议；其余无应事。 |
| 九二 | 下离，同人；王注「出潜离隐」，可见而非尊位 | 春夏末火较强克体，保相见但缓表白，末火候限已私聊或约见后的推进阻节；秋土冬有条件轻表意，秋本用限已提见面，土体互限已有共通话题，冬不取日。 |
| 九三 | 下兑，履；「终日乾乾，夕惕若，厉无咎」以危处自警为义；王孔句读另作「夕惕若厉，无咎」，不以此换时辰 | 前中末皆比和。春宜了解而缓正式表达，夏不宜，冬原来往内轻表意。秋土已有真实双向接触时可表达，主动有机会不定先后。秋取变用末段已有私下谈话，土取用互中段深入交流。 |
| 九四 | 上巽，小畜；「或跃在渊，无咎」，可进可退、自试其可 | 春冬轻约不告白，夏难；秋土已有双向实际往来才可表达。秋用互限实际轻松邀约明确答复，土体互限双方早已提出想见的商量；不取受体克木为凶日。 |
| 九五 | 上离，大有；「飞龙在天，利见大人」，古义居中正时位而可见，不用于现代关系尊卑 | 春夏末离克弱乾，利见不宜正式表白，火日分别限已有私聊突然推进或重要会面临尾公开谈感情的压力。秋土在实际私下来往已具时轻表意，秋本用限已有私人约见，土用互限双方愿私聊的中段；冬先见后看表意，不硬取日。 |
| 上九 | 上兑，夬；「亢龙有悔」重知进退、不推进过满 | 春夏冬缓正式告白，秋土有真实双向接触时可适度表意但不能催结果，自发机会不定先后。秋末兑限已有私下谈话、土用互限双方先前已想接续的话题。 |
