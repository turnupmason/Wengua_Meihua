# 风天小畜（009）暧昧表白规则审计

## 古籍底本

- 《周易正义》上经卷二小畜，仓库 `sources/reference/zhouyi-zhengyi-hans/02小畜.txt`，维基文库 revid 2404941（https://zh.wikisource.org/wiki/周易正義/02小畜）。实际阅读王弼注、孔颖达疏、六爻及小象。以卦内具体动爻立义而非仅据卦名。初九「复自道，何其咎？吉」注初应四而四不距，循自身之道顺无违，现实取恢复双方认可的相处；九二「牵复吉」注居乾中，所升五非畜极，不闭固九二，疏释牵连、反复，象在中不自失，今取双方实际共同恢复，不以牵连读固有感情；九三「舆说辐。夫妻反目」注上为畜盛，不可牵征，疏上九固而止三、车辐脱落与夫妇乖戾为譬，不断实际争吵、不套古代夫妻位置；六四「有孚，血去惕出，无咎」注近九三有侵惧，四与上九合志同诚，三不得犯，小象上合志，现代取信实纾解现实顾虑而不预测伤害；九五「有孚挛如，富以其邻」注明五不疑二不拒其来、二牵五攀迎不专固其富，疏邻谓二，小象不独富，今取自愿实际相互照应而非推定情意；上九「既雨既处，尚德载，妇贞厉，月几望，君子征凶」注小畜之极能畜，阴满再进失道，疏同论，小象有所疑，今取已有成果宜守、戒强进，不搬古代夫妇君臣层级，不将月近望作日期。
- 《梅花易数》仓库 `sources/references/meihua-2.json` 和 `meihua-3.json` 实读体用分主宾、互变先中后、衰旺及婚姻占方向原段，本用、两互、变用均各自对原体。体克用不作外来生体；比和不决定谁先联系。古籍用于检核传统断法及释义，不是实际预测准确率的实证验证。
