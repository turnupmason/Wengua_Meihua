# 天山遁（033）暧昧表白规则审计

## 古籍校读

实际校读《周易正义》下经咸传卷四遯（仓库 `sources/reference/zhouyi-zhengyi-hans/04遯.txt`，维基文库 revid 2404968，https://zh.wikisource.org/wiki/周易正義/04遯），六爻经文、王弼注、孔颖达疏、彖象逐爻对应。维基文库简体转换本经文“遁”，项目正式目录采用“遯”及目录标点；下注乾亦见简体转换为“干”。均不据异体、标点另作判断。卦辞遯亨，王孔以退而后得通、相时度宜解释；大象“不恶而严”取不强求同时守分，不套古代阴阳消长下君子小人的权力关系，不用礼貌退让作为促使对方追求的手段。

- 初六「遯尾；厉。勿用有攸往」：王弼以尾最在后、危至而后行解释厉而勿往，孔疏以迟遯往则难免，反而不往无灾。取不再增加相处负担；厉不预示现实伤害，前段关心或中段同气不能抹掉末克。
- 六二「执之用黄牛之革，莫之胜说」：王弼以居内处中为遯主，中厚顺固；孔疏释黄中，牛顺，革厚，志坚固。《正义》本六二疏后文作“六三居中得位”，上下文及爻位实指六二。现代只取以真诚可履行的相处约定及分寸为由，不作占有、留人或必不分离的预测。
- 九三「系遯，有疾厉，畜臣妾，吉」：王注近二有系，当退而未退，惫于所系；孔疏以近系之道仅小处有宜，不可大事，小象亦明“不可大事也”。今取日常小事处理与正式改变关系不同；疾厉不作实际病伤，古代臣妾关系不套现代恋爱及身份控制。
- 九四「好遯，君子吉，小人否」：王弼以处外有内应，君子能舍、小人系恋释；孔疏贵超然而退。仅取已有接触而仍能照实际意愿留空间，不以古义给当事人定品性，也不靠故意疏远求得回应。
- 九五「嘉遯，贞吉」：王弼以遯得其正、不恶而严为嘉；孔疏申五居外中正且二为内应。现代只取坦率清楚的实际分寸，后段确有照应也仅先恢复合宜相处，不据古代上下安排彼此意愿。
- 上九「肥遯无不利」：目录无逗号，正义本“肥遁，无不利”。王弼“最处外极，无应于内，超然绝志，心无疑顾”，孔疏引《子夏传》“肥，饶裕也”，四五尚有内应，上九无应而遯最优。现代只取从容去掉不必要的牵累，既非体貌判断，也非退即能诱人追来；无不利只论退而非告白之利。

《梅花易数》依仓库规则所列《人事占》《婚姻占》《占卜总决》《体用总诀》《体用互变之诀》《体用衰旺之诀》《先天后天论》《占卦诀》《占卜克应之诀》《日应》核原体、作用阶段、盛衰及候选口径。古籍文本只能校传统解释的一致性，不是现实恋爱预测准确率的证明；真实心意、主动举动、自愿表白及确认关系均以真实本人表达和实际事实为准。
