# 雷火丰（055）暧昧表白规则审计

## 古籍校读

通读《周易正义》下经丰传卷六丰卦，仓库简体参考录文 sources/reference/zhouyi-zhengyi-hans/06豐.txt，revid 2608391，https://zh.wikisource.org/wiki/周易正義/06豐 。彖以阐弘微细、明以动为丰，戒盛必衰、盈虚消息而非恒丰。仅借真实相处是否可持续，古刑狱等语不用于现代施压。六爻完整引文均从项目目录定本，保留原标点和字形（上六闚，参考录文窥）。上六小象孔疏“天际翔也”参考录文已经依据四库本《周易注疏》卷九网页校旧“天祭”误字，本稿不声称核过古本影像。

- 初九「遇其配主，虽旬无咎，往有尚」：王注旬均，初四同阳能相光大；孔疏非正阴阳相应而同阳能够互明故无咎；小象过均相倾夺争。现代借双方平等实际分担，不以旬取十日，不将往有尚当强求推进。
- 六二「丰其蔀，日中见斗，往得疑疾；有孚发若，吉」：王注蔀覆暧障光，阴居阴且内，往见疑；居中履正、暗中不邪而有信，能够发志才吉，若为语辞。孔疏二五俱阴与往见疑。现代借现实一事需要诚实、共同澄清，不以疑疾断真实病症、猜忌或他人心意。
- 九三「丰其沛，日中见沬；折其右肱，无咎」：王孔沛为幡幔御盛光，沬微昧之明；九三应上六，仍不能充分明察，譬折肱只可自守、不可大事。只取实际相处所具条件有限，不将古身体譬喻预测伤害。
- 九四「丰其蔀，日中见斗；遇其夷主，吉」：王注阳居阴有蔀，得初以发，夷主吉；孔疏夷平，初四两阳均平互显，同配主、旬均通义。现代借平等分担、有疑须实际解，不能借见斗断真实隐情，也不以爻吉替代双方稳定自主相处。
- 六五「来章，有庆誉，吉」：王注阴柔来适尊阳之位，自光大而章显其德有庆誉；孔疏柔处尊位而居中、致庆善。现代只取实际可见照应，不以誉辞预言他人赞赏或已接受感情。
- 上六「丰其屋，蔀其家，闚其户，阒其无人，三岁不觌，凶」：王孔释丰道已成而仍自深藏，非有为而隐，可出不出则失时反道；三年为古治丰道之成。现代取实际接触不能仅靠一回热络、须有连续自愿参与，不据无人及三岁断真实失联、位置或联系日期。

依据仓库《暧昧表白：断法与古籍出处》所列《梅花易数》人事占、婚姻占、占卜总决、体用总诀、体用互变及衰旺之诀、先天后天论、占卦诀、占卜克应之诀、日应，核固定原体、各阶段直接生克比和及候选合法性。古籍核对可验证传统解释和推演一致性，不是现代实际预测准确率证据。

## 本互变与五态

- 下三固定震木原体生本离是己方投入；体互兑金直接克原木，用互巽木同比。春木旺承相离泄与囚兑弱克、旺巽实比，末死艮可制、囚乾弱克或旺震实比。夏休木生旺火实耗、死兑克微、休巽比平，末相艮难制、死乾克微或休震比薄。秋死木生囚火耗浅而原体弱，旺兑克实、死巽弱比，末休艮难制、旺乾实克或死震弱比。冬相木生死火耗浅、休兑克可承、相巽实比，末囚艮可制或休乾克可承或相震实比。土月囚木生休火见耗、相兑来克实、囚巽比薄，旺艮体克难制、相乾实来克、囚震薄比。不可把体生旺火、体克旺土视作外来克节点。
- 上三固定离火，本震及体互巽皆直接生原火，用互兑金为火体所克而非金克火。春相火获双旺木实生、囚兑可制，九四末死坤薄耗、六五末囚兑可制、上六末相离比实。夏旺火获两休木平生，制死兑，末相坤可承其耗、死兑可制、旺离实比。秋囚火获双死木薄生，旺兑体克难，末休坤有耗、旺兑难制、囚离薄比。冬死火获双相木实生，休兑难制，末囚坤薄耗、休兑难制、死离薄比。土月休火获两囚木薄生，相兑体克难，末旺坤实耗、相兑难制、休离平比。古爻对实际条件的限制不可被强体、比和或生扶取消；同气不指定先联络的人。

- 初九春夏 conditional、冬 favourable、秋土 difficult。春／冬用互旺／相巽同比取寅卯木日参中段共同兴趣接续（春若已有交集）或双方共同安排（冬原来往顺当）；秋土体互旺／相兑来克，原已谈见面取申酉金日参中段现实约法限制。夏无日，旬均不取十日。
- 六二春冬 conditional，夏秋土 difficult。春／冬用互旺／相巽同比木日参中段共同理解（春双方关心一事待澄清、冬仍有普通交流）；秋土末旺／相乾直接克原震，若正谈未明的实际见面或联络条件，申酉金日参末段限制，不另加中段候；夏无日。
- 九三春冬 conditional，夏秋土 difficult。春末旺震同比，已有经常来往方木日参尾段熟悉相处接续；冬末相震同比，原有未谈完的熟话方木日参重新接续；秋土体互旺／相兑克原震，若已谈见面加深来往（秋）或正在新约法（主动联络或见面，土）申酉金日参中段实际限制；夏无日。
- 九四春夏 favourable，秋冬土 conditional。春冬本用旺／相震直生原离，已有来往时寅卯木日参初段对方可能主动询问、给实际照应；夏秋土均无日，末旺土为体生泄不取外阻日期。
- 六五春夏 favourable、秋冬土 conditional。春冬有既有往来方本用旺／相震木日参初段实际主动联系、问候或具体关心；夏秋土无独立日候，双旺／相兑属于体克对象，不据此立外阻日。
- 上六五气全 difficult；春冬本用旺／相震直生，原仍有往来时木日参初段对方可能实际问候，不能因此推持续私人来往或改变原不宜判；夏秋土无日，即使夏末旺离同比也未有实际开放的日期依据，三岁只作古义。
