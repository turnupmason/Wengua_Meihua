# 天火同人（013）暧昧表白逐月规则审计

原五气稿 \`sources/editorial/confession-decision/hex-013.json\`；实读 \`sources/reference/zhouyi-zhengyi-hans/02同人.txt\` 对应王弼、孔颖达古注，核本库同人经文。梅花体用、人事占、婚姻占、体用互变、衰旺、克应为结合依据。古代宗亲、争战、城墉等不照字面套现代情感，不据爻象猜现实竞争者，不把三岁定为日期期限。

初二三动于下离，静上乾为原体，本离克乾，体互乾同比，用互巽受原乾克；四五上动于上乾，静下离为原体，本用及用互乾由离所克，体互巽生原离。同一原体贯通本互变，月令定旺相休囚死，不另加直接生助。

| 动爻 | 古义及末变 | 五气判势与取期 |
|---|---|---|
| 初九 | 同人于门，无咎；王孔无应于上、心无系吝而通同，末遁艮生乾。 | 春夏本离克弱乾，候火限已想到新增私约之起头不便；夏末相艮实生利后，春薄生。秋土有末艮生，前情已实才有自主续联、可轻表；候土限原有相处后的续联。冬薄生无具体日事，缓告白。 |
| 六二 | 同人于宗，吝；仅同所应、范围偏狭，末乾比和。 | 春夏本离克而缓表，火候限已有私人话题或约见的开端不便；土秋只有原圈限已经实际放宽、双方确有圈外接触才宜轻表，末金同气限续话、不定谁发起；冬普通接续、主动弱，无日。 |
| 九三 | 伏戎于莽，升其高陵，三岁不兴；王孔量势观望不进，末无妄震受体克。 | 五气均不宜当前表白，春夏本火候仅真实已有私人谈话或反复同一邀约之起头障碍，土秋体互金候仅实际普通会面/共同事项中段，冬无日，三岁不作期限。 |
| 九四 | 乘其墉，弗克攻，吉；困而反则，王孔重能反自思愆，末家人巽生离。 | 春夏旧不合宜办法已经实改且双向已具，宜表；末木候限真正改变后外方续联。土弱生可轻表无日，秋弱体弱生缓告白无日，冬相巽生体有后助但正式表白后置，末木候限改实后续联。三金不是外来克体，勿由卦名断家恋。 |
| 九五 | 同人先号咷，而后笑，大师克相遇；先隔后遇，末离比和。 | 春体互旺巽生体，木候限正在处理此前实际不便时的主动照应，双向已实宜表；夏末火同气候只已实去隔后的交谈，不单定谁先；土秋薄生与同气不足找具体应事，土轻表秋缓；冬体互木候限实际处理中照应，末同气弱，缓表。 |
| 上九 | 同人于郊，无悔，象曰志未得；远内争而未获亲近同心，末革兑受体克。 | 春秋冬土夏均以一般来往为边界。春旺巽体互生、已有共同事项可轻表，木候限中段主动搭话；夏同样可轻表但无日；秋土弱生、受克之金不作阻日，无日且缓；冬相巽生体，木候限已有双方愿照看的实事中段互助，正式表白稍后。 |
