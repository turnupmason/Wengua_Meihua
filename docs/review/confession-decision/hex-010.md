# 天泽履（010）暧昧表白逐月长稿规则审计

- 履上乾下兑，互卦上巽下离；初、二、三动下，原体固定上乾金，本用下兑金，体互巽、用互离；变用分别坎水、震木、乾金（天水讼、天雷无妄、乾为天）。四、五、上动上，原体固定下兑金，本用上乾金，体互离、用互巽；变用依次巽木、离火、兑金（风泽中孚、火泽睽、兑为泽）。中末各直接对同一原体；不重取体，不由月令引入假生扶节点。
- 十二月令：寅卯木旺、巳午火旺、申酉金旺、亥子水旺、辰戌丑未土旺；生旺者休、旺生者相、克旺者囚、旺克者死。乾兑春囚、夏死、秋旺、冬休、土相。五态同组 outcome、judgment、timing 完整相等。
- 实读《婚姻占》“体用比和，则彼此相就”；此项目以双方接应为比和，不指定近期先发联系者；体克用取问事人可料理的实际相处条件，体生用是其投入，克体仍须按实际旺衰与爻戒。全卦任一动爻皆无直接生原体，不虚构外方起话的必然证据或感情承诺。
- 初九依王注“履道恶华，故素乃无咎”“独行其愿，物无犯”，孔疏以质素而往释之。末坎受乾生，夏秋冬春土分别囚相旺休死；初相接不掩中离克与末泄。春夏火气候选只参已有接触的中段顾虑；秋土金候选只已有熟悉小约或普通交流；冬无独立近事。各月缓正式表白，秋土有轻表机会，夏不宜。
- 九二据王注“履道尚谦，不喜处盈，务在致诚”“居内履中，隐显同”，孔疏以阳居阴谦退得中解释坦坦。末震与体互巽均受原乾克；春夏弱金难制且离克实，秋土两木可制且中克可承，实际私人双向来往已具适合正式表达。春夏中段火候只参已提议从公开转私人相处的不便；秋土初段金候已有相约，冬无近事。
- 六三完整爻辞“眇能视，跛能履。履虎尾，咥人凶。武人为于大君”。王孔以阴居阳失其位、所见所行有限而自许刚进、欲行九五之志为凶；不借古代形体、位分、虎尾词判断现实人物或伤害。末乾与原乾比和，前末再强也不能取消爻戒，全年不宜正式表白。春夏体互/用互角色仍按下动，选用互离中段火候参已准备私人谈话或普通接触突变压力；秋土末金候仅普通交流续接，冬无近事。
- 九四依王孔近五危惧、以阳居阴而谦退终于获志，明白与六三强进之凶相区别。变巽与用互巽双体克；春夏身弱受体互离克而难制木，秋土金强可承轻克、可制木，已具私人双向条件可正式表白。春夏中段体互离火候选只本人顾虑，秋土本用金候已有实际相约，冬轻表、正式缓且无日级事件。
- 九五“夬履，贞厉”，王孔解释刚决行正、履道恶盈而居尊故厉。现代不套古位分，取不能用果决强求感情答复。体互离及末离两次直接克，春夏不宜表白，秋土冬可轻表而正式缓。春夏末离火候仅已在谈关系时尾段压力；秋土本用金候前段既有相约相谈，冬无独立日级近事。
- 上九“视履考祥，其旋元吉”，王注履道已成可考所行，孔疏“旋谓旋反也”“不坠于履而能旋反行之”。现代回看实际共同照应和是否能再行，而非读取未表达感情。末兑与原体比和；春弱同气、相离克但旧无具体谈话候选；夏不宜正式表白，体互离旺克火候参已备复谈旧事中的实际中段顾虑；秋土末兑金候参可信往来后能够合意谈话，双向条件已实宜表；冬轻表正式待实无日级事件。
