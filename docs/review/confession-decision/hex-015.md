# 地山谦（015）暧昧表白规则审计

## 古籍本据

- 《周易正义》上经卷二谦，仓库 `sources/reference/zhouyi-zhengyi-hans/02謙.txt`，维基文库 revid 2000726（https://zh.wikisource.org/wiki/周易正義/02謙）。逐爻核对王弼注、孔颖达疏和小象；《彖》天道亏盈益谦不等同于被动等待；以实际动爻及具有相处证据的情境为限。
  - 初六「谦谦君子，用涉大川，吉」：王注处谦之下、能体谦谦而涉大难；孔疏“大川”假像，象“卑以自牧”养德。取双方合度料理实际困难，而非推现实危险。
  - 六二「鸣谦，贞吉」：王注明鸣为声名闻之，得位居中谦且正；孔疏释行谦广远、象以中和为心。取真实礼貌表达并守分；不以声名判他人心意。
  - 九三「劳谦，君子有终吉」：王注唯一阳为众阴所宗、上承下接劳谦匪解；孔疏引接众人疲劳而君子有终、象万民服。取双方实际承担而做成事，不以劳换取对方服从或感情。
  - 六四「无不利，撝谦」：底本简化字作㧑（异体），沿原稿撝谦字形。王注位在三上而能谦下、承五谦顺、上下皆合；孔疏指㧑皆谦、不违法则。取言行合宜有分寸，非无条件推进。
  - 六五「不富以其邻，利用侵伐，无不利」：王注尊位用谦顺得邻而不待富，所伐骄逆；孔疏不滥罚无罪，象“征不服也”。只借具体实际妨碍可以合情处置，不将古代征伐直接应用于任何人，尤其不能把对方拒绝感情视为过错或要克服的对象。
  - 上六「鸣谦。利用行师征邑国」：王注最外不与内政、有名而志功未得、仅可邑一国；孔疏外位非内有实功、所能及有范围，象“志未得也”。只取自己现实能处理的范围有限、尚未实现的感情不可视为已成，绝不以征伐取感情服从。
- 《梅花易数》仓库 `sources/references/meihua-2.json`、`meihua-3.json` 原文体用、互变、衰旺与婚姻占方向实读，遵守静原体贯穿本互变；古籍支持传统断法和用语核对，不能作为其真实预测准确率的实证验证。
