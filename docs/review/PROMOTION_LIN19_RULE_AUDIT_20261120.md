## 三、必须纠正的古义限缩

1. **初九咸临**：王孔以初四正应、刚感顺、志行正而获吉，含有完整守正得吉的积极意义。不能压成“只是方向没错”，更不能倒推读者已经缺少某项管理经历。现行未升来自无生有克、本泄与在任专条；保留吉辞的解释张力。
2. **九二咸临**：保留“吉，无不利”的完整吉义与二五相应中的刚柔取舍。孔疏“有从有否”包括献可替否，既不全顺、也不全违；不等于尽量少附依据，更不推定上级错误。两处木克受金制而轻，不能为未升夸大成强压。
3. **六三甘临**：“甘”指佞邪悦媚而不正，不能缩成说话流利或回答偏题。既忧在王孔为尽忧其危、改修其道，能使过咎不长；要写足真实纠偏的作用，也不声称读者已经谄媚。变泰本有交通吉义，不反写成虚假顺利。
4. **六四至临**：王孔强调处顺应阳、不忌刚长、履位正而尽临之善。原稿把“至”写成凡事亲自下场、每项亲手操作，失之过窄；任责与接纳合宜的力量可以并行。变归妹“征凶，无攸利”与晋升之求进有张力，须完整登记；现项目无生无克的卦象否决条不适用于这里有生无克之盘，仍保原结论，不能消去反证。
5. **六五知临**：以礼纳刚、委任有能而不侵其任，成就众人能力，正对居位任事与统领职责；不能说与晋升全然无关，也不能只落成“某套方案选对”。保留现行末泄优先；不再援引“变生体及比和”反推其余全部无吉义。该句是原典的正面陈述，不是穷尽所有可能的排他命题。
6. **上六敦临**：志在内指向内卦二阳、志在助贤，敦厚地支持贤能而得吉。不能解释成向内翻旧数据或积累的纸张很厚。用党与三处生体可并见，整体体势衰不抹去扶助的存在，亦不把诸助相加写成托举有力。
