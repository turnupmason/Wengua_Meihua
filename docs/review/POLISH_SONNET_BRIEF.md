## 过不了的篇怎么写判词

简断前两句里、总断里，必须出现下面任一说法（检查脚本按这张表认）：
还差一截、还差一口气、还差几分、离合格线还差、离线还差、差在线下、落在线下、落到线下、够不到线、够不着线、没够上线、没能过线、还没到线、未到合格线、差一点到线、差几分到线、停在线下、压在线下、没上线、上不了线、差着几分、还欠一截、还欠几分、离那条线、没摸到线、线下还差、还差半截、差了一口气、够不上、达不到、没能过。

- 过不了的篇里，不能出现能过、拿下、过关、稳过、过得去、考得过这类「过了」的字眼。
- 判词别贴着泛词放（「总分没够上线」「分数落在线下」在全库已经用滥了，会撞 8 字片段）。把这一篇的具体事放在判词旁边，例如「末题只收回一小半，没够上线」。
- 简断末句不要写成留分句。检查脚本的认法是：末句同时含「分/拿/丢/在手/算数/落袋」中的一个，和「稳/照/不会/丢不/拿得/实/足/都在/算数/一分/不少/落袋/跑不掉/在手」中的一个。注意「照样」「其实」「证实」「每一分」也会被认成留分句。

## 其他硬性限制（检查脚本会拦）

- 简断 60–120 个汉字，不以「这一场 / 这次 / 这回」开头。
- 开局不以「开头 / 开场 / 开卷 / 开局 / 起步 / 起手 / 一开」开头。
- 正文别用「空着」「半空」这类会被当成空亡术语的词，改说「没写出来」「留白」。
- 8 字片段：全库任两篇不能共用连续 8 个汉字（不算标点），**跨栏也算**，简断末尾接开局开头会连成一串。撞了就改自己这边。

## 怎么写回

写 edits.json，用 `node scripts/review/agentfix.cjs N edits.json sonnetPolish` 写回：

```json
[{"i":3,"col":4,"set":"简断全文","why":"委婉判词、去起首判语"},
 {"i":3,"col":8,"from":"原句片段","to":"新句","why":"……"},
 {"i":3,"col":"t2:0","set":"事件","why":"应期重写"},
 {"i":3,"col":"t3:0","set":"提示","why":"应期重写"},
 {"i":7,"col":"omit","set":"无期说明","why":"……"},
 {"i":3,"read":"读出了什么、怎么改的（或为什么不改）"}]
```

col：3 题、4 简断、5 开局、6 过程、7 结局、8 总断；`t2:k` / `t3:k` 是第 k 个应期窗口的事件 / 提示。

## 每卦交付门槛（全部为 0 才算完）

`bash scripts/review/chk-exam-hex.sh N` 一次跑四项：

- `flag 0`（text-packet）
- `err []`（check-hex --polish）
- `sim 0 []`（similarity：无超限、无共用 8 字片段）
