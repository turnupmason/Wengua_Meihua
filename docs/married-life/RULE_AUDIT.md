# 夫妻婚姻第二版样稿 · 逐项卦象证据审计

## 新定写作方式

根据用户对首批稿的意见，六篇重新原创正文与简断，另补一篇乾受体克的对照盘，不以虚构的家庭开支、周末活动、探亲、家务争执等情境充当断语依据，也不以一条泛泛的生克结论去套所有家庭问题。每一具体判断须能回溯到实际卦的角色、五行作用方向、月令力度，以及相关卦类或古爻依据，再提出直接针对该象的经营建议。

本问适用于已婚夫妻，关联现有 `relationships.married-life.improvement` 及 `relationships.married-life.continuation`（[正式分类](../PRODUCT_CATEGORIES_V1.md)）。问婚姻长期安稳与当前矛盾能否改善应分别作判断。子女方向仅看婚姻现状及共同承担新增家庭责任的条件，明确回答较宜考虑、宜先处理特定矛盾、或目前不宜急于决定；不写孕期、生产期、性别、是否能怀孕或生育能力。夫妻有无相应亲属、真实交往和共同意愿以本人情况为准，不凭卦象判定已发生事实。

## 原典立证

- [《梅花易数》卷一至三修订录文](../../sources/revised/meihua-volumes-1-3.txt) 第129–137行《八卦万物属类》、第769–770行《八卦定阴阳次序》：乾父老人、坤母老妇，震长男、巽长女、坎中男、离中女、艮少男童子、兑少女舌妾。身份类象是取象方向，并不是现实身份识别。
- 同书第493–511行《体用总诀》：本为始、互为中、变为末。第495行体克用、用克体、体生用、用生体、比和分别定其作用；第496行乾生体有尊长惠送之益，第502行艮生体有安稳之意，第503行兑生体有喜悦事、朋友讲习之事；第504行乾卦克体「或有怒于尊长」，第511行兑卦克体「主口舌事之纷争」。乾来克、乾被原体克、乾生体、乾同气不能互换。后两种或被体克结合角色、旺衰作现代亲属关系类推，不冒充原书已有该专断。
- 同书第520–522行《人事占第二》、第524–525行《家宅占第三》、第530–532行《婚姻占第五》：体为主，用为宾或所问之事；用生体有益、体生用耗、体用比和吉、克体不宜，详察互变及盛衰。婚姻占较多涉及未婚成婚、门户旧制，现用于已婚相处须重新审核，不直接搬运成婚吉凶或外貌性情。
- 第542–543行《生产占第六》另定「以体为母，用为生」，与本问作用不同，不用于推算是否生育。此处的育儿适宜性是基于婚姻关系承接力的现代经营判断，不是书中已有的专门生育结论。
- 第795行起《体用互变之诀》《体用衰旺之诀》按本、体互、用互、变用分别对原静体判关系；体互较紧、用互次之，不因互变重新定体，不擅自采用间接生克消解直接克体。
- [《周易正义·说卦传》八卦名训](../../sources/reference/zhouyi-zhengyi-hans/09.07.txt) 第21–22行：「乾，健也。坤，顺也。震，动也。巽，入也。坎，陷也。离，丽也。艮，止也。兑，说也。」兑之说为悦，不能一出现就断争吵；[身象](../../sources/reference/zhouyi-zhengyi-hans/09.09.txt) 第21–22行坎为耳、兑为口，孔疏明主听、主言语；[畜兽象](../../sources/reference/zhouyi-zhengyi-hans/09.08.txt) 第22行孔疏「离为文明」；[广明卦象](../../sources/reference/zhouyi-zhengyi-hans/09.11.txt) 第21–36行乾父、坤母、震决躁、巽进退不果、坎隐伏加忧、兑口舌妾。以本问实际关系决定采用哪个象，不枚举所有象，不从隐伏假定隐瞒，不从妾象断婚外恋。
- 《占卜克应之诀》婚姻吉凶期：「若吉凶之期，但以生体及比和之年月为吉期，克体之年月为不吉之期也。」本批只给已有相处事项的年月观察方向，不规定婚姻结局日。
