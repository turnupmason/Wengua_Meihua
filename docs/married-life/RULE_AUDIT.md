# 夫妻婚姻首批原创断语 · 规则与出处审计

## 问项定义

本批为已婚夫妻的联合阅读样稿，关联项目现有 `relationships.married-life.improvement` 和 `relationships.married-life.continuation` 两个细分问项（[正式分类](../PRODUCT_CATEGORIES_V1.md)）。长期婚姻质量、能否继续安稳生活、当前具体矛盾能否改善不是同一个结果：允许维持但仍有摩擦、暂时改善但长期仍有约束、相处有稳定基础但须持续经营等不同层次，不将吉凶机械地换成离婚或不离婚。

本次未重用表白、确立关系、复合或谈婚事稿件，也不从旧求婚判码继承结论。六个不同盘分别按实际原体、四处作用关系与原爻古义重新撰写。首批是文稿预览，不变更正式应用导航、数据结构及运行时。

## 古籍依据、适用范围

用本仓库修订录文 [《梅花易数》卷一至三](../../sources/revised/meihua-volumes-1-3.txt) 与 [《周易正义》王弼注、孔颖达疏](../../sources/reference/zhouyi-zhengyi-hans) 为本批实读材料。

- 卷二第520–522行《人事占第二》：“体卦为主，用卦为宾。”用生体为进益，体生用有耗失，用克体不宜，体克用可料理，比和利；再看互变、盛衰。婚姻中的开头、过程中和其后生活安排分别以本用、体互及用互、变用对原静体的直接作用判断。
- 第524–525行《家宅占第三》：“体用比和，家宅安稳。”家庭环境的适用仅限现实共同生活，不把家庭环境的吉凶偷换为某个长辈的品性。
- 第530–532行《婚姻占第五》：“体用比和，婚姻吉利。”该章另有婚易成、可成但迟、婚资、门户等未婚求婚语境。已婚关系不直接继承成婚成败、嫁奁或门户等级断法；参考相助相合、克制耗失之理，结合婚后相处的长期性质重新作适用判断。原人物外貌、性情条目不直接应用于本人或亲属的身份指认。
- 第542–543行《生产占第六》另定“以体为母，用为生”，其占事与婚姻原体用途不同。本批婚姻盘只可借古爻意和相助分担象谈双方对于子女的意愿、家庭资源与共同准备；不据此确定怀孕、孕产健康、能否生育、性别、日期等。
- 卷三第795行起《体用互变之诀》《体用衰旺之诀》：原静体贯穿本互变；“用为占之即应，互为中间之应，变为事占之终应。”同气为接应，不指具体人物，克体不等于婚外恋，体生用不等于单方过错。
- 卷三《占卜克应之诀》有“然婚姻亦不过卜其吉凶，不必刻其期也。若吉凶之期，但以生体及比和之年月为吉期，克体之年月为不吉之期也。”长期相处质量采用年月参考；只有原来已发生或正在商量的相处事项才谈相关阶段，不直接断离婚、婚外关系、怀孕或生产时间。体克用不偷换成来克，不将五态作为必然改变的定时保证。

五态依据：寅卯木旺火相水休金囚土死；巳午火旺土相木休水囚金死；申酉金旺水相土休火囚木死；亥子水旺木相金休土囚火死；辰未戌丑土旺金相火休木囚水死。以项目显式月令键为准，不取公历月份代替月令。
