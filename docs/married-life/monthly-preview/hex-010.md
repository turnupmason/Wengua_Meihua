# 10 · 天泽履：六动爻与十二月令

本页为夫妻婚姻逐月原创断语，已完成 60/72 篇（5爻）。

本问适用于已婚夫妻，按卦、爻、月令与具体象类看相处方向、矛盾、经营和育儿适宜度；年月仅供已有家庭事项参考。真实家庭成员、行为、意愿及育儿决定依现实确认。

## 初九动 · 寅月

日常还能好好说话，也要正视原来尚未处理的具体生活难处

天泽履 → 风火家人 → 天水讼

夫妻之间能维持平常的和气，并不说明共同生活中各项责任都已经处理得很好。寅月天泽履初九，静上乾金为原体，春囚；开端虽有同气接应，力量有限，中途既有难以料理的事务，又有直接来克，后面还须自己投入精力。婚姻长久安稳的条件偏弱，宜从原来真正难办的事情着手改善，不必急于维持别人眼中的和睦。

本用下兑金春囚，与原乾同气比和。兑为悦又为口，平常能够听取彼此意见的长处宜保留，但目前并不容易仅凭商谈就把难处解决。《体用总诀》在兑克体时才有口舌纷争的直接条文，这里本兑比和，说明双方还有理解的方向，不能因为原有沟通未奏效便断言争吵已经发生。若现实已有争议，则照实情料理，不必从一回不合推及全部相处。

中间体互上巽木春旺，受原囚乾克而难料理，巽进退不果，家中尚未定下的具体安排较容易停在商谈上。用互下离火春相，直接克原乾，离取明，需要看清哪些现实条件依然制约双方。还没有取得共同意见的事，先别让其中一方开始承担，在已有安排中找出能够同时减轻两边负担的部分。

初九「素履往，无咎」，王孔以质素而不尚华解释，今借朴实相处、不作过多表态之义。末变天水讼，下坎水春休，受原乾生而有己耗，坎耳听、取加忧，后续沟通宜有明确目的，别在已说明白的顾虑上继续耗费。无孩夫妻目前暂缓要孩子，先解决眼下家事难处、建立稳定共同分担。让当前生活逐渐变得两个人都担得起，比靠一回谈得开心就增加责任更有助婚姻长久。

## 初九动 · 卯月

夫妻相处宜少些费心的表态，把尚未确定的家事逐件处理清楚

天泽履 → 风火家人 → 天水讼

有些话不一定要夫妻两个人都同意才算相处得好，已经过共同决定的事情能够稳定照办才有长远意义。卯月天泽履初九，原静上乾金春囚，开头同气支持虽然还在，中途料理实际难处的能力不足，后面自己也还要付出。婚姻眼下较难安稳，改善需要让平日和气真正起到处理家事的作用，不能只是反复表达善意。

本用下兑金卯月囚，与原乾比和，兑主说悦、口言，说明已有交流尚可保留，但同气弱，实际共同应对的力量需要积累。若原来已经能够有话好好说，就可以从双方都确认的责任做起，不必把所有想改变的事情都放在同一次谈话中。没有商量好的做法，可以各自提出需要哪些条件才能照办。确实需要他人参与的安排，也应等有关的人亲自表示同意。

体互上巽木春旺，为原囚乾直接所克而难理。巽有迟疑不果之象，原来议而未定的现实安排需重新处理。用互下离火春相，直接克原乾，取离为明，过程中尚有实际牵制，宜确认是缺少实际条件还是彼此尚未取得共识。已经无法实施的旧安排，可以先缩小责任范围，待两人有真实余力后再议其他事项。

「素履往，无咎」，初九古注以处履之始用质素、独行所愿，今取不为表面的和气勉强自己接受未议妥的责任。末变天水讼，下坎水卯月休，受原乾直接生而耗，坎主听和加忧，后段维护沟通还须心力。还没有孩子的夫妻眼下宜先缓下育儿计划，把现有生活安排实际料理好。两个人能够从简明的共识走到真实分担，婚姻才较有改善条件。

## 初九动 · 辰月

良好的沟通若能直接转化为家事分担，两个人长久安稳的条件就更有实际根据

天泽履 → 风火家人 → 天水讼

若日常相处中已有两人能共同料理的事情，就可以从这些实际长处开始，继续改善原来还有分歧的生活安排。辰月天泽履初九，静上乾金土令相，开端同气有力，中间虽仍有现实限制，却有处理相应事务的能力，后来自身耗费较薄。婚姻长久安稳有较好的趋稳依据，宜不急不躁地保持双方已经认可的合作。

本用下兑金辰月相，与原乾比和。兑为口言、说悦，夫妻间通过交流形成共识的方向较实。对于已经共同决定的事情，仍需将后面到底谁负责哪些内容说明白；如果两个人能够各自照做，不必事事一起操作，这样也能减少彼此不必要的劳神。过去共同料理过的实际问题，日后还可以从这种合作方式借鉴，而不是一回回重复彼此原来已经说清的意见。

体互上巽木土令囚，原相乾克巽而较可理，巽有进退不果之象，尚未确定的具体家事有能力找出办法。用互下离火辰月休，直接克原乾而普通，离取明，中段限制应依事实逐项处理，不因目前沟通较好便略过尚存的分歧。双方仍可以按各自实际条件作选择。

「素履往，无咎」，初九古注贵质素去华，今天夫妻重真实相处、实际承担，而不刻意追求一切都做得尽善。末变天水讼，下坎水辰月死，受原乾生，后续自己的耗费较薄；坎取耳、加忧，有不明的顾虑仍可听清。没有孩子的夫妻若共同分担稳定，两个人真实愿意、现实养育条件具备，可以考虑要孩子。保持原有共识和解决难处的能力，才较能使婚姻和睦长久。

## 初九动 · 巳月

先解决现实生活中已经吃力的事情，不要借表面和气增加共同责任

天泽履 → 风火家人 → 天水讼

已有的共同责任若一直没有找到恰当的分担办法，眼下最应该重视的是现实难处，而不只是让两个人感到彼此仍然关心。巳月天泽履初九，静上乾金当夏为死，前面同比弱，中段有旺火直接来克且还有不易料理之事，后段自身会有少量付出。婚姻长久安稳的条件偏弱，宜优先缩减原来难以完成的安排。

本用下兑金夏死，与原乾直接比和，兑取悦及口言，平常交流可以继续，但同气承接之力微。夫妻如果还有事情没谈妥，不妨先让彼此说明到底哪些责任真的想承担，哪些客观条件目前不允许。能够商议已是可取的地方，仍不足以证明以后的家庭生活能由双方稳定共同维持。已经谈明的事情也要看后来能否由承担者照着实行。

体互上巽木巳月休，受原死乾直接克制而仍难处理，巽进退不果，实际事务尚未决定不宜立即增加新责任。用互下离火夏旺，直接克原乾，中途真实牵制较重，离主明，尤其要核实原先打算做的事为何实际做不到。在这些条件尚未改变以前，不因对方表达了愿望就把相关事项全部定下来。

初九「素履往，无咎」，王弼孔颖达解处履之初贵质素、恶华，现代夫妻取朴实按现实能力做决定。末变天水讼，下坎水巳月囚，由原乾直接生，后段自己耗费虽薄，坎耳听、加忧，尚需把未解决的顾虑听明白。无孩者目前宜暂缓要孩子，先处理既有家事制约和分担问题，让两边真实有余力。能够少作一些尚不具条件的计划，更有利于婚姻以后慢慢走稳。
