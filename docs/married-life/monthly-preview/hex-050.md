# 50 · 火风鼎：六动爻与十二月令

本问适用于已婚夫妻，按卦、爻、月令与具体象类看相处方向、矛盾、经营和育儿适宜度；年月仅供已有家庭事项参考。真实家庭成员、行为、意愿及育儿决定依现实确认。

## 初六动 · 寅月

原先家庭分担有不合宜处，可以先利用真实帮助将它改好

火风鼎 → 泽天夬 → 火天大有

如果夫妻原来已经认识到日常生活里有些安排不够适宜，现在也找到了能够改变它的实际条件，不妨先让这份改善真正发生在日常分工上。寅月火风鼎初六，静上离火为原体，春相；开端巽木直接生原离强，中间兑和乾以及末段乾均受原离克而可料理。婚姻较有长久安稳的条件，宜积极利用现实已经具备的协作能力，将以前尚未安顿好的事情逐项改善。

下巽本用寅旺，直接生原离有力。巽取进退，现实若原先一些需要共同办理的事务总是因为时间不够而改变计划，可以借现在确有相应帮助的条件，先商量有没有一种两人都能长久照办的分担办法。真正有利的支持应当落实在原来实际遇到困难的事上，不因出现一次照应便默认日后任何家事都有人帮忙。

互卦泽天夬，上兑寅囚，下乾亦春囚，各受原相离克可理。兑主口言，已有安排上的不同意见比较有条件一起商量；乾有父老人意象，若实际家事涉及长辈，应按其真实需要与能力协作，并非原来有人来克体。末变火天大有，下乾寅囚，另外受原离克而可料理。后续实际家事要求仍需要认真处理，前有旺巽强生并不等于末段已经办成，也不因中尾两乾计算亲属人数。

初六「鼎颠趾，利出否；得妾以其子无咎」。古王孔取鼎覆倒趾以出否、弃秽纳新，妾子是古侧媵继室及母以子贵的历史伦理，不据此判实际第三人或生育。今借先实际去掉不合宜的家庭安排。未有孩子者若现实已经长期稳定共同分担，两个人真愿养育且实际养育条件齐备，可以考虑要孩子。

## 初六动 · 卯月

两个人已有改善具体家事的能力，就可以优先改变原先真正不合宜的安排

火风鼎 → 泽天夬 → 火天大有

夫妻对于从前一些不合宜的生活习惯，如果已经有各自认可而且能够实际一起处理的办法，宜沿着真实有成效的方向改善，不用只靠长期忍让维持过去的安排。卯月火风鼎初六，静上离火春相，本用巽木旺而直接生原离，中间兑乾和末乾各受原体克而较易料理。婚姻长久安稳的条件较好，可以先共同处理原先确有实际不便的生活责任。

本用下巽卯旺，直接生原离强。巽进退可取现实中某些做法此前没有定下来而需要实际调整的情况。如果两个人原本已有合作的条件，不妨一起确定原来哪些责任适合换个办法办理，再让能实际提供的帮助真正起作用。原有家事里的改动宜以双方真实愿意和能够持续的条件为依据，而不只看谁更想按照自己的办法处理。

互为泽天夬，上兑金卯囚、下乾也是囚，分别受原相离克而可理。兑的口言之象可取家事仍有一些意见需要互相说明，乾取父老人，若实际涉及长辈协助生活，可以共同确认需要照料的责任及各人实际能力，不从受体克推外来约束已经发生。末为火天大有，下乾卯囚，另受原离克制而可理，后续具体责任较容易安顿，却仍要以实行的结果为准，不能把中末两乾当两位实际人物或者将三个作用相加。

「鼎颠趾，利出否；得妾以其子无咎」，初六王孔释倒鼎出否、弃秽纳新，妾及子属古侧媵继室等角色说法，非现代实际第三者、子女事实或身份判断。用于婚姻，适合先把真正妨碍共同生活的旧分工改善。还没有孩子的两个人若早已在日常分工中形成长期稳定的共同承担，双方真想养育并且有实际养育能力，可以考虑要孩子，选择仍须两人真实自愿。

## 初六动 · 辰月

还有一些生活责任没有安顿好时，先看看现实能够共同承担的范围

火风鼎 → 泽天夬 → 火天大有

有些生活安排虽然最初两个人已经商量过，可真正实行时仍需要彼此投入更多精力，宜先想明白原来的分工是否适合两个人现在的生活。辰月火风鼎初六，静上离火季土休，开端巽木虽直接来生却力薄，中间两个金以及末段乾金又都是原体较难处理的对象。婚姻长期安稳的条件偏弱，目前最重要的是共同把那些还不能真正实行的生活责任改好。

下巽辰囚为本用，直接生原休离力量薄。巽有进退不果之义，现实若原来有些家庭责任一直不能确定合适的办理时间，可以先看现在真正可以得到的帮助是什么，以及这些照应究竟能减轻哪项困难。两个人愿意一起调整固然重要，但要先看实际条件，原先并没有能够持续办理的责任不宜当成后来自然可以做到。

中互泽天夬，上兑辰相、下乾辰相，分别受原离克而难料理。兑主口言，现有的意见分歧还需按实际需要进一步说明；乾主父老人，如果确有长辈参与实际家事，宜听取其真实需求再共同商量怎样负责，不能从体克对象难理推成外人对自己来克。末变火天大有，下乾也是辰相，另受原离克难理，后面还有现实责任要逐项落实，不能因为卦名大有便觉得实际情况已经改善，两个乾象也不说明真实参与的人数。

初六「鼎颠趾，利出否；得妾以其子无咎」，古义翻鼎去不善之物而纳新，古妾子说属侧媵继室母以子贵，今不以此推现实人物或生育。现代借先改变确实不合宜的生活安排。没有孩子的夫妻当下宜暂缓要孩子，等实际旧难妥善解决，现有责任能够长期稳定共同分担、双方真愿养育且有实际养育条件后再考虑要孩子。

## 初六动 · 巳月

现在已经能共同解决许多家事，有效果的分担值得认真维护

火风鼎 → 泽天夬 → 火天大有

目前两人若已经有一些共同能够处理的家庭事务，从过去的实际经验出发来调整比较不合宜的责任，比一次重新决定以后所有家事更妥当。巳月火风鼎初六，静上离火夏旺，本用巽木来生原离普通，中间上兑和下乾以及末段下乾均受原体克而容易料理。婚姻有较好的长期安稳条件，可以把原先真正行之有效的分担保留下来，实际还需要共同处理的部分也可以安排。

下巽本用巳休，直接生原旺离有普通力量。巽进退不果可借生活中以前一直还没有决定怎样办更适合的责任。若原先某些日常事务需要临时改变两个人的日程，现有实际协作可以用来共同选择更方便的办法，尤其需让各自真的能够履行。直接来生只是原来现实关系中实际有用的支持方向，不代表具体事情都已妥善解决。

互泽天夬，上兑及下乾皆巳死，分别被原离克而易理。兑主口言，原先还有不一致的生活意见，当前较有条件共同说清；若确有父辈老人参与日常责任，乾的取象应当用在其真实需求与当前照料条件上，并非外方来克。尾变火天大有，下乾巳死，被原旺离克较易料理，实际之后还需要落实的家庭责任也有处理能力。中尾两个乾和一个兑都是各自的体克对象，不累加成某种强助。
