## 初九动 · 寅月

原先没谈妥的事可以重新商量，先留住双方已有的合作

火泽睽 → 水火既济 → 火水未济

如果只为生活中的一件小事出现分歧，不一定需要立刻把两个人过去的看法全部理清。先办好眼前那件需要合作的事，往往比追问谁原来有理更有价值。寅月火泽睽初九，婚姻有继续改善的空间，已有实际顾虑仍需分别处理。静上离火春相定原体，本用下兑金寅囚，受原离直接克制而可料理。兑取口言之象，若涉及对某项家事的不同说法，可以从实际困难着手重新商量，而非争取谁先承认错误。

互为水火既济，上坎水体互寅休，直接克原相离而力平，坎取耳及忧，已有难处应当具体听清；下离火用互寅相，与原离直接同比有气，中间两个人有一起做事的实在方向。若原来为家用品添置有不同意见，可以各说清实际预算和使用需要，再共同承担选购和使用的责任。一项协调顺利的事，宜让它真正成为日常能持续的安排。

「悔亡，丧马勿逐，自复，见恶人，无咎」，古注初九无应而与九四合志，取睽离中损失不必贸然追逐、遜接以免咎之义。今日借不同意见无须急于强求一致，古恶人非给现实家人定性，自复也不许为事情自然解决的保证。末火水未济，下坎水寅休，另直接克原离而力平，后续若仍有预算以外的实际困难，须另外商议，不能拿中间的合作代答。

如果夫妇尚无孩子，当前宜先将现实顾虑及未解难处处理妥当，待日常责任能够持续共同承担、两个人有真实养育意愿及实际养育条件以后，再考虑要孩子。前后实际牵制仍应逐件处理，双方对新增责任有真实了解才宜作共同决定。特别是每日照料需要的时间，应当按各人的真实余力商定。

## 初九动 · 卯月

不妨从做得到的事恢复协作，别把一次意见不合变成旧账

火泽睽 → 水火既济 → 火水未济

夫妻一起过日子，有时候想要了解对方的态度，最有用的办法并不是反复讨论上次谈话里的每一句话，而是从两个人都愿意负责的事开始。卯月火泽睽初九，婚姻有修复和改善条件，意见不合对日常责任的真实影响仍需处理。静上离火春相为原体，下兑金本用卯囚，受到原离直接克制而较易理顺。兑主口悦，现实若在安排休息和承担家务上说法有别，可以将相互责任讨论得具体些。

中间互卦水火既济，上坎体互卯休，直接克原相离为寻常力量，坎有耳及忧象，已有难处要仔细听其真实缘由；下离火用互卯相，直接与原离同比有实，过程并非没有共同处理事情的条件。若实际一人要提前出门，另一人也有固定休息需要，可以把原来集中一时做的家务分在两边都有余力的时间，不必把任何人的休息看作可以随意取消的。

古初九「悔亡，丧马勿逐，自复，见恶人，无咎」，王孔取合志而免悔，睽时所失不宜妄逐，以及能遜接异己以免咎的原义。今借不用追着现实的人讨一种满意说法，古辞绝非断所失都会回来，也非指某人为恶。末变火水未济，下坎卯休，另直接克原离力平，后续若仍有难以协调的生活时间，应当根据实际调整，不能以中间的协作自动消除尾段制约。

尚未有孩子的夫妻，宜先把原来需要协调的生活难处处理好，等日常家事能长期共同分担、两个人真实愿意一起养育且有实际养育条件，再考虑要孩子。两边在已有责任上能否持续配合，比临时做好一两件事更值得参考；新增的照料和休息安排也宜说得清楚。

## 初九动 · 辰月

两边说法没有完全相合，先试一个实际可执行的办法

火泽睽 → 水火既济 → 火水未济

若夫妻对共同生活的开支各有一套不同考虑，宜先确定一项双方近期确实用得上的支出怎样共同决定，而非将不同的消费习惯一下作成相处好坏的结论。辰月火泽睽初九，婚姻有继续维护及改善的条件。静上离火季土休作原体，下兑金本用辰相，受原离直接克制而不易料理；兑取口言，前段某项已有的生活安排还需要费心商议，不能把善于表达等同于已经合宜。

「悔亡，丧马勿逐，自复，见恶人，无咎」，古注从睽时初无应而与九四合志释免悔，失马不妄逐及接人免咎，切勿拿古辞评判现实的人。现代所取是不用逼出一致意见，已共同承担的责任仍须负责。末变火水未济，下坎水辰死，另直接来克原离微，后段制约虽浅，原先仍未谈妥的开支分配也不能因此视为完成，要看尝试结果及后来双方能否继续共同承担。

## 初九动 · 巳月

共同承担事情的能力已经较强，可以把不同意见落实为分工

火泽睽 → 水火既济 → 火水未济

商量一件家事时，两个人若都能认真听完不同意见，再决定自己实际愿意负责的部分，已经是共同生活中非常重要的基础。巳月火泽睽初九，婚姻较有长久安稳的条件。原体为静上离火，夏旺，本下兑金巳死，受原离克而容易料理。兑有口悦之象，现实已有的沟通差异可以尝试变成实际可执行的分工，而不是只要求自己的想法得到赞同。

初九「悔亡，丧马勿逐，自复，见恶人，无咎」，王孔以初无正应而与四同心、失者不妄逐以及在睽离中以遜接免咎释。现在借看重已有的合志，而非要求一切意见相同；不以见恶人把现实任何家人定性。末火水未济，下坎水巳囚，另直接克原离力浅，后续若又遇到需要协调的事，同样宜由双方实谈实办，不能用中间的旺同比替代后续的实际分工。
