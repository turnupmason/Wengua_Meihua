## 初九动 · 寅月、卯月

活一件件做了，日志上却没几行

天泽履 → 风火家人 → 天水讼

简断

你做事踏实，不声不响把派下的活一件件做完，却很少落成文字。中期考核要翻工作日志和周报，你那几个月的记录稀稀拉拉，好些成果找不到出处，转正因此还差一截。

开局：交给你的活和你过去做的路数相近，接得顺，上手不费劲。

过程：试用中期考核那一轮，要求每项成果都对得上日志和周报里的记录。你的日志常常一周只写一两行，那几件做得最好的活，翻遍记录找不到起止和经手，只能按没有记录算。

结局：「素履，往无咎」，照本色做事，本身挑不出错，小象说「独行愿也」，你按自己认定的做，活也都做成了。可评定认的是纸面上的那份记录，日志空着的地方，成果就落不了地；期满前补写，也找不回几个月的细节。
