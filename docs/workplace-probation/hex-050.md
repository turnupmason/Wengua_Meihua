## 初六动 · 寅月、卯月

先把旧账倒干净

火风鼎 → 泽天夬 → 火天大有

简断

能转正，不费多少周折。进来头一件事是清理前任留下的积压单据，你把错的、过期的一并清出去，台面一下干净了，后面几项考核都顺着这个底子往上走，评定时几乎没有要补的。

开局：交接时留下一大堆旧单据，有对的也有错的，带教让你先理这一摊。这摊活看着乱，真动手才发现规律不难找，几天下来便有了条理。

过程：随后几件常规考核内容，流程熟悉度、报表、协作，都在你拿捏得住的范围里，一件件做下去，没遇上难缠的。交接资料帮了些，帮得不多。

结局：「鼎颠趾，利出否」，把鼎倒过来，正好倒掉里面的陈渣，小象说「未悖也」，并不违理。你开头那一番清理，就是倒掉陈渣的那一下：旧错清了，新账才立得住。期满评定照章走完，转正审批没有卡在哪一环。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，转正审批签完，结果写进人事通知，属吉应。通知到手后，对一下生效日期写的是哪一天。

总断：试用期能通过，底子是开头那一番清理打下的。清出去的那些旧单据列个清单，交接时说明去向。

古籍依据：《周易·火风鼎》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·体用》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。

## 初六动 · 申月、酉月

清了一个月的旧账

火风鼎 → 泽天夬 → 火天大有

简断

能转正，只是费力又慢：接手的那套旧账错漏多，你整整清了一个月，期间几项考核内容同时压着，一项比一项硬。清干净以后，账目站住了，评定时才把这些辛苦一并算上。

开局：交接下来的旧账第一眼就不对，借贷对不上，附件缺了一半。开头能用的线索只有一份残缺的旧台账，帮得上一点，帮得不多。

过程：紧跟着月报、核对、协作一齐压到手上，样样得使大劲，你一边清旧账一边应付，日子排得满满当当。

应期：以下为传统推算的参考窗口。

总断：清旧账清得慢，最后能转正。清出来的错漏清单留底，往后月报照着核。
