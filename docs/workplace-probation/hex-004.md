## 初六动 · 寅月、卯月

纠正过的毛病换个场合又犯

山水蒙 → 地雷复 → 山泽损

简断

带教在头一个月纠正过你一个做法：给客户报方案前要先核库存。你记住了这条规矩的样子，没记住它为什么要这样，换成内部调拨的单子，又照老习惯先报后核，单子被退了回来，考核表上「流程规范」那一栏够不上。

开局：基础的活你上手快，交上去的大都没问题。

过程：那次纠正之后，同一类客户单你都改了过来，做得规矩。

结局：「发蒙，利用刑人，用说桎梏」，启蒙要立规矩，规矩立住了，桎梏才解得开。你立住的只是外形：客户单照做，换了一种单子就认不出是同一个道理。这一回卡得早，也卡得硬，内部调拨那几张单子退回来时，评定已经近在眼前。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，内部调拨单照老习惯先报后核，被退回，属凶应。每类单子动手前，先说一遍那条规矩为什么这样定。

总断：那条规矩的来由没吃透，这次没转成。把它为什么要先核库存写成一句话，贴在每类单子的流程旁边。

开局：前半段的活做得顺，交上去的那几件都站得住。

改一个数，后面五份跟着重做

山水蒙 → 地雷复 → 山泽损

开局：起先几件活进展慢，样样要琢磨，好在做下的都站得住。
