山泽损 → 地雷复 → 山水蒙

简断

开局：春死艮土生囚兑，起头的额外投入未必大，却容易分去本来就不足的精力。

过程：坤土体互春死，同艮比和，只宜与同事核清分工。用互震木旺而克艮，中段会遇到较难满足的要求。

结局：初九须已事才宜遄往，又要斟酌所损。变用坎水春休为艮土所克，临交验还有事要处理。宜先收自己那件，这次仍偏难过。

  本用对原体为开局的直接依据。
