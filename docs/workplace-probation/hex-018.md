## 初六动 · 寅月、卯月

接下的旧摊子，漏算了一条

山风蛊 → 雷泽归妹 → 山天大畜

简断

交接来的那个项目让转正还差一步：前任的方案没算进一项新加的限制，你按原样往下做了大半，回头补那项限制时，能改动的只剩一小块，前面那一大截来不及重做。

开局：接手第一周就拿到一摞旧材料，方案、进度表都是前任定下的。

过程：做到第三周才看出方案里漏了一条新加的限制，往前翻，几乎每一步都沾上了它。

结局：能补的只有你接手后新写的那一块，按限制理顺后交得出去。初六「干父之蛊，有子考，无咎；厉终吉」，替前一任理旧账，先险后吉，吉在你理顺的那一块，沿用旧方案的那一大截来不及收拾。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，交接方案里漏掉了一条新限制，属凶应。交接材料里的方案，先和最新的规定逐条对。

总断：交接来的方案先拿新规定逐条过一遍，再决定沿用哪些。没能转正，缺口出在那条没算进去的限制上。
