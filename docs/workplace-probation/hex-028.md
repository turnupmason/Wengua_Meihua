处处小心，压不住那摊重活

泽风大过 → 乾为天 → 泽天夬

简断

手上那摊活分量太重，这次没转成，差在力气不够压。你做事极小心，每一步都垫得稳，几乎没出过错；可分到的业务量远超一个人的节奏，小心只保得住不出错，撑不起考核表上的完成量。

开局：分到你手里的业务量很大，一件接一件，节奏比你预想快得多。

过程：你照熟悉的次序一项项核，核出过一处漏掉的条件，及时补上，这几个月没出过差错。

结局：满期时完成量仍缺一块。初六「藉用白茅，无咎」，象曰「柔在下也」，《系辞》说这是「慎之至也」：东西放地上还垫一层白茅，谨慎到了极处，所以无过。你守住的正是这份无过，只是量没跟上。

泽风大过 → 乾为天 → 泽天夬

简断

常规的事你守得稳，变了样的那几件没接住，差了一步，偏差出在换了提法的任务上。日常业务照熟悉的次序推，件件不出错；可试用期过半，几项任务换了提法、改了要求，你没先把它们还原成熟悉的样子，硬按新提法从头摸，耗掉了时间。

开局：日常业务按惯例推，交得稳。

过程：试用期过半，几项任务换了提法，要求也改了，你按新提法从头摸，越摸越慢。

结局：满期时常规那块干干净净，变了样的几项没收完。初六「藉用白茅，无咎」，象曰「柔在下也」：慎守能免过，变化来了还得先认出它是哪一类旧事。
