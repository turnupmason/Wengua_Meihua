## 最高优先级问题

1. 当前场所补充主要在动侧变用取象，形制、材质、颜色与器物构造缺少逐盘适用记录。后续补写应先确认每项取象所指及来源，再解释与本用、两互、变用和原体的具体联系。
2. 来源章节中的不同方法存在前提差异。形物、验色用于见物起卦，三要十应需要现场信息，射覆猜物另有物数取体。每条新增用法都需要相应适用说明，现有 4,608 个键不能自动代表这些维度已经齐备。
3. mh-126 第 848 行有“长于凯撒之内”，公开卷三对应段落也有同文。当前只能记录疑似讹文，独立影印本校勘仍待完成。同章第 847 行的离条形制和土石内容也应另核版本。未据此改动用户原始上传资料。
4. mh-150 第 1013 行含“＄足”，第 1014 行作“近利市三位”。公开《说卦》第十一章相应处见“馵足”“近利市三倍”，提供了明确的校勘候选。原书影印、整理文本与引用版本仍需逐项登记，原始资料保留。
5. 独立专业审核和取期断法审核维持 pending。当前已完成的逐篇作者记录、程序复算和这一轮来源覆盖复核，按各自范围分别记录。
