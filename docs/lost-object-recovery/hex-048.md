## 初六动 · 寅月、卯月

旧途径没有多少新消息，原物偏难追回

水风井 → 火泽睽 → 水天需

简断

这件物品偏难找回。先看看最熟悉的收放处是否已经查过，若问了几次都只有同样的答复，不如留下最后一次实际用途和物件特征。中间可能仍要自己辨明一两条说法，到了末了有点回音也先问有没有实物能核。

开局：春令坎体休，旺巽本用受坎生，开头查找的耗费较实，旧线索偏薄。

过程：体互相离受坎克，现场查证要花力气；用互囚兑生体，能补的资料不多。

应期：此盘暂无有据的日期可列。

总断：原物难寻。先给经手处留下原件记号，等有人能实际对照再查。
