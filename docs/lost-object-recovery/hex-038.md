## 初九动 · 寅月、卯月

易辨认的东西有望从原处回来，别顺着传言追

火泽睽 → 水火既济 → 火水未济

简断

原物有机会回来，尤其是特征明显、经手处还找得到的东西。先把最容易认出的记号告诉对方，给对方一点时间核实。中间可能有认不准或找错的情形，宜就原来的收放范围查清，不用每听到一个地点便亲自赶过去。

开局：春令离体相，本用囚兑为体所克，有条件主动查找，先从辨认最容易的一处起。

过程：体互休坎克离，手续或说法可能出现不合；用互相离比体，原先收放的位置仍可请熟悉的人查。

结局：初九失马勿逐而自复，古注说马显而难隐，易被辨还。末变休坎仍克离，物件若难区分，单等未必能回来；有鲜明特征和经手渠道便仍有机会。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，原收放范围的人查到容易辨认的特征，属吉应。若最后经手处能按特征复核，较易辨清消息指的是不是原物，属吉应。

总断：有条件可寻。将特有标记留给东西最可能经手的一处，不急着追未经证实的去向。
