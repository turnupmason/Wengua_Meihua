## 初九动 · 寅月、卯月

先把经手范围问小，末了从旧处还有一寻

地火明夷 → 雷水解 → 地山谦

简断

原物有机会找回。第一步若问得到一个能说明最后用途的人，不妨先请他回想用完后的动作。到了中间，地点可能被几种说法带偏，最好回到确知接触过物件的一处。末后的机会系在那一处，范围摊得太宽就很难接上。

开局：起初有较实帮助可借，自己原有的线索却薄。坤土体春死，离火本用春相而直接生体，可先请能说明最后用途的人补清用后收放。

过程：后段去向较受限制，听说的地址仍需核实。体互震木春旺，直接克死坤，原经手记录宜先查清。用互坎水春休，受死坤所克，制力不足，消息能否接到物件还须实看。

结局：初九明夷于飞、垂其翼，君子于行、三日不食，有攸往、主人有言，取避难而行仍有困与言，求助宜把事实说明白。变用艮土春死，与坤体比和，末后配合很薄。若开头实助能接到确知收放、原物能认准，仍有找回机会。 东北是传统方位，艮的场所包括近路边、岩石旁。若原经过尚可确认，可先向对应停留处问招领，把实际见过与后来听说的分清。

总断：原物有条件找回，最后经手者能说明收在何物之中，可先据此补核。其他说法问清来历，原记号留准，真正见物以后再领。
