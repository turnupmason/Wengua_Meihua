## 初九动 · 寅月、卯月

先把经手范围问小，末了从旧处还有一寻

地火明夷 → 雷水解 → 地山谦

简断

原物有机会找回。第一步若问得到一个能说明最后用途的人，不妨先请他回想用完后的动作。到了中间，地点可能被几种说法带偏，最好回到确知接触过物件的一处。末后的机会系在那一处，范围摊得太宽就很难接上。

开局：春令坤土为死，相离火本用生坤。起头有外助，手上原有的线索却较单薄。

过程：体互旺震木克死坤，动到陌生处查容易费力；休坎用互受坤克，能否把听说变成证据也得花工夫。

结局：初九垂翼以避，出门投人又有言，借此提示别处的说法未必可靠。末段死艮与坤比，原来范围仍可回查；找到实据才有机会。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，问出最后一次使用的实据，属吉应。若能联系最后经手者，较容易取得一项能核对的用物细节，属吉应。

总断：可以寻，宜等一处确认后再动身。让最后经手者说明它收在何物之中，线索会更好核。
