头一回问不清，末后仍较有希望取回

火地晋 → 水山蹇 → 火雷噬嗑

简断

这件东西较有希望找回，实在进展多在后段。头一回问不清时，可请经手者指出谁能打开存放处、哪里留有收放记录，原特征准确留下。中段还有小处受限，末后帮助较足，能实际看物以后再核独有记号。

开局：开始需要准备清楚的辨物资料，所费较轻。离火体春相，坤土本用春死而受体所生，自己有力整理最后使用与收放的记录。

过程：询查可能有一段依据未明，后续补问仍需投入。体互坎水春休，直接克相离，限制较缓，可先问谁能打开原收存。用互艮土春死，受离体所生，耗费较轻，原查结果宜留准确。

结局：初六晋如摧如、贞吉，罔孚、裕无咎，进退守正，暂未取信时宽裕以待较免失。变用震木春旺，直接生离，末后支持较有力。原范围有据可查、物件可按标记认准，较有希望取回。 取象指东方，场所可参闹市、大途。原路线若有对应停留点，可先补问招领与收拾记录，尚未得到信实时把原物描述给稳。 原件已有的方整轮廓、布帛软面或瓦陶部分，可参本用坤核原接缝、质地和黄黑色块。变震的竹木、乐器及青碧花草另参周边，真实路线上的停留处可问木架、竹器或绿植旁的收拾，原物资料保持同一份准确描述。

  本用对原体为开局的直接依据。
