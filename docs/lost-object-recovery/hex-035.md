## 初六动 · 寅月、卯月

头一回问不清，末后仍较有希望取回

火地晋 → 水山蹇 → 火雷噬嗑

简断

这件东西较有希望找回，实在的进展多半要等到后段。头一回向人打听，他也许只能说清其中一小段；可以先请他指出谁能打开存放处，或哪里留有收放记录。等有条件实际看一眼，便容易把模糊的说法弄实。

开局：春木令，离火为体属相，本用死坤受离所生。开始得自己准备一份好辨认的描述，所费不大。

过程：体互休坎克相离，问着问着可能一时失了依据；用互死艮仍耗体，反复问同一句没有多少收获。

结局：初六兼说进与受挫，未得信时能宽裕守正才无咎。末段旺震木直接生离，弥补中段欠清楚的地方，已有一处可查时较有望落实到原物。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，经手处核看实物而确认，属吉应。若有人能查看留存物并核独有记号，较有机会确认原件，属吉应。

总断：较有望找回，前慢后实。逢暂时无从辨认的答复，留下能继续查的途径，等实际查看的机会。
