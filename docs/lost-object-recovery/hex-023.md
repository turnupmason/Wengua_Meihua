## 初六动 · 寅月、卯月

旧存放点若已变动，原物眼下很难寻回

山地剥 → 坤为地 → 山雷颐

简断

原物偏难找回。如果原来放它的一角最近整理过，先问变动之前有谁实际看见过。旧位置还可以核一次，但要是连同批物件也已经换了去处，别只围着老地方继续找。先把能够证实的最后一段经过留下。

开局：开头仍能向熟悉处查询，实际查验条件较薄。艮土体春死，坤土本用也春死，与体比和，可以先问原存放处是否整理、谁见过变动前的物件。

过程：原位置与后续经手能添的照应都有限。体互坤土春死，与体比和，宜先核惯常收放是否对应最后那次。用互坤土同为春死，也与体比和，转手经过仍需亲见来补。

结局：初六剥床以足，蔑、贞凶，根基初受削损，旧依据需要重新核实。变用震木春旺，直接克艮，末段查验限制较重。较薄的熟处照应尚难接齐去向，原物本次偏难回来。 东方及闹市、大途是变震的传统取象。若早先凭据已有缺处，可先用真实行程找回尚能核问的停留点，再联系对应场所招领。 若原物有方形轮廓、柔软布面或瓦陶部分，可据本用坤核旧织纹、角边与黄黑色，辨认资料先补齐。变震的竹木、乐器及青碧花草另参环境，旧凭据缺处可从真实停留的木架、竹器或绿植旁补问收拾记录。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，核实存放位置变动后的具体收纳。若已查到原位置后来挪过，继续核新的经手处时较可能遇到阻碍，属凶应。

总断：这次较难找回，可以先确认旧位置有没有变动。若同批物件也换了去处，就留准最后可证实的一段，后续有实际查看条件再接查。

古籍依据：《周易·山地剥》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·八卦类象》《梅花易数·八卦万物属类》《梅花易数·形物占》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。
