## 初六动 · 寅月、卯月

旧存放点若已变动，原物眼下很难寻回

山地剥 → 坤为地 → 山雷颐

简断

原物偏难找回。如果原来放它的一角最近整理过，先问变动之前有谁实际看见过。旧位置还可以核一次，但要是连同批物件也已经换了去处，别只围着老地方继续找。先把能够证实的最后一段经过留下。

开局：艮与坤同死仍比和，开头可以在熟处问一问，实际查验条件薄。

过程：体互、用互都为死坤，都是原范围能得到的有限照应。前者可核惯常位置，后者若涉及其他经手人，要把所见说清。

结局：初六剥从床足开始，基本依托已受侵削，爻以凶戒。变旺震克艮，末后还会有实际的查验限制，原物眼下偏难回来。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，核实存放位置变动后的具体收纳。若已查到原位置后来挪过，继续核新的经手处时较可能遇到阻碍，属凶应。

总断：难找回。先确认老位置有没有变过，没法核到后一步便留材料。

古籍依据：《周易·山地剥》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。

最初落脚处还可核，原物仍有窄一些的找回机会

山地剥 → 坤为地 → 山雷颐

简断

原物还有找回机会，不过得趁能够查看的时候把原位置核实。把当时放在一起的一组东西先找出来，确认是不是有个环节早已改变。若变化后找不到实际经手的人，就只在能证实的近处查，不继续追模糊消息。

总断：有条件找回。遇到尚未变动的实在位置尽早核，后面跑不通就停。

老地方还能查一遍，原物这次仍偏难回来

山地剥 → 坤为地 → 山雷颐

简断

找回的希望偏低。假如原处只有当时常放的位置可看，就仔细核那一处是否真的打开过。查看后还是没有，不必再把周边所有收纳逐一翻。留一份记录，等有人知道物件后来怎么被放走，再顺新的实情查。

开局：艮坤同休而比，近处有基本查询条件，支持不厚。

过程：两互皆休坤。体互可帮核原处是否查过，用互的同类照应可以问到旁边的收纳，却都不足以接全去向。

应期：此盘暂无有据的日期可列。

总断：偏难寻回。先查老位置能看到的部分，后面不要只凭可能就翻更多地方。
