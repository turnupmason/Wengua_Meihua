## 初六动 · 寅月、卯月

按原线索小心核查，原物目前偏难找回

泽风大过 → 乾为天 → 泽天夬

简断

看见相近的物品，可以先请保管人保持原样，等你拿旧照片来核。眼下能接触到的位置不多，原物偏难找回。先确认原来的容器有没有打开过、开看的是哪一层，不用把不知来历的同款全算进来。

开局：兑金囚而克旺巽，头一处有方向，但较难按自己的办法查看。

应期：此盘暂无有据的日期可列。

总断：眼下偏难寻回。找能够照实辨认的人开看，其他位置留待有证再查。
