## 初六动 · 寅月、卯月

按原线索小心核查，原物目前偏难找回

泽风大过 → 乾为天 → 泽天夬

简断

眼下原物偏难找回。若见到相近的物品，可先请保管者留清原收放的样子，再拿旧照片核对。原容器哪层看过、哪层还未打开，都问具体。前后照应有限，把可辨认的细节存好，能实看的部分先查。

开局：最初的收放即使有方向，也较难由自己查透。兑金体春囚，巽木本用春旺而受体所克，制力不足，宜先问原容器究竟打开到哪一层。

过程：熟悉处可以补问，后续经手能添的帮助也有限。体互乾金春囚，与兑体比和，可复核先前记录下来的收放细节。用互乾金同囚，也与体比和，另一收存处要问到亲眼所见。

结局：初六藉用白茅、无咎，慎重承垫以免处置失误，取在核物时留清原样。变用乾金春囚，与体比和，收尾的配合仍薄。原范围难核全，谨慎有益，原物目前偏难取回。 方位取象偏西北，乾列高处、圆器之中。若要补查原收纳，可先核实际用过的圆盒或高层格，请能安全接触的人把里面看清。

应期：此盘暂无有据的日期可列。

总断：这次找回偏难，先把能够辨物的照片、记号与查验结果留齐。还未开看的部分问到实际经手处，待实看以后再认物。

古籍依据：《周易·泽风大过》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。

## 初六动 · 亥月、子月

原处仍值得细看，这件东西有机会找回

泽风大过 → 乾为天 → 泽天夬

简断

原物尚有找回机会。若之前只问了有没有，可以改问真正检查到了哪一层，哪些东西没有动过。把没打开的位置单列，再看谁能去核，照能辨认的细节查。已看过的地方不必为一条新猜测全部重查。

开局：起手能够亲自核查的范围有限，收放细节需要先证实。兑金体冬休，巽木本用冬相而受体所克，制力偏弱，可以先问原处实际查到了哪里。

过程：已有查看能补些细节，邻近经手也可继续核问。体互乾金冬休，与体比和，熟悉处的配合较缓。用互乾金同休，也与体比和，尚未打开的部分须落实给能实看的人。

应期：此盘暂无有据的日期可列。
