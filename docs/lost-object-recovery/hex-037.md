## 初九动 · 寅月、卯月

能把收放次序排清，原物尚有找回机会

风火家人 → 火水未济 → 风山渐

简断

这件东西还有找回机会。查过哪些地方、哪些仍待补看，可先记清，再向经手处核最后一次收放。前中需要较实投入，过程中仍有帮助可借，末后能按原范围查到遗漏。原照片与独有记号备齐，辨清物件以后再取。

开局：起头自己有力查原范围，投入工夫也较实。巽木体春旺，离火本用春相而受体所生，可以先把最后的收放与已查内容整理清楚。

过程：重复查看会增加所费，相关经手仍能补些帮助。体互离火春相，受巽体所生，原查所见宜随看随记。用互坎水春休，直接生巽，较缓援助可以用来补明未清的经过。

结局：初九闲有家、悔亡，防闲在初、先定其序，查找从开始就宜分清已核与待核。变用艮土春死，受旺巽所克，末后有力核遗漏。中段帮助能接到真实收放，原物仍有找回机会，落实稍慢。

应期：此盘暂无有据的日期可列。

总断：本次有条件寻回，原范围划清后按实际收放细查，层次与外包装的查看结果留准。找到相似物以后，再用独有标记认原件。
