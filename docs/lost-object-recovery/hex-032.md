## 初六动 · 寅月、卯月

起手别把查找铺得太深，眼下原物仍难回来

雷风恒 → 泽天夬 → 雷天大壮

简断

找回的希望偏低。若只记得早先放过某处，可先核当时有没有实际记录，后段搬动的说法逐项问到出处。前面有力查，收尾却仍受限，得物帮助尚不足，原标记和已核结果留全，待能实看以后再辨认。

开局：起头熟悉范围有力核查，自己能先作实际复核。震木体与巽木本用春令同旺、彼此比和，可以先问原放置处有没有当时的记录。

过程：原位置有小处需明，后续经手也要补实际凭据。体互兑金春囚，直接克震，阻力较薄，未看清的收纳可先问具体。用互乾金春囚，也克原体，另一段查看须由经手者补实。

结局：初六浚恒、贞凶、无攸利，事情才起便一味深求，固执这种走法仍不利。变用乾金春囚，直接克震，末后限制依旧。前面虽有力查原处，得物实助尚缺，眼下原物偏难找回。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，从原来确实使用过的位置核实收放。若熟悉范围还可以打开，适合只把最初一段收放查到实处，属吉应。

总断：本次偏难取回，最早收放有证可核的先查清，后段的搬动问到实据再接。独有标记和已有结果准确留存，待实际能看时再辨认。
