## 初六动 · 寅月、卯月

起手别把查找铺得太深，眼下原物仍难回来

雷风恒 → 泽天夬 → 雷天大壮

简断

找回的希望偏低。如果早先只记得某次放在一处，先核那个地方有没有实际记录。不要上来就要求把后面几次搬动全查清，手里只有一段见闻就做一段。查验条件没有以后，把独有标记留好即可。

开局：震体、巽用同旺而比和，熟悉范围能核一处，原体能做实际尝试。

过程：体互囚兑克震，原位置有待明的一步；用互囚乾也克体，其他经手范围可能又缺实据，各自需要实际复查。

结局：初六浚恒起初便求太深，守此仍凶且无利。变囚乾继续克震，原处可查只宜小步，眼下原物偏难找回。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，从原来确实使用过的位置核实收放。若熟悉范围还可以打开，适合只把最初一段收放查到实处，属吉应。

总断：偏难找回。最早那一处证实便收住，别全靠同一个猜想来追。

古籍依据：《周易·雷风恒》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·日应》《梅花易数·先天后天论》。
