## 初九动 · 寅月、卯月

能顺着一起收的东西去找，原物仍偏难回手

地天泰 → 雷泽归妹 → 地风升

简断

这件东西偏难找回。若它原来和几样物件一起拿过，就挑仍在手上的那一样，想清它怎么被收回来，从那里核一处。一起拿过不代表一起放下，到了已经无法确定的那一步，先保存查实的范围，别跟着假设一直走。

开局：可先借手边仍在的物件，核一段真实经过。坤土体春死，乾金本用春囚，体生用仍有耗费，开始能够展开的范围宜小。

过程：从同组东西往回推，可能遇到无法核实的一步。体互震木春旺而克坤，中段阻力较重。用互兑金春囚，受坤土所生，逐件询问也要花精力，宜先查确有同时收放依据的部分。

结局：初九拔茅茹、以其汇而征吉，同类相牵给查相关物件留出入口。变用巽木春旺，继续克坤，末段限制仍重。核清一组收放虽有帮助，尚难补明原物后来的经过，本次寻回偏难。

可留意本月12、13号前后，核查已知同组物品最后有没有分开存放，属凶应。若已经找到一件当时同行的物品，追问两件后来是否分开放时容易缺一段事实，属凶应。

总断：这件物品近期较难取回。可以先查一件确曾一同携带的东西，看它怎样收回，再核原物是否同放，得到实据以后才接着追下一处。
