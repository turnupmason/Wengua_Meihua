## 初九动 · 寅月、卯月

能顺着一起收的东西去找，原物仍偏难回手

地天泰 → 雷泽归妹 → 地风升

简断

这件东西偏难找回。若它原来和几样物件一起拿过，就挑仍在手上的那一样，想清它怎么被收回来，从那里核一处。一起拿过不代表一起放下，到了已经无法确定的那一步，先保存查实的范围，别跟着假设一直走。

开局：坤土春死，生囚乾仍费力，开始寻物要借手边实据。能查到的范围宜窄。

过程：体互震木旺克坤，从同组东西倒推过去可能遇到无法核实的动作。用互兑金虽囚，仍受坤生，逐个问只会增加消耗。

结局：初九拔茅而牵一丛，同行为吉，给了从相关物件下手的路。变旺巽木依然克坤，能复核一组，不足以把断掉的尾段接上。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，核查已知同组物品最后有没有分开存放，属凶应。若已经找到一件当时同行的物品，追问两件后来是否分开放时容易缺一段事实，属凶应。

总断：原物难找回。先查一件曾同行的东西，证实去向后再判断有没有下一处。

古籍依据：《周易·地天泰》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。

## 初九动 · 亥月、子月

先核最可靠的一条关联，实物偏难寻回

地天泰 → 雷泽归妹 → 地风升

简断

这件东西难找回。若知道另外一件东西确实和它同放过，可以去查那件后来停在哪儿，再确认两件有没有分开。不要从一件后来出现的位置往回猜另一件一定也在那里。那一步查不清，宁把两件的记录分别留下。

开局：休乾由囚坤所生，开端能投入的余力不多，宜选手里已有的线索。

过程：体互震木相而克土，到了核实两件是否分开的地方较可能受阻。用互休兑仍耗坤，再问许多处也未必得到原话。

应期：以下为传统推算的参考窗口。

总断：取回偏难。先找确能证明同时收放的证据，其他提示不用并着查。
