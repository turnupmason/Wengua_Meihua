## 初九动 · 寅月、卯月

若能折回原路细查，原物还有机会找回来

风天小畜 → 火泽睽 → 巽为风

简断

这件东西还有找回的机会。若先前把整条路想成一段，现在可以拆开回忆，想清最后一次拿在手里是为了做什么，下一步又做了什么。若中间有过换手或临时放下，就回到那里核查。中途会费些工夫，末后仍有接续查明的条件。

开局：先记下最后一次确实看见原物的时刻，再倒推随后的动作。巽木体春旺，乾金本用春囚仍克木，查找有阻，但你这边有力，尚能沿真实经过一点点核。

过程：细找会花实际工夫。体互离火春相，受巽木所生，中段耗费较多。用互兑金春囚仍克体，问到交接细节时可能受限，宜核物件是否曾随手里的其他东西一同挪动。

结局：初九“复自道，何其咎？吉”，回到本来适宜的路上，便有转好的余地。变用巽木春旺，与体比和，末段较有条件收拢范围、继续核查。若能回到确有凭据的收放环节，仍有找回机会。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，回到最后一次换手的地方核查，属吉应。若还能进到原先换手的地方，前后两处可各实查一次，属吉应。

总断：有条件在回查时寻回。按确实记得的动作倒着核，能现场查看的优先查看，再把新发现与原物特征对清，避免沿途漫无边际地翻找。
