## 初九动 · 寅月、卯月

若能折回原路细查，原物还有机会找回来

风天小畜 → 火泽睽 → 巽为风

简断

这件东西还有找回的机会。若先前把整条路想成一段，现在要把它拆开，想清最后一次拿在手里是为了做什么，下一步双手又去做了什么。回到中间那个换手的地方核查，比把沿途每间屋子都翻一遍合适。

开局：旺巽木受囚乾金所克。眼下虽有断处，仍有余力倒推经过。先记下确实见过原物的一刻，把更早那段暂且划掉。

过程：体互离火相，木去生火，细找颇费脚力。用互兑金虽囚仍克木，问一圈也可能卡在同一个交接点。先查物件有没有随着手里别的东西一起挪动。

结局：初九以复自道得吉，所贵在回到自己的路上。变用旺巽木与体同类，所查范围终有收束。若能重到当时换手的那一步，条件比往远处扩张好。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，回到最后一次换手的地方核查，属吉应。若还能进到原先换手的地方，前后两处可各实查一次，属吉应。

总断：有机会在回头核查时找回。按确有动作的几个点倒着验，能现场核看的先看。
