## 初六动 · 寅月、卯月

开头难查，若有人实地补看，原物还有机会回来

地山谦 → 雷水解 → 地火明夷

简断

东西还有机会找回。倘若原处的收纳改过，先请熟悉的人讲清改变了哪一小片，再找能够打开看的人去核。把你已经亲手查过的地方说在前头，才好请人补，不必把整个寻找交出去。

开局：熟悉的位置还有接着核问的余地，起步配合较薄。坤土体与艮土本用春令皆死而比和，自身查找力量弱，宜先讲清已经亲手看过的范围。

过程：若原处收纳有变，中途较难核明。体互震木春旺而克坤，实查阻力较重。用互坎水春休，受坤土所克，死体力量不足，后续收放仍需直接凭据来补。

结局：初六谦谦君子，用涉大川而吉，知所不能、谦以济难，求助宜落在自己查不明的一步。变用离火春相而生坤，末段支持较实，可改善前面的被动。若能请人实际补看、核准物件，仍有找回机会。 南方、明窗及文书旁是变离的传统取象。可从最后真实整理过的文件或台面细查起，把已核与待核部分留清，补看有证的细处。

总断：这次寻回有条件，可让熟悉变动的人说明实际范围，再请能够查看的人补查。把原物独有特征交清，等实物细节对上以后再领回。
