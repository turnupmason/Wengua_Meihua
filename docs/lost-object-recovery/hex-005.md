## 初九动 · 寅月、卯月

先等确切消息，原物仍有找回机会

水天需 → 火泽睽 → 水风井

简断

这件物品还有机会找回来。若已经向最可能的地方留过资料，可以给对方完成核对的时间。接着把自己确定使用过的位置查实，先别忙着另走一条路线。后来若有细节对得上原物，值得接着查。如只有零散回音，重复奔走会比较费力。

开局：坎水体春休，乾金用春囚生坎，起头可借到少许帮助，实际证据仍不多。

结局：初九远险而待，守常可无咎。变用巽木春旺由坎所生，后段追查容易耗力。能等到可核的消息，再从原范围接着找，尚有寻回余地。

应期：此盘暂无有据的日期可列。

总断：可保持一个已经说清的联系途径。新的答复确实对得上时再去核，别把多跑几趟当成更快。
