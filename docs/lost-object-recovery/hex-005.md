## 初九动 · 寅月、卯月

先等确切消息，原物仍有找回机会

水天需 → 火泽睽 → 水风井

简断

这件物品还有机会找回来。若已经向最可能的地方留过资料，可以给对方完成核对的时间。接着把自己确定使用过的位置查实，先别忙着另走一条路线。后来若有细节对得上原物，值得接着查。如只有零散回音，重复奔走会比较费力。

开局：最初能借一些帮查，先把已留的资料说准。春令坎体休，囚乾本用生水，援助有限，直接证据还少。

过程：体互相离受休坎克制，实际查验仍较费力。用互囚兑生体，中间可有一点回应，尚未核实的部分还须据物补清。

结局：初九需于郊、守常无咎，宜远险而等可核消息。末旺巽受坎生，后段追查耗费较实。真实细节能够对应原件，再从原范围接着核，仍有取回机会。 取象可从东南、木器之内参看。若曾把物品随手收入木柜，可先查原层位与叠放物之间，等经手方核查时把具体特征给清。

应期：此盘暂无有据的日期可列。

总断：还有寻回机会。保留已经说清的一条联系，新答复能对到原件再去核，少为催快而重复奔走。

古籍依据：《周易·水天需》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。
