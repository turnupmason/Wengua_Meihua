## 初九动 · 寅月、卯月

四处找容易白费力，先守住一条能核的线索

水雷屯 → 山地剥 → 水地比

简断

这件物品眼下较难找回。若刚发现不见，就想把所有可能的地方一次查遍，先停下来把最后见到的时点想清楚。后来有些范围看着不难去，问到具体经过还是容易卡住。先给实际经手处留好物件特征，新的线索能核实了再动。

开局：坎水为体，春令属休。震木用当旺，受坎水所生，起头要花不少心思，能直接证实的事却不多。

过程：体互艮土春死，仍克坎水，原先的界限尚在。用互坤土同死也克体，核实时多半还要问清交接，不能把同一次回覆当成多条消息。

结局：初九磐桓而宜居贞，宜先把眼下能查的一处守实。变用坤土春死，尾段克体虽轻，前面的消耗和后续缺乏直接支撑仍在。这次找回偏难。

应期：此盘暂无有据的日期可列。

总断：先留给经手处一份可核的描述。自己若已查过最后那处，接下来等能指出哪一步该复查的消息。

古籍依据：《周易·水雷屯》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。

前头找得费力，后来核实仍容易受阻

水雷屯 → 山地剥 → 水地比

简断

近期较难寻回。假如已经顺着记忆找过一次，可以把未能进入或无人能答复的地方单独记下来。再花力气在同几处打转，未必能补齐关键的空白。先问原经手处是否还有记录，现场不便核实时，别靠模糊的印象硬找下去。

开局：坎水体夏囚，震木用夏休。坎生震使寻找先有花费，原体能查的资源也有限。

过程：体互艮土夏相直接克坎，实际核查较容易碰到条件限制。用互坤土同相亦克原体，整理过的场所需要具体的交接记录才能追。

结局：初九宜停守、先有组织再行动。变用坤土夏相再次克坎，到了最后仍欠实查条件。眼下继续扩大范围效用小，找回偏难。

应期：以下为传统推算的参考窗口。
可留意本月11、14号前后，询问经过时碰到无法实际核查的限制，属凶应。若已经有一个地方可以查，中途可能发现记录或可核范围不齐，属凶应。

总断：把已经联系过的经手处和未核实的范围区分开。如果原来那一处仍没有人能查，先按实际影响作安排。
