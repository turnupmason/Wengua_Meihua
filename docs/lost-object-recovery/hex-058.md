## 初九动 · 寅月、卯月

兑为泽 → 风火家人 → 泽水困

简断

这件物品偏难找回。开头从熟悉的地方问起即可，不必因为别人一时说不清就急着追责。中间有些实际经过不容易核准，末后还要自己继续查。礼貌能让问话顺利些，是否找到了，仍要看有没有原件的独有细节。

开局：春令兑体囚，本用同囚比体，旧范围能提供一点核查条件。

过程：体互旺巽受囚兑克，自己查实较难；用互相离克兑，辨认过程还容易遇阻。

结局：初九和兑吉，在平和而无偏私的询问。末休坎受兑生，自己仍需付出，过程实阻未解，顺利问到话尚难促成取回。

应期：以下为传统推算的参考窗口。

总断：较难取回。把问题问到具体收放，不让一份客气答复替代实物证明。
