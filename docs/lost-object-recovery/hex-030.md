简断

开局：起头能从确知的使用经过着手，原范围有条件复查。离火体与离火本用春令同相、彼此比和，可先按当时换手与收放的次序核。

总断：这次有条件找回，可以依自己能验证的动作先查，余下收放请经手者补看。独有记号核准后再取，原查结果保持清楚。
