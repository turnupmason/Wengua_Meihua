## 初六动 · 寅月、卯月

近处不应只看一眼，细查仍有找回机会

风地观 → 山地剥 → 风雷益

简断

原物还有机会找回。上一次若只站在柜前扫了一眼，可以把视线挡住的东西移开，再照当时收放的办法核。旁人说已经找过时，问他看过哪一层。熟悉的地方最容易凭印象跳过去，重新看实一处比再猜一个位置有用。

开局：旺巽克死坤，初段寻找有实际范围，自己能做一次深看。

过程：体互死艮和用互死坤皆可由旺巽制，先补原位置，再核同批是否挪过；两段中的细处可以看清。

结局：初六童观，小人可无咎而君子有吝，责在所见浅。变旺震比巽，熟悉范围前后可复查，只要从眼见的大概进到实看原物，仍有找回机会。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，补看之前未真正打开的一处近旁收纳。若能确定某一格前次只看过表面，适合深查后依特征复认，属吉应。

总断：有条件找回。把以前只扫过的近处查到里面，再按特征确认。

古籍依据：《周易·风地观》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·日应》《梅花易数·先天后天论》。

## 初六动 · 巳月、午月

眼下难寻回，先把看不全的范围交代清楚

风地观 → 山地剥 → 风雷益

简断

这次偏难找回。若在几处只看到了门口或靠外的一排，先别把那些地方都记成已经查完。选最后使用过的一处，问真正能打开查看的人。这样能改掉误记，但现在缺少把里面情况一一核明的条件，先留好物品识别点。

开局：休巽克相坤，开场存在真实可问的范围，靠自己未必能查看里面。

过程：体互相艮为休巽难制，原近处可能还留未查部分。用互相坤同样难制，另一处经手经过并不容易补足。

结局：初六童观无咎与吝分见所处、所当，查找不能只停在眼前片段。末用休震比体，仍可回原范围复看，原物暂难找回。

应期：此盘暂无有据的日期可列。

总断：找回偏难。只问能进里边的人实际看过什么，不把门口看过当查完。

## 初六动 · 申月、酉月

所见有限，原物眼下难以找回

风地观 → 山地剥 → 风雷益

简断

这件物品偏难找回来。假使有人发来一张只拍到一角的照片，可以问那里还有没有别的角度，先确认是否同一处收存。对方也没有办法看里面时，把原物的独有特征留下。别为一张看不清的图另跑几处。

开局：死巽克休坤，开头可问可猜，实际能掌握的查找范围少。

过程：体互休艮仍受巽克，近侧的一点迹象不易核足。用互休坤同受弱木制，到了另一个存放范围尚缺能当场验证的条件。

结局：初六童观见浅，对所应有的查验不够。变死震与巽比和，末后回到熟处也只有极薄的照应，原物偏难回。

应期：此盘暂无有据的日期可列。

总断：偏难找回。只留能证实地点或标记的照片，信息不齐便先登记。

## 初六动 · 亥月、子月

别只凭一眼作判断，若核得仔细仍能找回

风地观 → 山地剥 → 风雷益

简断

原物还有找回机会。如果你之前看过同一个位置，可以想当时有没有打开盒里或移开一旁的东西。没查过的那个小范围有条件就重看，不用请人把整个房间再翻一遍。看到和原物相像的物件时，用旧细节再对。

开局：相巽能制囚坤，第一步可把找物落在当时接触过的范围。

过程：体互囚艮和用互囚坤皆由巽制。前者可补看近角，后者可请经手处核有没有一同挪走。

结局：初六的童观不足恃，见得浅便容易忽略边角。末用相震比和，认真查过原有范围以后，仍有机会辨到原物。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，把原有范围内只看了一眼的位置重新查全。若可以重新打开那个没细看的位置，适合用独有标记识别原物，属吉应。

总断：有条件找回。先补一个看得不全的地方，再用原物标记逐项对。
