## 初六动 · 寅月、卯月

近处不应只看一眼，细查仍有找回机会

风地观 → 山地剥 → 风雷益

简断

原物还有机会找回。上一次若只站在柜前扫了一眼，可以把视线挡住的东西移开，再照当时收放的办法核。旁人说已经找过时，问他看过哪一层。熟悉的地方最容易凭印象跳过去，重新看实一处比再猜一个位置有用。

开局：初段有条件把已知范围查得更细。巽木体春旺，坤土本用春死而受体所克，自己有力补看先前只扫过一眼的地方。

过程：原位置和后续收纳都有条件细查。体互艮土春死，受旺巽所克，可先核视线被遮住的部分。用互坤土春死，也受原体所克，适合再问同批东西后来是否挪动。

结局：初六童观，小人无咎、君子吝，所见浅而未尽其所当，查找要由大概看过转为实看细节。变用震木春旺，与巽体比和，末段复核条件较实。把原范围查完整并验准物件，仍有找回机会。 方位可参东方，场所见闹市、道路。若只记得大概经过，可先用出行记录缩清真实停留点，再向对应场所问招领。 原物确有方角、软布或陶质时，可参本用坤核原轮廓、织纹与黄黑色，先整理能够区分同类物的记号。变震的竹木、花草及青碧另参行程环境，模糊经过可用真实出行记录缩清，再问木架、竹器或绿植旁的实际收拾。

总断：原物还有机会找回，可先补看上次视线没到的地方。协查者说找过时，问清具体看了哪层，再拿独有特征确认。
