## 初九动 · 寅月、卯月

末段能补回查，原物仍有找回机会

雷天大壮 → 泽天夬 → 雷风恒

简断

这件物品仍有找回的机会，但开始别凭一股急劲把可能去过的地方都查遍。头两段较容易碰到说不清的记录，末后若能重回最后一个确知的取放点，倒有机会把漏看的那一步验出来。

开局：自己有力重新核查，起步仍有些限制。震木体春旺，乾金本用春囚而直接克体，阻力较薄，可先按最后确知的取放问原经手处。

过程：原处与后来经手都有小处待明，答复须问到实际所见。体互兑金春囚，直接克震，可先核旧位置谁能打开。用互乾金春囚，也克原体，另一段收放仍需记录接续。

结局：初九壮于趾、征凶、有孚，古注以有孚连征凶，戒恃初壮而急进。变用巽木春旺，与震体比和，末后仍有力配合查验。原来确知的收放能补看、独有标记能核清，仍有找回机会。 东南与木器之内是传统提示。若原收纳涉及木柜或木盒，可先托能查看的人看清内部，原处有权限和实物线索以后再安排前往。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，回查最后使用处时发现一项遗漏。若最后取放点仍能进入复查，较容易重新对上一项原先漏看的动作，属吉应。

总断：原物有条件找回，先把最初所据问实，再从最后使用倒查取放。能够实看以后核原标记，新的消息也问明来源。

古籍依据：《周易·雷天大壮》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·日应》《梅花易数·先天后天论》。
