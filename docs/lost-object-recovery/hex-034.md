## 初九动 · 寅月、卯月

简断

这件物品仍有找回的机会，但开始别凭一股急劲把可能去过的地方都查遍。头两段较容易碰到说不清的记录，末后若能重回最后一个确知的取放点，倒有机会把漏看的那一步验出来。

开局：寅卯震木体旺，受到囚乾本用克制。虽然有能力重新核查，起步仍受限于现下已有的说法。

过程：体互兑、用互乾同为囚金，先后限制旺震。原处和经手人说得不一样时，宜分清谁能见到原物。

结局：初九壮于趾，注疏以「有孚」为征凶之信，戒一开始便急着前往。变巽木旺而同体比和，回到确知的地方慢查，仍有机会找回。

总断：原物还有机会，宜先收住脚步。从最后一次使用倒着核，能落在一处再实际翻查。
