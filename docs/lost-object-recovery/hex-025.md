简断

原物仍有找回机会。若最后一次使用的地点已经确定，可以先问那里有没有一处能够按物件特征核看。不要把几次记忆混在一起。能得到具体收存位置就继续，对方若没有实查，先把能辨认的痕迹留下，不必逐处跑。
