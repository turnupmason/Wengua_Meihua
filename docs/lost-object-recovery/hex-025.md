## 初九动 · 寅月、卯月

按真实去向补查，原物还有找回机会

天雷无妄 → 风山渐 → 天地否

简断

原物仍有找回机会。若最后一次使用的地点已经确定，可以先问那里有没有一处能够按物件特征核看。不要把几次记忆混在一起。能得到具体收存位置就继续，对方若没有实查，先把能辨认的痕迹留下，不必逐处跑。

开局：头一处可能有查找方向，实际掌握范围仍较困难。乾金体春囚，震木本用春旺而受体所克，自身制力不足，宜先核最后一次确定使用的位置。

过程：后续收放较难自己查明，协查能补的帮助也少。体互巽木春旺，受囚乾所克，原体较难查透。用互艮土春死，仍生乾，支持很薄，可以先问经手处能否按原物特征实看。

结局：初九无妄、往吉，所行真实而合宜，才有可取的吉义。变用坤土春死，仍生乾，末后帮助较薄。若具备查看条件的人接手，补齐去向并辨明原物，仍有找回机会。 方位取西南，坤列仓储、方器之中。可从最后真实用过的储物处补看起，若当时曾放进方盒，先核内部与同批收放的物件。 本用震的竹木、乐器与青碧色，可对应原件已有材质、构件和纹路，认物记号照旧图整理。变坤的方器、布帛与仓储另参周边，先核实际用过的方盒、布袋或同批存放格，原物轮廓与容器外形分别说明。

应期：此盘暂无有据的日期可列。

总断：还有机会找回，宜以末次亲眼见过的位置为准，核实具体收存。对方能够打开查看以后，再按独有痕迹与原资料辨认。
