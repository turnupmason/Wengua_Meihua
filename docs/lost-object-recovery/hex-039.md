## 初六动 · 寅月、卯月

拐回可核的地方，还有机会慢慢找回

水山蹇 → 火水未济 → 水火既济

简断

这件物品还有机会找回，先把那些只能凭印象才想到的地方划出去。若最近有一处肯定拿出来用过，可以请经手者复现当时如何收好。中途直到收尾都可能要自己核对，范围越清楚，越有机会把力气花在对的一处。

开局：春令坎水体休，死艮土本用仍克体，起步知道得少，但限制也不算强。

过程：体互相离受休坎所克，实际翻查偏费力；用互休坎比体，可以保留原来记住的次序。

结局：初六往蹇来誉，《象》说宜待。末相离仍由休坎来制，具备可寻而迟之理，但得先有可证的旧范围，盲目新增去处容易再受阻。

应期：此盘暂无有据的日期可列。

总断：有条件可寻，偏慢。只在能还原那一次使用的地方验一遍，不必急着换路。
