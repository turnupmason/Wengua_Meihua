## 初六动 · 寅月、卯月

先守住确知的地点，往外追反而难找

天山遁 → 天风姤 → 天火同人

简断

这件物品偏难找回。最后一次经过的地方若还说得清，可以向当时在场的人问明白。问到后来可能出现别处的说法，先弄清那是亲眼所见还是听人转述，尤其别在没有新凭据时赶去陌生处翻找。

开局：乾金为体，春令囚；本用艮土虽死，仍有生金关系。原处或有人肯指一指，能提供的细节有限。

过程：体互乾金囚而比，有助于沿原路说明情况；用互巽木旺，囚金克木颇费力。发现新的地点说法，先找能说明转移过程的人。

结局：初六处遯之尾，事情已经迟了，爻辞说有危而勿往。末段相离火克囚乾，向外追索易再遇受阻。起头虽有薄助，留在确知范围内核一次已是合适的做法。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，外查时无法把说法和原物对上。若正在核对一个未经确认的去向，可能遇到说法对不上实物的阻碍，属凶应。

总断：原物难寻。问清最后一次取放后再决定查哪里，避免为了捕捉一条传闻跑得更远。

古籍依据：《周易·天山遁》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。
