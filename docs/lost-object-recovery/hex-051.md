## 初九动 · 寅月、卯月

稳下来按原来的步骤核，原物较有希望回来

震为雷 → 水山蹇 → 雷地豫

简断

这件物品较有希望找回。刚发现不见时先别把周围东西都翻动，可以按最后一次拿出来、暂放、收好的次序查。中途若有人还记得一项细节，就请他核过再接下去。原来的疑处比较容易厘清，最后可直接看看是不是原件。

开局：春令震木体旺，本用震木同旺而比，开始有条件沿原用物处稳定查找。

过程：体互休坎生震，可补一段经历；用互死艮被旺震制，取放疑点容易逐项排查。

结局：初九先惊后笑言，福来自警惕和修省。末死坤也受旺震所克，前面查出来的经过可拿来动手找，原物较有希望取回。 西南及仓储、方器是变坤的传统取象。发现遗失后先把确知收放理稳，实际用过的盒格可以补看，查询结果随查随记。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，回到最后一次确知用过的地方复查。若能照原取放顺序复现经过，较易核明一处忽略的动作，属吉应。

总断：较有望找回。先标出临时腾手时可能漏查的那一步，再核原物自己的特征。

古籍依据：《周易·震为雷》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·日应》《梅花易数·先天后天论》。

## 初九动 · 亥月、子月

原来的过程能补齐，东西较有希望找回来

震为雷 → 水山蹇 → 雷地豫

简断

这件物品较有希望找回。可以先把最后一次明确使用的动作顺下来，再请当时的人核用完以后有没有换过位置。中间有人能实地复查，较容易把开始想不起的一处补齐。最后顺着已证实的位置查，辨清特征后取回。

开局：冬令震体相，震本用同相而比，起手可按确定的范围找。

过程：旺坎体互生震，实际经手处有力补证；囚艮用互受相木克，具体疑问较容易处理。

结局：初九遇惊而能修省，后得安定。末囚坤还受相震克，先前查实的经过能用于现场查找，原物较有望回来。 西南及仓储、方器是变坤的传统取象。发现遗失后先把确知收放理稳，实际用过的盒格可以补看，查询结果随查随记。
