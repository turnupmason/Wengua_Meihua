## 初六动 · 寅月、卯月

有人愿同查也要看是否有实据，原物偏难回

地风升 → 雷泽归妹 → 地天泰

简断

这件东西偏难找回。若原来有人和你一起用过，可以让对方把最后一次收拾时看到的事说清，别让后来听来的话混进去。中间容易碰到查不实的去向，尾段又需要自己付出工夫。先把真实的过程留下，有人能照它看实物再续。

开局：春令坤体死，旺巽本用克土，起步要拿到可靠去向较难。

过程：旺震体互再克坤，来路容易说不合；用互囚兑受坤生，另找人传问会增加耗费。

结局：初六允升大吉在与上合志、得同力。变囚乾仍从坤受生，查到最后也要自己出力，条件未支持实在协查，原物偏难回来。 西北是变乾的方位，圆器之中、高处是场所象。若初步有人愿意协助，可请其看实际使用过的收纳物，把原来的层位问明。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，开头追问时原物去向难查明。若已向可能的经手者查问，较易发现目前没有能把去向证实的线索，属凶应。

总断：找回偏难。原来一起用过的人能说清所见，才把该处作为下一步。

古籍依据：《周易·地风升》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。
