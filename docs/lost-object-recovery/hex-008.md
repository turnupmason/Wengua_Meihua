## 初六动 · 寅月、卯月

先把可核的情况留下，原物目前还难找回

水地比 → 山地剥 → 水雷屯

简断

这件物品近期偏难寻回。若最后见到它的地方不大确定，可以先把你亲手用过的时间和一项辨认特征留下，让经手处按实核对。途中可能不容易拿到完整消息，后面也要继续花力气。收到别人主动给的线索时，先查它能不能接到原物。

开局：先把仍记得清楚的经过留下，便于经手处核对。坎水体春休，坤土本用春死仍克体，开始的限制较轻，自己可用的力量也有限，查找宜从确有凭据的一处展开。

过程：中途想核清物品如何收放，还得过查验这一关。体互艮土春死而克坎，现场能查的内容可能有限。用互坤土同属死而克体，转问交接情况时，也须有记录或实际经手的经过可核。

结局：初六从有孚无咎说到盈缶而终有它吉，重在真实充足，才可能得到额外的响应。变用震木春旺，受坎水所生，末段还会耗去较多精力。眼下未见能落实核验的帮助，询问虽值得留下，近期找回仍偏难。 方位可从东方参看，场所取道路或闹市。若最后确认物品还在的一段涉及这些地方，可先核停留、付款和收放的实际记录。 方形轮廓、软布结构或陶瓦表面若属于原件，可用本用坤核折角、接缝及黄黑色块，先整理能认同件的细节。变震的竹木、花草与青碧环境则随实际行程补看，木竹台架、绿植陈设旁有明确取放记录的地方可以优先核实。

应期：此盘暂无有据的日期可列。

总断：这次寻回偏难，先趁记忆清楚，把最后接触的时间与辨认特征交代好。若后来有人提供消息，问清实际看到的物件细节，再决定是否往下追。
