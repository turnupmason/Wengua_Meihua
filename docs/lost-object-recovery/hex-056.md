## 初六动 · 寅月、卯月

临时放下的那一步若能想起，旧处还有一寻

火山旅 → 泽风大过 → 离为火

简断

这件物品还有机会找回。若记得离开前忙过好几件小事，可以先挑和物品有关的那一件，问经手者后来有没有另放。中间有人能帮着核，不必把其余地方重新翻一遍；先查清原来的收放，最后认准原件再领。

开局：春令离体相，死艮本用受离生，起步需要自己整理，所费不大。

过程：体互囚兑受离克，具体疑点可核；用互旺巽生离，真正经手的人可以帮到实处。

结局：初六旅琐琐而困，取勿让零事扰乱原来的查法。末相离比体，旧范围仍有实地核验条件；能把中段帮助落在一处，原物还是有机会。 传统方向参南，明窗、文书之侧是离象场所。零碎消息宜先落到实际使用过的一处台面，问明那次整理以后东西如何收起。 若原物有石陶质料、黄色或独有石纹，可参本用艮核原边沿和轮廓，把旧资料里能辨同件的细处给明。变离另取文书、彩纹与明窗参环境，零碎消息可先落到真用过的文件台、印字包装旁，问清那次收拾后的存放。

可留意本月12、13号前后，经手者补明临时放置的一步。若能请在场人照当时的收放查看，较容易核到先前遗漏的细节，属吉应。

总断：有条件找回。只问临时离手的那个动作，核准物件再安排领取。
