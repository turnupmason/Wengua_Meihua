## 初六动 · 寅月、卯月

小线索须赶早核对，眼下找回偏难

坤为地 → 坤为地 → 地雷复

简断

眼下较难找回。刚发现少了一件东西，可以先把最后一次能确认的收放记下来，别靠着越想越模糊的印象兜圈子。若有关场所正在交接或清理，尽早问还能留查哪些记录。前面能做的事少，拖到后面更容易连核实的机会也失去。

开局：坤土体与本用春令同死，体用比和还留着原范围，能直接核对的资料偏少。

过程：体互是春死坤土，与体比和，可从原来的收放次序找一点线索。用互也为死坤，资料若未保留，后来即使有人回忆也不容易对实。

结局：初六履霜而知坚冰将至，提醒趁小疑点还可核时先核。变用震木春旺，克原体坤土，后面可查范围还容易受限。眼下找回偏难，宜尽早抓住真实记录。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，到复查时可核记录变少，属凶应。若遗失场所已经换班或开始清理，之后较容易碰到记录暂时难查的情况，属凶应。

总断：这次先把会变动的线索问实。若有场所可以查，问清他们现在仍能核对什么，别等自己把每个细节都想齐才联系。
