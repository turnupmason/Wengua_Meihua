## 初六动 · 寅月、卯月

小线索须赶早核对，眼下找回偏难

坤为地 → 坤为地 → 地雷复

简断

眼下较难找回。刚发现少了一件东西，可以先把最后一次能确认的收放记下来，别靠着越想越模糊的印象兜圈子。若有关场所正在交接或清理，尽早问还能留查哪些记录。前面能做的事少，拖到后面更容易连核实的机会也失去。

开局：春令坤土体、用同死而比和，原范围仍可回查，只是能直接核对的资料少，宜先保住还在的记录。

过程：体互死坤比体，可以从原收放顺序找一点线索。用互也是死坤，与体比和，资料若未留下，后来即使有人想起一段，也较难对到实处。

结局：初六履霜而知坚冰将至，提醒趁小疑点还可核时先核。变用震木春旺，克原体坤土，后面可查范围还容易受限。眼下找回偏难，宜尽早抓住真实记录。 方位取东方，震在失物章还指闹市、大途。可从最后实际经过的商街或道路问起，核当时是否停留、取用过物品，再联系对应招领处。 本用坤有方物、柔物、布帛和瓦器之象，原件若为方形小物、布套或陶器，可核折角、织纹与接缝，黄黑色依原资料对证。变震的竹木、青碧与乐器放在周边场景参看，实际停留处若有木竹陈设或花草，可沿当时使用的一面补查。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，到复查时可核记录变少。若遗失场所已经换班或开始清理，之后较容易碰到记录暂时难查的情况，属凶应。

总断：眼下偏难找回。先问清会变动的记录现在还能查什么，别等每个细节都想齐才联系原场所。
