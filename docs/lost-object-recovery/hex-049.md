## 初九动 · 寅月、卯月

先守住已知一处，原件仍偏难找回

泽火革 → 天风姤 → 泽山咸

简断

这件东西偏难找回。若开头已有几个推测的地点，先拣能证实实际用过的一处，让经手者按原样核对。中间再来的说法未必准确，后面的小帮助也不一定能接上。把现有记录留清，别因为一时没有消息就换好几种找法。

开局：春令兑体囚，相离本用克兑，起步要核真实的去处较难。

过程：体互囚乾比体，旧范围可留；旺巽用互受囚兑所克，分辨几个相似说法较费力。

结局：初九鞏革取固守，变法的时机还没成熟。末死艮仍生兑，能补一点信息，难抵先前阻碍，原物偏难回。 东北与近路边、岩石旁是变艮的传统提示。起查可先核最后确知的停留点，相关场所若仍能补问，把实际经过与原件记号一并给清。 本用离的书文、文彩和赤色，可比原件已有的字样、壳面与红紫标记，原形制和质料照旧图辨。变艮的石土、门径及黄色陈设另看环境，起查可按真实停留补问门边、石台或原临存格，把实际经过与原件记号接清。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，开头问查时暂无法核定最后去向。若已经开始寻找经手人，容易出现只有模糊地点、无法核实的情形，属凶应。

总断：原物难寻。把确知的最后使用和收放留一份，再接受可以核对的答复。
