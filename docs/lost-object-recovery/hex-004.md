## 初六动 · 寅月、卯月

先解开一处疑点，眼下仍难把东西找回来

山水蒙 → 地雷复 → 山泽损

简断

眼下较难找回。若你还拿不准最后一次是什么时候用的，宜从最容易证明的那一处开始问。前半程可能有人能帮你确认范围，问到物品到底怎样收放，仍容易碰到难弄清的地方。把查明的事留下来，别为了一点头绪就把剩下的力气都花进去。

开局：艮土原体春死，坎水本用春休，土虽克水，眼下实查较吃力。起头先核自己确定持有物件的时点。

过程：体互坤土同属春死，和原体比和，有少量旧经过可续。用互震木春旺克艮，到具体查验时阻力明显，现场条件须先问清。

结局：初六发蒙有释疑之利，也有用得过头则吝的告诫。变用兑金春囚，艮土生兑，收尾还要花些力气，难突破中段阻碍。能解一处疑点，眼下仍较难寻回。

可留意本月12、13号前后，弄清遗落范围后仍遇到实际查验限制，属凶应。若已确定有一处值得核，对方仍可能无法提供必要的记录或允许查看，属凶应。

总断：争取查清最后一处能证明的存放信息即可。若遇实查限制，先记下缺什么资料，后面有具体消息再补查。

- mh-077《失物占第十五》，原文第 573 行起。
  “又以变卦为失物之所在。”
  依动侧变用取传统场所类象，只在已知行程内作补充排查。

- mh-117《体用互变之诀》，原文第 795 行起。
  “用为占之即应，互为中间之应，变为事占之终应。”
  本用及两互、变用各自对原体，分阶段核看。

- mh-119《体用衰旺之诀》，原文第 803 行起。
  “凡体卦宜乘旺，克体之卦宜衰。”
  各位置同时使用实际月令五态。

- mh-116《占卦诀》，原文第 791 行起。
  “如占吉事，无生体之卦，有克体之卦，则事不谐矣。”
  核对初段难寻、两互能否提供有效线索及收尾能否领回。比和可取在已知处回查，不视为物品已定位。

- mh-077《失物占第十五》，原文第 573 行起。
  “用克体，不可寻。”
  本用对原体为开局的直接依据。

- mh-122《占卜克应之诀》，原文第 822 行起。
  “应之期远，则以年，近则以月，又近则以日也。”
  近期已有可继续核查的记录或可联系的经手方时，才依生体、比和或克体择一个可观察的阶段事件，不据取日推定已经寻回。

- mh-122《占卜克应之诀》，原文第 822 行起。
  “细观生体之卦为吉，应决期克体之卦为凶。”
  末坤土旺克坎，以真有经手点为前提，只报认领受阻候选。
