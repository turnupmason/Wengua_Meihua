## 初九动 · 寅月、卯月

有人肯接查询，原物眼下仍难找回

地泽临 → 地雷复 → 地水师

简断

约好请人协查之前，先说明你确知物品什么时候还在、用过以后做了什么。这一轮偏难找回，常常只能查到其中一小段。如果对方只是应了一声，可以再问他有没有条件打开原收纳处。真没看过便先留下登记。

开局：坤在春死还生囚兑，找物开始已耗一点精力，须从手里的实据问起。

过程：体互死坤与原体同类，熟悉人员虽能应声，实际协助有限。用互震木旺克坤，走到经手细节不明处，复核容易中断。

结局：初九咸临而守正吉，重在回应得其正。变休坎仍是死坤难制的一段，接应若未落实为查看，原物还是偏难回来。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，核清承接查询的人能否查看原存放处，属凶应。若原来的代查还要转交，问到实际谁能查看时较可能留下一段空白，属凶应。

总断：这次偏难找回。让有实际查验条件的人接手，其他答复只记他见过的部分。

古籍依据：《周易·地泽临》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。

## 初九动 · 巳月、午月

有一处能互相核查，原物仍有机会回来

地泽临 → 地雷复 → 地水师

简断

找回仍有机会，先把能自己回看的范围查一下。需要别人接手的地方，把刚查过的部分交代清楚，请他只补一处。若收到相像物件的消息，拿原有特征去辨认，把已经确认的结果告诉协查的人，免得大家还在同一处找。

开局：相坤生死兑，起头可动手，查找所耗不多。

过程：体互相坤同比，近处有人或有记录能相互核对。用互休震仍来克坤，交接时有一处需要把话说清才能查。

结局：初九咸临，本来有应，还须行正。变囚坎能由相坤克制，手头有条件把话问到实物，原物仍有找回机会。

应期：以下为传统推算的参考窗口。
可留意本月11、14号前后，从熟悉的经手范围取得实际查验，属吉应。若真能请到了解原放置处的人，适合对照手头实查和他的结果，属吉应。

总断：有条件找回。两边把实际检查范围对好，再核物件的独有记号。

有人能应一声，东西眼下仍难接回来

地泽临 → 地雷复 → 地水师

简断

这次偏难找回。若已经联系了一处可以查的地方，先问他们能否按收放时段核到一批具体的物件。对方一直给不出能检查的位置，就把最后确见的经过和标记留好。多拨几个号码也未必补得上这个缺口。

开局：休坤生旺兑，开头容易付出不少时间，实际收放未必能随之查清。

应期：此盘暂无有据的日期可列。

总断：难找回。确定谁能实际核对，地点和时间都不明时先别跑远。

## 初九动 · 亥月、子月

原来有人可问，眼下并不容易找到原物

地泽临 → 地雷复 → 地水师

先找最后亲眼见过它的人，把那一段动作问实。这件物品目前偏难找回，往后若只剩别人转述，记下出处即可，暂缓继续追。能找到真正保管过的地方时，再拿辨识照片去看，比把原来的经过反复说出来有用。

总断：原物偏难取回。把可靠见闻递给能实查的一处，不在转述中来回打转。
