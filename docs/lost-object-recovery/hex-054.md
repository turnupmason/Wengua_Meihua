## 初九动 · 寅月、卯月

开头略有难处，后面还有协查机会

雷泽归妹 → 水火既济 → 雷水解

简断

这件东西有机会找回。若最早只有一处能说清最后用过，可以从那里查有限的一步，不用一开始翻遍周围。中间若有人能补一点收放细节，先用照片核实。末了仍可请经手方再看一眼，条件真能接上，原物就有取回希望。

开局：春令震体旺，囚兑本用克震，开头虽有小阻，自身能够应付。

过程：体互休坎生体，有些经手协助；用互相离受震生，核多处会有实际耗费。

结局：初九跛而能履，能做合宜的一段才为征吉。末休坎再生体，晚些还能补助，宜沿可见原物的地方查，取回有条件。

应期：此盘暂无有据的日期可列。

总断：有条件可寻。让真正接手的人按一项特征核一回，不做超出已知范围的查找。

古籍依据：《周易·雷泽归妹》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。
