## 初九动 · 寅月、卯月

先慢一步核准，原物仍偏难找回

水火既济 → 火水未济 → 水山蹇

简断

这件物品偏难取回。最早自己查证就要费力，可以先核完最后一次真实取放，不必因有人说像便马上换路。中间能一起查的帮助有限，末后原件辨认还可能受阻。把已经核实的细节留好，少为一份未证实的答复急着动身。

开局：春令坎体休，相离本用受水制，初查较难做实。

过程：体互相离仍受坎制，自行辨证吃力；用互休坎比体，配合有限。

结局：初九曳轮濡尾无咎，王、孔取始济未易而志在弃难，不预言沾水。末死艮克坎，阻薄却少实援补自查之难，取回偏难。 东北与近路边、岩石旁是变艮的传统提示。原行程若还清楚，可先核最后确实停留的一段，查看记录与原物记号宜同时留好。 本用离的书文、文彩和赤色，可对应原件已有的字样、红紫记号及原构造，形制、材质照旧资料认。变艮的土石、门径与黄色陈设另看周边，原行程清楚时，可请真实停留处补看门边、石台和原临存格，查看结果连同原物资料留好。

应期：此盘暂无有据的日期可列。

总断：较难寻回。做完能证实的一步，别把急于离开困境变成跟着猜测跑。

古籍依据：《周易·水火既济》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·八卦类象》《梅花易数·八卦万物属类》《梅花易数·形物占》《梅花易数·卦应（与前八卦类象，大同小异，观者可以互参）》《梅花易数·占卜克应之诀》。
