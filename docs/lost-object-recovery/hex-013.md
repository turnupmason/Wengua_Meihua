## 初九动 · 寅月、卯月

可以到原活动处问一趟，东西暂难找回

天火同人 → 天风姤 → 天山遁

简断

这件东西暂时难找回。先问回到原来活动的地方以后，谁能当场看实际收存的位置。只要有人愿意受理，还不能说明已经查到，不用逐个给熟人转发一遍。把最后一次使用的时间和独有标记交给能核的人。

开局：离火得相，开头就克囚乾。能走到现场，也可能没办法直接核看。先问明查找的入口。

过程：体互囚乾同比，原处尚有些照应。用互旺巽在囚乾难制之处，倘要追到另外一个收存环节，可用的记录和人手未必够。

结局：初九在门与人相同而无咎，可从正常公开的查询处借力。变艮土死而仍生乾，薄助抵不住前面实际的查证难处，原物不易回来。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，确认原场地有没有条件实际查询，属凶应。若已回到原来活动的地方，问到能不能核看原存放位置时，可能暂有实际限制，属凶应。

总断：失物偏难找回。照手续留一次具体信息，等到了确能辨认的答复再去取。
