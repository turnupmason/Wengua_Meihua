## 初九动 · 寅月、卯月

可以到原活动处问一趟，东西暂难找回

天火同人 → 天风姤 → 天山遁

简断

这件东西暂时难找回。若能回到原活动场所，可以先问由谁查看实际收存的位置，把最后使用的时间与独有标记交给能核实的人。开始的查验不容易，中间可能还缺交接记录，末后的帮助也较有限。先留妥查询，等有可辨认的结果再跟进。

开局：即使能到现场，也未必能直接查看物品。乾金体春囚，离火本用春相而克体，初段限制较实，先问清谁负责实际核验，能使查询有所着落。

过程：原处尚可得到少量配合，深入收存细节仍可能困难。体互乾金春囚，与体比和，照应有限。用互巽木春旺，受乾金所克，原体较弱，跨到另一经手环节，还需相应记录支持。

结局：初九同人于门而无咎，妥当接洽、从正常查询处求助，是可行的做法。变用艮土春死仍生乾，末段帮助偏薄，较难补上前中较重的查验难处。近期取回原物偏难。 方位取东北，艮列近路边、岩石旁。若最后取用发生在出入途中，可按确知路线向沿途管理方查询，物品描述宜清楚公开地给到对口人。 若原物有文字、彩纹、外壳护着内里的构造，可参本用离核字样、接缝与原有红紫色。质料从原件资料辨。变艮的石土、门径和黄色陈设另看周边，出入途中确实用过的门边或石面，可以先请原处补看当时收拾到哪里。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，确认原场地有没有条件实际查询。若已回到原来活动的地方，问到能不能核看原存放位置时，可能暂有实际限制，属凶应。

总断：找回倾向不利，可循现场手续留一份具体资料。等经手处查出与独有标记相符的物件，再安排认领，原来实际查过的范围也应留清。
