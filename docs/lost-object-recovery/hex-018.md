## 初六动 · 寅月、卯月

能补旧查找的疏漏，原物眼下仍偏难回来

山风蛊 → 雷泽归妹 → 山天大畜

简断

这件物品找回的把握低。若前一回没分清谁真正核过，可以自己整理出最后一次使用的确切事实，再请实际经手处看看。补过之后还是没有可辨的物件，就留下前后结果。重来一遍有益，范围却不能只凭新想法扩开。

开局：旺巽克死艮，头一处搜寻便有明显限制，原来留下的记录并不足用。

过程：体互旺震继续克艮，接到别人整理过的那一段难核。用互囚兑受艮生，补问又要花工夫，宜只查有证处。

结局：初六有能任事者补前事之弊，虽厉而终吉，所以值得修查漏的那一步。变囚乾仍耗艮，前段阻碍未解开，现有条件下原物仍难回。

应期：此盘暂无有据的日期可列。

总断：本轮找回偏难。把过去漏的核验补上，等一处确能辨到原物才再追。

古籍依据：《周易·山风蛊》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。
