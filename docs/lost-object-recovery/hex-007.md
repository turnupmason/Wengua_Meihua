## 初六动 · 寅月、卯月

查找先分先后，眼下仍难见到原物

地水师 → 地雷复 → 地泽临

简断

这件物品近期偏难找回。若已请几个人帮查，先把谁核哪一处说清，免得大家只追同一条消息。中间关键的实查仍可能办不了，末后自己核证也费力。先问明哪些地方真看过、哪一步还缺，交给能实核的人接着查。

开局：起头宜先分清谁能查哪里。春令坤体死，休坎本用受土克，自己把范围查细并不轻松，重复询问难补实据。

过程：体互死坤与原体比和，可按已经核准的位置分工。用互旺震克体，实际到场查看的限制较强，需先问清可查的一步。

结局：初六师出以律、否臧凶，查找也宜有明确先后与负责者。末囚兑受坤生，后段仍要花工夫，中段实阻未解，近期原件取回偏难。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，分头查找以后仍碰到一处要紧限制，属凶应。若已经分好各方负责的地点，中途可能因现场或记录无法查看而停顿，属凶应。

总断：近期较难找回。先问谁真查过哪里，尚无条件验证的留给能实核者，暂不扩大新范围。
