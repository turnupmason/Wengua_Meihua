## 初九动 · 寅月、卯月

守住一条可信线索，末后仍有寻回机会

风泽中孚 → 山雷颐 → 风水涣

简断

这件物品有机会找回。开头若某处答不清楚，先留好真实收放，不因又听到一个地点就把原来的查找推翻。中间有人能一起核，末后也会有少量帮忙。把查证集中在真正接触过物件的一处，独有记号对上时再认领。

应期：以下为传统推算的参考窗口。

总断：有条件找回。把一条可证的收放查到底，再据新事实决定是否换路。
