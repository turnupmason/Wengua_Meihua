## 初六动 · 寅月、卯月

别把查找拉得过远，原物偏难回手

雷山小过 → 泽风大过 → 雷火丰

简断

这件物品偏难找回。起头仍能在确知范围主动查，可以先看最后一次实际取放，别因听说另一处像就马上跑远。中间有人能共同核，末后却还要自己多花工夫。查过的结果留清，没有新的实物记号便先不扩大。

开局：春令震体旺，死艮本用受木制，初查能主动落实。

过程：体互囚兑克震，疑点尚可处理；用互旺巽比体，共同复查有力。

结局：初六飞鸟以凶，取进而违宜、终无所托，不据鸟象定位。末相离由震生，末段所耗实，前中能查仍难变成原物归还，取回偏难。 南方与明窗、文书之侧是变离的场所取象。起头宜先补看实际用过的文件台，问明收拾经过，再据真实新证安排下一处查询。 原件确有石质、陶面或黄色旧印时，可参本用艮核原纹理、边沿与形状，把旧照片里能认同件的细节给清。变离的书文、文彩与明窗另参环境，起查可先补看真用过的文件台、印字包装旁与原临存格，再凭真实新证继续。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，中段共同核一处最后的真实收放。若原接触范围仍能一起查看，较容易确认一项先前漏查的动作，属吉应。

总断：较难找回。把原范围的一轮做完，少随无据消息另起远路。
