## 初九动 · 寅月、卯月

早一点止住错误查法，原物仍有机会找回

火雷噬嗑 → 水山蹇 → 火地晋

简断

还有找回机会。最初如果给了不够准确的描述，可以先改成确切的时间和物件标记，免得别人顺错了去向再查一轮。知道哪处原来真放过它，就把这一步做完。其他地方暂时只保留记录，有实际消息再接。

开局：旺震生相离，起头有实际帮助，适合把握住较有凭据的位置。

过程：体互休坎克离，原来可查的范围可能有一处需重核。用互死艮受离生，补查仍要工夫，范围可以收窄。

结局：初九屦校灭趾无咎，能在小错初起时止住，所贵在及时纠正。变用死坤仍耗离，尾段证物不宜拖久，前面查实便有找回机会。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，从最早可靠的经手处发起核查，属吉应。若原来使用的位置还有人能实看，较容易拿到可继续核对的消息，属吉应。

总断：有条件找回。先把查找的早期描述改准，再让实际经手处核看。
