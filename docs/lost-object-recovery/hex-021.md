## 初九动 · 寅月、卯月

早一点止住错误查法，原物仍有机会找回

火雷噬嗑 → 水山蹇 → 火地晋

简断

还有找回机会。最初如果给了不够准确的描述，可以先改成确切的时间和物件标记，免得别人顺错了去向再查一轮。知道哪处原来真放过它，就把这一步做完。其他地方暂时只保留记录，有实际消息再接。

开局：起初有较有力的查找支持可借，适合先核最有凭据的位置。离火体春相，震木本用春旺而生体，可以将确定的时间和原物标记交代清楚。

过程：原来可查的范围可能有一处需要重核，补看仍要花些工夫。体互坎水春休，克离，阻力较轻。用互艮土春死，受离火所生，耗费较薄，可先纠正不准的查询描述。

结局：初九屦校灭趾、无咎，取小错初起能够止住，及时改正便有益。变用坤土春死，仍受离火所生，末段有轻耗。前面的实际支持若能用于核清原物，仍有找回机会。 西南及仓储、方器之中是变坤的传统场所象。若起头查验有缺口，可先核实际用过的方盒与储物处，边查边补清原记录。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，从最早可靠的经手处发起核查。若原来使用的位置还有人能实看，较容易拿到可继续核对的消息，属吉应。

总断：这件东西还有机会找回，可先把早期登记中不准的描述改明白。将真正存放过的一处交给经手者核看，查到实物后再辨认领取。

## 初九动 · 亥月、子月

火雷噬嗑 → 水山蹇 → 火地晋

简断
