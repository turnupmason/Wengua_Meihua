## 初六动 · 寅月、卯月

沿已知的一组物品排查，找回仍有机会

天地否 → 风山渐 → 天雷无妄

简断

这件东西还有机会找回来。若最后一次使用时手边有一组东西，先核哪几件确实是同一回收起来的。能够复原的那一组可以查到底；看到收法相似的另一拨物品就先别混进去。范围守得住，遗漏反倒容易露出来。

开局：坤土入死，仍给囚乾一点帮助，开始宜借已有的存放依据。

过程：体互巽旺而囚乾制之有限，零散收纳未必一并可查。用互艮土死而生乾，近旁或能补一段，却无力包办。

结局：初六拔茅同类而以贞得吉亨，意思是守住本分、顺有据的同组查验。变旺震仍是乾难制的一关，最后一处若能实查才有找回机会。

应期：此盘暂无有据的日期可列。

总断：有条件找回。清点同一次收过的物件，不用把相似的收纳都拉进来。

古籍依据：《周易·天地否》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。
