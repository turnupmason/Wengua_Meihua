## 初六动 · 寅月、卯月

沿已知的一组物品排查，找回仍有机会

天地否 → 风山渐 → 天雷无妄

简断

这件东西还有机会找回来。若最后一次使用时手边有一组物件，先核哪几件确实是同一回收起的，再把那一组查完整。起初能借到的帮助有限，中间和末后仍有实查难处。共同收放的记录若能补齐，就沿它辨认原物，取回仍有希望。

开局：先借已有存放依据展开查找。乾金体春囚，坤土本用春死仍生体，起头能添一点帮助，力量较薄，可以从仍拿得出的一组相关物件问起。

过程：同组收纳未必能一次查全。体互巽木春旺，受囚乾所克，自己较难核透。用互艮土春死仍生乾，中段或能补核一部分，帮助有限，还需经手处说明实际查看了什么。

结局：初六拔茅茹、以其汇，贞吉而亨，取同类相牵而仍守正，查找宜紧扣有据的同一次收放。变用震木春旺，受乾金所克，末段实查也较难充分。若最后一处能够实际核验，仍有找回机会。

应期：此盘暂无有据的日期可列。

总断：寻回有条件，先清点确实同一次收过的物件。请能够查看的人补明最后的收存，再以独有特征核物，保持这条已有实据的查找路径。
