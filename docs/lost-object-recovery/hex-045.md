## 初六动 · 寅月、卯月

把零散消息归到原来的那一步，还有找回机会

泽地萃 → 风山渐 → 泽雷随

简断

物件尚有机会找回。起初得到的回复可能太简短，到后来又传出相似物的说法，不妨把亲见和听说各自归到原处。若最后找到一个人能照经手经过复查，就把物品特征交给他；其余猜测不用都跟着跑。

开局：春令兑体囚，坤本用死而仍生兑，起步可得一点帮助，依据偏少。

过程：旺巽体互受囚兑克，核查说法较费力；死艮用互仍生体，能补有限的经手信息。

结局：初六有孚不终而乱聚，谦退再往可免咎。旺震变用也被囚兑克，尾段核物需费工，有确切证据才适合接下去，仍可回收。 东方及闹市、大途是变震的取象。消息零乱时，可先照最后确认携物的一段筛出真实停留处，向当地招领方核相应记录。

应期：此盘暂无有据的日期可列。

总断：有条件寻回，宜先把混在一起的消息分清。请见过原件的人核特征。

古籍依据：《周易·泽地萃》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。
