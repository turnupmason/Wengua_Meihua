## 初六动 · 寅月、卯月

从最后用过的位置起查，原物仍有一寻

风山渐 → 火水未济 → 风火家人

简断

这件物品有机会找回。先问最后实际用完后有没有暂放，不用一下问完整条路线。中间可能听到和印象不同的话，哪一项能证实就先核哪一项。末了自己还要花工夫确认，手里有确切的收放证据时，再借它去核原件。

开局：春令巽体旺，死艮本用受巽克，起步可主动核实际取放。

过程：体互相离受木生，仔细查问会花工夫；用互休坎生巽，某些疑处可从经手方补证。

结局：初六渐于水涯，有言而义无咎，借提示起步有小波折。末相离仍耗体，前面若确已查实，仍有机会找回；力气留给最后认物。 方位可从南方参看，明窗、文书旁属于离的场所。若初来消息仍浅，可先核原来是否在文件台取用过，再向原处问具体收拾经过。

应期：此盘暂无有据的日期可列。

总断：有条件可寻。先问能验证的一个细节，不把后来传来的话全算进去。

古籍依据：《周易·风山渐》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。
