## 初六动 · 寅月、卯月

查到没有实据的一步就停，原物眼下偏难回来

坎为水 → 山雷颐 → 水泽节

简断

这一轮偏难找回。先把最后一次确定持物的位置与后来听说的经过分开。若第一处还能开看，就按原来的使用动作核一次；往后没有人真正见过，不必只靠推测另往几处。查询一处接一处，却拿不到实物时，先留清楚的物件特征。

开局：坎体与本用同休，比和让熟悉之处还有入口，掌握的实际范围不大。

过程：体互死艮仍克坎，起初可问，到了收存处可能有条件要补。用互旺震再耗坎，来回查询更容易费力。

结局：初六重险又入坎底，凶在沿错处走深。变囚兑虽生坎，帮助薄，当前不易让原物回来。

应期：此盘暂无有据的日期可列。

总断：偏难找回。发现哪一步不能核便先停，在那里留一份能辨物的资料。

古籍依据：《周易·坎为水》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。
