## 初六动 · 寅月、卯月

查到没有实据的一步就停，原物眼下偏难回来

坎为水 → 山雷颐 → 水泽节

简断

这一轮偏难找回。最后确定持物的位置与后来听说的去向，先分别记清。原处若还能开看，可按使用经过补查，再往后就要问到真正见物的依据。中段查验不易，末后帮助也薄，把独有特征留给能实核的一方。

开局：熟悉处尚可回查，起步能够掌握的范围却不大。坎水体与坎水本用春令同休、彼此比和，可先核最后确定持物的位置。

过程：原收存可能有条件待补，继续追问也较费力。体互艮土春死，仍直接克坎，阻力很薄。用互震木春旺，受坎体所生，往后查询耗费较实，去向宜问到亲见依据。

结局：初六习坎、入于坎窞、凶，已有重险又陷其深，沿无实据的方向深追易失。变用兑金春囚，直接生坎，末后帮助较薄。原查验所缺尚难补上，原物目前偏难回来。 西方是变兑的传统方位，场所参泽畔、破壁。若原路确实经过相应地带，可向管理方核安全可见处，查验步骤先从能够确认的记录开始。

应期：此盘暂无有据的日期可列。

总断：眼下较难寻回，亲见的使用经过和原标记留清，原处能补看的先核。新的去向有实据再接，尚无法查看的部分问明所缺条件。

古籍依据：《周易·坎为水》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。
