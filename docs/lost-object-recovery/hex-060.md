## 初九动 · 寅月、卯月

先在确知范围内查，原件仍偏难寻回

水泽节 → 山雷颐 → 坎为水

简断

这件物品偏难找回。先把最后一次确定拿出来的地方核清，别一想起别的可能就急着跑远。中间自己还要费工夫追收放，末后原处虽可继续问，配合仍有限。把已查位置和原件标记记在一起，有实物消息再往下认。

过程：体互死艮克坎，阻碍薄；用互旺震受水生，中间自行核问会耗费较实。

应期：此盘暂无有据的日期可列。

总断：原物难寻。先做完确知的一处，不把没看过的地方都当成下一站。
