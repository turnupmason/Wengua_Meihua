## 初九动 · 寅月、卯月

可先做一次就近核查，原物仍不易找回

山泽损 → 地雷复 → 山水蒙

简断

这件东西偏难找回。若知道最后在哪里用过，先把那一处查完再决定去不去别处。中间可能收到方向不同的消息，应留住其中能对原物特征的一条。到了收尾若只能凭印象翻找，就把这轮核查的结果记好，暂不必继续扩大。

开局：春令艮土体死，兑金本用囚而受土生，开头多靠自己费力找，实物线索不多。

过程：死坤体互比艮，旧位置还有一次复查余地；用互旺震克死体，后来听来的去向较难对证。

结局：初九事毕方速往、酌而损之，取先查完一处，再适量投入。变用休坎受死艮克，收尾难落实主动搜回，中段强克又在，原物仍偏难寻。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，中途得来的去向不容易和实物对上。若正在核实不熟悉的新去向，可能发现途中的说法无法对上原物，属凶应。

总断：取回偏难。挑最后确曾用物的一处看完，后来的地点须有原物特征作证。
