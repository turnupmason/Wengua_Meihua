## 初六动 · 寅月、卯月

眼前好查也需亲自验过，原物仍有机会回来

雷地豫 → 水山蹇 → 震为雷

简断

东西还有找回的机会。若有人一听描述就说大概找到了，先问原物上那处独有的标记还在不在。对方看不清，你可以拿以前的照片去比对。先稳稳查完这一处，再决定是否停掉其他查询，免得把一个相似的东西认成原物。

开局：旺震能制死坤，起手有能够掌握的查找范围。辨认时以自己确知的一点作准。

过程：体互休坎生震，身边能帮你核验的照应有限而实在。用互死艮由震克，具体位置若还未查完，有条件再开看。

结局：初六鸣豫而凶，早早以为已经解决容易把后面的核对省掉。变旺震比和，前后的实查条件不差，守到实物验准才有找回机会。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，确认收到的近处物品确实是所失原物。若已有一件相像的东西可作比对，适合实看独有标记再认领，属吉应。

总断：有条件找回。先看看是否真有独有标记，再收掉失物查询。
