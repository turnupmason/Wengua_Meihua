## 初六动 · 寅月、卯月

先接住能帮查的一处，原物仍有找回机会

风水涣 → 山雷颐 → 风泽中孚

简断

这件物品有机会找回。若刚发现遗失，还能联系到最后经手的人，就先请他看原来的收放，别等所有路线想齐才问。中间有人能一起查，末后仍要核一个难点。把开头的帮助用实，及时留下可辨记号，原物便有希望认回。

开局：春令巽体旺，休坎本用生木，起步能借一些帮助查明旧处。

过程：体互死艮受旺木制，疑点可以主动核；用互旺震比体，共同查找的条件较实。

结局：初六用拯马壮吉，在分散未甚时及时借力。末囚兑克旺巽，最后认物仍有阻，但前中能查，及时核出实物仍可取回。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，经手处一起复查最后收放，属吉应。若原来的人尚能查看现场，较容易补出一项认物细节，属吉应。

总断：有条件找回。先请眼下能看物的人查，不让可核的收放拖成模糊印象。
