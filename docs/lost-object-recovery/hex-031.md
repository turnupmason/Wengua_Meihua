## 初六动 · 寅月、卯月

最初的一点迹象还不够，原物眼下难找回

泽山咸 → 天风姤 → 泽火革

简断

原物偏难找回。若现在只记得好像在哪里拿过，可以先核那一次是不是实有其事，别沿着一丝印象直接去约认领。能拍清独有痕迹的实物值得核，地点只听他人说又不能打开看时，先留下原来的描述。

开局：初步帮助较薄，自身直接可核的范围也窄。兑金体春囚，艮土本用春死而直接生体，可先问那次拿过物品的印象是否有记录可证。

过程：近处尚能添些照应，后来收放却较难查全。体互乾金春囚，与兑体比和，原描述可先留准。用互巽木春旺，受囚兑所克，自身制力不足，下一去向需有经手者实看。

总断：这次偏难找回，先核最初印象有没有亲见经过或可辨物件。能拍清独有痕迹的再对证，地址只凭转述时问明依据。
