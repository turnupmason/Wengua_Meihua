## 初九动 · 寅月、卯月

原处可照常回找，暂难把东西带回

天泽履 → 风火家人 → 天水讼

简断

这件东西暂时难找回。可以把最后使用的经过拆成平常动作，想清一次拿了哪些东西，腾手时又先放下哪件。若能在原处重做一遍，就核那一刻手边还有什么。中间实查可能有难处，后面仍要费力，新想到却无法验证的去向先记下。

开局：熟悉的原处还有回查的余地，进展可能偏慢。乾金体与兑金本用春令皆囚，体用比和，起头能接到一些配合，宜按平日的收放顺序核。

过程：查到细节时会有难以看全的一段。体互巽木春旺，受乾金所克，体弱而较难查透。用互离火春相又克乾，若还需记录或他人代看，中段便容易受实际条件限制。

结局：初九“素履，往无咎”，取依平常、真实的步骤行事，可少偏失。变用坎水春休，受乾金所生，末段还须投入工夫。前中查验尚有难处，继续追问也较难落实为取回，当前寻回偏难。 北方与水边是变坎的传统提示，酒醋之旁也属原典所列。先从确实去过的相应场所问起，照最后真实取放核查，步骤可以朴实些。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，恢复核查原先存放处的条件。若正准备调看记录或回到原处复查，有些材料或位置一时可能看不到，属凶应。

总断：常用范围可再核一遍，近期找到仍较难。先把日常拿放的那一段做实，记录实际查过的地方，后面出现有依据的新位置再接查。

古籍依据：《周易·天泽履》《梅花易数·占卜总决》《梅花易数·失物占第十五》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。

## 初九动 · 巳月、午月

从日常收放查起省力，这回物品未必能回来

天泽履 → 风火家人 → 天水讼

简断

这件东西难找回。先问自己上一次用完它，有没有照平日的习惯一起收走什么。只查那个动作会带到的地方，不必先设想有人移走。假如连自己的收放步骤都核过而没有发现，别再反复把见过的地方掏空。

开局：寻找可以先沿日常收纳展开。乾金体、兑金本用夏令都属死而比和，起头尚能接触原范围，配合却很弱，宜先查最后那次用完后随手收走的东西。

过程：关键环节未必查得透。体互巽木夏休，受乾金所克，原体力弱，能核的内容有限。用互离火夏旺克乾，中途向外求证的阻力较重，缺少记录的一步尤其难补。

结局：初九素履而往无咎，按真实收放次序查，可以少生枝节。变用坎水夏囚，仍受乾金所生，末段继续耗费。前中薄弱的配合较难承接实查阻力，这件物品眼下难找回。 北方与水边是变坎的传统提示，酒醋之旁也属原典所列。先从确实去过的相应场所问起，照最后真实取放核查，步骤可以朴实些。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，在惯常的收纳点以外核查去向。若需要请人核对离开常放位置后的经过，接下来那一步可能暂时核不到，属凶应。

总断：本次取回偏难，可先核一遍明确的日常收纳处。自己的步骤若已查全，就把结果留清，等有新消息再继续寻找。
