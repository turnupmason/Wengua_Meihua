简断

这件东西暂时难找回。先把寻找还原成平常的动作：一次拿了哪些东西，腾手时先放下哪一件。能在原来位置做一遍，就看那一刻手边都有什么。新想到的去向若无法验证，先用纸记住，别急着逐处去跑。

开局：乾体、兑用同为春囚，起初比和，原来熟悉的地方还有门路，进展只是慢。

过程：体互巽木当旺，囚乾想克而难制，核看原处有一段力所不及。用互相离火又来克乾，到了要查记录或请人开门时，可能碰到实在的限制。

结局：初九朴素行事得无咎，宜按寻常动作查明，不因着急横生枝节。末用坎休水受乾生，前面若没查到，下一步仍要投入，回手偏难。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，恢复核查原先存放处的条件，属凶应。若正准备调看记录或回到原处复查，有些材料或位置一时可能看不到，属凶应。

总断：常用范围值得复查，找回偏难。找不出未经核验的新位置，就先把实查记清。
