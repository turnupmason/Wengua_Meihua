## 初六动 · 寅月、卯月

进退反复难有新证，原物偏难找回

巽为风 → 火泽睽 → 风天小畜

简断

这件物品偏难取回。若已经在去原处和问另一个地方之间犹豫，先挑一项确实用过的证据去核。中间可能会费一些工夫，末后还缺实物可认。定下一次能完成的查找，再把结果记下，比凭感觉来回改范围更有用。

开局：春令巽体旺，本用巽同旺比体，开始有能力在旧位置回查。

过程：体互相离受木生，核问占去实际工夫；用互囚兑克体，几条说法不合需查。

结局：初六进退因疑，利在用明确的准则整齐。末囚乾克巽，末段仍欠实援，虽有回查力气，取回仍偏难。 西北与高处、圆器之中是变乾的场所象。查询进退不定时，可先按真实收放核原容器，把可查的层格问清再继续。 本用巽的竹木、绳、长直与工巧器，可对原件已有材料、轮廓和原接合，青碧洁白按旧照片认。变乾另参圆器、高处及金玉陈设的环境，查询进退不定时，可先请原处看真用过的圆盒、高层格和硬质器物旁，实看后再接续。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，在原位置实际核完一次收放。若最后用过的地方仍能回查，较容易证实一项先前漏问的动作，属吉应。

总断：原物难寻。先完成一项能核准的收放，不让下一条传话又改了计划。
