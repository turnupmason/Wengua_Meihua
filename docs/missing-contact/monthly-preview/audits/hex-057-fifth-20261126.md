# 巽九五逐月稿 · 2026-11-26

《周易正义》九五「贞吉，悔亡，无不利。无初有终。先庚三日，后庚三日，吉」；王孔从阳居阳损谦巽、执中正宣令、初皆不悦而终于中正解释，庚为申命，先申三日、令著复申三日。程颐释庚为变更之始、始未善而更之使善，改更当原始要终；朱熹释无初有终为有悔而亡悔，先庚三日丁、后庚三日癸，丁宁其变之前、揆度其变之后。各按所收原典录文说明，古日非现代失联者的实际联系日期，不把六日定为等待期。

原体下巽，本用上巽比和；体互下兑克原体，用互上离受原体生而耗；动九五上巽化艮，山风蛊，尾上艮受原体所克。非生体。春木旺、金囚、土死，原体能承中克制末用，虽离相耗仍有条件寻获；冬木相、金休、火死、土囚，亦有条件寻获。季土木囚、相金克中、尾土旺，秋木死、旺金克中、末土休，原体乏力，较难；夏同休木、旺离实耗、死金克薄、相土末受体克仍需出力，也较难。九五古辞有终与具体盘之强弱分别，不作必归之断。

有近期实际可信查证渠道，春冬按原本用巽木比和取木日举初段资料衔接之演示；其余缺明确近期现实事件，不定联系日。原用方位传统类象、尾艮及蛊卦都不作人员位置、安危或缘由证据。

逐篇首读：寅王孔行令初终不直接定寻获；卯程朱庚日异释、修“本批”内语；辰土令中克末制，具体近期事件改词；巳朱本义悔亡及丁癸非日期；午程传庚为变更之始，夏旺离耗实；未木囚弱体制旺土；申死木非死亡，简断自然起首；酉程传始未善后更之使善不写真人行为；戌朱本义刚健中正不代替现实人地；亥有气之木制尾囚艮，修“实着”语义；子程传改更始终、末体克用非生助；丑王孔申命不作等待期。受改卯辰申亥经作者和独立读者整篇复读。
