# 全库断语开头与文气专项返修（2026-11-26）

## 实际范围

本轮此前已补齐64卦4,608篇，完整首编实读及独立全文核读记录可查。初扫4116篇的机器报告识别了归一首句和简断重复开头、整爻12个月均从月令直起等文风风险。机器不可以代替文学判断，故采用逐个标示对象、人工阅读原文、自然化开头、不同读者完整复读及具体修改反馈的流程，不批量用程序生成文字。

第一批589个对象针对归一化首12字、跨标点或首16重复的起笔；第二批177个不重叠对象针对仍整爻十二月均月令直起的连续节奏，每组抽取分散月份以不同自然逻辑起笔。两批共766个不同对象，影响35卦。作者及独立读者实际全文阅读改后对象及对照原文，受改篇完整重读后按文章JSON摘要锁定；其他旧对象保留历史全篇核读证据，未宣称本轮重新读完所有4,608篇。原月令事实、术数正反证、判码、应期、原典与三栏均原样保留；只改标示的正文首段或简断。详细每个改键及双人意见、源摘要旧新对应见[766个实读修改对象记录](STYLE_REPAIR_20261126.json)。

## 机器复算与语言

[全库修后扫描，口径小修前](STYLE_SCAN_4608_PRE_FINAL_20261126.json)覆盖4,608篇。正文和简断去除明确引文及标点的首12字，无论原样还是按实际月支归一，跨第一句标点亦无重复组；没有任何整爻十二个月全用月令直接起笔。首16/24字重复组为零，全文重复和24字以上完整重句为零，正文Jaccard≥.64及简断≥.72近重复为零。仍有不同表达的自然月令开头，月令是计算事实，并非一律删除；偶有很短的相同结论句及传统术数必要词汇，另做末轮定向精修，不使语义为了形式去重而改变。机器检查不是全库语言完美的客观证明。
