# 巽六四逐月稿 · 2026-11-26

参《周易正义》巽六四「悔亡，田获三品」，小象「田获三品，有功也」；王弼、孔颖达以乘刚有悔而得位承尊，行命有功，田猎所得譬喻，王孔三品干豆、宾客、充君之庖；程颐《伊川易传》卷四以阴居阴而上下能巽，田获三品譬遍及上下；朱熹《周易本义》卷二阴居阴处上体之下，悔亡、卜田之吉。古义不移作寻找人员的数目、地点、行动或期限，取用与现实证据区分。

六四动上巽为乾，天风姤，原体换为本卦下巽、上巽本用固定；体互下兑克原体，用互上离由原体去生，末上乾克原体。比和只是初段。春两巽旺、两金囚、相离耗，冬两巽相、两金休、死离耗薄，原体较可承而留下条件性机会；夏同休、旺火耗实、双死金克较轻但末无生和较难；土令囚木、双相金克、休离耗，秋两巽死、双旺金克、囚离耗，均较难。无直接生体，不将间接火克金当成确定解围。

春冬候本用巽与原体比和木日为已有近期现实核查渠道中的起段材料衔接演示，其余缺具体可取日事件不设日；不以田获三品定三条线索、三处地方、三天或确定联系时间，现实危险及时依法求援。

作者逐篇核读：寅正反证并列并改相生为所生；卯朱本义悔亡不指脱险，去立即及时叠词；辰明确上下体用位置不混同初六；巳王孔三品古训非真人交往；午程传遍及上下不作线索数；未中末相金克原体、本用囚非受困；申死木非人员死亡、旺金克体；酉程传三品不决定独立信息来源数；戌古辞与现代人地证据分问；亥相木起比有气、休金双克仍在；子朱本义卜田古义非实际位置；丑直接克制方向改词且无应期。受改寅卯丑经作者与独立读者整篇复读。
