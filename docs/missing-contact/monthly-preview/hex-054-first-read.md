## 初九动 · 寅月

卦辞说征凶，初九为什么偏又说「征吉」

雷泽归妹 → 水火既济 → 雷水解

《归妹》卦辞说「征凶，无攸利」，初九却有「归妹以娣，跛能履，征吉」。王孔不是把这一爻的话一概改成了吉，孔疏说少长非偶，以正妻身份径行则凶，依娣的身份行其所宜才吉。寅令问失联的人，用这一爻，我断寻获有机会。不能从卦辞的征凶说绝无办法，也不能看到爻辞有吉，就把家里还没核到的信息算成已经拿到。

孔疏将卦辞的戒、初九所行各从本处说。一边戒不当进而强进，一边借娣从之道讲还有走得通的一路。今天问人，不能把古礼身份搬来猜本人家中发生过什么事。手边真有一处可信来话，能知道从哪里查证，就照那一处做；如果只凭别人随口一说，并没有可以复核的根据，先问清来处，再决定怎样用。可信实情足以认准本人和眼下所在，照实报告寻获，是否靠原先那条路办成的另有事实才说。

本盘原体上震为旺木，本用下兑金囚，仍直接克木，春震旺，还能承受这一层克。中体互上坎休水来生上震，用互下离相火却受震木所生，原体也耗。初九动，使下兑化坎，末下坎仍是休水，直接来生上震。中、末虽皆有坎，两份相助应分在各自一段；旺木担得住前克，又有末段接续，才留下这回可以再查的机会。若一条旧消息只证当时所处，不能由于卦里有后助便把它挪到眼下，仍须问当前的实情。

本用兑参西方、泽边一类地方，实际地点依可靠来源核。若有可信紧迫险情，应及时据实求助。

取末下坎休水生原体的水日，参收尾查证得助。经文两处的征吉凶各有条件，不能据此解释此人缘何失联。

## 初九动 · 卯月

「跛能履」取的是有局限仍可行，别指成人真的伤了脚

雷泽归妹 → 水火既济 → 雷水解

初九说「归妹以娣，跛能履，征吉」。孔疏说娣虽非正配，并未废了在古礼里可以行的那一步，拿脚步有所限而还能行走来作比。问卯令这盘，寻获有机会。《履》六三也有跛能履，小象却接「不足以与行」；归妹初九的小象是「吉相承也」。同样能行，两处对行动结果的判断不同。

就所寻者的日常活动说，已知能行动到哪一步，也只能据证说明到那一步。若有真实可信的近况只说能自己走动，不能把“有能力走动”说成刚从某处走到哪里，更不能代填已在什么地方住下。一个问题问眼下人在哪里，一个问身体如今怎样，证据能一并核准便一并报；若只答得出其中一项，就把所知的那项讲明白。《履》进一步说独能履还不足与行，归妹则许初九所行在当时合宜。现实有行动能力，也不补出没有目击或联系证实的那段行程。

卯令原体上震旺，本用下兑囚金来克，尚能承。中段体互上坎休水生上震，原体另生下离相火而耗。末下兑一动成坎，末水同休，直接生震，收尾有助可留。春令木气旺，前克与中耗不抹，仍有机会把现处查实。若有人带来真正能够核明身份及处所的近信，即可按实确认，没有身体消息也不妨先如实说明下落。此处照所问核眼下所在和已经做过什么，两件事都有据才一同答。

本用兑参西方、泽边等处，脚力或跛的爻义不能代替实际见闻定位。若有可信紧迫险情，应及时据实求助。

取末下坎来生上震的水日，参核查当前真实所在能否得助。能履的古辞不替所寻者解释先前为什么中断联系。
