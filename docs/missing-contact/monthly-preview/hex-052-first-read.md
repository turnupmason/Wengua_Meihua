## 初六动 · 寅月

走到“请止步”的牌前，越过去的那一段究竟谁看过

艮为山 → 雷水解 → 山火贲

若有人照实说“到那块请止步的牌前，我就没再往里走”，先把他所说的这一层听准。未越过牌，不等于一定看不见牌后。站在牌前若确能认出里面的本人及所处，就照实说；若看不清，牌后也可另问有条件了解的人。寅月艮初六，寻获较难。眼前若只听到这一位查到哪里便停了，不宜向家里作结论，说所寻之人已经被发现困在里面，也不能报里头已经查过而没有人。若他还能认清牌前哪条路拐过去，可以按原话留下，没看清的地方也不另添见闻。

王孔释「艮其趾，无咎」，说趾是足，处止之初，若行无所往，脚下宜先止。《周易》又讲时止则止、时行则行，须照所遇而定。你若真有可信紧迫险情，及时据实求助；若有看守或其他确能了解到里面情况的人，也不妨请他说明能核到哪一层。牌前的人确有一面亲见，仍可以用，不必因他没有再往前走便一概舍掉。若原来只是到了牌前，未曾在那里认出本人，就照这一步说。

寅月上艮为体，本用下艮与体同死，比和薄。中有体互震木在春旺，来克弱土；用互坎水休，原体制它亦乏力。末变下离火得相，确实来生艮，有人在后段相助的余地。前中原所受的阻还在，能问到一处与眼下已经找到本人仍要分别说。眼下另有可靠近况核了人和所在，便照实报，不必硬要和牌后的地方相合。

本艮参东北、山径、近山地。牌子立在哪里照实际说，所寻者若确在别处，应随真实近况查。

候火日是末变离来生上艮，参最后核实可能得到的帮助。牌前没有再往里查，说的是查访者当下做到了哪里，不能据来解释本人先前为何没有联系。

### 方位与寻找线索

本艮参东北、山径及近山地，查访到哪里停住不能拿来给本人指定眼下所在之处。

### 处境与安危倾向

若有可信紧迫险情，应及时据实求助，位置还未核得很细也可先向接手者讲明已知实情。

### 失联原因参考

知道查访者因提示止步不能说明本人曾被留在什么地方，也不能代他解释此前失联。

### 应期参考

以下为传统推算的参考窗口。仅在已有可继续核查的现实渠道时观察对应事件；没有新的事实，也不因此推定找到人。

可留意本月27、28号前后，收尾核查本人身份、实际所在及原信由来时，参看能否得到可信帮助，属吉应。初六动下艮变离，末变下离火来生原体上艮土，取火日参收尾所得帮助。中间体互震木克艮、体克用互坎的前阻不抹去。

## 初六动 · 卯月

说在开头宜止，真正有消息时难道也先搁下来

艮为山 → 雷水解 → 山火贲

艮初六「艮其趾，无咎，利永贞」，说到脚下才起的一步。王孔讲行无所往，当先止足；这处止，不是叫所有事都挨到后面再办。卦的《彖》明说时止则止、时行则行，朱熹还指出时宜行而行，也是止于所当。卯月这一问，寻获较难。若眼前只有未经查实的猜话，先别照它把人和去处说死。能认准本人所在的可靠消息已经来到，该核的就核，该报的也可照实报。

譬如有亲友先传来“我看像他”，家里还没听到那人究竟在哪里看见。此时可把原话留下，暂停的是凭还未辨清的一眼就报已经找到，原来的线索和疑处仍可以照实报告。若后来这位能说明当时怎样认得、另有人知道实际所在，便依新的实情往下问。纵然看见这一眼与家里先前猜的方向不同，也应当照真实所在去核。若手边真有此前已经核准的消息，也照实留它原有的来处。果真遇到与本人相关的可信紧迫险情，及时据实求助，一爻之止不耽误这一层。

卯上下两艮土同死，初比和薄；体互震木旺，来克上艮，用互坎水休，亦要原体去制。前中两处实有费力，末变下离火相，来生原体，在收尾仍能有帮助。艮初戒躁进，可保住所知这一分，却不替家里许定在哪天问到。若目前只问到可能的旧处，寻获仍难，别误把收尾有帮手当作现在已知。

本艮参东北、山径和近山处。实情若确落在别方，应随实地去核，不能只求合古象。

末变离火生上艮土，火日参收尾核实有无真实助力。眼下为什么暂不把疑似目击报成已找到，与本人此前何故失联，各要照各自的依据来说。

### 方位与寻找线索

本艮取东北、山径和近山处，实际所在从可核见闻，不为了合方位多添一个去处。

### 处境与安危倾向

有关本人确有可信紧迫险情时须及时据实求助，不由艮止将眼前需要办理的事押后。

### 失联原因参考

寻找一方照实转述存疑的见闻而暂不报已找到，不能拿来指认本人有意隐去联系或为何失联。

## 初六动 · 辰月

原卦比和，书上说“归期不日”，这回究竟问的是归还是寻

艮为山 → 雷水解 → 山火贲

《梅花易数》论行人，比和曰“归期不日”；论谒见，同是比和，却讲“欢然相见”。一处说在外的人回来，一处说能不能见到。《谒见占》说欢然，也不能就写成失联者此刻心里欢喜，或一定愿意见哪一位亲友。今日家里问失联者要寻到哪里，先得认准这回用哪一问。辰月艮初六，寻获有机会。若人确实已经由可信近况核准身份及所在，家里可以照实说知道了下落，回不回来，后面仍是一件须据实际再问的事。

本卦两艮都是旺土，同气有力，却还要将中间和收尾照盘里看。体互震木在季土囚，仍来克上艮，力量较薄；原体制用互死坎较能办。末变下离火休，来生上艮，是最后核准本人时仍能有帮助。这份助力撑得起寻获的机会，不能将行人占的归期收来许给此人。若已有本人可信自报或其他见闻，确知他现在身在何处，直接照实际近况讲才对。

艮初六「艮其趾」，小象说未失正。守住所问的一件，所断也不混。若有人只说他肯给家里打电话，尚不知道眼下所在，照实说只是有通电话的意愿，尚不能据此报已经通话或已经找到。若早先正是要与他见面，后来从可靠消息知道本人何处，有人事先没想到会从这一途接到，也可以确认寻获，到哪时能当面见或真正回家，仍须听实际安排。

本艮参东北、山径及近山之处。去向若另有可靠见闻，照见闻核，不因现在还未归家而另找一处象位。有可信的紧迫险情，应及时据实求助。

火日从末离生艮来，参收尾核人核处有无实助。即便知道眼下在哪里，先前缘何失去联系也须据实，不能从“归期不日”替本人许一个见面日。

### 方位与寻找线索

本艮参东北、山径及近山地，已经确认本人实际所在便如实报告，不由起初所望的归处重定位置。

### 处境与安危倾向

若有可信紧迫险情应及时据实求助，不以等到本人归家或尚未当面见为由迟延。

### 失联原因参考

归、见与寻获各依其所问，不能从行人原书的归期话语替本人说明此前缘何失联。
