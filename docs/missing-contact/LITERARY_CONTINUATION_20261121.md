# 失联寻人后续逐批规则与文字审计

本页接续[长版精修总审计](LITERARY_AUDIT_20261121.md)，记录第4卦起实际完成的批次、全文复核发现和修订依据。完成数由最终作者回执、独立第二读者回执与源稿共同生成；正在撰写或尚未完成复核的稿件不计入。日期沿用本轮2026-11-21版本标识。

## 本轮共同口径

用户指定的[面试逐月稿](https://github.com/turnupmason/Wengua_Meihua/tree/editorial/interview-preview-216-20261118/docs/interview-pass/monthly-preview)与[关系确定逐月稿](../relationship-establishment/monthly-preview/README.md)作为厚度和表达参照。每篇按本用、体互、用互、变用及当令五态分别展开，正面条件、限制和爻辞的取舍要落入连续正文。正文四段单独统计，简断、应期和审计不能补足正文厚度；字数合格也不代替全文审读。

本问以指定失联者可确认的双向回应为联系恢复的标准。核实渠道、他人代转和本人回应分别记录；一次符合该标准的回应已经属于本问的实际进展，不额外要求关系长期稳定。恢复通信是对《梅花易数》[卷二人事占、求谋占](https://zh.wikisource.org/wiki/梅花易數/卷二)的现代事项类推，不移用行人、谒见或失物专法，不从卦爻推断失联者所在地、安危、年龄、心理或现实遭遇。

原体贯穿本互变，体互和用互分别与原体比较。月令轻重不改变生克方向：休、囚、死态的克仍是克，休态也不等于全无作用。比和是支持，不能用含混的“无生扶”把它抹去；确无相生时，须明确写“无直接生体”。不使用间接生克链、分数或人为权重补出盘中没有的帮助。

### 全文复核发现与修订

1. 九二春令旧简断将前段也并入比和。实际本用坎水受艮土体所克，故改为“中后段比和”，并重读该整篇，确认前中末的直接关系一致。
2. 九二、六三若干段原写“无生扶”，会使仍存在的坤土比和失去意义。逐篇改清为“无直接生体”；六三夏令规则审计中的同一歧义也在最后再次修正并整篇复读。
3. 六三若只笼统说金夫古注有异，读者仍无法知道正文采用哪条依据。相关段落明确王注刚夫与失守逐求之义，不据象编出现实人物。
4. 删除“此篇”“未增加生体”等审稿自指，改为直接说明可办之处、尚存限制和本人回应的关系。六四秋令不再借其他月份解释本篇；上九秋令标题改成自然的问询分寸表达。
5. 保留强体、弱克、比和及吉爻的正面作用，不为原偏难结果删除正证；也不把办得动、查得清写成已经接通。可能的代问、转述和记录均以条件情境说明，不冒称这些事已发生。

第二读者先读完30篇，包括简断、四段正文、规则审计和完整应期，再对19篇受改全文逐篇读回；六三夏令审计修字后又独立重读整篇。发布文风检查另将六五夏令改为直接说明求明态度与年龄无关，作者和第二读者再次读回该篇，合计20篇有修改后整篇复读记录。回执绑定最终源文件、cases、作者签收及三类历史基线，不能靠重新计算哈希代替阅读。
