## 初九动 · 寅月、卯月

前助可用，中途阻力仍难越过

地火明夷 → 雷水解 → 地山谦

简断

这次恢复联系偏难。开头可借到帮助，但你这边承接较弱，中途核实的阻力又较重，收尾虽能维持配合，仍未必接到本人答复。必要所问说简明，留好直接记录，不为解释暂时没有消息而猜测对方遭遇或态度。

开局：坤土体春死，本用离火春相而生体，开始有支援，可以补一些承办不足。若已有合适渠道，先将确知信息交代准确，未知背景不随请求扩散。

过程：体互震木春旺而克体，中段阻力较实；用互坎水春休，受体土所克，核实仍可着手，较弱土体办起来费力。能得到原始消息时，先核清来源，不急着用它解释所有疑问。

结局：初九“明夷于飞，垂其翼；君子于行，三日不食。有攸往，主人有言”说的是原处境中守义而行的艰难。变用艮土春死，与体比和，收尾仍可相接，但不足补旺木克弱土的缺口；相火本生虽有帮助，本轮仍倾向难接通。

总断：本轮偏难恢复，先守住有限的有效渠道。把必要内容说清、原始资料留完整，暂时查不到的照实记录，不为让解释完整而补出他人的经历。

地火明夷 → 雷水解 → 山火贲

简断

本轮恢复联系偏难。你这边承接较弱，中途核实压力较重，虽可借到支持，收尾仍要投入。先把每一条消息能证明什么记清，原记录之外的解释不要急着接上；帮助用于补证，未有本人回答时仍按未确认处理。

开局：冬死离火体对冬囚坤土本用，体生用，起初仍有耗费，承担核查较弱。必要所问先依直接记录，避免过多猜测改变最初内容。

过程：体互坎水冬旺而克体，核实较受限；用互震木冬相而生体，支持也较好。可以借助它追查原话与身份，但帮助有力仍不等于关键证据已经齐备。

结局：“不明晦；初登于天，后入于地”在原失则转晦中有明确警戒，不指现实所处天地。变用艮土冬囚而受体生，末后仍耗费；相木中助虽好，弱火承受旺水克又需前后投入，本轮仍难落实本人回复。

应期：此盘暂无有据的日期可列。

总断：仍以难恢复为主，已有协助先用来补直接依据。资料经过整理以后，保留原话与后来解释的区别，不拿解释更完整当成本人已表达更多。
