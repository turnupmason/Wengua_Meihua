# 失联寻人 · 余下 10 项现代适用争点复查

本次以上一轮留存分歧的 10 项为范围，基线为 cde05e18。先核夬上六秋、土月和蛊初六夏、土月。共核 44 篇对应断语、106 个月令键。

夬上六秋令、土令 2 篇调整为有条件接通。蛊初六夏令、土令 2 篇补《象》与孔疏的适用条件，仍取偏难。复上六按《周易正义》校正动爻句读，沿用同一卦爻全部十二月令键，原库文本照存。其余已复核的争点按原判或具体分歧记录。作者收束 5 项，另 5 项保留分歧。独立断法和独立取期审核仍待完成。

本次研判只涉及与指定失联者恢复可确认的双向联系。已有的正当渠道可用于核验，转达或配合的改善只能支持相应阶段。动态应期和既有未取期原因均沿用。夬上六秋、土虽有强比，尚无共同约定或其他可据的方法锁定一个具体日级事件，仍不补日期。

逐月令旺衰、关系和判断见[核对记录](../../sources/editorial/missing-contact/recheck/application-10-recheck.json)。改动前后和全文核读哈希见[作者修订记录](../../sources/editorial/missing-contact/recheck/application-10-edits.json)。

| --- | --- | --- |
| 泽天夬上六 | 修正判断 | 申酉 偏难 → 有条件、辰未戌丑 偏难 → 有条件。秋令乾、兑同旺，四季土月则同相。本用、两互和变用都与乾体直接比和，无直接克体，也没有直接生体。《求谋占》明列比和为利，《占卦诀》的「无生有克」条件在此不成立。王孔认为凶在孤阴势已尽，程颐释为其道不能再行，朱熹另分凶应于占者还是其敌。该伦理分配无现代对应，保留不宜在旧路尽头继续催逼的戒意。秋、土改为有条件接通，已有本人可直接收发的正当渠道才谈此机会。其余三组金囚、死、休，保留偏难。 |
| 山风蛊初六 | 原判断保留 | 王孔释《象》「意承考」为随事损益、有所沿用也有所改正，程颐重能担责且戒惧，朱熹重初蛊未深才易治。三者不同，均有可修的明确对象。巳午艮相能受两休木之克，兑、乾死而耗轻；四季土月艮旺承两囚木，兑、乾相，查证仍要投入。终吉用来判断旧记录或旧办法可以修到什么程度；本用仍克、两组末用都泄，能修正来路的证据只能支持核查，维持偏难。 |
| 风天小畜九二 | 原判断保留 | 王孔取九二往九五，程颐重二五同患相助，朱熹取九二与初九牵连。《象》共重得中、不自失，古注分歧不改变现代协作必须有确实内容这一点。春旺、冬相巽能承乾兑之弱克；中与末仍有离耗。实际有人能以原始记录帮助核对且沟通渠道合宜时可争取，原有两组有条件判法已涵盖。夏火旺耗、秋金强克、土月巽囚分别维持偏难。 |
| 地雷复上六 | 原判断保留 | 王孔把「以」释为用此迷复治国，程颐同指治理失道与久迷不改，朱熹释「以」为及。依王注连读「以其国君凶」，旧库文本保留。对本问可共取继续沿实已失准的路径难成。春旺、冬相震能克本互坤和末艮，可核查和纠正；它们仍属体克用的办理条件。另有新证可以另行核实，原盘无据先许回音，春冬仍偏难。 |
| 山雷颐六三 | 分歧保留 | 王孔以不正求养为谄，程颐重背离养道，朱熹认为既拂颐而虽正亦凶。夏、土早段震克较弱，中段坤比有力，后段旺离或休离都直接生艮，巳午尤其强。争点在后段若出现可验证的直接通道，能否作为另一路而不受拂颐限制。注疏未为这种转换给判准，故维持偏难并保留后助，尤其不把十年转为等待时限。 |
| 泽风大过九三 | 分歧保留 | 王孔重系心于一而不能救弱，程颐重过刚而不能取人以自辅，朱熹以刚过不能胜重。秋、土兑能制弱巽，两互乾均比，后用坎受体生，秋相耗较实而土死耗轻。能否解决结构上的薄弱处，取决于中途协助能否提供独立来源，而非同一说法被多转一次；原典没有特别说明轻耗可否承重，原两组偏难暂保留。 |
| 离为火九四 | 分歧保留 | 王孔重突进逼上而无应无承，程颐重失善继，朱熹重以刚迫后明。春离相、体互巽旺扶，末艮死所耗较轻；夏离旺而巽休仍生、末艮相耗较实。两组本用皆比，无直接克体，中助确实存在。是否已有合宜安排、是否会因骤然扩大而中断，关乎爻戒能否降为仅约束问法，已知资料不足以区分，保留偏难及两组的实助。 |
| 天山遁初六 | 分歧保留 | 王孔以落在后面、危至才进难免解释，程颐以晦藏可避，朱熹取静俟。《象》的「不往何灾」是止进避患的承接，不给相反的求成结论。秋令艮休生旺乾，土令艮旺生相乾，初助确有且中乾比和；末离囚、休皆仍克体。无从判定被禁之「往」只限新增接触，还是也约束已经展开的核验，古今条件保留，维持偏难。 |
| 艮为山九三 | 原判断保留 | 王孔说止在关节则上下不通，程颐强调固止一隅、行止失时，朱熹说过刚使上下判隔。夏相、土旺的本末比和是前后接得住材料；中间休震、囚震仍克，囚坎或死坎受艮制可办理，未出现直接生助。三家都把问题落在断处，故已查明的材料能接续仍不足以改变本次偏难，原两组核查事件仍成立。 |
| 雷火丰九三 | 分歧保留 | 王孔区分可守与不可用事，程颐以所应不足而失其所赖，朱熹取幡幔深蔽，虽不可用而本无咎。春、冬用互与末用两木相应，冬死离耗轻，但兑金体互仍克且全盘无直接生助。古文排除承办大事，也指出右肱所指的关键能力不足；一次回复是否能由未受阻的独立途径取得，原典不能定，保两组正证与原判。 |
