# 宠物走失：事项适用表与作者复核

版本：pet-search-modern-analogy-1.0.0。问项 search.pets.recovery，question_type lost_pet_recovery。本文是项目解释政策，不把现代类推冒充古书专门规定。只写指定宠物的寻找和安全接回倾向，不判断宠物生死、疾病、具体坐标、被盗或他人真实行为。作者核读与独立专业审核分别记录。

## 一、先核对原典，再选择占法

项目库《梅花易数》卷一至卷三逐章查阅与本事项相关的动物起卦、动物外应、体用、类象与克应。公共原典对照：
- [卷一：占动物、牛哀鸣占、鸡悲鸣占、形物占、八卦类象及万物属类](https://zh.wikisource.org/wiki/梅花易數/卷一)
- [卷二：体用总诀、人事占、求谋占、三要与十应](https://zh.wikisource.org/wiki/梅花易數/卷二)
- [卷三：体用互变、衰旺、克应与日应](https://zh.wikisource.org/wiki/梅花易數/卷三)

上述相关篇章没有可直接当成现代“走失宠物寻找并接回”统一规则的专项章。不能声称已经穷尽所有版本或典籍。

| 依据 | 原文与项目定位 | 本事项适用及限制 |
| --- | --- | --- |
| mh-070 求谋占第八 | user-meihua 549–551行：“占求谋，以体为主，用为所谋之事。” | 明示现代类推：体为主人可调动的查找条件，用为寻找并安全接回这一件事。不是把宠物当成静物，也不是以体推其健康。 |
| mh-070 | “体克用，谋虽可成，但成迟。” | 搜索行动可能逐渐接到结果，不能把“克”解释成制服宠物，更不能鼓励追赶、围堵或擅闯。 |
| mh-070 | “用克体，求谋不成，谋亦有害。” | 当前搜寻受制的反证，结合旺衰和完整爻意判倾向；不作宠物受伤或死亡证明。 |
| mh-070 | “用生体。不谋而成；体生用，多谋少遂。体用比和，求谋称意。” | 生扶或配合支持查找，耗泄可能指投入难接结果；原文“不谋而成”不用于劝主人停止找寻。比和不等于宠物没有离开、自动回来或已经被收容。 |
| mh-064 人事占第二 | user-meihua 520行起：“更详观互卦、变卦，以断吉凶；复究盛衰，以明休咎。” | 四条关系逐一对同一个原体，所有节点同一月令五态，不借动物取象更换体用。 |
| mh-117 体用互变之诀 | “用为占之即应，互为中间之应，变为事占之终应。” | 本用、体互、用互、变用分别用于开局、过程、收尾。变用不包办结论。 |
| mh-119 体用衰旺之诀 | user-meihua 803–805行：“内外并无生体，虽体之卦党多，皆是衰卦，终不吉也。” | 衰比和不是凭数量堆出的接回保证。旺体可以承接衰克，是否足以成事仍须回应动爻、前中后直接关系。 |
| mh-028 占动物 | user-meihua 117–119行：“凡占群物之动，不可起卦。”其后另列一物、来方、时数及初生置买起例。 | 原文有特定起卦条件，不假装现有年月日时盘已经观察到某只动物或其来方。 |
| mh-041、mh-042 牛哀鸣占、鸡悲鸣占 | user-meihua 171–178行 | 保存古案当时鸣声、来方、时刻和断案的整体语境，不能把屠宰等古案结果转移为现代宠物的命运。无新增古案反馈。 |
| mh-092 复明动物之应 | user-meihua 660–662行，列乾马、坤牛、艮狗等 | 只说明传统类别，不凭艮推断此问必为犬，其他卦也不改造主人已知的宠物种类。无实际外应输入时不编造叫声、遇见或动作。 |
| mh-048、mh-049、mh-051、mh-052 | 形物、验色及万物属类 | 按已知实景参看器物形状、材质、颜色及环境。形物、验色原本有“所见”条件，不据此猜宠物未知毛色、性别、体形。每个卦爻的实际选句与限制另存 cases/hex-NNN.json。 |
| mh-088、mh-091 | 地理及方卦之应 | 真实存在的地理环境和观察方位才可作条件性对照。无实际来方，不把多处经卦当成多条已验证移动路线。 |
| mh-077 失物占第十五 | “体用比和，物不失矣。”“又以变卦为失物之所在。” | 不作为宠物结果与定位规则。活体会自行移动，本入口不沿用失物章的原物收放、静置容器和“物不失”结论。 |

《易隐》六畜占、六壬与奇门六畜走失资料属于不同起卦与判断体系，不把其六亲、纳甲、宫门、神煞混入本项目经典体用盘。未取得适用依据的间接生克不启用。全部稿件不看旬空。

## 二、类象与现实搜索分层

每篇把卦理落在主人能够核实的行动：最后一次确见地点、时间、原始照片或影像、目击者实际看到的方向、现有登记及联系方式。线索不等于团聚，笼子、门、墙、树木等只在确实存在的现场参看。

宠物毛色、花纹、体形、项圈或脚环由实际照片和登记核对，不由卦象补造。金玉圆物、竹木长物、布帛方物、明窗、土石、缺器等是周边设施对照，不能说宠物自身是某种材质或已经在该物内。危险水边、道路、封闭空间由现场情况和专业协助处理，不鼓励擅入。

实用查找参考 [ASPCA Finding a Lost Pet](https://www.aspca.org/pet-care/general-pet-care/finding-lost-pet)：及时联系周边及收容机构，登记照片和可辨识细节，核对芯片登记联系方式（仅适用于实际植入并登记的宠物）。不是所有物种都能用同一接近和接回方式；无法安全接近时联系相应救助人员。文中条件性建议不冒充古书原话。

## 三、应期：先定阶段事件，再换算日期

取期证据为 mh-116 占卦诀、mh-122 占卜克应之诀及 mh-143 日应。原文分别定位“看卦中有生体之卦，则事应于生体卦气之日”“细观生体之卦为吉，应决期克体之卦为凶”“盖卦宜生体，宜比和；”“应之期远，则以年，近则以月，又近则以日也。”采用日尺度是对已经可以近期继续查证的阶段事件的明示现代类推，不声称古籍给出宠物统一通知期限。

每篇至多一个阶段事件、两天候选。支持或比和窗口写目击核实、登记对照或协同查找；克体窗口写联系、辨认或接近的具体阻滞，不写必有伤害、不利命运或确定失败日。过程事件与最终接回倾向分离。没有足以支持所选事件的节点和适用理由时，保存具体未取期原因，不凑数字。

库存储规则与支类，不存死公历日号。软件使用确定的当地起卦日期，先查该月剩余匹配日，没有再查下月，最多两日。历史盘沿用原起卦日，查看日不会滚动改期。文档示例日期只用于校读。无论窗口为何日，及时现实搜索都不延后。

## 四、单篇与批次检查

每篇保存本互变、完整真实动爻、体用及两互定位、月令五态、直接关系、主要正反证、结论、行文、取期事件与精确引文。原文中的无咎、悔、利见、终吉等有条件地解释，数字和动物意象不变成未提供的天数、物种、人数或遭遇。作者实际全文阅读后才能记 author-checked。独立专业与应期解释审查仍 pending，用户逐篇验收未完成。

固定阅读顺序：卦爻月令标识、标题、本卦→互卦→变卦、简断、开局、过程、结局、应期、总断、古籍依据、完整动爻、可折叠计算说明。动态上下文取实际月令与当地起卦日。不开额外 V5.0 精修轮，但初稿作者核读和去除重复照常完成。
