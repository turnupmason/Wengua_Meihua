这一例为什么也放上来：书里自己说，这一卦用克体，本该没有饮食，结果却有人相请，因为占的人当时身边有应，卦名「升」又有升阶入席之义。公式有算不到的地方，所以每一篇断语还要师傅读过。我们写断语时只依体用下结论，把「卦理另有一层」的情形交给审读的人把关。
