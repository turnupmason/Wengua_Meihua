## 按日查询无需填写时分

新增 `data/day-calendar.json`，预存2026-11-10至2028-11-09共731天，覆盖闰日。日期键必须包含年、月、日，前台可在月份标题下简称“14日”。

给定同一个 `YYYY-MM-DD`，不论用户在哪里都得到同一个日期键和干支日。手机自动提供当前本地公历日期即可，按日查表不必额外询问时分、城市或定位。这里没有把“同一瞬间各地日期相同”作为前提。

这层只做日期键到干支日的换算，不做时刻到本地日期的转换，也不决定子初/午夜换日、农历年月日或节气交接。若以后调用年月日时起卦或时辰应期，仍由对应历法接口处理原有时刻输入。

```js
import {getCivilDay,formatCivilDay,findCivilDayMatches} from './src/index.js';
getCivilDay('2026-11-14'); // 壬辰日
formatCivilDay('2026-11-14'); // 2026年11月14日（壬辰日）
findCivilDayMatches({startDate:'2026-11-11',endDate:'2026-11-22',branches:['申','酉']});
// 2026-11-18 丙申、2026-11-19 丁酉；selectedAsEventDate:false
```

缓存及纯JS日期算法已用 `lunar_python 1.4.9`、`sxtwl 2.0.7`逐日交叉核对731天，差异为0。证明记录在 `sources/audit/day-calendar-verification-20261110.json`。两个外部库只作校核，不进入移动端运行依赖。默认离线构建不联网，不需要安装它们。

`npm run build:calendar`重建相同缓存。需要复核时，可另行安装上述固定版本，再运行 `python scripts/verify-day-calendar.py`。更新缓存区间后应重新执行独立核对，不能沿用旧记录冒充新日期已校验。

查出未来两年所有申酉日，不等于原书已确认本事就在每一个申酉日应验。每次只展开所问范围；既定应事、吉凶、方法与是否已经选定轮次仍由应期模块保存。

## 六个位置全部展示，一个原体贯穿

按《体用互变之诀》，本卦定原体，用、互、变围绕原体论；互卦分体互、用互，“体互最紧，用互次之”。单动爻的变卦静止经卦承继原体，不能另立一个自己。

新增 `buildFullChartRelations(reading)`，也可读取 `getStory().fullChart`：

- 六个可见经卦位置都有角色、五行、月令与空亡。
- 15组位置间的五行关系完整列出；原体在变卦中的重复出现有同一身份标记，不自造新的独立能量权重。
- 补充“制克体者”的路径及连续生扶路径。例如井九五：离火制兑金，兑金克巽木；另有兑金生坎水、坎水生巽木。
- 路径保留双方旺衰和空亡，不能因图上存在离克兑，就认定离火已经有效护体。
- 同一原体的旬空评估贯穿变卦，不把原体真空悄悄换成另一个已恢复的体。

《体用动静之诀》称本用与变卦为动象，这和“只有本卦本次动爻持续发光”不是同一个层次。把动象接入用户旬空扩展时，仍须明确适用口径，不能把视觉上没有第二次动爻直接解释为变用静止。

这些是可核对的关系与条件，**不是已经发明出一个总能量分数或唯一完整决策公式**。现有总断器仍属此前编者口径；最近十篇口吻现已获准，重写1,920篇时逐盘核对关系与原文。新增接口给下一轮详写提供依据，月令、空亡、阶段与领域仍须进入判断。

## 应事日期与行动候选日分开

原书生体、比和吉期可支持有利时段的判断，但“某事可能在此期显现”与“安排在这天做就会成功”不能互换。产品可另给基于本盘的行动建议，明确是编写的实用提示，不冒充原文逐字断语，也不提供虚构成功率。

- 全盘支持成事：在生扶较好的候选日提示利商谈、约见、提交或催办，具体动作用所问领域限定。
- 全盘可成但夹克：列有利推进的候选日，也列阻力容易显现的日子；凶期写明本事应注意的争执、耗费或落实受阻，并给缓办、核条件等建议。
- 全盘不成或真空：提示先改变实质条件、收住不必要投入；不许承诺换个日期就改成。

每个候选日期还须核对其与原盘的生克、填冲及适用前提；两年表只存日期事实，不预先把所有申日涂成凶日。现有查询接口列事实和关系，尚不代替这一步完整的逐期判断。

“凶”只针对本次事项，不扩写成当天所有事情都不能做。出现克体的支期，也不能越过全盘生扶和月令，就宣告一定重大损失。

## 展示示例

以下是明确指定的演示盘，不冒充原书已发生案例：2026-11-10，冬水当令，戊子日；问近期生意求财；水风井九五动，互火泽睽、变地风升。按日查询范围为2026-11-11至11-22，仅用于展示日期候选的格式。

| 位置 | 经卦 | 需要说明的作用 |
| --- | --- | --- |
| 本体 | 巽木 | 得月水、日水及本用坎水生扶。 |
| 本用 | 坎水 | 冬令旺，生原体。 |
| 体互 | 兑金 | 克巽木，仍有中途牵制。 |
| 用互 | 离火 | 木生火为耗；离火又能制兑，但冬弱、静空，眼下制金帮助有限。 |
| 变卦承原体 | 巽木 | 原体延续，保持同一主体。 |
| 变用 | 坤土 | 木克土，求财有可求之财；仅部分逢空，不全抹去作用。 |

在这一查询范围，土日为11月11、14、17、20日；水日为11月21、22日；金日为11月18、19日。可分别呈现求财有利、得助有利、受阻风险的候选窗口，并写清所应之事与行动建议。该列表没有自动挑定其中一天为必然收款日。
