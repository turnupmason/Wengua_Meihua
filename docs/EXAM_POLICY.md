# 考试选拔断语的取义和复核

## 本次考试能通过吗

`career.exams.exam` 对应 `examination_result`，回答所问这场考试是否达到合格要求。资格证的审核发证、岗位竞聘的名额、其他选拔的入选各按原有入口查取。成绩、合格线、名次及公布时间以实际考试信息为准。

| 核对事项 | 原典和采用范围 |
| --- | --- |
| 确定所求 | 《梅花易数·求名占》mh-071 以体为人、用为名。以本次考试的合格结果作现代类推，原体为应试者，本用为这次考试。参看《人事占》mh-064 所述互、变与盛衰，分辨备考、实际作答与末段能否交出完整答卷。 |
| 本互变 | 《体用总诀》mh-061、《体用互变之诀》mh-117 以同一个原体对看本用、体互、用互和变用。能答出熟悉部分、答题手续顺、达到合格要求是三个不同层面的事实。 |
| 旺衰与反证 | 《体用衰旺之诀》mh-119 结合月令辨承受能力。《占卦诀》mh-116 的有克无生为求取受阻的反证。原体有力可承压力时，仍须看起步关系、两互和爻意能否支持合格。项目统一使用五态表，乾、坤取中四爻互卦。 |
| 动爻 | 《占卜总决》mh-056 要求察动爻。《周易》经、象与传统注疏用于核原文和爻义。「无咎」按其条件解释；答题建议是现代用例。 |
| 取期 | 《求名占》mh-071 以生体卦气看名成；无克才有参原体时序的条件。《占卜克应之诀》mh-122 区分远近，和《先天后天论》mh-058 一并核适用尺度。阶段协作、直接阻力、额外投入另参 mh-116、mh-122、mh-143。每篇至多一个事件窗口，近期开考或近期已有对应安排才参照。正式考试与公布日期依主办方安排。 |
| 公历与显示 | 按实际当地起卦日匹配，先本月余日、无匹配再查下月，保留每事件至多两个候选日。历史记录以原起卦日为准。阅读文档用固定示例，应用取实时字段。 |

## 逐卦记录

### 乾为天

初九以「潜龙勿用」取未可遽进；九二取已能表现并可就正；九三兼顾戒惕、危与无咎；九四依《小象》与《文言》取进退自试、进可无咎；九五取能用所长，仍须看末段的实际限制；上九的悔来自过高而不知退，具体检查答题有没有扩大范围或为了难题失掉已经能做的题。两互皆乾，和本用分别对原体。初九、九四同样变巽，初九以时未到为主，九四依具体承接力区分试而可进与试而尚难。九二、九五变离克乾，秋金与土令的前、中段承接和春夏衰金的末段压力有别。题型、评分和是否有复核均依实际安排。[《周易正义·乾》](https://zh.wikisource.org/wiki/周易正義/01乾)
