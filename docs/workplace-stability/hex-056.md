## 初六动 · 寅月、卯月

琐事缠身的外派

火山旅 → 泽风大过 → 离为火

简断

外派到分点这一阵，起头事情不多，中途也有一份现成的资源可用，岗位不受影响；隐患在你被一堆琐碎的报销、考勤纠纷缠住，越理越乱，耗掉的是本该用在正事上的心思。

开局：你被派到外地的分点驻一段时间，起头的工作量不大，主要是熟悉当地的流程。

过程：中途总部给分点配了一套现成的业务模板，你照着用，几项正事推得顺。

结局：可后面一堆零碎事缠上来：报销单据不全、考勤和总部对不上、几笔小账来回扯，你一件件去争，正事反被拖慢。「旅琐琐，斯其所取灾」，在外头为琐碎的事纠缠，灾是自己招来的；小象「志穷灾也」，心思被小事占满，才是麻烦的根子。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，总部给分点配来一套业务模板，属吉应。模板到手，先把最常办的三项业务套进去。

总断：隐患在被琐碎小事缠住，耗的是自己的心思；岗位不动。报销和考勤按规定办，争不清的交给财务，不再自己扯。

起头往外掏，末了照旧

火山旅 → 泽风大过 → 离为火

简断

起头你被抽去帮一个临时项目跑腿，投进去的工夫不少，又被一些鸡毛蒜皮的事牵着，变数就在这两处。你自己底子足，到收尾分工一样没变，位置在，只是别在小事上较劲。

开局：部门临时组建一个项目组，借你过去跑前期的手续，起头几周大半工时花在那边。

过程：随后项目组里分工不清，谁来订会议室、谁去盖章，琐事一件件落到你头上。

结局：借调期满回到原岗，分工一样没变。「旅琐琐，斯其所取灾」，做客在外还计较琐细，灾是自己找的；小象「志穷灾也」，心思别耗在订会议室这种事上。

应期：以下为传统推算的参考窗口。

总断：变数在起头那次借调和缠上来的琐事；位置照旧。借调的工时记清楚，琐事按分工推回去。

## 初六动 · 申月、酉月

活又重又碎

火山旅 → 泽风大过 → 离为火

简断

活又重又碎，这阵子不算稳：一大摊难缠的对账压在中段，你底子虚，应付得吃力，偏偏还有一堆零碎手续要你亲自跑。岗位没被碰到，耗的是工夫和心思。

开局：外地有个项目缺人，派你去支援，起头的事不多，几份手续按部就班办了。

过程：随后，对账量最大，几家供应商的单据格式各异，你一笔笔对，费力又费时，帮衬只有一份残缺的旧表。

结局：后面零碎事更多，跑签字、补发票、催回执，你样样亲自上。「旅琐琐」，出门在外被琐碎缠住；「斯其所取灾」，小象「志穷灾也」，琐事交给流程，别让它们把心思全占了。

应期：此盘暂无有据的日期可列。

总断：活重又碎，这一程不算稳，岗位没动。对账按供应商分批，零碎手续能走线上的走线上。
