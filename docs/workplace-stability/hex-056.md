## 初六动 · 寅月、卯月

有人能帮着续，别让零碎工作占住岗位

火山旅 → 泽风大过 → 离为火

简断

手边条件还能把当前的事办下去，中途也有实际援助。若手上的工作大多是零散补位，先和负责人定出一项可持续的职责，免得每天忙却交不出完整成果。岗位暂可守，关键在把精力集中到有承接的工作。

开局：相离体生死艮本用，早段零散投入尚轻，原体有能力办理。

过程：囚兑体互受相离克，过程难处好处理；旺巽用互生离，能够取得实用帮助。

结局：初六旅琐琐，失其所安而陷于琐劳。末相离与体比和，后段可接续，先把零散事务理成实际职责较利稳岗。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，中途获得可用于建立实质职责的协助，属吉应。近期若正在协调临时工作，较容易拿到可用资源或答复，宜据此确定一份可交成果。

总断：现职暂可守。用已有帮助定下一项从头到尾能负责的工作，其他杂项按分工交回。

古籍依据：《周易·火山旅》《梅花易数·占卜总决》《梅花易数·人事占第二》《梅花易数·求名占第九》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。

手上的基础够用，杂事太多会妨碍原岗位稳定

火山旅 → 泽风大过 → 离为火

简断

开头就可能有些零碎事务要处理，手边有能力做，问题是做得越多越容易失去重点。先核实哪一项属于正式职责，其他的逐一交回。后段可按原分工继续，现职有维持余地。

开局：旺离体生相艮本用，前段事务所需投入较实，原体能承。

总断：岗位暂可维持。把零散请求归到实际负责人手里，留够时间做好最能验收的一项职责。

## 初六动 · 申月、酉月

小事做了不少，现有条件仍难撑住原岗位

火山旅 → 泽风大过 → 离为火

简断

眼下有些工作一直需要补，却没形成清楚的分工，真正难办的一项又缺少条件。把已经做完的部分先交给能验收的人，再问哪些琐事可以停。现职有收缩风险，后续接续偏薄。

应期：此盘暂无有据的日期可列。

总断：现职风险偏高。先确认哪件事是必须交的职责，长期无归属的杂项请负责人重新安排。
