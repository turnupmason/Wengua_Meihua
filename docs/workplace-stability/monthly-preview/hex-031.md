## 初六动 · 寅月

会上两三回提到梳理职能，季末真的来查这条线

泽山咸 → 天风姤 → 泽火革

开春例会几次提起要重梳各条线的职能，到了季末专项审查真来，岗位风险大。前面的话断断续续说过两三回，没有见到后续安排，你也就照常接手新的需求。那阵子新事一件跟一件，自己管得吃力，老客户这边又冷了些，手里的旧记录能用，业务上的助力很少。

审查进来很快，问的又是这块业务花了多少、做出了什么、有没有继续留着的必要。宜提前把每月投入和产出的账排好，不能一上来报一个总数，底下是哪几件做出来的却说不清。可以压到一页，写清当时用了哪些资源、换来了哪些实际结果，再给仍要保留的工作留一两条可以查的依据。

上兑金为体，下艮土为本用，艮土生兑。互卦天风姤，下互巽木受兑所克，上互乾金和兑比和。下艮初爻动成离，变泽火革，离火到尾段克兑。寅月兑乾囚、艮死、巽旺、离相，开头生体薄，手里管新需求已费力，变离又得巽生，最后来查的压力实在。

初六「咸其拇」，小象说「志在外也」，最早的感觉像足趾先动一下，还未走出去。放在这阵子，会上反复提过的几句话就是先露出的苗头。宜在准备审查材料时把当时所说的业务职能和手上真正做过的事放在一起，哪里已经能用结果回答，哪里还得再查，早点过一遍。

尾段逢巳、午日，可旁参专项审查实际进场。宜把逐月账压在一页，同业务确实被用到的地方放在一起。结论看实际审查结果，手里先准备好回答哪项值得继续、为什么有这一块工作，避免临到被问才把几个月的材料拼在一起。

## 初六动 · 卯月

先前只是提过职能调整，季末审查直接问业务去留

泽山咸 → 天风姤 → 泽火革

几次例会把职能重整提到桌上，真正到季末查这块值不值得留时，卯月岗位风险大。开春听了两三回也没说要动哪一条线，手里正有几项新需求往下推，你当作一时的风声。老客户那边这阵子也清淡，本来想用他们现成的业务撑一段，真正能接上的不多。

「咸其拇」，小象说「志在外也」。最初只有一点动静，等正式问话，才发现相应的事已从几句建议转成对这条线的审查。宜从每月做了什么、剩下还有谁在用着手，能对上原件的那几项先列成实际结果，遇到需要说明的空处尽快问清。开春听到的说法也按照实际通知重新核一次。

尾段巳、午日附近，可旁参专项审查何时实际进到本岗。宜把投入与产出照月份排好，届时拿一页能说清两个数字如何对应。最后是否保留依部门实际决定，手里准备的是能回答认真追问的记录和继续做这块业务的具体缘由。

## 初六动 · 辰月

开头的续约托得住，尾段一项旧审批程序要换

泽山咸 → 天风姤 → 泽火革

老客户开头续了约，进账也稳，后来部门发文要改一道沿用多年的旧例，工作有隐患。季度里新派到手的几件规模小，多是上次办过的，你沿相同的分工接下去也有着落。到收尾看通知，原来这块业务要过的审批有一步开始改了，今后提交的顺序得重排。

## 六二动 · 子月

年底事挤在一处，不妨就按已经熟悉的步骤继续

泽山咸 → 天风姤 → 泽风大过

排期上的几项都赶在年末，资料偏又不好借，现有工作仍稳得住。你手里的做事顺序前些天就排过一遍，哪一处原是要别人给个确认，得等到回声才继续。这样慢下来，有时便想换一个轻一点的位置，自己实际已经把几块理到大半，还有能够交出去的东西。

宜拿当前任务一项一项看，已经有办法办完的给它留足工夫，先别想着一换岗位日程就轻松。哪份事少一段资料，先写出现在真正经手的人以及需要他说清楚的条件。问清以后从下一步接着做，把当前不依赖这份东西的常规工作也照原先安排完成。

这卦上兑金是体，下艮土为本用，艮土生兑。天风姤为互，下巽木受兑所克，上乾金与兑比和。下艮中爻动变巽，成泽风大过，变用巽木也受兑克。子月兑乾休、艮囚、两巽相，体力薄，末段要管的量重，虽费工，盘面无克体。

六二说「咸其腓，凶；居吉」，小象「虽凶居吉，顺不害也」。眼下的担子有点重，变大过又有梁上承重之意，先让自己留在熟悉的分工里，能用上之前经手的东西。宜把已经走明白的那些一项项收好，后来再有人问起怎么做，也有自己的实际记录可看。

这股忙碌要按整段工作实际办理来衡量。宜每送出一项便在原来的计划上改一次，下一步该找谁也写明白。事情多，先照现有排期处理即可，仍然要等资料的继续问。若某件较重可以分成两段交，宜先问接手人需要哪部分，原来能按期交的也照常做。

## 六二动 · 丑月

订单能支撑原来的工作，别为新项目把手上的放下

泽山咸 → 天风姤 → 泽风大过

老客户的量稳，这阵子账上一直有实在进项，丑月工作稳得住。平日已经知道本岗要办什么，几样新分的也不重，按已有的材料交就能继续。有人见你时间上还有一点空，建议你去争一个更显眼的项目，真要接，就得先把几件在手的老业务挪开。

宜把接到的订单同日常交付放在一起，看看哪项承诺下一处已经等着，哪一份新任务照旧方法当天便可处理。正在往下办的先按本来的约定做清楚，其余还没轮到的写好先后。这样以后谁问为什么这月还做得稳，可以从实际交件、到账和各方的确认去核。

卦里上兑金为体，下艮土是本用，艮能生兑。互卦天风姤，下巽木为兑所克，上乾金和兑比和。下艮二爻成巽，变泽风大过，变用巽也受兑克。丑月兑乾相、艮旺、两巽囚，助力有些折损，现有业务仍能支撑，盘里并无克体。

六二「咸其腓，凶；居吉」，越想临时往新处走，越需要先看看脚下原有的工作是否已经交清。宜先守着自己办熟的那一段，老客户本来继续下单，排好的几项照原来的先后做。季末碰到盘点，真正完成的东西和合同约定对得上，也能说明这格已有贡献。

开局的辰、戌、丑、未日可旁参老客户究竟什么时候正常下单。宜将订单按月份逐项汇在一页，实际已有进项也记得清。季末直接照这一页去对，以现时要办的交付为先，旁的项目按自己手上的进度缓着看。宜让接手的几处都知道哪些会按原样交，不因听说有个显眼的项目就先改变已经答应的事情。
