## 初九动 · 寅月

本职原本按时交，末段去支援后渐渐顾不过来

水天需 → 火泽睽 → 水风井

原来的工作交得稳，后面去支援新业务，自己的交付开始没人照看，这份工作有隐患。临时帮几天时，同事还能替你接一下。等新业务的量上来，原本临时去的人留成了常驻，旧工作还会按原来的分工来找你。宜在去之前讲明白，手头正在做的几件由谁接、支援多久再作安排。

寅月上坎为体，水休。开局本用乾金和中段用互兑金都能生坎，原有资料、流程与对接人就是可用的支持。春月金弱，又受互离火牵制，能替你腾出的工夫有限。中间一桩协调虽然费事，按已有的关系还是能理下来，工作没在那一块卡住。

「需于郊，利用恒，无咎」，古注说事情离险处还远，宜循常等待。放到这里，手里熟悉的事可以照原分工干。新业务刚铺开，看不清每天会进多少工作，宜先问哪部分确实需要你一直在，哪些有原经手人可以接。知道临时支援是怎样一回事，才好安排原岗位的交付。

下乾变巽，得水风井。寅月巽木旺，由坎水所生，最大的耗费在尾段。原来的同事若只答应暂时看一下，支援一长，他也不一定能长期接。全盘没有克体的地方，所以眼下看的是一人分在两头以后，原来那条工作还有没有人负责，不能光拿新业务的忙碌当本职进展。

宜把已有成果和下一次交付交给实际接手的人，请他确认自己能接到哪一步。支援的范围、预定结束时间和回原分工的安排，也一并和定分工的人说实。到了约定的时间，先看原岗位哪项交付要恢复，再问增派的任务是否需要另外安排人手。

## 初九动 · 卯月

临时支援变成长驻，原来那摊活还在等你

水天需 → 火泽睽 → 水风井

一开始说的是支援，后来新业务人手一紧，你的日常也得跟着换，这份工作有隐患。旧对接方平常知道找谁办，抽调之后如果还是来找你，你手里就是两头各有件要交。宜从原岗位已经约定的工作查起，看看最长能离开多久，哪几样需要明确交到另一个人手上。

卯月上坎水休，开局下乾和中段的兑金原有生水之力，本月都弱，又受离火制。原有同事还有配合，前头按常规能做成，中途多方协调也有门路。只是大家手里也有自己的事，能够替你看住几天的工作，延长以后还要另问。

初九说「利用恒，无咎」。小象的「未失常也」是还守着原来的常道。工作里原先哪项一直由你确认，宜在抽出时间前记清楚。比如同事只能帮忙收材料，决定怎样处理仍要找本来的经手人，这一条就要在交接时说明，免得两头都觉得对方已经有了安排。

到水风井，下变巽木在卯月旺，受上坎所生，收尾一段有实在的工夫被抽去。盘里没有直接克坎，麻烦就在新业务越做越多，原来的交付跟着松下来。有时支援的是同一项业务，开始只帮着铺开，后来连日常维护也追到你这里，宜请实际负责的人早点确认这样的变化。

支援前，和原接收人核一遍最近真会用到什么，挑出能完整移交的先交。也宜约好何时评估支援安排，到了那天问清还有多少是新业务的日常需求。原岗位若仍需要你回来接，等负责人确认后，把自己应继续的那几项重新排上，而期限以实际沟通为准。

## 初九动 · 辰月

几件都得从头做，最后两样小活反而来不及收

水天需 → 火泽睽 → 水风井

同时要交几件，手边有模板却还得自己改，忙到收尾有两个小项空着，这份工作有隐患。每件事照平常的步骤做，开头都能找到办法。到了最后，单项收尾不算大，合在一起就过了手上能撑的工夫。宜早点让等这两项的人知道进度，免得他照原来的顺序等着接。

辰月上坎水弱。下乾金和中段的用互兑金原本能生坎，金在土月相，受互离火牵制后，支持有用却不全。拿到一份现成模板便是这样，版式和几项资料可以沿用，具体按这次怎么交却还要自己处理。宜先问原来用过的人，这次多出来的部分由谁确认。旧模板填过的事如果和这次不同，就把那处条件也记下来。

「需于郊，利用恒，无咎」讲离险尚远，保守日常才不生过错。同行已经办通的办法可以照用，自己做这回的活也不能少了必要的核对。你按步骤走，其实没有因为求快把事情做错。真正得看的是每样手头要用多少工夫，有没有给临尾两件都留出来。

下乾变巽，成水风井，巽木在辰月弱，由坎水生，末段还得出一点力。没有直接克坎，晚交的缘由多在前面每项都要从头做，轮到两件小事时，手里已经没有合用的时间。若接收者只急用其中一项，宜先把那一项做完整，另一项另约合适的进度。

模板刚到时，可以先标出用现成内容的地方，再把要另改的几处单独列出来。交付临近，和两件小事的接收人讲清哪一处仍要补、谁可以先拿目前成果准备。宜把更新后的期限写进实际的分工安排，避免两件都留到最后靠别人来催。

## 初九动 · 巳月

多方协调迟迟没收口，后面的小差事也接不动

水天需 → 火泽睽 → 水风井

本来照日常的做法就能维持，一件多方协调的事却拖了好几周，后面新派的小事也腾不出手，这份工作有隐患。大家此前各有自己的安排，你每谈完一方，还要回去问另一方接受到哪里。事情有进展却一直没说怎样算谈完，自己的日常工夫就被一点点用掉。

巳月上坎水弱，开头下乾与中途用互兑本有生坎的关系，这时两金很弱，对接的人也只能搭把手。难处落在体互离火旺，坎水要去制它，实际是中间那件事需要你一处处协调。宜看看还有哪一项离了你的答复就不能继续，其他问题可以交还给有权限的人各自确认，问清答复是直接给你，还是送给下一位经手人。

## 初九动 · 子月

新任务不断往里添，旧工作已经多等了一轮

水天需 → 火泽睽 → 水风井

开始只接了一件不大的事，后来又添几项相关的工作，原来有人等的交付被推后，这份工作有隐患。你还有办法做，只是每次把新要求接下来，就又占了旧工作原先留着的几天。宜让真正排活的人同时看两边，确认这次要完成到哪里。

子月上坎水旺，新旧任务都有能力做出结果。开头乾金和中间用互兑金有生体关系，在冬月力轻，合得上分工时有人帮，最终仍得把能用的工夫按实际算。体互离火弱，中途即使要协调一处也不费太多，真正变重的是接连加进来的后段工作。

「利用恒，无咎」有守常才能免过的意思。回到眼前，看看原分工里哪份交付已经有人照它排了后面的事。可以先问对方这次非等不可的是哪件，保证那件有人办。末段新任务一环接一环，宜在能给对方使用的节点先确认收下，余下的另约。

变到水风井，尾巽在子月相，由旺坎来生，做得下去也确实费时。全盘没有直接克体，问题在一项原本小的活失了边界。若只顾着不断答应，最后谁都以为你能及时交，两个接收人反而都没得到完整的东西。

和派新活的人说明目前实际已经做到哪一步，先让对方认领能用的一段。新增的几件整理到另一份安排里，由负责人核定范围、实际人手和交付人。原岗位要交给谁、什么时间要，都另外排清楚。已经推迟过的那一项向接收人说清目前还能做到哪一步。做完一项就交给接收者，别再等所有附加工作一起才收口。

## 初九动 · 丑月

几件事情都得按常规从头走，手里只有一份还需要改的模板，末尾两个小项眼看交不齐，这份工作有隐患。日常做法没有问题，就是同一轮要处理的地方多，谁都在等各自那一份。宜趁两件小事还没互相挤，把各自真的需要什么时候交问清。

丑月上坎水弱，开头的乾金和过程里的用互兑金能生坎，在土月相，却同时受互离火制。就像模板拿来能省去开头的安排，遇见这次独有的几处仍要找经手人确认。预计工夫时，把要现场查的地方算进去，别照已经做熟的那几次来估。同事若能提供旧材料，也要提前问他什么时候拿得到。
