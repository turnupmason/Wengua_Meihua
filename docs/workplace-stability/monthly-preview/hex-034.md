## 初九动 · 寅月

三道新规接着来，先拿新流程做出可以核的交付

雷天大壮 → 泽天夬 → 雷风恒

新管理层到任不久，报销和采购各加一道签字，周报换了样式，紧接着还要各岗重写职责和产出，岗位风险大。单看这些要求并不重，手头业务也仍做得顺。原来送上去的一笔被退回，职责表又被要求补了两回，三道都出自同一处，合起来是在重新看你手上的工作。

宜从眼下退回的单子入手，弄清报销和采购后来各由谁签、新模板的数字具体从哪份记录取。岗位表上已有的工作写实，已交的附上使用或接收的时间。还没有到交期的一笔说清经手人和当前进度，免得补了两回以后又有人把正在做的一项当成已经交完。三种新要求要是同时落在同一单上，也把先后问准，避免补过审批后还用没有更新过的数去填周报。

上震木为体，下乾金为本用，乾金克震。互为泽天夬，上兑金是体互，下乾金是用互，均克震。下乾初爻动成巽，变雷风恒，巽木与震比和。寅月震巽旺，两乾与兑皆囚，单处克轻，三金同属用党，且无生体。尾段巽比和，仍按眼下的职责经手。

初九「壮于趾，征凶」，脚尖使劲往前抢，原有的一步还没踩实，新规这里便容易吃亏。宜先照刚落地的流程把真实交付做出来，再从那些经手过的步骤判断有什么应当改。分工表仍挂你的名，也注着待梳理再定，暂时先照这份做，不抢着另提一套分工。

寅、卯日可旁参末段分工表出来，原来的职责暂时仍由你管。宜据新的签字、报表和职责要求重写一份实际经手的流程，把核过的记录按使用日期归档。等梳理落定再提交改进想法，已经有的成品和对应记录正可以说明本岗怎样继续。

雷天大壮 → 泽天夬 → 雷风恒

本卦上震木为体，下乾金为本用，乾金克震。互卦泽天夬，上兑金为体互，下乾金为用互，也克震。下乾初爻变阴成巽，得雷风恒，末用巽与震比和。卯月震巽旺、两乾和兑囚，三处约束各轻，用党多、无生体，尾段尚能续原责。

「壮于趾，征凶」，这里取一上来就急着改。新规都是同一处陆续给的，岗位还在梳理时，宜先按要求办出实绩。爻辞「有孚」落在能拿出来核的凭据，手头有办法可以改的先用实际记录记着，等分工真正落定后再核要从哪条程序提。

尾段逢寅、卯日，可旁参分工表确定目前仍由你经手原来的一摊。宜趁还做着的时候把现有规程按新签核和填报要求重写一遍，留好前后用过的版本。这样有人再问岗位产出，也可以沿实际材料说明哪件已经办完、哪件是照新流程刚接上。

## 初九动 · 巳月

预算、人头、评审一关接一关，先用到手的经费做出成品

雷天大壮 → 泽天夬 → 雷风恒

可留意本月11、14号前后，尾段暂停的业务恢复实际运行，按新标准由本岗经手，属吉应。执行头几周按周给出实际运行记录。

<summary>卦理与出处</summary>

判断：这份工作稳得住。本用震木受体所克；体互乾金与体比和；用互兑金与体比和；变用坤土生体。

旺衰：丑月，体卦乾金相；本用震木囚；体互乾金相；用互兑金相；变用坤土旺。

间接作用：按本库所取的一层作用解释，变用坤土：生体受制而薄。上列月令五态保持原值，不作连环累计。

爻辞：九四「贞吉，悔亡；藩决不羸，壮于大舆之輹。」；象曰「“藩决不羸”，尚往也。」。

专业说明：体乾金克本用震木，体互乾金、用互兑金与体比和，变用坤土生体，全盘无克体之卦。《占卦诀》「无克体之卦，则吉事必可成就矣」（792 行）。辰戌丑未月乾金相，体有力，本用震木囚，制之有余；变坤本旺，受震木所克而无火生之，《体用》「彼灭其吉」（682 行），后段之助不如表面足，体有力仍接得住，定为稳。九四「藩决不羸」同向。

取期依据：丑月旺坤变用生相乾，辰、戌、丑、未日旁参末段实助。
