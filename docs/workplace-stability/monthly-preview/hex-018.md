## 初六动 · 寅月

交接单写着正常，头一周就有两笔对不上

山风蛊 → 雷泽归妹 → 山天大畜

接手后头一周就有两笔往来款查不平，这份工作风险大。交接单写着运行正常，手里的任务也已经换成你的名字，偏偏那两笔款得从前任经手的记录往回找。谁在什么时候凭哪张单子入账，接手时没人说清，几份报表已经照旧交出，现在也要重做。手边先把曾经引用这两笔的表找齐，免得补了一张，另一张仍按旧数往下传。

寅月的艮土在死地，接在手里的底子本来就薄。开头的巽木和中间的震木都当令来克艮，正合账没查明、日常也有人催的处境。兑、乾两处金可以牵制木，盘里又无水助木，查着查着总能解开一两处；艮土仍要生金，本身得不到生扶，新活能排进去的时间就少了。

初六「干父之蛊」，说的是把前面留下的事接过来整治。小象说「意承考也」，这里可以从接住原来的业务、照着实情补漏洞来理解。修掉一处，交付就恢复一处，可是要把前任的凭证和你补的材料分开留底，免得下次翻账时只认最后的经手人。

几份报表退回来重做，占去大半工夫，原来答应何时交的新活也会往后挪。「厉终吉」的好处落到已经对平的账上，这部分能向主管交代你做过什么。剩下几笔要继续追单，谁出具原始记录、要等多久，当下还得逐项问清。

宜趁第一轮对账就把金额、入账时间、发现日期和所缺单据列进去，请负责人签认哪些在交接前就已存在。能补的项目写明用了什么依据，仍缺凭证的留在交接记录原处。以后谁来问进度，翻这一张表就能看出你的工夫用在哪里。

## 初六动 · 卯月

旧账挤掉了新活，进度问到你头上

山风蛊 → 雷泽归妹 → 山天大畜

旧项目占掉大半时间，新交付偏偏已经报了期限，现职风险大。交接时看到的是一张写着运行正常的单子，等头一周对账，才有两笔往来款从里面露出来。单据得问原经手人要，报表又引用过这几个数字，改掉眼前一行，还要顺着往后翻。拿走过相关汇总的同事，也要知道哪一份正在重做。

上艮土是你眼下能守住的岗位和工夫，在卯月处死地。下巽木先克，互卦中震木接着施克，两处木都旺，追完一件常又带出一件。归妹互中的兑金与变出来的乾金对木有牵制，能让几项核查走通，但这两处也要艮土来生，手边始终少一股真正帮你补工夫的力量。

「干父之蛊」放在这次移交里，说的是眼前的活要接着做，前面存下的问题也要一项项修。比如一张单据迟到，能翻出双方当时的记录，报表便有机会重做。还有些账只查到以前的一条录入，要等原件到手才能确认。追单据的人可以先说清旧档是否还在、由谁去调。「厉终吉」只能先从理清的部分看。

中途若被催新交付，最好能直接拿出改过的几张表，说明这段时间为何不能照原排期。现在开始把每一项核对所需的人、材料及预计回信时间记下来，便知道哪些能先办，哪些一直占着日常处理的时段，拖下去会挤到下一轮考评。

宜把两笔款从发现到补单据的记录列在一起，也留下交接前的原账，哪几处修好了当周让人确认。仍在等材料的交给明确的人去追，请主管在问题单上签认起点和分工。下一次查到报表，依据能分得清，前任和现在各该说明什么就看得见。

## 初六动 · 辰月

交接时账能对上，结项仍要逐笔追到原处

山风蛊 → 雷泽归妹 → 山天大畜

旧账交接顺利，到了结项却要逐笔核引用的数据，这份工作有隐患。交接当天已经拿台账和系统对过，大面上都能合起来，照原来的办法顺手办完了几件旧事。真正花时间的是收尾那次。交付里每个被引用的数都得找回原处，再核取的是哪一笔。连已经对得上的总数，也要按结项要求把所含的各笔拆出来查。

辰月艮土当令，本用巽木、互卦里的震木都在囚地，开头虽有前任的事要接，落到日常还能照原流程办。中间的兑金有相气，初六一动，下巽变成有相气的乾金，作用落在末段，两处都从艮土得生。越近结项，越容易把已有的工夫耗在找记录、认出处这些细事上。

初六「干父之蛊」可以从接前任的账来看，前面留得清楚，你顺着原来能查的地方做，也看得见哪处还要再核。到了「厉终吉」，被追问的多半是结项进度。每个数字都能回到原记录，才是这一轮真正做完的地方。

进度会上有人提一句怎么还没好，能请他看实际工夫用在哪，原先估的量大约只抵得上现在的一半。引用过的数据有多少条，哪些已经对上，哪些还要找台账的经手人，把这些数给出来，下次按剩下的量报时间。可以把来源相同的几处一道核，给还要找人的部分单留一点工夫，免得报了期限又得往后改。

宜把结项会用到的数字提前挑出来，按来源分好，每周五先清手边能核的那摞。前任留下的一笔和你后来补的证据分别放好，最后交出去的数字才能顺着找到凭据。已有的工作还能照办，眼前先给这几周额外的查账留出时间。

## 初六动 · 巳月

山风蛊 → 雷泽归妹 → 山天大畜

季度检查翻到一份沿用多年的表，指出签批栏一直没设，这份工作有隐患。表在你接手以前就是这么用的，季度检查按现在的分工问情况。拿到意见，可以先把检查记录里那份表的版本和期数记下来，回去查清沿用的是哪一版。回去补这一栏容易，还得弄清过去几期哪些已经批准，凭什么能认出来。

巳月艮土受夏火得相气，本用巽木、互卦的震木俱休，有克也做不到把原工作压停。兑金和后来换出的乾金都在死地，整盘虽无直接生扶，原来的人手仍能把补签批、查历史表格的事排下去。季度意见来得急，忙过这一阵，其他职责还有办法照常交。

初六「干父之蛊」说的是前头存下的问题轮到你整治，小象「意承考也」，接住原来的事，还要看哪里该改。表格以前跑得通，没签批栏的地方同样得改；能解释旧表怎么走，再把后来的凭据补到位，检查时才有一条能说通的来路。

「厉终吉」在这里落在检查时被点名一次，后来问题收住。宜趁一周补表的时候顺便翻翻同样沿用的表，看看以前的签批是写在表内还是另有记录。意见上的问题有了答复，原来在手里的职责继续照旧做。
