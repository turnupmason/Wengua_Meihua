## 初六动 · 寅月

手上的交付都做得住，谈到来年可以多想一步

风地观 → 山地剥 → 风雷益

平时的几项交付照旧由你做，流程也熟，这份工作稳得住。到了讨论明年规划的会上，你提的都是执行怎么安排、哪一步要留工夫，眼前能办的事说得清楚。谈到整个部门要往哪里走，自己的意见就少一些。眼下仍负责原来的工作，这点欠缺只在需要你牵头多看时才显出来。

寅月上巽木为体而旺，下坤土本用在死地，巽木去克，手边常做的几项还有余力处理。互卦山地剥，上艮土是体互，下坤土是用互，三处土都在春令死地，照旧分工经手也不费力。盘里没有生巽的卦，也没有克巽处，日常这套做法能够把交付接好。

初六的「童观」是看到身边的一段，远一点的事还没细看。《正义》从所处位置离上方较远来解释。拿这一点回到工作，自己的执行已经做准，会上如果也需要你给出规划意见，可以从近来经手的交付多问一步，哪些变化会影响明年的人手，哪些流程值得提前调整。

下坤初爻变阳成震，得风雷益。寅月变用震木和体卦巽木同旺，到了尾段，原来的分工还照样排到你这边。执行的事有成果、有人继续找你，可以据此把岗位接续的把握看实。至于开规划会时少说的那层，提早准备一两条有实例的意见就能补上。

手里原来的交付仍照现有节奏。下次谈计划时，宜先写三条自己从实际经手中看到的事，附哪份结果或哪次交接能说明它，再说改了以后会帮助哪个接收方。别人问起可直接用例子回答，也不必临场从平常的工作里现找依据。

## 初六动 · 卯月

规划会上想得少一层，原来负责的事仍照做

风地观 → 山地剥 → 风雷益

明年规划会上，大方向说得少，平常那几项交付却照旧交得稳，这份工作稳得住。你对实际操作有话可说，哪种安排容易到期、哪一处常等人，组里知道可以来问你。要求往后多谈一层时，眼下只说得出手边的步骤。若下一年需要多牵头一块，这部分可以提前准备。手边如果已有去年同类交付的记录，可以看看哪个问题反复出现，再把下一次安排会怎么受影响说清。

卯月上巽木为体，正当令。下坤土本用、山地剥上艮土体互、下坤土用互都处死地，巽制三土有余，跟着熟悉的步骤交几件工作不难。卦里无生体处，底气来自体卦本身有力，常做的工作也有原来的分工在维持，手边的日常仍有人接。

「童观，小人无咎，君子吝」要结合所承担的事读。负责执行时，先把眼前的事按要求做完，旁边的人能直接接；若规划也要你牵头，光知道先做哪张表就显得不足。可以先用本组经常遇到的一个例子问，决定这一项的不只是怎么做，还包括明年要不要继续做这么多。

下坤底爻由阴转阳，成为震，得到风雷益。卯月的变用震木和原体巽木比和，两木都旺，最后几项仍照平常交，原来的分工也排在你手上。现职有明确的交付接续。日常交着的材料，恰好可以从里面挑出下次讨论时有必要多看的一两处。

正式开会前，宜把自己对来年的三条看法先写下，注明是从哪类日常交付、哪位接收人的需求看出来，再补一句自己手里能实际做的。即使只从分内写，也比只交代去年的步骤多看一步，手上的工作按原先的办法继续办。

## 初六动 · 辰月

预算、盘点和合同一齐来，盯一件容易丢另外两件

风地观 → 山地剥 → 风雷益

年度预算、库存盘点和合同续签同时摆到手上，最后有一件返工两次，这份工作有隐患。开头最急的那项先得逐条核，另外两件要找的材料便往后放了放。等三处都有人催，才发现原先以为只要照表一填的，少了一道确认，前面留给另外两件的工夫也被挤掉。可以把起初要问的几个问题回看一遍，看看哪一条若早确认就不必改两个版本。

辰月上巽木为体，在囚地。本用下坤土、互卦山地剥的上艮土和下坤土三处当令，巽木得逐处去克，接来的事情量重，不能只拿最急的一件来估整个工作量。没有一处生扶巽木，现有的人手若全用在预算上，盘点与续签的准备还等着有人开头。

「童观」取的是看得近，先盯着快到眼前的那一件，手边其他事情缺什么还没看见。初六也说「君子吝」，三件都落到你名下，得提前问清另外两件的下一步。报表最后做得出，接收人对两次退回仍有印象，返工的来处要从开头少确认哪一步查。

下坤初爻动成震，变为风雷益。辰月震木也囚，虽然和巽木比和，收尾的协作只能依原有的工夫补几处，挪不来大量额外人手。三件最终可以办完，返工还是占了两次。盘中无直接克体，这份工作的隐患主要落在交付反复、自己这边的用时被拖长。

宜给三件列一张总表，每天分别推一小步。预算待谁确认、盘点差哪批原始记录、合同还在等什么答复，都提前看。若一天要先做最急的一项，也给另一件至少发出取材料的请求，免得做到它的时候才知道别人也得花两天。

## 初六动 · 巳月

一边做一边才发现少看一层，三块最后都交晚

风地观 → 山地剥 → 风雷益

三块业务同时到整理的时候，中途还一再回头补，最后三块都比约定晚，现职有隐患。每一块单拿出来都有当时要办的内容，开始只先理手边最明白的一段。理到一半，有的得重找之前的记录，有的要等经手人确认，往回走的那一轮就用掉了原本能按期发出的工夫。遇见三块要靠同一位经手人给资料的，先把各次最晚的用件时间一起说清。

巳月上巽木为体处休地，下坤土为本用，山地剥上艮土为体互、下坤土为用互，三土都相。巽木能克这三处土，但原体气弱，分别理它们都要花时间。局里没有直接克巽的卦，眼前没有哪一道外来限制，主要看自己能不能先理清三块各要干什么。

「童观」说看见了眼前的一段，没看见它后面还有要求。「君子吝」放在工作里，是本来能早问的几步拖到半途又回来补，记录上多了一轮迟交。现在把一块完整要交的东西先列出来，有缺的先问原经手人，省得每次要合起来时才发现少了一段。

下坤初爻变阳成震，得风雷益。巳月震木也休，与巽比和，收尾有人沿同一分工做，但没有多少额外工夫能追先前落下的进度。三块最终都能交，慢下来的那截确实留在接收时间上。下一回要看原先漏过的那一层能否在开做前就核出来。

宜先给每块画出从手边材料到接收人能用的几个步骤，缺得最多的一块拆成小段做。每天先查过三块各欠什么，再去做最急的，遇见等人答复就早问。一块做到哪里随手记，后面接另一块也不用重来。
