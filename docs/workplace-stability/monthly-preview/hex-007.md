## 初六动 · 寅月

带小组赶着往前走，跳过的审批很快被查了出来

地水师 → 地雷复 → 地泽临

小组为赶进度跳过一道规定的审批，合规检查很快追到实际经手的人，这份工作风险大。已经做了哪些事、在哪一步开始先做后报，宜照真实次序记清。该补什么也先问实际查核的人，免得忙着补一张表，却还没回答当时谁有权让工作继续。

寅月以上坤土为体，土弱。下坎水为本用，坤土克坎，开始推工作还得自己花工夫安排分工。互卦里的用互震木当令，直接克坤，查到的恰好是本来就得先做的审批。坎水生震，末段兑金又克震，助与制并见，看震木在春月本有的力量，问责的分量仍实。

初六说「师出以律，否臧凶」，小象说「失律凶也」。王注重在用同一规矩把众人组织起来。带一组人做事，有些步骤负责确认下一段能否开始，时间紧也宜先弄清由谁批准。眼下既然已经越过，照实际经过说明，再听清补办条件和要暂停的范围。

下坎变兑，成地泽临，末段兑金在寅月弱，由坤土生，后来整理交付也会费些时间。卦里没有直接生坤，审批补办能让一部分工作重新依程序安排。合规检查仍得按事实核。若之前已有人按未批准的结果开始下一段，早点请实际经手者讲明该等还是可以继续，尤其是谁何时推动了下一步，哪些结果已被用过，宜让有权确认的人看过。

可以把缺的审批和已经产生的成果放到同一份说明里，请查核者确认是否能补办、此前的材料能否沿用。实际需要重新核的，明确由谁经手，办完留真实接收记录。分工再往下推之前，宜让全组看清哪一步必须等确认，岗位上的压力则以实际追责结论来判断。

## 初六动 · 卯月

审批没等到就先做，检查问的是当时谁决定继续

地水师 → 地雷复 → 地泽临

手上这件小组任务还没过一道规定的审批，已经赶着往下做，检查现在要核谁同意的，现职风险大。若先前有说先准备材料，也宜弄清准备什么时候转成了实际操作。按实际记录把时间、做了什么和谁接到结果摆出来，后续补办才有依据。

卯月上坤土弱，本用下坎水力量不强，坤来克它，开头仍要自己带着人往前推。中段的震木当令，直接克坤，检查追到已经跳过的审批。坎生震，尾段兑克震，助制并见，还是以震木当令为准。检查问的那一层，在尾段加几份材料以前就已经成立。

初六说「师出以律」，小象直说「失律凶也」。几个经手人能按一套规矩办，才知道下一步该等谁点头。放到眼前这一关，宜先问实际批准的人，原来需要看哪些资料、哪些动作得等他确认以后才能做。过去若已给下一环送过东西，也说明现在拿去用到了哪一步。

变为地泽临，尾段兑金弱，由坤土所生，补送说明还要多花些工夫。盘里没有直接生坤，原先责任如何认，须等正在进行的检查给实际意见。宜把可以补办的项目和需要另外处置的旧成果分别说清，也告诉小组现在哪几件能照常走。例如某项成果还没离开原组，先留完整记录，等检查人确认是否要重走步骤。

眼下把实际经手记录交给合规检查的人，不要把后来补的东西写成当时已有。需要补走审批，就依正式答复处理，收件后请实际审批人确认新的办理范围。其余人知道哪道关是现在必须等的，往后的事情才好根据实际结果接起来。

## 初六动 · 辰月

组里前面推得稳，收尾多写的那部分反而占了工夫

地水师 → 地雷复 → 地泽临

小组按原安排把事情办得稳，最后那份交付写出了约定的范围，多花了工夫又被提醒，这份工作有隐患。对方原先能用的是那几项成果，加进去的如果用不上，他还得分辨哪里属于这次。宜把手里那一份放回原来的约定里核，一项项问是否确实需要。

辰月上坤土旺，底下的坎水弱，由坤克，起步能照分工办。中途用互震木弱，克坤的力轻，手上的压力落不到很深。坎水生震与末兑制震俱有，照震当月本来的力量，过程里碰到的要求仍可以处理。前面做顺，也给后来收尾留下能用的成果。

「师出以律」的「律」在古注是整众的法度。放到这次交付，可以看事前说好的范围。若原来只要供接收者办理某一步，超过范围的内容宜问他能不能另作参考。已经写出的保留出处，确需随交付的放进去，多铺的一段可另存，不用把全套再重写。

下坎变兑，成地泽临，尾段兑金在辰月相，由坤土生。这个耗费正是临交自己又加了不少内容，接收者提醒以后得再削回去。四个用位没有直接生坤，旺体能把这处收住，原来事务也仍有人接。宜用实际交付范围把多出的一轮工夫停下来。

让原接收人对一遍最终要用的那几项，按约把它们交完。超出的可以注明将来可能用在哪一件，放到后面的材料里。如果额外部分已让别的同事做了准备，顺手告诉他这次仍以什么为准，免得跟着再花一轮工夫。组内负责整理的人也宜得到同一份范围，免得有人又拿其中几页补进去。眼下该交的交得清楚，上次那一处超出便有实际改法。

## 初六动 · 巳月

组里做得快，省在各处的小步骤攒到一起被点了出来

地水师 → 地雷复 → 地泽临

带小组赶得快，几处规定动作各少了一步，中段被叫去说了一回，这份工作有隐患。看起来每处只差个签字或确认，接手的人合在一起检查，才发现都要回头找。宜先拿实际流程查清少的是记录还是动作，已经有人做过的，要找到能查的凭据。

## 初六动 · 子月

接收方一翻规定，前面做过的一整段都得重新核

地水师 → 地雷复 → 地泽临

手上的量已经排得很满，长要求漏读了一条，对方现在要把那一块退回重做，现职风险大。宜先问清规定到底怎样改变了原来做的事，哪些已经照错条件交到别人手里。原来的量还在，重做又要真出一段工夫，早点让排活的人知道这两处碰到哪里。

子月上坤土囚，下坎水旺，本用已经费力。到了过程里的用互震木相，震受旺水所生，直接来克坤，返工的要求确实挡住正在做的活。尾兑能克震，两处助制并见，震木仍照原月势，旺坎所主的量也不能从这一层消掉。宜和真正接收的人核准从哪一步改起。

「师出以律」说起步宜明法度。「否臧凶」在这里取漏掉一条后真的会使已经完成的工作不合要求。对小组讲这一次，宜指到原有材料哪儿不符合，说明怎样才算改过。只是转发整份长说明，下一位经手人仍可能没看到这一处。可以把正确的一件样子给同组看，正要往下办的人也能知道自己现在该停在什么地方。

下坎变兑，得地泽临，尾兑弱，由坤所生，最后汇总和更新还要些时间，重处在中段的整块返工。盘里没有直接生坤，眼下能先做的宜看哪项改好以后接收者就能继续，其他新工作有人急用的，也给他知道还要等哪个步骤。

可以把遗漏的规定用短句记在原来操作的位置，跟实际经手者对一遍，再分配重做的工夫。已拿出手的成果，要让接收人确认哪些可以暂用、哪一段必须换。中段这一关有了真实答复，尾段再把收尾安排讲清楚，岗位上的情况随实际进展看。
