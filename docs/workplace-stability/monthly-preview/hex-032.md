## 初六动 · 寅月

接手第一周就想全改，先在一个小组试起来

雷风恒 → 泽天夬 → 雷天大壮

刚接手一周就交了份全面改造方案，评审说先只许在一个小组试，岗位有隐患。提意见的人语气并不重，也留了一个能推进的办法。急着一回把所有小组都改过来，才是现在最容易被打回去的地方。既然准了小组试点，手上早就能做的那部分还可以接着做。

宜先问试点小组日常最容易在哪一步耽误，和全面方案对着看，挑一两项现有的人能试、能看出变化的。测试期间谁经手、出了问题怎么回到原来做法、何时给评审看结果，事先讲清。其他组先依旧做，以后想改的几件另外记下，免得试点还没走完，就得给几边重新排工作。

上震木为体，下巽木是本用，两木比和。互卦泽天夬，上兑金为体互，下乾金为用互，两金都克震。下巽初爻由阴转阳为乾，变雷天大壮，乾金在末段也克震。寅月震巽旺、兑与两乾囚，三处意见力道轻，震能承；盘里无卦生体，办得太大到收尾还会受限。

初六「浚恒，贞凶，无攸利」，小象说「始求深也」。头一周还没看出各组怎样经手，就想让人照同一套办法全改，后面改不动还要加倍解释。宜先用试点的实际结果回答会上提的意见，做成一项就说明改在何处、谁用过。剩余的等确认这几步真能走，再去谈要不要铺开。

整段看试点能不能按评审同意的范围办完。宜从方案里保留当下确实做得成的内容，拿小组真实用过的记录讲成效和问题，再报下一步。还没试过的地方保持原来的手续，多出来的活也先不加给别人，等现有的结果收到再议。

## 初六动 · 卯月

评审开口只准小组试，手里的方案还能推一段

雷风恒 → 泽天夬 → 雷天大壮

一接手就想把原有流程全换了，第一周报上去，评审之后只给了一个小组试点，卯月有隐患。几个意见都提得平和，集中在能不能先做小一点。原来写的方案里，已有同事可以把其中几步做起来，眼下还有路可走，宜先把那几步摆到这个小组实际办的工作里。

试点开始之前，和组里直接经手的人对一遍哪几项比较费事。实际只需要动其中一步就够的，先把交接点和用的材料改清，别老流程刚看明白就把前后几处全推倒。宜记录原先用了多少工夫、试完以后哪里顺一点，届时让试过的人也给出具体感受。

本卦上震木为体，下巽木为本用，比和。互为泽天夬，上兑是体互，下乾是用互，两金克震。下巽底爻动成乾，得雷天大壮，变乾金照样克震。卯月震巽旺、兑和两乾囚，三处阻力虽轻，没有卦生震，末段照原来宽的范围行事仍受限制。

「浚恒，贞凶，无攸利」，说的是开头就求得很深，一门心思照着办容易吃亏。宜从评审留下的那一点空间着手，把方案缩成小组真正能试的几项，没约定由这个组办的先放一放。要是做的过程中还有同事提出困难，先分清是这个办法不合用，还是试的那一步还没办全。等这组把试用结果交齐，再请评审确认下一步的边界。

看先试后改这一段，结果以经手的人确实走过新步骤为准。宜拿交付或使用记录回报评审，哪些做成了、哪些还欠材料，分开说清。以后若准许再做一段，就从这份试点有把握的结果接着排，原来的全面改造先放后面。

## 初六动 · 辰月

改造只做了一角，先把这一角交清

雷风恒 → 泽天夬 → 雷天大壮

开季报了一份分量很重的改造计划，到了中段评估和总部条文都按那份计划来问，辰月岗位风险大。收尾还有职责核定，把计划摊开以后，已经推进的只是一小部分。中间每一道要求都对着那几项，手里同时办别的也腾不出工夫，已经完成的反而还压着没交。

宜把大计划拆成能各自交清的小段，先找出现在已验过的那部分，按要求把材料与经手记录送到。剩余的照仍要补人手、等核准或需要调整流程分开列，分别问清谁能接。中段评估提出的几项，哪一项需要你给实际结果，也从准备交的这份里找到具体依据。

尾段申、酉日，可旁参职责核定时实际只推进一角的情形。宜把已经做好的部分先交，新的阶段按核过的人手与工夫去排。也把评估已经认可的做法随件附上。如果当初有一项要等其他组改好才能动，说明现在卡在哪、下一回何时再问。这一纸计划后续能走多远，就用这些可查的进展来定。

## 初六动 · 巳月

年度计划写得太满，每次只问一两项也应付不过来

雷风恒 → 泽天夬 → 雷天大壮

上半年交的年度计划把很多事一并算进来，目标定高了，几次评估、总部问进度和期末盘点接着来，巳月岗位风险大。每次追的不过一两项，单拿出来都能说明。到了季末把各边问过的和业绩对着看，差距就不好遮过去，本来要填的几个结果仍空着。

宜先用本季已经交出去的东西核原计划，哪一项有接收记录，哪一项只到准备，分别记明。许过的目标按眼下能拨出的人手与时段收小，改过的先让负责看计划的人确认。几个方向如果都需要同一拨人，先排真正能做完的那一项，另外几件给出重新核对的日期。

## 九三动 · 丑月

收尾有确认回函，先把两次报的进度说明白

雷风恒 → 泽天夬 → 雷水解

季度考核表里几项要求具体，同一项进度你先说七成，后来又答一半，被问了好几遍，丑月有隐患。末尾能收到一份确认回函，这份帮助只有一点。想把问题收住，还要从现有的接收记录里核清真实完成量，然后让问过的几边都按同一份说法核。
