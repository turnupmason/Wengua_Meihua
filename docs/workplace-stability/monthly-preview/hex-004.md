## 初六动 · 寅月

刚把规矩立起来，问责就查到你负责的几项

山水蒙 → 地雷复 → 山泽损

手里的流程才开始理顺，中途已经有人要查整顿成效，这份工作风险大。最难的是一项工作刚变了做法，实际记录还没有走完一轮，对方却要现在就说清哪里补好了、哪里仍有遗漏。能够说明方向正确是一回事，已经有结果可核，还得等经手的人按新办法实际办过。

上艮是体，代表你在岗位上的力量。寅月土弱，开头要整理原有问题，靠同事找来几份旧记录，还能往前走。真正吃紧的是中途的问责。震木得令，直接来克艮土，查的也正是你手头还没办完的部分。卦里又有一生一克同时作用在震木上，这里仍以震木当令的力量为准。

初六说「发蒙，利用刑人，用说桎梏，以往吝」。王注把前半解释为疑处弄清，严正与解除约束各得其当，后半则戒一味沿严治往下走。用在工作，宜先让大家知道哪条规矩要照办、怎样才算改完。遇到承担范围不清的情况，继续加一层审批也填不上原来欠的记录。

下坎变兑，成山泽损，末段是艮土生兑金。寅月兑囚，后面还有些补漏的工夫要出，分量弱于中途问责。盘里没有生体来兜底，因此应先看书面问责要核到什么职责，最后补好的文件也要照这个范围来看。

宜把已经试行的纠错步骤同实际结果放在一起。经手人还没有照办的，写明卡在何处；能由外部查明的，优先附上。这样等真正讨论岗位责任时，对方至少能辨出哪些问题已经收口、哪些还需要时间处理，剩下的压力也好据正式结论判断。

## 初六动 · 卯月

旧问题还没查完，问责已经要你回答结果

山水蒙 → 地雷复 → 山泽损

整顿的范围才说清，问责的人已来调看实际处理记录，这份工作风险大。比如你让几个经手人换成同一套做法，第一批还在等确认，检查先问起前面哪几次谁签过。打算补上的事不能当作已经解决，一项项查起来，现职所担的责任便有了具体的边界。

开头要弄清旧流程怎么走、几次确认在哪里漏了，这部分就已经费工。卯月艮土与互坤都弱，同事能帮你找到经办的线索，却不容易替你把缺处一并补齐。到了中途，震木当令而克艮，问责有实在分量。前后另有力量一助一制，仍看这处旺木带来的压力。

「发蒙」讲先把昏昧处打开，初六的「用说桎梏」也说条件弄清以后，合当解除的约束就解除。若明知旧流程的问题在经手和确认脱节，再给所有人多加数道检查也不一定有用。「以往吝」可以用来提醒：规矩已经能约住那一处就宜收手，把工夫留下来办尚未解决的事。

变为山泽损，下兑受上艮所生。卯月兑金囚，最后整理几份说明、把记录补全也会耗力，却不是最重的压力。没有另一处生体可援，尾段补好一项还不能推断中途的责问就轻了；认哪些错误已经压住、谁负责后续，得看正式核定怎么写。

可把旧问题和整改之后的两类材料并列，注明已经发生的变化、尚未验证的一段。若有几项已经按新办法运转，还宜注明用了几轮、有哪位经手人确认，以便同只列入计划的事项区分。宜先请问责经手者确认用什么资料核过，再照他的要求交。若原有职责仍需继续承担，也请把接下来的权限和工夫一起说清，免得仅靠临时加班填在表面。

## 初六动 · 辰月

原本已经能交，最后又改了一轮才误了期限

山水蒙 → 地雷复 → 山泽损

前半段的工作做得扎实，交付前又把成形的内容改了一遍，这份工作有隐患。接收的人原先按那份材料安排好了后面的事，临送时才知道还会变一处，只好一并往后等。问题出在新增的修改占用了已留给确认的工夫，前面做好的部分仍可用。

辰月艮土旺，前头整理工作比较顺，原同事也有工夫照着旧分工接手。中途虽有震木来克，木弱，最常见的影响是一两处被挑出来要解释。你拿得出经手记录答复，真正会拉长进度的，反倒是临交前又多做了几件改动。

「发蒙」宜把看不清的处所弄明白。爻辞又接「用说桎梏，以往吝」，古注兼言限制可解除，也说严治不可长。放在已成形的交付上，宜先问改动是否是现在必须解决的。如果接收方已经认可原条件，一点尚可留后再议的想法，用不着令整件工作重新归零。

到山泽损，下兑金相，由艮土所生，末段有实在的耗费，是你自己继续改过了头。往后的同事需要知道哪些地方仍可照旧用，不能等他说看不懂才开始标记。有旺土与同气支撑，这一处主要留在迟交和要说明一次，并未到工作无人接的地步。

如果已经决定做小修，宜将当前认可的版本留在手里，只把确会影响使用的一两处调好。同时说清改的是说明还是交付本身，再请经手者按原约核认。接收记录接得上，真正需要留到下一版的变化也有了去处。接收方若只等一项确定的结果，可以把它先送到，再将改动缘由附在交付后面，这处隐患就有办法在本次交付里收住。

## 初六动 · 巳月

流程已经顺过来，中途还是有人要你解释一处遗漏

山水蒙 → 地雷复 → 山泽损

手头的流程整顿已经见效，小处被查出来还要去说明一回，这份工作有隐患。最容易见的是有几位同事已经知道要按新标准办，旧记录却没全部补在一起。负责看进度的人问到其中一处，查得出前因，短时间内还能修正，不碍现有的工作继续往下做。

巳月艮土有力，开始时原来的事能够理清。同组的人也找得到旧记录，遇到核查，可以把当时是谁办的问明。中段的震木在休地，虽克艮，分量偏轻，较像有人叫你说明一处遗漏。已有的材料和分工足以应对，后面可以把补好的留给接手的人使用。

初六「发蒙」先把问题说清楚，才好依规行事。「用说桎梏」也讲弄清以后有可以解开的一层。放到现职，宜把怎样验收整改同原来做过的整理区别明确，能够证明已解决的一步，复问之后便可回到原分工。若每种可能再补一遍手续，容易失了「以往吝」的限度。

## 初六动 · 子月

活量先顶住了人，中途的检查又要看旧案

山水蒙 → 地雷复 → 山泽损

几项工作同时来，正在补的旧漏洞也被要求当场解释，现职风险大。原来定下的规矩并不难懂，每一位经手人要同时照着做，还得有工夫真正验证。问题一件件出来时，短时间内只能先补重要的。到检查提起一处沿用已久的做法，手里的现成依据还不够。

子月艮土偏弱，要去理的坎水却旺，原来一个人能兼顾的几项，到了这里就容易错开工夫。旧同事能帮着找几条记录，未必能替你把所有事情重新核过。中途来了有相气的震木克艮，生它和制它的力量都有，仍取一次有实质约束的检查。

初六说「发蒙」，须先让模糊的事情变得有边界。古注解释「以往吝」是过头的强治容易招致困顿。工作的分寸是改可以真正挡住漏洞的一步，把没条件立刻遍查的列出来商量先后。若在手头已经紧张的时候多立几条没人接的规则，容易让原来的错继续漏过去。

到山泽损，尾用兑在子月休，受艮土所生，后面可能还要自己补交几件记录。分量较开头任务和中段检查轻，不能倒推检查已经没有影响。体囚且无生体，职责有压力，最应关心的是检查后具体由谁办理，以及原岗位还有没有合理的安排可接。

宜拿实际工作量和这次查出的事项同定排程的人先过一遍，挑能立即补好的做完。余下写明须由谁发资料、哪一步要重新查看。如果原先日期已经拖不住，宜把希望增补的人手和真实到期日一起拿给管分工的人核准。等经手人能够沿新手续真的走完，原来的活也有人按适当时间送到，风险的实情才能查出。

## 初六动 · 丑月

现有的已经能用，交付前又多改出一轮

山水蒙 → 地雷复 → 山泽损

手里已做成的东西可以照常用，临交时却准备把几个旧决定重新排一遍，这份工作有隐患。比如归档时原想挪一处提示，方便下一手看，动起来又想把整份都整理一遍。要改的越来越多，原先约定的日期便容易来不及。

丑按土月看，上艮和同气的互坤都有力。前头立下的规矩可以照着做，到了中途，有人问一两句也能解释。震木虽来克艮，力量偏轻。原先按期承接的工作仍有支撑，后来那次耽搁，主要因为自己又拿出工夫改了已经能用的东西。

「发蒙」可用来提醒把哪里出了问题说清。「用说桎梏」有解除不必再留的限制之意，「以往吝」又令当止处知止。放在目前，宜识别实际接收的问题已经在哪个版本解决。之前已经核过而且能用的东西，与验收方明确认过就可以沿用。

尾段下坎化兑，卦为山泽损。丑月金相，由旺艮所生，消耗切实出在末段。正在收尾却改了原来的范围，会多花时间重新准备一轮，最后被问为何延期。现任职责本有稳定交付支持，隐患范围主要在这一次把力气用得太满。

宜用接收方给出的验收范围逐条核，确认这次只动影响使用的内容。临时想到要改而对这轮没有影响的，另留于下一次排程。已经认可的版本若仍由另一组使用，也宜明确这轮只改哪里，使现有交付不必再从头确认。在约定时间先发可用的交付，顺手告诉对方改过哪几页。原分工按这一份还能往下办，岗位的这处轻重就容易看出来。
