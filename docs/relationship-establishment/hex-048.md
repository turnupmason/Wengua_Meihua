## 初六动 · 寅月、卯月

旧的来往接不上，近期难把恋爱定下

水风井 → 火泽睽 → 水天需

简断

若每次开口都得你铺垫许久，这段近期较难确定。可以直说一件你愿意一起做的事，说过便给对方独自回应的时间。等有人真正接着做，关系才有新进展；现在先别为维持热度不断找话题。

开局：春巽木旺而泄休坎，话题虽然可以展开，负责发起的一边较容易累。

过程：离火体互相，休水很难制住，牵涉对彼此的要求时还谈不拢。囚兑用互仍生水，偶尔接得上话，却不足以照顾最费劲的地方。

结局：初六的井泥久滞，连禽也不向，指旧的来往方式一时难用。变乾囚仍扶坎，稍有缓和，须先清掉彼此往来时的积碍，恋爱近期难落实。

应期：此盘暂无有据的日期可列。

总断：近期较难确定。已经提过的事不用换个话头再问一遍，给对方留一点能主动尝试的空间。

零星的接话还撑不起确认，近期较难定

简断

两个人若只在方便的时候说几句，最近难靠这样的来往变成恋爱。先问一次对方愿不愿意单独见面，听到含糊的话就照它本来的分量理解，别把零星的回话合在一起当成一个明确答复。

开局：夏巽虽休，仍受囚坎所生，手里原本能用的心力便不多。

过程：离火体互夏旺，水想把分歧理顺很吃力；兑金用互死，偶尔的接应难抵前面不断消耗。

应期：此盘暂无有据的日期可列。

总断：暂难定下。先听对方能不能给一个完整而具体的答复，答复若迟迟没有，也可以把注意力放回自己的事。

冷下来的来往或能再接上，实有回应才好确定

水风井 → 火泽睽 → 水天需

简断

前面若有些冷淡，后面还有重新接上话的机会。能不能确定恋爱，要看原来不顺的相处能否真有新动作。若对方愿意把以前没接下去的话说明白，或者主动约一次，再顺着这一步谈走不走得更近。

开局：秋巽木死，仍耗相坎，发起一次的负担没有那么重，开头的反应可能仍淡。

过程：离火体互囚，相坎制离较有余地。用互兑金当旺，直接生体，遇到肯给具体答复的时候，对话便可从僵处出来。

应期：以下为传统推算的参考窗口。
可留意本月18、19号前后，原先冷下来的来往重新接上，属吉应。若之前已有想谈却搁下的话，可留意对方是否给出实际回应，属吉应。

总断：有转机，先看对话能不能从你一个人在讲变成双方来往。愿意接住新的相处安排，再提明确关系。

  “如占吉事，无生体之卦，有克体之卦，则事不谐矣。”
  分别核对起初愿意往来、解决实际分歧和最后能否确认关系。完整爻辞的限制须放回具体阶段。

- mh-067《婚姻占第五》，原文第 530 行起。
  “用生体，婚易成，或因婚有得；”
  本用对原体为开局的直接依据。

- mh-067《婚姻占第五》，原文第 530 行起。
  “体用比和，婚姻吉利。”
  同一关系条文用于理解末段走势。

- mh-122《占卜克应之诀》，原文第 822 行起。
  “应之期远，则以年，近则以月，又近则以日也。”
  只有具备近期现实前提的见面、相互商量或具体阻节才取日窗。事件和所取节点一一对应。双方确认关系另外看是否有足够依据。

- mh-122《占卜克应之诀》，原文第 822 行起。
  “细观生体之卦为吉，应决期克体之卦为凶。”
  相兑金申酉日应直克木体，仅作中程条件限制参考。
