## 初九动 · 寅月、卯月

一天一通电话，还是想到才发消息

天泽履 → 风火家人 → 天水讼

简断

你们在陶艺课上认识，下课一起走一段路，聊得很投合。走到具体怎么相处，对方想每天通一次电话，你习惯想到才发消息，两边各让了几回，卡在这一处没解开，这回便定不下来。

开局：起先合得很自然，捏坏了泥坯一起笑，课后顺路去喝碗汤。

过程：熟了以后，对方说想每天睡前通个电话，听听声音。你答应了，可下班常常累得不想说话，接起来也是嗯嗯啊啊；改成隔天，对方又嫌少。这一处是真分歧，你挤出来的那点精神，撑不了几回。

结局：到后来你照自己的样子说清：电话可以有，不能天天。「素履，往无咎」，你没有装作喜欢天天通话，照本来的样子走过去，这一步挑不出错，只是两人的习惯仍对不上。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，说到多久联系一次，两人想法不一样，属凶应。照实讲你舒服的联系频率，不勉强答应。

总断：电话这件事对不拢，这一段还停在暧昧里。照实说出自己舒服的联系方式，比勉强答应更站得住。

同一栋楼里，对方要求先瞒着

天泽履 → 风火家人 → 天水讼

简断

你俩在一个部门，工位隔着两排，对方把话说在前头：要来往，就不能让同事知道，楼里遇见只当普通同事。这个条件压得最重，这一回难成。你这边本就撑得吃力，躲躲藏藏几个星期，人先疲了。

开局：起头很顺：午饭常坐一桌，聊项目，也聊周末去哪。

过程：条件一摆出来，日子就变了味。电梯里不敢多说一句，下班要错开时间走，周末约在离公司很远的街区。你每天都在算谁会看见，这份小心比哪一次争执都耗人。

结局：几个星期后，你提出能不能至少告诉一两个熟人，对方摇头。「素履」是照本来的样子走，你走不成本来的样子；「往无咎」，这件事上你没有做错，难处在条件本身。

总断：瞒着的来往撑不了多久，藏着掖着，你们没走到一起。这个条件你接不接，照实告诉对方，不必硬扛着。

开局：初见就投缘，第一次吃饭聊到店家打烊。
