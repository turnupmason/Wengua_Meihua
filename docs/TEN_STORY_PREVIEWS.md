# 十个故事试读 · 直接断语版

组合版本1.1.0。以下是程序原始输出，未另行润色。示例输入不是读者个人占卦，内容为传统卦断，未编写事后应验。箭头为本、互、变；日期按各例明确给定的日干支及日尺度计算。

第10例另有明确输入：体卦衰极、受日月侵害。不能仅凭夏月或逢空就判真空。总断取用口径见 [DIRECT_STORIES.md](DIRECT_STORIES.md)。

## 1. 求财：正在推进的一件财务事项

泽火革 → 天风姤 → 泽山咸；初九动；春木当令；示例日：甲子。

卦断：这次求财有进账，所得不多。

起初是泽火革。春木当令。体为兑金，用为当下所问之事。事情压着你，往前办会受阻。

动在初九：“巩用黄牛之革。”这爻说的是先守住，眼下还不到大改的时候。急着推翻原来的安排，反而把自己弄被动。

中途到了天风姤。乾金这一边，体互静空，这份配合眼下还没有落地。巽木这一边，这事你还能管得住，由你来推动。

最后变为泽山咸。这一爻动后，离火变成艮土，用克体变成用生体。所以这卦断：这次求财有进账，所得不多。

成事应期取丑日（起卦后第1日）、辰日（起卦后第4日）。
