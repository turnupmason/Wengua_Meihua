# 八卦配支与基础断语的空亡处理

本项目使用八卦配支，不把方位配支说成六爻纳甲。

| 经卦 | 地支 |
| --- | --- |
| 乾 | 戌、亥 |
| 兑 | 酉 |
| 离 | 午 |
| 震 | 卯 |
| 巽 | 辰、巳 |
| 坎 | 子 |
| 艮 | 丑、寅 |
| 坤 | 未、申 |

以起卦日干支确定旬空，扫描本、互、变的经卦，原体沿用位置不重复累计。

没有任何配支命中则正常使用基础生克与月令稿。命中形态分全空与半空：配支全部命中为全空；双支卦只中一个为半空。半空定性减力、仍有作用，程序不擅设50%、零力量或一半金额。

用户在本轮将全部命中称为“真空亡”。为避免与此前已定的“衰极受日月攻击而失效”的真空状态混同，数据把命中形态hitKind与作用状态state分开保存：前者none/partial/full；后者继续记录动不为空、旺不为空、得扶假空、静空、衰极失效等。全空命中不直接抹去原已确定的发动、旺相与生扶条件。

先看核心体、用与变化位置。普通互卦静空仅保留计算事实，不自行编出隐藏情节，不另排填冲日期；体互的直接生克与旺衰依旧保留。需要改变核心结论的空亡情境必须另写有依据的版本，未写返回待写。

当前60篇基础正文不预设某旬空。运行时允许无核心作用变化的情境使用基础稿；记录过的午未空情境另显示简短核心提示。未记录的半空核心、静空体或其他改变核心的情境，不用近似故事替代。取期依据节点若不再有效，也不沿用原日期。

填实优先、冲空次之，合空不作为通用出空。真正失效的空亡不因未来日支到来自动恢复。只有具体核心稿有审核过的事件和条件时才展示出空日期；阶段修正、沟通受阻与最终成败分别标注。

用户可见结果不追加关于用户批准规则的尾注。来源与规则版本保留在内部记录。

当前实现规则版本trigram-void-2.1.0，由src/void-policy.js独立记录，与月令旺衰表、稿件版本及历法计算分开。半空与命中详情放calculationExplanation，前台默认折叠“计算说明”，不附加在简断或开局、过程、结局、总断中。
