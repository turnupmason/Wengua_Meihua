# 《周易六十四卦详解》入库审校

版本：2026.11.10.2。原 DOCX 完整保存，未改写原稿。核对结果不以“百分百正确”作不可验证的保证；机器可验证的文本与结构有强制检查，传统解释与作者归属有明确边界。

## 覆盖与结果

| 检查 | 结果 |
| --- | --- |
| DOCX 段落 | 8,770：正文8,706，目录表格64 |
| 提取文字 | 315,194个 Unicode 码点，逐段登记处置；含目录862字 |
| 卦序、卦名、上下卦 | 64组与主库逐项一致 |
| 普通爻位 | 384组编号与阴阳名称一致 |
| 单动爻变卦 | 384处原稿变卦描述经修复后与单比特翻转一致 |
| 本轮 DOCX 编辑记录 | 128条，含错字、白话、伪标题、诗象署名与串贴修复 |
| 错置片段 | 64段隔离，含一个段落尾部；对应63个整段加1个部分段落 |
| 经文差异 | 剩余15处保留于参考对照，运行时不从这些差异字段覆盖主库 |
| 主库反向复核 | 新增14项古文订正，主库累计52条编辑记录 |

正文与目录的每个提取段落均有稳定 `paragraphId`。`bodyParagraph` 为文档正文的顶层段落编号；目录表格段落没有这个编号。错字修改按链条核对 before/after，能定位到原 DOCX XML 的段落。字符覆盖检查证明没有漏导资料，**不等于逐字认证每句话的学理或现实预测正确**。

## 本轮确认的问题

- **大有六爻**：“哲学解析”整组混入同人六爻。移出错误段落，另提供依据大有本爻与小象新写的经义说明。
- **谦六爻**：“哲学解析”整组混入大有六爻。即使卦首已经删除一处错误，六爻部分仍需单独检查；现已隔离并补经义说明。
- **丰初九**：爻辞、小象、白话和所署名家解释混入归妹初九；变卦错误写解。恢复“遇其配主，虽旬无咎，往有尚”，初爻动应变**小过62**。错误作者解释不以新编文字冒名补写。
- **兑九四**：夹入九五的整块资料与“变归妹”内容；还把九四资料排在九五变卦后。移除重复九五块，九四正确变**节60**，九五仍变**归妹54**。
- **坤六五、屯六四、蒙六五、比六四、履初九**：有相邻爻的重复解释混入。逐段隔离错误位置的拷贝，保留正确位置原有内容。
- **字词**：“童豕之牿”改童牛，“三是不食”改三日，“覆公诉”改覆公餗，“濡其道”改濡其首；并处理客/容、即/既、曰/日、土/士等具体语境。没有将全部同音或相似字全局替换。
- **爻位事实**：修正九二居刚位、六三为阳爻、九四为阴爻、初六居柔位等明确结构陈述。得位、居中和相应另由代码从六个阴阳位计算。
- **白话冲突**：屯六二“字”与“反常”沿用所据古注的许嫁/恢复常道读法，不再一处说怀孕、一处说出嫁。
- **署名错误**：民间吉凶诗不署为《周易》象传；新编经义说明不署为邵雍或傅佩荣原话。

## 入库门槛

`data/knowledge.sql` 与生成的 SQLite 包含主库卦爻文本、来源、五档分类、用户最新等级、384条结构与变卦映射、领域原文、规则配置和参考路径。

**长篇整理注解正文、隔离段落、未确认作者归属不写入正式数据库事实表。** 长篇注解保存在 `sources/commentary/`，通过单独的参考阅读接口访问；它们经文本整理、明显结构问题修复，仍不宣称每一条传统占断可被证实。作者姓名按“整理稿所署”说明。

程序默认详情来自 `data/details/` 与主库，查爻文采用原本卦ID+1至6爻位。参考注解不能反向改排盘、改等级、改空亡或生成未经给定的权重。

## 逐项复核入口

- `data/details/import-report.json`：机器统计与入库门槛。
- `data/details/editorial-patches.json`：128条 before/after 与证据。
- `sources/review/details-quarantine.json`：被隔离的原段落、原位置、原因。
- `sources/review/details-paragraph-dispositions.json`：8,770段处置表。
- `data/details/variants.json`：参考原文与正式经文的差异。
- `data/details/source-manifest.json`：原 DOCX 与提取结果的 SHA-256。

## 网上依据与异议

64个周易固定修订号快照仍见主库来源清单；本轮针对疑义重新查看需、讼、谦、大有、坎、离、大壮、晋、蹇、革、丰、兑、节等页面。

- [丰经文](https://zh.wikisource.org/zh-hans/周易/豐)、[丰古注](https://zh.wikisource.org/zh-hans/周易正義/06豐)：核对配主、旬/均与小象。
- [谦](https://zh.wikisource.org/zh-hans/周易/謙)、[大有](https://zh.wikisource.org/zh-hans/周易/大有)：确认两组串贴与相应经义。
- [兑](https://zh.wikisource.org/zh-hans/周易/兌)：九四、九五经文不同，不能混组；变卦另用程序复算。
- [讼](https://zh.wikisource.org/zh-hans/周易/訟)、[坎](https://zh.wikisource.org/zh-hans/周易/坎)：核对作事谋始、归逋窜、徽纆等字句。
- [屯古注](https://zh.wikisource.org/zh-hans/周易正義/01屯)：字与反常的所据解释。
