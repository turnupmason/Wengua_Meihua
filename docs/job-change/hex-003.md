## 初九动 · 寅月、卯月

为那边补材料，补得自己脱了一层皮

水雷屯 → 山地剥 → 水地比

简断

利在守着现职，不辞为好。为了新单位，你补作品、改简历、熬夜做测试题，花出去的力气远超所得；那边条件处处带着小限制，一处不重，处处都有，算下来去了也只是勉强。

开局：对方要你交的东西不少：作品集、推荐信，外加一份限时测试。

过程：你下班后全扑在这上面，现职的事也照样压着，几周下来夜夜如此，那边只回了句「还在比较」。

结局：等条件终于摆出来，薪资、假期、调岗规矩各带一条小限制，没一条致命，凑在一起就把好处磨平了。「磐桓，利居贞」，在原地盘桓，利在守正，这一回守在现职，比往外使劲划算。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，那边又要补一份材料，又是一个晚上，属耗应。先问清这份材料是不是最后一份，再决定做不做。

总断：做着现职。那边的测试交完就不再追加投入，把夜里的时间还给现在这份工作。

到岗以后，没有人把活交到你手上

水雷屯 → 山地剥 → 水地比

简断

开局：新岗位的职责写得周全，看上去接过来就能做。

过程：你为这边已经花了不少工夫，每回沟通都要你先准备一大堆东西，对方回得平平。

结局：问到入职后跟谁交接，对方说前任早已离开，资料在共享盘里自己看。阻力不算重，可你得从零理一遍，前几个月都在填坑。小象说「虽磐桓，志行正也」，徘徊不是错，守在正处等一个接得住的时机，才是正路。

## 初九动 · 申月、酉月

那边只管一半，另一半要你自己跑

水雷屯 → 山地剥 → 水地比

简断

守住现职。新单位条件尚可，主干也对路，可细问下去，入职的手续那边只管一半：社保要转、档案要调、户口要挂，都得你自己跑，件件不难，却件件要请假；为这些零碎换一份相差无几的差事，不划算。

开局：你这阵子底子不弱，新单位的主要条件也和你对得上。

过程：问到入职手续，人事说他们只出接收函，其余的你自己去办。

结局：一列清单，七八样，社保、档案、证件各有各的窗口，各有各的时间。没有哪一样卡得死，只是散在各处，一样要请半天假。「利居贞」，守在原地不动，这些零碎就都省了。

总断：那几样手续若对方肯代办或给出办理时间表，再拿来比；否则先留下，这一步不值得迈。
