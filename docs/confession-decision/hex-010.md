天泽履 → 风火家人 → 天水讼

简断

这卦有两人说得上话的意思，对方的心意不妨从最寻常的照应看。近期对方自己来联络的机会不多，眼下宜保持真诚朴素的来往，表白先缓。哪怕只问起一件你们都关心的事，只要对方愿意有下文，也比铺排一个大场面有用。

开局：乾金春囚，兑金本用也囚，与原体比和。彼此能在熟悉的事情上找到相处的办法，另添新安排则余力不大。

过程：体互巽木春旺，休息和见面的条件难靠囚金全盘掌握；用互离火春相，克乾，中段话题若说重了，还可能添上彼此不方便回答的地方。

结局：初九素履，循朴实的本愿往才无咎。末变坎水春休，受乾所生，想让后面每一步都如愿会再耗心力。眼下宜先把你本来就做得起的来往照料好。

可留意本月15、16号前后，若已有一回简单的接触，临时把谈话说得太郑重可能增加顾虑，属凶应。顺着两边本来都容易说的事情去谈。

总断：平常可以说话就平常地说，少铺路，少造势。对方以后自己接得上，才更适合说出你对相处的喜欢。
