有机会先听见关心，表白等来往前后一致

风泽中孚 → 山雷颐 → 风水涣

简断

卦里对方有认真对待来往的一面，近日也可能先来联系。起头稍有距离，后来有机会谈顺。眼下先别表白，看看对方说过的事能不能按约做，第一次的照应以后还有没有。

开局：巽木体春令旺，兑金用囚而克巽，刚开始会有不太好接的分寸，不过原体有余力慢慢聊。

过程：体互艮土死，巽木能克，具体一点的约法也有办法料理。用互震木旺，与本体比和，谈话到了彼此都明白的地方，容易多一份配合。

结局：初九的吉在开始用信时能专一，有他顾就难安。变用坎水休而直接生木，后面有人愿意给一点实在照应。宜从目前已经可信的相处接下去，表白须在对方的主动确实持续之后。

总断：说好的事是不是真的做了，比见面时有没有聊得热闹更容易看清。表白可留到相处让两人都觉得踏实时。

风泽中孚 → 山雷颐 → 水泽节

简断

卦里对方有愿意帮助你的一面，近日也较可能主动联系。实际相处有机会办成一件事，眼下却可以先不表白。看看对方的主动问候能不能接到一次自在的见面，之后两个人还想不想再约。

总断：一句实在的关心值得收下。若后来能看到对方照约参与，还愿意接下一回，再想要不要把喜欢说出。
