## 初六动 · 寅月

别拿表白去弥补悄悄积下的隔阂

坤为地 → 坤为地 → 地雷复

先不要表白，尤其是最近连普通的邀约都要反复确认，或者有一句话让你们都不知该怎样接下去的时候。寅月这卦尚有熟悉的相处基础，却看不出多强的恋爱心意；对方近日自己开口联络的迹象也偏弱。不能把对方礼貌地应了一声，或者没有立刻说不，当成愿意与你进一步发展的表示。

上下坤土相同，以静卦坤为体，本用坤表示这段实际往来，体互和用互依次亦为坤。四处同属土，寅月木旺，土死，同气虽在却不足以承担较重的情绪和决定。《婚姻占》所说比和为彼此相就，是两边容易接得上的传统条件，并没有确定哪一方先发消息；本盘无直接生土的卦，不能将这份相近当作对方一端正主动靠近。

初六「履霜，坚冰至」，王弼从初微而积著解释，孔疏提醒防渐虑微、慎终于始。若一件安排常在最后才被改掉，或者彼此习惯了绕开某句话，值得在还能平静谈论时说清。卦爻说的是逐渐累积的风险，不是证明对方心中早有积怨，也不是让你为尚未发生的误会道歉。

末变地雷复，动侧震木当旺，直接克弱坤体，这是最重的限制，前中几处死土比和不足以承担这层制约。若近期真有一件约好的事，可照原来所谈的内容核定时间及双方意愿；候选木日也仅观察这件事是否遇到阻节，不是对方拒绝、来信或答应交往的日期。复的名字没有改变震克土的关系。

相处中的普通善意可以珍惜，却不必借它追问感情的答案。眼下若有适合的平常话题，只说你在那件实际小事上的感受，听到对方愿不愿意继续谈，再决定下一步；对方不想谈，也可以结束这一回。等相处确实松下来，而且对方有自己的参与，才重新考虑表达好感。表白与确定恋爱始终不是同一件事。

## 初六动 · 卯月

有一句话接不住，就别急着说更重的话

坤为地 → 坤为地 → 地雷复

有时候一句消息明明发过去了，却总要绕开其中真正想问的部分；若近来确有这类情形，眼下不宜把表白压在上面。卯月仍有互相接话的象意，但没有足够依据将它解释成对方喜欢你，近日自己来联络的迹象也偏弱。已有往来值得保留，是否要进一步则须另看实际意愿。

原体坤、本用坤，体互和用互皆同土，春木得令而土死，几处比和力量都薄。按照《人事占》体主用宾、兼考盛衰的办法，这说明有相处的共同点，却未必能负担更深入的话题；《婚姻占》比和的彼此相就也只支持双向承接。即使对方顺着你说下去，也不等于有一处来生体，更不能指定其一定先来联系。

「履霜，坚冰至」出自初六，《象》说「驯致其道，至坚冰也」，孔疏以积渐教人防微。放在暧昧中，小处渐积可能只是约时间时总碰不上，也可能是彼此对一个玩笑的理解不同；有没有发生，仍须由真实相处来判断。不能仅凭爻辞认定对方已有不满，更不宜为猜出来的事情去追问、责怪对方。

收尾震木在卯月旺而克坤，体弱而克者强，前中几处同气仍未提供直接生扶。若近期已有明确约定，可留意是否正好有一点没有取得双方同意的安排；所谓候选木日只指这个末段阻节，不排对方回绝或发来消息的时间。与其先预设谈话会坏，不如实际有问题时只解决问题本身。

暂时把感情留在自己的感受上，不需要借一场正式表白判明对方的想法。可以请对方说说某件实际小事怎样安排，不追问其是否因此不喜欢你；如果得到的答复是现在不方便，就尊重它。等普通往来重新形成双向力量、彼此都愿留下私下谈话的空间，再讨论表达的时机。即使日后表达，也应听其真实回答，而非视为关系已定。

## 初六动 · 辰月

先把小小的分歧说透，再谈心意

坤为地 → 坤为地 → 地雷复

先缓一缓正式表白，不是因为你们没有来往的余地，而是现有往来尚有值得维护的部分。辰月同气旺，传统上较能互相照应，也留有近期续联的机会，发起者却并不明确。若对方平素愿与你谈日常、讨论共同安排，这是可以确认的互动；至于是否有恋爱的好感，还要听本人怎样表达，不能用一来一往的次数推定。

## 初六动 · 巳月

能商量的地方先商量，不催定义关系

坤为地 → 坤为地 → 地雷复

这时适合把正在相处的事谈清楚，正式表白先缓一缓。巳月两边并非没有接近的余地，若彼此常有共同话题，近期可以有自然接续，不过还不能指出一定由对方主动发来消息。卦里可取的只是相处较有承接这一面，真实喜欢与否，须结合本人明确的话和愿意参与的行为来看。

此局原体坤土相，本用坤及体互、用互先后同相，比和各自成立；夏火旺而土得相，盘里没有离火节点直接生体，不能将月令的旺火想成一个额外助力。《婚姻占》对古代婚事取体用比和为彼此相就，迁到现代只能说明往来较易相接，不能保证表白成功。当前两个人较能商量，并不表示谁已经准备好恋爱。

真正值得维护的是两个人都仍愿在自己的范围内接触。对方说不方便时，可以接受，不必在同一次话题里再追加感情问题；自己感到不适，也可依实际情况调整联系节奏。等彼此更加从容且有不依赖某件事务的自愿互动，再考虑怎样告诉对方你的感受。那是表达自己，不是要求对方交出同样的感情，更不是一种决定关系成立的方法。

## 初六动 · 丑月

相处有余地，告白不必赶在前面

坤为地 → 坤为地 → 地雷复

先把表白放在需要商量的日常事情之后，这样更合丑月这份前中承接较好的卦意。两人有机会在实际相处中互相照应，也有近期续联的余地，只不过并不能从比和判定谁会先来。对方愿帮一个忙、愿就共同事情接着聊，已经是可以承认的事实；是不是喜欢你、是否愿意恋爱则是另一层意思，不能提前归在这些事实名下。

四处坤土同旺，原体指你在相处中的立足条件，本用与两互各对原体比和。《人事占》主宾与互变、盛衰的次序让相接有其基础；《婚姻占》比和为彼此相就，是古代论婚中的方向，现代只取互相承接。盘中没有直接生土的经卦，同气再多也不代表定有一方来给予接近或消息。

初六「履霜，坚冰至」，王弼说阴道从卑弱而后积著，孔疏说「防渐虑微，慎终于始」。这不说明你们已经有很严重的矛盾，只提醒有力气时宜察小处。如果相约多次都因同一个问题没有落实，可以邀请对方说明实际情况，自己的想法也可说出来，但不要求对方为这种不合适表明感情态度。

末震木丑月囚，克旺坤的作用弱而未消。原体强、比和厚支持平常照应，初六的警戒却限制正式表意的时机。若真实存在曾谈过的共同小麻烦，土气候选参考用互旺坤同气的中途协商；只有双方确有一件可商量的事项才有这样的日级意义，不能将它说成对方必发消息或者需要在那时表白。

现阶段更应让普通相处不背负必须改变关系的任务。愿意分担什么，尽可以平实商定，不超过彼此接受的范围；当双方在事情办完之后也自然愿意有私人接触，再考虑是否真到表达喜欢的时候。若届时表达，应留出对方接受、拒绝或者需要时间的空间。喜欢的表达不要求马上确定关系，实际关系还须由两个人都愿意来完成。
