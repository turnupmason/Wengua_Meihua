## 初六动 · 寅月

等原来共同的话题过去，再看两个人是否还想联系

风地观 → 山地剥 → 风雷益

有些时候对方很愿意接着你的话聊，比如你提出某件事情，他就谈自己的想法，这只能说明你们在这件事上已有一定接触。寅月风地观初六眼下正式表白宜缓，可先照实表达具体的欣赏。卦有后段交流接续的可能，近期也有对方自行来一句问候的机会，但不定谁先开口；真正心意仍须对方本人说明。

静上巽木取原体，在寅月旺，下坤土为本用，在春死，由原体去克，开局较有能力主动找实际共同话题。体互艮、用互坤同为死土，各受原巽克制，中间由你料理接触条件较易，却并非他方直接来生扶。倘若多数是你先开启谈话，对方愿意接，也只能照当次实际接应认识，不作他主动另起联络的证据。

初六「童观，小人无咎，君子吝」，王弼以初六处观时而离上所见甚远、阴柔不能自进，故所鉴如童稚，孔疏亦说趣在顺从、无所能为，君子如此则鄙吝。现代只取所见尚浅不足以作全面决定，不以童、小人等古辞评价对方心智或品德，也不让一方通过表白求取对方现在必须给出感情答案。

末变风雷益，下震木寅月旺，和原体比和，尾段有双方在交流上自然相接的较强条件，并非外方直接生体。末旺木的寅卯木日候选仅参实际从原来共同话题转到各自问候，可能有一句非为正事的联系，不能指定由谁发起或推对方会接受感情，更不把候选当恋爱成立的时间。

原先共同关心的事情聊完，若双方还愿意相互问候，可以接着自然了解彼此的真实生活，留意对方自己会不会想起上次谈过的事。等真实的私人来往有持续双向投入以后，再考虑正式说喜欢。表达好感是个人选择，确立恋爱关系必须两个当事人明确且自愿地共同同意。

## 初六动 · 卯月

聊得来是一件好事，真正的感情还须更多实际相处

风地观 → 山地剥 → 风雷益

若你发现自己每次提出一个共同话题时，对方都能说上几句，也许你们确实有一些相近的兴趣，却未必已经在私下相处中有了更深的了解。卯月风地观初六宜先说真实欣赏，正式表白仍须稍缓。传统取象后段可有更对等的接话，近日对方主动问候的机会也可留意，不过谁先仍看实际，不能由卦替本人说明心意。

上巽木是静原体，在卯月旺，下坤土本用死，被原体克制，起头自己寻找共同的交流内容较有能力。体互艮土、用互坤土也都处春死，由旺木克之较容易，过程中真实相处的具体条件可料理。但三个土都是体克用，不是外方来生体；自己愿意起头、对方愿意参与不能算成对方也已自行来发起下一次联系。

「童观，小人无咎，君子吝」，王注初六位距朝美最远、柔弱不能自进，所以无所鉴见；孔疏说如童稚之观，重于顺从而不能广鉴，小人行之仅无咎，君子则鄙吝。古辞中的身份、行为评语不用于现代两人的身份高低，借其提醒目前所见有限，不以几回轻松谈话为充分恋爱依据。

末变风雷益，下震木与原体同在旺地，体用同气，后段有双方较自然接起话题的条件。取末旺震同原体比和的木气候选，参真实往来能否由原本共同的事情转到彼此平常的问候，例如实际出现一句无关正事的消息。它不保证由对方先来，更不作为表白接受日期，初六浅见的限制仍在。

有双方都想继续聊的事情，可以在对方也乐意的范围里多听一些实际生活的想法，而不反复找话题测试他喜不喜欢你。若日后两边都曾自己想起而主动联系，实际私人相处逐步建立，再郑重表达喜欢；恋爱关系与一方个人表意必须分别看，双方各自明确同意才能确定。

## 初六动 · 辰月

正事聊完以后，还要看看两人有没有真实的私人往来

风地观 → 山地剥 → 风雷益

如果你们平常联络不少，但多数还是因为共同要办的事情才发消息，辰月风地观初六当前不宜正式表白。卦里实际能够深入了解彼此的接触条件不足，不能由聊天次数判断对方真正的感情。近期即使有对方自己来联系的机会，也更可能围绕已经有的具体事情，不一定是自主增加私人交往；其真实来意应当由本人说明。

静上巽木为原体，辰月囚，下坤土本用旺，由原巽克制，但囚木难制旺土，开局要从共同事务转出时间接触未必容易。体互艮、用互坤同为土月旺土，也都是原体所克，中间很多事情仍需投入心力办理。这不等于土来克木，也不是对方直接来生体；一个人能按时回应事务，不足说明有私人主动意愿。

初六「童观，小人无咎，君子吝」，王弼讲初六离朝美最远、柔弱而无所鉴见，只能如童稚之观；孔颖达说小人如此无咎而君子如此为鄙吝。今天只取在目前相处中看到的部分还浅，不把古人的身份词给任何一个现代人定性，也不觉得因为正事上互相照应就必须在感情中给对方肯定答复。

末变风雷益，下震木辰月囚，与原体比和，后面还可能有普通交流接续，却承力有限，不能由此补足前中难制三旺土及私人了解不足的实际限制。四处关系不足给一个独立实际近事作日期依据，不取土气为他人的阻隔日期，也不由木同气指定对方何时主动找你。

原来需要一起处理的事情，可以按照双方同意的范围完成；忙完以后若他自己还愿意聊一些原本无须联系的事情，再看双方有无自然的私人交往。不要把感情问题加到一项已经很费心的事务上。等真实双向来往形成后再想表白，而成为恋人还须两个当事人的共同明确选择。

## 初六动 · 巳月

话题可以自然接下去，不必立刻转到表白

风地观 → 山地剥 → 风雷益

可能每次你先在共同话题上开口时，对方都愿意聊一会儿，却鲜少见他自己另起关于个人生活的谈话。巳月风地观初六更适合让这种普通相处自然延续，正式表白宜缓，有真实欣赏可以轻说。卦里虽有后段彼此接应的余地，但对方真实心意仍须本人说明，近期可能有随手的问候，主动找你聊私事的倾向尚淡。

静上巽木作原体，在巳月休，下坤土本用相，由巽去克，开局想主动换成自己感兴趣的话题并不一定顺利。体互艮、用互坤同为夏相土，由原木克制，过程中见面安排等实际条件仍会占用不少余力。这些不是外来生体，自己愿意多聊几句与对方也会主动安排接触须按各自事实判断。

「童观，小人无咎，君子吝」，王注初六在观时距上美远，柔而不能自进，所观如童稚，孔疏说趣在顺从、尚无广鉴，所以小人无咎而君子有吝。今日只取了解仍有限的意思，不以童观断定对方幼稚或怀有什么动机，也不觉得表白可以一并让两个人知道彼此尚未真正谈过的感受。

末变风雷益，下震木巳月休，与原体比和，尾段能够有一些普通话题的自然接续，却不是另一边直接来生体，力量亦不足指向确切的主动来意。中前三相土受克仍难处理，末木同休，当前无具体能取为日期的独立事件，不能规定对方哪天会来找你或你该表白。

一件共同的话题聊完，让交流自然告一段落也可以，不必把沉默都看成关系变差。如果对方后来自己想起什么、愿意重新联系，在双方都自在的范围里继续认识彼此。正式表白等实际双向私人接触更充分再考虑；一个人愿意说明喜欢，不等于两个人共同确定恋爱，后者必须双方明确同意。

## 六二动 · 子月

风地观 → 山地剥 → 风水涣

## 六二动 · 丑月
