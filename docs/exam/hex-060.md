## 初九动 · 寅月、卯月

三种解法只留一种

水泽节 → 山雷颐 → 坎为水

简断

几道得把理由摆出来的题最耗时：一种解法写到一半又想换另一种，时间就从这里漏掉。能过，认准一条路写到底，其余的题照常推，卷面上的分攒得到线上。

开局：前两题几乎没有提示，题意得一个字一个字读出来，写得慢些，倒也没有哪里绊脚。

过程：真正吃时间的是后面几道讲理由的题。思路一多，这个办法写了半截，又觉得那个更漂亮，草稿纸上三种起头，哪一种都没收尾。题里那条必须满足的要求反倒好办，照着核一遍就过去了。

结局：哪条路走得通，就在哪条路上走到头，小象把初九守在户庭之内叫作「知通塞」。做到最后几题，用的仍旧是你手上最顺的那套写法，前后一个调子，写下的步骤都算得上分。

应期：以下为传统推算的参考窗口。
可留意本月13、25号前后，写理由题时又在三种办法之间换来换去，属耗应。草稿上起头的办法只留一个，其余当场划掉。

总断：草稿上起了头的办法，挑定一个，另外两个当场划掉，这一卷能过，三种解法只留一种。

限制多的那道，留到最后

水泽节 → 山雷颐 → 坎为水

简断

前几题没有能照抄的套路，要自己摸着写；卷中有一道限制条件一大串的题，看着吓人，逐条排开其实不难。能过，绕过它先把别的写完，再回头慢慢核，分数够得着线。

开局：第一页没有哪一道能直接套公式，题目都要多读一遍才敢动笔，速度提不起来。

过程：卷子腰上横着一道题，四五个限制摞在一起，像一扇关着的院门。它没那么硬：限制之间互相牵着，排成一列看，有两条说的其实是同一件事。难只难在一上来就啃它，越核越乱。

答对了，理由没写

水泽节 → 山雷颐 → 风泽中孚

简断

题不难，前后都做得顺，失分在那几道明写要说明理由的题上：赶进度时只写了判断，理由一句带过或干脆不写，判断对了，分只到手一半。几道一凑，总分差了一步。

开局：题型熟，前几道落笔快，没什么卡顿。

过程：卷中有一段材料，正好能拿来当后面一道题的理由，抄一句、接一句就够。其余几道要说明理由的题就没这么现成了，得自己组织。
