## 初六动 · 寅月、卯月

题干里那两个小字

火水未济 → 水火既济 → 火泽睽

简断

卷面上的题大多写得动，坑藏在题干的限定词里，两处看漏，上不了线。前面一道大题和中间一道综合题都带着「不超过」「仅限」这类小字，一看漏，整题方向就偏，回头重算要花双倍的时间。

开局：领头那道大题读起来顺，条件像是都给全了，真正管事的是句末那个限定范围的小词。

过程：写到第三、四题，同样的事又来一遍：限定躲在括号里，答案算得出来，却落在题目不许的区间。

结局：初六「濡其尾，吝」，刚下水尾巴就湿了，河渡不过去；小象怪它「亦不知极也」，没摸清边在哪儿。这一卷的边，就是那两处限定。末尾几道写得完，可前面推倒重算的两题已经吃掉了时间，分数补不回线上。

应期：以下为传统推算的参考窗口。
可留意本月22号前后，重做旧题时又漏看一个「仅限」，属凶应。重做一道答偏的旧题，圈出被越过的那项限制。

总断：每道题读完，先用笔把限定词圈出来，再动手算；两处限定一漏，分数就差着几分。

古籍依据：《周易·火水未济》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·体用》《梅花易数·占卜克应之诀》《梅花易数·八卦万物属类》《梅花易数·先天后天论》。

开局：前两页一路顺下来，草稿纸几乎还是白的。
