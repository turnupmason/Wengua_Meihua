## 初六动 · 寅月、卯月

最后一问点名要用的方法

雷水解 → 水火既济 → 雷泽归妹

简断

卷子大半是你顺手的题，落笔快，草稿也清爽。总分没够上线，只因为一处：最后一问指定了解法，你换成自己熟的那条路，答案没错，步骤那部分的分却拿不全，线就差在这几格上。前面那些顺手题，分都稳稳落袋。

开局：题型是你练得多的那几类，写起来几乎不停手。

过程：往后几题要在草稿上多推一两步，题目给的条件不算丰厚，多想一会儿也能写出来。

结局：压轴那问在题面上限定了解法，这是整卷唯一的一道硬限定，分值小，题也浅，难在它只认指定的那条路。你换了熟路，结论对，过程分那几格却空着。归妹讲的正是这种错位：东西没错，放的不是它该在的位置。初六只有「无咎」两个字，小象补了一句「刚柔之际」，两股劲交接的地方站稳了，不出错。大方向你没走错，可不出错不等于给分，这几分一丢，总分就停在了线的下沿。

应期：以下为传统推算的参考窗口。
可留意本月21、22号前后，前几道都是练熟的题型，一路写得顺，属吉应。顺的时候也看一眼题面，有没有点名要用哪种解法。

总断：压轴那问先看清它限定的是哪种解法，照它的路写，熟路的答案留在草稿上对一对。那几格过程分一空，总分差在线下，隔着的就是它们。

古籍依据：《周易·雷水解》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·体用》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。

一道想通的题写掉了半场

雷水解 → 水火既济 → 雷泽归妹

简断

想通一道难题，不等于写得完它，这张卷子就卡在这儿，还没到线。前半张写下的步骤照样给分。可时间全搭进了那道题，推导越写越长，卷末几题来不及动笔，空出来的比写上的还多。

开局：前面几题没什么能直接套的，题题要自己多想一层，进度偏慢。

过程：卡住你的那道题，写到一半终于想通了，麻烦接着就来：每一步都得写出从哪来，草稿翻过一页又一页，像灶膛里添了柴，越烧越旺，停不下手。这一题拿到的分不少，可它吞掉的时间，本该分给后面三四道你会做的题。

结局：交卷铃响时，最后几题还空着，那一块本身不难，只是没轮到你写。「无咎」应在写下的几步都没错，空着的几题却不是对错能算的。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，一道题想通以后越写越长，压住了后面的时间，属耗应。给每道题定个页数上限，写满一页还没收尾就先跳过。

总断：哪道题写过一页还没收尾，就先停笔，把空着的题过一遍再回来。卷末的空白全是时间造成的，分数因此落在线下。
