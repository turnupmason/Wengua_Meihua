## 初六动 · 寅月、卯月

最后一问点名要用的方法

雷水解 → 水火既济 → 雷泽归妹

简断

卷子大半是你顺手的题，落笔快，草稿也清爽。考不过，毛病只出在一处：最后一问指定了解法，你换成自己熟的那条路，答案没错，步骤那部分的分却拿不全，就差在这几分上。前面那些顺手题，分都稳稳落袋。

开局：题型是你练得多的那几类，写起来几乎不停手。

过程：往后几题要在草稿上多推一两步，题目给的条件不算丰厚，多想一会儿也能写出来。

结局：压轴那问在题面上限定了解法，这是整卷唯一的一道硬限定，分值小，题也浅，难在它只认指定的那条路。你换了熟路，结论对，过程分那几格却空着。归妹讲的正是这种错位：东西没错，放的不是它该在的位置。初六只有「无咎」两个字，小象说「刚柔之际」，你在这卷子上没走错大方向，可它并没许你分数，这几分一丢，总分就停在了线的下沿。

应期：以下为传统推算的参考窗口。
可留意本月21、22号前后，开头碰到一条能顺着做下去的熟悉线索，属吉应。近期若做练习，可留意哪类题一上手就能接上思路。

总断：过不了。压轴那问先看清它限定的是哪种解法，照它的路写，熟路的答案留在草稿上对一对。

一道想通的题写掉了半场

雷水解 → 水火既济 → 雷泽归妹

简断

想通一道难题，不等于写得完它。过不了，是时间全搭进了那道题：思路有了，落到纸上是一长串推导，越写越长，卷末几题来不及动笔，空着的分比那道题本身还多。前半张写下的步骤照样给分。

开局：前面几题没什么能直接套的，题题要自己多想一层，进度偏慢。

过程：卡住你的那道题，写到一半终于想通了，麻烦接着就来：每一步都得写出从哪来，草稿翻过一页又一页，像灶膛里添了柴，越烧越旺，停不下手。这一题拿到的分不少，可它吞掉的时间，本该分给后面三四道你会做的题。

结局：交卷铃响时，最后几题还空着，那一块本身不难，只是没轮到你写。「无咎」两个字管得住你不犯大错，管不到钟表。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，真正写完整原先卡住的一题需要较多工夫，属耗应。近期若有模拟，可检查哪部分展开后几乎没有增加得分。

总断：考不过，丢在时间上。哪道题写过一页还没收尾，就先停笔，把空着的题过一遍再回来。
