山地剥 → 坤为地 → 山雷颐

简断

卷面上的题大都眼熟，可每一道都得从定义写起，没有哪一步能直接套。前两页照公式代数的那些题拿得到分；总分差在卷尾分量最重的那道大题上，题干第二行夹着一个限制条件，一漏，后面几问顺着错的前提推下去，一问比一问远，分数也就够不到线。

开局：前两页多是照公式代数的题，步骤短，只是每个公式都得先想清它从哪来才敢用。

过程：再往后，每道题都要回到定义上起步，没有哪道能借上一道的结果。

结局：卷尾这道大题一翻过来就压人，题干占了小半页，四问层层相叠，全压在那个限制条件上。条件一漏，第一问的式子就站歪了，第二问、第三问照着它算，算得越细，离正确答案越远，等最后一问把矛盾摆出来，已经没有时间从底下重搭。「剥床以足」，床是从腿上削起的，小象说「以灭下也」，坏在最下面那一层，上面搭得再细也撑不住。

简断

卷子平平常常，哪道题都要一笔一笔写全了才给分，没引到那个数的题分照常拿。毛病出在第一问：题干里一个数誊错，后面几问全拿它来算，到卷尾核对才对不上，来不及一处处改回去，总分落在线下，后几问全顶着那个誊错的数。

开局：大半是见惯的题型，照平常的步骤一道道往下写。

过程：写到后面速度不快，好在没出新的岔子。

结局：卷尾那一问本身轻，三两行就能答完，可它要拿最终结果回头验第一问，一验就对不上。错的根子埋在最底下，上面每一问都是照着它盖的，方法都对，数却全跟着错，这就是「剥床以足」：床腿上削掉薄薄一层，整张床都歪。卷尾的关口不重，重的是要回头拆掉的那一摞。

山地剥 → 坤为地 → 山雷颐

简断

基本功派上了用场，前后几问接得严，大半张卷子写得扎实，那几问分落得实。压卷那道大题直接搬了一个记熟的结论来用，没写它从哪来，评分要的恰恰是推出这个结论的那几步，搬来的结论不给分，大半分值就空了，总分落在线下，结论搬来没推。

结局：顶上这颗大果子，是整张卷子里分数最多的一道。上九这句爻辞一头是车，一头是剥掉的屋顶：踏踏实实推出来的，有车载着，走得稳；取巧借来的那一句，像把自家屋顶也剥了，到头来没有遮挡，小象说「终不可用也」。那道题用了一个背熟的结论，这结论不假，可题目考的正是它怎么来，搬来的那一句在评分表上站不住，最重的分空了一大半。
