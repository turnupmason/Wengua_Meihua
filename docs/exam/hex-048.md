## 初六动 · 寅月、卯月

半页草稿陷在老路上

水风井 → 火泽睽 → 水天需

简断

卷子换了考法，头一道大题却眼熟，提笔就照最熟的老步骤推，推出大半页才看出题目要的是另一回事。前半卷的时间陷在这半页里，后面一路追赶，离合格线还差的，正是这半页吃掉的那些分。

开局：题面上的图和条件都眼熟，像做过好几遍的那一类，笔一落就顺着老路推，推到第三步，算出的东西和设问对不上，回头再看，半页草稿只能划掉。

过程：再往后，每道题都先把条件和问法对一遍才敢下笔，对得清楚，就是一题比一题慢，表上的时间始终追不回来。

结局：卷尾几道小题照公式代数就有分，填不满前头那个坑。初六「井泥不食」，小象只说「下也」：泥淤在井底，打上来的是泥，不是水。这一卷淤在底下的，就是卷首那半页老写法，它不出分，还把后面的时间压住了。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，练题时又顺手套上那套老步骤，属耗应。每道题动笔前先说出它问什么，再决定用哪套步骤。

总断：老步骤写两步对不上题意就停，照题目给的条件重起一行；卷尾那几道套公式的小题留出时间写完。卷首那半页拖着，这一回还没到线。

简断

开局：概念题照旧笔记的路子答，题浅，一会儿就写过去了。

过程：写到卷子正中，两道大题把分量一下子压上来：材料长，问法活，题干不提用哪种方法。材料里每个词都认得，下手的角度却找不着，换了两种写法，都在第二步停住。

结局：卷末几问写得完，分是零碎的，填不回卷子中央那两道的空。「旧井无禽」，旧井连鸟都不来落脚，小象叫它「时舍」，被时候撂下了。那几本笔记整理得再细，这一卷的出题方向已经从旁边走过去。

旧格式交出去，评分点空着

水风井 → 火泽睽 → 水天需

简断

卷子写得顺，时间也够，偏偏用的还是旧版那一套答法：结论都对，评分新加的那条要求，每一步写出凭什么，却一处也没照做。每道大题被扣一点，合起来，总分差在线下几分。

开局：熟题一道接一道，只在头一道大题上照老格式多写了一段，前半卷几乎没停过笔。

过程：几道跟练过的很像，问法拧了半圈，略一想就转过来，难处一处也没卡住。

结局：麻烦不在难，在对不上号。新标准要每一步说出凭什么，旧答法只交结论，阅卷照点给分，一道扣一点，扣到最后刚好落在线下。「旧井无禽」，小象说「时舍也」：这口井没塌，是淤旧了，被时候撂在一边。卷上写得不少，评分要看的那几处恰好空着。

总断：大题照新要求，每一步跟上半句依据，哪怕只写「由题设」三个字；基础题照常写。差在线下那几分，全出在格式上。
