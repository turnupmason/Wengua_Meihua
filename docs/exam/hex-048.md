## 初六动 · 寅月、卯月

老步骤陷住了前半卷

水风井 → 火泽睽 → 水天需

简断

考不过。卷子换了考法，你最熟的那套老步骤一上手就用，写出去大半页才发现题目要的不是这个，前半卷的时间就陷在这里。后面理条件跟着慢，能保住的是卷尾几道照公式直接算的小题。

开局：头一道大题眼熟得很，提笔就照老路子推，推到第三步才发觉方向不对，回头重来，半页草稿作废。

过程：再往后，每道题都得把条件对一遍才敢落笔，对得清，就是一题比一题慢。

结局：卷尾几道小题只要套公式，代进去就有分，可这点分填不满前面那个坑。「井泥不食」，小象只两个字「下也」：泥沉在最底下，上面的水再清也打不起来。这一卷沉在底下的，正是卷首那半页老写法，后面收得再好，总分也浮不到线上。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，开头在一种已不合用的老做法上花去较多工夫，属耗应。近期若做模拟，可检查哪条旧步骤最早应当换掉。

总断：卷面上够不上。考场上给老步骤立条规矩：写两步对不上题意就停，按题目给的条件另起，卷尾那几道小题的分留得住。

水是满的，没人来打

简断

卷子写得顺，时间也够，可还是合格不了。这一卷的评分要点换了，你沿用的是旧版的答法：结论都对，却没按新要求交代依据和步骤，每道大题都少几分，合起来就差在线下。基础题的分一分不少。

开局：熟题一道接一道，只在头一道大题上照老格式多写了一段，前半卷几乎没停过笔。

过程：再往后有几道题跟练过的很像，问法拧了半圈，稍一想就转过来了，难点没有一处真卡住。

结局：麻烦不在难，在对不上号。新标准要每一步写出凭什么，旧答法只交结论，阅卷时一道题扣一点，扣到最后刚好落在线下。「井泥不食，旧井无禽」：井里不是没水，是这口井已经没人来打水了。卷面上写的东西不少，评分看的那几处恰好空着。
