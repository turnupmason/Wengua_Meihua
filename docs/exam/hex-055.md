## 初九动 · 寅月、卯月

两页答卷换几行分

雷火丰 → 泽风大过 → 雷山小过

简断

这张卷子考到的，恰好是下功夫最多的内容，下笔不缺话说。前几道大题问得宽，写得满满当当，阅卷只认其中几行，篇幅越长后面越挤，两页答卷换回来的分，离线还差那么几分。

开局：打头那道大题口子开得很宽，像是邀你把会的全倒出来。你也倒得出来，两页纸写满，真正落在得分点上的只有几行。

过程：再往后一道题设了个限制，绕开它要多想一下，好在不硬；熟悉的路子换个条件还是走得通，这几题写得稳当。

结局：收尾那道题分量轻，要你做的不多，难处早就不在这里了。王弼解「虽旬无咎」，说旬就是均，两相匹配就没有过错；小象补一句「过旬灾也」，过了这个均就出事。这一卷的亏，正亏在前面写超了分寸，篇幅没换回分数，后面的稳当补不满这个缺。

应期：以下为传统推算的参考窗口。
可留意本月14、15号前后，换了条件的题，熟法照样接得上，属吉应。挑一道能用旧方法变通的题，练接到新条件上。

总断：宽题按得分点分条写，写够就停笔，中间用熟的那几题稳稳拿住。这一回还差几分，差在前面写超了分寸。

一条限制把熟路拦腰截断

雷火丰 → 泽风大过 → 雷山小过

简断

这套卷子专挑少练的那类题出。中途那道题加了一条硬限制，平常那套做法套上去只走得到一半，剩下一半没有别的路可换，这道题分量压得重，前面一路攒下的分顶不上去，总分还差一截，那条限制把熟路拦腰截断。

开局：前头几题要先把散开的条件拢到一处，才知道从哪下手，这一拢就比平常慢了一截。

过程：真正拦住你的是后面那道带限制的题。题干明说某种做法不许用，或者某个量只能取在一个范围里，你最熟的那条路恰好被这一条截断。熟法套上去走到一半就停，换一种走法，又没练过。这道题分值重，丢了它，前面攒的分撑不到线上。

结局：最后几题倒不吓人，能处理一部分。初九讲「遇其配主」，两边相称，往前走才有「尚」；这一卷那条限制比手里的办法硬得多，两边不相当，往前硬拼也换不来那个「尚」。

总断：碰到那条限制，先把它抄在题旁，能用的步骤写出来，不硬套旧法。这一回离那条线差的，就是被截断的那半条路。
