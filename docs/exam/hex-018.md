## 初六动 · 寅月、卯月

题干多给的那个限制

山风蛊 → 雷泽归妹 → 山天大畜

简断

头一个大题多给了一个限制条件，你平常那套解法偏偏没把它算进去，后面几题又顺着这套解法写下去。考不过，题本身不刁，可整张卷子都落在你最少碰的那一片，找不到一道能借力的题。补上那个限制后改过的几问，分拿得回来。

开局：第一道大题读到一半就会察觉，题干里多出一个限制，旧解法从来没用到过它。

过程：后面几题沿着同一套思路，凡是漏了这个限制的步骤，都得拆开重算。单拿哪一题出来都不刁，难受的是没有一道长成你写惯的样子，每一题都要从头摸。

结局：前人留下的旧账有儿子肯接手收拾，前人就落不下过错，过程有险，终了是吉，这是「干父之蛊，有子考，无咎；厉终吉」。辞是吉的，可这一盘里哪道题都垫不了脚，吉只落在你回头补上限制条件的那几问，铺不满整张卷子。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，开卷发现旧做法没处理题目给出的条件，属凶应。近期若做模拟，可回看最早不成立的一步。

总断：过不了线。先把第一题那个限制补进去，顺着它改对的几问，分是实的。

山风蛊 → 雷泽归妹 → 山天大畜

简断

卷子上找不出送分的题，每道题的问法都和你练的差半步，得先翻成熟悉的样子才好下笔。合格线够不上，路上的坎都不高，你也一处处应付下来了，可整张卷子跟你的路数是拧着的，攒到最后还在线下。订正过的步骤，分保得住。

开局：问法总比你练的偏半步，先要在草稿上把题意改写一遍，才认得出它考什么。

过程：这一步不难，费的是工夫，越往后翻得越快，压力并不大。

结局：末尾订正一处后要连带补几步，量不多，写得完。子承父事，「厉终吉」，先险后吉，吉辞落到的是你改对的那些步骤；卷子整体逆着你的路数，哪道题都不顺手白给，零零碎碎凑起来仍差一截。

改得对，写不完

山风蛊 → 雷泽归妹 → 山天大畜

简断

错你找得到，也改得对，输在时间上。过不了，改一处就要把后面连着的结果全部重算重抄，到最后一道大题还得把修正后的过程从头誊一遍，笔赶不上钟。已经改对并写完的题，分都算数。

开局：头两道题顺，下笔照常。

过程：麻烦从第一处改动起：一个数换了，后面几问的结果全要跟着换，每换一处又得重抄一遍。全卷最吃钟点的就是这一段。

结局：压轴那题要把修正后的整套过程写完整，写到一半，剩下的时间已经见底。「厉终吉」是吉辞，干蛊的人肯动手，终归有好结果；这一盘消耗太大，吉只照到改完的地方，没写完的那一截拿不到分。
