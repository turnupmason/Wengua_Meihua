题面点名要的那一条

天水讼 → 风火家人 → 天泽履

简断

卷子正中有道题点名要一条依据，你备好的答案偏偏缺这一条，这一次的总分落在线下。前几题照准备的写得出来，卷尾也照平时的水平收住，两头的分都在；只是中间那道想补又补不圆，只拿到零碎几分。

开局：读题比平常慢些，答案倒是现成的，前几题顺着准备好的路子写下去。

过程：卷子中部那道题明写了要说明依据，而这一条你从没准备过。原来的答法舍不得丢，新的一条又写不圆，两头拉扯，自己排好的先后顺序也给打乱了。

结局：这道题本不值得耗那么久。初六「不永所事」，小象说「讼不可长也」：跟一道题较上劲，越拖越亏。「小有言，终吉」，有几句说不清的话，讲明白也就过去了，这道题上该做的，是把能说清的那一层写两句，收笔。可它挡在卷子正中，分值又实，收笔保住的只是后面的时间，前面丢的那一块，没有别的题补得回来。

总断：那道点名要依据的题，能说明的写一两句就停手，把时间让给后面，这一回仍没够上线。

## 初六动 · 巳月、午月

一条门槛连着整道题

天水讼 → 风火家人 → 天泽履

简断

卷子中间那道占分最多的大题设了一道门槛：某一项没写明，后面的步骤一概不给分，你写到一半才看见，前面大段内容全悬了空，离合格还差一截。别的题照常写，前面拿到的分都还在；发现门槛时先补那一项，补不上就去写能单独计分的小问。

开局：题量不小，卷子一发下来就得赶着写，前几题写得匆忙。

过程：到了那道重题，题干第一行就立了规矩，你却是写满半页之后才回头看见。它是全卷最重的一道，也是最不肯通融的一道，一处没满足，整片分跟着落空。

结局：「讼不可长也」，初六小象这一句，是这一卷最该守的：守住「不长」，门槛那一项补得上就补，补不上，立刻离开这道题，别再往悬空的步骤上添字。分值最重的一道落了空，卷尾又没有哪道能把分找回来，这一爻许下的「终吉」，在这里至多是没让这一道把后面的题一起拖下水。

总断：门槛那一项先补，补不出就去写别的小问，那里的分单独算；这一卷还没到线，缺口正是那道大题悬空的一大块。

## 初六动 · 申月、酉月

字写出去了，分没跟回来

天水讼 → 风火家人 → 天泽履

简断

题都在会写的范围里，中部那条附加要求一句话就答对，卷尾也写得稳。毛病出在前半张，分数离线还差几步路：那几道论述题写得又长又满，阅卷只按要点给分，写过头的那些字白搭了时间。

开局：题一到手你就有话可说，前几道一写就是大半页，越写越顺。

过程：中部那条附加要求只多问一句理由，一句话就答完。真正吃掉时间的还是前面那几道，每道都写过了头。

结局：「不永所事」，事情别拖长。这一卷拖长的不是争执，是笔下的字：每道论述都写成了一篇辩护词，该说的三点说完，又补上五点。「小有言」，话本该少，小象说「其辩明也」，辩明就够了。卷尾那几道写得稳稳当当，可整张卷子找不到一处白给的分，前面淌掉的工夫补不回来，到线还差几分。

可留意本月15、16号前后，论述题又写过了头，附加那一问差点没顾上，属凶应。每道论述写完数一数要点，够了就翻页，附加那句理由别漏。

总断：前几道论述点到要点就停，腾出来的时间正是差的那几分；照眼下的写法，分数还落在线下。
