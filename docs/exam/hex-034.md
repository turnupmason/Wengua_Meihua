## 初九动 · 寅月、卯月

底子足，开头别急着往前冲

雷天大壮 → 泽天夬 → 雷风恒

简断

你精力足，题目压过来的分量也不重，只是从头到尾没人能帮你一把，每一分都得自己挣，这次过线难。最怕一上来凭感觉往下写，写到一半才发现条件没看全。收尾还有力气整理，开头宁可慢半拍，把题读准。

开局：一开场你手感不错，题目给的约束不算紧，你应付得来。正因为顺手，最容易在第一步就跳过核对。

过程：到了中间，得自己把条件一条条对上，这里会停下来想一阵。真正落笔时，又会冒出一两项非满足不可的要求，只能逐项处理。

结局：初九说壮在脚趾，往前走就凶。力气花在起步抢快上，后面就得回头补。最后一段你还有余力把卷面理一理，改掉几处匆忙写下的地方，可前面漏掉的关键依据，很难全部找回来。

应期：以下为传统推算的参考窗口。
可留意本月18、19号前后，中段落笔时被一项没核清的要求拖住，属凶应。近期若做整卷，可核第一次下笔前有没有确认适用条件。

总断：这次难过线。考场上开头宁可慢几分钟，第一个条件核清楚再往下写；考后把读题核条件这一步单独练熟，留给下一回。

开头那几项约束你扛得住，碰上复杂的设问也有余力回头查，可这场还是难过线。最容易失手的是一读完题就照老套路写，写深了才发现少了一项条件。最后还能改回一两处，所以下笔前先确认条件对得上。

开局：开头有几项条件要照顾，你接得住，这一段不必慌。

过程：中间自己核题要花些工夫，作答时的限制也在，好在可以一项项办，不会一下子压垮你。
