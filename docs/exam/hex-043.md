## 初九动 · 寅月、卯月

翻到最后一页先啃大题

泽天夬 → 乾为天 → 泽风大过

简断

卷子一发下来，你先翻到末页，去啃最压秤的那道大题，时间赔进去一大截，总分落到线下，先啃大题啃掉了前面的分。那道题枝节多，一问牵着一问，手里那套写法只破得开头一层。掉头回来再写前头的熟题，几道都答得齐整，只是剩的时间已经不宽。

开局：卷子前半是认得的题型，按顺序写，本来稳当。

过程：你没从第一题写起，坐下就翻到卷尾，想趁手热先把最重的那道拿下。

结局：那道题像大过卦里压弯的房梁，枝枝杈杈全挂在一根主线上：第一问写出来，第二问要拿它的结果再变一次形，第三问又分出两种情形。题的分量正足，手里的写法只够破开头一层。「壮于前趾，往不胜为咎」，劲都使在脚尖，冲出去胜不了，过错就出在这一冲。等你掉头去写熟题，时间已经短了一截。

应期：此盘暂无有据的日期可列。

总断：按题号从前往后写，末页那题写完第一问就收手。这一回先冲后赔，总分够不上线。

古籍依据：《周易·泽天夬》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。

## 初九动 · 亥月、子月

一环扣一环的最后一题

泽天夬 → 乾为天 → 泽风大过

简断

压轴的综合题几问连成一串，下一问得拿上一问的答数往下算，第一问你推得出，第二问接不上，后面几问跟着落空，链子一断，总分便够不上那条线。前面的题步子慢，却一道道写稳了。

开局：平常的步子一点没乱，稳，就是快不起来。

过程：写到卷尾，剩下的时间只够在那道综合题上硬拼一阵。

结局：那道题几问连成一串，题本身有分量，每一问都踩在前一问的答数上。第一问你推出来了，第二问要换个角度用它，你在这里试了几种写法都没接上，后面几问也就没了着落。初九的「往不胜」是去了却拿不下，这里正是这个样子：冲上去了，链子在第二环断开。

应期：以下为传统推算的参考窗口。
可留意本月18、19号前后，练综合题时，第一问的结果写得干净完整，属吉应。综合题第一问的答数单独誊清，后面几问都从它起算。

总断：那道综合题第一问的结果先写清楚，别为后面几问把它涂掉。链子断在第二环，总分就差在这一环上，没够上线。
