## 初九动 · 寅月、卯月

前三问连成一串

泽火革 → 天风姤 → 泽山咸

简断

能过，这份过是一点点磨出来的：卷首那串连环小问，头一问的得数要带进第二问，再带进第三问，越往下越吃紧。卷尾几道单独成题的基础题能把分一点点捡回来，总分慢慢挨到线上。

开局：卷首三问绑在一起出，上一问的得数，就是下一问的起点。这类连环题你练得不多，第一环得慢慢核，核准了再往下走。

过程：随后几道大题篇幅都长，条件给得密，一题要读两遍才下得了笔，分数在这里是一分一分挣出来的。

结局：到了最后几页，题目反倒短了，都是各管各的老题型，写过不止一遍。黄牛皮又韧又紧，「巩用黄牛之革」就是拿它把东西捆牢，小象补一句「不可以有为也」，眼下不是翻新的时候。前面那串小问磕磕绊绊，难免想换个巧法重算，这一卦偏叫你别动：老办法慢，可它一步一步走得到头，卷尾那几道题也靠它收进分来。

应期：以下为传统推算的参考窗口。
可留意本月11、14号前后，卷尾几道基础题能印证旧办法仍然可用，属吉应。近期若做练习，可查哪一处变化真的需要另选做法。

总断：能过，过得慢。连环小问宁可多核一遍，也别半路另起一套算式。

泽火革 → 天风姤 → 泽山咸

简断

能过，过得也省力。卷首两道题分量实，写完要比预计多花几分钟，不过都在你练过的范围里。要留神的是中间那道有两种解法的题：熟悉的那条长一点，另一条看着巧，走到一半常常卡住，走熟的那条就行。

开局：前面两题题干长、条件多，一眼望不到底，耐着性子写，步骤都是熟的。

过程：再往后一路好走，大半是闭着眼也会的路数，时间宽裕下来。

结局：关口在那道两种解法都能走的题。巧法步数少，可它要先认出一个隐蔽的条件，认错一步就全盘落空；老解法多写半页，每一步都有着落。皮条捆紧了不松，「巩用黄牛之革」，秋天这一盘根底正硬，用不着冒险。小象说「不可以有为也」，这里的不为，就是不去试那条没走过的捷径。卷尾几题还能顺手添几分。
