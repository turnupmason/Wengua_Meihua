## 初六动 · 寅月、卯月

顺风飞到最后一题

雷山小过 → 泽风大过 → 雷火丰

简断

前面几题快得出乎意料，练熟的路子题题对得上。总分却停在线下，症结在压轴那道：一步没有依据就往下推，越写越长，推到时间用光也没落到结论上。

开局：熟面孔占了前面几道，算得快，草稿纸也用得少。

过程：再往后有一处限定条件要回头对一下，挡一下就过去了，熟悉的解法照样接得上。

结局：正因为一路顺风，到了压轴题就收不住。那一问要先立一个前提，前提还没站稳，笔已经往高处推，推出一页又一页，每一步都悬着。「飞鸟以凶」，鸟往上飞，脚下没有可落的枝；小象说「不可如何也」，飞到那一步，再想回头已来不及。前面省下的时间，全填进了这一题。

应期：以下为传统推算的参考窗口。

总断：到最后一题，先把前提写在第一行，前提立不住就换一条路，不硬推；离线还差几分，就差在压轴那一页的前提上。

一条标准卡住半张卷

雷山小过 → 泽风大过 → 雷火丰

简断

整张卷的中间立着一条很严的评分标准，每一步都要合它的规矩，平时惯用的做法正好不合，写了一大段也算不进分，离合格线还差着好几步。前面几题和最后的补写都不重。

开局：题量不大，题面也直白，前几道照着步骤走就写完了。

过程：难处集中在中间那两道：题目先定了一条标准，答案必须逐步照它来，差一个环节，整步不给分。你熟的那套做法在这里偏偏走不通，换成它要的写法，又练得少，只能边想边写，写出来的东西大都落在标准外面。

结局：后面补写几句就收尾了，花不了多少力气。「飞鸟以凶」，鸟往高处冲，落不下脚；这一卷的落脚处就是那条标准，没踩上去，后面写得再整齐也补不回来。

应期：以下为传统推算的参考窗口。
可留意本月19号前后，重做旧题时一步又没合上评分标准，属凶应。重做一题，把当初跳过的那条标准逐步对上。

总断：答到中间那两道，先把标准抄在草稿上，每写一步对一次；坎就在那里，这回分数没上线。
