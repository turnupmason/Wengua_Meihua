雷山小过 → 泽风大过 → 雷火丰

简断

开头推进得动，熟悉的办法也能用上，中间那项要求挡得不算硬。麻烦在整场没有外力帮你，一旦写散了只能自己拉回来，这次难合格。每写完一个判断就回看题目问的是什么，别一路顺着往远处写。

开局：起手的难处你处理得来，题目里的具体问题能一个个拆开。
