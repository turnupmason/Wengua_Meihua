顺风飞到最后一题

简断

开局：前几道全是熟面孔，算得快，草稿纸也用得少。

过程：再往后有一处限定条件要回头对一下，挡一下就过去了，熟悉的解法照样接得上。

结局：正因为一路顺风，到了压轴题就收不住。那一问要先立一个前提，前提还没站稳，笔已经往高处推，推出一页又一页，每一步都悬着。「飞鸟以凶」，鸟往上飞，脚下没有可落的枝；小象说「不可如何也」，飞到那一步，再想回头已来不及。前面省下的时间，全填进了这一题。

应期：以下为传统推算的参考窗口。

雷山小过 → 泽风大过 → 雷火丰

简断

题都不难，偏偏考不过，病在一个「远」字：思路顺，一路往外推，写到后来答的已不是题目问的那件事，字写了一大片，真正踩在得分点上的没几句。头几题答得准，那几题的分稳稳在手。

开局：头几道问得直接，拆得开，答案也短。

过程：往后有一处条件会随前一问变动，要停下来重看一遍，费不了多少事。

结局：问题出在最顺的时候。笔下越顺越不肯停，一个判断引出另一个判断，像鸟乘着风越飞越高，回头已看不见出发的那棵树。「飞鸟以凶」，凶不在飞，在飞离了该落的地方。题目只问了一件事，你答了三件，阅卷只认那一件，剩下的篇幅白写。

总断：分都散在离题的篇幅里，总分够不上。每答完一段，看一眼题干那句问话，再决定写不写下一段。

唯一的生面孔

雷山小过 → 泽风大过 → 雷风恒

简断

前后两头都是练熟的题型，答起来干净。过不了，只差中间那一道：它的要求扣得死，题型也生，熟悉的解法套上去只对一半，这一道丢掉的分正好让总分差在线下。前后两头的分不会少。

开局：前几题一眼就看得出该怎么写，步骤也记得清楚。

过程：只有夹在中间那道不同。题面不长，要求却一条条扣得很死，问法也不是常练的那几种，惯用的解法只接得上前半截，后半截得自己现搭。整张卷子的胜负就压在这一道上，它答不全，别处写得再干净也补不上来。

结局：最后几题又回到熟路，写得稳，交上去不出错。「过其祖，遇其妣；不及其君，遇其臣，无咎」，到了该止的位置就止，不越分，所以无咎；可无咎只是不犯错，算不上有所得，中间那道丢的分它补不回。
