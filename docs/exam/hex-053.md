## 初六动 · 寅月、卯月

写满两页，踩中的给分点没几个

风山渐 → 火水未济 → 风火家人

简断

前面几题条件直白，提笔就有，卷上硬骨头不多。最后几道说明题把分数压在线下：一落笔就铺成一大段，给分点只认几个关键词，纸写满了，踩中的没几个。

开局：头几道题把条件摆得很直白，几乎不绕弯，读完就知道写什么。

过程：往后要你讲理由的题一道接一道，每道你都写得很足，钟走得比你算的快。

结局：鸿雁才飞到水边的岸上，头一站还没站稳，「小子厉，有言」，有点惊险，也落了几句话柄，终归「无咎」。卷面上那几处小毛病就是这几句话柄，扣不了几分，病根不在这里，在最后两页：每道说明题都铺成一篇短文，给分点只有三四个关键词，写出去的力气多，换回来的分少，总分就差那么一截。

应期：以下为传统推算的参考窗口。
可留意本月16、28号前后，练长答时又把说明铺成一整段，属耗应。写说明题前先在边上列三个关键词，再连成句子。

总断：最后那几道说明题，先在草稿边上写下关键词，再连成句子，多踩中一两个给分点。说明题上还欠几分，这一回就差在铺得太满。

「说明理由」四个字没顾上

风山渐 → 火水未济 → 风火家人

简断

这套题没有哪一道能一下看穿，会做的也得一步步磨，时间一路吃紧。总分停在线下一点，差在最后一小问：题末那句「说明理由」只写了结论，理由那几分整块空着。

开局：卷首那道就要算好几步，题不难，每一步却都得自己铺。

过程：做到一半，有道题的材料里藏着一句提示性的条件，顺着它找到了入口，卡住的那一处接上了。

能过，不吃力。卷首有道题会拦你一下，出得不顺，绕开就好；其余的题都在你站得稳的地方，写到最后还有余力。唯一要提防的是收尾时写顺了手，往答案里添些可有可无的话，反倒把原本干净的卷面搅乱。

开局：最先那题的条件摆得别扭，要换个角度读。

过程：此后的题一道比一道熟，写得扎实，回头看也挑不出大毛病。

结局：最后那题轻，三两下就写完了。渐卦六爻一站站往上飞，上九是最后一站；飞到这里，羽毛还是齐整的，「其羽可用为仪，吉」。小象「不可乱也」是这一篇的要害：卷面本来干净，收尾那几分钟只查不添，就是不乱。

应期：以下为传统推算的参考窗口。
