## 初六动 · 寅月、卯月

能把卷面收整，过于纠缠细处仍吃亏

火山旅 → 泽风大过 → 离为火

简断

拘在小处太久，这场偏难过线。熟题里有小地方拿不准时，先看它会不会改变答案。若只是表述上的细节，照已经确认的办法往下做。中途会有题给你找回思路的机会，末尾也能稳住一部分，怕的是前面为琐细处耗去时间，真正要答的反而欠着。

开局：春令相离生死艮，开头要自己花工夫把答案写实，负担较轻，但仍宜把得分处放在细节之前。

过程：囚兑在体互受离克，具体疑处能处理；用互旺巽生火，题里可用的线索较有力。

结局：初六旅处窘迫而琐琐，自取其灾，警惕小处牵住整场。末相离与体比和，能整理已经做成的部分，前段失去的时间仍较难追回。

应期：以下为传统推算的参考窗口。
可留意本月14、15号前后，中段较易找到值得继续的一步，属吉应。若本场尚未考试，这几日前后可对照题目区分决定结果的条件和无关细节，属过程利应。

总断：本场偏难过。一个细节反复验过仍无新线索时，先把主要步骤完成。

古籍依据：《周易·火山旅》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·八卦万物属类》《梅花易数·先天后天论》。

火山旅 → 泽风大过 → 雷山小过

简断

开始能作答，中间和尾段的要求仍使过关偏难。先看有哪一问真的能照平常的步骤写，别为早早答出一点就放松后面的检查。中间碰到条件变化时，把它和原先的结论分开核对。末段还是容易卡在没留意的限制上，先把确定无误的内容留下。

开局：冬令死离仍生囚艮，开局有少许帮助，能用的准备不足以应对连续变化。

过程：体互相巽克囚艮，新的条件有实质牵制；休兑受艮生，解释与检查还要费力。

结局：上九巢焚而由笑转号，所凭难保，爻凶。变用相震又克囚艮，前段的少量助益不能解后段重处，本次偏难过。

应期：以下为传统推算的参考窗口。
可留意本月13、25号前后，最终核查的限制较难满足，属凶应。若尚未考试，这几日前后可专练改掉卷尾常漏的硬条件，属末段凶应。

总断：这一轮较难过。做完一问先按题干查条件，留出余时应对后半程。

古籍依据：《周易·火山旅》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·八卦万物属类》《梅花易数·先天后天论》。

## 上九动 · 辰月、未月、戌月、丑月

前段能做，卷尾仍得防疏漏

火山旅 → 泽风大过 → 雷山小过

简断

先前有优势，最后疏忽仍较难够线。平日准备能帮你较快完成一批题，尤其不要在顺手的时候草草略过问法。到后面有些题还要说明理由，留心是不是每个关键条件都已经写出。先把有把握的内容护好，再考虑最后还能多答什么。

开局：土令休离生旺艮，开场有接应也有自己的准备，常规题较容易落笔。

过程：囚巽克旺艮，过程出现限制时尚能承受；相兑受体生，写明依据仍要留时间。

结局：上九先笑后失，守不住所依而凶。末囚震仍克旺艮，能承担并不意味着尾段可以略核，整场偏难通过。

应期：以下为传统推算的参考窗口。
可留意本月13、25号前后，最后容易漏查新增的限制，属凶应。若本次还没考，这几日前后可给旧卷后半段逐题标出新增条件，属末段凶应。

总断：本场较难过。到最后先核新条件，再看哪里可以增写；别因开头顺便一路抢写。
