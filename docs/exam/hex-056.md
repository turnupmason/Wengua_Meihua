## 初六动 · 寅月、卯月

分数漏在誊抄和描图上

火山旅 → 泽风大过 → 离为火

简断

会做的题差不多都做对了，分数却考不过线。丢分不在难题，在零碎处：誊题干、描图、来回改措辞，一处只耗一两分钟，累起来正好是最后两道题的时间。卷面上保得住的，是已经写对的那几道大题。

开局：卷子比预想的友好，题型大都眼熟，下笔不费思量。

过程：有道题的条件看着眼熟，顺着推得动，推不了几步又得自己接。

结局：要命的是那些不计分的动作。每道题先把题干整段誊一遍，图描了又描，一个词改三回，单看都不起眼，加起来却把最后两题挤成了空白。「旅琐琐，斯其所取灾」，旅人在零碎处计较，灾是自己招来的。这份灾不大，偏偏卷面离线也就差这么一点。

应期：以下为传统推算的参考窗口。
可留意本月14、15号前后，中段能找到一步可以接着往下做，属吉应。若本场尚未考试，这几日前后可对照题目区分决定结果的条件和无关细节。

总断：过不了线，差在零碎的耗时上。题干不必誊，图画一遍就够，省下的工夫给最后两题写出个样子。

古籍依据：《周易·火山旅》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·体用》《梅花易数·占卜克应之诀》《梅花易数·八卦万物属类》《梅花易数·先天后天论》。

开局：前三道小题一眼就有思路，想写的要点一条接一条往外冒。

过程：后面那道公认的难题反而干脆，两步就落了地，题干里给的一处提示几乎没派上用场。

结局：账是在前面欠下的。小题按点给分，写够两点就满了，多写的五六行一分不加，却实打实吃掉了大段时间。初六讲旅人琐琐、自取其灾，小象说「志穷灾也」：眼睛只盯着眼前这一问，看不见后面还有多长的路。后半卷的大题，就是在这里被挤短的。

## 初六动 · 申月、酉月

一道大题验了三遍

火山旅 → 泽风大过 → 离为火

简断

考不过，时间压在第二部分那道大题上。它分值最重，路子认得，推起来却一步一停，算完一步又回头验同一处，写到收尾，后面几题只能匆匆带过。这道大题本身做对了，分能拿到。

开局：卷面前几题平常，挑最熟的先写，手才慢慢热起来。

过程：能借的东西很少：题目只给了最基本的条件，熟悉的套路在这道大题上只用得上第一步。

结局：麻烦出在验算上。同一个数算了三遍，每遍结果都一样，还是要再算，这正是「旅琐琐」：旅人捏着几文钱反复地数，数不出多的来，只数掉了赶路的工夫。那道大题本就硬，再添这几遍验算，留给最后几题的只剩零头。灾是自取的，爻辞说得很直。

应期：以下为传统推算的参考窗口。
可留意本月11、12号前后，起步整理细节偏费劲，属耗应。若考试还没开始，这几日前后可挑复杂题先写主干，观察哪些细节最容易拖住进度。

总断：过不去，根子是那道大题耗得太久。一步算对就往下走，最后几题至少能写出头几步的分。
