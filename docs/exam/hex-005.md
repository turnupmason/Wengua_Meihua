## 初九动 · 寅月、卯月

卷子最后一题一直往下要

水天需 → 火泽睽 → 水风井

简断

前两道的题型认得，公式也想得起，只是没有一道能原样照搬。考不过，坏在压轴那道连环题：后一问要拿前一问的结果去算，你推得对，却推得慢，第三问写完已没剩多少时间，后两问只能空着。前面推对的步骤，阅卷都认。

开局：题型认得，可下笔前都得先在草稿上推几行，没有现成的路可抄。

过程：往后有道带图的题，数据要一格格读出来再代进去，读得准，就是磨。

结局：压轴题像一口深井，绳子放下去一截还够不着水：头一问算出的数，是下一问要用的条件，下一问的答案又垫在第三问底下，一环扣一环，哪一环都省不得。答案没错，时间却被一桶一桶提走了。「需于郊，利用恒，无咎」，远远守着常法，没有过错，前面那几题你没抢没乱，这是无咎；无咎只保你不犯错，填不上后两问那片空白。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，卷尾换了问法，重做其中几步可能用时偏多，属耗应。若近期已有模拟或实考安排，可留意最后一道变式从哪里开始要另算。

总断：线是过不去的。后两问哪怕只把要用的式子列上，也有步骤分，别让它整块白着。

古籍依据：《周易·水天需》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·体用》《梅花易数·占卜克应之诀》《梅花易数·日应》《梅花易数·先天后天论》。

材料题啃掉了大半时间

水天需 → 火泽睽 → 水风井

简断

卷子当中那道材料题最费工夫，几段文字夹着两张表，能用的信息要一条条挑出来。整卷够不上线，时间都填进了这一题，挑得准，却挑得久，卷尾三道小题本身不难，轮到它们时只剩几分钟。材料题里挑对的那几条，分是你的。

开局：前几题样子眼熟，没有哪道和做过的题一模一样，细处全得自己补。

过程：材料题占了整整两页，文字、表格、注释搅在一处，真正要用的只有四五条，还藏得深。你挑得出，也挑得准，可每挑一条都得回头对一遍表，纸面上一来一回，抬头看钟，已经过了大半场。

结局：卷尾那三道小题很轻，换个时候十来分钟就收拾了，这一回每道只写了个开头。「需于郊」，小象说「不犯难行也」，不往险处硬闯，你没有在材料题之外再去赌难题，这份稳当是对的，可它只稳得住写下的那些字。

应期：以下为传统推算的参考窗口。

简断

卷子的大半部分你写得顺，时间也宽。过不去线，差在最后那道论述：材料、道理、例子都摆上了，句句不错，偏偏题目只问一件事，那句结论始终没落笔，这题只给了少半的分，总分离线还差一口气。前面顺手写完的题，一分也不会少给。

开局：前几题是常见问法，条件和练过的路子对得上，提笔就知道往哪写。

过程：后面那道看图题，图画得清楚，要找的关系一眼就见。

结局：最后那题问得窄，只要你把一件事说清。你写了满满一页，离题眼却总隔着一层，正像「需于郊」的郊，在城外，离城门不远，就是没进城。小象说「未失常也」，你一路照平时的写法，没出一处错；平时练的是把话说全，这道题要的却是一句准话，分就丢在那句没写出来的话上。
