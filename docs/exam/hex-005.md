## 初九动 · 寅月、卯月

连环题一环套一环

水天需 → 火泽睽 → 水风井

简断

前两道的题型认得，公式也想得起，只是没有一道能原样照搬。铃声响起时总分还差一截，差在压轴那道连环题：后一问要拿前一问的结果去算，你推得对，却推得慢，第三问写完已没剩多少时间，后两问只能空着。前面推对的步骤，阅卷都认。

开局：前两道动笔前，草稿上先要推几行，记得的公式得变个形才用得上，没有现成的路可抄。

过程：接下来一道表格题，数字要一格格读出来再代进去，读准了，只是慢。

结局：压轴题像一口深井，绳子放下去一截还够不着水：头一问算出的数，是下一问要用的条件，下一问的答案又垫在第三问底下，一环扣一环，哪一环都省不得。答案没错，时间却被一桶一桶提走了。初九在郊外等，水还在远处，「利用恒，无咎」，守着平常的做法，不出错；前面那几题你没抢没乱，无咎就落在这里。可不出错换不来分，后两问那片空白还是白的。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，连环题推到第三问，后两问的时间被吃光，属耗应。掐表做一道连环题，记下从哪一问开始超出预定时间。

总断：后两问哪怕只把要用的式子列上，也有步骤分，别让它整块白着；那两块空白一留，分数就落在线下。

材料题啃掉了大半时间

水天需 → 火泽睽 → 水风井

简断

卷子当中那道材料题最吃时间：几段文字夹着两张表，能用的信息要一条条挑出来。分数够不上线，原因就在这里，你挑得准，却挑得久，卷尾三道小题本身不难，轮到它们时只剩几分钟。材料题里挑对的那几条，分是你的。

开局：眼熟的题型打头，可细看每道都换了个零件，缺的那几步只能自己补上。

过程：材料题占了整整两页，文字、表格、注释搅在一处，真正要用的只有四五条，还藏得深。你挑得出，也挑得准，可每挑一条都得回头对一遍表，纸面上一来一回，抬头看钟，已经过了大半场。

结局：卷尾那三道小题很轻，换个时候十来分钟就收拾了，这一回每道只写了个开头。「需于郊」，小象说「不犯难行也」，不往险处硬闯，你没有在材料题之外再去赌难题，这份稳当是对的，可它只稳得住写下的那些字。

应期：以下为传统推算的参考窗口。

总断：离线还差的这几分，是被材料题占走的时间。材料题和前面几道是稳的；那三道小题，动笔前就给它们划出一段时间，到点就写。

答在了题眼外面

水天需 → 火泽睽 → 水风井

简断

卷子的大半部分你写得顺，时间也宽，前面顺手写下的题，分一点没少给。总分离线还差一口气，毛病出在最后那道论述：材料、道理、例子都摆上了，句句不错，偏偏题目只问一件事，那句结论始终没落笔，这题只给了少半的分。

开局：常见的问法排在卷首，条件一摆出来，练过的路子就对上了，笔下不用犹豫。

过程：后面那道判断正误的小题，几个说法一读就分得出对错。

结局：最后那题问得窄，只要你把一件事说清。你写了满满一页，离题眼却总隔着一层。初九「需于郊」，郊是城外旷野，离险地远远的，图的是稳；小象说「未失常也」，你按平日的路子一路写来，没出一处错。平时练的是把话说全，这道题要的却是一句准话，分就丢在那句没写出来的话上。

可留意本月18、19号前后，开卷几道和练过的路子对上，提笔就写，属吉应。顺手的前几题别磨蹭，省下时间给论述先写那句结论。

总断：差几分，够不上线。最后那道论述先用一句话把问的那件事答死，再往下铺。

中间那一问要你写出结论后再说一句为什么，你写了结论，漏了理由，这一问的分只拿了一半。达不到线，就差在这一半：卷尾的生题你接得住，前面也没出大错，可这张卷子没有白送的分。

开局：前几道写得顺手，每道都要按部就班写，没有能跳过的步骤。

过程：那一问的要求写在括号里：「并说明理由」。你写完结论就往下走了，括号里那几个字没落到卷面上。阅卷照要求给分，结论一半，理由一半。分不多，可这一卷每一分都是一步一步挣来的，没有哪题白给，丢掉的这一半没处找补。

结局：卷尾那几道新问法你读得清，答得也稳，三位不速之客都敬到了，没有大失。「密云不雨」是小畜的卦辞，云已经厚了，雨就是不下；卷上的分数也这样，贴着线，没过去。上六说的「终吉」管的是待客，括号里那句漏掉的理由，它管不着。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，写完结论就往下走，括号里的理由漏了，属凶应。单查一遍括号里的要求，看每个结论后面跟没跟理由。

总断：凡是括号里写着「说明理由」的，结论后面紧跟一句为什么。这一次就差这一句，总分够不到线。
