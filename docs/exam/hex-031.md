## 初六动 · 寅月、卯月

老题换了一个条件

泽山咸 → 天风姤 → 泽火革

简断

压在卷尾的是一道你一眼认得的老题型，可条件被悄悄改了一处，照旧法写下去，答案就偏了，这一道分值最重，卷面停在线下，改掉的那一处没认出来。认得出的旧题第一问也写得出，这几步别空着；前面却没有哪题能替它补分。

开局：前两题看着眼熟，写出来只够拿个基本分。

过程：接下来几道材料长、要来回比对，一道比一道拖时间。

结局：压轴题就是那道被改过条件的老题。它和你练过的那一道几乎一样，只在一个前提上动了手脚，原来的结论不再成立，要你先看出来，再换一条路。咸卦初爻「咸其拇」，感只到了脚的大拇趾，小象说「志在外也」：碰到的只是题面那层熟悉，脚趾头先动了，身子还没跟上。这一处来得又硬又整，换路要用的那套办法，偏偏是你平时最少去碰的，前面也没攒下能挪过来的分。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，练题时又把改过条件的旧题照老路写，属凶应。翻出那几道熟题，每道换掉一个前提再做一遍。

总断：动笔做压轴题前，拿它和练过的那道逐项比一遍条件，改动后的第一步先写对。改了的那个前提没认出来，分就丢在那里，没够上线。

末题接着用前一题的答数

泽山咸 → 天风姤 → 泽火革

简断

卷子前大半是你熟的题，写得顺，时间也宽，拿手的那些题分一分都不会少。毛病在末题：它拿中间那道题的答数当起点，再往下问一层没练过的东西，起点一歪，后面全歪，差着几分没上线。

开局：翻开卷子，练熟的内容占了大头。

过程：几道中档题写得干脆，交出的答数看着也像那么回事。

结局：最后一题把中间那道的答数抄过来做条件，要你接着推出一个新结论。这一层你没练过，中间那一步又恰好有个小地方没核，两样叠在一起，末题从起点就站歪了。初六「咸其拇」，小象「志在外也」，感应停在最外头的脚趾上：前面写得顺，并不说明后面也顺。总分本来离线就近，这一题一丢，正好落在线下。

总断：中间那道写完，花一分钟把答数代回去验一遍，末题的起点才站得正；起点一歪，线边那几分就没够上线。

## 初六动 · 亥月、子月

时间被中间几道吃掉

泽山咸 → 天风姤 → 泽火革

简断

中间几道题条件给得又细又多，你拆得开，一道却要花两道的工夫，拆出来的那几道分都算数。轮到卷尾那题，它要的推导一步不能省，余下的钟点写不全它，这回时间上差了一截，没够上线。

开局：头几道题都得一点点往下抠，没有能照搬的。

过程：随后几道条件密，每一条都得用上，你拆得出，就是拆得慢，表针走得比笔快。

结局：卷尾那题看上去不长，真写起来，每一步都要交代来历。题本身不凶，可前面几道把钟点拖走了，它就成了压在最后的一块石头。「咸其拇」，感应还停在脚趾，人没迈开步子；这一卷的节奏也是这样，前面迈得太碎，走不到终点。

应期：此盘暂无有据的日期可列。

总断：每道题旁边先记个停笔的钟点，过了就翻页，卷尾那题至少把思路写出来。钟点分错了，这回还差一截。

古籍依据：《周易·泽山咸》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·体用》《梅花易数·占卜克应之诀》。

末题要你推翻熟结论

泽山咸 → 天风姤 → 泽火革

简断

题型都是做过的原题，只改了个数，前面一路顺，那些原题的分稳稳在手。绊在最后一问：它要你说明一个常用结论在什么情况下不成立，再举出例子，这条结论你只会正着用，从没倒过来想，这一问空着，没摸到线。

开局：卷上有几道眼熟得很，提笔就有。

过程：后面几题也没出复习的圈子，写完还有空回头看。

结局：最后一问把方向掉了个头：常用的那条结论，要你找出它失效的情形。变到这里是个「革」字，旧的要先破开。你会用这条结论，没想过它的边在哪里，写出来只是又把它用了一遍，这一问的分就落了空。「咸其拇」，感只到脚趾，碰到了，没进去；前头顺得越久，这一问越容易被当成顺的。

总断：最后一问先写一句「这个结论在……时不成立」，再找最简单的反例，哪怕只举一个；这一问一空，卷面就没上线。

## 六二动 · 寅月、卯月

两道长题一刀一刀切

泽山咸 → 天风姤 → 泽风大过

简断

能过，就是两道长题要一刀一刀切：一道在卷子当中，一道压在卷尾，题干长，步骤多，得自己一段段拆开写，拆一道就占掉一大截时间。全卷没有一处挡得死你。拆到一半最忌换方法，原来那套步骤走到底。

开局：前面的题给得干巴巴，没多少现成的东西可套。

过程：第一道长题占了大半页，要先分清哪几句是条件、哪几句是陪衬。

结局：末尾又是一道长题，比前一道更绕。「咸其腓，凶；居吉」，腓是小腿肚，人还没想好，腿先动了，所以凶；安住不动就吉。凶落在半路改道上：拆到第三步嫌慢，就想换一个没练过的巧法，往往换到一半两头落空。慢是慢在这两道长题本身，照练熟的路子切到底，分是够的。

应期：以下为传统推算的参考窗口。
可留意本月11、14号前后，凭题面给的一点提示，先答定一问，属吉应。挑一道长题，只用练熟的步骤从头拆到尾。

总断：过得去。两道长题各留足时间，慢慢切，用不着抢。

## 六二动 · 巳月、午月

每题都卡在第一步

泽山咸 → 天风姤 → 泽风大过

简断

能过线，只是每道题起手都慢半拍：这套卷子偏偏多出自你练得少的几章，第一步怎么列，要先想一会儿。列出来以后，后面的步骤都不难，没有哪题拦得住你。第一步没想清，宁可多停一会儿，别抢着先把式子列上去。
