## 初六动 · 寅月

小题守得住，卷尾大题只写了半段

水地比 → 山地剥 → 水雷屯

比初六逢寅月，这一场过不了，欠分在末道论述刚铺开，来不及把判断和依据接全。上坎水为原体，在春令休，下坤土为本用在死，来克坎而起步所限较轻。题目中若规定了符号写法，或要求写明某项限制，逐个看清便能做对。几处细节各占用一点钟点，当下不觉得，翻到必须连续写一段说明时，前面散用的工夫已经挪不回来了。

用互坤土、体互艮土都在死地，也克坎，来势轻却接在卷首所受的限制之后。初六动，下坤变震，上坎不变，成水雷屯。变用震木旺，由坎水去生，末处正是耗得重的地方。早段没有生体作补，尾段又须长写，按源断过不了。寅、卯日取变用震木，参的是收束时连续写作所需的投入。

经言「有孚盈缶，终来有它吉」，王弼说诚信用到素朴之器也能充盈，孔疏说从始至终诚意一贯，故不止一人来相亲。借到答卷，前面已经照明文写清的几个判断之所以能得分，在于说出的东西有据可查。末道论述即使观点立得住，其后理由没有写全，所问仍未办毕。爻中的吉有所指，这一局依旧要合看三处土制与末木之泄。

练整张卷时宜留出一段完整的钟点给末题，记录前面的细小要求各费多久，辨哪些可在第一次落笔就办妥。正式作答要写成段，可以先写总判断，在下句接能支持它的题面事实，再说两者怎样相合。时间接近用尽，先完成一段有首尾的说明，比两段都只开头更能显示已经证清的部分。寅月前分确能留住，卷尾所欠仍使这场够不上线。

## 初六动 · 卯月

小处都写仔细，尾题的理由还短了一截

水地比 → 山地剥 → 水雷屯

比初六在卯月，考试过不了线，少在卷尾长答缺了一段把理由引到结论的说明。上坎水为体，在卯月休，下坤土为本用，死而克坎，开场的规矩虽然有几条，按题面写仍可照办。前面能以短句解决的要求一个接一个，你担心遗漏，总要再查一眼才继续。遇到最后一问需要把两处材料合起来，剩下的钟点只够论清一处，另一处来不及接到判断上。

用互坤土与体互艮土在木令俱死，皆克原坎，约束在前中相连但不重。初六变下坤为震，上体仍为坎，得水雷屯；变用震木在卯月旺，由原坎去生，到了尾处消耗最显。全盘无生体，先前能办的题照样有所得，未完的长答不够补，源断仍过不了。寅、卯日按变用震木取，参收尾真正要用去的工夫。

「有孚比之，无咎」，孔疏以初六为比之始，须存诚终始如一，方能免咎。「有孚盈缶」又取诚意充实而不私于一。用到作答，可以借来说明几道小题都照同一要求办，是能稳拿的部分；到长答仍要令材料和判断彼此承接，光摆出一半依据不算做全。原案并读爻中的吉、卦中的克泄，整场仍按后者看。

备考可以在同一套限时卷里试着把前面易漏的细节一笔处理完，并为长答记下最迟起笔的时刻。临场读到结尾需要同时比较两处材料，可在草稿各记它能说明什么，再用一两句连接事实和结果。写完一处就确认有没有正中题面所问。若论述必须回应两个判断，宁可各用一条证据写完整，也别把第一段的例子堆得太多。卯月当下能完成的分已有着落，末段只写一层仍不足过线。

## 初六动 · 辰月

计算本身会做，规定格式从开头牵住整卷

水地比 → 山地剥 → 水雷屯

比初六临辰月，这一场过不了，实亏在卷首统一的计算格式没有落实到每道题。上坎水为原体，在土令死；下坤土是本用，正在旺地而来克坎，开卷已有规矩须看清。若明定要先列关系、再代数、末后说明所得，平时习惯只写其中几行，头一问就得重新想怎样组织。其后计算题沿用同一条说明，每题少一个可核步骤，整卷所得便渐渐不够。

用互坤土、体互艮土同旺，两处也来克坎，前中各有实限。初六动下坤为震，与上坎成水雷屯，变用震木在囚，由原坎去生，末段的泄较轻。依原案，震木亦能稍制三土，尚不足以解土旺水死之势。盘中无生体，所欠主要起自卷首，依原断过不了。辰、戌、丑、未日从本用坤土取，参最初开始管住后面计算题的规矩。

经说「有孚比之，无咎。有孚盈缶，终来有它吉」，王注以立诚解释相亲，孔疏重在从始至终相贯。应在卷面，卷首定给整组计算的做法，后面每问都应兑现，不能只在第一题写出样子。论述和概念问另有题面要求，照各自所问完成即可。爻中的信与吉有其情境，眼下决定过不了的在强土制体与切实没有写出的步骤。

练计算宜先选一道题干很短的例子，完整写明列式、代入、结果各落在哪里，用同一种格式连做几道。临场把卷首明写的规定转成小记号，放在每道计算旁，写完当场查三处是否都在纸上。若最后余时很短，就补能立刻写清的一步，给其他问留分。辰月论述辨析能有实分，计算的统一要求仍拉低了整场所得。

## 初六动 · 巳月

每一问都要凭据，几处没有跟在答案后

水地比 → 山地剥 → 水雷屯

比初六入巳月，考试过不了线，几道题明要写清凭据，卷面却只有几处写全了。上坎水为体，在夏火令囚；下坤土为本用得相，来克坎，开卷形式便要照题明文办理。第一个判断能从记熟的定义直接认出来，写时容易只说对错，省去为何可用那条定义。后面要将各题给出的不同事实逐项接上，少写的还是出自同一个习惯。

六三「比之匪人」，《象》以「不亦伤乎」说其所比不当。孔疏指出二、四自有其所比，六三近处不相得，远处亦无应。放在卷上，熟悉的推法在它原用的地方有凭据，错误出在将它拿来处理受新限制的那一问。判此局难成并不取消前面已经取得的分，所欠就在卷尾来不及证明之处。

训练临卷核算宜看题干最后一行在限制哪个量、哪种情况，记在草稿上，等求得结果就逐项对照。若原答仅一部分越界，保留仍成立的关系，重查排除的理由，不能只删结果里的一个数字。若末行要求先证范围，再报告所得，宜给证明范围的那句留一行，才有根据说明为什么改。复练也可将原题的限制挪到不同位置，检验读题能否始终找齐。实在剩不下全写的工夫，也把排除条件说明清楚，卷面能看出做到哪里。子月已经答好的地方有分，末题最后一层没收住，仍低于线。
