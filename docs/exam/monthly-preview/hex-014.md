## 初九动 · 寅月

从「都如此」换成「曾如此」，熟悉的答案只须改准这一层

火天大有 → 泽天夬 → 火风鼎

这场能过，寅月最值得你花工夫的地方恰在熟题上。火天大有，初爻动在下，上卦离火代表应试的你。春木生火，离在这时渐有力量，对着的下乾金却弱，开头让你辨认、解释、作出判断，都有平常所学可用。只是同一句话放在不同问法下面，分量会变。若题问「作者是否曾在雨中渡江」，一则亲记渡江遇雨的文字足以作证。若问「他每次渡江是否都逢雨」，那则记载便只能说明其中一回。若另有一日亲记风清月明、舟过江心，那才是能使「每次都逢雨」站不住的一件事实。

初九说「无交害，匪咎，艰则无咎」。王弼、孔颖达释这一爻，着眼于大有之初虽未涉害，仍宜有知艰之心。用于考试，并非说一见熟题就得把自己会的东西从头怀疑一遍，而是问那一句能证实多少，答语是否真的只说到了那里。你若为了表示谨慎，把确有其事的一次渡江也写成猜测，反而丢掉了本有根据的分。

卦到中间仍有乾金、兑金，都得由离火去制。春月金弱，读完几份材料再挑合用的一则，你有能力自己料理。收尾下乾变巽，巽木虽旺能生火，却受卦中三处金所制，末段给的帮助有限。比如题末附了一句「行旅日记原有散佚」，只提醒你不宜妄断每一次行程，不能替你指出哪一天确实遇过雨。

复习宜拿同一段原文，各用「曾有」和「一向」问一遍，写完指出两答需要的证据差在哪里。前面几问这样守住，便毋须靠末尾那点提示来补全卷。寅、卯日可参合格消息，实际以报名处公布的成绩为准。这次能过，靠的是熟悉的东西拿得准，也肯为改了的那个字多读一眼。

## 初九动 · 卯月

记得他说过什么，还要看问的是谁听见的

火天大有 → 泽天夬 → 火风鼎

卯月这次能过。大有初九动，上离火得春气，下乾以及中间所见的乾、兑都属金，这时力量较轻，题目要你亲自查对的事情虽不止一件，做起来还是顺手。你平日若常练摘录原话的题，一见引号，便知道从哪里起、到哪里停。这回真正值分的也许只在一个「闻」字。譬如主人在席上宣布次日动身，记事人亲耳听到，后来有人读他的札记才知道此事。两个人能复述同一句话，却只有席上的那位可以称为亲闻。

「无交害，匪咎，艰则无咎」，小象说「大有初九，无交害也」。朱熹说初在事始，尚未涉害，仍须以艰处之。借这层意思说，你已经练到能把原句抄准，这份功夫可以放心用。宜细读的只是问题把耳闻算在谁身上。若它另问后来那人从何得知，刚才上不了亲闻名单的人反而有据可用，可以说他见于那份札记，不必连他的知情也一并抹去。

收尾下卦由乾变巽，卯木虽旺，能来生离，却有卦中几处金来克它，所以末问的附注只够替你核实一端。假如注中说札记曾传抄多次，能提醒你文字如何传开，不能据此写每一个抄写者都到过当日的席上。分数主要从前面各问分清原话、听见与读到这几件事上来。

练习宜把同一句话依次接在三个人的名字后，分别写「他说」「他听见」「他读到」，看看原文各肯支持哪一句。若札记是在席散许久之后补记，还得区分当时亲耳听见与事后何时落笔。认准这两件事，才不会拿写作日期替代那次聚会的日子。寅、卯日参正式查分见到合格的消息，此处所看仍是这场过线，卷面每处是否圆满则各依所答。

## 初九动 · 辰月

问的是收摊前还剩什么，得把末半句管到哪一刻看清

火天大有 → 泽天夬 → 火风鼎

这场考试能过，辰月答得慢些，慢在一段题干读到最后才知道开头几行该怎样用。譬如题上先列一日进了几筐果子、卖出多少、另拨了多少给邻摊，直到末尾才问「收摊以前，架上尚余几筐」。若晚间又有一批送到，账簿照日期把它也记在同一天，你顺着账从上加到底，所得是当日最后的存数，未必是收摊那一刻的存数。先找准问的是哪一刻，比拿着错数再验两遍加减更值这点工夫。

上离火在辰月休，下乾金与中间乾、兑两处金反而较有力。火能制金，事情办得成，却都要你自己下力，长题自然不宜抢快。若第二问另请算当晚实际收到多少货物，前一问没算进去的那几筐便可能要重新算进去。同一个数在两问里该不该取，须依各自问到的时刻来定，不是第一问划掉它，后面也一概不用。

初九说「无交害，匪咎，艰则无咎」。孔颖达解为在大有之初虽无交切之害，尚须能自艰其志。借到考卷，你有能力处理眼前这些数，只要肯在动笔前把时点说出一句，才不会将本来会答的题办成另一道。把「这天」与「收摊时」分别写在两问边上，后面要复查也知道该回看账簿哪一笔。尤其须看末行那一筐有没有写明时辰。账页下方有空位，人可以在那儿补记早先到的货，登记的位置并不能说明到货是在收摊之前还是之后。

到末问下乾变巽，巽木虽生离，辰月木弱又被金制，附在卷末的线索只能帮你查一处。宜拿它对一下晚来那批的交收时刻，勿把一处对得上就当作全账已经核过。寅、卯日可参收尾由线索发现漏答的那一步。主要几问从开头就守住范围，整场便能过线。

## 初九动 · 巳月

数算对了，末尾那一格还要写成人家指定的单位

火天大有 → 泽天夬 → 火风鼎

这次能过，巳月最好用的一点余力，在全卷写完到交出去之间。火旺时取上离为应试的人，下乾与中间所见的乾、兑都属金而弱，题虽要自己亲手做，平日学会的本领到了卷上使得出来。譬如一张裁布图按米标数，你已算出剩零点八米，答纸的空格右边却印了「厘米」。若顺手把零点八原样填过去，草稿上尺寸并未算错，交给阅卷人的却成了不到一厘米的短头。

初九说「无交害，匪咎，艰则无咎」，王弼说大有在初，虽未逢害，还须知艰。借到这份卷上，不必把容易的题想出许多从未给过的弯来。有一件实在可做的事，就是先看数后面跟着什么，再看答案栏旁印的是什么。同样一张布，零点八米与八十厘米指的是同一段，先在草稿把这句写明，便知道交到空格里应保留哪个数。

核完单位，还有一道只求大致范围的题，便照它所要的精度写，不多添小数显示自己算得细。分数主要已在前段拿住，余时做的是让卷面忠实交出自己真正会的那一份。取寅、卯日参正式合格名单，核对本人的准考号码即可。此卦得力处在能做好又能查清，这一回足够过线。

## 初九动 · 子月

折了几次纸各算一次，最后拿展开的全幅来验

火天大有 → 泽天夬 → 火风鼎

这次考试能过，子月写得慢，事情却有头有尾。若题给一张长纸先沿短边方向折去一半，再沿另一方向折一次，问折好后哪一边多长，起头就得分清究竟是纸的长变短，还是纸的宽变窄。你若只记「对折两次剩四分之一」，指折好以后纸在桌面盖住的面积，说得通，拿来回答某一条边的长度却还无从下笔。宜把原长、原宽各占一栏，每折一次只改真正被折短的那一栏。

下乾与中间所见的乾、兑都为上离火所克，冬天离火力弱，金也休，逐行记这些数有些迟，盘里却没有一股来克离的力量使它办不下去。初九的「无交害，匪咎，艰则无咎」，朱熹说是在事初未涉其害时便须谨慎。用来读这道题，最省错的一步是先在纸上指明两条相对的边哪两条要相贴。说得出贴住的是哪两边，才知道两边中间隔的那段距离该减半。纸若原长二十、宽十，先让两条短边相遇，便是长减成十，宽仍然留十，这一步写实，下一折才有可用的起点。

变卦为火风鼎，巽木在离火之下，像下头添了一点柴，冬月木虽有气，仍受三处金制。末问若给纸完全展开时的一个已知尺寸，你能从折好那格倒着算回原长，看看是否正合。题目若只给长而没有给宽，这条数便只替你核准了长的一边，宽在第二折有没有改错，还要回到折法本身去查。

复习宜挑一折沿长边、一折沿短边的小题，做完将纸真正展开，对照自己在哪一行改变了哪个量。寅、卯日参末段验回原数的那点帮助。此卷不靠末题突然多出许多答案，靠前面从每一折的两端推得扎实，所以虽迟而能过。

## 初九动 · 丑月

题末只要同一天仍在场的人，来过又走的不宜混列

火天大有 → 泽天夬 → 火风鼎

丑月这一卷能过，先要把一道长题问的是哪一刻认定。譬如会议从早到晚陆续有人来，签到簿上十个人都留了名字，题后还附几条中途告辞和午后再来的简记。若问当日有谁到过，十个名字都有来由。若末句限「散会时尚在席者」，早晨签过名、午前已经走的人便须另行处置。把来过的人一律留到最后，再认真地把姓名按笔画排好，也还没有答到末句。

离火在丑月休，所面对的下乾和中间乾、兑都有气，事情能办，读材料的一段要花工夫。宜在每个人名后按次序记他到、离、再到的时刻，而非只圈他出现过几次。若同一个人早上告辞，下午受邀重又返回，他不应因为名下有个「离」字便从末席删去。在这道题的范围里，最迟一条确实的去留记录比累计出现的次数更有分量。

大有初九「无交害，匪咎，艰则无咎」，小象说「大有初九，无交害也」。古注把知艰落在事情尚且顺手的时候，留给你的功课是逐条细看眼前已有的记录。用在眼前，不要急着凭常识断某个人既告辞便绝无回席之理，看题上是否真的记了他再来。若材料只说「约他午后再议」，应先分出约请与到场，并不因有了约定就替他添一笔已经回来。

下乾变巽，巽木能生离，可丑月木弱，卦里还有金来克它，末段的助益不大。卷尾若有「散会时甲执笔」一句，只够核准甲在场，其他人还须照各自记录定夺。寅、卯日参末尾借这一句查缺之处。先把长问读实，后面就不必频频改动名单，做得虽慢，这次能够合格。
