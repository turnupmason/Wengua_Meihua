## 初六动 · 寅月

这场主要靠自己，好在正是自己有力的时候

风地观 → 山地剥 → 风雷益

乍看这场考试，前面好几处都要自己出力，似乎得很费工夫才走得完，寅月却能过。观卦上面的巽木代表你，正当春木得时，下坤属土，是开头所要承担的事情。木能制土，本来就归你去应付，又逢土在初春弱，所任的分量并没有超过你的力量。卦里虽无另外一处直接来生你，自己这一边已有的本事仍然够用。

中间看见的还是土，有坤也有艮，两处同样由木来制。这意味着开始能承当还不算完，经过当中仍要亲自出力，若自己本来势弱，就很容易看见越往后越费劲的一面。但春木在这里有力，所任的三处土又都弱，费工夫的分量宜照实减轻。到最后变出的震木与你同气，也同样正在旺时，原有力量走到结尾还保持得住。

初六的「童观」，王弼以它位置在下、离所观之处最远来解释。见得不广，只能巽顺以从，爻辞才分别说「小人无咎，君子吝」。借到这场，不必用这两个称呼去评说应考的人，值得记下的是一开始所见终究有限。单从初位看，确有未能远观的遗憾，而通看起初、中间的所任以及最后能否相接，事情便另有更完整的根据。

所以许过，所凭的正是旺木任得起三处弱土，整卦无一处能克你，归处又有同气相应。《求名占》说自己能制事情，虽可成却往往稍迟，放在寅月，一边强、一边弱，这份迟意并不重。若另参看何时收束得较顺，宜取末尾震木所应的寅、卯日，所指是同气相应的时段，至于考试什么时候有正式成绩，仍依实际安排。

## 初六动 · 卯月

没有另外的帮助，也有足以承当的本领

风地观 → 山地剥 → 风雷益

有些卦要先问能得到多少接应，卯月这场能过，却主要是你自己的力量足以应事。卦取上巽的木为你，木到仲春正旺，开始所遇的坤土已经处在力量最弱的时候。木来制土，事情要归你承担，并不是外面送你一份便利。只是你有力，眼前的分量又轻，单看这开头，你要靠自己并不等于你会因此陷入困难。

再往中间看，坤土、艮土还是同样的关系，三处前后接续，都没有跳出木所能制的范围。若木力不足，接连承担就会费时，眼下正值你强而它们弱，虽说处处要出力，也没有哪一处反过来压你。归处则换成震木，同你所代表的巽木相合，而且都得着当时的旺气。经历了前面的付出，到要见结果时仍有自己能凭的根基。

初六离上面可观的中心最远，所见仅在眼前，古人因而称它「童观」。爻辞将无咎与吝分开讲，取决于这样一种有限的见识放在怎样的身份与责任上，并未一概许吉或断凶。用到这一占，宜记住单看一端容易遗漏什么。只看开头要自己出力，容易忧虑，若只看春木旺，又可能忽略经过当中仍有接连需要承担的地方。

问能不能合格，将两端都看进来，答案便清楚。你虽无专门生自己的力量，整局也没有直接来克你的一处，中段所任的轻重合宜，末木相应又有力，故依卦可成，迟意也淡。若参最后相合的日子，取变出的震木看寅、卯日，所应在事情收得住的一段。前面的三处土关乎承担，最后的震木关乎能否收住，各有分量。

## 初六动 · 辰月

从开头到中途，担子都落在你身上

风地观 → 山地剥 → 风雷益

倘只看「事情可以由你作主」，辰月本来有一分可取，但加上实际分量，这场考试过不了。代表你的是上巽木，到了辰月木力受拘，起头所见坤土却正当旺时。木能制土，是关系上有你能承担的一面，木弱土强，是实际要你承担时力量相差太远。两者同时成立，恰说明为什么能轮到你去应付，并不保证你便应付得来。

过程里还有坤土和艮土，都和原先的土同样得令，而且还是靠你的木来制。卦中没有专门来伤你的一处，这是有利依据，却也没有别的力量来生你，前面才费了一番工夫，中间还须照样出力。到了结尾虽然变出震木，和你同气，本来应有合得上的好处，偏偏它也处在受拘的时令。两个都力薄，相合所能留住的仍然很少。

「童观，小人无咎，君子吝」说的是初六处得远，所见有限。王、孔以其只能巽顺、不能自进解释童观，若所负的责任本来要求看得广，只能看到眼前就会有憾。借在这次考试，不必推成你自己犯了什么错误，宜看有限的力量与眼前需承担的事情是否相称。辰月这两边恰不相称，能说由你任事，但所任的分量已超过弱木的力量。

因此不能仅以没有克你的地方就把它判断为可成，也不能看见结尾同气便略掉双方都弱的实情。起头到经过三处旺土都须弱木应付，归处又无足够力量来接续，卦里欠的是一段贯穿全程的承担之力。这样的为难并不专属某一步，也就没有依据另取某一天去对应败处。只就所问的这次考试，依全局断难以合格。

## 初六动 · 巳月

开头的事尚可亲自去办，随后却接连都要靠自己

风地观 → 山地剥 → 风雷益

若只需你应付开头那一层，巳月这卦还有些可说之处，但问整场考试依然过不了。上巽是木，代表你，木入夏刚退了当旺的势头。开头的坤土却在夏天有气，木能制土，事情是你能够着手的事，可说到真正要承担的分量，已经是力量稍退的一方去应付正有力的一方。只看「能制」二字，容易把关系看得比实力更重。

到了中间又是坤土，还有艮土，两处同样有气，都没有离开仍须由你亲自承担的关系。卦里没有外来力量直接压你，本是值得认取的好处，遗憾的是也没有另一处真能来生你。一次出力未得补充，接着还有下一处要办，久而久之，费力就不仅是迟一点而已。到末尾见震木同你相合，可两处木在夏天都退势，合起来仍缺接续之力。

爻辞说「童观，小人无咎，君子吝」，王弼看重的是初位离上面的朝廷之美远，本身又柔弱，所能看到的有限。若只需要随顺，未见得便有过失，若承担的是要通观全局的事情，眼前这点见识便显得局促。用在考试宜照这个分寸看，你有能够起手的地方，不能因为结果难成就连这一点也否认，但一处能做还不足以承担整场。

因此巳月这一断，须把开头、经过与末尾连起来才说得清楚。前面三处土都要自己制，自己力已退，末木同样不强，原有的不足一直没有得到补充。即使没有外面的力量直接克你，仍然难以凭这点本领支撑到合格。这里说的难是前后一贯的分量差，并没有明确集中在某一端，取期也就不另外挑某一天来指作失败的时候。

### 应期参考

## 初六动 · 午月

风地观 → 山地剥 → 风雷益

午月这场过不了，倒不是外面的事情强到反过来克你，而是从开头到中间，都找不到一处肯替你分担的力量。巽木在上，代表你自己，木到盛夏退气，开始要制的是有气的坤土。木制土，意味着事情得由你去承担，虽能着手，力量却比春天薄了。若因为事情不曾直接压你，便估计自己可以一口气承当到底，先得问后面还有多少同样的要求。

「童观」之所以分「小人无咎，君子吝」，古人是将初六的位置、所能看见的范围与相应的责任一同来讲。处得远，所见自然浅，若所负的事须看得周全，眼前这一层就不够。借来理解这一占，宜肯定你能够着手的一端，同时问问凭这样的力量还能承担多少。这里的憾在分量不相称，不必另外猜到考场上是什么事分了你的心。

把两端都放进来，才看得出这一占不成的缘由。能制开头的土是关系上的主动，中途还得接连应付有气的土是实际上的负担，归处同类也弱，则是先前的付出终未得到接应。卦里并没有特别指出哪一个日子不利，强行挑出一天，反会把本来贯穿全程的难处说小。单问这一场，依这种前后关系仍然难以合格。

## 初六动 · 未月

还须看这个条件会不会只在起步时有用。中途再见坤土、艮土，仍由木来制，在冬月也都没有变成难以任受的重担。这一段确有需要工夫的地方，能自己应付是一回事，完全不必出力又是另一回事。最后换成震木与你相合，同样处在有气的时候，前面所用的力量还有收束的所在，至此才好把起头的一分把握推到结果上。

「童观」在观卦初六，是从最下面、离可观之处最远的位置望去。王孔说其所见有限，只能随顺，爻辞所以分「小人无咎，君子吝」两层来论。借来看子月这场，最初的观照本不完备，若只凭眼前有利或不利的一端就下定论，容易遗漏末尾。宜把中间的承担同走到最后是否还有力量相合一起看，爻辞的提醒才有落处。

这样看来，没有直接来克你的地方，确实是一份有利，那份有利还须由你能够制土、末震又可与你相应来落实。前中所任皆轻，两木皆有气，合格因而有根据，不能把它说成恰巧遇了什么便利。若参看归处较顺的日子，可以震木所应的寅、卯日为参考，所应为收束时的相合。这一场真正的成处，仍在你自己一路都有能力承担。

## 初六动 · 丑月

问题出在一路都重，难挑出其中一步来说

风地观 → 山地剥 → 风雷益

一场考试的分量，也要看落在怎样的时令、由怎样的力量去承担，丑月这一占过不了。上巽木为你，木到这个土月正受限制，开头下坤的土却旺。虽说木能制土，你不是全无着手的余地，真正论办起来的轻重，弱木要制旺土，总要花超出平常的工夫。单从开头这层关系，可以说有事能够亲自去办，还不能说足以一路办成。

问题在于接着出现的依然是土。经过中坤、艮都得时，卦里不见别处给你生扶，同一份有限的力量，开头已经需要付出，往里走还得连续承担。末尾变出震木，和原来的巽木同气，本应有相合之利，但两处木在土月都受拘。相应的一端既没有强到能接住你，合起来仍不足以弥补前中所任太重的难处，故不宜从比和就轻许有成。

初六「童观，小人无咎，君子吝」，孔疏释童观，是位置离得远，自己又不能前进，所见便浅。若只须随顺，这样的观看尚可无咎，若本应观察得周全，就留下遗憾。用在丑月，宜从一开头所能见的好处往后多推一步，起头能以木制土，本来留有自己可以任事的一面，所任的分量却并未因此减轻。这里讲的是所见的范围，不是替应考的人下一个品评。

因此无克虽然可取，全局仍是木弱、所任之土旺，而结尾那点相合也少力。最难的地方贯穿开头与经过，不能只挑其中一处当作成败的关口，自然也不另定某个日子去应它。若问是否通过，宜依整场来答，有限的力量接连要应付很有分量的事，到归处仍得不到相称的支持，前面能够出力，终究没有推到最后能够合格。
