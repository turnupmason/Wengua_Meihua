## 初六动 · 寅月

有把握是一件好事，宜留到最后让它坐实

雷地豫 → 水山蹇 → 震为雷

有把握的事，等到真正办成时再高兴也不晚，这次考试按卦能过。豫卦初六说「鸣豫，凶」，乍看似乎与所问的结果相反，细读却有它所指的地方。王弼解释，初六一开始便在上面得到了响应，乐过了头，志意也就到此为止。古人所戒，在事情初起便以已有的顺意为足，和你这场实际具不具备通过的条件，还要分别来论。

寅月上面的震木代表你，正是春木旺的时候，下面的坤土却弱，由木来掌握土，你原有的能力在开头便能用得上。中途的艮土也是如此，虽还需由你自己去应付，双方强弱有别，并不格外费力。这些有把握的地方是由你自身得时而来，因此即使中间另有的帮助有限，也不妨碍你在事情的主要部分作主。

这份帮助来自坎水，水能养木，可春水已退气，又受前后土的限制，所以只宜算作一份小助，不能说你的力量全从这里来。反倒是到了末后，下面由坤变震，两处震木同气，都在当旺之时，开头原能掌握的本领，到收束还用得出来。局中也无金来制木，前后的顺势才有着实的根据。

若参时日，寅、卯日取的是末段同你相合的震木，所看在事情怎样收得稳妥。初六与九四相应，只能说明起初为何容易感到顺意。问到本次能否如愿，宜以实有的旺木能够掌握弱土、末后又见同气来定，这两处才把起头与收束连到了一起。你这一场的信心只须安在应当安的地方，能做的仍照实做到，开头的顺意便能由末后的实力印证。按全卦来断，真正可凭的力量足以成事。

## 初六动 · 卯月

开头这份顺意，后面还有本领接得上

雷地豫 → 水山蹇 → 震为雷

「鸣豫」最值得玩味的是这一个「鸣」字，事情才刚开始，心里的高兴已经发了出来。问本次考试，卦上能过，这句提醒也仍说得上。孔颖达释初六，是它独得九四响应，因得其应，欢喜便容易超过眼前真正得到的分量。放在你身上，宜先弄清楚哪一面已经有把握，哪一面仍须凭后来的实际发挥才算做成。

卯月震木正在旺处，对应你一方的正是这处木，下面坤土较弱，木能制土，说明你承担眼前的事有实力作主。过程中又见艮土，同样处在弱时，仍在你能够掌握的范围。因而这次的顺意有根，起点的有利也并非只凭心情得来。不过能胜任，毕竟还得由自己去承担，不能把尚待完成的事提前算成已经有了结果。

中间坎水可以生木，水在春季力量已退，又受到坤、艮两处土的限制，这份接济算得上，但不能算得太多。即使把它按轻处看，你自己的震木本就旺，卦内也未见金来克木，所以并没有一个比你更强的外来约束，能把先前的把握截断。爻辞所说的「凶」，在过早把一时的喜悦看成足愿，仍有自己能作主的地方。只要回到实有的强弱来看，春木能够担当，末段也有同气接应，整场从吉处断便有了根据。

真正把开头的信心接到最后的，是变卦又见震木，与你同气，在卯月也同样有力。宜从末段取寅、卯日参看，所指是原有本领到最后仍有发挥的余地。初得响应时能够快乐，是人之常情，把快乐留在它该有的分量内，眼前可掌握的事便仍靠你自己一一做实。如此看全程，本次所求可以达到。

## 初六动 · 辰月

吃力有它的来由，仍在自己能承担的范围

雷地豫 → 水山蹇 → 震为雷

要花许多力气才能做成的事，也可以是自己做得到的事，这次考试能过。辰月下坤土当旺，你对应的是上震木，木在这一时节比较弱。木原能制土，所以承担眼前事情的还是你自己，方向并未颠倒。只是双方的力量这样悬殊，要将原本能够掌握的事一一办实，所花的本钱便大，不能照春木旺时的轻快来估量。

过程里还有艮土，同样强，坎水虽能生木，却正是水弱的时候，周围又有土来制它。这说明你自始便要凭自己的力量承担，中间即使稍有接济，也难替你卸掉很大一份负担。卦内没有金来克木，这是吃力而尚能做成的一个依据。木本身偏弱，只说明可用的余力少，不宜据此将旺土当成反过来克木的一方。

初六说「鸣豫，凶」，小象特将凶归在「志穷」。王弼从初时即得上应、安乐太过解释此爻。于是这句话的分寸，在尚有许多事须由自己承担时尤其清楚，到手的一点顺意宜按实看待，不能只因认得方向就先把事情看成已经办妥。爻辞所提醒的，恰在最初已有所凭时，如何把眼光放到尚须付出的那一段。你要面对的是旺土，即使这件事归自己掌握，也仍然需要一程一程承担，不能只凭最初认定能做便略过当中的工夫。

到最后，下卦变震，虽不是旺木相助，却已回到与你同类的局面，原有的能力到这里还能继续发挥。全程的吃力从自己掌握旺土、补养又弱而来，没有单独一处足以把慢定在哪一个日子。宜从起初直到收束的连续投入来量，费力与成事可以同在一卦，辰月这一场，结果仍能如愿。

## 初六动 · 巳月

起初有把握，走下去比想的费力

雷地豫 → 水山蹇 → 震为雷

能过这一场，依据在于从开头到收尾，事情始终在你能够作主的范围之内。巳月震木退气，你对应的就是这处木，起初面对的坤土却有夏火生养。木能制土，原是自己能掌握眼前事情的意思，可一边力量已退，另一边却在得力的时候，要将它真正担下来，比刚看出自己有办法时所想的更费工夫。

到了中间，又有艮土需要应付，也有坎水能生养震木。宜把两方面都看见，木确能由水得到一些接济，但夏天的水本弱，旁边的土又有力，它能送到你这里的帮助便十分有限。能过的主要根据，仍在这些有分量的事还由木来掌握，并没有另外出现一处金来约束木，让你失去本来能够做主的余地。

初六的爻辞为「鸣豫，凶」，小象落在「志穷凶也」。孔颖达解释，初六独得九四相应，初时便因有应而自乐，若这时就把志意停在欢喜上，后来要办的事倒容易顾不上。这句话落进你这场，尤其宜分清刚有把握与真正完成相隔多远。能做的根基既有，该由自己出尽的那一份力也还在，卦并未预先说你一定会失了分寸。

末段一变，上下同为震木，虽在夏天都已退气，毕竟同你相合，前面凭原有本领承担的事，最终能够有所收束。寅、卯日参看的是末震同气，不能因此便把夏木的力量看成当春之旺。把中间的费力看足，再把末后自己仍能作主的好处看实，便知道前面的辛苦为什么有它的用处。能掌握土，得靠你实际出力，到了收束原有的力量仍有同类相合，并没有在最后受到压制，因此辛苦有所得，整场可以通过。

## 初六动 · 丑月

最难的是一直要出力，方向始终在自己手里

雷地豫 → 水山蹇 → 震为雷

事情究竟在谁手里，比一时做起来轻不轻松，更能说明这次考试为什么能过。丑月震木力量偏弱，初遇下坤土却十分旺，依卦的关系，仍是木来掌握土，并没有因此换了谁制约谁。可由一方掌握的事，也有轻重之别，弱木面对旺土，需要拿出比平常更多的工夫才能办妥，这是本月进展较慢的来处。

后来还要应付艮土，能给你助益的坎水却在弱地，又有旺土限制它。因此想倚靠中途突然多一份厚实的帮助来使全局转轻，很难在卦里找到根据。宜把眼光放在你自己所能承担的部分，虽需多花力量，却始终是木去制土。局中没有金来直接克木，已有的本领仍有凭它做主、将事情接续下去的余地。

王弼读「鸣豫，凶」，讲初六刚得到上面的响应，安乐容易过度，以致志意穷尽。这句话处在起头，尤其能提醒人分清刚看到了有利的方向，和这件事已经真实做到哪里。你占得这一场，能办成的依据可以信，不能因此轻看需要由自己承担的分量。丑月水的支援薄，土的力量实，宜按这两处卦里的条件把工夫看足。

到了末后，下坤变为震木，和体木同类，虽然都在力量不足的时令，却已走到自己能够安处的地方。先前一路上须不断承担的旺土，不再以同样的情形留到最后，收束因而有了实在的好处。木弱确实使人费力，可木与木相合之后，原有的本领还有稳稳发挥的余地，这个变化照应的才是整场结果。要取时也不宜硬指某日，这一回费力是在全程，慢在要靠自己把该做的都做实，整场仍有能够通过的依据。
