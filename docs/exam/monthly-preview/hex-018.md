## 初六动 · 寅月

妨碍已经减轻，可供自己发挥的底子仍薄

山风蛊 → 雷泽归妹 → 山天大畜

若只问拦在你面前的东西重不重，寅月这一卦可以把话说轻些。可这场还是过不了，差处更多在自己能拿出来的力量有限。山风蛊的上艮属土，是应考的你，土在春天很弱。眼前的巽木和中间的震木正当旺，都有制土的关系。若只看到旺木克弱土，原会以为起初的压力十分沉重；实际能落在你身上的那一份，还要看中途与末后两处金能把木制到什么程度。

中间的兑金和末后的乾金都能制木，卦里又没有水来接济木，所以木旺虽是改变不了的时令，真正要你承受的压力却能减轻。可它们跟你自己还有另一层关系。土能生金，面对兑、乾是你要给出去，本来就薄的土并没有因帮手出现而多得一份滋养。春金也弱，所耗不算大，但少耗和真正得到补给之间，毕竟还差一步。

初六说「干父之蛊」，讲的是接过原有的事，能担起整治的责任。王弼解释小象「意承考也」，指出情况有变化，前人的做法不能全盘照收。用在考试上，你原来学得扎实的东西有它的用处，知道为何如此，自然可以随眼前所需有所取舍。这份能承接、也能调整的本领确实可贵，却还不能代替这场整体要有的力量。

所以爻辞「厉终吉」的吉并非一句空话。处事之初有危险，终于能够胜任所承之事，王弼、孔颖达都是据此讲吉。宜将它安在你自己确有能力承担的地方。到了末后，乾金仍须艮土去生，没有一处火直接回来养土，先前所欠的底子终究不厚。你已经掌握的，仍然可以踏实地用出来。可问到整场需要多少力量，情形却仍是靠原本很薄的春土独自支撑。

## 初六动 · 卯月

外面的压力减了，自身的底子还薄

山风蛊 → 雷泽归妹 → 山天大畜

原来制约你的力量，自己也遇到了制约，这正是卦里容易让人乐观的地方，可问到整场考试还是过不了。上艮是土，代表你，下巽是木，本来木能制土，中间还见同属木的震。在卯月正是木旺土弱的时候，如果两处旺木毫无顾忌，施加给你的压力应当看重。只是中间的兑金、末后的乾金，都对木有制约，局里也没有水去支持木继续加力。

因此，这一场不能说是外在的难处全都冲着你来，挡不住它才失利。那些看似能帮你的金，究竟是在替你减轻外面的压力，还是给你自己添了力量？若从木的一边看，是原本强势的一方受到约束，若从你自己的艮土看，却是你还要拿自身的力量去生金。春天金弱，你在这里需要付出的也轻，已经是对你有利的一面。只是自己的土气也很薄，少一些消耗到底没有添出原本缺少的实力。

「干父之蛊」的干，是能够任事。孔颖达解小象，说须看眼下事情的合宜之处来承接前意。放到应考上，原有的掌握并非无用，能明白何处该守、何处须调整，这就是确能承事的一面。爻辞的「厉终吉」由初任有危、终能胜任而来，不是凡事一占此爻，所问的每种结果都随之有吉。这个分别在春土薄弱的时候尤其有必要说清。

到了最后，下方变乾，仍是土要生金。回看整卦，从最初需要应付的木到最后自己需要付出的金，都没有一卦是火来生土。宜将减轻的压力按实处算在你能应付一部分上，而将未获得的补养也按实处留下。如此便能说明这场仍有可发挥之处，却没有足够力量把这些可取的地方连成一个合格的结果。

## 初六动 · 辰月

有力量接手，到收尾却还得由自己一再付出

山风蛊 → 雷泽归妹 → 山天大畜

开头有力量承当，这话在辰月很站得住，论到整场还是过不了。蛊卦以艮土代表你，土在此时当旺。眼前的巽木本来克土，过程中的震木也克土，可两处木在土旺时都受拘束，局里还各有金来制木。你面对的要求虽有压力，远未重到全然承受不起。因此并无必要为了说明结果不成，就把你原有的能力看轻。

真正费力的地方须往后看，因为中间的兑金和后来变出的乾金在辰月都得到时令照应，这两处又恰好都由土去生。从你能不能应付来看，旺土确能拿出力量；从事到末后有没有再给你一点接济来看，方向却是你向外付出。金还会制木，这一层对你有好处，却只是减轻旁来的制约。它并没有因此变成养土的一方，不能将一个好处算作两份。

「干父之蛊」，王弼讲初六处在事情开头，初次见任，因为确能担当，才说到「厉终吉」。小象又指出「意承考也」，继承的是用意，处事时还要按眼下情形作取舍。这对你是一个很实在的肯定。懂得某件事的来由，就能在需要时依其本意去做，既有力量也有分寸。爻意所许在能承事，并未将这一份可贵换算成所有想得的结果都能得到。

收束时的乾金很有力量，你的旺土确实还能继续生它，由此看得见的是你很能承担，也看得见直到最后究竟是谁在给谁。卦中从头到尾没有火来直接生土，只有土自己得时的那份根基。宜凭这根基承认你受害不重，又须凭末后仍向外耗力，认清这场还少了使付出转为自身补益的一层。能接手、能尽力，依然未能把整场带到合格。

## 初六动 · 巳月

既能承当，难处也轻，为什么还不能许过

山风蛊 → 雷泽归妹 → 山天大畜

就你自己的情形而言，巳月是颇能担得住的，整场考试却过不了。难处本来就轻，自己的根基也有凭据，因为蛊卦的上艮属土，得夏火之时而有力，正是你本人此时的情形。最先的巽木来制土，中间的震木也制土，但两木在夏天都已退气。它们又都遇上能制木的金，局内没有水来接济木。所以头一层虽有不顺，力量并不重，你原有的本事仍然能发挥。

往后是中间的兑金和末后的乾金，土要生金，所需的力量从你身上出。金在夏天很弱，你付出去的并不多，因而这里宜将话说得公允，原有底子不错，遇到的压力轻，最后要花的力气也轻，说你力竭或无从应付，都与卦不相称。真正欠的是这些轻处之外，还有没有一处能给你直接支持，使你不仅可以把事扛下来，还有做成所问之事的条件。

「干父之蛊」讲的是初次接任而能担事。王弼以初任说明「厉」，以堪任说明「终吉」。孔颖达释小象，又说要量事制宜，承前人的用意并不等于原样照办。这份判断落到考试上，是已真正掌握的东西，你能辨认它何以可取，也能按眼前所需去运用。能够这样承担，有它值得肯定的地方，并不因整场未过就变成无用。

不过，收尾的乾金和你究竟是什么关系，并没有随它的衰弱而改变。它仍是由土去生，卦里没有火来生土。夏令让你有力量承担，是原有底子的好处，不能再把这个时令当成收尾另获的接济。如此读，「厉终吉」所许的担当有它的着落，所问这场考试欠缺成事之助的地方也清楚。末后消耗虽轻，仍没有转作补益你的一面。

## 初六动 · 午月

有些事你确能承担，最后的力气仍由你出

山风蛊 → 雷泽归妹 → 山天大畜

能把自己分内的事情做稳，本是午月这场考试里有根据的一面。可问到合格与否，过不了。初六在蛊卦之始，爻辞说「干父之蛊」，王弼解作初次被托付事情，柔顺而能承担。之所以先说有危，又说「厉终吉」，正在初受其任时还有难处，后来能尽到所承之事。这句爻辞带着肯定，须看清它究竟肯定了什么。

在你这一边，有力量承担不是只凭一句爻辞。蛊卦上艮属土，夏令火旺而土有气，应考的你有自己的根基。下巽和中间的震虽都属木、能制土，如今木已退势，又有兑金和乾金来制木。金本身虽弱，卦里毕竟有这层牵制，反倒没有水来扶木。说你可以承受得较从容，是兼看了自己的力量和外面那份压力，两边都有来由。

不过，站在你身上看两处金，还能看见另外一面，它们在替你约束巽木与震木的同时，也都要由你的艮土去生。夏金微弱，付出不算沉重，但所付的方向是向外，不是有东西还给你。整个卦里也没有直接养土的火。这里不能因午火当令，便说卦里又凭空多了一处火，那样就把使你自己有气的一项好处算重了。

小象「意承考也」，孔颖达说有该增该减之处，要量事制宜。照这个意思，你能把原有根基用得合宜，已经当得起对你这份本领的肯定。若要凭这份本领再往前推到整场合格，末段原该有一层支持才好，可变出的乾金仍旧受土所生，从先前轻些的阻碍到最后轻些的消耗，始终未见有额外的力量归到你这边。因而不必夸大困难，也不能替所问的结果许得过宽。

## 初六动 · 未月

经得住眼前的压力，并不说明还能不断向外给

山风蛊 → 雷泽归妹 → 山天大畜

如果只问你能不能把眼前的事情接下来，未月这卦大可把你看得扎实些。问这场能否通过，却仍过不了。山风蛊的上艮土指应考的你，眼下正逢土旺，最初的巽木和过程中的震木虽都能制土，却并不当令，卦里还各有金能约束这两处木。因此早先所受的压力很有限，不能将结果难成一概归在应付不了外面的要求上。

看中间和看最后，都还须将土与金的关系转过来想。在木的一边，金有力，替你减轻的是来自木的压力。在土的一边，同样是这些有力的金，却要你付出力量去生它们。这样一来，妨碍小了，自己的根基却没有随之增加。未月的旺土固然经得起出力，说你一开始便耗尽自己没有根据；若将承受得住直接说成后面还有充足补益，也少了一层根据。

「干父之蛊」这个干字，是能任、能办的意思，而要理解这层担当做到什么分寸才合宜，正可接着读小象的「意承考也」。王弼说到事有损益，不能一切照承。落到你已有的掌握上，是辨得清本意，知道到了眼前究竟有哪些仍可用，有哪些须调整。正因确能承担，有便于落实的地方，爻辞的「厉终吉」才不是泛泛的好话。这一层宜好好肯定，不必为了说明这场不成便介意那个吉字。

## 初六动 · 申月

拦路的力量很轻，重的是一路要你自己出力

山风蛊 → 雷泽归妹 → 山天大畜

眼前并没有一层特别重的阻力挡着你，为什么申月这场仍过不了？蛊卦上艮属土，代表你；下巽和中间的震属木，原本都能制土。可是木在秋天最弱，当旺的兑金和乾金又能制木。这样看，初起的压力不必说重，事情并非一开始便难到你无法接手。木受制只是让你在接手的时候较能发挥，往下要付出的究竟有多重，凭自己现有的力量又能承担到哪里，才是和过关与否更相关的两件事。

中间的兑和末后的乾都是正当令的金，力量须由艮土来出，而你自己的土在秋天已退了气，不能照土旺时那个较为宽裕的分量估量。况且从中间到收尾，关系都是你继续给出去，全局没有一处火来补养艮土。金制木使你所受的压力减轻，是金对木的关系；同一处金又靠你去生，却是土与金的关系。前一层好处并不能把后一层的消耗也一并带走。

「干父之蛊」，干是能任事。王弼、孔颖达解初六，都从初次接事有危、能够胜任所以终吉来说。落实到你身上，接得过原有的东西，也知道不宜处处照搬，原本就是可取的本事。可爻辞肯定你能担起一件事，跟你能不能一直付出到整场所需的程度，毕竟还隔着力量的宽窄。尤其申月金旺而土休，耗力这一面分量很重。

到了末后，卦变山天大畜，名字虽有蓄积的意思，得先看是谁在蓄、是谁在给。眼下乾金得到土生，尚未见有力量反过来积在你身上。宜把起初木弱、阻力轻说到实处，也把后来两金旺、一再需要你出力的分量说到实处。合起来是能够着手、确有可取之处，末段却缺了让自身得到补充的条件，终难过关。

## 初六动 · 酉月

能把已有的接过来，也要看最后还剩多少力量

山风蛊 → 雷泽归妹 → 山天大畜

比起有没有机会发挥，酉月更要看的是，有了发挥的地方之后，你的力量够不够支持到最后。问这次考试，过不了。上艮是土，土在秋天退了气。与你相对的巽木和中间的震木此时又比你更弱，而且都受金所制，因而一开始并没有很重的阻碍。你能着手做自己有把握的事，这一点宜照实留下，不能因结果不理想便说处处受阻。

看起来替你挡住木的金，之后恰好成了需要由你出力的所在。兑金在中间，乾金在末段，都正当令。从木的角度说，它们够强，所以外来压力给你造成的影响有限；从你自己的角度说，土要生金，两处金越有力，这份向外的消耗越实在。全卦没有火能生土，于是你能花出去的和能够补回来的并不相称，这才是酉月左右整场的缘由。

小象解「干父之蛊」，着眼于「意承考也」。孔颖达说遇到该增该减之处，须按当下所宜承前人的本意。这份承接自有它的分寸，你真正掌握了某个道理，便能据其本意斟酌轻重，无须将过去的一切不问缘由地照样再做一遍。爻辞「厉终吉」指着初承其事虽然有危，实际能任，终有所善，这份肯定不必因所问的结果欠缺而舍去。

只是能尽到已有的本分，并不能说明不断付出之后还能得到补充，因为变卦的土金关系仍是乾金受益、艮土向外给，一直到最后都没有转过来。把起初的轻阻当作全程有助，就会漏看后半这一份尤其吃力的负担。说你仍有自己能做的，理由在两木失势；说整场难成，分量却落在两金都旺而你没有外来接济。

## 初六动 · 戌月

自己有力量收拾，不能把向外付出算成收获

山风蛊 → 雷泽归妹 → 山天大畜

能接手，也能把有把握的事办得像样，戌月并不缺这一层，却仍过不了。上艮土代表你自己，戌月恰是它得时的时候，下方的巽木与中间的震木虽然能够制土，本身却都受到时令拘束，另有兑金、乾金也能约束它们。起头即便不全由自己作主，所受的压力也不会很重。倘若说你一直在勉强挣扎，便将这份真有的实力看轻了。

单从木来制土看，冬月这一场会叫人担心压力很重。把卦看全，阻力其实轻些，结果却还是过不了。山风蛊的上艮土代表你，土在亥月力量受束。下面的巽木和中间的震木已有生气，原都能制土。只是卦里还见到兑金和末后的乾金，金能制木，因而没有理由把冬木的那份力量全算成已经落在你身上的妨碍。

亥月属水，木因此有生气，这一点已经顾到了。在局中却没有另外出现水来支持巽和震，不能把月令重算一遍，好像木受金约束之后，还能从卦中得到新的补给。这样把外面的压力看准，你是有可发挥之处的。可也须从自己的立场看，金能减轻木势，对艮土而言依然要土去生金，并未转成一份直接回到你身上的支持。

「干父之蛊」，王弼说初六处事之首，初次受任，因而有危，能堪其事则「厉终吉」。小象又说「意承考也」，孔颖达着眼于按事制宜。自己当真明白的东西，你既有本领接得住它，又能在它已经不适合眼下的情形时作出调整，这一份理解本就当得起爻辞所许的肯定。那个吉字不轻，但它指的是能够承担所接的事，并没有把应考时欠缺的力量也一同给足。

末段乾金在冬天已经退势，要你出力不多；中间兑金同样如此。可是你自己的土也缺乏余裕，又没有火卦来养。两边的轻处让这场不至于处处沉重，却都没有为原本不宽的根基另添力量。宜从过程中木仍制土、前后无所补养来看这次的欠缺，便不会随意说你做得不好，也不会把压力有所缓和误认作整场已经足够。

## 初六动 · 子月

能接得住原有的，仍缺使全场够得上的力量

山风蛊 → 雷泽归妹 → 山天大畜

在你这边，最紧要的是原有的力量究竟有多少，而不只是哪一处给你出了难处。这场过不了。子月的艮土有所拘束，正是你自己能够动用的底子。巽与震两处木都能制土，也都已有冬令的生气，如果只按这个关系去看，容易把事情讲成全因外面给的压力太重。细看还有兑金、乾金来制木，克土的力量实际上得到牵制。

那么，这两处金能不能算作给你的帮助？说能，是因为有它们在，木的压力可以看轻些；再问它们是否能养足你的土，关系恰好相反，土要去生金。冬金本身退气，所耗并不严重，但你也不是有厚实根基的旺土。这一来一往，属于你能安稳发挥的地方可以保住，已经不宽裕的力量却没有因此变得充足。轻阻、轻耗和直接生扶，三件事各有所指。

「干父之蛊」说的是承接父辈的事业。小象「意承考也」所说的考，指的是父亲，王弼解为初受其任的人能够承担前事，也知道所承的是本意，未必要将前人的做法照样一一搬过来。用到所问，你确有能够依已有的掌握处理眼前之事的地方。能承担所以终吉，是对这份能力的肯定，不能替代判断整场到底有无力量支持的那一步。

回到收尾，变出来的是乾金。一直到末段，仍是土将力量给出去，局内没有火回来生土。子月的水已经用来理解冬木有气，卦里并没有另一处水再来帮助木，所以中间的压力不宜夸大。把这一轻一弱都看清，才知道结果欠缺在原有的根基无所补养，而不是说你从头到尾皆被挡住。中段那份尚在的制约，便按中段来看它。

## 初六动 · 丑月

前面承受得住，临到最后还要继续向外用力

山风蛊 → 雷泽归妹 → 山天大畜

有本领让事情照常往下进行，和能将这场稳稳拿下来，中间差的是什么？丑月这场过不了，答案须往收束看。上艮是你，属土，正逢得时的月份。起初巽木虽能制土，却在土旺时力量有限，中间的震木也是如此。两木另外受兑金和乾金节制，开头并没有强大到使你处处不能发挥的限制，所以大可承认你有力量担起眼前的事。

初六的「厉终吉」，王弼解为担事之首，始而有危，能任其事则终吉。这里的吉相当实在，既不只是安慰人好好努力，也不应当在一切所问上都直接作吉论。小象「意承考也」，孔颖达说要按眼前事情斟酌增减，继承的在其本意。你肯用已有的理解来看还有哪些合宜、哪些需要调节，便是这份承担可以落实的地方。原有能力当得起这句肯定。

但卦里还有两处需要你付出。兑金在过程中，乾金在末后，同在丑月有气，都要艮土生它。你因为旺，确能给得出力，金又能制木，确实可以减轻外来的妨碍。宜把减轻妨碍这一层同你自己能否补得上分开。两金越能办它们该办的事，也越要靠土生，不能因此说金重新给土添了力量。放到整场看，这是接连付出了，却没有得到回补。

到了山天大畜，别因其名有畜就认作你本人得以积蓄。下乾仍是土所生，力量一直向外给，卦里又没有火来养土，因而你最后所能依靠的，还是自己原有的、在丑月也确实够扎实的那份本领。已经用它说明了你承受得住，就不宜再将它多算一份，去填中间和最后留下的消耗。整场难成，缘由在这里，跟你应不应该相信自己的能力并不矛盾。
