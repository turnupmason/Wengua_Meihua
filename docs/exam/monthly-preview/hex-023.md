## 初六动 · 寅月

起初还有相应之处，真正难担的力量在末后

山地剥 → 坤为地 → 山雷颐

最先还能做起来，走到最后，这场考试过不了。寅月代表你的是上艮土，到了木旺的时节，土自身没有多少气力。开头碰见的是下坤，也是土，所遇和你同类，有地方能相接，没法额外给你很多力量。由这一处只能说起步尚有凭借，前头又没有强的约束逼过来，尚未到显出差别的时候。

经过仍见两处坤土，都与原来的上艮同类，彼此眼下的分量也一样少。看见多处相应，可以说原来能做的能够延续一段，宜把这份好照实算进来。要说别处能否帮着把土扶起来，还得找有没有一处力量真正往你身上添，全卦所遇仍不见火来生土，几处弱土能接上的依旧是已有的一点。

「剥床以足」，小象说「以灭下也」。王弼说床是人能安处的地方，床足在下面，从这里开始受损，是可安凭的根本渐受削弱。孔颖达以削其贞正解释后半句，朱熹也取剥自下起。放在此占，开始能够相接，能接到什么程度要看下面的根本厚不厚，同类虽多，遇上压力时仍须看它们各自有多少力量。

春天这场难处，比秋天同样由震来克更重，重在木旺而土极弱。一路土同类，数目虽多，算的仍是同一时令里的力量。若把相应的几处当成几次强援，便会以为最后还有余力承住，实际卦里并没有添到这份力。

末了下坤变为震木，正逢寅月木旺，能克代表你的艮土。到这里，原来相处的一端由同类改成制约你的一端，两边轻重也相差很远。寅、卯日照末震取，宜参收尾较重的制约。未变时所见的相合，说明经过还有凭借，真正要落实的时候，没有力量扶起弱土，又受到最有分量的一处制约，这场考试终究过不了。

## 初六动 · 卯月

一路有相应的地方，到了结果却受实在的制约

山地剥 → 坤为地 → 山雷颐

先从末后遇到的一处来看，这场考试过不了。变出来的震是木，卯月木正当旺，所克的上艮属土，是自始代表你的那一端。几处同类的土在前面可以与你相应，等木真正起来制约，彼此的力量要重新摆出来看。原来有的一点把握放到这个时候，用来承担新遇上的压力，已经不宽裕。

最初的下坤可同上艮相接，两处土在木令都失势，一边能分给另一边的力量有限。到了经过还见两处坤，仍是这一层好，也仍只有当时那一点力。这里没有木来施压，情况便比到了末处容易些。可全卦也没有火来生土，原来的几处土想借旁力添厚，无从得到。用这一点看中间，既知道原有的本领还能做些什么，也知道它接不到哪里去。

读「剥床以足，蔑贞凶」，王、孔讲剥从下面开始，所削是人能安的根本。朱熹亦以剥自下起说凶。照到本次，前面还有几处相应，宜承认那时所做有凭；拿这些来论全场，仍应问能不能使少力的自己担得起后面的压力。真正遇上不利的时候，原有的能力还不足以承担，这才是爻义在所问上可以参到的一层。

小象所说的是下边能让人安稳的地方被削，照到眼前，起头位置的下坤正是到最后发生变化的一端。失去的是原先能和你相应的关系，又添旺木来克，两方面合在一起，结果才和途中显得的轻重不同。

寅、卯日照变出的震木取，参木在最后来克土的一段，此时所遇已经不再同类。卯月旺木起作用，弱土少援，结尾所受比前面需要承担的分量重。前中各处能相接，终究未能改变这份轻重，所问到了归处才显出不足，所以过不了。

## 初六动 · 辰月

能站住一程，收尾仍缺一股向着你的力

山地剥 → 坤为地 → 山雷颐

有本领，也有地方能把本领用出来，到了结果，这场考试为什么仍过不了？辰月的上艮属土，代表你，正在当旺的时候。起初遇见下坤，同样属土，也有力量，和你相接就有实际的用处。刚开始凭自己的本领有能办的部分，旁边也找得到同类呼应，于是开头能稳下来。这一段的好，在当时的土气里有根。

再往后看，两处坤同是旺土，还是与你同气，没有出现一处专来克你的力量。此时用已有本领做事，宜照有把握来取。几处同类相应，能把原来做得到的接下去，临到结果，又另有形势。这些土可以把自己原有的一份力量保到后来，但从头到尾也不见火来生土，真正需要新添一道力的时候，仍只能用原来的。

王、孔读「剥床以足，蔑贞凶」，取剥从最下面开始，所削的正是可以安凭之处。那一层原来有所依托，后来却被破坏，所以小象说「以灭下也」。用到这场，起头至中间的相应还照有力说。真正需要自己有凭靠的地方，末后偏出现一处制约，这转到哪里、能影响多少，宜依据末处的轻重说清楚。

古书说克体之卦气衰为宜，辰月确可取这一层轻，已经有力的艮土也能把前中所做的维持住。所问能否过仍看最后所遇，轻只是说受到多少阻，末处既有阻而无外助，早先的同气还不能替这一步定成。

最后下坤变成震木，木来克上艮，虽然辰月木弱，落在收尾也是一层制约。寅、卯日依震参应，指的是所求将定之处所受的牵制。木弱土旺，所受不能照春月说重。只是前面相应的地方没有延到末处，这里也不见新来相生的力量补进来，结果偏落到克你的一端，故本场过不了。

## 初六动 · 巳月

起头有照应，到了末尾所遇转来相克

山地剥 → 坤为地 → 山雷颐

前中两处都还做得来，这场考试仍过不了，所差在最后遇上的已经换了方向。巳月的上艮为土，代表你，土在夏天有火气，自己本有力量。开始下坤是同样有气的土，两个地方相应，能把原先有的力好好用出来。此处先看得明白，就知道难处没有落在开始，也不能把下面几处都照一个样子看。

到了经过，仍见两处能与你相应的土。两处都是坤，与原来艮土同样有气，已经能做的部分又往后接了一程。能继续依靠的，就是这些同类相应的分量。这里还须看合起来有没有新的力量来养你，卦里虽然土多，却不见火来生土。所以有力量做中间这一段，到了末处仍得看最后所遇，可不可以把事情接到成处。

「剥床以足」，孔疏以床足在下面说明剥从下起，朱熹也用剥自下起说凶。这番意思落到所问，可以从够凭靠的地方什么时候有变化来读。原来相应的一端能帮你站住，直到后来变为会制你的力量，最后所求已经很难由之前的那层相合承接，这便是本场真正的不同。

## 初六动 · 子月

先前能够相接，最后却由有气的木来克土

山地剥 → 坤为地 → 山雷颐

一开始还能相应，到最后却没能撑住，这场考试过不了。子月上艮土代表你，在冬日受拘，下坤原也是土，所以开头仍有可以相合的一段。两边都少力，能相应仍是好处，宜照有限的一点算。由此只能看出原来的力量还有地方可用，到了实际要受约束的时候，是否够用，要看后面那一处的分量。

经过里还有两坤，与上艮都属土，彼此互相接续的关系没有改掉。只是赶上子月，几处土都弱，所助究竟能起多大作用，要照它们自己的分量算。卦里没有火来相生，能把先前的工夫延续下去，与还能再添一份给你应付难处，是两个不同的分量，前者在这里见得到，后者一直没有来处。

初六「剥床以足」，孔疏说床足在最下，所削及的是可以安人的根本。朱熹同样说剥自下起，到了伤正便见贞凶。照这一场，前面有能相合的地方，宜看那一份支撑原来就少，再来一层实在的约束，能否凭相应的力量承下来。在末处遇到的木有气，这些同类的薄力不能抵尽它。

有力的木克在收尾，应该连它和土之间的轻重一起看。最先的困难还不明显，缘于自己与所遇同类，也没有力量来压住这几处。到归处不同，原先自己和同类能相接的力量又都弱，真正可以承当制约的分量便少。

走到归处，下坤成了震木，紧要的变化是从同类变成克自己的一端。寅、卯日照末震取，参这一处有力的制约。子月的土本来少力，末后木又确能压过来，局中再无能生土的火，站住一程的分量到这里就不够了，全场不能通过。

## 初六动 · 丑月

前面彼此能接住，结果却换成了制约你的一边

山地剥 → 坤为地 → 山雷颐

从起头到中间并不缺自己的本领，这场考试过不了，主要还是归处的所遇变了。丑月上艮土代表你，正当有力，最先相遇的下坤也属旺土。两处有共同的力量可以相接，开头便做得到一些事情。宜按旺土实际能用的分量来看这里，不能因后来有不利，就回过头把本来已有的能力也说弱了。

经过见两处坤，仍能和你相应。丑月的土气足，连着前面的本领，要做下去也有凭借。前和中如果合起来看，真正的好是已有的可以用，也能彼此相接。要说这一场能不能过，另有一个分量，看结果处是不是还和原先一样，或有没有旁来一处力量直接生你。盘里没有火生土，这种来力全场都没有。

「剥床以足，蔑贞凶」，王弼和孔颖达都从床的根本说起，剥到最下的足，人可安处的一端已经受伤。照此问，前面与中间有能够相接的所在，卦的结果处却另成一处制约。宜看此时支持从哪里来，能靠原来那份力走到哪里，结果并不单凭已经做到了中间这一点。

丑月几处土都旺，已有的力量足以维持前段，难处确实只见在转成震木以后。木并不强，也不宜用一句末克就把早先的好处都压低。只须照结果处所遇已改，眼下没有来生的力量，便知道此前的相应还停在过程里。

最后下坤一变，成了震木，木来制土。丑月震木不旺，宜按轻处说，寅、卯日参的是收尾这份制约，力并不厚。可偏在所求要落定的地方失去一处相应，又没有另一处来生扶，前面有力也没有接到最后，这场考试过不了。
