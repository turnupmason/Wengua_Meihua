## 初六动 · 寅月

指定解法被跳过，答数对也过不了

地水师 → 地雷复 → 地泽临

师初六逢寅月，这场过不了，卡在那道指定方法的大题。上坤土为体，在寅月死；下坎水休，为本用，由坤土去克，起头几道熟题大体能依常规动笔。题面随后把所用的方法明写在题干上，你眼熟的是另一种快法，草稿很快有了结果，到誊写时才发现指定的步骤没有一行在卷上。得数虽对，卷面仍缺题目要检验的推导。

体互坤土与原体比和，同在死地；用互震木正旺，反来克坤，所限在卷中成为实际阻处。旧案并参坎水生震、兑金制震，仍以旺木论中段受克。初六动变下坎为兑，上坤不变，合为地泽临；变用兑金囚而受体所生，收尾还有耗。全局无生体之卦，又有旺震来克，源断过不了。寅、卯日按用互震木取，参指定解法真正约束作答的中段。

「师出以律，否臧凶」，孔疏解律为法，否为败而臧为有功，指出一项看似有功也抵不掉失律。用在这道题，快法确实能算到正确答数，题目定下的推演仍得交出；另有可自由选法的题，才照自己最稳的路子写。《象》说「失律凶也」，借来说明失分落在规定上，本月卷面同时有弱体受旺用互克的卦理。

复习宜选一题兼有长、短两套解法，圈住题干所指定的那套，按要求从已知写到结果，短法只作为末尾验算。临场若做惯另一条路，在题号旁记下指定方法的第一步，再检查是否真按它起笔。已有几行可靠推导时照实留下，莫花时间为不合要求的做法另作解释。当前这一卷前几题能得分，重题的指定过程缺得多，仍够不上线。

## 初六动 · 卯月

能算到答案，卷面却走错了路

地水师 → 地雷复 → 地泽临

师初六在卯月，考试过不了线，要紧的一题没有采用指定的推法。上坤土为原体，春令在死；下坎水是本用，在休地，由坤土去克，开头阻力尚小，已有的训练还能让几问写得有条理。当题面另行指定一个要展示的方法，照熟例换路，往往可以很快得到数值，题目要看的过程却从指定的条件和步骤走出，数值相同也不能倒过来补这段推导。

体互坤土与原体比和而俱死，自身可守的力有限。用互震木当令旺，克坤，卷中看作题目给的写法压在要紧处。原案合坎水生震、兑金制震，仍以旺震见中克。初六变下卦坎为兑，合原上坤为地泽临，末兑金囚，受坤土生而耗体。全局找不到生体之卦，无法补上重题，按原断过不了。期取寅、卯，参用互震木之克，中段限制落得实。

「师出以律，否臧凶」，孔颖达说重点在失律后即使见功仍有凶。《正义》还辨因事制宜与故违明确禁令，二者所据不同。这里借来讲考试：正常允许多解时可各展所长，本题明写须用某一方法，就得看卷面有没有体现这项要求。照旧办法算对，仅足以说明数值；题所问的方法要另有纸上的步骤。

准备这种题，宜在同一道题里专练指定方法起步的两行，找到写完这两行之后哪些旧技巧仍然能用。考试中看到「用某法」几个字，先把它写在草稿开头，免起笔时仍用另一法。若一时想不起后续，写出肯定无误的一小段并移到别题，别将已会的题一起拖住。卯月其他地方有自己的分数，缺的是最重一问所指定的东西。

## 初六动 · 辰月

要点写得出，太长挤到作答框外

地水师 → 地雷复 → 地泽临

师初六到辰月，这场过不了线，难在论述时该写的要点没能留在题定的篇幅内。上坤土当辰土而旺，为不动的体；下坎水死，为本用受坤所克，起头手里的能力够用，熟题能稳着写。写长答前没先估计纸面位置，将原可一句说明的背景铺开，后面转到论点时已经没有多少地方可落笔。

体互坤土与原体比和同旺；用互震木在囚仍来克原坤，中段所限不重，遇到单独的约束仍能照要求写下去。初六动下坎为兑，合上坤成地泽临，末兑金相，由旺坤去生，到了结尾还要往外给力。全盘没有生体一处，体旺减早段的难，末泄仍牵住结果，依原断过不了。这一月原案只留篇幅和位置上的毛病，未从盘中另立支日应期。

经说「师出以律，否臧凶」，《象》以「失律凶也」讲明原因。孔疏辨否为破败、臧为有功，特意把有功而违律也写在内。应在这卷，文字里说得在理是一层，正式答题究竟写到多少、写在何处又是一层。已写进合规位置的几个要点算得上所得，最后那段即使自己知道怎么说，超出题定的作答范围就落在卷面之外。

练习论述可以照题定行数先分三处，每一处先落结论与最关键的一条证据，再看所剩位置是否容得下解释。非写不可的术语应挨着与它相关的判断，背景中对结论不起作用的句子就收短。平日按这个行数读回，若删去一行还能推出原结论，那行便可留给下一问。临场后半段发现快没地方，宜写出尚缺的要点和支撑它的事实，留在规定位置以内。这次早段做得扎实，末卷没能交全要点，总分仍不够。

## 初六动 · 巳月

答数多半对，漏掉的步骤把分拉下去

地水师 → 地雷复 → 地泽临

师初六入巳月，考试过不了线，失在几道题习惯把该交代的步骤并掉。上坤土在夏令得相，为原体；下坎水囚，作本用而受坤所克，开题并不难，熟悉的计算多能写准。原本心里能走完的几步，到了纸上只留前后两行，看得出所求结果，却看不出中间用了哪个条件。分着问的题，这一处落在不同的小问上，所得就一段段少下去。

体互仍坤，与原体比和同相，有可自行稳住之处；用互震木休，来克相坤而阻力轻。初六动下坎成兑，与上坤成地泽临，变用兑在死，受体土所生，末处仍有轻泄。全局不见一卦来生，早段体克本用虽能办理，不能填足几问累积的所欠，原案过不了。寅、卯日按用互震木取，所参是过程所受的一层轻约束。

「师出以律，否臧凶」。王弼说失律而有功，与败失的后果相类；孔疏更辨场中制宜与故违规范。借到卷上，省去不必重复的计算可以节时，题面分开要求的理由仍要分别写。看到得数正确，只能说明眼前这一环合题，漏掉的过渡仍要补足。《象》说「失律凶也」，这次正见于一次次省掉要求落实的部分。

复练时可将题干写着「说明」「列出」的地方用笔标明，做完一题宜查答案有没有对应文字。容易并掉的两步，可以一行说明成立的条件，一行列出得到的关系；有限时间先保证这两行，修饰性的文字留到最后。一卷过后也可逐题记下自己总在哪一步省写，下次专练把那一处留下。眼前这场正因若干小处积在一起，分数仍不够。
