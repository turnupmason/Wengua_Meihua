## 初九动 · 寅月

能辨题意，还欠独立作答的功夫

乾为天 → 乾为天 → 天风姤

这次考试过不了，但你并非无从下手。乾为天，互卦仍为乾，所问的考试同你已有的积累有相合之处。熟悉一个道理，再遇到相近的问法，往往知道从哪里着手。本卦给你的这点便利应当算进去，落到能否合格上，还须看你能把这个开头做出多少实在的内容。

寅月以乾金为体，金囚，本用和两互的乾金也同处囚地。好比备考时能够沿着讲解跟到末尾，撤去提示，要自己说明为什么从这一步走到下一步，才看出掌握得深浅。几处比和都指向既有的基础，不能当成几股另外来扶你的力量。《梅花易数》讲同类相助还须看同类本身有无力气，这层分别在春令尤其要紧。

初九说「潜龙勿用」，小象说「阳在下也」。龙已经在，位置却在下。《文言》说到「行而未成」，用到问考试，着眼的是懂得的东西尚未成为这一次可以交验的成效。单凭这句爻辞，推不出究竟是哪一道题有失，也没有理由说你平日的功夫全都白费。

初爻一变，下卦成为巽木，上乾仍是你的体。金能克木，事情要由你自己收拾到位，偏偏寅木当旺，承担这一着的乾金又弱。复习时可挑一道自己觉得已经懂了的题，先合上讲义，完整作答，再对照要求检查哪里借用了题中没有给的条件。真正值得补的，正是离开提示便解释不清的那一步。这里的主动，是在有限的时间里选对根据、按要求把事情做完，不能只从金克木三个字便推成事易。

## 初九动 · 卯月

熟悉的解法须经得起换问

乾为天 → 乾为天 → 天风姤

这次考试不能通过，卦中最容易看重的一处，是好几处乾金都与你相合。上下皆乾，互卦也是乾。拿平日的学习来对照，这种相合可以是看得懂题意，能辨出它在问哪一类问题，却还不能据此断定你已经能把每个必要的理由讲清。

卯属木，木旺而金囚。乾金代表应试的你，本用是你所面对的考试，两互看中间能怎样接续。它们的五行相同，确实少了一层相互妨碍，所凭借的力量却一样偏弱。如果一道题改变了原有的条件，还需自己辨明熟悉的解法可以用到哪里。这个需要独自作判断的地方，不会因为前面认出了题型便自行解决。

「潜龙勿用」中的「潜」，说明有其才而尚未显于用。小象以「阳在下也」说明初位，并没有把龙说成无所能。《文言》把隐而未见与行而未成相提并论，移到这次考试，重点便是知晓和做到之间尚有距离。不能据龙之为阳，便把潜藏着的本领取作已经达标的表现。

动后成天风姤，原体乾金要制变用巽木，木在卯月有力，收尾处需要的功夫比认出方向更重。练习时不妨把旧题的一个条件换掉，再写一遍原来哪条理由还能保留，哪条已经失去依据。如此能查到理解停在什么地方，也能分清真正掌握的部分和沿着旧答案才会做的部分。此盘没有指向某一天的独立事件，勿从月令推出考试失利的日子。

## 初九动 · 辰月

底子能担事，成效尚未显

乾为天 → 乾为天 → 天风姤

这次考试过不了，却不能把缘由讲成底子太薄。辰为土月，乾金得相，体与本用比和，向内看两互仍是乾金。以考试来讲，你所具备的条件与所考的要求可以接得上，遇事也有自己承担的力量。若只按《求名占》体用比和的一面来读，这原是支持通过的理由。

初九的「潜龙勿用」，恰好要在这样的好条件里仔细读。小象说「阳在下也」，取的是龙在初位的时与位。龙的可用之才并不因潜而减少，只是问这场考试，所求在本次能否显出成绩。能做和已经做到之间，还隔着把所学准确交付的一步。《文言》所谓「隐而未见，行而未成」，将这个差别说得很清楚。

变为天风姤，巽木在辰月为囚，受有力的乾金所克。按这个关系，你能主动料理眼前的要求，卦里没有足以推出题目格外艰险的东西。也正因如此，末段宜查的，是自己能够完成的工作究竟有没有完整体现出来。有可控制之处，仍须经过实际运用才能成为这场考试的结果。因此，爻意在这一个问题上能影响成败，不能将它推广成凡遇初九，所做之事一概无成。

可取一份自己熟悉的练习，只据题目明示的条件写答案，让没听过你原先讲解的人也能看懂依据。再逐条对着要求看，哪些话只是心里有数，哪些内容已在答案里说到了。这比反复揣测难题出在哪里切合此爻，也较能照见本来有力的地方为何尚未成为此次过线的凭据。

## 初九动 · 巳月

解题的中间一层还须接牢

乾为天 → 乾为天 → 天风姤

按卦来看，这次考试过不了，难处无需归到某一道特别难的题上。上下皆乾，取互仍为乾，开头所接触的要求与中间要运用的本领并不相背。平时能够听明白一种做法，见到相近的要求也能想到那种做法，这些相通的地方都可以承认。只是你若再追问一句，为什么偏在这里这样做，答案便要由你自己组织了。

巳月火旺，乾金处死地。这里的死是说在这一季难得其力，同类虽多，仍是几处失令之金。卦里没有另外一卦来生体，也没有直接克体的卦，因此宜把力气放在充实已有理解上。若把火旺直接说成遇到某种外来刁难，就越出了本卦的关系。金处死地仍能同金相合，宜保留那些经过练习已经能解释清楚的部分，把功夫用在真正断开的地方。

「潜龙勿用」，小象以「阳在下也」指明阳气所居之位。拿来解释眼前的考试，是已有所得还不能充分见诸实际运用。若只练习照样复述，看起来头尾熟练，中间默认了哪些前提却不容易看出来。可将一个常用结论写下来，试着说明它何时成立，再举出一种不能照用的情形。

变卦天风姤的下巽属木，巳月木休，仍要由原体乾金去克。所问之事本身并非强旺到不可料理，但承担它的金更不得时。不要为了把一处生疏讲通，把已经会的部分也说得含混。能清楚区分可确定的条件和还没有把握的推论，才知所学究竟落实到了哪一步。

判断：这次考试能通过。本用乾金与体比和；体互乾金与体比和；用互乾金与体比和；变用巽木受体所克。

旺衰：丑月，体卦乾金相；本用乾金相；体互乾金相；用互乾金相；变用巽木囚。

爻辞：九四「或跃在渊，无咎。」；象曰「“或跃在渊”，进无咎也。」。

专业说明：本用、两互皆乾金，与体比和，变卦巽木受体克，无生体、无克体之卦；辰戌丑未月体相。《占卦诀》「无克体之卦，则吉事必可成就矣」（792 行），《求名占》「体用比和，功名称意」（553 行），变卦体克用，《求名占》「体克用，名可成，但成迟」，定为能过。九四「或跃在渊，无咎」，象曰「进无咎也」，与盘面同向。

取期依据：辰未戌丑乾体、乾用同金而相，按本用比和取申、酉日，所应仅为开头得以着手。
