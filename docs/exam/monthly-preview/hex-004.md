## 初六动 · 寅月

开头能着手，中途旺木制体

山水蒙 → 地雷复 → 山泽损

这场考试过不了，寅月的难处主要落在中途。初爻在下坎动，以上艮土为体，下坎水为所问之用。体能克用，原是自己可着手处理的关系。寅土无气，坎水在休而仍比艮土易动，故虽看得到从哪里入手，真要照此答全，还不容易。能从题面先把一项事实认清，仍应将它用到相应的地方。例如题设同时给出一般原则和一个限制，开头能用的是两者合起来仍然成立的那部分。

互坤同属土，在本月也处死地，与艮比和所能给的帮助薄，而另一互震木得令，直接来克艮土，本用坎水也能生震，后来变兑又克震，源断把两者相抵，仍按旺木看中段的克。初六变后，下坎成兑，卦为山泽损，体艮还要生兑金。兑囚，末段的耗用较轻，难处仍集中在旺震克弱艮的经过。全盘缺的是生体这一层，体互比和不足以将前面的制约转开。

初六「发蒙，利用刑人，用说桎梏，以往吝」，说读为脱，指解去拘束。王弼说疑明以后刑与解各得其当，同时告诫刑不可长。问考试，知道原来错在何处，就按实际依据纠正，误会解开便可以回到题意。将一种更正手段用到所有题目，反会失去分寸。

可挑一题曾经答错的练习，先写出旧错因为何种前提不成立，再找一个换了条件的例子试办，改了问法但仍有同一前提，可用原先校正过的办法，真正变了条件才须重新判断。这样用发蒙之意，能在中段受制之处辨出根由，勿只凭记熟了旧答案向后推。

## 初六动 · 卯月

查出旧错有用，中途的限制仍重

山水蒙 → 地雷复 → 山泽损

按盘本场过不了，卯月在中段遇到的制约较实。初六在下动，上艮土是原体，下坎水为考试本用。盘面为土克水，说明确有能亲自料理的部分。只是艮土失去时令，坎水尚休，真要以已掌握的办法把所问说透，起步也要多费功夫。先认清一项条件怎样用，能保住开头力所及的一段。

体互坤与艮同土，卯月皆死，比和也很薄。用互震得木令，来克原体，坎生震与末兑克震按源断相抵，中段仍见旺木克弱土，到了下坎化兑而成山泽损，末变金囚而耗土较轻，真正难以承担的克仍在经过处。又没有经卦来生艮土，不能单凭前头有可着手的地方便把这场断成。答到由事例推及一类情形的地方，先看这一类是不是都具备已经用过的前提，才能知道该补哪一层。

「发蒙」在王弼注里从疑事得到照明来理解。初六既有「用说桎梏」，也有「以往吝」，能脱开疑滞，仍须知道何时收手。问到考试，宜打破已经察出的一个误解，照实说明判断为何要改。若题意换了，先诊清有没有原先那种毛病，不能见到相似字眼便一律套同一个更正法。

练习时可对照一份旧答与订正版，指出第一个实际不成立的理由，再找一道条件略异的题，看看改过的理由是不是也适用。找得出相同前提便照用，找不到就从新题给出的事实另推。这比把两份订正抄熟，更能照见哪处由自己作得准，哪处到了中间仍有制约。

## 初六动 · 辰月

开局做得动，收束还会多费力量

山水蒙 → 地雷复 → 山泽损

就此盘，考试不能通过。辰土当令，上艮作原体而旺，初六下卦坎水作本用，水失时，土能制水，起头有力量处理所问，看到题意中可以落实的一层，能依已有见识写出一个可靠结果。开头的把握应该保留，后面耗费的部分仍须照末处自己的关系来看。

体互坤土也旺，与艮同气，是经过中可以相应的一层。用互震木囚，虽来克体而力轻。到初六动成山泽损，下坎变兑，兑金于辰月得相，要由上艮土来生，末段的耗用有实际分量。原体旺可承受一些，却未改变体生用的去向，盘里又无生体者，这一层在《梅花易数》求名所论的终应上不利，故断过不了。

初六说「发蒙，利用刑人，用说桎梏，以往吝」，王注所重是疑明以后处分各得其当，施治不可无止境。移到答题，可以据规则查一处实际错在哪里，也该将已经解决的疑滞放下。若只因手里还有些力气便将已答妥的一段重新改写，牵动下文，正容易使末段耗得比原先更多。这句还能用来检查所谓的错究竟在哪里。若只是同原先的答案用词不同，先看它们各自说明了什么，免得多费精力。

复习时可拿已经订正过的一份作答，从末句反查它究竟引用了哪些前面的结果，必须更正的内容也宜逐一查清会不会改变后来用到的理由。已经足以证实所求的部分就留着，把工夫用于仍需补足的那一层。这样在初段强处能做成确实的工作，到终处也较容易分辨哪里值得追加力量。

## 初六动 · 巳月

开头能制，中途有克，末处还要出力

山水蒙 → 地雷复 → 山泽损

这次考试过不了，巳月开头并不差。初六动于下坎，上艮为体，得到相气，下坎水囚而受土克，自己有力量料理考试中的要求。若从题面已经辨明一项事实，能够用平时的办法答出一段，这便是本用可制的一面。已经能做的内容照实写下来，随后须看各层所需有没有改变。比如起头从一条限制判断了适用范围，后面的结果若想说得更宽，便必须核清题中另有哪些事实容许这样做。

体互坤得相，与艮同气，经过处可以相应，用互震木在休地，仍有木克土，力度较轻。变为山泽损，下坎成兑，巳月兑金死，末泄不重，但每处的牵制都要照旺衰看，盘里没有来生艮土的卦，结尾的去向仍是原体生变用，求名所取的结果受其影响，故依本盘过不了。取寅卯参用互中间的克，所取的时机同结果的末应各有根据。

「发蒙，利用刑人，用说桎梏」，小象说「以正法也」，王注又说明已经发蒙以后，按实情分别施治与解除。后句「以往吝」所戒的是沿强治一路走下去，用于考试，真正错误之处要按清楚的准则更正，疑处既已厘清，便应回到尚未写足的要求。

可选一次自己改了多遍的短答，圈出哪一次更正实际改变了结论，哪一次只是换了措辞。若关键事实没有改变，继续改写对完成所问往往没有帮助。练习时把空出的时间留给尚缺依据的结尾，更能照见巳月开头的力量可以用在哪里，以及中间、末段各有何种牵制。

## 初六动 · 丑月

起步已能办，末段还要实在投入

山水蒙 → 地雷复 → 山泽损

依本卦这回过不了，丑月宜将开头可办和末段耗力分开看。上艮为体，土旺，下坎水为本用处死地，艮能制它，事情由自己先办一段不难。如果有熟悉的办法确合题意，可以照实际条件答出所求。这个初段有力的地方应算在判断里，而到了收尾的要求，则还须看最后有什么依凭。

体互坤也旺，与艮同气，用互震木囚，来克原体的力度不重。初六使下坎变兑而成山泽损，得相的兑金仍要原体艮土来生，收成要在已经出力之外再付工夫。全盘缺少生原体的卦，就求名看，末段是体生用，尽管原体有力，最后仍不利于所求，故取过不了。取申酉日参相兑所耗，是看末处怎样应事。

《周易》初六说「发蒙，利用刑人，用说桎梏，以往吝」，注疏认为疑窦既明，应依其事而处，可治也可解。考试里真正的错处应该改，但已经得当的便不必继续以同一手段去查出更多毛病。强于起步也容易使功夫过多落在真的不必再动之处，爻辞正好可以节制这一点。

可用一份答过的练习核清末句需要何种支持，若依赖前一问，便核对前一问是否已经列清条件，缺哪一项便给那一项补写依据。若前面的内容已经够用，就不为换一套写法使后文重新再做。这样能够保住丑月开始确实能做成的部分，也能正面处理最后要耗去力量的部分。特别是最后还要说明判断过程时，应指出前一问的结果如何应到当前条件，而不只是抄一遍原来的结论。
