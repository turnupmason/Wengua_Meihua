## 初六动 · 寅月、卯月

两行字的题，要先证出两步

水山蹇 → 火水未济 → 水火既济

简断

过不了。打头的那道大题只有两行字，动笔才发现要先证出两个小结论才能往下写，这一关比看上去陡；往后的题也得一层层自己推，快不起来。套路题你做得熟，那几道写全，分丢不了。

开局：题面短得让人放心，问的却是一个要先垫两步才用得上的结论。两步垫不稳，结论就没处落脚，越想补齐越往里陷，在这里耗掉的时间，后面整张卷子都得替它还。

过程：往后的题不偏，哪一道都要自己从头捋，找不到现成的台阶。

结局：「往蹇，来誉」，往前硬闯是难，退回来反倒得称许，小象只一句「宜待也」。那两步一时证不出，就先跳过，这是这一爻给的分寸；可这张卷子上没有一处借得上力，跳过省下的工夫，只够把会的写完，第一题丢掉的那一大块，到交卷也没补上。

应期：以下为传统推算的参考窗口。
可留意本月21、22号前后，实际作答转回熟题后能按原次序展开，属吉应。近期若有计时练习，可查先搁下难题以后哪部分真正做完了。

总断：考不过。头一道大题暂且放下，套路题写满，最后真有余下的时间，再回去碰那两步。

一条定理只记得一半

水山蹇 → 火水未济 → 水火既济

简断

考不过，差在第一题。那道题要用的定理你认得结论，适用条件只记得一半，写下去每步都悬着；后面的题倒写得顺，熟悉的做法都用得上，时间还有富余。顺的那部分是你的分，整张卷子就缺这一块。

开局：定理的结论一眼就认出来了，难在它什么时候成立：有一条限制说不全，这道题偏偏就卡在这条限制上。不写它，推导不完整；硬写，又怕写错。这一处篇幅不大，分值却重，全卷数它最实。

过程：往后几道都是熟门熟路的题，下笔快，写完还能回头看一遍。
