## 初九动 · 寅月、卯月

同一个道理，反过来再问一遍

天泽履 → 风火家人 → 天水讼

简断

同一个知识点被反过来问，背熟的那套说法一句也用不上，卷面就此离线还差一截。那道题要你当场重新组织理由，偏偏它前面的材料又长，读完理顺，留给它的只剩零头时间。前几题照老路子写，分不会丢。

开局：题面朴素，几道基础题按惯常的路数写下去就是。

过程：难处在卷子半腰。它不问结论，反过来问为什么不能那样做，原先的答句全派不上用场，得从定义重新推。这一段的阅读材料又格外长，光是读完、分清哪句有用，就花去一大截工夫，轮到这道题时，表上的指针已经走得很远。

结局：「素履，往无咎」，穿着本色的鞋往前走，不出过错。你照本色作答，写下的每一句都站得住；那道题却要你倒过来走一遍，问的是为什么不能那样做，往前走惯了的鞋，倒着走就迈不开。没出错的句子都算数，缺的是那段得重新推出来的理由。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，反过来问的那道题，背熟的说法套不上，属凶应。同一知识点换个方向问自己一遍，理由当场组织。

总断：差在那道反问题上，落在线下的就是这一题的分。反问的那题先写你最有底的一层理由，别把时间全押在上面；其余各题守住平常的写法，不添花样。

草稿上省掉的几步，卷面上一步一扣

天泽履 → 风火家人 → 天水讼

简断

几道小题和练过的差不多，那几分是实的。分值最重的大题排在前面，评分细到每一步，草稿上省掉的两三步正是扣分处，补写又是一大段，挤掉了后面几题的时间，总分就够不上线。

开局：几道小题眼熟，答得出。

过程：那道大题位置靠前、分值最重，像正午的日头直晒下来。它要求步步见诸纸面，用了哪个条件都得注明，这类题在草稿上又最容易省掉两三步。补是补得上，一补就是一大段，等写完抬头看钟，剩下的题已经没有余裕。
