## 初六动 · 寅月、卯月

一眼看到底的卷子

风地观 → 山地剥 → 风雷益

简断

能过，省力。这张卷子比你练过的要浅，题干短，设问直，大半题读完第一行答案就出来了。会丢分的只在一两道题上：后半句还藏着限定，要读到句号再落笔。

开局：卷面铺得很开，题目却都薄，翻完两页就知道这一卷的深浅。

过程：写下去一路顺，难度没有起伏，草稿纸用不了几面。

结局：小孩子看东西，看个热闹就走，王弼注初六的「童观」，说是「趣顺而已」。这一卷浅，顺着写也能写对大半，吝只落在那一两道后半句另有要求的题上，丢的是零碎分，动不了大局。交卷前还有整段空闲，拿最熟的那套办法从头核一遍，看浅的地方捡得回来。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，收尾回查时把一处看浅的要求补完整，属吉应。近期若做整卷，可留意最后回查那一段有没有把前面的理由补齐。

总断：过关，而且宽裕。读题读到句号，剩下的时间够从头再查一遍。

古籍依据：《周易·风地观》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·日应》《梅花易数·先天后天论》。

## 初六动 · 巳月、午月

看得懂，写不出

风地观 → 山地剥 → 风雷益

简断

考不过。题你几乎都见过，看答案也看得懂，可这张卷子不考认得，考的是从空白写到结论，每道解答题都要一步步拆，拆到后面时间不够，最后两道只写了个头。选择、填空这类认得就能答的题，分保得住。

开局：前几道选择题顺手，看一眼就知道出自哪一节。

过程：解答题一道比一道厚，条件给得实，每拆开一层都得停下来想下一层怎么接，钟走得比笔快。

结局：「童观」是站在远处看，看见了样子，摸不着里面。看懂一道题的解法和亲手把它写出来，中间隔着好几步，这一卷偏偏把分押在这几步上。写到最后两道，想换成平时最顺手的写法收尾，那套写法也只够起个头，后面的步骤接不上。

应期：此盘暂无有据的日期可列。

总断：后两道解答题，中后段的步骤分大多没拿到，所以过不去。前面认得就能答的那部分，一分别漏。

古籍依据：《周易·风地观》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》。

## 初六动 · 亥月、子月

余下的时间留给熟题

风地观 → 山地剥 → 风雷益

简断

能过，不费事。题量、难度都在你手上，写完还剩一大段时间。这段时间别花在最难那道上，倒回去查那几道和旧题长得像的：它们最容易换了一个条件，照老答案写就白丢分。

开局：拿到卷子先排顺序，排得很快，几乎没有要犹豫的题。

过程：越写越松，难的那两道也找得到入口，写完看表，时间还宽。

结局：「童观」的毛病在看得浅，浅处恰恰是最熟的题：看着眼熟，眼睛就不肯往下读了。小象叫它「小人道也」，图省事的看法，答卷吃亏就吃在这一眼。好在收尾那一段手上有空，熟方法也趁手，逐题对一遍条件，看浅的那一两处改得回来。

总断：稳过。剩下的时间去核那几道眼熟题的条件，比啃难题值。
