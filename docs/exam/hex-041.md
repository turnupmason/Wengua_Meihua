## 初九动 · 寅月、卯月

卷子正中横着一道综合题

山泽损 → 地雷复 → 山水蒙

简断

过不了，卡在卷面当中那道大综合题。它来得像一声闷雷，一上来就要你把几个条件同时用上，你熟的那几种题型都套不进去，草稿越写越多，后面的题跟着被挤。前几道小题耗时不多，分照拿；那道题写到能单独给分的一步就收住。

开局：前两道题不费什么劲，交出去的工夫有限。

过程：翻到卷子当中，那道综合题横在路上：题干长，要求一条压着一条，平时练的几种套路一个也对不上。你在草稿纸上换着法子试，每试一种都要从头推，钟一分一分走，这一题还停在半截。整张卷子最重的一下就落在这里，而且落得早。

结局：后面几题本身不难，只是时间已被那道题吃掉一截，写得匆忙。「已事遄往」，手上的事了结了就快走；「酌损之」，减要掂量着减。那道题推到能单独得分的那一步就该放手，再磨下去，丢的是后面的分。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，真正写题时一项本来要办完的要求较难完成，属凶应。近期若做限时练习，可核哪一问要先写到能单独得分的一步。

总断：考不过。综合题写出能给分的一步就转身，前后小题一题不丢。

古籍依据：《周易·山泽损》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。

## 初九动 · 巳月、午月

看懂了，不等于写完了

山泽损 → 地雷复 → 山水蒙

简断

考不过，分就丢在一个「快」字上。卷子不难，有道题按步骤给分，要你把每条依据一条条写出来，你看懂了就跳去下一题，步骤只落了一半，几分就这么漏掉，总分正差在这几分。其余顺手的题，分都扎实。

开局：翻开卷子，头几页全是熟面孔，提笔就有。

过程：按步骤给分的那道题夹在卷子腰上，看着不起眼，分量也轻，难只难在它不认结论，只认一条条写出来的依据。

结局：「已事遄往」是事情了结了才快走，这道题偏偏是没了结就走：心里明白了，卷面上却只写了一半。「酌损之」让人掂量着省，该省的是复述题干的话，不是阅卷要看的步骤。收尾几题你写得动，前面漏掉的那几分，到交卷也拣不全。

总断：过不去。转题照样可以快，阅卷要看的那几条依据一条不省，漏的分能少一截。

头一道大题收不住笔

山泽损 → 地雷复 → 山水蒙

简断

过不了线，时间大半折在头一道大题上。它要你写一段很长的说明，能写的点多，写完一条后面又牵出一条，等收住笔，钟已走掉一大截，后面只能赶。卷子当中那道拗口的题其实好对付，分保得住。

开局：头一道大题摆在最前面，要你把一件事从来由讲到结论。可写的点一个接一个，草稿纸翻过一面，题还没收住。全卷数这里最吃时间，比后面哪道都重，而它偏偏排在第一个。

过程：过了这道，卷子腰上有一题绕了个弯，平时的路子照样走得通。

结局：末尾题量不小，时间却已经不从容。「酌损之」三个字正对着头一道大题：题面要的那几点写到了就停，多出来的周到不加分。小象说「尚合志也」，办完该办的就走，心思才跟得上整张卷子。
