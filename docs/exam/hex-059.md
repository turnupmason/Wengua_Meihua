## 初六动 · 寅月、卯月

算得出，写不成理由

风水涣 → 山雷颐 → 风泽中孚

简断

卷首两题有几分眼熟，这套卷子的路数又和平时练的对路，前面写得不卡。卷尾那道大题按理由给分，结果算得出来，可它要一步配一句凭什么，理由一栏写得稀稀落落，扣掉的恰是线上那几分，整卷就此停在线下。

开局：眼熟的只有开头两题，借得上的不多，往下写也不卡。

过程：再往后那道材料题你拆得开，拆出来的那个结论，压轴题还要拿去当台阶。

结局：压轴题前半截用的正是刚才那个结论，后半截却要逐步交代：这一步依据哪一条，为什么可以这样换。每一步心里都清楚，纸上却只留了算式，阅卷照着理由一栏一栏扣。「用拯马壮吉」，健马救急，救在起头；这一卷起头确实顺，靠的就是这匹马，卷尾那一栏理由，得自己一句句写上去。

应期：以下为传统推算的参考窗口。
可留意本月19号前后，练压轴题时算式写全，理由一栏又空着，属凶应。压轴题每写一个算式，旁边补半句依据。

总断：卷尾那题每写一个算式，旁边补半句依据，结果哪怕没算完，写出的理由也有分。理由一栏写得太稀，这回总分差着几分。

过程：腰上那道材料题又长又密，你理得出头绪，就是一行行磨，钟走了一大圈。

改错题改不动

风水涣 → 山雷颐 → 风泽中孚

简断

第一道几乎就是一道做过的原题，借着它起步很稳。卷尾那道改错题全卷分值数它最重：给一份现成解答，要找出断在哪一步再改对，毛病看得出，完整的一版却拿不出来，整卷离线还差这一题。

开局：第一道和你做过的一道原题几乎一样，照着旧步骤写，又快又准。

过程：往后几题换了新问法，办法想得到，笔下却越来越迟。

结局：最后那份现成解答看着工整，其实中间有一步断了，后面全是顺着错处写下去的。断处看得出，可要改对，就得把后半段整个重写，而这题恰是全卷分值最重的一处。初六讲起头有健马可乘、脱险要趁早，这一卷的健马确实来过，就是第一道原题；到了卷尾，马早已跑远，后半段只能自己重写。

总断：改错题先标出断处、写明错因，能落在纸上的先落下。后半段没能重写完，这一回落在线下。

## 上九动 · 辰月、未月、戌月、丑月

跳来跳去，乱了次序

风水涣 → 山雷颐 → 坎为水

简断

满卷题目道道要慢慢磨。那道分步作答的大题要求按指定的次序作答，卷上写了第二步又回头补第一步，跳来跳去接不上，几步对的也连不成一份答案，整卷离线还差几步。

开局：前面几题件件得从头琢磨，没一题能一笔带过。

过程：到了那道分步作答的大题，题目要你按一、二、三的次序写。你先写了最顺手的第二步，回头补第一步，又发现第三步要用第一步的结果，只好在卷面上加箭头、插小字，越补越乱。

结局：上九要人把伤散掉、走远，「远害也」；那道题的乱就是伤，乱了就别在原处越改越乱，空出一行重新按次序写一遍，比在旧处插字强。后面几题写下的几小步不会互相打架，无咎留得住那些小分，补不上线。
