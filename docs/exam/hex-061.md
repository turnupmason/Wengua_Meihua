## 初九动 · 寅月、卯月

开头一关硬，底子撑得住，这场能过

风泽中孚 → 山雷颐 → 风水涣

简断

开场那项要求分量实在，会结结实实卡你一下，好在你这阵子底子正足，扛得过去，这场能过。中间的难点拆得开，练熟的步骤接得上，后面还会补进一点小帮助。认准一套做法写到底，别一见别的解法就推倒重来。

开局：一上来就是一项硬要求，分量不轻，正好压在起笔的地方。你手上的准备足，读清题意后按最有把握的做法下笔，顶得住。

过程：过了开头，中段的疑点能一个个拆开，平时练熟的步骤在这里接得顺，前面耽误的时间能追回来。

结局：初九说安守本心就吉，另有所图便不得安宁。放到考场上，就是认准一套练熟的办法写到底。后面会补进一点帮助，分量不大，或许是想起一个漏掉的条件，够把开头丢的分捡回一些。

应期：以下为传统推算的参考窗口。
可留意本月22号前后，正式成绩较易确认本场达到合格要求，属吉应。若本场已考且正在近期等分，这几日前后较容易见到正式反馈。

总断：能过，靠的是自己的底子。开头那关咬牙顶住，之后别换思路，多出来的时间拿去补漏。

古籍依据：《周易·风泽中孚》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·体用》《梅花易数·占卜克应之诀》《梅花易数·八卦万物属类》《梅花易数·先天后天论》。

风泽中孚 → 山雷颐 → 风水涣

简断

这一场能过，只是一路都要下功夫。开头那项要求硬，你的余力不算宽裕；中间又有一道分量足的题要慢慢啃，后面补回的不多。考前把最拿手的一套解法练到不假思索，考场上认定它，别在两种写法之间来回改。

开局：开场的要求比看上去严，卡得实实在在。你这时精力只算平常，先挑最明确的那条路走，把基本分拿稳。

过程：中间那道题牵扯多，想彻底压下去得花不少工夫，熟悉的步骤能用上一部分，剩下的要现场推。这一段最该稳住，别急着换方法。

结局：初九讲一心守定才吉，三心二意就不安稳。卡在中段时最想改道，越改越乱。后面还能找回一条漏掉的依据，分量轻，要前面写得扎实才接得上，过线就靠这一点点攒起来。

总断：能过，但不轻松。考前补熟分量重的综合题，考场上重题量力而行，拿手的部分先写完整。
