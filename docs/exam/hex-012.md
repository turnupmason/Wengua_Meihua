## 初六动 · 寅月、卯月

头一道长题推通，后面跟着通

天地否 → 风山渐 → 天雷无妄

简断

考得过，要磨的是后半张那几道长推导。题目给的条件少，没有现成步骤可抄，每一步都得亲手推出来。好在这几道是同一个路数，头一道推通了，后面几道顺着同一条思路往下写，分是一点点挣够的。

开局：第一、二题只给了零星几个条件，读完题面手上没什么可借，只能从定义推起。

过程：第三题往后，推导一题长过一题，环环相扣。

结局：最吃工夫的是后半张那几道长推导：步骤多，中途断一环就得倒回去重推。春天的茅草根扎得深，拔一根要使足力气，可根是连着的，「拔茅茹，以其汇」，一根起来，旁边同类的跟着就松了。头一道推通，后面几道走的是同一条路。初六的吉在一个「贞」字上，守着正路慢慢推，不去抄近道，所以过得去。

应期：以下为传统推算的参考窗口。
可留意本月11、14号前后，从做过的题里挑出一个真正适用的步骤，属吉应。近期若复习，可拿自己写过的题来比对。

总断：考得过，花的是笨工夫。时间先留给后半张，前面的小题写完就走。

古籍依据：《周易·天地否》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·体用》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。

题不难，难在多

天地否 → 风山渐 → 天雷无妄

简断

能过，要磨的是速度。卷子上没有一道题真拦得住人，每道都不深，可题量大，一题慢半分钟，积到最后就是一整道题的时间。同类题挨着做，一个思路连着用，比按顺序一道道重新想要快。

开局：题干把条件给得齐，只是埋在长段文字里，要先挑出来。

过程：做到一半，题目一道接一道都是浅题，手却一直停不下来。

结局：夏天的茅草长得密，一片连着一片，正合初六「以其汇」的样子：这张卷子的题按类成片出现，同一类的四五道，用的是同一个办法。挨着写，办法只想一次；跳来跳去，每回都要重新想起。收尾几道更浅，前面省下的时间到这里正好用上。守住练熟的写法不换，这份「贞吉」落下来就是写得完。

应期：以下为传统推算的参考窗口。
可留意本月11、14号前后，通过练习意见弄清一个原来不懂的条件，属吉应。近期若有评阅，可问清用法之后做一道新题。

总断：过得去。别在第一题上抠细节，整张卷子写完，分才是全的。

## 初六动 · 申月、酉月

秋草一拔就起

天地否 → 风山渐 → 天雷无妄

简断

不费事就能过。难一点的那几道，到你手里都拆得开，没有哪一处真拦路。唯一的隐患是手快，步骤跳着写：阅卷按步骤给分，想到的那一步不落在纸上，就不算数。

开局：题目给的提示浅，这张卷子也用不着它，题型都是常见的那几种。

过程：往后换了问法的题也好拆，转一下就回到熟路上。

结局：收尾几道没有硬骨头，像秋天干透的茅草，根松了，手一提就带出一串。「拔茅茹，以其汇」，同类的题连着出来，你连着写完。初六的「贞」在这里落成一个很小的动作：每道题按次序把步骤写全，哪怕觉得显然，也写上一行。

总断：稳过。交卷前那段空闲，回头把跳过的步骤补成完整的一行。
