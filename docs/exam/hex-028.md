## 初六动 · 寅月、卯月

材料一长，就啃不完

泽风大过 → 乾为天 → 泽天夬

简断

卷子上每道题都拖着一大段材料，读得懂，可要从里面拣出有用的那几句，只能一行行去啃；啃过的那几道几乎没有扣分处。啃完前三道，墙上的钟已经走过大半，后面的大题来不及动笔，卷面停在线下，材料太长啃不完。

开局：考的都是见过的知识点，题目本身不偏，难在每道都裹着一大段材料。

过程：熟悉的那几套做法这时用得上，可也只是熟，没有一套能让你读得快一点，进度一直落在后面。

结局：器物放到地上之前先垫一层白茅，「藉用白茅，无咎」，《系辞》称作「慎之至也」。你答卷就是这样垫着写的，每句落笔前都对过材料，卷面上挑不出错；可这卷子的难处全压在材料的长度上，越慎越慢，后面几道空着，总分落在线下，慢就慢在每句都对过材料。

应期：以下为传统推算的参考窗口。
可留意本月18、19号前后，中段照熟悉的次序核出一处漏写的条件，属吉应。材料题先看设问，再回材料里找句子。

总断：读材料时先看设问再回头找句子，前几道省下的时间，挪给后面的大题多写几步。材料太长，这一回停在线下。

古籍依据：《周易·泽风大过》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·日应》《梅花易数·先天后天论》。

## 初六动 · 亥月、子月

两道变式题找不到入口

泽风大过 → 乾为天 → 泽天夬

简断

卷子大半是常规题，你按熟悉的步骤稳稳写完，这部分分拿得住。难在两道变了问法的大题：条件还是那些条件，问的角度变了，你绕着看了几遍也没找到第一步，只写出半截，这回差在线下。

开局：常规题铺了大半，步骤都是练熟的，写得稳当。

过程：到那两道大题，问法拐了个弯，你在草稿上试了几条路都走不通，时间一点点耗过去。

结局：初六处在最下面，小象说「柔在下也」，守着底下这一层，不出差错。你这一卷也是这样，常规题一道没写错，「无咎」落在这里是实的。可要过线，还得往上够那两道变式题，够不着，稳妥写法攒下的分就差了这一截。

应期：以下为传统推算的参考窗口。
