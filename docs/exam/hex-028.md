## 初六动 · 寅月、卯月

材料一长，就啃不完

泽风大过 → 乾为天 → 泽天夬

简断

卷子上的题干都长，后面拖着一大段材料，你每道都读得懂，可要从里面拣出有用的那几句，得一行行去啃。考不过：啃得仔细，错处很少，啃完前几道，轮到后面的大题，表上只剩一小截。前面写下的部分，几乎没有扣分的地方。

开局：题目本身不偏，考的都是见过的知识点，难在每道都裹着一大段材料。

过程：熟悉的那几套做法这时用得上，可也只是熟，没有一套能让你读得快一点，进度一直落在后面。

结局：放东西前先垫一层白茅，「藉用白茅，无咎」，《系辞》称作「慎之至也」。你答卷正是这个样子，下笔前先垫稳，落到卷面上的字句几乎挑不出错。可无咎只管不出错，不管分够不够；这一卷的分量摆在材料长上，慎重换不来时间，后面几道空着，总分就落在线下。

应期：以下为传统推算的参考窗口。
可留意本月18、19号前后，中段照熟悉的次序核出一处漏写的条件，属吉应。近期若有练习，可专查条件写全却少了一步的题。

总断：过不了线。读材料时先看设问再回头找句子，前几道省下的时间，挪给后面的大题多写几步。

古籍依据：《周易·泽风大过》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·占卜克应之诀》《梅花易数·日应》《梅花易数·先天后天论》。

核一遍就翻页

泽风大过 → 乾为天 → 泽天夬

简断

稳过，不费事。卷子考的正是你最熟的东西，题题有现成的路子，写起来快。唯一会拖你的是太小心：一道小填空核了又核还不放心，大题的时间就被挤掉。每题核一遍，确认了就翻页。

## 初六动 · 亥月、子月

两道变式题找不到入口

泽风大过 → 乾为天 → 泽天夬

简断

卷子大半是常规题，你按熟悉的步骤稳稳写完，这部分分拿得住。坏在两道变了问法的大题，考不过就考不过在这里：条件还是那些条件，问的角度变了，你绕着看了几遍也没找到第一步，只写出半截。

开局：常规题铺了大半，步骤都是练熟的，写得稳当。

过程：到那两道大题，问法拐了个弯，你在草稿上试了几条路都走不通，时间一点点耗过去。

结局：初六处在最下面，小象说「柔在下也」，守着底下这一层，不出差错。你这一卷也是这样，常规题一道没写错，「无咎」落在这里是实的。可要过线，还得往上够那两道变式题，够不着，稳妥写法攒下的分就差了这一截。

应期：以下为传统推算的参考窗口。
