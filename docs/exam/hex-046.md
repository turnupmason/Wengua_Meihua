## 初六动 · 寅月、卯月

每一步都得现推

地风升 → 雷泽归妹 → 地天泰

简断

卷面上的难处其实拆得开，前两处卡点换个角度都能解。麻烦在卷子里没有一样现成的东西可用：公式要自己推，格式要自己摸，每道题都从零起步，写到后半张已经没时间，总分离线还差一截。

开局：头一道大题落在平日很少碰的一块，乍看吓人，细看只是绕了个弯，弯绕过去就松了。

过程：后面要把题里几条线索串起来，也打了一个结，同样解得开。真正拖住你的，是卷面从头到尾不给样子：没有例题格式，没有现成公式，每写一步都要先回想、再推。

结局：交卷前，最后一道还空着一半。这一卦在《梅花易数》里占过一回：有客来问今日动静，断出当天有人请饭，席上只有黍米和鸡，书里说卦中没有相生的东西，所以菜不丰。这张卷子也是这样，席开了，菜要自己做。「允升，大吉」，初六在最底下，跟着上面一道往上升，升得名正言顺；你下手的方向一直是对的，只是每一级台阶都得自己垫，垫到一半，铃就响了。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，第一步要用的公式，又得当场现推，属凶应。把每类大题第一步要用的公式默写一遍，记不全的圈出来。

总断：拆得开的先拆，每道题先落下能推出的第一步，别去找捷径。时间都让现推吃掉了，卷上的总分还没到线。

## 初六动 · 巳月、午月

眼熟的题改了一处

地风升 → 雷泽归妹 → 地天泰

简断

卷子里的题大多认得，后半张落笔也轻快。偏偏第一道大题是练过的老题型改了一个条件，你按老路子写，步步都顺，答的却是旧题，这几分丢掉，总分差一点到线。

开局：那道大题眼熟得很，一看就认得是练过的那种，题干里却有一个限制和练习时不一样，藏在第二行。

过程：往后要自己把思路理一遍，难度不高，只是那个没留意的改动一直跟着，越往后越别扭，答案总差一点对不齐。落到纸上的题倒写得快。

结局：分数就差在最前面：方法用得熟，答的却是老题，不是这一题。初六升得上去，靠的是和上面心思相合，小象叫「上合志也」；这道大题偏没和题目合上，后半张写得再轻快，也只是轻快，那几分没处补。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，做到一道眼熟的旧题，偏偏改了个条件，属凶应。拿练过的老题和新题逐句对照，圈出改动的那个条件。

总断：落笔做那道大题之前，把题干和记得的老题逐句对一遍，改了哪里，就从哪里另起。那一处改动没看出来，卷面便没能过线。

## 初六动 · 申月、酉月

两道大题吃掉了半场

地风升 → 雷泽归妹 → 地天泰

简断

前面几题门槛低，看一眼就有思路。后半张两道大题每道都要铺满一页，步骤一环扣一环省不得，写到最后一题的大半，铃声一响，卷面总分落在线下。

开局：几道小题都不刁，题意一读就明白，下笔没有犹豫。

过程：再往下，思路也理得清，偶尔一个小坎，回头看一眼就跨过去了。时间是从动笔那一刻漏走的：一道看着会做的题，要写的步骤比你估的多出一截，草稿纸翻到了第二张。

结局：压在最后的那道最长，从头推到尾，一步跳不得，停笔时还差三步。初六「允升」，往上走是顺着上面的势，一路被认可，前面那几道小题写得干干净净，正是这个样子；后半张没有势可借，长题只能一行一行往上垒，垒不到顶。

应期：以下为传统推算的参考窗口。
可留意本月18、19号前后，一道长题的步骤，比估的多出一截，属耗应。限时写一道长题，到点只看主干写齐了没有。

总断：长题先写主干几步，细节回头再补，别让一道题从头吃到尾。这一回时间漏在长题上，分数还差几分。
