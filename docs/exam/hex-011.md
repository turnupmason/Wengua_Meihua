## 初九动 · 寅月、卯月

认得的只有连根那一把

地天泰 → 雷泽归妹 → 地风升

简断

翻完整张卷子，熟面孔只有连在一起的那几道。考不过，其余的题都不在你常练的路数上，每道都得从题干一点点往外推，推到卷尾那道换了一套条件的题时，钟已经快走完了。连着的那一串做对了，这部分是实打实的分。

开局：第一题就要你把一整套推导从头写出来，卷面上找不到一句现成的话可以照搬，落笔很慢。

过程：往后换了个角度考，好在题目自己把方向点出了一半，没有走岔；只是理由要一条接一条地交代，草稿纸用得飞快。

结局：「拔茅茹，以其汇」，拔起一根茅草，根连着根带出一把，这本是吉辞。卷子里那几道熟题就是这把茅草，一道通了，几道跟着通。可整张卷子只有这一把，卷尾那题条件全换，和前面不是一个根，吉落不到它身上。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，卷尾碰到不能沿用前题条件的变式，属凶应。近期若有整卷练习，可检查最后一道变式的起手。

总断：过不了线。先把连根的那一串写满，卷尾那道能写几步写几步，别把前面的时间搭进去。

古籍依据：《周易·地天泰》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·体用》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。

## 初九动 · 巳月、午月

顺手带出来的最后一题

地天泰 → 雷泽归妹 → 地风升

简断

卷子不难，一路写得顺，熟题一道牵出一道。过不了，错在最后那题：它把前提悄悄换了，你顺着前面的做法一口气写完，整题从起点就偏了，这题一丢，总分就沉到了线下面。前面那些顺题的分，照数都在。

开局：前几题要交代的东西不多，写完一道，还有空闲把下一道的题干读两遍。

过程：后面换了个问法，你停了一下就找到了路，这一停没耽误多少。理由要写，三言两语也就够了。

结局：「以其汇」是同类相随，一拔一串，前面的题确实是这样连着出来的，吉辞落在这里。卷尾那题看着也是这一串里的，根却不同：条件里有一处和前面相反。前面的做法搬过去，每一步都对，起点错了。吉只照到同根的那几道。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，写到卷尾碰上与前面不同的前提，属凶应。近期若有练习，可核相近两题从哪一步必须分开写。

总断：这一关够不上线。动笔写收尾那题之前，先把它的条件和前一题逐条比一遍，变了的那条圈出来。

## 初九动 · 申月、酉月

同一段铺垫写了好几遍

地天泰 → 雷泽归妹 → 地风升

简断

一组题共用一个题干，你每一问都把同一段分析重写一遍。考不过，时间就耗在这些重复的字上，轮到卷尾那道变了条件的题，只剩几分钟。题本身不难，要写的量却大得出奇，前面写下的每一问都给分。

开局：第一部分要交的东西就很多，一题顶别的卷子两题，笔一直没停。

过程：接着是一组连着的小问，同出一个题干。每问都要交依据，你把题干的分析在每一问前面都抄了一遍，卷面越拉越长。换角度那一处倒没卡住。

结局：茅根相连，「以其汇，征吉」，几问同一个根，本该一次拔起。吉辞应验的，只是那组小问全答对；答对却是用重复的篇幅换来的，卷尾的变式轮到时，笔还没停稳就要交卷。

应期：以下为传统推算的参考窗口。
可留意本月18、19号前后，同一组题逐一写依据时耗时过多，属耗应。近期做模拟，可分别记录共用步骤与每问单独步骤的用时。

总断：合格不了。共用的分析写一次，后面每问用「由上一问」接着往下写，省出的时间正够卷尾那题。
