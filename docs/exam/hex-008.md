## 初六动 · 寅月、卯月

卷尾那题刚冒了个头

水地比 → 山地剥 → 水雷屯

简断

前面零零碎碎有几处小规定，守起来都不费劲，只是一处挨一处，时间被悄悄分走了。考不过，输在卷尾那道要成段作答的大题：该写的东西最多，答案刚铺开半截就收卷。守住规矩的那些小题，分照拿。

开局：读题时这里要求写单位，那里要求标出处，都是小事，你一条条照办了。

过程：往后的题同样平平，没有一道能难住你，可每道都比预想多花一两分钟。

结局：最后那题分值最重，问的内容你都会，偏偏要一层层写出来，字数抵得上前面几题加在一起。初爻这一变，卦就成了屯，草木刚破土、还没长成，这道题的答案也就停在刚冒头的地方。「有孚盈缶，终来有它，吉」本是吉辞，讲诚意装满一只朴素的瓦缶，日后自有意外的好处上门；这一卷找不出一道能省力的题，前面又一路零碎地扣着时间，吉只落在小题守了规矩、没有乱丢分这一层，照不到卷尾那半截答案。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，卷尾要把想到的内容整段写上答卷，属耗应。近期若做限时整卷，可记下卷尾成段作答实际用了多久。

总断：够不上线。前面小题写快些，把省下的时间整块留给压轴那题。

## 初六动 · 巳月、午月

每一问后面都要跟一句依据

水地比 → 山地剥 → 水雷屯

简断

这套卷子偏向你最少练的写法：每答一问，都得交代依据的是哪一条定义、题里哪一个已知。过不了，依据一处缺一处，分一问一问被扣掉。有几条要求写得宽，没有字面上那样死，照常理作答也能得一部分。

开局：题面一摆出来，每道小题末尾都缀着「说明理由」四个字。

过程：有几道看着规定很严，细读才发现留了余地，写个大意也给分。

结局：真正吃亏的是那一串依据。答案你写得出，凭什么这样写却常常落了空：用了哪条性质没点名，条件从哪来没交代，阅卷按点给分，每题都少那一两分。缶是粗陶罐子，初六讲诚意要像装满这只罐子一样实在，最后才有意料之外的好处。吉辞是吉辞，偏偏这一卷依据题密，又找不到一道能直接搬用的熟题，吉只落在你写下的每句话都老老实实、没有乱编上，补不回依据缺掉的那些分。

应期：以下为传统推算的参考窗口。
可留意本月11、14号前后，原答案可能仍缺一项规定要写的依据，属凶应。若近期已安排评阅，可先查自己写过的结论有没有相应的支持。

总断：这场考试合格不了。作答时给自己定个动作：写完答案，紧跟着补半句「因为……」。

## 初六动 · 申月、酉月

分是一小片一小片剥掉的

水地比 → 山地剥 → 水雷屯

简断

卷子不难，从头写到尾都顺手，时间也够。考不过，丢分全在细处：单位漏一个，符号抄错一处，订正时又把原题的一条限制改没了，一处扣一两分，攒起来恰好落在线下。会做的大题照样拿满。

开局：第一页的题你几乎不用打草稿，看完就落笔。

过程：翻到后几页依旧顺手，写得快，回头检查的时间都留出来了。

结局：问题出在检查那一遍上。回头改一道题时，你只盯着算错的那一步，原题里一句「结果取整数」随着改动丢了；前面几页的单位、正负号也散落着小错。这一盘夹着山地剥的象，像墙皮一片片往下掉，每片都不大，掉多了墙就露了底。初六说「有孚盈缶」，罐子要装满才算数；这句是吉辞，吉落在你大题写得扎实，可罐沿上这些小缺口一处没补，分数就从缺口里漏到了线下。
