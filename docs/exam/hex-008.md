## 初六动 · 巳月、午月

每一问后面都要跟一句依据

水地比 → 山地剥 → 水雷屯

简断

这套卷子偏向你最少练的写法：每答一问，都得交代依据的是哪一条定义、题里哪一个已知。依据一处缺一处，分一问一问被扣，缺到第五六处，总分就没够上线。有几条要求写得宽，没有字面上那样死，照常理作答也能得一部分。

开局：题面一摆出来，每道小题末尾都缀着「说明理由」四个字。

过程：有几道看着规定很严，细读才发现留了余地，写个大意也给分。

结局：真正吃亏的是那一串依据。答案你写得出，凭什么这样写却常常落了空：用了哪条性质没点名，条件从哪来没交代，阅卷按点给分，每题都少那一两分。缶是粗陶罐子，初六讲诚意要像装满这只罐子一样实在，最后才有意料之外的好处。你写下的句子确实句句实在，阅卷挑不出一句乱写的；可依据题一道挨一道，卷上又找不到能直接搬来用的熟题，实在换不回那些没写出来的依据分。

应期：以下为传统推算的参考窗口。
可留意本月11、14号前后，答案写对了，依据那半句又没跟上，属凶应。每写完一问，回头圈出它用到的定义或已知，没写出来的当场补上。

总断：每写完一个答案，紧跟着补半句「因为……」，把这个动作练成习惯；眼下缺的依据太多，总分还没到线。

## 初六动 · 申月、酉月

分是一小片一小片剥掉的

水地比 → 山地剥 → 水雷屯

简断

卷子不难，从头写到尾都顺手，时间也够。丢分全在细处：单位漏一个，符号抄错一处，订正时又把原题的一条限制改没了，一处扣一两分，几处凑起来，总分差几分到线。会做的大题照样拿满。

开局：草稿纸几乎没动，前几页的题看完就落笔。

过程：翻到后几页依旧顺手，写得快，回头检查的时间都留出来了。

结局：问题出在检查那一遍上。回头改一道题时，你只盯着算错的那一步，原题里一句「结果取整数」随着改动丢了；前面几页的单位、正负号也散落着小错。这一盘夹着山地剥的象，像墙皮一片片往下掉，每片都不大，掉多了墙就露了底。初六要的是「有孚盈缶」，瓦缶装到满。大题你装得满满当当，缶沿上却磕出几道细豁口，一处没补，分数就顺着豁口一点点漏到了线下。

应期：以下为传统推算的参考窗口。

总断：细处小错一点点攒，这次就没够上线。往后检查时改哪道，先把那道原题从头重读，限制条件一个个对过。
