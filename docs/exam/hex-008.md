## 初六动 · 寅月、卯月

水地比 → 山地剥 → 水雷屯

简断

可以把手里真实做过的题交给熟悉要求的人看，尤其别避开做得最不完整的那一问。实际约束较多，收到意见之后还有不少工夫得自己花。眼下有改进的路，整场仍偏难通过，宜先专注一处可改的疏漏。

开局：春令死坤本用仍克休坎，开头有规定要办，压力偏轻。

过程：死艮体互与死坤用互都克坎。自身整理受到约束，卷面上也有实在要求，两处都须照看。

结局：初六有孚则免咎，诚实可有额外的吉。旺震变用受休坎生，末段落实反馈耗力较多，前中又见克体，本次仍偏难。

总断：把最不完整的一问拿出来核清，再留时间亲手重做。能接到指点，距过关仍有一些差距。
