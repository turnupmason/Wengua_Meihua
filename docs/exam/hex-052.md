## 初六动 · 寅月、卯月

半路换了考法

艮为山 → 雷水解 → 山火贲

简断

考得过，功夫得花在卷子半路那道换了考法的大题上。整张卷子往你少碰的几块上偏，这道题又来得早、来得硬；越往后题目越透亮，回头补它，丢掉的分能追回大半。

开局：头几道题面熟，可每题都比练过的深一层，写得不快。

过程：写到半截，一道分值不小的大题把熟悉的考点倒过来问，旧步骤一套就错，卷面会在这里停很久。

结局：前面写对的，别因为这一下就涂掉。「艮其趾」，脚还没迈出去先站住，所以「无咎」；落笔前那一顿，正是这一爻要的。后面几题把条件一题比一题给得透，看明白题目到底问什么，再折回去补那道大题，大半的分追得回来，「利永贞」就应在照原路稳稳走到底。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，后来较容易理清题目的边界，属吉应。若仍在备考，这几日前后可重做一道自己从开头就看偏的题，找准什么时候该停下来重读。

总断：过得去。那道倒着问的大题先空几行留着，等后面看清了再填，别在原地耗。

古籍依据：《周易·艮为山》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·体用》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。

后半张越写越亮

艮为山 → 雷水解 → 山火贲

简断

能过线，要磨的只是一问。卷子大半是你练熟的那类题，半路有一问拐了个弯，照老路写会掉进去，得停下来重想；拐过去以后后半张越写越顺，前面没写透的地方，交卷前还来得及补上。

开局：题都是熟面孔，照平时的顺序一道道往下写就行。

过程：有一问把常见的条件悄悄换掉，照老路写会得出一个看着对、其实不对的答案，得停下来重算一遍。

结局：后半张卷子一道比一道亮堂，前面给的条件到后面都派得上用场，回头再看那一问，错在哪一步一眼就看得出。初六「艮其趾」，脚未动先停，于是「无咎」；在那一问上停一停、不急着往下抢，正合这一爻。交卷时卷面是完整的。

总断：拿得下。拐弯的那一问别凭眼熟下笔，读完最后一句条件再动手。

一大段材料喂出一道难题

艮为山 → 雷水解 → 山火贲

简断

过得了，要磨，磨在那道带长材料的大题：材料一段段都像有用，问法又和练过的不同，挑句子、换思路要耗掉半场的力气。收尾补得回的分不多，过线靠这道题写得稳。

开局：起笔几题用得上熟悉的写法，只是每题都慢半拍。

过程：那道大题先甩出一大段材料，句句像相关，真正撑得起结论的只有寥寥几句；等你把它们挑出来，才看清它问的方向跟练过的岔开了，思路得重新搭。

结局：没核实的句子不往答案里塞，宁少一句也别错一句。「艮其趾」是未迈步先止住，小象说「未失正也」，守的就是这份不乱塞。快交卷时会看出一个先前漏掉的条件，添上去能多两三分，不多；真正把分数托在线上的，还是大题里你挑得准的那几句。

应期：以下为传统推算的参考窗口。
可留意本月16、28号前后，末段有机会看懂一个漏掉的条件，属吉应。若还没考，这几日前后适合回看材料题，辨出过去略过、其实直接决定结论的那句话。

总断：能合格。材料先划出证据句，划完再定往哪个方向答，别整段往卷上抄。
