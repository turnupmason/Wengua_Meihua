## 初六动 · 寅月、卯月

第一锹就想挖到底

雷风恒 → 泽天夬 → 雷天大壮

简断

题目并不刁，前后几处关口都低。总分还差一截没到线，毛病在第一道大题：题目只要结论和两步理由，你从定义一路往下推，推到最底层才肯停，留给后面几题的工夫就这样被它吞了。会做的题都在，轮到它们时已来不及写全。

开局：题型对路，前几问一看就知道从哪里下手。

过程：再往下，每道题里都埋了个小坎，单拿出来都不难，难的是每到这里，手边剩的时间都比该有的少一截。

结局：症结在第一道大题。浚是往深处掏，初六刚踏进恒卦就要掏到底，小象说「始求深也」，凶就凶在这个「始」字：深本身不错，错在太早。末尾那题本身不硬，前面掏下去的那些时间却收不回来，它只来得及写几行，总分因此没过线。

应期：以下为传统推算的参考窗口。
可留意本月18、19号前后，卷尾那题只剩几分钟可写，属凶应。第一道大题写到题目要的那一层就停，抬头看一眼钟。

总断：开卷大题写完结论和那两步就收笔，把时间让给后面几题。这回够不上线，会做的那些题至少要写到纸上。

## 初六动 · 申月、酉月

越挖越深的那个坑

雷风恒 → 泽天夬 → 雷天大壮

简断

卷子偏硬，偏偏硬在平日碰得最少的几块，前两三题之后几乎每道都卡，总分离线还差老大一截。最伤的是卡住时还往下钻，一道题耗掉大半时间。守得住的只有前面几道基础题，写完整、写干净。

开局：前两三题是基础题，认得，写得出。

过程：再往后两道大题接连压过来，入口都藏得深，读完题还找不到第一步该写什么。

结局：碰到这种题，最怕犯初六那一错：卡住了不退，反倒往深里钻，想从头把原理推出来。「浚恒，贞凶，无攸利」，越守着这条路越凶，到头来什么也没捞着。最后那道题也是块硬骨头，前面卡掉的那些分钟，此时已无处去补。

应期：以下为传统推算的参考窗口。
可留意本月18、19号前后，卡在一道大题里越钻越深，属凶应。大题卡住一刻钟就撤出来，先去写会写的步骤。

总断：能做的只剩止损：基础题一分不丢，大题卡住一刻钟就撤出来，去写会写的步骤。这一回合格线够不上，基础题那一块要守得完完整整。

卷上没有一处真正拦路的地方，总分却没够上线，毛病出在一个习惯上：题目允许直接引用的公式和结论，每用一次都要从头推一遍，推得对，却慢。到了最后一题，时间只够开个头。
