## 初六动 · 寅月、卯月

本事够用，别在第一道题上挖到底

雷风恒 → 泽天夬 → 雷天大壮

简断

你的准备和开头的题对得上，中间几条限制也扛得住，本事是有的。可这一场还过不了线，毛病出在起手就想把一道题挖到底，时间被吃掉，收尾那项要求没留出工夫。每题先拿能拿的分，深究放到后面。

开局：开卷的题型你熟，准备的东西用得上，起步很顺。

过程：中间要你自己掂量答到多深，还有几条作答规定要照顾，这些都不算重，你应付得来。

结局：初六说一开始就往深处挖，守着这种做法也凶，没有好处。你不缺能力，缺的是分寸：第一道长题若想一次写尽，收尾那项要求就会被挤掉。最后那一关本身不硬，可时间已经被开头占走，这一场就差在这里。

应期：以下为传统推算的参考窗口。
可留意本月18、19号前后，尾段还要处理因开头用时过多而留到最后的一项要求，属凶应。若近期做整卷，可核第一道长题占了多少答其他题的时间。

总断：这次过不去。第一道长题写到够用就转身，别把全场的时间押在开头，这个习惯在下一场之前改掉。

## 初六动 · 亥月、子月

能力够用，开头写细了会误结尾

雷风恒 → 泽天夬 → 雷天大壮

简断

你手上的力量不弱，熟题写得清，中途要核的几条规定也能逐步处理，可这一场的分数够不上线。要防的是开头一道题答得顺手，越写越细，回过神来卷尾还有几件事没办。顺的题写到够用就停，给每题必答的部分留出时间。

开局：开卷的内容在你准备范围内，你有力量照计划起步。

过程：中间要自己安排思路，还要满足一些作答条件，这些要求一路都有，分量不重。

结局：初六说一开始就求深，没有好处。最后那项要求本身不重，可前面在一道题上铺得太开，到那时已经没剩多少时间，结尾只能草草收场，分数就差在这一截。

应期：以下为传统推算的参考窗口。
