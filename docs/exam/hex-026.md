## 初九动 · 寅月、卯月

每道题都得从零搭起

山天大畜 → 雷泽归妹 → 山风蛊

简断

卷面上挑不出一道能照搬旧解法的题，每一问都要回到定义现推，这种从头搭的写法你练得最少，写到后半张时间已经透支，分数停在线下。保得住的是前面几道概念小题，一句一分，写准就有。

开局：题干都读得懂，前几道概念小题也认得出考的是哪一条定义。

过程：再往下几道长题绕了几道弯，细读只是条件摆得散，并不刁钻。

结局：真正拖垮这一卷的是那份慢。熟悉的卷子总有几处能抄近路，这一张一处也没有，你只能一格一格往上垒，垒到最后那道大题，铃声已经不远。「有厉，利已」，初九被上面的山压着，硬冲有险，停下才有利；小象说「不犯灾也」，停下来不再添错，可前面垒得慢的那段时间，停也换不回来。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，推不动的那道大题又硬推了半天，属凶应。记下在哪一步停笔，看停下后还剩多少时间给小题。

总断：推不动的那道大题写出确定的两三步就停笔，回头把概念小题一句句核准。总分够不上线，这几块分却丢不了。

## 初九动 · 巳月、午月

最后一题多了一根绳

山天大畜 → 雷泽归妹 → 山风蛊

简断

前面题题写得动，写稳的那几题照常给分，总分还差一截，最后一题多出的那根绳没解开。这张卷子出得规矩，可给分抠得紧，没有哪道题能多挣几分；收卷前那道大题又拴了一条限定，这里丢的几分，前面没处找补。

开局：复习到的地方都考了，下笔就有，草稿纸也用得省。

过程：再往后有道小问得自己核对数据，停一下就理清了。每道题都按要点给分，写对一点拿一点，没有多出来的。

结局：卷尾那根绳并不粗。题目只是把最熟的那条路堵上，要你换一种办法走到同一个答案；那种办法学过，只是没在这种限定下完整写过，写出一半，分也只拿一半。初九「有厉，利已」落在这里：看出老路被拴住就别硬拽，拽得越久，前面干净的卷面越容易被涂改弄乱。停下保住的是前面几题，补不出这一题缺的那几分。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，卷尾一条限定把熟路堵住，属凶应。碰到被限定堵住的题，先想别的路能否走到同一答案。

总断：最后那题先写清题目限定了什么、准备怎么绕，写出一步算一步，前面的答案别再动。这一卷够不上线，差的正是那几分。

答得太满，时间不够

山天大畜 → 雷泽归妹 → 山风蛊

简断

前两道论述写得又长又全，那两道的分扎实，阅卷挑不出毛病。可一道题耗掉两道题的工夫，后面只好草草带过，最后一页空了大半，没够上线，过线的那几分让篇幅吃掉了。

开局：题一发下来，前两道正是吃透了的内容，能写的东西太多：定义、推导、例子、反例，一样不落地铺上去。每一句都对，每一句也都在花时间，等抬头看钟，半场已经过去。

过程：后面几题仍照这个篇幅写，到第五题就得开始压字数。

结局：末尾那题门槛很低，等笔走到那里，只剩几分钟。「有厉，利已」，该停就停：答到得分点即刻收笔，多铺的那半页不加分。

可留意本月18、19号前后，前两道论述又写得太长，属耗应。论述题写满一页就停，回头再补。

总断：从第三题起每题限一页，先让每道题都有字。前两道写得太满，这一回差在线下。
