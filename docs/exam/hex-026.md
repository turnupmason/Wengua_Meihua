## 初九动 · 寅月、卯月

每道题都得从零搭起

山天大畜 → 雷泽归妹 → 山风蛊

简断

过不了。卷面上挑不出一道能照搬旧解法的题，每一问都要回到定义现推，这种从头搭的写法你练得最少，写到后半张时间已经透支。保得住的是前面几道概念小题，一句一分，写准就有。

开局：题干都读得懂，前几道概念小题也认得出考的是哪一条定义。

过程：再往下几道长题绕了几道弯，细读只是条件摆得散，并不刁钻。

结局：真正拖垮这一卷的是那份慢。熟悉的卷子总有几处能抄近路，这一张一处也没有，你只能一格一格往上垒，垒到最后那道大题，铃声已经不远。「有厉，利已」，初九被上面的山压着，硬冲有险，停下才有利；小象说「不犯灾也」，停的好处是不再添错，并不是停了就够线。那道推不动的大题，写出已经确定的两三步就收手，把剩下的时间还给前面的小题。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，尾段发现继续试旧办法仍无进展，属凶应。近期若练整卷，可核最晚才停的一问是否耽误其他题。

总断：考不过。推不动的大题写出确定的那几步便停，小题逐一核准，这些分跑不掉。

最后一题多了一根绳

山天大畜 → 雷泽归妹 → 山风蛊

简断

前面写得动，总分却差一截，考不过。收卷前那道大题多加了一条限定，平常最顺手的那套办法被它拴住，换别的路又接不上，这一题的分丢在这里，总分缺的正是这一块。前面写稳的几题照常给分。

开局：前几题考的都是复习到的地方，写起来不费劲，草稿纸也用得省。

过程：往后有一处要自己核对数据的小问，停一下就理清了。

结局：卷尾那根绳才是要害。题目把最熟的那条路明明白白地堵上，要你换一种办法走到同一个答案；那种办法你学过，却从没在这样的限定下完整写过一遍。初九的「有厉，利已」落在这里很实：看出老路被拴住，就别硬拽，越拽越乱。王弼注讲进则有厉、已则利，停下来保住的是前面几题干净的卷面，补不出这一题缺的分。

总断：过不去线。最后那题先写清题目限定了什么、准备怎么绕，写出一步算一步，前面的答案不要再动。

山天大畜 → 雷泽归妹 → 山风蛊

简断

考不过，输在篇幅上。前两道论述写得又长又全，一道题耗掉两道题的工夫，后面只好草草带过，最后一页空了大半。前两道的分扎实，阅卷挑不出毛病，缺口全在没写到的那几题。

开局：题一发下来，前两道正是吃透了的内容，能写的东西太多：定义、推导、例子、反例，一样不落地铺上去。每一句都对，每一句也都在花时间，等抬头看钟，半场已经过去。

过程：后面几题仍照这个篇幅写，到第五题就得开始压字数。
