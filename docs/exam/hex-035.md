末尾那道熟题，回头撬开第一题

火地晋 → 水山蹇 → 火雷噬嗑

简断

前面有道题读了两遍还摸不着门，不必慌，能过，也不费事。越往后的题越顺手，压轴那道几乎就是练过的原题，写得快，省下的时间正好回头拆开那道拦路的题。

开局：第一页就有一道题，题干读了两遍还没弄明白在问什么。别的几题不难，花不了几分钟。

过程：往后要自己验算的地方多出一处，数对不上时停一下，再算一遍就顺了，耽误得不多。

结局：轮到压轴，题路正是做熟的那一种，几步写完，还顺手把第一页那道题的关窍带了出来：两题靠的竟是同一个条件。被挡回来的那一下，原来只是没看出这层关系。初六「晋如摧如，贞吉」，往前走被推了一把，站得正就吉；小象说「独行正也」，那道题先空着往下走，这一步走对了。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，本次正式成绩中较易核实考试通过，属吉应。近期若已有出分安排，可按主办方实际渠道查询。

总断：这张卷子过得去。读不懂的题先跳过，别在第一页耗着，后面的题会把它的门路递回来。

古籍依据：《周易·火地晋》《梅花易数·占卜总决》《梅花易数·求名占第九》《梅花易数·人事占第二》《梅花易数·体用互变之诀》《梅花易数·体用衰旺之诀》《梅花易数·占卦诀》《梅花易数·体用》《梅花易数·占卜克应之诀》《梅花易数·先天后天论》《梅花易数·日应》。
