## 初九动 · 寅月、卯月

头道大题换了问法

山雷颐 → 坤为地 → 山地剥

简断

卷子头一道大题就换了问法，分值占得最多，来势也最猛，能接住它的办法你手里本就不多。熟悉的步骤一时搭不上，就转去套一个背熟的模板，整题写偏，这一处就让总分差在线下，分值最多的就是它。后面那串只考记忆的小题，分还能保住。

开局：卷面翻开，分值最重的那道题问法跟平日做惯的差了一截，题干只有几行。

过程：往后是一长串平铺的小题，都不难，可每题只值两三分，写得再顺也攒不出多少。

结局：麻烦全在那道大题。你会的那套步骤本来走得通，只是慢，眼看时间一分一分过去，就撇下它去套背过的模板。模板长得像，条件却对不上，越写越偏。龟本可以不吃不喝，自己养着自己，初九偏要「舍尔灵龟，观我朵颐」，丢下它，去盯一张大嚼的嘴，小象说这「亦不足贵也」。整卷的分就塌在这一题。

应期：以下为传统推算的参考窗口。
可留意本月12、13号前后，头一道大题换了问法，一时搭不上步骤，属凶应。背熟的模板先别拿出来，对着题干找自己会的那一步。

总断：新问法那道大题上丢了自己的步骤，总分还没到线，模板套偏了整题。慢也照自己的路写，能落几步落几步；后面的记忆小题一道别空。

差在头一题那一处拐弯

山雷颐 → 坤为地 → 山地剥

简断

卷面大半是你练熟的东西，题题写得稳，偏偏头一题藏着一处小拐弯。原来的步骤挪一步就能用，你却换上一个看着更利落的公式，它要的条件题里没给，这一处丢了分，整卷就够不上线。

开局：看着眼熟的头一道题，读到第二个条件才露出一个小弯，步骤得跟着挪一挪。

过程：后面成片都是练过的题型，旧笔记里的做法几乎原样用得上，写得又稳又快。

结局：那几分丢得冤。原来的做法只要挪一步就对，你却换上一个看着利落的公式，公式要的那个条件，题里恰好没给。手里的灵龟是好东西，眼睛却跟着别处的朵颐走了，初九的凶就凶在这一换。卷子其余部分都扎实，少了这一块，偏就到不了线。

总断：整卷差几分到线，差的只是头一题拐弯处那几分。那里照原来的步骤挪一步再写，别换公式；其余各题照常写满，那部分分是稳的。

雷声大，雨点小

山雷颐 → 坤为地 → 山地剥

简断

头一道题看着吓人，题干长、说法生，真拆开不过两步。平时那套稳当的拆法没拿出来，去试一条没走过的新路，时间都耗在试错里，分数便落在线下几分。卷子本身不刁，可每道题只给该给的分，没有一处能把耗掉的补回来。

开局：卷首那题像一声闷雷，满纸陌生说法，题干占了小半页。

过程：后面的题平平常常，难度不高，只是每道给的分不多，写完也就一题一分地往上加。

结局：其实那道题的骨架很简单，照你平时一条条拆条件的笨办法，用不了多久就能写完。卷面上留下的却是一条试了一半的新路，前面推的作废，后面没写完。「舍尔灵龟」的凶，正在这一换：龟一直在你手里，你没用它。题目没难住你，是打法换掉了分数。

总断：那道吓人的题本不难，丢分是因为没用自己的办法拆它，这一回还差几分。看着再生的题，也先照老路拆条件；后面那些平常题照常写，它们的分落袋为安。
