# 故事口吻与未来日期

最新以 [断语审核 V2](INTERPRETATION_AUDIT_V2.md) 和 [V6开发交接](CLAUDE_BUILD_PROMPT_V6.md) 为准。用户此前认可的口吻仍有参考价值，但最新又指出专业依据和表达的问题；不能把早先认可视为当前稿件全部合格。

正文分开局、过程、结局、总断，回答明确的 question_type。先写事情怎样发展和最终倾向，专业依据放可展开详情。关键条件可以自然点明，不将文章写成五行计算日志，不用星号。

本用、体互、用互、变用对同一个原体的直接关系均须进入证据；六个可见位置同用一套完整旺衰表。间接作用须有批准规则，部分空亡仅作标记。不靠一个克字、固定卦等或最终一卦决定整盘，也不强迫把每条候选作用写进正文。

写得自然，例如：“这件事一开始有人愿意帮你，但真正谈到钱和具体条件时容易起分歧。机会还在，接下来要把条件谈清楚。”这只是语言示例，具体盘须确有支持，不能作为所有盘的固定模板。避免“帮助没有断”“已有同类接续”“体互的克制会带来波折”等句子。

结论明确到所选问题，允许有依据的倾向、条件和迟速；不能以空泛套话回避判断，也不能为求具体而虚构人物、钱数、对方心理或确定结局。动爻解释本次变化，不把爻辞人物和刑罚等当作用户必遇的现实情节。最后另写总断，不只留一个日期。

应期先审查应事、吉凶、方法、尺度与轮次，再做历法转换。未核定不写日期。新盘候选>=起卦当地完整日期；近期先本月余日、无候选再查下月实际干支，不简单把同一日号搬到下月。历史盘保持原窗口，不随阅读日期滚动改期。按时辰需排除已过去时段。
