## 初六动 · 寅月、卯月

先看清能查到哪一步，找回仍有余地

火水未济 → 水火既济 → 火泽睽

简断

宠物仍有找回机会，但不宜一看到近似消息就立即扩大搜寻。先问清楚这一条究竟能查到哪一步，能辨认的先辨认，需要现场查看的再安排。把可办理的事情逐项做实，别让不断换方向打乱原来有依据的查找。

开局：离火体春令属相，坎水用属休而克体，起初有查证上的限制，你尚能承接。先从最后确定出现的地点整理可核查的消息，不凭一声模糊转述就把搜寻重心挪走。

过程：体互坎水属休，继续克相火体，中段仍要处理核查门槛；用互离火属相，与体比和，有助于把既定步骤接起来。若某处暂时不能查看，记录具体原因，先完成手里可以确认的部分。

结局：初六“濡其尾，吝”提醒不看条件便往前赶，容易陷入徒劳，所幸还留有收住、改正的余地。变用兑金春令属囚，受相火体所克，末后较可处理，故仍有条件找回。若目击现场确有白色设施、金属器物或缺口，可辅助对照；濡尾不是宠物落水的证据。

应期：以下为传统推算的参考窗口。
可留意本月15、16号前后，中段厘清可继续办理的核查事项，属吉应。可将已查明、尚待查与暂时不能查看的部分分开，属于调整搜寻步骤的参考。

总断：找回可以继续争取，行动应有明确的查证目标。先把一条消息查到能够辨认，再决定下一步，不为追求搜得更远而放过眼前能问实的细节。

## 初六动 · 申月、酉月

先收住无凭据的奔走，找回仍偏难

火水未济 → 水火既济 → 火泽睽

简断

这次找回偏难，前面的查证容易受限，后面的事项也不轻松。越急着扩大范围，越应先问清一条消息有没有原始来源。把可以联系的亲见者找出来，核对具体位置和特征，别让几次模糊转述带着你来回跑。

开局：离火体秋令属囚，坎水用属相而克体，初期较难掌握查看和核认条件。先确认消息能否查下去，再决定是否前往，减少到了现场也无从辨认的投入。

过程：体互坎水属相，继续克囚火体，中途限制仍较实；用互离火属囚，与体比和，能维持已有安排，却难增加有力支撑。将每次未能核实的原因记下来，后面才能针对缺口补查。

结局：初六“濡其尾，吝”给出急进而受困的警戒，也仍容许收住错误方向。变用兑金秋令当旺，受囚火体所克，末后仍难处理，故取找回偏难。若既有影像附近有金属器物、白色或有开口的设施，可据实比对，不从濡尾推断动物涉水受伤。

应期：以下为传统推算的参考窗口。

求助不能替代核认，找回仍难落实

火水未济 → 水火既济 → 雷水解

简断

这次找回偏难，前面的核查费力，后面仍要继续投入。可以请合适的人协助，但要说清要查什么、怎样回传结果。自己掌握的可靠资料继续跟进，不因有人口头答应便停止，也不靠反复试探判断对方是否认真，具体反馈更有用。

开局：坎水体土令属死，离火用属休而受体克，起初调查事务较难承接。先把关键资料补齐，联系实际能查看的人时带着明确问题，减少来回补充造成的空转。

过程：体互离火属休，受死水体所克，中途仍要投入查证；用互坎水属死，与体比和，只能维系现有安排，支撑不强。把已委托的事项记清，尚未得到具体反馈的仍列待查，不先当作完成。

结局：上九“有孚于饮酒，无咎；濡其首，有孚失是”容许得当的信任，同时戒失去照应。变用震木属囚，受弱水体所生，末后仍耗，尚不足支持顺利找回。若已知周边确有竹木、绿色或草地特征，可以协助比对，但不能从饮酒、濡首推出动物实际遭遇。
