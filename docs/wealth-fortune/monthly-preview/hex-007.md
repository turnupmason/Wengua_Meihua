## 初六动 · 寅月

最近想增加一份可靠的收入，恐怕有些吃力。原来有条件领取的工资、熟悉的经营所得还值得维护，但新进的钱不好拿到手，后来的开支也可能进一步压薄结余。地水师初六，上面的静坤代表你，下面动坎代表财，土能克水，本是可以主动取财的关系。寅木当旺，坤土在死地，就连已经休弱的坎水也不容易制得住，别把可能的财当成已经有能力取得的收入。

现有财源比陌生机会更值得先照顾。坤取西南、地土谷帛、仓库和乡人众人，若原来有实物供应、仓储、地土收入及本地旧客，照已知条件去做。上体互也是坤，和自己同气，但同为弱土；原有伙伴愿意配合可能也拿不出多少实际资源。坎在北方，古书取舟人、鱼盐水货之利，原先若有运输流通、相关货品顾客，此时宜核自己实际交付能力及报酬要求，先不为新款承担更多成本。

中间的下互震木春旺，直接克原上坤，所受阻力比同气配合大。震主东、动、竹木，古有震克体山林损之说。如果原有东边木货交收、业务搬动或人员安排需要改变，先问有无追加费用、谁按现实承担。最后变地泽临，下兑为囚金，由土去生，收尾仍可能有花费但不另断重耗；西边确有交易沟通、餐食支出便照实核。

初六师出以律，孔疏说失律虽有功亦凶。眼下宜把工作范围、付款及费用责任说清楚。寅卯月或问期内寅卯日留意已有震木变动造成的压力；辰未戌丑土旺月日用于备账。末兑力薄无独强耗候。未收款与实损分清，当前先留生活和应急周转。

地水师 → 地雷复 → 地泽临

这阵子财运有比较实在的好处，原来已经知道怎样取得报酬的事情，可以用心办成。自己做得来的经营业务也有争取来款的机会，实际开销扣除后还有一定的留财空间。巳月地水师初六，上静坤土代表你，下面动坎水是财，夏火旺使土处相地，水却囚弱。土克水有力，说明所求的财能够凭自己的实际条件去掌握，不只是一种收入意向。

## 初六动 · 子月

近期先稳住应得的钱，别为难以兑现的财事早早付出

地水师 → 地雷复 → 地泽临

现阶段宜先保原来有把握的收入，不需要为了多挣一笔钱而提前扩大自己负责的范围。正常工作所得、自己熟悉的经营还可维护，但额外财不易拿到手，实际支出也可能使积余变少。地水师初六逢子月，静上坤是你，动下坎是财。按五行坤土原本可以制坎水，可是冬水很旺，土却处囚位，承接和取财的力量都不算充足，先做有确定条件的事比较实在。

坤的古象有西南、乡人众人、地土谷帛、仓库以及静中、多中取利。若你本来凭本地供应实物、仓储或土地农产有收入，可维护现实已有的顾客及西南渠道。上面的互卦同样是坤，和你相合但也处囚地，伙伴即使愿意配合，也未必拿得出足够的资源。原用坎指北、舟人、水货流通，如果已经有北边货运、水边货品客户等事项，先核手里能够承担的货量、给付条件和实际成本，而非另外投入求新财。

中间下互震木在子月相，对静上坤直接施克，前段本来取财吃力，遇到中间的阻力就更要注意。震东、动及竹木，古震来克有山林损忧。如果原本有东边木货交接、搬运或财事变更，应检查是否添了支出以及实际由谁负责。最后变地泽临，下兑处休金，由原土生出，尾部也有耗财意味。兑取西方、交易、口、饮食，已有西面交易费用或沟通餐食支出才核实。

初六师出以律强调不能以求利好坏代替规则，临到支付前应该有明白的责任和报酬依据。寅卯月或问期内寅卯日可留意实际震木变动的压力，辰未戌丑土旺月日准备、核原账；尾兑泄不旺，不另定强损期。钱已收到再计划支出，先留生活周转和应急费用。

## 初六动 · 丑月
