## 初六动 · 寅月

近期收入难落实，先保住手里的余钱

山水蒙 → 地雷复 → 山泽损

近期即便有意求取收入，落实起来也颇费力气。山水蒙初六，上艮为静体，下坎为动用，按照求财占所说的体克用为有财，原局本有将财拿到手里的方向。无奈寅令草木旺而山土死，坎水虽休，艮土依然难以克制。若目前有按约应得而未实际收取的钱款，可以先把领取的条件核实了，财源有着落与钱已经到手是两件事。

复卦为互，上坤土和原艮直接同气，但春令坤同样死，给自己的财务余地添不了多少实在力量。下震木旺，于用互位直克艮土；震有动和决躁之意，体用总诀还提到震克体主虚惊、山林之失。落在求财上，需要着意察看当前财源所依赖的活动是否易变，尤其原有木材、山林等事项若与收入有关，要查实条件有没有改动。

初六讲发蒙、用说桎梏，以往吝，注疏从发去蒙疑、正其法制和用刑有止来释这一爻。以财事作类推，宜把影响收款的实质疑难一次弄明白，反复无效的争取本身也占用资源。若遇行动条件有所变动，先区别哪些疑难能够解决、哪些目前还需要核实。变成山泽损以后，兑金囚而由原艮来生，末段仍见耗财倾向，兑为口舌，原本需要花力气解释或商量的财事可以留出处理成本。

整体看，近期财务承压，而清楚可期的进账象较薄。实际尚未获得的钱不要当作已有可用余额，容易耗钱的额外安排要区分必要与否。春土受制，首先保护已有可支配的钱，若现有财源的事项并无山林或口头协商等关系，只按求取受限和中后有阻耗的本义理解即可，不必另找相应对象。

## 初六动 · 卯月

费力争取也难增厚余财，近期宜守

山水蒙 → 地雷复 → 山泽损

这段时间做财务打算，最好将预期的收入往谨慎处估。卯月山水蒙初六动，求财以不动的艮土为己，坎水作财，土克水有争取财利之象。然而土气春死，水月气休，财虽不是极旺，求财者掌控它的力量更不足，实际进账难度较大。坎在说卦中为陷，眼下若对钱如何到手尚有不明之处，宜先查明有没有可实际履行的条件。

主要压力落到了事情的中间。山水蒙的两互，下震木主行动，在卯月旺而直接克原艮，古书说震来克有虚惊之忧。牵涉收入的行动环节若尚不稳定，主动奔忙容易累及自身安排；与林木等既有财事有关者，也可按震木来克的原义审视其中不利之处。上坤为体互，与艮同土相合，只是土死，实际支持能力仍然有限。

初六的主旨在解开蒙昧，以正法明明白白地分辨该放开和该约束的事。孔疏说若以刑人的做法一径出往则吝。用于收支，就是有疑处认真查清即可，过了必要限度还继续投入倒不合此爻之意。到变卦山泽损，下兑金在卯囚，受艮土直接所生。它的耗财力量并非很大，但现在原体也薄，余力不多，宜留意已经存在的议价或沟通事项究竟还需付出多少。

有些收入机会在看似可以取得时，便让人误以为以后能收到不少钱。从这个月令的本克难制与强震中克看，进账象不足；总财势的改善同样需要更实际的条件。若目前无法确认未来收入，应把费用责任按可承受的程度列出来，先安排有必要性而且数目可核实的支出，避免所谓的财源最终只留下求取财源时花掉的力气和钱。

## 初六动 · 辰月

近期有财可求，余钱能留下多少仍看后续花费

山水蒙 → 地雷复 → 山泽损

比起寻找全新的收入门路，这一盘更有意思的是，已有一定条件的财能不能真正拿回来。山水蒙初六坎水动，艮土在上为体，辰月土旺水死，自己对所求之财较能掌握。古书求财专章把体克用列作有财，此处力量又相济，故近期进款的象较明。具体仍须根据现实分辨哪一项收入有可以兑现的依据，而不是只见坎水便以为某个方向另有钱来。

互地雷复，上坤土随令而旺，在体互的位置与原艮比和，求财中途有实际承接的有利象。下震木辰囚，虽向艮直克，威力却薄，尤其当前涉及行动、变更的安排，即使有些扰动也较有余力处理。震克体古有动中虚惊、山林之忧象，若原财事真与此有关，可核查曾经商定的条件是否有变；不宜另行猜测平白出现什么损失。

蒙初六说发蒙而利用正法，末诫以往吝。古注认为疑明之后该解的束缚当解除，刑不得长期施用。用在求财上，是有把握处理的疑难宜据实说明，额外花费的边界也宜提前约定。变为损卦，兑金得辰土所生而居相，以原旺艮生末兑，仍有较明显的付出。兑为口为言，有实际商议环节的钱款，可事先弄清需要花的时间和费用。

综合起来是进账有较好的条件，实际财务好坏却还得看看收入扣除真实支出后的情况，宜按有进有耗来评估。已经满足领取条件的款项可着眼落实，到了后来宁可把支付责任与收入分别入账。原体旺能办事，但相金得生亦实，不能仅凭进款的机会就把预计净得也抬高，把钱真正结算并留下来才是这一段财运较值得关心的地方。

## 初六动 · 巳月

力有所余，眼下财源有条件落实

山水蒙 → 地雷复 → 山泽损

有把握得到的那部分收入，值得趁眼下条件较好将它办妥。从巳月山水蒙初六看，下坎作动用为财，上艮是原静体。土得夏火之令而相，水在巳囚，体克用有力，正合求财章所说的有财之象。虽无用卦直接生体的回益，却有自己能够争取得到的益处。因此应分清现有财源哪些已具取得资格，自身确实有办妥手续或满足条件的能力。

原体后面的扶持来自体互坤，同属土而在夏相，虽非直接相生，比和之力颇有承接。用互则为震木，夏休而克原艮，依旧有中间的阻力，只比强克之令要轻。《说卦》称震为动，梅花另以震来克取虚惊，现有求财事情若需要经过实际活动或变动，可预留解决其中临时问题的余地，不把尚未落实的收入看成无须再办就能到手。

山下的泉水一时不知适处，蒙卦初六要人发其蒙，释其桎梏，而处置过长又有吝。求财若有不明白的规定与要求，正宜依据事实弄明白；既已查清则适时结束无用的解释。变卦山泽损，下兑死金受原艮之生，是末尾的耗财象，兑主口舌，与原先的报价或结算商议有关时或有小的附加成本，因金气死弱而尚易承担。

全局来说，近期进账和财利都有不错的实际争取条件，后续虽非全无花费，余力足以应付盘中较轻的耗克。已有收入条件可依次办好，账目上不妨保留一定活动余地，免得把原本来克的微小阻隔因急躁放大。有钱赚和有钱实际收到仍须核对，但目前的财务倾向确实比土弱而遭强木克的时候好，不必因损卦之名便先作全盘破财判断。

## 初六动 · 午月

进账机会较明，宜把可得之财落实到手

山水蒙 → 地雷复 → 山泽损

近期的财势较有可收之处，关键不在预想能添多少种收入，而在已有资格和条件的收入能否落实。山水蒙初六动在坎，静艮定为原体，午令火旺土相水囚，体克用有力，有财可求。坎主陷也有通的象，与现有钱款交付的环节相联系，可理解为求财有可打通的地方，实际取得条件是否满足仍应依据可核对的资料。

再看中间两互，不是全然安顺。下震在午休，对艮土有直接的克制，古人取震克有虚惊，故钱款的取得如有需要行动或反复确认的阶段，仍需留神其中已知易变的事情。不过此时土相而木休，抵御较有余力；上坤同属相土，作为体互也有力，既定财源中能实际提供便利的相合条件可以好好利用。

初六发蒙，利用刑人，用说桎梏，王弼说蒙发疑明，刑说当也，至于以往吝，是施刑不可无止。以今日求财之事来看，既然有需辨明的规定和条件，先据实辨明；解决之后也无须再把资源投入其中。末变泽为下用，受相艮直接生，金在午死，耗自己的力量不重，兑主口舌，确有沟通费用的事项把它们算进去即可。

从整个近期财运看，进益的机会较为清楚，手中的力量也能较好承接实际进款，所以倾向较有财利，而非钱来以后全被耗去。已有收入尚待收取，适宜先把该做的环节完成；至于款项之外需要额外支付的成本，则宜以真实需要和现实数目为准。勿因后卦成损忽视主客旺弱的实际关系，也勿因本卦有财，将结算之前的账面预期提前当成留得住的钱。
