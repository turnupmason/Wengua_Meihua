## 初六动 · 寅月

求财费力而余财偏薄，先守稳已有收入

山水蒙 → 地雷复 → 山泽损

最近的财运偏劳碌，想多挣一点钱却未必有相称的进项，就算得了少量收入，求财过程中也还有费力费财之处。寅月山水蒙初六，上艮土为静体而死，下坎水为财、月气休。本用虽受原体克，弱土制水无力。原艮守静、山田土物之象，可理解为宜耐心经管具体事务；现在与其过度奔走开拓，不如先维持已有的本职或熟悉的业务。

坎求利有水边、鱼盐酒货的古象，今可联系已有流通、水产食品或运输服务的财路，与此相关的舟人、经办流通者也可视作潜在客户。古坎北方，这些只表示尝试求取的方向，此月收取能力偏弱，北边新财源若尚无实际途径不值得据卦另作投入。体互坤同样春死，虽与艮比和，现实中的乡里、旧有协作者若有相助意向，也得看能否真正分担工作及费用，未见有力来生的贵人财。

用互旺震直接克原体，古书取震来克主虚惊、山林之失。原本在办的业务若涉及东边的行动、木竹货或进度有变，先核实有无新增供货或办理成本，未落实前不急于许诺后续费用。末山泽损，下兑金囚而受艮直接生，兑口舌，在已有报价、议价事项上容易费自己的时间及钱财，虽金气囚薄，弱体也宜仔细计算承受力。

蒙初六发蒙、解桎梏而以往吝，古注刑不可长；眼下应先弄懂收入条件及阻碍，解开疑问后不再无谓重复投入。聚财能力偏弱，宜按实到账列收入，必要支付留足周转，不拿未收的钱维持额外花费。寅卯木旺的月日有中震克体之忧，查清已有行动和费用的变化；土旺或火旺的月日较宜整理经营和账目，非确定得财。

## 初六动 · 卯月

多求未必多得，稳住现有的收入和周转更重要

山水蒙 → 地雷复 → 山泽损

若最近想靠多接一些事情赚更多的钱，最好先核算自己眼下还能承担多少，财务上可能是费力多、余钱少。卯月得蒙初六，静上艮土死，下用坎水休，体克用虽有财路，土弱却制不住水。艮是守静，也是山石田土的象，财力不足时适宜经营原有较稳定的事务，如真实已有场地、实物管理的收益，不必仅为另求机会而大幅增加成本。

本用坎的古财象在北方，水边的货物、鱼盐酒货和舟人等，可结合现实中流通、配送或水产食品相关的客源来看。现有相应收入宜先核实实际取得的条件，原无这些途径时，它只是潜在方向而非必须改行的启示。互上坤土比原艮，春土同死，熟人或共同经办者若愿协助，多是意向尚需落实，合作的职责和费用怎么承担要先查清。无生体节点，不宜寄望突然遇见出钱相助的人。

中下震木旺而来克艮，震动、虚惊，财事如确实涉及东边活动、货物周转或林木经营，尤其防原有办理条件变更而多费财力。初六发蒙而以往吝，孔疏解疑明、刑不可长，求财不明就认真核实，弄明以后也无须反复付出。末变损卦下兑囚金受原艮生，兑为口，若已有报价及沟通成本还未定，应当明确由谁负责，防小额花费积累占去余钱。

总体进账象薄，留财能力也较弱。支出与收入分两账列开，先留必需的支付和周转余地，再考虑尚未落实的财源想法。寅卯木气较强的月日有旺震的中段阻力，可对已知货物或活动费用重点复核；在土旺或火旺土相的月日，有利于从经营条件和账目上蓄力，暂不作确定进财日期。

## 初六动 · 辰月

主动求取较有成效，得财以后仍要把费用顾好

山水蒙 → 地雷复 → 山泽损

比起等别人送钱，眼下更有条件依自己的本事落实收入。辰月山水蒙初六，上艮土处旺而静，下用坎水死，旺体克弱用，体克用有财。艮守静山土之象较适合稳定经管现有业务，有场地、仓储或实物经营的现实背景时尤其可发挥这种有条理的掌握力。近期进账的机会明，但总财势要兼看末段较实的花费。

可取之财以坎为主，古本坎为北方，求利见水边、鱼盐酒货，人物又有舟人。现代可借流通配送、水产食品等理解财源，真正有相应客户、渠道的人方可据此落实原已明确的取财条件，不需把卦象当成另找行业的理由。互上旺坤同气有实承，坤有西南、田土货物及乡人、众人的象，现实已有仓储或实物业务的协作者较能配合，分清谁收款、谁担成本，比寄望无据的贵人给钱更合体克和比和。

下震木囚而直接克艮，古法震来克有虚惊、山林之失，结合震动可知行动环节仍有风险。原财事若涉及东边林木或行动上的调整，现有问题宜处理妥当，原体旺亦有应对余力。末下兑金相，原艮去生它，虽有钱进来，随后仍有较实的耗财之象。兑主口舌，已有议价、交付商议的成本要核实，勿将已谈好的毛收入错作全部可留的财利。

蒙初六要人发其蒙疑而处置有止，用在理财上是查明既有业务的收入取得、成本支付的实际依据。眼下有财可进，净余未必丰厚，宜为后续支出留周转，再看实际可存下多少。若已有符合领取条件的财款，亥子水气的月日可参考见财机会；末相兑泄己的申酉月日，相关费用则宜及时查清，未有真实财项不设公历兑现日。

## 初六动 · 巳月

可凭能力把钱办到手，所得也较有望积下来

山水蒙 → 地雷复 → 山泽损

有明确取得条件的财利，在这段时期比较值得靠自己的能力争取。巳月山水蒙初六，上静艮土居相，下动坎水囚，相土能制囚水，古书体克用有财的意义在这里较有力量。原艮守静、山田土物，若已有稳定的本业、场地或实物经管事务，可通过整理原有收入条件落实报酬，而不是靠临时搜寻不熟悉的获利途径。

本用坎北方，其求利有鱼盐酒货与水边财，舟人亦是坎的人物象，今可联系有实际流通、配送、水产食品客户的业务，原已有北边财路的尤其可详查目前办得成的条件。这是原体可克的财，所得更多靠自己的办理能力。上体互坤在夏相，与原艮同气，坤地、仓库、乡人与众人；已有在西南方向或实物仓储上共同经办的人员时，较有配合及分担工作的条件，仍宜明确约定好的利益归属。

用互震木休，虽克艮而力度不重。震在东，古法取震克有虚惊、山林所失；若眼下原有涉及行动、木材或货物交付的事项有变，可及时核对相关安排而不必当成一定破财。初六发蒙，疑明之后处置须有止；末变山泽损，下兑死金受艮体所生，虽有耗己方向，金弱容易承受。兑主沟通，已有条件商议或结算费用需核实时，按真实金额处理，不让小事反复占用财力。

## 六三动 · 丑月

近期取财较有力，重在按实际条件收好所得

山水蒙 → 地雷复 → 山风蛊

眼下如果已有可以争取的收入，现有财务条件也许比单看表面的困难更能支持自己把它办成。丑月山水蒙六三动，静上艮土得时而旺，动下坎水死，体克用的力量比较清楚。求财古占以此作有财之象，近期进款希望较明，尤其可着眼有真正取得依据而尚待办理的收入；它与用生体外来财利不同，自己的现实履行能力较有条件使财办到手里。

互为地雷复，上坤土在体互旺，原艮与它直接比和，帮助承接财事的相合条件较有力；下震木当季土之月囚，虽为用互直克原艮，程度较轻。古书取震主行动，又以震克体主虚惊或山林之失；眼下已有林木财事则依真实情况看其中变动，更多一般财务可从需要完成的实际动作、领取要求去理解，而不因为一处来克便判断有了已成事实的损失。

六三阴变阳成下巽，山风蛊的末巽木也囚，虽直接克旺艮，却不属于盛木来克弱土那样有很重阻力。巽有进退不果之象，若财务要求、责任或费用尚未定，宜先把具体内容商议清楚。蒙六三所言见金夫不有躬，注疏把上九的刚阳称金夫，六三行不顺故无攸利。财事上借这个古爻义，提醒自己哪怕较有取得利益的能力，也不为财利之外观承担不明确的费用或要求。

整体看近期财运较可取，进账条件明朗，原体旺且中比有力，中末两薄克亦有余力处理。先按已有现实条件办理财源，将后续需要解决的问题实际弄清，各项所得记在真正收到钱的时候，现实支出依实际记下，不能因盘中无体生用而省略。这一时期宜着力收好本来有条件获得的财，而不是仅凭收入势好就增设大量新的财务目标；按实有的钱来安排，财务也较有机会得到具体改善。
