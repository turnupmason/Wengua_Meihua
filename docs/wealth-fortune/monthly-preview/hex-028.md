## 初六动 · 寅月

手里原本能够挣到的钱先维持，新财还得等自身条件改善

泽风大过 → 乾为天 → 泽天夬

眼下比较需要把原来熟悉的工作和原有客户维护好，想在此基础上多挣一些钱还需要自己的承办力。即使已有新的客户需求，也不宜只看他们提到的报酬，实际能积下的钱要等真实工作完成再算。寅月泽风大过初六动，上静兑金在春囚，下巽木在春旺，金本能克木取财，但现在自己的金气弱，财不容易掌握。

较可靠的财路仍从兑象所代表的工作着手。兑主西方、口才交流、饮食、口译和金属器物，原先有相应服务与货品客户的，依实际需求取得报酬。初段巽为自己想取的财，它取东南、工巧、山林木货和茶果，现实若已有这类加工、材料或者茶货客户，先确认自己究竟能交付多少工作，不拿尚未明确的收入安排现款。原先有材料供应的报价，还可核客户实际需要的数量及交付期限。

中互乾为天，上下两乾金都在春囚，末变泽天夬，下乾金也是春囚，三处分别与原兑同气比和。乾对应西北、公门管理、金属器物，原本有规范流程、相关管理或器物服务的同业伙伴，可以按真实职责配合，但各自的承办力尚有限。共同任务的费用、应得报酬及付款期限先说明，同一项工作不因三乾重复计，也不把比和当成贵人出钱的依据。全盘没有直接生体或来克、自己向外生泄，难取财并非已经损财。

初六藉用白茅，古疏取细心谨慎，如实处理财务。申酉金旺、辰未戌丑土旺扶金月日适合整理原有业务及准备能力，不另立强进财期。实际收到的钱扣必要费用、留基本日用周转，有余再积存。

## 初六动 · 卯月

已有工作和客户先做好，额外收入还不宜估得很高

泽风大过 → 乾为天 → 泽天夬

现在若手里有原本可以完成的工作，又有明确的客户报酬，宜先稳住这部分收入。自己暂时没有很强力量掌握额外的财，哪怕与别人有商量合作的意向，实际余钱也不要估得很多。卯月泽风大过初六动，上静兑金为你自己，在春囚，下巽木当令旺，原兑金克巽木为自取财，眼下力量弱而难取。

适合优先维护自己原有的收入方向。兑取西方、口才、沟通、口译、饮食和金属器物，原来有这些服务或货品客户，可以照真正能做的任务争取报酬。下巽对应东南工巧、木货山林、茶果，若以前有加工、材料供给和茶货类客户，也要先核实际需求及自己承接能力，不能因为客户愿意接洽便估下次实际收入。

中互乾为天上下乾金与末变泽天夬下乾金在春都囚，各自与原兑比和，配合方向有而力量薄。乾主西北公门、管理、金属器物，原有了解规范手续、器物供给或共同管理工作的伙伴，可按各自有能力做的部分协作。仍要核实际费用和报酬，不把三个同类关系理解成三个人会给钱；若有共同使用的器材，先核真实时间及费用。原来有共同办手续的工作，说明具体责任及计价；合作方代付的款也按真实归属记清。盘无直接来生的外援，也无来克或生泄，财难取不等于已经亏。

初六藉用白茅取谨慎细致，原有业务的计价及工作责任宜说明。申酉金旺及辰未戌丑土旺使兑金有气的月日整理手里的工作，无强财候。实际到账的报酬先扣成本，留必要日用及周转，余钱再存。

## 初六动 · 辰月

自己比较有能力取得工作报酬，已熟悉的合作也可继续

泽风大过 → 乾为天 → 泽天夬

最近原来已有客户和明确报酬的工作，比较值得用自己的本领把它完成。若还有自己能够掌握的额外财，也可以依真实工作争取；原有伙伴共同办事的力量不错。实际收入扣正常成本后有积存机会。辰月泽风大过初六动，上静兑金在土令相，下巽木处囚气，原兑金有力制木，自己取得财的条件较好。

自己的财路可以从兑象来看。兑主西方、口才沟通、口译、饮食及金属器物，原有相关服务或器物货品的顾客，可以依已确定的工作和报酬办理。另一个较能凭自己本领取得的财是本下巽木，巽取东南、工巧、山林木货及茶果，已有材料加工、木茶货客户若需要能切实交付的工作，适合照真实需求收报酬。原来按货品实际数量或加工工作量收费的，更宜把计价依据整理好。若原本承接技术加工服务，材料成本也应与操作报酬分别核实。

中互乾为天上下乾金及末变泽天夬下乾金都在土令相，与原兑分别比和有力。乾主西北公门管理、金属器物与规范事务，原有相关管理、器物供给及手续服务的同业伙伴共同办事时，较有配合能力。但卦无直接生体，合作不是有人给钱，分工所得与共同费用照真实安排，同一项任务只记实际收入一次。全盘无来克或己耗，难点不在额外损失，正常费用依实际所需扣。

## 初六动 · 巳月

自己和合作方的办事条件尚弱，先保住已经明确的工作

泽风大过 → 乾为天 → 泽天夬
