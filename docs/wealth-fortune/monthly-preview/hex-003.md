本问只看所选近期的总体求财、进账及耗失趋势。现有收入来源、款项、成本和资产须按实际核实；进账不等于净利，无财不等于破财。时段仅供已有财务事项参考。

## 初九动 · 寅月

花钱办事的劲头大，近期不易从中见财

水雷屯 → 山地剥 → 水地比

眼下办求财的事，很容易把手中的余钱一点点花到事情上，真正得到的收入却跟不上。水雷屯初九动，静上坎水为体，寅月水休，动下震木正旺。水生木，是自己去生所问之财，古法直指损耗之忧。从震主动来看，特别是已经在办的、需要走动或持续投入才能维持的求财事项，容易有继续花费的压力。事情看起来在推进，与收入已经可以到账是两码事，应先看有没有可兑现的成果。

互山地剥，上艮为体互，下坤为用互，两土都在春令死地，直接克原坎却力轻。艮克体原书主百谋中阻；若手上确有待验收、确认的收入，宜弄明白何事尚未办妥，免得在未满足付款条件的时候重复用力。坤克体另有田土损失之说，有实际场地、土地相关费用者尤其要核对，其余人就按已有的负担查账。两土虽弱，毕竟是制身而非增益，中途并无可补回前面开支的强财象。

初九说「磐桓，利居贞，利建侯」，孔疏解磐桓为不进，宜居处守正，并非只管坐着什么事都不做。在求财上适合厘清已有权责，稳住能够落实的部分，别因一时进展顺利就增加未定的支出。初阳变阴，下震成坤，末为水地比，春死坤再克原坎，最后阻力不重却无生扶。前面已经形成的耗费，也难仅凭此一转卦弥补。

这段时期进账之象偏薄，财务重点在于减少必要开支之外的消耗，而不是预先给没有落实的钱找用途。有明确收入来源的人，可把实际应收、尚欠条件和取得收入需要另付的钱分开记，看净留下多少；没有具体财源则先按已有收入安排生活。卦中着重的是付出与所得未能相称，并非断言每一项支出必亏或原有资产已经受损。手头留有余地，比让钱随着事情越做越多地流出去实在。

## 初九动 · 卯月

求财先算自己的付出，所办事情勤快也未必换来收入

水雷屯 → 山地剥 → 水地比

这段时间若一心想靠把事情做得多来增加进账，反倒容易使自己负担加重。屯卦初九，上坎水静守为体，下震木动为财，卯令木旺水休，自己之力流向所求之财，而不是财反来滋养自己。震是动，故需要反复奔走办理的事项虽还有继续做的可能，消耗却占了主要位置。古书求财篇将这一方向称作财有耗损之忧。近期应特别分清有多少事务已经有付费依据，有多少支出仅仅是为了给未确定的财源创造条件。

过程的两互在剥卦，体互艮、用互坤以死土直接制休水，克力已经很微弱，和旺土围困不同。艮取止，克体又主谋事受阻，若某个正在求取的收入仍有环节停住，要查那一处究竟有没有继续办的条件；坤的田土之忧也只适用于生活中确有相关事项的情形。一般的困难不必夸大为一定会失财，但弱克也没有变成来财的力量，前面的付出仍缺所得相抵。

初爻的「利居贞」是屯难初起之时，处其位而正。象传强调志行正；孔疏又说明且住未进绝非贪逸乐。因此暂缓额外的费用不等于不理会眼前的收入：该交付的做完，该对的账对清，已经成立的权利尽力落实即可。下震动了初爻化坤，终成水地比；卯月末死坤仍为来克，看不到后一段转得生体、比和或体克得财的机会。

近期求新增收入不占优势，而已有财务状况仍有自主管理的余地。若确有收入计划，可先把能够确定的款和正在争取的款做区分，只用前一项的实际到账情况来估量手中可安排的钱。对于仍需垫付的事，把付出之后的现实回款条件弄清楚，有缺项便先解决缺项，别把希望中的所得当作已有本金。将这份精力从增加事情转向整理收支，会比盲目增加工作量更贴合卦意。

## 初九动 · 辰月

容易卡在收钱条件上，手头财务宜预留回旋地

水雷屯 → 山地剥 → 水地比

眼下最要留神的不是有没有事可做，而是做了之后能否把钱稳当地拿到手。辰月水雷屯初九，上坎水为静体落死地，下震木囚而受体生。开头已有自己付出、财物未向自己聚集的关系，木囚也意味着这里耗泄的力不及旺木。真正需要警惕的是事情到了实际结收的阶段，承受压力的坎水本就弱，一旦其他条件加重，收支安排便会容易失去余地。近期求财整体偏不利。

两互组成山地剥，直接制原体。其中上艮体互在土令旺盛，艮克体在古书中有百谋中阻之义，指向收取收入之前尚待解决的关节；如果现在有实际付款手续、交付等前置条件，就先查有何未满足。下坤用互也是辰旺土，古书坤来克另言田土之忧，有场地相关责任者应核实已经约定的费用和期限。两旺克同时来，未有一卦直接扶助坎，现实可参考中程阻力较重而非单纯起步有些支出。

屯初九的磐桓，王孔皆以屯初不可进来解释；所谓建侯，是在秩序未立时建立治理条件，并不是古书说此爻有某个贵人会给钱。借其义处理近期求财，宜明白自己能完成的事与他方应承担的条件各是什么，未具备的部分不先做大。初爻动为水地比，下坤继续以旺土克死水，末段与互中同属直接受制；结尾并非由剥变比卦名便转为进财。

在当前财务能力并不宽裕的时候，建议把已有必须承担的支出、待收但尚未落实的收入与手中流动的钱分开估量。如果有较大额的既定费用，先根据实际时间与付款要求做好准备，再看有什么收入尚需达到条件。近期来自求财的进账机会偏弱，所防的是尚无新增收入而财务又受阻的局面，也有耗损风险；是否已出现亏损，则要拿真实账目核定。

## 初九动 · 巳月

进账难补前后花费，先核清还需承担的条件

水雷屯 → 山地剥 → 水地比

求财宜先承认一件事：现有财力要支持尚未办成的事情，眼下并不轻松。屯卦初九动，上坎水静作原体，巳令水囚，下震木休，水生木，是求财方向牵走自身资源。震之动象适合提醒已有外出办理和反复工作所需的开销，而非推断一定另有某项花费。以本用休木来看，耗费有但不是全局最强的压力；这时付出不易直接见进项，若还有求财事项正在酝酿，宜先弄清楚它怎样才能转成实际收入。

山地剥为互卦，两土在巳火之月皆相。上艮体互克原坎，紧于下坤用互之克；艮义有止，克体主谋事中阻，提示尚未做妥的环节可能影响后来收钱。至于坤克体的田土等类象，只有现实中存在相关事务才以其费用、手续作查核重点。两土作用有力，水体又囚，这与开头中等程度的己耗有区别：事情即使已经付出成本，也可能还要过一道外在条件才能完成兑现。

初九得「磐桓」而利居贞，停在合适的位置上还能做成立之事的准备。象疏释此不是宴安弃务，所以现实中若有可认领的收入或应交付的成果，仍应在自己的能力内办妥，先别将额外投入混在已经明确的义务中。震起而化坤，尾变水地比，下坤依然夏相土，直接制囚水；不能仅取坤顺及比卦相亲之义当作收益会自然归来，这个劣势到了末段仍在。

近期的进账象弱，需要注意有所支出而收入未能相应增加，以及兑现中的财务风险。还没落实的收入应根据已知条件逐项核对，若其中有尚需承担的费用，先评估它是不是手头已有义务、钱付出后还缺哪一步；日常开销也以实际可用资金为依据。这样做并不表示所有收入都会被阻断，只是卦中没有强财象来抵消眼前的负担，别给尚未掌握的钱过早安排去处。

## 初九动 · 午月

收钱比办事费劲，防在尚无回款时多担一层开支

水雷屯 → 山地剥 → 水地比

办财务上的事情，最怕以前的成本已经付过，还需要钱才能把剩下的条件补齐。水雷屯此时初九动，原上坎水在午月囚，下震为休木。水去生自己的求财对象，所指是投入与消耗的方向，未见进财。震象活动，若目前确有需要奔忙办理的财事，应该把那些随办理而需承担的费用预先算进收支，不把精力用在哪里当成一定就会在哪里得到收入。

到了互山地剥，艮为体互，在原坎近处直接克它，坤用互也来克体。午月土相而水囚，两处压力相对于自己的承受力较实。艮克体主阻，实际收入涉及确认、验收等步骤时，可能需要等已知的要求满足才有兑现条件；坤克之田土损象，若自己本有土地、场所等事务，则要注意相关责任所需的开销。并非假定某个行业出事。原就没有生体，时间上的拖缓和额外支出都不容易由收入在中程补上。

本爻「磐桓，利居贞」教人在屯难初起之际先居处守正，而非看到难处就一味往前走。求财可借它整理目前已经具备的条件：例如已有明确收入，则按照原有权责做好自己应办的部分，尚无可证实的财源就先不要扩大所需费用。初阳动而成下坤，末为水地比，午相坤再克水体。最后仍须面对来自事情本身的制约，而不是因为互变便见另一处钱财送来。

近期进账的机会较薄，需从财务实际能承受多少往回安排。手中的钱之外，还有应付未付及收款未确定的事项，二者对支出的影响各不相同；尤其已有相应事务的人，应给必要费用留下可以周转的部分。这里说有财物耗失之忧，是根据体生用及中末受克判断风险，而非判定任一现有收入必落空。先保住已经确认的财务来源、避免未落实的事项牵动更多钱，便是在此卦中较有效的处理方向。

## 六二动 · 丑月

过程不顺却非没有后援，收支周转仍须慎重安排

水雷屯 → 山地剥 → 水泽节

最不宜的是一边财务能力吃紧，一边已经给那笔尚无着落的收入安排了许多用途。丑月水雷屯六二动，原体上坎水处死位，震木囚作财，水生震木，自己先流出资源的象在此不很重。震为动，倘若手头已有正在办理的求财事项，不妨着眼于什么时候真满足取得收入的条件，而非见前期钱花得不多就急着扩充其他费用。原体的状态需要谨慎对待后续事上加来的压力。

互卦剥的上艮体互、下坤用互在丑旺盛，分别制原来死水体，艮又在较切近处。艮克体旧说诸谋多违，有尚未处理明白的收入手续时，最值得查的是那个实际关节是否能完成。坤克体有田土耗损的类象，如日常确有与场地、农地等相关的支付责任，则应仔细核查已有费用。中段旺克力强，问到求财上既有收入受阻之忧，也有资金消耗风险，只知两类风险不可当作现实已经负债或亏损。

六二在屯难之际本有正当所应，一时受隔而班旋未进。孔疏于十年乃字解为难息而反其常，不作现实取得收入的历时；借爻义耐心守住已有财源的正当条件，重点去除真正妨碍领取的部分。下震因动爻转兑，末变节卦，兑金丑相直接生原坎。原书兑生体主货利、喜益等象，若本人已有相应财事且领取条件确有机会解决，到了最后一段颇有外来帮助或财利回流的方向。

这盘后来虽见生扶，整段财务仍有较实在的中途难处，进账并非立即明白的事。现有责任若需要按时支付，先根据真实余额与到期要求作准备，不将后程可能落实的收益先配给这些费用。真有应得的收入待处理，可逐项查清能由自己补足的是哪些条件，到账之前还有何必要的成本。待出现实际回益时，也须量一量与先前的消耗相抵之后余额如何，财势是否宽些最终仍从现实收支判断。
