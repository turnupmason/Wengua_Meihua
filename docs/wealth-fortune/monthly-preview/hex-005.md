## 初九动 · 寅月

求财的着力点宜放在留住已有的钱

水天需 → 火泽睽 → 水风井

若问最近的钱好不好挣，这卦有些希望，却不宜把心思全放在寻找新的进账上。寅月水天需初九发动，静在上的是坎水，春令水休；下乾金囚气，虽直接生坎，求财本有外来增益之意，眼前真能落实的财力却薄。梅花以乾生体取公门之益、尊长惠送以及金宝之利，现实已有稳定收入渠道或相关给付安排，可查其支付条件是否齐备；乾失时只是提示支持有限，并没有哪位长辈一定会给钱的意思。

互见火泽睽，上离为体互，下兑为用互。兑金春囚，生坎的力量与本乾一样偏薄；兑为口，可将它落在已经存在的收入商议，例如双方对报酬条件是否说清，眼下比一味增加接洽更值得留意的是答应的款项有没有实据。离火春相，受原体休坎克，所代表的可争取财利尚非轻易能收，若有关文书、凭据方面的工作需要完善，宜先把实际条件整理妥当。

初九爻曰「需于郊，利用恒，无咎」，王孔解释远离坎险而待时，仍可保常。这里正好说明为什么在财源薄弱的时候，保有原来的秩序比急于增添收入目标更合乎卦意。初阳变阴，下乾成为巽，末见水风井，旺木受休水之生，后段反见较实的耗泄。巽又有进退不果之象，凡支出数额或责任尚未确定的事项，宜在实际确认以后再安排。

所以目前整体财运偏弱，新增进账也不强；其中的生体说明财路并非完全没有，难处在所获的利益未必能补后面的耗。即使现有收入如期出现，也宜分开核对已到账及尚待支出的部分，切莫把暂时留在自己手里的款都记成结余。眼前可以做的是稳妥维护已有的收入基础，对尚不明确的后续投入留出余量，待真正收到钱以后，再看能增加多少安排。

## 初九动 · 卯月

有可等待的财源，短时仍难宽裕

水天需 → 火泽睽 → 水风井

已经有可能带来收入的事项，眼下应当尽心把它办完，额外求财倒未必容易多得。卯月占需初九，上坎水休，作为本次求财的原体；本用为春囚乾金，向体相生而力不足。乾生坎有财益临身，古书所提的公门之利、金宝之利，都要依已知求财背景来取，譬如已经有由正式安排产生的收入，就把正常兑现的进度问明白，而非凭乾象认定另有一笔收入从外面来到。

这份进益在中途还见有相续之意，然而力薄的状态没有改变。火泽睽下兑金同囚，仍然生原坎；兑主口舌，在这一支关系中属于来生，不宜将它理解成因争执而破钱。若已有定价、费用等往来商议，能把对方的意思听清，再留出核实款项的时间，便合于兑来相助的性质。体互离火在卯月得相，受原休坎克，文书或明白归属的报酬尚待真正取得，单有依据也不等于能收下。

需初九「需于郊，利用恒，无咎」，疏言远于难而保守其常。卜到这里，便该分辨哪些事情已经具有持续进益的条件，哪些只是寄望自己手中再多一笔钱。下乾初变为巽，水风井之旺巽木由原坎直接生出，原体要承担后来的耗费。巽进退之象也在末位，尤其是已有计划而实际需要尚待确定的费用，先把金额和履行责任查实，免得来日需支用时自己手中没有余量。

财运判断以耗明显、进益不厚为主，近期新增进账机会亦较弱。这不是说原有的财源中断，而是这段时期靠它增加可用的钱未必容易。若手头有固定进入和出去的财项，宜依各自的真实时点算一遍，尤其把未到账收入同手中现款分开。有可守的便维持，不因将来或能得财而提前作下目前无力落实的承诺，才能使这次求财少受后段耗泄的影响。

## 初九动 · 辰月

进账有较好机会，能留下多少还要看实际条件

水天需 → 火泽睽 → 水风井

钱从外面进入的机会，比单靠自己去争取额外财利要明显一些。辰月是土旺之时，水天需初爻动，上坎水居死气，下乾金相而直接生体；这不是财力本身充足的格局，但所求之事确有能补益自己的力量。《梅花易数》将乾来生体的利象列为公门、尊长的益助以及金宝之利，已有相应财路的，收入若来自正式给付，可就原有规定核实近期实际可兑现的部分。

中段火泽睽里，用互兑金也相，原体再受其生，故不是一处财源之象孤立无援。兑为口，古法又有货利、朋友讲习之益，现实如涉及交易条件的商谈，可把实际应得的报酬与交付要求说实，使来生之象有可落实之处。体互为休离火，受死水直接克而难制，若另想经文书、核算等途径取到更多钱，暂时仍受自己办事条件限制；两处来生不会使这一难处自动消除。

古爻讲的是「需于郊，利用恒，无咎」，王孔明言远难待时、保常而无咎。它不是有财便奔赴而取的教法。下乾变巽，末成水风井，辰月巽木囚，受体水生，其耗象虽轻，却仍是一层实际支出的可能性；尤其原体失令，已有待履行的支付安排，宜把能够承担的数额先核实，而不是在两个生体的前景上又安排大量新事。

综合看近日有望进账，整体财务却还需经现实结算才好判断。一头是相金在本与用互俱能生身，一头是自身水气不足而较难取得所克之财，末又有余耗。重心宜放在确定能够到手的那部分，通过已经存在的财源增加手里的钱，而非仅凭进益的象就把预计到账当作收益。收入逐一落实以后，再扣除原本要承担的成本和支出，才可明白到底留下多少。

## 初九动 · 巳月

把求财的重点转向能真实承受的收入与支出

水天需 → 火泽睽 → 水风井

只看能否收到更多钱，这个时期比较费力。水天需初九动在下乾，巳月原体上坎水入囚，乾金入死，仍以本用直接生体论，然而金气既弱，来财之力也轻。古书说乾生体有官贵或尊长之财益；放在眼前，应依自己原有的收入来源，若确有正式的给付渠道，重点便是核实其实际兑现条件。自己尚未收到款时，单凭将来或有帮助的想法还不宜增列可支用的金额。

接下去见火泽睽，上离体互在夏令旺，下兑用互死。原坎试克旺离，古财占以体克用为有财，但弱水遇旺火，取财的作用很难如愿；若自己手头有待确认的文书、结算类收入，宜先查手续及实际给付的条件，而不把这些事项一概视作马上可以到手的钱。兑金虽仍生坎而势衰，借商议可求助益，却难说因此就会有厚实的进项。

需初九说「需于郊，利用恒，无咎」。孔颖达认为此爻尚远于难，适合避险而守常，所取不是急进之利。乘夏囚水，盘理也不支持勉强求取旺火所象的利益。至末变水风井，下休巽木受原水生，己身还有耗泄；巽为进退不果，若后面仍存在尚待商定的支用责任，把何时需要支付、究竟需付多少落实清楚，是眼下应为之事。

这里财务压力主要源于两处进益力薄、所克之财不好取得，以及末处仍有支用，盘中并无直接克体的卦，也不从这点断有确定的外来破财。近期进账机会偏弱，已有财源宜守，其余根据真实进度看待；倘若自己的收入尚够应付既有的支出，照原计划缓行便合于爻义。最重要的是厘清已经收到的金额与还要开支的款，莫提前动用靠未来到账才可支持的余量。

## 初九动 · 午月

眼下的求财不宜寄望于尚无着落的款

水天需 → 火泽睽 → 水风井

倘若近期正等着一笔钱，重要的是认清它目前是否已有实际支付条件。午月求财，水天需初九以不动的上坎为体，水囚于火旺之时，本下乾金死而向体相生。这份财源来得不够有力；乾生体在旧时有来自公门、尊者或金宝方面的增益之取象，现实已经存在的收入安排可循正常手续等待兑现，如果并无此类事项，就不应据此另去假定有谁愿意出钱。

互卦是火泽睽，体互旺离受原坎所克，用互死兑直接来生。先论其作用强弱，水囚而火旺，即使有体克财的关系，也难把待取之利作成厚实收获；离明、文书之象可用于提醒自己看清费用依据和真实权责。死兑虽然生水，仍不足以使原来的财源变得充裕；兑口所指的已有商谈可求明白答复，不过口头的收入意向和实际款项尚有距离。

初九「需于郊，利用恒，无咎」，象传讲不犯难行、未失常，疏谓去坎难既远，守常有利。此时与其把近来的计划都寄望于还未敲定的款，依实际收入安排眼前的事情更合爻意。初阳改变下乾成巽，井卦的巽木午休，仍是水体生木而耗，最后便有需要继续付出的情形之象。巽为进退，已有待决的支出安排宜先搞清尚不确定的部分。

问总体财运，眼下难在补益薄而自身仍有耗用，进账象也偏弱，若现实已有固定收入则宜维持正常履行，不是说一概会拿不到。支出的部分尤宜以自己已经拥有的钱来衡量，有些款项可能只是需要付出的正常费用，并不意味着已有损失。把确定将收、已经收讫和尚需付的金额分开对照，才能知道本段求财实际为生活留下多大余量，待条件具备以后再谋进一步增收。

九二「需于沙，小有言，终吉」注疏释履健居中，能够等待机会，虽有小的责让，也能守住近而不逼难的分寸。如果实际收款条件有待商议，早点说清哪一部分尚未达到要求，比急于要求多得财更合爻意。二爻动后下乾化离，末水火既济，离火也是休气；受原死坎克制仍困难，说明后来需要自行解决的取财条件未能保证全部齐备，古卦名本身不替代实际体用。

近期较明晰的是从已有财源得到进款的机会，财运能有所改善，真正富余的程度却还要等收款与实支核算。盘面未见体生用和直接来克的关系，不据财难制来断本金损失；然而原体乏力，能够办到的收入有一定限制。弄清既有财务事项哪些可以照常收取，哪些还需进一步满足实际条件，以手上真实可用的钱承接已有支付安排，能够避免将本来仅有希望的来财算作现时所有。
