## 初六动 · 寅月

挣钱的事情容易到后面又用掉资源，宜先稳住原来所得

水地比 → 山地剥 → 水雷屯

最近为了挣钱要不要接手更多事情，最好先算算最后有多少收入能真正留在手里。眼下有些原来的工作还可以照常做，但额外财力难充足，扣掉前后费用后结余恐怕不多。水地比初六，下坤为财事，上静坎水代表自己。寅月水休，土则衰极，坤土本来克水，不过这时给你的阻力不是很强。比较需要留意的是办到后面是否又需要自己的钱或工夫。

眼下较有根据的收入在原有工作与熟悉客户里。坎的古象有北方、舟人、水边鱼盐酒货，若原来在运输、货物流通、水货等领域挣钱，可依据原来的约定维护熟客、经办和运送人员。不妨先把已有的工作所得照真实要求办好。中间山地剥的上艮、下坤，也都是死土分别克原坎。艮主东北，来克有谋事中阻，坤主西南，来克有田土之忧；现实如果已有仓库场地、东北办手续等事情，只需核清现在实际的付款责任和缺项，不因弱克便猜有大损。盘中没有有力生扶或比和让伙伴直接添财，合作仍按各自实际工作和分担说清。

后面初六变成水雷屯，下震木春旺，原坎要生旺木，便有自己的财力向外消耗之象。震主东方、活动和竹木茶货，若后期确有东方采购、材料、送货或外出事务，可看看还要花多少钱，会不会吃掉原来的报酬。盘上不见财进的强象，别把投入的事又当成新增财源。

初六「有孚比之，无咎」古疏取诚实相亲、终始如一。共同办财宜把实际报酬、支出说明，不凭口头承诺多花钱。寅卯月或问期内相应木日留意已有后续投入；申酉亥子月日水相旺适合整顿旧财，非见财期。实有余额先留生活和周转。

## 初六动 · 卯月

暂时别凭新财安排支出，先看后面的实际成本会占去多少

水地比 → 山地剥 → 水雷屯

眼下最值得重视的，是不要让后来还得付的钱超过自己原有收入。若平常就有固定工资或者熟悉的生意，先将这部分报酬维护好。额外的财可能需要不少工夫和投入，利润恐难如原先期望那样宽裕。卯月的水地比初六，静上坎水为自己，动下坤土为财事，土来克水。好在春木旺时坤土衰极，水虽是休气，眼前这部分限制还不特别重。

财从什么范围来宜优先看能继续做的旧事。坎为北方、水边鱼盐酒货及舟人，做运输、货物流通或者类似水货工作的，先看看原来熟悉的客户和运送方有哪些真实报酬可以按约落实。互山地剥的上艮和下坤均为死土，分别克原来的坎水，也是弱制。坤克体古有田土忧，西南仓地费用有事实才核；艮来克有百谋中阻，东北已有办理手续或交付事项的，则看实际缺什么。合作没有生体或比和的强帮助，若原先有人共同参与，真实分工、付款方式说清即可，不认为另有贵人送钱。

到最后下坤化为震，变水雷屯，震木卯旺，由原坎水去生木，反把自己的钱力送到了事情上。震主东方、活动、竹木茶货等，若你原来有东方木货购运、出行或有关材料的支出事项，后续要核其究竟还需要增加多少费用。做事不见得一定亏钱，收入未确定时别用预计报酬去抵消实际花去的成本。

初六有孚盈缶的古意是诚信始终如一，已知的合作和收付应照现实约定履行。寅卯月或问期内寅卯日，留意后段已有的动务投入。申酉亥子月日水相旺，只作准备旧收入条件，没有确定财日。钱先留正常生活和必要开销，别扩大垫付。

## 初六动 · 辰月

前面办财的限制较重，手中现款应先照顾已有责任

水地比 → 山地剥 → 水雷屯

如果最近有收入等着办理，尤其要先看看拿到报酬以前，还需要完成什么事情、承担什么费用。这段财运的限制不轻，稳定的工作收入或已经有给付依据的旧业务更宜维护，实际能留下的钱恐怕不宽。水地比初六，上坎是静体，辰月水衰极；下坤土旺，直接克制原坎。古书说用克体无财，现有财事会比较难办，不宜单看收入的预计数目。

## 初六动 · 巳月

较宜保护原来有收入的事情，先把实际领取条件弄清

水地比 → 山地剥 → 水雷屯

## 六三动 · 丑月

这段钱难拿到手，实际办款和合作责任都要先看清楚

水地比 → 山地剥 → 水山蹇

最近若有些挣钱的事情需要许多现实条件才能办成，先不要因为看上去有报酬便应允额外费用。当前新增所得比较难取得，原来的稳定工作或熟悉营生更宜在实际范围维持，扣支出后的净余不宜高估。水地比六三，静上坎水为你，下坤是动用的财事。丑月土气当旺，水至死地，坤土直接克原坎，领取收入的前段已有不小限制。

此时先处理原有熟悉的收入来源较稳妥。坎古为北方、舟人、水边鱼盐酒货，如果原本有物流、运输及水货流通等营生，可依北边已有客人和运送人员的实际报酬条件办理。中间山地剥的上艮、下坤也皆属旺土，分别向衰坎来克，过程中的条件阻力较重。坤克体古有田土忧，西南实际原有场地或仓库费用须核清；艮克体主百谋中阻，东北有领取或验收手续，先看还有哪些没满足。盘中没有别的卦生扶或相合来添财，与人合作得看真实能不能分担，而非相信一时意向。

最后变水山蹇，下艮土在丑仍然旺，直接克原来的弱坎，收尾的要求压力也不小。艮古象东北、山田土石及山中人，实际原有东北山地货品交接、尾部验收或收费条件的，应把最后办到手需要什么、多少钱说清。比六三比之匪人，古注说所亲非己亲，借其义去看现实合作能力和收入条件，不凭卦判某人为恶。现在难挣到钱与真的赔钱不一样。

辰未戌丑月或问期内相应土日，应核已有前中尾受制及相关费用；申酉亥子月日坎水相旺可整理旧财条件。暂无强见财日，已有现款先留生活和确定的支出，真正到账后再算能存多少。
