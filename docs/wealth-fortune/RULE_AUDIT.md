# 财富财运（求财）· 写作与原典规则审计

## 问题范围

本项为近期求财总问，关联 [正式分类](../PRODUCT_CATEGORIES_V1.md) 的 `wealth.near-term.outlook` 与 `wealth.near-term.inflow`。同篇分别答财务进益/耗失的趋势和进账机会，明确有财是否有留存条件。正文按现实已知财源、已有事务谈财，不假定职业、交易、家业或投资经历。本项不代替特定投资、约定收入、经营、订单、借款或出售专项。近期以用户所选问期为限，不擅自设置时长。

## 原典依据

- [《梅花易数》卷一至三修订录文](../../sources/revised/meihua-volumes-1-3.txt) 555–557 行《求财占第十》：「体克用，有财；用克体，无财。体生用，财有损耗之忧；用生体，财有进益之喜。体用比和，财利快意。」求财专条的“无财”和“损耗”是不同事件；有进财象也不保证现实净利。
- 493–495 行《体用总诀》及 795–798 行《体用互变之诀》以静卦为原体，动处为本用；本为始、互为中、变为终。本用最紧、体互次、用互再、变卦收束。所有直接作用均对原体，不因变卦重取体，不以生克链条抵销存在的直接作用。804 行《体用衰旺之诀》明确体旺时受衰克影响较浅、衰体无生即使多同党亦乏力。
- 496–503 行各**生体**之象：乾官贵、金宝、尊长；坤田土、果谷等；震动中及木货；巽山林茶果；坎水边、鱼盐酒货文书；离文书；艮山田、安稳有终始；兑金玉货利、朋友讲习。只在相应节点直接生体时用该条；源自八卦类象的现代类推另行标识，不指定用户行业或保证财源。
- 504–511 行各**克体**之象：乾公事、财宝之失；坤田土之忧；震、巽草木山林之忧；坎险陷；离文书之忧；艮谋事中阻；兑口舌纷争。仅依据真实直接来克的节点采用，权衡五态；古说的欺、害等不推定具体人已行欺骗、犯罪或现实损失。
- 129–137 行《八卦万物属类》，[《周易正义·说卦传》09.07](../../sources/reference/zhouyi-zhengyi-hans/09.07.txt) 第21–22行：乾健，坤顺，震动，巽入，坎陷，离丽，艮止，兑说。实际经卦的物、人、事类象依据所在角色及五行关系具体分析。每篇另取该动爻正文及王孔注疏，明确其古义，再以近财语境类推合宜做法，不将古爻原本不同语境改称专断财利。
- 555–557 行专条还明载：生体、体克用之卦气可参得财之时，克体、体生用之卦气可参破财之时。比和有利而求财专条未独立著明应期，不机械套通用吉候。792–793 行明确本用先、互渐、变稍迟、生克并见则有阻节。仅选作用有力且实际所问事项适用的卦气候，未给起卦日、具体问期，正文、简断及时段不写确定公历日期；支日/支月按问期尺度选择。候是传统观察方向，不是已到账、已损失或保证日期。

## 五态与判码

寅卯木旺火相水休金囚土死；巳午火旺土相木休水囚金死；申酉金旺水相土休火囚木死；亥子水旺木相金休土囚火死；辰未戌丑土旺金相火休木囚水死。同卦爻同五气须有一致两项判码，不机械以吉凶节点数决定结论。

| 维度 | 判码 | 定义 |
|---|---|---|
| 财务趋势 | favourable | 进益容易、耗失可承 |
| 财务趋势 | conditional | 有进有耗、力薄或落实有条件 |
| 财务趋势 | difficult | 求财受阻或耗失主导 |
| 进账 | promising | 有明确进账象及承接条件 |
| 进账 | conditional | 有争取空间但落实受限 |
| 进账 | weak | 进账象薄或求财受阻 |

两者分开论证。进账不等于扣除成本后净余；无财不等于本金已亏；用克体可提示求财受阻或破财候，而体生用属于原体实际向外耗泄。原体弱克强用不直断得财，弱用来克体旺不机械断重大损失，有生有克分别说明所在阶段。强支出不能因末比和凭空归零。

## 交付与核验

参照已完成的夫妻婚姻逐月库：64卦、6动爻、12显式月令，目标4,608篇；每篇500–650汉字正文和60–120汉字简断，正文实际原创，拒绝固定开头、同篇重复句及“不能……更不能”式。写清求财趋势、进账/耗失、证据及相应处置，不建议具体证券、杠杆、收益承诺或凭卦猜金额。每篇作者、不同独立AI审读末版全部字段，具体来源及文章对象指纹锁定；逐卦30组季节规则审计，Guan隔离已发布版本独立复核。文稿预览不改变运行时，不冒称人工或预测实证验收。
