# 财富财运（求财）· 写作与原典规则审计

## 问题范围

本项为近期求财总问，关联 [正式分类](../PRODUCT_CATEGORIES_V1.md) 的 `wealth.near-term.outlook` 与 `wealth.near-term.inflow`。同篇分别答财务进益/耗失的趋势和进账机会，明确有财是否有留存条件。正文按现实已知财源、已有事务谈财，不假定职业、交易、家业或投资经历。本项不代替特定投资、约定收入、经营、订单、借款或出售专项。近期以用户所选问期为限，不擅自设置时长。

## 原典依据

- [《梅花易数》卷一至三修订录文](../../sources/revised/meihua-volumes-1-3.txt) 555–557 行《求财占第十》：「体克用，有财；用克体，无财。体生用，财有损耗之忧；用生体，财有进益之喜。体用比和，财利快意。」求财专条的“无财”和“损耗”是不同事件；有进财象也不保证现实净利。
- 493–495 行《体用总诀》及 795–798 行《体用互变之诀》以静卦为原体，动处为本用；本为始、互为中、变为终。本用最紧、体互次、用互再、变卦收束。所有直接作用均对原体，不因变卦重取体，不以生克链条抵销存在的直接作用。804 行《体用衰旺之诀》明确体旺时受衰克影响较浅、衰体无生即使多同党亦乏力。
- 496–503 行各**生体**之象：乾官贵、金宝、尊长；坤田土、果谷等；震动中及木货；巽山林茶果；坎水边、鱼盐酒货文书；离文书；艮山田、安稳有终始；兑金玉货利、朋友讲习。只在相应节点直接生体时用该条；源自八卦类象的现代类推另行标识，不指定用户行业或保证财源。
- 504–511 行各**克体**之象：乾公事、财宝之失；坤田土之忧；震、巽草木山林之忧；坎险陷；离文书之忧；艮谋事中阻；兑口舌纷争。仅依据真实直接来克的节点采用，权衡五态；古说的欺、害等不推定具体人已行欺骗、犯罪或现实损失。
- 129–137 行《八卦万物属类》，[《周易正义·说卦传》09.07](../../sources/reference/zhouyi-zhengyi-hans/09.07.txt) 第21–22行：乾健，坤顺，震动，巽入，坎陷，离丽，艮止，兑说。实际经卦的物、人、事类象依据所在角色及五行关系具体分析。每篇另取该动爻正文及王孔注疏，明确其古义，再以近财语境类推合宜做法，不将古爻原本不同语境改称专断财利。
- 555–557 行专条还明载：生体、体克用之卦气可参得财之时，克体、体生用之卦气可参破财之时。比和有利而求财专条未独立著明应期，不机械套通用吉候。792–793 行明确本用先、互渐、变稍迟、生克并见则有阻节。仅选作用有力且实际所问事项适用的卦气候，未给起卦日、具体问期，正文、简断及时段不写确定公历日期；支日/支月按问期尺度选择。候是传统观察方向，不是已到账、已损失或保证日期。

## 五态与判码

寅卯木旺火相水休金囚土死；巳午火旺土相木休水囚金死；申酉金旺水相土休火囚木死；亥子水旺木相金休土囚火死；辰未戌丑土旺金相火休木囚水死。同卦爻同五气须有一致两项判码，不机械以吉凶节点数决定结论。

| 维度 | 判码 | 定义 |
|---|---|---|
| 财务趋势 | favourable | 进益容易、耗失可承 |
| 财务趋势 | conditional | 有进有耗、力薄或落实有条件 |
| 财务趋势 | difficult | 求财受阻或耗失主导 |
| 进账 | promising | 有明确进账象及承接条件 |
| 进账 | conditional | 有争取空间但落实受限 |
| 进账 | weak | 进账象薄或求财受阻 |

若本用、两互、变用四处都直接比和且没有生体、克体、体克、体生的另项作用，全盘同质：旺相则 F/P；休则 C/C；囚则 C/W；死则 D/W。依据804行“虽体之卦党多，皆是衰卦，终不吉也”，死气难以取得财，非现实破财或本金损失；囚休仍有相合而兑现力薄的条件。同质特例不外推到其他混合盘。

两者分开论证。进账不等于扣除成本后净余；无财不等于本金已亏；用克体可提示求财受阻或破财候，而体生用属于原体实际向外耗泄。原体弱克强用不直断得财，弱用来克体旺不机械断重大损失，有生有克分别说明所在阶段。强支出不能因末比和凭空归零。

## 用户补充的完整求财断语口径（第二版）

不再只说明收支。每篇先用自然、不重复的起笔给出该问期财运总基调、求财的顺遂或劳碌、偏稳定本职/主动争取/机会与资源增益的性质，以及相对可留利润空间。正文随后结合真实四关系、旺衰及古爻说明取财方法、可能适合的行业属性和传统方位、协作与外援、客户或资源方类型、主要破财隐患、留存能力与实际处置。不存在支持时明说具体项目不能由此盘确定，不用想当然的亲友借钱、同行争抢或跟风投资情节撑篇幅。没有真实财源条件不冒称已有某种职业、薪资或偏财命格，近财不硬断一生。

具体取象按原体的办事特点及财源节点角色，不把直接生体的专条套到同比、体克用或体生用。《梅花易数》原各卦门提供人物、求利与方道：乾222、235–236、242西北；坤253、265–266、275西南；震284、294、299、306东方；巽315–319、327–328、337东南；坎346–349、357–358、367北；离376–379、388–390、398南；艮407–410、418–420、428东北；兑437–440、449–451、459西方。463行「各以其类而推」可供现代相似职能的有限类推，655行时令之应、658行方卦之应、965行《方应》及968行日应需辨体和强弱；965明示生体或比和方向可取，体克财的方位则只是该财对象所在经卦的属性；不独立摘取八卦门中单象的无财、破财、利三倍等绝对词，亦不把方位解释为迁居即可发财。行业性质、方位、人群都从实际相关节点取象并以现业务或可核资源为条件；原体特性仅支持工作方式类推。

人际方面直接生体可取外来资源支持，强比和可取合作相合，体克用则是自身能掌握之财，不冒称贵人。乾生体才直接取公门、尊长、老人进益；其他生体各依496–503，克体各依504–511取象；弱比和、弱生不等于可靠的合作承诺。用克体是求财阻节或防损候，体生用才是财力向外耗，风险依实际经卦及事项细分。无克耗盘不硬找破财故事；提醒核实合作分账、尚待兑现收入即可。利润仅相对倾向，留存按实际成本、应付和可支配余额核算，不给卦象买卖指令。

时段说明具体用神卦气对应的月支或问期内日支，并标明是见财、蓄力准备还是防耗事项。卦中没有足够财候时以原体旺相月日作准备、弱令作稳守的环境参考，不冒用求财专条。直接比和无独立专条应期的盘也按体气环境说明何时适合处理已有财事；转月后须按届时旺衰重核。不指定未给出的公历日期或保证现实兑现。对于大额支出和置产配置，建议依据预算、实际需求与风险评估，而非卦象单独决定。

第二版稿每篇对象新增 `editorialVersion: wealth-fortune-v2`，只在实质改写/补齐、作者和不同独立AI全文复审锁闭后计入新版覆盖。此前216篇有完整第一版交付与验收记录，逐批复审更新；不以第一版完成冒称第二版覆盖。最终4,608篇均需符合第二版口径。

## 具体公历应期动态换算

依据用户最新指示，作者将每篇已经写定、独立复读的卦气时段另存结构化旁证（`sources/editorial/wealth-fortune/timing-monthly/hex-NNN.json`），每条绑定文章末版对象指纹、真实原体/本用/体互/用互/变用角色、具体事件、适用原典与理由；独立读者逐对象核查并锁应期指纹。历法程序不从句子猜测财候，也不从卦盘自动补造财务结论。需要区别得财、条件增益、己耗、来克阻节、实际弱克/弱泄的风险复核、体旺相的蓄力环境、体囚死的守持环境。

`src/wealth-fortune-timing.js` 沿用现有 `src/day-calendar.js` 的先天五行日气历法，本月参考日（含当日）到月末筛真实地支日，有匹配优先本月，无匹配才检查下月；显示具体几号，若问期给定结束日也不得越界。新的看盘按当时实际月支选当月稿并用新的参考日重新计算，旧历史按原起卦日保留计算结果，已过日期明确标记，不能重新滚动并冒称历史应期。实际月令须由使用方沿仓库既有历法输入，不将公历1–12月粗暴硬套寅丑月，也不把旧月令读文挪用作新月。调用示例和测试见[动态应期使用方式](TIMING.md)。

本次新增只读预览 API 和日期渲染，不将尚待用户逐篇验收的语料接入正式产品调度。Markdown为指定参考日的静态快照，重新生成或调用只读 API 即取得当前具体日期，正文和简断不会随换日被改写。
