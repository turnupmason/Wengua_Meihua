# 素材出图记录

本包使用内置 ImageGen。原始分辨率 PNG 保存于 `keyframes/` 和 `masters/`。运行图由对应母版导出为 WebP 或灰度遮罩。参考图来自本轮用户截图与仓库既有美术。以下是重制时可复用的出图 Prompt 要点。最终尺寸、alpha、哈希和用途以 [清单](asset-manifest.json) 为准。

| 文件 | 输入与可复用 Prompt |
|---|---|
| `keyframes/01-moonlit-courtyard.png` | 图一只决定光色与质感，图二决定布局。竖版 9:16，摄影级写实中式道观月夜，正中同一双门，整座灰瓦屋顶和斗拱，古铜香炉及石灯位于近景。冷灰紫远山有雾层，右上月面可见，墨棕阴影和暖象牙局部光。空匾，画面纯环境。 |
| `keyframes/02-open-threshold.png` | 输入新殿外图和原图三。竖版 9:16，从石阶上人眼高度看同一栋殿门。两扇有厚度的乌朱漆门沿左右外门轴向内开，格窗与旧铜环可见，冷月光过渡到暖灯。门内能看到深处的红毯和梁枋；牌匾中央留空。 |
| `keyframes/03-hall-lighting.png` | 输入登录图、新殿外图和原图四。竖版 9:16，同一殿内，墨棕木壁和局部柔暖光，旧铜香炉、暗色供桌、三座留空台基，中央略高。为原有三尊图像留出背景和剪影空间；画面无人物。 |
| `masters/moon-and-mountain-matte.png` | 输入新殿外图。2:1 宽画幅，月与烟灰夜空，灰紫层云，底部约 30% 分层远山，右上单一有表面纹理的暖银月。纯远景，无建筑、地面或近景。 |
| `masters/basecolor-atlas-3x3.png` | 输入新殿外图。方形 3×3，无缝隙、标签或投影。三行从左至右分别为炭黑漆木、乌朱漆木、炭灰瓦；暖灰石、旧铜、旧金箔；近墨绿彩绘木、暗红织物、象牙灯纸。统一漫射光，只提供底色信息。 |
| `masters/door-leaf-albedo.png` | 输入新门槛图。竖版 1:3，正交、单扇，深乌红漆木和竖木纹，上部规整低对比方格，下部为实木和细古金边。画面只包含门扇正面，门环由网格实现。 |
| `masters/cloud-frieze-mask.png` | 输入新殿内光照图。横版 3:1，黑底白线一枚对称如意云纹，两端渐收，正交亮度遮罩。 |
| `masters/incense-wisp.png` | 竖向单股细香烟，柔灰、低密度，边缘与两端平滑消失，真实透明背景和足够透明边距。 |
| `masters/architecture-props.png` | 输入新殿外与门槛两张图。2×2 造型板。左上旧木斗拱，右上门环，左下石灯，右下古铜香炉和石座。比例可信、轮廓清晰、无字。 |

所有场景母版使用低饱和、墨棕层次、局部香槟和象牙高光，避免文字和 UI。画面里的现有神像身份由项目现有图片保持。导出时保持母版原始像素，应用优先用压缩图。
