# 入殿动画 · 实施记录（2026-11-12）

分支 `feature/entrance-art`，起点 main `2a2d64a`（工作区干净）。

## 做法

用户要求入殿和殿内落位与三张关键帧一模一样，因此直接使用关键帧画面。

| 镜头 | 画面 | 动作 |
|---|---|---|
| 月下殿外（等待、启屏） | `keyframes/01` → `plate-courtyard.webp` | 缓慢呼吸；四盏石灯窗微闪；香炉低烟（`incense-wisp.webp`） |
| 推门（2.5–3.5 秒） | `keyframes/02` → `plate-threshold.webp` | 图一推近殿门后叠化到门开的图二，宫灯微闪 |
| 穿门（4.4–6.9 秒） | 图二 | 推进门洞并淡出，露出下层殿内 |
| 殿内落位 | `keyframes/03` → `plate-hall.webp` + 三尊原图 | 太上老君（左）、元始天尊（中，稍高稍后）、灵宝天尊（右）坐在三座台基上；接触阴影；略压亮度并加暖色；墙上补「三清殿」匾；宫灯微闪，香炉低烟 |

- **匾额文字**：「三清殿」用应用的毛笔字体（Ma Shan Zheng，OFL）以旧金浮刻写进图一、图二的空白匾里，并在图三墙上补画同样风格的匾。生成脚本为 `apps/mobile/scripts/build-entrance-plates.py`，以关键帧为输入。
- **3D 的位置**：只在起卦走向石桌、去藏经阁或问事录时淡入；殿内画面完全显示时，3D 暂停渲染。
- **取景**：殿内画面按托盘顶边和顶栏实时测量，三尊（法冠到台面）放进两者之间；左右两尊离屏幕边至少 8 像素。

藏经阁、问事录：用户另发的书架、书案图（4:3），转成 `place-library.webp`、`place-records.webp`（同一脚本第二个参数为图片所在文件夹）。用户文件夹里两张的文件名与内容相反（`records.png` 是书架），脚本按内容对应：书架 → 藏经阁，书案 → 问事录。画面从屏幕顶端铺到面板顶边稍下，宫灯微闪，书案小香炉一缕细烟；切换处所时三张画之间叠化。缺这两张时，这两处保持 3D，入殿和殿内不受影响。

起卦仪式里看殿的部分也用这幅殿内画（`PaintedHall` 的仪式模式，读仪式时钟）：

- **走向三清、坐下、抬头**：全程是这幅画，一条连续的缓推，从三清整体推到元始天尊（1 倍到 1.38 倍），中途不切 3D。
- **祖师赐卦**：金光放射，手中宝珠发光，一道金色光柱带细碎金点垂下。宝珠落到石桌的时刻在半秒内淡入 3D 石桌，开始刻卦。
- **石桌前**：画面上方加暗角，3D 殿隐入暗处。

3D 殿内作为退路，也按图三收敛：三清身后用图三台基以上部分（`hall-wall.webp`，两侧渐暗）作后墙，不受灯光和雾影响；梁枋、天花压成暗褐，供桌正面改深色木面，红烛压暗。

石材（用户 2026-11-12 提供，`public/art/entrance/materials/`）：

- **石桌**：`table-stone.webp`（灰石）用于桌面、桌腿、石凳、桌框、桌裙的底色，保留程序凹凸和刻卦。金字、金爻和红色动爻在新石面上照常清楚。
- **地砖**：`floor-stone.webp`（深褐石）用于三清殿及外庭地砖底色，每块砖一整张、深浅略有不同，程序叠加砖缝暗线；凹凸与砖缝凹槽沿用程序法线，网格对齐。

## 时间与状态

- **时长**：完整入殿 7.6 秒（`WALK_IN`，`scene/timeline.ts`），减少动态为 2 秒（直接淡入殿内）。
- **同一时钟**：画面、3D 镜头和入殿结束都读仪式时钟（`useRitualClock`）。页面在后台时时钟暂停，回来后从原处继续；原来独立的 12 秒墙钟定时器只在 3D 退路里使用。
- **跳过**：「跳过 · 直接入殿」立即落位。
- **简洁问事**：老访客直接到殿内画面。
- **无 WebGL**：殿内首页也显示画面。
- **退路**：任一画面加载失败时，回到原 3D 入殿（第一轮已按美术规范调过光色：月夜远景贴图、炭灰瓦、乌朱漆、墨绿梁枋、分区雾）。

## 性能（2026-11-12 修）

- **3D 暂停**：画面盖住时 3D 一律暂停渲染，包括启屏、整个入殿、殿内首页、藏经阁、问事录；只在走向石桌时恢复。实测在前述三段里 3D 渲染 0 帧，起卦后正常恢复。
- **取景不再挪动**：殿内画面按托盘高度取景（托盘贴底、约 410 像素，量过一次记在本机），托盘出现前后同一取景；样式只在变化时才写。
- **首页不放烟**：殿内香炉在托盘下方，首页不放烟动画，免得毛玻璃托盘每帧重算模糊；三尊原图去掉投影滤镜；灯光和烟改为普通叠加。
