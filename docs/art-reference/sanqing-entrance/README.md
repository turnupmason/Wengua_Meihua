# 三清问道 · 入殿美术交接包

从 [Claude 实施 Prompt](CLAUDE_PROMPT.md) 开始。将整个目录放在仓库的 `docs/art-reference/sanqing-entrance/`，Claude 可直接读相对路径。2026-11-12 制作，依据用户发来的四张界面截图和本机移动端场景源码。素材包当前未接入应用。

## 文件怎么用

| 目录 | 内容 | 接入方式 |
|---|---|---|
| `reference/` | 四张用户截图、现用登录原图、左太上老君／中元始天尊／右灵宝天尊的现用原图 | 定风格、固定人物身份、对比现状。应用继续从原路径读取人物原图。 |
| `keyframes/` | 月下殿外、推门临界、殿内照明三张 941×1672 关键帧 | 用来对照实机镜头。殿内图刻意留空三尊原像位置。门外、门槛图的匾额留白，应用沿用代码绘字。 |
| `masters/` | 夜空、材质图集、门面、云纹、透明烟，以及斗拱／门环／石灯／香炉造型图 | 保留原始尺寸做局部核对。造型图供现有程序化网格重建。 |
| `runtime/` | 14 个可接入文件，含院外备用首帧、天空远山、门扇正面、香烟、云纹遮罩和九种材质底色 | 压缩资源共约 411 KiB。按需复制到移动端 `public/art/entrance/`，避免把母版、参考图和整组关键帧加入包体。 |
| `asset-manifest.json` | 尺寸、alpha、文件大小、SHA-256 与用途 | 可独立检查完整性、盘点资源引用。 |

### 三张关键帧

1. [月下殿外](keyframes/01-moonlit-courtyard.png) · 墨灰远山分层，月光保留月面，石灯暖光沿地面衰减。
2. [门槛](keyframes/02-open-threshold.png) · 同一栋建筑、同一副门扇，近处可以读出木纹、厚度和铜件。
3. [殿内灯光](keyframes/03-hall-lighting.png) · 保留安静的背景和暖色光区，把视觉中心留给现有三清画像。

### 交付边界

本包包含可用贴图和关键帧。真实门扇、斗拱、石灯、香炉继续使用项目的程序化 3D，由 Claude 按图加厚、倒角、修正材质和灯光。造型图是建模参考，无 GLB 模型。九张底色是材质样张，需检查重复平铺边界；凹凸和粗糙度用项目程序纹理和材质参数实现。门图上的浅浮雕感已包含在底色里，独立铜环仍需用网格表现。生成过程使用内置 ImageGen，移动端运行时只读取本地素材。
