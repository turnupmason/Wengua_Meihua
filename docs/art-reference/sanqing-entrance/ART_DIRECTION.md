# 三清问道 · 镜头与材质规范

## 现状与目标

图一的写实感来自局部逆光、暖白高光、真实的表面与明暗过渡。当前图二到图四把纯白月亮、亮门格、青绿梁枋、朱红门板和金色供桌分别推到高饱和或高亮，视觉焦点在镜头之间跳动。门与柱边缘太直太薄，地面与台阶缺接触阴影，拉近后容易显出模型的尺度差。统一顺序为光位 → 相机 → 材质 → 近景轮廓 → 空气感。样色是取景调色起点，成片以图一与三张关键帧的并排观感为准。

| 用途 | sRGB 样色 | 用法 |
|---|---|---|
| 墨黑 | `#17161B` | 夜空、深阴影，保留色阶 |
| 月下雾灰 | `#777580` | 冷雾远景、檐口和石阶的冷侧 |
| 暖墨棕 | `#2A211B` | 殿壁和低反射阴影 |
| 乌朱漆 | `#3D201B` | 门扇、柱、红色细节 |
| 古铜 | `#6A5033` | 香炉、铜环、门钉 |
| 旧金 | `#AA8351` | 雕刻边缘、字、稀疏云纹 |
| 香槟光 | `#D5B487` | 木口与石材的暖侧 |
| 象牙灯芯 | `#F2DDC0` | 极小面积灯芯，向外渐暗 |

可用 3 段短转场基于同一个世界坐标。殿外暖灯先建立视觉引导，进入门槛时月光沿台阶退去、暖灯沿红毯接入，殿内由两侧暖光把注意力带到中央三像。相机焦距变化保持缓慢，近景利用门环、门轴、柱与台阶获得真实视差。320 视口先检查整块屋檐和人物面容，其次检查装饰。图中暖光和雾层已烘焙到参考帧，实际实时亮度应以共享色调映射和局部光模拟。

## 可复用材质

下表的值是 Three.js 初始试值。根据实渲截图调整。底色图中已包含基础着色，不用全局黄染再叠一层。现有 `normalFromHeight` 适合微小石纹和木纹，门板深结构由几何或 UV 对应法线提供。

| 材质 | 底色文件 | Roughness 起点 | Metalness 起点 | 几何与纹理 |
|---|---|---:|---:|---|
| 檐梁 | `black-lacquer-wood.webp` | 0.64 | 0 | 低频漆色起伏，梁边小倒角，云纹稀疏 |
| 柱、门侧 | `oxblood-lacquer-wood.webp` | 0.56 | 0 | 木纹沿柱纵向，散射高光不过白 |
| 屋瓦 | `charcoal-roof-ceramic.webp` | 0.68 | 0 | 屋脊和勾头用形体，瓦沟方向跟坡度 |
| 石阶、地面、石灯 | `warm-gray-stone.webp` | 0.83 | 0 | 踏面薄倒角、接缝和接触阴影，现有程序法线低强度 |
| 门环、香炉 | `aged-bronze.webp` | 0.52 | 0.68 | 低段数环及厚度，角边少量高光 |
| 金边 | `antique-gold-leaf.webp` | 0.55 | 0.60 | 仅窄边和浮雕，云纹遮罩建议低混合 |
| 青绿梁枋 | `painted-dark-timber.webp` | 0.76 | 0 | 退成接近墨绿，限制彩绘面积 |
| 红毯 | `muted-burgundy-cloth.webp` | 0.95 | 0 | 弱织纹，旧金稀疏图样，边缘更暗 |
| 灯纸 | `ivory-lantern-paper.webp` | 0.88 | 0 | 小面积暖光，减淡远端强发光 |

九张底色均为 384×384 独立样张。大面平铺前先观察接缝，再利用现有程序微纹和 UV 范围减轻周期感。使用云纹遮罩贴近梁面时处理深度偏移；暗金强度以主要节点仍低于人物面容为准。烟图作为低处、低透明度、轻微上升的有限精灵层，建议 `NormalBlending`，透明绘制、`depthWrite=false`，保留深度遮挡。远景图是 2:1 的单视角画面，天空区域比山层大，可作为有限视角 matte。人物卡片与匾额用现有原图和字体。色彩空间的技术依据见 [Three.js 色彩管理](https://threejs.org/manual/pages/color-management.html)。

## 造型参考

[斗拱、门环、石灯、香炉](masters/architecture-props.png) 从左上、右上、左下、右下阅读。斗拱需要有承接层与阴影间隙；门环保留轮廓，底座可简化为素铜圆盘；石灯要读得出底座、灯腔和瓦顶；香炉以低矮宽口、厚唇、双耳和石座为主。造型图高光只用于理解表面，实渲使用同一套殿外光。

## 建议预算与验收机位

- 建议新增运行位图约 0.5 MiB 内。本包运行素材共 421,190 bytes。该值是压缩文件大小，显存按解码尺寸和 mip 另计。复用材质、近景低段数倒角、远景合批，沿用原有画质分级。
- 固定 4 个对照机位：等待、门开约一半、过门、殿内托盘出现。保存每张图的视口、DPR、机位时间、浏览器和画质。门半开检查两侧光差、真实厚度和门槛接缝。
- 观卦石桌单独核对。画面共用材质或曝光调整后，金爻、红色动爻、本互变卦名、体用标签和触控映射需要复核。
