## 逐条追溯与验证

[逐条终校索引](interview-pass/final-review-20261112.tsv) 按本卦、动爻、气类排列。每行列出月令键、三卦编号、原体与四节点五态、结论、应期节点及地支、作者源、修订范围和生成摘要。按本卦找到 [对应 JSON 分片](../data/authored-readings/interview-pass/) 后，可用动爻与气类定位完整出处、直接关系、反证、未取期理由和已有作者复核记录。`manual-verdict-wording-check` 记录本次人工核对的机器措辞提示数量。

本次对 1,920 篇执行全库扫描，逐条重算本互变、真实动爻、六位置体用和旺衰、四条直接关系及 4,608 个精确月令键。校验完整动爻、引文与出处定位、简详结论绑定、应期事件性质及数据状态。检查标题、简断、开局、过程、结局、总断的完全重复，以及简断去开头后的四字片段近似。上述扫描未发现重复字段或仍需更正的卦象、月令、引文及应期阶段错误。结论措辞最后有 21 处触发措辞检查，涉及 20 篇，人工核读后确认均与结论一致。近似检查的相似阈值为 0.17。本轮采用全库程序复算和命中稿件人工核读、修订，历史的逐篇作者全文复核沿用原记录。独立专业审核待完成，用户逐篇验收为 0 篇。

数据重建后核对 JSON、完整 SQL 与 SQLite 的 1,920 条正文和 4,608 条月令映射。核心 113 项、移动端 128 项测试及移动端构建通过。用独立历法库 `lunar-javascript@1.7.7` 对照，实际日期重放覆盖 60 个连续干支日及 4,608 个月令键，共 276,480 次查稿。生成 253,680 个窗口，其中 29,996 个匹配到次月。23,040 次按稿件设定留未取期。日历对照验证干支与匹配结果，传统应期的独立专业审核仍为待完成。
