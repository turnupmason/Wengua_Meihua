# 问卦 Wengua — 手机应用

第一视角道观起卦应用：入观 → 恭诣三清、坐到石案前 → 祖师赐卦，石桌显出本卦、互卦、变卦。排盘、体用、互变、月令、旬空与经文全部来自仓库根目录的知识模块（`src/index.js`、`data/`），应用不复制任何排盘算法。

## 运行

需要 Node 20.11+（仓库根目录资料脚本要求 Node 22，建议统一升级到 22）。

```bash
cd apps/mobile
npm install
npm run dev        # http://127.0.0.1:5173 ，用浏览器手机模式（竖屏）查看
npm test           # 37 项：历法、起卦冻结、仪式状态机、384 爻映射、详情面板交互
npm run build      # 类型检查 + 生产构建到 dist/
```

在仓库根目录也可用 `npm run app:dev`、`npm run app:test`、`npm run app:build`。

## 原生壳（Capacitor 7）

```bash
npm run cap:sync      # 构建并把 dist/ 同步进 android/ 与 ios/
npm run cap:android   # 用 Android Studio 打开，连接设备或模拟器运行
npm run cap:ios       # 仅 macOS：先 `cd ios/App && pod install`，再用 Xcode 运行
```

- `appId` 目前是占位 `app.wengua.meihua`，**第一次上架前必须确定**，上架后不可再改。
- 未签名、未上架。iOS 需要 Apple 开发者账号与 Mac/Xcode；Android 发布需要签名密钥。
- Android 当前 target SDK 35。Google Play 对新 target SDK 的要求每年提高；升级到 Capacitor 8（需 Node 22）即可跟进，命令 `npx cap migrate`。
- 图标/启动屏：`resources/icon.svg`、`resources/splash.svg` 为占位图。导出 1024px PNG 后可用 `npx @capacitor/assets generate` 生成各尺寸。

## 画面构成与流程（全部代码生成）

- 殿堂：彩绘天花与藻井、旋子彩画梁枋、朱漆金箍柱与雀替、两侧山水壁画与透光隔扇、三清身后金色祥云屏风、宫灯、三层烛架、经幡、高窗斜射光束、红色拜垫通道、抛光石地。
- 三清：三张美工坐像各自抠出（人物、宝座、冠、祥云与彩绘底座；去掉星空、柱子、名牌和画中光环），`public/art/sanqing-{laojun,yuanshi,lingbao}.webp`，按原画颜色显示。各坐一座三维须弥座：元始居中、座高且稍后，老君在观者左、灵宝在观者右，微向中间转；头后各有一圈八卦光环，身影投在金色云屏上。座位数字在 `src/scene/shrineLayout.ts`，抠像脚本与轮廓在 `scripts/deity-cut/`（原图存 `docs/art-reference/*-seated.webp`）。赐卦光芒聚在元始手中宝珠。二维模式用同三张抠像。三清半身合影 `public/art/sanqing.webp` 作登录页背景。
- 供品：供桌桌围、烛台长烛、寿桃/橘/苹果/寿桃馒头五盘、四盏茶、长明灯、两瓶花；香炉内原有数十炷燃香与袅袅香烟。
- 起卦：在殿内选好问事领域与起卦方式，点「入观」即冻结本卦（不再上香）。镜头从殿中望着三清缓步上前，转到旁边石案，途中字幕依次显示问卦三戒（初筮告…／有疑方卜…／不诚不卜…）。
- 坐上石凳 → 金光自三清处照下，「祖师赐卦」 → 卦爻由金光一笔笔写入石中（初爻到上爻、本卦→互卦→变卦），刻完槽底亮起金光，再刻出竖排卦名与等级。
- 石案布局（竖屏优先）：三卦由近到远排列——本卦（目前）最近、互卦（经过）、变卦（结果）最远；「目前／经过／结果」单独刻在左侧带框的一列并以箭头相连；体用标签与生克箭头在本卦左侧；「生克 · 短句」刻在最近一侧。
- 变爻：朱红色持续闪烁，旁刻传统符号（老阳 ○ / 老阴 ×）；变卦对应位置只有暗色小圈，不是第二动爻。
- 声音：殿内轻声道乐（古琴、箫）；入观一声颂钵（柔和，不用低沉钟声）；坐下衣袖轻响；赐卦时颂钵、法铃、磬相继；刻卦每爻一音，本卦用磬、互卦用柔和的埙声、变卦用编钟，各六音由初爻至上爻渐高；全部经殿内混响。
- 字体：思源宋体子集；匾额、对联与标题用马善政楷书（Ma Shan Zheng，OFL 1.1，`public/fonts/OFL-MaShanZheng.txt`）子集。`npm run font:subset` 重新生成。

- 开场：先是水墨夜山、明月与金色「问卦」的启屏（加载时显示进度）。初次进入在启屏上登记道号或以游客入殿（`src/domain/profile.ts`，本机保存）。登录页已有微信、Apple、Google、手机号验证码入口，接入账号服务后由 `AuthProvider` 提供；未接入时点按会提示，并可先以道号或游客入殿；之后启屏只问候“某某，欢迎回殿”。启屏背后是实时三维的夜色殿前：星空明月、远山薄雾、石灯、香炉青烟，殿顶、彩画额枋、斗拱、彩绸、楷书匾额与对联。轻触后一声颂钵，镜头从庭院绕过香炉走到殿门前，殿门向内缓缓打开，穿门走到三清像前，问事托盘再升起。礼毕回殿不再重放；设置里可“更换道号”。
- 详情面板：可按住顶部拖动到任意高度，拖得足够低即关闭；轻点把手在半屏与全屏间切换。阅读时镜头把石桌放在底部按钮之上，刻字不被遮挡。

- 会员（`src/domain/membership.ts`）：免费每日 1 卦、断语只见一句摘要；单次解锁本卦完整断语 ¥6 / $0.99；月度 ¥28 / $4.99、年度 ¥198 / $39.99，每日 3 卦、全部断语。不设“无限占”（合“初筮告，再三渎”）；同一件事 7 天内再问会先问是否同一件事（见下）。起卦次数记在独立的使用记录里，删除历史不会重置。付款经 `PurchaseProvider`：开发版用“测试购买”（不扣款），正式版需接入 App Store / Google Play 内购，并由服务端校验收据、执行次数限制。
- 结果页（2026-11-11）：结论先行。石桌下方是结论卡：标题（如「先难后易」）、基调（以不顺为主／以顺为主／以耗费为主）、一句“开局…，过程…；结局…”，以及「目前 · 经过 · 结果」三段（点开进入读卦）。主按钮依次为「断语」「读卦」「收卦入册」，「礼毕 · 回殿」降为小字。石桌刻字改为三段事实（如“用克体 · 互克体 · 变比和”）。判断来自引擎 `reading.synthesis`（用卦影响最大，互卦次之，变卦再次；体互重于用互），规则见 `docs/RULES.md`。动爻上有红金色呼吸光（减少动态时为静态高亮），点动爻有较重的双震。
- 首页（2026-11-11 第二轮）：殿内只放一层独立、不透底的操作面板，位于三清下方，不盖神像。依次是：「问何事」六大领域（事业工作、财富财运、感情姻缘、健康疾病、家庭家宅、寻人失物，3×2 大按钮），右上「专业分类 ›」打开《梅花易数》十八类占法；选领域后出现常见问题（可点选），一个问题输入框；一行起卦方式与时辰，「更多起卦方式」打开全部七种方法；「完整仪式 / 简洁问事」切换；一个「诚心起卦」按钮。必须先选领域、写下（或点选）问题才能起卦。会员次数从神像下方移到设置里。
- 领域与古籍占法的对应在 `src/domain/topics.ts`：每个常见问题按最贴切的十八类占法解读（如“这份工作能拿到吗”→求名占，“这笔投资能赚吗”→交易占，“等的人会回来吗”→行人占），自写问题用该领域默认占法。六大领域都不会落到天时。健康、感情附带提醒（以医生诊断为准；他人心意不能由卦得知）。
- 节奏：`settings.ritualMode`（auto / full / quick）。auto 时第一次走完整仪式（庭院走入、恭诣三清、祖师赐卦），有过问事记录后默认简洁问事：点「入殿」直接到殿内，点「诚心起卦」直接出结果。两种节奏调用同一次起卦，排盘结果相同。
- 结果先答所问：结论卡与读卦页先写“就‘……’而言：《求名占》说「用克体，名不可成」；结局转顺，末后或有转机。”——引的是该类占法对本卦体用的原句，结局一句按《体用互变之诀》看变卦。
- 命名：「三清问道」是品牌（启屏、网页标题），「三清殿」是场景，「梅花易数」是方法，「入殿」是进入场景，「诚心起卦」是起卦按钮；「藏经阁」为六十四卦与古籍，「问事录」为问事记录与卦册。原生壳（Capacitor）的应用名尚未改。
- 隐私：问题只存本机。应用唯一的网络读取是自身打包的数据；将来查断语只按本卦、互卦、变卦、动爻和占法类别查询，不发送问题原文。
- 殿中三处（`src/scene/placeLayout.ts`、`Places.tsx`）：殿内顶部「问事香案 · 藏经阁 · 问事录」。藏经阁是左墙两柱之间的藏经柜（格中卷轴、「藏经阁」匾），问事录是右墙的书案与书架（线装册、展开的册子、笔砚、「问事录」匾）。点标签或直接点三维里的柜子、书案，镜头从香案前走过去，页面以面板形式出现在下方，上方仍能看到所在之处；返回时镜头走回三清前。开启“减少动态”时直接切换。
- 切换流畅：所处位置放在 `src/ui/placeStore.ts`（不放在 App 状态里），切换只重绘标签和面板；三维场景 `TempleScene` 与首页面板经 memo 不随切换重绘；藏经阁、问事录页面进殿后空闲时预先建好并常驻，点击只滑入；顶部标签不用毛玻璃；两处共用一盏随行的灯；分辨率调节只在持续掉帧 3 秒以上且距上次调整 6 秒后才动，避免移动途中改画布尺寸。
- 美术（2026-11-11）：地砖改为哑光深色大块石材（去掉细碎噪点和强反光）；三清身后云屏改为深漆底、少量大朵暗金祥云，不再密铺。
- 手机：渲染分辨率自动调节（`src/scene/adaptive.ts`，帧率持续低于约 40 时降低、富余时慢慢升回，起步不超过 2 倍）；iOS 键盘弹出时，首页面板与弹出面板抬到键盘上方（`src/ui/keyboard.ts`，CSS 变量 `--kb`），聚焦的输入框自动滚到可见处；所有输入框字号不小于 16px，避免 iOS 自动放大；左右与底部留出刘海/圆角安全区。
- 真机测试：`npm --prefix apps/mobile run dev:lan` 在 5174 端口对局域网开放（同一 Wi-Fi 的手机用 Safari 打开 `http://电脑IP:5174`）。只在自己的网络里用；它会把开发中的源码提供给局域网。
- 结论卡（2026-11-11 第三轮）：标题与基调之下先写所问，再用一句话直接回答（引擎 `synthesis.verdict` + `topics.ts` 的所问之事），三段标签在下。读卦页的「综合判断」逐行列出 当前 / 过程 / 后势 的证据与综合结论、冲突时的边界说明和可能改变判断的条件；古籍原句与《体用总诀》在其下。
- 冻结原盘（`CastRecord.snapshot`）：起卦时保存当时的标题、基调、结论句、三段证据、规则版本、内容版本与证据编号（爻辞、类占原文、所据篇目）。之后规则更新不改写它；卡片与问事录都显示当时所给，读卦页若规则已更新会注明。每次起卦另有 `eventId`。
- 问事录：点一条记录，按 当时所问 → 当时卦象 → 当时解读（原样保存）→ 后来进展 显示，进展只能追加、各带日期，与原盘分开；可「重看此卦」。导出 JSON 含原盘、快照与进展。
- 同一件事（`src/domain/sameMatter.ts`）：7 天内、同一领域，若与先前所问提到同一名称（如都含 Amazon）或措辞高度相近，先问“是同一件事吗？”——是，则打开原卦记进展，不另起卦、不扣次数；否，则作为另一件事起卦。不同名称（Amazon 与 Google）不视为同一件事。统一为 7 天。
- 藏经阁：六十四卦两列卡片（卦符、卦序、卦名、上下卦、等级），可按卦名、卦序、卦辞与爻辞搜索；每卦一页：卦辞与白话、象传、六爻（爻辞、白话、小象、此爻变成何卦，可点跳转）、互卦、出处行号与维基文库原文。读卦页每卦与动爻旁有「在藏经阁中看」，直接打开该卦并标出本次所用之爻。
- 性能（第三轮）：殿内灯从 25 盏减到 11 盏可见（院外 7 盏进门后关闭，两种灯光组合预先编译；烛台、单支蜡烛与赐卦不再各带灯）；平行光阴影只在需要时重画；音效引擎（殿内混响与古琴音色）改在启屏时分片预先生成，点「入殿」不再卡顿；殿内视图整体不可被滚动（`overflow: clip`）。
- 第四轮（2026-11-11）：字体子集脚本现在也收录知识引擎（仓库 `src/`）与天时原文中的字，新加的「藏经阁」「问事录」、解卦与卦页文字不再回落到系统字体，牌匾恢复毛笔字（改文字后运行 `npm --prefix apps/mobile run font:subset`）。石桌刻字贴图提高到每米 1800 像素、各向异性 16；分辨率调节在手机高清屏上不低于 1.5 倍，读卦时立即回到全清晰。刻字贴图在走向石桌途中分批绘制并预先上传，刻字着色器异步编译；殿内香烟粒子减半。藏经阁改为锦面经函（带题签）与卷轴束，问事录书架为线装书与靛蓝函套，书案上有毛笔字册页、笔筒、砚台与印盒。启屏：月亮有月面明暗与两层光晕，夜空分高低两层云并在近月处镶银边，香炉烟变淡变低不再遮门，殿门打光加强，启屏顶部的暗化遮罩减轻。藏经阁、问事录面板常驻在屏外，滑入不再重绘，问事录数据在滑入后再刷新。
- 第五轮性能（2026-11-11）：殿堂、三清底座、藏经柜与书案的静态构件按材质合并（`src/scene/StaticBatch.tsx`；会动的部件放在 `userData.dynamic` 的组里，透明与实例化网格不合并），三清视角每帧绘制调用从 346 降到约 128；静态布景经 memo，仪式换阶段时不再重走整座殿的 React 树；场景内所有贴图在进入时预先上传；阶段变化后阴影只重画两帧。
- 第六轮（2026-11-11）：启屏殿门、灯笼更亮，「轻触 · 入殿」为发光按钮；入殿动画与问事仪式均可「跳过」（同一卦，只省动画），简洁问事偏好照旧记住。三清身后云屏改为平滑深漆、淡云纹；石桌石纹降低对比，卦爻凹槽与刻字更亮。读卦页默认只显示「简断」（接入后为作者审定的断语摘要；未接入时注明为体用结构判断），「详断」「专业依据」逐层展开。藏经阁卦页列出本次所用依据（爻辞、体用证据、类占原文），等级注明出自所传六十四卦吉凶表。问事录说明「全部问事」与「已入册」的区别；断语首次所得即按卦冻结保存（`src/domain/judgmentStore.ts`），之后更新不覆盖。
- 专业依据（2026-11-11）：顶部「从卦象证据直接对应断语」——目前／经过／后势三列（卦名与体用标签，体互用互不同时如「互克兼比」），下附「卦象依据」一句（引擎 `synthesis.evidenceSummary`）与「古籍依据」链接（打开《梅花易数》该类占法全文与《体用互变之诀》，本次所引句子高亮）。卦卡之间留白加大；原文链接写明去处，如「查看《雷火丰·九三》原文」。

## 已落实的关键约定

- **爻位**：所有爻对象携带 `{ stage, hexagramId, linePosition }`，1 在下、6 在上；阴爻左右两段共用一个触摸区，查同一条记录。
- **动爻**：只有本卦本次动爻持续发金光；互卦无独立动爻；变卦只在对应位置标一个小圆圈，文字注明“非第二动爻”；浏览中的爻用白色选中态。
- **体用**：动爻所在经卦为用，静经卦为体；箭头方向取自引擎 `edges` 的真实 from/to。形状区分关系：克 = 实线、实心箭头、尾横；生 = 虚线、开口箭头；比和 = 双线无箭头。
- **等级**：前台显示 `rawGrade`（姤显示“中卦”），英文附五档 `canonicalGrade`。等级不随月令、空亡改变。
- **详情顺序**：卦名等级 → 本次动爻标记 → 经文/白话/小象 → 爻位事实与正确变卦 → 新编经义说明 → 点击后才加载的整理注解（标注来源性质）→ 本次依据（体用、四条生克、六节点时令与旬空、出空节点、领域原文）。
- **请求顺序**：详情请求带序号，旧响应不会覆盖新点击；详解加载失败保留基础经文并可重试；内容版本不一致显式报错。
- **冻结**：起卦在点「入观」时冻结一次；刷新或切后台后以同一份记录继续，不重新起卦。
- **缺资料**：手动联调未填月建/日干支时显示“待提供”；不生成分数、成功率或确定日期。

## 起卦法（`src/domain/methods.ts`）

每法皆按 `data/meihua-sections.json` 原文取数，再由引擎“卦以八除、爻以六除”。先天数：乾一 兑二 离三 震四 巽五 坎六 艮七 坤八。

| 起卦法 | 上卦 | 下卦 | 动爻总数 | 所据篇目 |
| --- | --- | --- | --- | --- |
| 年月日时 | 年支数 + 农历月 + 日（+ 姓氏笔画） | 上卦数 + 时支数 | 同下卦数 | 年月日时起例；起卦加数例（加姓） |
| 物数 | 所见之数 | 时支数 | 物数 + 时数 | 物数占例 |
| 声音 | 闻声之数 | 声数 + 时数 | 同下卦数 | 声音占例 |
| 字占 | 十一字以上：字数一半（不匀则少一字为上） | 其余字数 | 总字数 | 字占；一字占至十一字占 |
| 字占（十字以内） | 用户按所示规则填写（笔画或平仄） | 同左 | 上 + 下 | 一字占至十一字占 |
| 物象方位（为人、自己、动物） | 所见之象的卦数 | 来方（后天方位）卦数 | 两卦数 + 时数 | 物卦起例（端法后天起卦）；为人占；八卦万物属类 |
| 尺寸 | 尺数 | 寸数 | 尺 + 寸 + 时数 | 尺寸占 |
| 丈尺 | 丈数 | 尺数 | 丈 + 尺 | 丈尺占 |

“物数占例”原文为“以时数配作下卦”，按字面取时数为下卦；“声音占例”明言“加时数配作下卦”，故两法不同。起卦时辰默认取此刻，也可指定（如屋宅初创、器物初成、动物初生之时，见占静物、占动物）。起卦时辰显示在入殿界面，并刻于石桌体用一行之下。

## 历法政策（每次起卦一并保存）

使用 [lunar-javascript](https://github.com/6tail/lunar-javascript) 1.7.7（MIT），已用测试核对：2024-02-10 甲辰正月初一、2026-02-17 丙午正月初一、2000-01-01 戊午日、2023 闰二月、2026 立春 02-04 04:02（北京时间）前后月建丑/寅。

| 政策 | 默认 | 可选 |
| --- | --- | --- |
| 时钟 | 本地时间直接入历（`local-wallclock`） | 换算北京时间入历 |
| 子时 | 23:00 起算次日（子时换日） | 晚子时仍属当日 |
| 闰月 | 按本月数（闰四月记 4） | 记为下一月数 |
| 起卦年支 | 正月初一换年 | 立春换年 |
| 月建（论旺衰） | 按节气交节时刻 | — |

这些是显式工程约定，不宣称是唯一古法。已测试美国夏令时开始（2026-03-08）、结束（2026-11-01 两个 01:30 对应不同 UTC 偏移）与本地跨日。已保存记录不会因设备时区变化而重算。
