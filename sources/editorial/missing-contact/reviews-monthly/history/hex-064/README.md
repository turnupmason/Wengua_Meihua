## 修订不等于新增完成数

下半的引用格式、九二月气与额外生助的区别、六三两坎生末巽，及上半的六五守正前提、上九实际寻获终点与末木生原用，均有旧新内容和修订后的实际阅读记录。重复阅读只记录复读次数；同一篇无论改过几轮，完成进度均只计一篇。首次核读后仅看局部的情况也保留原记录，后续确实重新读完整篇后才计末版全文核读完成。

正式完成状态以 [首轮编辑回执](../../hex-064.json)、[独立第二读回执](../../../second-reviews-monthly/hex-064.json)、[阅读页](../../../../../../docs/missing-contact/monthly-preview/hex-064.md) 以及目录进度为准。传统取权中仍有解释余地的事项在回执中公开保留，不把阅读和机器核对写成真人审定或现实效度证明。
